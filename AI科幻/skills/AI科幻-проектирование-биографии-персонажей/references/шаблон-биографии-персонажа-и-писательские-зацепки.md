# Дополнение к шаблону биографии персонажа и писательским зацепкам (ИИ-фантастика)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/общий-проектирование-биографии-персонажей/references/минимальная-структура-биографии.md`

## 1. Дополнительные поля ИИ-фантастики

- Функциональная позиция в расследовании: преследователь линии / блокирующий / вводящий в заблуждение / «привратник» следов данных
- Триггеры риска: ключевые слова старого дела, аномальные квитанции, нарушенный порядок процедур, противоречивые показания
- Тип тайны: подтверждаемая доказательствами тайна + опровергаемое введение в заблуждение

## 2. Дополнительные пункты писательских зацепок

- Ритм высвобождения информации в диалоге (за раз раскрывать только один слой)
- Цепочка действий в сценах высокого давления (наблюдение -> решение -> оставление следа -> контрмера)
