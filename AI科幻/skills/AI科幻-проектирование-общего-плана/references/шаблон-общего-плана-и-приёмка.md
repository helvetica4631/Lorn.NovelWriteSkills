# Дополнение к шаблону общего плана и приёмке (ИИ-фантастика)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/общий-проектирование-общего-плана/references/шаблон-общего-плана-и-приёмка.md`

## 1. Способ использования (обязательно)

1. Сначала по общему главному шаблону завершить структуру общего плана.
2. Затем наложить специальные пункты ИИ-фантастики из этого файла.

## 2. Специальные дополнения ИИ-фантастики

- Общий план обязан чётко описывать четырёхзвенное согласование «загадка основной линии — сюжетный случай-юнит — цепочка данных — цепочка возвратов».
- Стратегические поверхности истории должны удовлетворять честности данных: ключевая информация адресуема, введение в заблуждение опровержимо.
- Матрица сюжетных случаев-юнитов в первую очередь охватывает: действия расследования, поле следов данных, системное трение, узлы вознаграждения.
- Межтомовое нарастание должно отражать «расширение пула подозреваемых -> внезапный поворот следов данных -> приближение правды -> приземление цены».

## 3. Дополнительные пункты приёмки ИИ-фантастики

- [ ] Как минимум 1 основная линия в первых двух томах завершает замыкание «поворот следов данных + логическая согласованность».
- [ ] У ключевых предзнаменований полный путь «закладка — продвижение — раскрытие — отголосок».
- [ ] Инженерия дочитывания глав учла цепкость первого экрана и вознаграждение середины, избегая «нагромождения загадок».
