# Список усталых слов научно-фантастического жанра

> Источник: усвоено из правил технической согласованности `sci-fi.md` InkOS и исследования частотных слов ИИ
> Область применения: жанры ИИ-фантастики и космической фантастики
> Способ использования: при создании активно избегать, при рецензировании сканировать превышения
> Норма контроля: не более 2 раз на тысячу знаков

## Усталые слова первого уровня (высокий приоритет, по возможности не использовать)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| 高科技 (хай-тек) | Пустой ярлык, нет информации | Писать конкретное техническое название и форму (квантовый дисплей / углеродный каркас) |
| 未来感 (ощущение будущего) | То же | Писать конкретные визуальные отличия (стены живые / тень отстаёт от предмета на такт) |
| 编码/代码 (кодирование / код) | Универсальное описание программиста, высокая частота у ИИ | Писать конкретный интерфейс / голографическую проекцию / жест управления |
| 数据流 (поток данных) | Абстрактное визуальное описание | Писать конкретные элементы интерфейса (прокрутка цифр / мигание красного предупреждения) |
| 意识上传 (загрузка сознания) | Исчерпанное киберпонятие, прямое называние — лень | Писать конкретное переживание (глаза закрылись и открылись — а тело уже другое) |

## Усталые слова второго уровня (средний приоритет, контролировать частоту использования)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| 赛博/赛博朋克 (кибер / киберпанк) | Ярлычная эстетика, уход от конкретного описания | Писать конкретный визуал (отражение неоновых огней в дожде / царапины на механической руке) |
| 纳米/纳米级 (нано / наноуровень) | Универсальный технический префикс | Писать конкретную функцию, а не принцип |
| 量子 (квантовый) | То же, уже стал белым шумом научно-фантастического фона | Писать конкретный эффект (запутанное состояние / коллапс / невзламываемая связь) |
| 反重力 (антигравитация) | Универсальное слово парения | Писать конкретный механизм парения (магнитный рельс / ионная тяга) |
| AI 觉醒 (пробуждение ИИ) | Чрезмерно использованный сюжетный шаблон | Писать конкретное изменение поведения (он отказался от указания / сам переписал собственный код) |

## Усталые слова третьего уровня (вспомогательный, обрабатывать только при плотном появлении)

| Усталое слово | Пояснение |
| -------- | ------ |
| 黑暗森林 (тёмный лес) | Эффект «Задачи трёх тел», чрезмерно цитируется |
| 降维打击 (удар понижением размерности) | То же |
| 宏观/微观 (макро / микро) | Слова абстрактной точки зрения, в основном тексте не стоит часто переключать |
| 平行宇宙 (параллельная вселенная) | Универсальный объяснитель, использовать с осторожностью |
| 虚拟现实/全息 (виртуальная реальность / голограмма) | Уже недостаточно фантастично, нужно более конкретное описание взаимодействия |

## Принципы описания технологий (производные от правил технической согласованности InkOS)

1. **Технология проявляется через взаимодействие**, а не через учебникоподобные пункты: ✗ «Это устройство мгновенной связи на основе квантовой запутанности» → ✓ «Она сунула записку в щель переборки, и через три секунды с той стороны донёсся стук»
2. **У каждой технологии обязаны быть ограничения и побочные эффекты**: временной сдвиг от FTL, задержка ответа ИИ, боль от наноремонта
3. **У новой технологии обязан быть социальный смысл**: изменение уровня безработицы после появления сверх-ИИ, демографическая политика из-за технологии долголетия

## Принципы обработки усталых слов

1. **Слов первого уровня в основном тексте должно быть близко к нулю**.
2. **Слов второго уровня — не более 1 раза на тысячу знаков**.
3. **Слова третьего уровня обрабатываются только при непрерывном плотном появлении**.
4. **Структурные проблемы обрабатываются правилами научно-фантастического жанра InkOS**: эта таблица обрабатывает только уровень лексики, проблемы технической логики обрабатываются в `правила-фантастического-жанра-inkos.md`.
