# Дополнение к отчёту рецензии основного текста главы

## Что в отчёте нужно прописать особенно подробно

### 1. Вывод об опыте читателя

Обязательно записать короткими фразами:

- Какова наибольшая награда этой главы
- Какова наибольшая точка дочитывания этой главы

### 2. Награда в середине

Нельзя говорить только «ритм ещё нормальный», обязательно указать:

- Тип награды
- В каком кадре она находится
- Достаточно ли ясна

### 3. Согласованность с биографиями

В объекте «глава» проверка по биографиям персонажей относится к уровню P0, её нельзя пропускать мимоходом.

### 4. Минимальные рекомендации по записи обратно

Рекомендуемые формулировки:

- В `【段落 / 场景】` (абзац / сцена) добавить `【数据痕迹/ 冲突 / 代价】` (следы данных / конфликт / цена), чтобы середина больше не крутилась вхолостую.
- Заменить `【当前结尾】` (нынешний конец) на хук типа `【转折 / 揭露 / 危机】` (поворот / раскрытие / кризис), усиливая необходимость следующей главы.
- В `【对话 / 动作】` (диалог / действие) добавить штрих подписи персонажа, чтобы уменьшить «одну интонацию на всех».

## Центр тяжести оценки

- Читаемость и погружение: наивысший приоритет
- Награда в середине: высокий приоритет
- Хук конца главы: высокий приоритет
- Согласованность персонажей: высокий приоритет
- Честная дедукция: средне-высокий приоритет
