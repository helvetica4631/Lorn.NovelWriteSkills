# Раунды рецензирования и правки общего плана / тома и стратегия записи обратно

## Порядок замкнутого цикла ИИ-фантастики по умолчанию

### Объект: общий план

- Сначала `AI科幻-рецензия-общего-плана`
- Затем `AI科幻-проектирование-общего-плана`
- Затем вернуться к `AI科幻-рецензия-общего-плана`

### Объект: план тома

- Сначала `AI科幻-рецензия-плана-тома`
- Затем `AI科幻-проектирование-плана-тома`
- Затем вернуться к `AI科幻-рецензия-плана-тома`

## Три типа проблем, на которые каждая правка обязана отвечать в первую очередь

1. Нет ли разрыва в подхвате вышестоящего
2. Нет ли разрыва в питании главной линии / награде в середине глав / обещании первого тома
3. Не потеряны ли при правке жанровые технические якоря, рамки процедур, платформенное прочтение

## Правило обновления одного основного отчёта

- Для одного объекта ведётся только один основной отчёт.
- Каждая повторная рецензия перезаписывает один и тот же файл, без параллельных ответвлений.
- В сводке правок должно быть видно: какие типы проблем исправлены в этом раунде, какие ещё не прошли порог.

## Напоминание: нельзя красть шаги

- Нельзя только давать рекомендации, не правя файл.
- Нельзя только править файл, не делая повторной рецензии.
- Нельзя останавливаться на 9.2; оценка должна быть строго больше 9.2.
