# Приёмы отчуждения городского микропространства и запретные пункты

## Три шага отчуждения микропространства

1. Сначала дать нормальный порядок пространства.
2. Затем дать небольшое, легко игнорируемое, но неприятное отклонение.
3. Заставить персонажа проверить отклонение действием и тут же получить последствия.

## Подходящие источники аномалии

- Системный контроль доступа / лифт / дежурные правила
- Освещение / эхо / наблюдение / рабочие пропуски / квитанции
- Повторяющийся процесс, который в пространстве должен быть стабилен, внезапно искажается

## Запреты

- Не писать микропространство как нагромождение пустых кадров.
- Не допускать, чтобы аномалия достигала вершины за один шаг, без слоёв нарастания.
- Не допускать, чтобы был только страх без действий и последствий.
- Не писать чистую страшилку-безделушку, оторванную от технического якоря.
