## 1. Дополнительные поля индекса ИИ-фантастики

- Состояние зацепки: заложена / продвинута / опровергнута / возвращена
- Состояние следов данных: появление / конфликт / разворот / реализация
- Роль персонажа: триггер подозрений, поставщик введения в заблуждение, продвижение правды, носитель цены

## 2. Дополнительные пункты приёмки индекса

- [ ] Индекс каждого уровня способен ответить на вопросы «что сделал персонаж, что потерял, что узнал».
- [ ] Для ключевых пунктов введения в заблуждение обязательно есть соответствующая точка опровержения.
