# Границы жанра и описание входа (ИИ-фантастика)

> Формат: табу жанра → специальные правила → железные языковые правила → руководство по повествованию → справка по ритму
> Это стандартный пятираздельный шаблон жанровых правил, все описания границ и входа жанров организованы по этой структуре.

## Табу жанра

- Научно-технические правила произвольно меняются ради сюжета: как только установлены физические / технические настройки, нужно сохранять их согласованность
- Технология решает всё: у каждой технологии должны быть ограничения и побочные эффекты
- Свалка технологий: научно-технические пояснительные тексты вне ключевых моментов сюжета
- Игнорирование социального смысла технологий: FTL, ИИ, биотехнологии — всё требует учёта социальных последствий
- Манера поведения будущих персонажей не отличается от современных людей: нужно показывать эволюцию культуры / языка / социальных структур

## Специальные правила

### На что эта жанровая линия по умолчанию должна ответить

- Где вход технической аномалии.
- Какой технический порядок аномалия разорвала первым.
- С какой технической идентичностью / методологией герой входит в игру.
- Как следы данных, алгоритмические аномалии, системные журналы продолжают усиливать опасность.
- Почему долгая техническая загадка способна выдержать долгое произведение, а не заканчивается на одном деле.

### Условия минимального замыкания

- У каждой технологии должны быть определённые ограничения и побочные эффекты.
- Новая технология создаёт новые проблемы — не только решает старые.
- Технология проявляется во взаимодействии, а не через учебникоподобные пункты.
- Хард-фантастика: научные принципы и последствия нуждаются в логической проверке, читатель проверит.
- Космическая опера: внутренние правила едины на протяжении всего текста, наука может быть мягкой, но не может быть логических разрывов.

## Железные языковые правила

- **Технология проявляется во взаимодействии**: ✗ «Это устройство мгновенной связи на основе квантовой запутанности» → ✓ «Она сунула записку в щель переборки, и через три секунды с той стороны донёсся стук»
- **Избегать нагромождения технических ярлыков**: не использовать пустые ярлыки вроде «высокие технологии», «ощущение будущего», «наноуровень» вместо конкретного описания
- **Технические объяснения встраивать в действие**: технические принципы естественно проявляются, когда технологию «используют / ломают / ей не хватает», не провозглашать их в спокойных сценах
- **Хард-фантастические термины должны быть точными**: неверные термины разрушают правдоподобие сильнее, чем неиспользование

## Руководство по повествованию

- Ключевой драйв ИИ-фантастики — «техническая разгадка»: читатель дочитывает, потому что «хочет узнать всю картину системной аномалии»
- Двухлинейное продвижение: в каждом томе одно техническое событие (замыкание технического юнита), одновременно скрытая линия продвигает системную загадку
- Хард-фантастика: ритм логического продвижения решения, каждая глава должна продвигать понимание или создавать новые ограничения
- Космическая опера: между экшн-сериями нужны политические / межличностные дуги
- Главы-исследования строят трепет через опыт персонажей, не опираясь на информационную свалку мироустройства
- Технические раскрытия появляются только в ключевые моменты сюжета

## Справка по ритму

- Раскрытия технологий и экшн-сцены чередуются, один цикл ритма на каждые 2–4 главы
- Структура сюжетного случая-юнита: обнаружение аномалии → отслеживание данных → рассуждение и моделирование → технический разворот → вывод и отголосок
- В каждом томе как минимум 1 поворотная веха технического восприятия
- Ритм нарастания противоречия: технические проблемы → человеческое противостояние → этическая дилемма → системный кризис
