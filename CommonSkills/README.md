# Описание каталога CommonSkills

Этот каталог содержит **основу общих Skill, стабильно переиспользуемых между жанрами**.

Эти Skill — цель маршрутизации для жанровых версий Skill в каталогах жанров; жанровые версии отвечают за **обнаруживаемый вход, жанровую обёртку и дополнение границ жанра**, а общие Skill поддерживают основу общих возможностей.

## Назначение каталогов

- `CommonSkills/`: основа общих Skill.
- `CommonSkills/写作研究/`: межжанровые писательские исследовательские материалы, относящиеся к возможностям общего слоя.
- `CommonSkills/短篇小说集最佳实践.md`: справочный файл с лучшими практиками написания рассказов.
- `CommonSkills/长篇小说最佳实践.md`: справочный файл с лучшими практиками написания длинных романов.
- `каталог жанра/.github/skills/`: жанровая обёртка, жанровые входы, дополнения, специфичные для жанра.
- `scripts/`: общие скрипты, не принадлежащие конкретному Skill.
- `仅用于参考/`: внешние справочные материалы, не являющиеся нормативными ресурсами возможностей.

## Принципы использования

- Ключевые возможности, стабильно переиспользуемые между жанрами, в первую очередь следует закреплять как общие Skill.
- Для возможностей, у которых уже есть общий Skill, на стороне жанра нужно создать соответствующую жанровую версию Skill как точку обнаружения по умолчанию.
- Жанровая версия Skill обязана явно загружать, вызывать или вызывать в комбинации соответствующий общий Skill.
- Общие правила ведутся только в общих Skill и не копируются параллельно в жанровую обёртку.

## Механизм автообнаружения шаблонов стиля / образца / писательских исследований

Нижестоящие Skill для написания / рецензирования / правки единообразно находят и используют три вида шаблонов через `Agents.md` в корне проекта романа:

| Вид шаблона | Skill-источник | Область действия | Число потребляющих Skill |
| --- | --- | --- | --- |
| Шаблон авторского стиля | `通用-蒸馏作者文风` | Ограничения письма (длина фраз, абзацы, чувства, диалоги, метафоры, запреты) | 33 нижестоящих Skill |
| Шаблон образца произведения | `通用-蒸馏作品蓝本` | Структурные ограничения (шаблоны начала главы, ротация хуков, интервалы наград, распределение темпа) | 33 нижестоящих Skill |
| Шаблон писательского исследования | `通用-蒸馏写作研究` | Базовая линия ограничений по умолчанию «жанр × платформа» | 33 нижестоящих Skill |
| Авторский стилевой портрет / библиотека живых образцов (динамические данные эволюции) | `通用-作者风格进化` | Живые образцы речи из интервью → дистиллированный портрет (повествовательный голос / мотивы / библиотека голосов персонажей) | Замкнутый цикл эволюции + предварительное встраивание в этапы создания + списание при написании / рецензировании / правке |

**Приоритет**: шаблон, явно указанный пользователем > шаблон писательского исследования > общая базовая линия по умолчанию.

**Деградация**: если в корне проекта нет `Agents.md` или соответствующий шаблон не зарегистрирован — все нижестоящие Skill автоматически возвращаются к общему режиму по умолчанию, без ошибок и без блокировки.

**Место регистрации**: файлы шаблонов выдаются в каталог `蒸馏产物/` проекта романа и регистрируются записью в `Agents.md` в корне проекта. Нижестоящие Skill при запуске читают `Agents.md` как единственный источник истины для обнаружения шаблонов.

- Если в будущем действительно потребуется переименование, сначала нужно единообразно изменить имена каталогов, а затем синхронно обновить README и сопоставления жанровых обёрток.
- Пока имена каталогов официально не перенесены, в README не ведётся параллельный набор «рекомендуемых новых названий».

## Отношения с жанровыми обёртками

Этот каталог поддерживает только основу общих возможностей; соответствующие Skill в каталогах жанров должны отвечать за:

- сохранение обнаруживаемости по названию жанра;
- роль входа по умолчанию для этого жанра;
- явную загрузку, вызов или вызов в комбинации соответствующего общего Skill;
- дополнение границ жанра, запретов жанра, групп файлов жанра и жанровых шаблонов.

Не копируй полный набор правил общего Skill заново в жанровую обёртку.
