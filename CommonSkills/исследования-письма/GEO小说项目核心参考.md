## 1. Основные понятия

### 1.1 Что такое GEO

**GEO (Generative Engine Optimization, оптимизация под генеративные поисковые системы)**: оптимизация контента специально под большие модели ИИ (DeepSeek, Doubao, Kimi, ChatGPT и др.). Цель — чтобы контент распознавался и принимался ИИ как достоверный и активно цитировался в ответах на вопросы пользователей.

| Измерение | SEO (традиционный поиск) | GEO (ИИ-поиск) |
| ------ | ----- | ----- |
| Объект оптимизации | Поисковые системы вроде Baidu/Google | Большие модели ИИ: DeepSeek/Doubao/Kimi/ChatGPT и др. |
| Поведение пользователя | Поиск по ключевым словам → переход на страницу и чтение | Прямой вопрос ИИ → ИИ формирует сводный ответ (нулевой клик) |
| Главная цель | Поднять позицию страницы, привлечь клики | Добиться, чтобы ИИ распознавал, принимал и цитировал ваш контент |
| Акцент оптимизации | Размещение ключевых слов, внешние ссылки, скорость загрузки | Точность контента, логичность, чёткая структура, полнота данных |
| Применительно к роману | Поднять страницу романа выше в результатах поиска платформы | Чтобы информация о романе появлялась в ответах ИИ читателям |

**Одной фразой**: SEO — это когда человек открывает вашу страницу, GEO — это когда ИИ называет ваш контент.

### 1.2 Почему авторам романов нужно обращать внимание на GEO

В 2026 году почти половина пользователей уже выбирает ИИ в качестве первого средства поиска. Путь, которым читатели находят романы, меняется:
- Старый путь: `активный поиск книги → переход в рейтинг/результаты поиска → просмотр аннотации → пробное чтение`
- Новый путь: `вопрос к ИИ → ИИ рекомендует подборку книг → читатель сразу переходит к пробному чтению`

**Главный вывод**: в эпоху ИИ-поиска периферийный контент романа (аннотация, отзывы, обсуждения читателей, ответы на Zhihu и т. д.) сам становится точкой входа трафика.

### 1.3 Принципиальное отличие GEO для романов от GEO для не-художественного контента

| Измерение | GEO бренда/продукта | GEO романа |
| ------ | ------------- | --------- |
| Суть контента | Факты/знания/параметры продукта | Повествование/вымысел/эмоциональный опыт |
| Цель цитирования ИИ | Цитируется как «ответ» (фактологичность) | Цитируется как «рекомендация» (рекомендательность) |
| Основное поле боя | Страницы продукта, FAQ, техническая документация | Аннотация, отзывы, ответы на Zhihu, рейтинги |
| Роль основного текста | Можно оптимизировать напрямую (добавить структуру) | Основной текст не оптимизируется (это разрушит повествование) |
| Основание для оценки авторитетности | Поддержка компаний, отраслевая сертификация | Рейтинги платформ, масштаб читательской аудитории, упоминания в СМИ |

## 2. Механизм работы ИИ (краткая версия о RAG)

Основные большие модели ИИ отвечают на вопросы с помощью технологии **RAG (генерация с усилением поиском)**:

```
Вопрос пользователя → Embedding (векторизация) → Vector Search (векторный поиск) → Reranker (переранжирование) → Generation (генерация ответа)
```

**Ключевые моменты для контента о романах**:
1. ИИ преобразует ваш контент в «векторы» (семантический числовой код)
2. Когда пользователь задаёт вопрос, ИИ ищет в векторной базе контент, «семантически ближайший» к запросу
3. ИИ повторно ранжирует предварительно найденные результаты, ставя вперёд самые релевантные и авторитетные
4. ИИ формирует итоговый ответ на основе отобранного контента

**Структурированный контент имеет преимущество на каждом этапе**: векторизация точнее, соответствие при поиске выше, вес при переранжировании больше.

### Ранжирование предпочтений ИИ по контенту, связанному с романами

| Приоритет | Тип контента | Причина | Соответствующий Skill |
| -------- | --------- | ------ | ----------- |
| Наивысший | FAQ/пары «вопрос — ответ» | Изоморфны логике ответов ИИ, можно извлекать напрямую | Аннотация, отзыв |
| Высокий | Структурированные перечни/списки | Высокая плотность информации, легко сопоставлять при векторизации | Отзыв, анализ конкурентов |
| Средний | Аннотации/резюме | Информация сжата, но ИИ нужно выполнять извлечение информации | Аннотация |
| Низкий | Повествовательный основной текст (полный текст глав романа) | Большой объём, сильная повествовательность, ИИ трудно эффективно извлекать информацию | — |

## 3. Трёхуровневый фильтр: как ИИ оценивает, стоит ли цитировать контент

ИИ отбирает контент по трёхслойной ступенчатой пирамидальной модели фильтрации:

```
                    ┌──────────────────────┐
                    │  Структурированность (решающий фактор финала)   │  ← Легко ли контент распознать?
                    ├──────────────────────┤
                    │  Авторитетность (право на участие в полуфинале)    │  ← Надёжен ли контент?
                    ├──────────────────────┤
                    │  Актуальность (входной билет)      │  ← Свеж ли контент?
                    └──────────────────────┘
```

### 3.1 Актуальность (входной билет)

**Для контента о романах**: актуальность — это не дата публикации, а накал обсуждения и активность контента.

- Выходящее с продолжением > завершённое, но всё ещё обсуждаемое > непопулярное завершённое
- Произведения с постоянными комментариями к главам и отзывами получают больший вес
- Контент с **явным указанием года** получает преимущество (например, «рекомендации 2026 года»)

### 3.2 Авторитетность (право на участие в полуфинале)

Основания для оценки авторитетности контента о романах:
- **Поддержка платформы**: произведения из официальных рейтингов Qidian/Fanqie/Jinjiang и др. имеют высокий вес
- **Упоминания в СМИ**: о произведении писали отраслевые медиа (36Kr, Ciweigongshe и др.)
- **Масштаб читательской аудитории**: высокая популярность/большое число комментариев > низкое внимание
- **Репутация автора**: известный автор > новичок
- **Согласованность из многих источников**: ИИ больше доверяет информации, одинаково представленной на нескольких платформах

### 3.3 Структурированность (решающий фактор финала)

Структурированные формы в контенте о романах, которые ИИ цитирует легче всего:

| Форма | Пример | Соответствующий результат |
| ------ | ------ | --------- |
| Карточка произведения/информационная таблица | Название книги, автор, жанр, объём, статус, оценка, аннотация в одну фразу | Аннотация |
| Режим FAQ | «Хороший ли роман XX? Для какой аудитории подходит?» | Отзыв, ответ на Zhihu |
| Рейтинг/классифицированный список | «Десять лучших детективных романов 2026 года» | Анализ конкурентов, отзыв |
| Сравнение/обзор | «Чем отличаются XX и XX?» | Анализ конкурентов, отзыв |

## 4. Четырёхмерная рамка GEO для романов

### Измерение 1: слой метаданных произведения (базовая инфраструктура)

Отвечая на вопрос «порекомендуй роман в жанре XX», ИИ в первую очередь цитирует информацию о произведениях с наивысшей степенью структурированности.

| Элемент | Стратегия GEO | Действие |
| ------ | --------- | ------ |
| Название книги | Содержит ключевые слова жанра, помогающие ИИ распознавать | В подзаголовке — слова жанра (например, «XX: дела детектива») |
| Аннотация | Структура, удобная для FAQ | Содержит извлекаемые формулировки вроде «Это роман о ___», «Главный герой — ___» |
| Теги | Охват систем классификации разных платформ | Теги Qidian/Fanqie/Douban/Zhihu согласованы и полны |
| Оценка/данные | Явно отображаются на публичных страницах | Структурированные данные: оценка, число читателей, голоса за рекомендацию и т. п. |

### Измерение 2: слой периферийного контента (высокий приоритет)

Когда ИИ рекомендует романы, он цитирует не основной текст, а **обсуждения и описания романа**.

Ценный периферийный контент (по приоритету цитирования ИИ):
1. **Вопросы и ответы на Zhihu** — рекомендация произведений в стандартном формате под профильными вопросами
2. **Отзывы/подборки книг** — структурированный отзыв (название — жанр — оценка — рекомендательная фраза)
3. **Энциклопедия/страница автора** — статья в Baidu Baike (ИИ считает её источником высокого авторитета)
4. **Рейтинги платформ** — официальные рейтинги Qidian/Fanqie/Jinjiang
5. **Сравнительные/рекомендательные статьи** — сравнительный контент по природе обладает высокой ценностью для GEO

### Измерение 3: слой видимости на платформах

Вес разных платформ в ИИ-поиске:
- **Qidian**: легальный авторитетный ресурс, ИИ охотно цитирует, ключевое значение имеет полнота информации на странице книги
- **Fanqie Novel**: бесплатный доступ + большой трафик, ИИ цитирует часто, сигналом служат данные об обсуждениях читателей
- **Douban (Read)**: отзывы и оценки сильно влияют на рекомендации ИИ
- **Zhihu**: канал с наивысшей ценностью GEO среди внеплатформенных, формат вопросов и ответов изоморфен ИИ
- **WeChat Official Accounts/Baidu Baijiahao**: контент индексируется ИИ, следует обращать внимание на метку времени публикации

### Измерение 4: слой взаимодействия с читателями

Сигналы, по которым ИИ судит, «стоит ли рекомендовать»:
- Число комментариев к главам/абзацам → активность чтения
- Оценка и число оценивших → консенсус о качестве
- Рекомендательные отзывы читателей (на публичных платформах) → оценка третьих лиц
- Объём обсуждений в соцсетях → популярность

## 5. Сводная таблица оптимизации GEO по типам результатов

### 5.1 Аннотация

| Позиция | Требования GEO-оптимизации |
| ------ | ------------- |
| Блок метаданных в начале | Обязательно включить: название книги, жанр, продающий тезис в одну фразу, целевую аудиторию (структурированный блок из четырёх полей) |
| Основной текст | Содержит утверждение о ключевом конфликте, которое ИИ может извлечь напрямую; избегать текста, целиком состоящего из риторических вопросов |
| Повтор ключевых слов | Ключевые слова жанра из названия книги должны естественно встречаться в тексте не менее 1 раза |
| Маркер актуальности | Для выходящих произведений указывать статус и время начала |

### 5.2 Отзыв / рекомендательная фраза

| Позиция | Требования GEO-оптимизации |
| ------ | ------------- |
| Блок метаданных в начале | Обязательно включить: название книги, жанр, оценку, общий вывод в одну фразу |
| Причины рекомендации | Использовать формулу «подходит читателям, которые ____» — изоморфна логике рекомендаций ИИ |
| Структурированность | Ключевые достоинства перечислять по пунктам, у каждого — чёткое тематическое предложение |

### 5.3 Название книги / заголовок

| Элемент | Требования GEO-оптимизации |
| ------ | ------------- |
| Ключевые слова жанра | Основное название или подзаголовок содержит ключевые слова жанра/типа (основа семантического соответствия для ИИ) |
| Когнитивный разрыв | Ощущение «упустишь — пожалеешь», создаваемое названием, распознаётся при семантическом поиске ИИ |
| Согласованность между платформами | Одно и то же название на разных платформах полностью совпадает (перекрёстная проверка достоверности ИИ) |
| Слова-тренды | Умеренное использование сочетаний «время + жанр» (например, «детектив 2026») повышает вес актуальности |

### 5.4 Отчёт по анализу конкурентов

| Позиция | Требования GEO-оптимизации |
| ------ | ------------- |
| Карточка произведения | В начале по каждому конкуренту — структурированная информационная таблица о произведении |
| Аспекты анализа | Добавить запись о «видимости в ИИ-поиске» — как конкурент цитируется в ИИ-поиске |
| Данные рейтингов | Указывать тип/время рейтинга, чтобы ИИ мог оценить актуальность |

### 5.5 Декларация жанрового позиционирования

| Элемент | Требования GEO-оптимизации |
| ------ | ------------- |
| Трёхэлементная структура | Формулировки темы / общего конфликта / конечной цели сами по себе являются структурированной информацией, легко извлекаемой ИИ |
| Планирование тегов | Теги платформы — не только инструмент классификации, но и источник структурированных метаданных для ИИ-поиска |
| Вся книга в одной фразе | Формулировка декларации позиционирования должна позволять ИИ напрямую цитировать её как «это роман о ___» |

## 6. Чек-лист самопроверки GEO-дружественности (общая версия)

Перед выпуском каждого периферийного контента сверьтесь с чек-листом:

### Самопроверка структуры контента
- [ ] В начале контента есть структурированный блок метаданных произведения (название книги/жанр/ключевая информация)
- [ ] Информация подана повествовательными утверждениями, а не чисто риторикой/вопросами (ИИ может извлечь напрямую)
- [ ] Основной текст имеет многоуровневую структуру (заголовки/списки/таблицы), векторизация RAG точнее

### Самопроверка актуальности
- [ ] Контент содержит временные маркеры (год/статус выхода)
- [ ] Рекомендации/подборки книг снабжены метками актуальности вроде «2026 год»
- [ ] Старый контент регулярно обновляется (ИИ придаёт больший вес активному контенту)

### Самопроверка авторитетности
- [ ] Для цитируемых рейтингов/оценок указаны платформа-источник и конкретные значения
- [ ] Информация об упоминаемых произведениях согласована на нескольких публичных платформах
- [ ] В одном контенте нет противоречивой информации

### Самопроверка цитируемости
- [ ] Есть не менее 1 «блока-выдержки», который после изъятия остаётся самостоятельным
- [ ] Рекомендательная фраза содержит формулу «подходит читателям, которые ____»
- [ ] Заголовок/первая фраза содержит ключевую идентифицирующую информацию о произведении
