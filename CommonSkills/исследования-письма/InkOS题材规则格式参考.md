# Справочник по формату файлов жанровых правил InkOS (заимствование Cross-Genre)

> Источник: [Narcooo/inkos/packages/core/genres/](https://github.com/Narcooo/inkos/tree/master/packages/core/genres)
> 15 встроенных в InkOS файлов жанровых правил (xuanhuan.md, xianxia.md, urban.md, horror.md, litrpg.md, progression.md, cultivation.md, isekai.md, sci-fi.md, romantasy.md, system-apocalypse.md, dungeon-core.md, cozy.md, tower-climber.md, other.md)
>
> Достаточность доказательств: достаточная — 15 файлов жанровых правил образуют полную систему жанровых правил
> Уровень уверенности: высокий — систему правил жанров можно использовать повторно как стандартную шаблонную структуру жанрового Skill
> Принадлежность к платформе: общая трактовка (по умолчанию)

## Общая структура файлов жанровых правил InkOS

Каждый файл жанровых правил InkOS (`.md`) следует единой структуре:

### YAML Frontmatter (метаданные)

```yaml
---
name: <题材中文/英文名>
id: <идентификатор жанра>
language: zh/en          # язык по умолчанию
chapterTypes:            # типы глав (может быть пустым)
fatigueWords:            # список «слов-усталости» (может быть пустым)
numericalSystem: true/false  # есть ли числовая система
powerScaling: true/false     # есть ли система боевой мощи
eraResearch: true/false      # требуется ли исследование эпохи
pacingRule: <правило ритма одной фразой>
satisfactionTypes:       # типы точек 爽 (может быть пустым)
auditDimensions:         # измерения аудита (может быть пустым)
---
```

### Стандартные разделы содержания (по порядку)

Каждый файл жанровых правил содержит следующие разделы (в порядке появления):

1. **Жанровые запреты (Genre Prohibitions)** — перечень того, что в этом жанре «делать нельзя»
2. **Специальные правила жанра** — название зависит от жанра:
   - `数值规则` (xuanhuan — правила проектирования числовой системы)
   - `修炼规则` (xianxia — правила системы совершенствования)
   - `System Design Rules` (litrpg — правила проектирования системы)
   - `Tech Consistency Rules` (sci-fi — правила технологической согласованности)
   - `Cultivation Rules` (cultivation — правила совершенствования в стиле сянься)
   - `World Transition Rules` (isekai — правила переноса в другой мир)
   - `Romance Rules` (romantasy — правила любовной линии)
   - `World Rules` (system-apocalypse — правила мира)
   - `Floor Design Rules` (tower-climber — правила проектирования этажей)
   - `Non-Human POV Rules` (dungeon-core — правила нечеловеческой точки зрения)
   - `Emotional Arc Rules` (cozy — правила эмоциональной дуги)
   - `年代与现实约束` (urban — эпоха и ограничения реальности)
   - `恐惧层级` (horror — модель нарастания страха)
3. **Железные правила языка (Language/语言铁律)** — языковые запреты и стилистические ограничения жанра
4. **Руководство по повествованию (Narrative Guidance/叙事指导)** — акценты повествования и рекомендации по структуре жанра
5. **Справка по ритму (Pacing Guidance/节奏)** — правила ритма для каждого этапа

### Ценность для данного репозитория

Жанровые Skill данного репозитория могут заимствовать эту структуру и организовывать жанровые правила в `references/` Skill `设计题材定位框架` по следующему шаблону:

```markdown
# Правила жанра <название жанра>

## Табу жанра
- ...
## <Специальные правила жанра>
- ...
## Железные языковые правила
- ...
## Руководство по повествованию
- ...
## Справка по ритму
- ...
```

Такой структурированный файл правил жанра может использоваться одновременно следующими Skill:
- `设计题材定位框架` (как входные данные жанровых правил)
- `创建小说正文` (как ограничения для творчества)
- `审阅章节正文` (как стандарт рецензирования)
- `设计总大纲` (как жанровая базовая линия)
- `设计人物传记` (как ограничения поведения персонажей)

## Справка по концепции списка «слов-усталости» InkOS

В файлах жанровых правил InkOS предусмотрено поле `fatigueWords` (сейчас пустое, ожидает заполнения) — концепция, которую стоит развивать и в этом репозитории:

- Для каждого жанра следует вести **список часто повторяющихся «слов-усталости»** (например, в сюаньхуане: «взрывной рост» (暴涨), «огромное количество» (海量), «не поддающийся оценке» (难以估量))
- Частоту использования этих слов в основном тексте жанра следует ограничивать
- Дополняет концепцию «кластеров частотных слов ИИ» (AI高频词簇) из `通用-去AI味重写`: частотные слова ИИ + «слова-усталости» жанра

> Рекомендуется в последующих итерациях добавить в `references/` каждого жанрового Skill файл `题材疲劳词表.md` — по аналогии с полем fatigueWords в InkOS.
