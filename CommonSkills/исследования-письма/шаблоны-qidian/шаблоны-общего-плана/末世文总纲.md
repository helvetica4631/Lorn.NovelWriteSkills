# Общий план постапокалипсиса

## 1. Хардкорное направление

- Выживание как внутренний мотив
- Отчаяние как общий тон
- Реализм как конкретные сцены

## 2. Лёгкое направление

- Выживание как внутренний мотив
- Душевный комфорт как общий тон
- Забава как приправа

## 3. 7 элементов

### 3.1 Фон апокалипсиса

- Зомби/вирус
  - Рукотворное происхождение
  - Образование в результате естественной мутации
  - Пришедшее из космоса
    - Метеорит с вирусом
    - Распространение инопланетянами
- Вторжение инопланетян/монстров
- Голод
- Вечный день, вечная ночь
- Стихийное бедствие
- Экстремальная среда
  - Экстремальные температуры (высокие, низкие)
  - Кислотные дожди, непрерывные ливни, ядовитые газы и т. д.
  - Загрязнение воздуха
  - Падение метеоритов на Землю
- Нашествие растений

### 3.2 Главный герой

- Преимущество во времени (先机)
  - Перерождение
    - В прошлой жизни был предан, брошен, подставлен
    - Случайное перерождение
    - Перерождение после смерти
    - Получение частичного предвидения
    - Возможный мотив: восполнить сожаления, изменить ход будущего
    - Возможный мотив: без сожалений, лишь ради выживания
  - Без перерождения
    - Заранее получил достоверные сведения
    - Нет информации, приспосабливается по обстоятельствам
- Товарищи по команде
  - Родители
  - Лучшая подруга
  - Парень/девушка
  - Братья и сёстры
  - Понимающие друг друга друзья

### 3.3 Распределение активов (может отсутствовать)

- Деньги
  - Выигрыш в лотерею после перерождения
  - Наследство от родителей
  - Крупный кредит
  - Накопления за много лет
- Убежище
  - Студенческое общежитие
  - Съёмная комната
  - Многоквартирный дом
  - Вилла
  - Большой одноэтажный дом

### 3.4 Путь развития

- Запасание припасов
  - Опора на сверхспособности, систему
    - Получение напрямую или обменом
    - Получение за выполнение заданий
  - Опора на деньги, заблаговременная закупка
    - Нужна определённая сумма и место для хранения (пространственная способность, недвижимость)
    - Припасы ограничены, на поздних этапах пополняются «золотым пальцем» или иными путями
  - Опора на поиск после катастрофы
    - Подготовки нет, припасы добываются целиком поиском снаружи
    - При таком направлении «золотой палец» служит для повышения способности к поиску, например: усиление тела, усиление восприятия
  - Примечание: необходимо оснастить пространством для хранения припасов (пространство системы, пространственная способность, ячейка/кольцо для хранения)
- Усиление себя
  - Награды за выполнение заданий системы для усиления себя
  - Убийство врагов, поиск особых предметов для повышения себя/сверхспособности
- Постройка крепости/базы конца света
  - Система/сверхспособность строит сооружения
    - Достаточно выполнить задание или выполнить условие, и можно строить сразу
    - Нужны материалы: сбор материалов, получение материалов за выполнение заданий, получение материалов обменом
  - Сбор выживших
  - По выбору
    - «Золотой палец» приводит людей, механизмы, роботов, которые помогают строить и развивать

### 3.5 Кризис

- Борьба за припасы, человеческая природа, встреча с «святой» (圣母, чрезмерно добросердечным человеком), хитроумная борьба со злодеями, безвыходное окружение, нехватка припасов

### 3.6 Месть

- Объективные факторы
- Косвенная вражда
- Человеческие факторы
  - Предательство, оставление, подстава, причинение вреда и т. д.
