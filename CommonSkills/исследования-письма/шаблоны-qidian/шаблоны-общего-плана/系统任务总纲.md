# Общий план системных заданий

## 1. Инструкция по использованию

### 1.1 Особенности плана

- Системными заданиями можно двигать развитие сюжета, требования к логической обоснованности низкие.
- Точка 爽 «выполнил задание, получил награду» прямая и эффективная, у неё широкая аудитория читателей.
- Порог входа в написание низкий, подходит для добавления в веб-романы любых жанров.
- Однотипных произведений много, а система лишь вспомогательна, поэтому нужно продумать коммерческие «точки продажи», чтобы выделиться.

### 1.2 Представительное произведение

- Хуэй Шуо Хуа Дэ Чжоуцзы (会说话的肘子), «Пощади, великий король» (《大王饶命》)

## 2. Настройки системы

### 2.1 Происхождение системы (с точки зрения главного героя)

- Получена при попаданчестве.
- Найдена случайно.
- Врождённая.
- Организована искусственно.

### 2.2 Способы общения

- Система в одностороннем порядке выдаёт задания.
- Возможен механический диалог.
- Обладает виртуальной личностью и ведёт настоящий диалог.
- За кулисами её играет человек, ведётся настоящий диалог.

### 2.3 Настройки наград

- Награду за выполнение заданий лучше привязывать к потребностям главного героя, пример: главному герою для культивации нужны очки для распределения, значит, в награду за задание даются очки.
- Награждаемые предметы и т. п. должны использоваться в будущем сюжете.
- Награждаемые предметы и т. п. должны обновляться по мере развития сюжета.

### 2.4 Разблокировка системы (необязательно)

- По мере роста главного героя могут разблокироваться новые возможности системы.

### 2.5 Магазин обмена (необязательно)

- Можно настроить получение очков за выполнение заданий для расширения возможностей магазина обмена.
- Можно задать дорогие товары как цель, направляющую главного героя к постоянному выполнению заданий.
- Товары должны обновляться по мере развития сюжета.

### 2.6 Атрибуты панели (необязательно)

- Можно задать панель и время от времени упоминать её, чтобы показывать изменения силы главного героя (необязательно).
- Рост числовых значений должен быть разумно продуман.
- Можно создать атрибуты других персонажей как систему отсчёта для силы главного героя (необязательно).

### 2.7 Примеры атрибутов

- Имя.
- Возраст.

### 2.8 Профессия

- Уровень/ступень.
- Атакующие: боевая мощь/сила атаки/боевая сила/интеллект.
- Защитные: прочность тела/запас здоровья/защита.
- Выносливость: магическая сила/мана/физические силы.
- Квалификационные: показатель таланта/уровень духовного корня/сродство со стихиями.
- Способностные: мастерство приёмов/уровень навыков.
- Другие распространённые атрибуты: ловкость/духовная сила/обаяние/сопротивляемость/сила души/удача.

## 3. Настройки заданий

### 3.1 Типы заданий

- Сюжетные: диалоги/сражения с другими персонажами и т. д.
- Исследовательские: расследование персонажей/мест/предметов/истории и т. д. по зацепкам.
- Коллекционные: сбор указанных материалов по требованиям и т. д.
- Испытательные: требование выполнить указанные события в ограниченное время и т. д.

### 3.2 Условия запуска

- Столкновение с опасностью.
- Появление нового персонажа.
- Прибытие в новую сцену.
- Достижение нового уровня.
- Выполнение предварительного задания.
- Получение новой информации при общении с другими персонажами.
- Периодический запуск по времени: ежедневное/ежемесячное обновление по расписанию и т. д.
- Наступление крупного события: влияющего на мир или судьбу главного героя и т. д.

### 3.3 Содержание задания

- Название задания.
- Тип задания: одиночный режим/командный режим.
- Фон задания.
- Конкретное содержание задания.
- Сложность задания.
- Награда за задание.
- Есть ли ограничение по времени.
- Является ли цепочкой заданий.

### 3.4 Подсчёт итогов задания

- Степень выполнения задания.
- Награда за выполнение.
- Наказание за невыполнение.

## 4. Сюжетные линии

### 4.1 Основная линия

- Главный герой постоянно становится сильнее.

### 4.2 Побочные линии (необязательно)

- Получение системы.
- Улучшение системы.
- Разгадка происхождения и целей системы.
