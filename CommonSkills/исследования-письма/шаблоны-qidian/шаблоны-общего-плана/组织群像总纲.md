# Общий план группового портрета организации

## 1. Инструкция по использованию

### 1.1 Особенности плана

- Через форму организации главный герой на разных этапах может обменивать подходящие ресурсы
- Взаимодействие с другими членами организации хорошо становится зацепкой для основной или побочной линии
- Необходимо постоянно создавать портреты членов организации, чтобы углублять впечатление

### 1.2 Представительное произведение

- Ай Цяньшуй Дэ Усэй (爱潜水的乌贼), «Повелитель тайн» (《诡秘之主》)
