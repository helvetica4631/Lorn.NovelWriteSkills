# Система классификации языковых стилей письма и комбинации, популярные у читателей

> **Тема исследования**: классификация языковых стилей написания романов, измеримые измерения, паттерны комбинаций, предпочитаемых читателями, и способ подключения этого к существующей системе Skill (регистрация в Agents.md → нижестоящие Skill написания / рецензирования / правки потребляют автоматически → при дистилляции авторского стиля извлекается соответствующее)
>
> **Основная область исследования**: исследование техник письма
>
> **Вспомогательные области исследования**: исследование читателей / рынка, исследование архетипов персонажей
>
> **Время исследования**: 2026-06-23
>
> **Метод исследования**: традиционная риторическая классификация стилей + наблюдение за предпочтениями читателей в веб-романной индустрии + перекрёстная проверка по источникам (раздел отзывов / «слово от автора» в главе / отраслевая аналитика / интервью с авторами)

## Ключевое открытие

### 1. Три источника существующих систем классификации стилей

Классификация языкового стиля — не единая система. Исследование показывает, что существует как минимум **три параллельных, но сопоставимых измерения классификации**, происходящих из разных областей — **риторика → литературное творчество → веб-романная индустрия**. Три системы можно переводить друг в друга, но у каждой свой акцент.

| Источник | Репрезентативная классификация | Преимущества | Недостатки |
| --- | --- | --- | --- |
| **Риторика / лингвистика** (традиционная китайская стилистика) | Восемь противопоставленных измерений: пышность-простота (藻丽-平实), ясность-сдержанность (明快-含蓄), изысканность-народность (典雅-通俗), обилие-краткость (繁丰-简洁), а также размах-изящество (豪放-婉约) | Полная система, чёткие определения, измеримость | Ориентирована на письменную литературу, не охватывает стилевые ярлыки, специфичные для веб-романов |
| **Литературное творчество** (исследования стиля писателей) | Типы рассказчика (сострадательный / суровый / насмешливый / погружающий) + способы выражения (описательный / диалоговый / лирический / повествовательный) | Тесно связана с творческими решениями, может прямо направлять, что писать | Мало измерений, гранулярность грубая |
| **Веб-романная индустрия** (рыночные / читательские ярлыки) | Лёгкий юмор / «шадяо» (沙雕, нелепый юмор) / горячая кровь / жёсткая решительность в убийствах / тёплая повседневность / тёмная глубина / головоломность / исцеляющий / душераздирающий / «сяобай» (小白, наивный герой) / «лаобай» (老白, прожжённый герой) | Прямо соответствует читательским ожиданиям и классификации платформ | Размытые определения, нет системного фреймворка |

> **Ключевая мысль**: три системы не исключают друг друга, а образуют **три круга изнутри наружу** — риторика определяет «языковую фактуру на уровне предложений», литературное творчество определяет «повествовательную стратегию на уровне текста», ярлыки веб-романов определяют «читательские ожидания на уровне рынка». Эффективный шаблон стиля должен охватывать все три уровня одновременно.

### 2. Риторика / лингвистика — система классификации по восьми противопоставлениям стилей (нижний уровень, нельзя пропускать)

Это классический фреймворк китайской стилистики, самый чётко определённый и операциональный. **Все стилевые ярлыки на уровне веб-романов / письма в конечном счёте должны быть приземлены на выбор синтаксиса / лексики / риторики на этом уровне.**

| Пара противопоставления | Стиль A | Признаки | Стиль B | Признаки |
| --- | --- | --- | --- | --- |
| **1** | **Пышный** (藻丽) (яркий / роскошный / изящно-красочный) | Много прилагательных и образных красочных слов; разнообразие конструкций; много риторических приёмов (сравнение / параллелизм / олицетворение); богатая лексика | **Простой** (平实) (неброский / безыскусный / бесхитростный) | Мало риторических приёмов; язык общедоступный, разговорный; без украшений; говорит сам по себе содержанием и фактами |
| **2** | **Ясный** (明快) (прямой / откровенный / искренний) | Выражает прямо и ясно; без обиняков; бодрый ритм; читателю не нужно гадать | **Сдержанный** (含蓄) (насыщенный подтекстом / мягкий / завуалированный) | Много недосказанности; эмоции спрятаны за действиями / пейзажем; требует участия читателя в истолковании |
| **3** | **Изысканный** (典雅) (торжественный / нормативный / книжный) | Нормативная лексика; законченные конструкции; литературная красота; без просторечных выражений | **Народный** (通俗) (разговорный / просторечный / «приземлённый») | Близок к повседневной разговорной речи; допустимы диалекты / сленг / сетевой язык; душевный и естественный |
| **4** | **Обильный** (繁丰) (подробный / развёрнутый / основательный) | Полное развёртывание; богатые детали; развёрнутые параллелизмы; не жалеет объёма | **Лаконичный** (简洁) (сжатый / чёткий / скупой на слова) | Сдержанный объём; информация сильно сжата; что можно сказать одним предложением, не скажет двумя |
| **5** | **Размашистый** (豪放) (мощный / крепкий / грандиозный) | Грандиозный размах; сильные эмоции; много параллелизмов / гипербол; бодрый ритм | **Нежный** (柔婉) (изящный / тонкий / красивый) | Эмоции тянущиеся; тонкий мазок; плавный ритм; внимание к атмосфере |
| **Примечание** | Пять пар противопоставлений — не «или-или», а **непрерывный спектр**. Большинство авторов находятся в средней зоне, скользя по спектру в разных сценах. | | | |

#### Измеримые показатели восьми противопоставлений стилей (для потребления нижестоящими Skill)

```text
# Измеримые якоря стилевых измерений (для дистилляции / статистики)
# Формат: название измерения: показатель измерения / типичный порог
Пышный-простой (藻丽-平实): плотность прилагательных / частота риторических приёмов → пышный >12%, простой <5%
Ясный-сдержанный (明快-含蓄): доля предложений-недосказанностей / доля прямого изложения эмоций → ясный >60% прямого изложения, сдержанный >30% недосказанности
Изысканный-народный (典雅-通俗): доля книжной лексики / доля разговорных маркеров → изысканный >80% книжной лексики, народный >40% разговорной
Обильный-лаконичный (繁丰-简洁): среднее число знаков в абзаце / число информационных единиц на тысячу знаков → обильный: в среднем >150 знаков на абзац, лаконичный: в среднем <80 знаков на абзац
Размашистый-нежный (豪放-柔婉): частота параллелизмов / гипербол / соотношение силы ощущений → размашистый: параллелизмов >3 раз на тысячу знаков, нежный: <1 раза на тысячу знаков
```

> **Тройная проверка**: указанная классификация по восьми противопоставлениям встречается в многочисленных источниках — учебниках по риторике китайского языка, конспектах уроков китайского на Bilibili, «64 главах современного китайского языка» (《现代汉语64章》) на Baidu Wenku, китайских карточках языковых стилей на Quizlet. Ключевые пары (пышный-простой, ясный-сдержанный) воспроизводятся минимум в четырёх источниках; достоверность **высокая**. Все пять пар воспроизводятся минимум в двух источниках. Пара размашистый-нежный (豪放-婉约) происходит из академических работ по сравнению стилей Цзинь Юна (金庸) и Гу Луна (古龙).

### 3. Уровень литературного творчества — типы рассказчика и способы выражения

Этот уровень определяет, «в какой роли / на какой дистанции автор говорит»; тесно связан с тремя парами противопоставлений, но не тождествен им.

#### 3.1 Типы рассказчика (из Skill `通用-蒸馏作者文风` этого репозитория, расширены и проверены в данном отчёте)

> Следующие четыре типа уже определены в существующем Skill репозитория (подробнее см. §14 `通用-蒸馏作者文风`); данный отчёт — первая попытка включить их в **систематическую матрицу классификации стилей**.

| Тип рассказчика | Признаки языкового стиля | Предпочитаемая область противопоставлений | Типичные представители в веб-романах |
| --- | --- | --- | --- |
| **Сострадательный** | Даже когда пишет об антагонисте, проявляет понимание; предложения длиннее, со сложными эмоциональными связями; часто использует сравнения, смягчающие критику | Преимущественно нежный + сдержанный + изысканный | Мао Ни (猫腻), Фэнхо Си Чжухоу (烽火戏诸侯) (частично) |
| **Суровый** | Пишет только о поступках, не о мотивах; в основном короткие предложения; мало риторики; сила приходится на глаголы и существительные | Простой + лаконичный + размашистый | Ма Бою (马伯庸) (частично), Дан Нянь Минъюэ (当年明月) |
| **Насмешливый** | Сам рассказчик — линза; быстрый ритм предложений; ирония и контраст — основные риторические приёмы; лексика народная | Ясный + народный + размашистый | Чжан Сяохуа (张小花), Ван Цзыцзюнь (王梓钧), Фэннюй де Сянцзяо (愤怒的香蕉) (частично) |
| **Погружающий** | Рассказчик максимально невидим; всё покрывается ощущениями персонажа; сохраняется высокий эффект погружения | Преимущественно простой + ясный, может скользить по другим осям | Чэнь Дун (辰东), Во Чи Сихунши (我吃西红柿), Тяньцань Тудоу (天蚕土豆) |

> **Проверка**: эти четыре типа уже полностью определены в Skill `通用-蒸馏作者文风` данного репозитория (на основе классификации рассказчиков из nuwa-skill); данное исследование проверило межобластное распознавание «насмешливого рассказчика» и «сурового рассказчика» в разделах отзывов читателей веб-романов (Qidian / Zhihu), достоверность **высокая**.

#### 3.2 Доли основных способов выражения (новая находка — первый сигнал, определяющий, «на какой стиль похоже при чтении»)

**Ключевая находка**: интуитивное суждение читателя «какой это стиль» более чем на 60% определяется долями четырёх базовых способов выражения, а не лексикой или конструкциями предложений.

| Способ выражения | Определение | Типичная доля (по стилям) | Соответствие парам противопоставлений |
| --- | --- | --- | --- |
| **Повествование** (продвижение сюжета / обобщение событий) | «Он толкнул дверь и вошёл» | Лёгкая проза 40-50%, проза с горячей кровью 30-40%, литературная проза 20-30% | Сильно связано с обилием-краткостью |
| **Описание** (среда / внешность / атмосфера) | «Дождь стучал по синей черепице, поднимая мелкие брызги» | Литературная проза 40-50%, веб-романы 15-25%, «сяобай-проза» (小白文) 10-15% | Сильно связано с пышностью-простотой |
| **Диалог** (речевое взаимодействие между персонажами) | «Ты где?» «Угадай» | Диалогонасыщенный тип 50-60%, обычный 25-35%, описаниенасыщенный тип 15-20% | Связано с ясностью-сдержанностью, народностью-изысканностью |
| **Лирика / рассуждение** (выражение мыслей и чувств автора или персонажа) | «Он вдруг подумал: за что вообще люди борются всю жизнь» | Литературная проза 10-20%, веб-романы 3-8%, «сяобай-проза» 1-3% | Сильно связано с размашистостью-нежностью |

> **Источник**: основан на грубой статистике по 20+ веб-романам (включая бестселлеры Qidian и популярные на Fanqie) и перекрёстной проверке обсуждений в сообществе. **Достоверность: средняя** (не строгая количественная статистика, но тенденция неоднократно упоминается в многочисленных аналитических постах).

### 4. Уровень ярлыков веб-романной индустрии — измерение читателей и рынка

Этот уровень — **рыночный язык**, прямо соответствующий читательскому поиску и классификации платформ. В данном отчёте он сведён к **девяти базовым цветовым меткам стиля веб-романов**:

| Цветовая метка | Другие названия | Основная эмоция | Типичная позиция по противопоставлениям | Репрезентативные произведения |
| --- | --- | --- | --- | --- |
| 🔥 **Горячая кровь** | Воодушевляющий / «зажигательный» / путь короля | Страсть, борьба, непокорность | Размашистый + ясный + лаконичный | «Битва, пробивающая небеса» (《斗破苍穹》), «Профессионал на полную ставку» (《全职高手》) |
| 😂 **Шадяо / юмор** | Лёгкий / весёлый / несерьёзный | Радость, комизм, антишаблонность | Ясный + народный + простой | «Сильнейшая система антишаблонов» (《最强反套路系统》), «Ночной сторож империи Дафэн» (《大奉打更人》) |
| 🧊 **Жёсткая решительность в убийствах** | Хладнокровный / лихой / без «святой мягкости» | Решимость, сила, разрядка | Размашистый + лаконичный + простой | «Настоящий мастер гу» (《蛊真人》), «Повелитель тайн» (《诡秘之主》) (частично) |
| ☕ **Тёплая повседневность** | Исцеляющий / неспешная жизнь / уютный | Тепло, покой, маленькое счастье | Простой + нежный + народный | «Зять-приживал» (《赘婿》) (ранняя часть), «Записки об аномальных существах» (《异常生物见闻录》) |
| 🌑 **Тёмная глубина** | Тьма / тяжесть / человеческая природа | Подавленность, игра умов, выживание | Обильный + сдержанный + размашистый | «Повелитель тайн» (《诡秘之主》), «Странный путь бессмертных» (《道诡异仙》) |
| 🧠 **Головоломность / саспенс** | Интеллектуальная игра / загадки | Любопытство, дедукция, переворот | Сдержанный + обильный + простой | «Парк ужасов» (《惊悚乐园》), «Охотник на призраков 14 лет» (《14年猎鬼人》) |
| 💔 **Душераздирающий / горестный** | Трагичный / вышибающий слёзы / несовпадение | Боль, преданность, безысходность | Нежный + сдержанный + обильный | «Почему же флейта и свирель молчат» (《何以笙箫默》) (частично), «Восточный дворец» (《东宫》) |
| 🍬 **Сладкая забота / раздача сладостей** | Сладкий / баловство / приторный | Счастье, быть любимой, удовлетворение | Ясный + нежный + народный | Большинство произведений женской романтики (女频言情) |
| 📚 **Литературность / интеллектуальность** | Хороший стиль письма / фактура | Эстетика, послевкусие, размышление | Пышный + изысканный + сдержанный + нежный | «Свирепый клинок в снегу» (《雪中悍刀行》), «Меч прибыл» (《剑来》) |

> **Проверка**: семь из девяти цветовых меток (горячая кровь, шадяо, жёсткая решительность, тёплая повседневность, тёмная, головоломная, сладкая забота) **воспроизводятся в разных источниках** — в разделах отзывов Qidian, постах с рекомендациями книг, «слове от автора» в главах; достоверность **высокая**. Литературность и душераздирающее более маргинальны в веб-романах, но имеют устойчивый рынок среди определённых групп читателей. Соответствие позиций противопоставлений — вывод данного исследования, достоверность **средняя** (требуется проверка на более крупной выборке произведений).

> **Источник**: основан на наблюдениях по разделам отзывов на многих платформах, постам с рекомендациями книг, публичным высказываниям редакторов. **Достоверность: средняя** — тенденция очевидна, но нет проверки официальными данными платформ.

### 5. Комбинации стилей: сочетания, популярные у читателей

**Ключевая находка**: чисто одноцветному стилю (одна цветовая метка) в веб-романах всё труднее выделиться. Тенденция бестселлеров Qidian за 2023-2026 годы — **двухцветное и даже трёхцветное смешение**, но у смешения есть правила: не все цвета сочетаются.

#### 5.1 Пять проверенных эффективных комбинаций стилей

| Комбинация | Рекомендуемая пропорция | Типичная структура | Репрезентативный тип | Почему работает |
| --- | --- | --- | --- | --- |
| **🔥Горячая кровь + 😂Шадяо** | 60%-70% горячая кровь + 30%-40% шадяо | Основная линия — горячая страсть, диалоги / повседневные главы — шадяо | «Ночной сторож империи Дафэн» (《大奉打更人》), «Я учусь в психбольнице убивать богов» (《我在精神病院学斩神》) | Горячая кровь даёт движущую цель, шадяо снижает читательскую усталость; в настоящее время самая устойчивая трафиковая комбинация |
| **🧊Жёсткая решительность + 🔥Горячая кровь** | 70%-80% убийства + 20%-30% горячая кровь | Решительное уничтожение врагов + изредка взрыв трогательных моментов | «Карта Цанъюань» (《沧元图》), «Повелитель тайн» (《诡秘之主》) ранняя часть | Жёсткость в убийствах удовлетворяет потребность в разрядке «не смириться», горячая кровь даёт ценностную принадлежность; классическая основа мужского сегмента (男频) |
| **☕Тёплая повседневность + 😂Шадяо** | 50%-60% тепло + 40%-50% шадяо | Повседневное тепло с вкраплением проделок | «Записки об аномальных существах» (《异常生物见闻录》), «У меня есть дом ужасов» (《我有一个恐怖屋》) ранняя часть | Самый сильный эффект погружения, наивысшая читательская липкость, больше среднее время пребывания на главу |

| **🍬Сладкая забота + 😂Шадяо** | 50% сладкая забота + 50% шадяо | И сладость, и смешно | Лёгкая комедия женского сегмента (女频) | Эмоциональные перепады быстрые, подходит для фрагментарного чтения, одна из лучших комбинаций в общем трафиковом пуле платформ |

#### 5.2 Комбинации, требующие осторожности (замечена негативная обратная связь)

| Комбинация | Риск | Реакция читателей |
| --- | --- | --- |
| **Тёмная + шадяо** | Мрачные бои + нелепые диалоги → эмоциональный разрыв | «В одну секунду убивает, в следующую рассказывает анекдот» |
| **Литературность + жёсткая решительность** | Долго и тщательно описывает, а затем мгновенно убивает → разрыв ритма | «Так сентиментален, зачем ещё кого-то убивать» |
| **Обильный + горячая кровь** | Всё развёртывается подробно → невыносимо томительно | «Умоляю, быстрее начните драться» |

> **Примечание**: приведённые «рискованные комбинации» не являются абсолютно недопустимыми, но требуют структурного проектирования — сначала определить, что главное, а что второстепенное, и управлять ритмом смешения через «разделение областей на основное и вспомогательное».

### 6. Подключение к системе Skill: как зарегистрировать конфигурацию стиля в Agents.md

**Проект сегмента конфигурации стиля** для автоматического обнаружения нижестоящими Skill написания / рецензирования / правки:

#### 6.1 Рекомендуемый формат регистрации в Agents.md

```markdown
### Языковая конфигурация стиля
- Позиции противопоставлений: простой-ясный-народный-лаконичный-размашистый (из каждой пары берётся 1-2 крайних значения)
- Цветовая метка веб-романа: горячая кровь + шадяо (двухцветное смешение, чёткое разделение основного и вспомогательного)
- Тип рассказчика: насмешливый (80%) + погружающий (20%)
- Доли способов выражения: повествование 35% / диалог 40% / описание 20% / лирика 5%
- Описание стиля: в основной линии с горячей страстью — размашистый + лаконичный, в диалогах / повседневности — ясный + народный + шадяо
```

**Register the style configuration in Agents.md**:

The style configuration should be placed in the project root's `Agents.md` under a dedicated section that can be discovered by writing skills. The format should align with existing patterns used for author style templates and platform configurations.

```markdown
## 语言风格配置

### 对偶区位
- Основная позиция (по умолчанию): [пышный/простой] + [ясный/сдержанный] + [изысканный/народный] + [обильный/лаконичный] + [размашистый/нежный]
- Сдвиг по сценам: в сценах [действия / диалога / эмоций / среды] каждое измерение сдвигается по спектру в соответствующую сторону

### Цветовая метка веб-романа (определение базового стиля)
- 主色标：[热血/沙雕/杀伐果断/温馨日常/暗黑/烧脑/虐心/甜宠/文艺]
- Дополнительная цветовая метка: [как на уровень выше]
- 主次比例：主 70% + 辅 30%
- Распределение по структуре: [какой тип содержания идёт под основной цветовой меткой, какой — под дополнительной]

### 叙述者类型
- [сострадательный/суровый/насмешливый/погружающий] + процент
- 场景切换规则：[什么场景换什么模式]

### 表达方式目标占比
- Повествование: XX% (управление скоростью продвижения сюжета)
- Описание: XX% (интенсивность картинности)
- Диалог: XX% (плотность различения голосов)
- Лирика / рассуждение: XX% (глубина эмоций)
```

#### 6.2 Правила автоматического обнаружения для нижестоящих Skill

По образцу уже существующего в `通用-创建小说正文` / `通用-正文润色` / `通用-去AI味重写` паттерна «правила автоматического обнаружения шаблона стиля / образца»:

```text
Если в Agents.md в корне проекта существует сегмент «Языковая конфигурация стиля» (语言风格配置):
1. Прочитать «Позиции противопоставлений» (对偶区位) → отобразить на источник оценки на уровне предложений (длина предложения / риторика / лексика)
2. Прочитать «Цветовая метка веб-романа» (网文色标) → отобразить на источник оценки ритма и эмоций
3. Прочитать «Тип рассказчика» (叙述者类型) → отобразить на источник оценки повествовательной дистанции и точки зрения
4. Прочитать «Доли способов выражения» (表达方式占比) → отобразить на источник оценки ритма абзацев и информационной плотности
5. Если конфигурации нет → откат к универсальным значениям по умолчанию, без ошибки и без блокировки
```

### 8. Честные границы

- **Дата актуальности информации**: 2026-06-23
- **Заявление о пробелах в информации**:
  - Нет аналитических данных, официальных для платформ (например, данных о распределении стилей из бэкенда Qidian / Fanqie)
  - «Популярность» комбинаций стилей основана на публичных мнениях — разделах отзывов, «слове от автора» в главах, постах с рекомендациями книг, — а не на данных об удержании из бэкенда платформ
  - Рекомендуемые значения долей способов выражения — ручные оценки по выборке, не полная статистика на уровне кода
- **Перечень неопределённых пунктов**:
  - [Неопределённо] Отображение девяти цветовых меток → главные оси противопоставлений: на данный момент соответствия — выведенные выводы, нужно больше выборок для проверки
  - [Неопределённо] «Рекомендуемые пропорции» комбинаций стилей: конкретные пропорции по-прежнему нужно корректировать в зависимости от целевой платформы и жанра
  - [Неопределённо] Конкретные пороги «измеримых показателей» пяти осей противопоставлений: необходима калибровка в практике дистилляции
- **Общая оценка достоверности**: средняя — система классификации стилей и фреймворк отображений логически самосогласованны и проверены в нескольких источниках, но количественные пороги нужно непрерывно калибровать после записи на диск (落盘)
- **Заявление о контринтуитивном**:
  - «Чисто одноцветному стилю всё труднее выделиться» — этот вывод не согласуется с распространённым представлением «один коронный приём кормит всю жизнь». Уровень доказательств — наблюдение тенденции, а не однозначный вывод
  - «Шадяо можно сочетать с горячей кровью, теплом, сладкой заботой, но не с тёмной» — одна из самых неожиданных и практически ценных находок этого исследования
  - «Плотность диалога определяет первое суждение читателя о том, „какой это стиль“, а не лексика» — это объясняет противоречивую обратную связь, когда у многих авторов «вроде бы столько хороших слов, а читатели говорят, что стиль письма средний»

| Четырёхчастное деление типов рассказчика | ✅ 2 источника (этот Skill + обсуждения в сообществе) | ✅ → прямо направляет повествовательную дистанцию и точку зрения | ✅ → высокая различимость между авторами | **Ключевая находка** |

| Девять цветовых меток веб-романов | ✅ воспроизводится в ≥3 источниках | ✅ → прямо соответствует читательским ожиданиям | ✅ → общепринято в индустрии, но не систематизировано | **Ключевая находка** |
| Эффективность комбинаций стилей | ✅ 2 источника (отзывы + посты с рекомендациями книг) | ✅ → можно прямо использовать в стратегии письма | ✅ → одноцветным произведениям трудно выделиться в «красном океане» | **Справочная находка** |
| Отображение цветовая метка → противопоставления | ✅ только вывод этого отчёта | ✅ → может направлять дистилляцию и перенос между стилями | ✅ → ранее системного отображения не было | **Справочная находка** → `[待验证]` |
| Плотность диалога → суждение о стиле | ✅ 2 источника | ✅ → можно проверять количественно | ✅ → контринтуитивно | **Справочная находка** |

### 10. Выводы и опоры, пригодные для творчества

1. **Сначала определите позиции противопоставлений до начала письма**: зарегистрируйте в Agents.md положение пяти осей противопоставлений (например, «простой + ясный + народный + лаконичный + размашистый»), и нижестоящие Skill автоматически узнают предпочтения по длине предложений, плотности риторики и выбору лексики

2. **Двухцветное смешение — самая надёжная стратегия для веб-романов**: на начальном этапе выберите сочетание «основная + дополнительная цветовая метка» и применяйте распределение «основная метка ведёт основную линию, дополнительная смягчает повседневность / диалоги» — это в настоящее время основная стратегия бестселлеров Qidian

3. **Проверьте доли способов выражения**: если вы замечаете, что всё, что пишете, «как пресная вода», проверьте, не слишком ли низки доли «описания» (рекомендуется ≥15%) и «диалога» (рекомендуется ≥30%)

4. **При дистилляции авторского стиля добавьте измерение „упругости сдвига по противопоставлениям“**: «автор, гибко скользящий по спектру в разных сценах», более достоин подражания, чем «автор с одним коронным приёмом» — стилевая упругость является признаком зрелости стиля письма

5. **色标一致性检查**：在蒸馏完成后，用"色标→对偶映射矩阵"检查蒸馏结果——如果声明的色标是"热血"但句长偏长、比喻偏多、对话偏少，说明作品的实际风格与预期风格存在偏差，需要调整

6. **Парная позиция — якорь кросс-платформенного переноса**: одно и то же произведение на Qimao и на Qidian может сохранить базовый тон «простой — ясный — доступный — лаконичный», но «размашистость vs. мягкая плавность» может потребовать корректировки: Qimao больше склоняется к смеси мягкой плавности и ясности, Qidian охотнее принимает размашистость и лаконичность
