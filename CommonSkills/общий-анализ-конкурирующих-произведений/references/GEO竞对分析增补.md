# Дополнение GEO-измерения к анализу конкурентов

## Пятый слой: слой видимости в ИИ-поиске (новое измерение анализа)

К традиционной четырёхслойной рамке разбора добавляется пятый слой — «слой видимости в ИИ-поиске» — для анализа стратегий видимости конкурентов в эпоху ИИ-поиска.

### Измерения анализа

| Измерение | Вопрос анализа | Источник данных |
|------|---------|---------|
| Показатели цитирования ИИ | При поиске «рекомендуй романы жанра XX» в DeepSeek / Doubao / Kimi / ChatGPT появляется ли конкурент в ответе? Как часто? | Прямо задать вопрос каждому ИИ для проверки |
| Степень структурированности внешнего контента | Содержит ли аннотация конкурента блок структурированных метаданных? Используют ли рецензии стандартный формат «название книги — тип — оценка — рекомендательная фраза»? | Открытые страницы книги, рецензии, ответы на Zhihu |
| Охват Zhihu / Douban | Сколько связанных вопросов-ответов у конкурента на Zhihu? Какова структурированность рецензий на Douban? | Поиск на Zhihu, страницы Douban |
| Согласованность информации на платформах | Полностью ли совпадают название, имя автора, теги конкурента на разных платформах (Qidian / Fanqie / Douban / Zhihu)? | Перекрёстное сопоставление нескольких платформ |
| Использование временных меток | Помечен ли внешний контент конкурента годовыми метками (например «рекомендации 2026 года»)? | Рецензии, рекомендательные статьи, рейтинги |
| Качество читательских рекомендательных фраз | Содержат ли читательские рекомендации конструкцию «подходит читателям, которые ____», которую ИИ может цитировать напрямую? | Раздел рецензий, комментарии к главе (本章说), круг читателей (书友圈) |
| Охват энциклопедиями / СМИ | Есть ли у конкурента статья в Baidu Baike? Освещался ли он отраслевыми СМИ? | Поиск по энциклопедиям, отраслевым СМИ |

### Шаблон вопросов анализа

```
## Слой видимости в ИИ-поиске

### Показатели цитирования ИИ
[Задать в области этого жанра вопрос DeepSeek / Doubao / Kimi: упоминается ли конкурент]
[Если упоминается: как ИИ его описывает? (название книги + тип + причина одной фразой?)]
[Если не упоминается: пояснить, что видимость конкурента в ИИ-поиске недостаточна]

### Структурированность внешнего контента
[Содержит ли аннотация конкурента структурированную информацию?]
[Используют ли рецензии конкурента / ответы на Zhihu стандартный формат?]
[Есть ли другие заметные следы стратегии GEO?]

### Сравнение с текущим проектом
[Какие преимущества / недостатки у этого проекта в измерении GEO?]
[Какие пункты стратегии GEO конкурента можно перенести?]
```

### Место размещения в отчёте анализа конкурентов

В существующий шаблон отчёта по «четырёхслойной рамке разбора» добавляется пятый слой — после «слоя отклика аудитории» и до «горизонтального сопоставления и завершения»:

```
### Пятый слой: слой видимости в ИИ-поиске (новое)
...
```

## Дополнение GEO к слою операционной стратегии

В существующем слое операционной стратегии добавить следующие подизмерения, связанные с GEO:

| Существующее подизмерение | Дополнение GEO |
|-----------|---------|
| Взаимодействие с читателями и удержание фанатов | Структурированы ли читательские рекомендации (название произведения + тип + подходящая аудитория)? Пишут ли читатели рекомендации на платформах с высоким цитированием ИИ — Zhihu / Douban? |
| Адаптация к ресурсам платформы и усиление трафика | Рекомендовалось ли произведение отраслевыми медиа / известными блогерами? Индексируются ли эти рекомендации в ИИ-поиске? |

## Самопроверка GEO-анализа конкурентов

- [ ] Через вопросы ИИ проверено цитирование конкурента в ИИ-поиске
- [ ] Проверена структурированность внешнего контента конкурента
- [ ] Сопоставлен разрыв в стратегиях GEO между конкурентом и текущим проектом
- [ ] Сам отчёт анализа конкурентов оформлен структурированно (чтобы затем его могли цитировать ИИ)
- [ ] Каждое данное о конкуренте в отчёте имеет временную метку («данные за X месяц 2025 года»)
