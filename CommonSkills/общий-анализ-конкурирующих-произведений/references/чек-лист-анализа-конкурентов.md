Нижеследующий перечень нужен, чтобы превратить «анализ конкурентов» из расплывчатой задачи в исполнимый, пересматриваемый и допускающий обратную запись в текущий проект четырёхслойный процесс разбора.

- [ ] Значение `N` для `TopN` подтверждено (если не указано — по умолчанию `10`)
- [ ] Подтверждено: сканировать только пул кандидатов TopN или продолжать глубоким разбором `3–5` основных образцов
- [ ] Текущий проект / текущее произведение подтверждены
- [ ] Выходной каталог подтверждён (если не указан — по умолчанию `竞对分析/`)
- [ ] Подтверждено: делать только по меркам Qidian или дополнять обсуждениями с других платформ

## 5. Минимальная линия сбора улик по одной книге (исполнение по четырём слоям)

| Слой | Минимальное требование | Примечание |
| --- | --- | --- |
| Слой рыночных данных | Хотя бы `1` пункт базовой информации по рейтингу / произведению; лучше дополнить страницей данных | Должно подкреплять суждение «это действительно сильный образец» |
| Слой создания контента | Не менее `3` классов улик из оглавления / названий томов / фрагментов основного текста / настроек | Должно подкреплять суждение «в чём именно он силён» |
| Слой операционной стратегии | Не менее `1–2` классов улик из ритма обновлений, взаимодействия, согласования ресурсов | Если не нашли — тоже написать «не найдено» |
| Слой отклика аудитории | Отклики не менее чем из `2` разных классов источников | По возможности охватить и положительные, и отрицательные |

> Для образцов Qidian (起点中文网) рекомендуется дополнительно проверять `https://www.qidiantu.com/`: его страницы деталей произведения / данных / рейтинга / первичной подписки / значков / главных фанатов / списков книг обычно позволяют дополнить такие сведения, как рекомендательные голоса, число избранного, реальное число фанатов, ежемесячные голоса, число знаков, почётные значки, число главных фанатов, включение в списки книг, вход в комментарии / рецензии; при известном ID книги в приоритете смотреть `https://www.qidiantu.com/info/{书籍ID}` и `https://www.qidiantu.com/info/{书籍ID}/d`.
>
> Такие страницы подходят для дополнения «данных о популярности и откликах», но не заменяют проверку официального оглавления, текста пробного чтения и фрагментов основного текста.
>
> Если улики какого-то слоя объективно трудно найти, прямо пропускать нельзя; обязательно написать «что искали, чего не нашли, и поэтому в чём не уверены».
>
> Если официальный сайт из-за капчи, антибота, барьера входа или ограничения частоты не позволяет стабильно получить улики по тексту / оглавлению, допускается перейти на **более стабильные, поддающиеся проверке заменяющие источники** (например официальное пробное чтение, открытые материалы автора, репортажи СМИ, короткие цитаты в рецензиях, обсуждения на форумах, послесловия читателей, пересказ сюжета и т. п.); **нельзя принимать страницы-зеркала полного текста или страницы-агрегаторы репостов с неизвестным происхождением и невозможностью стабильной проверки за основные улики для дополнения основного текста.**

## 6. Обязательные вопросы отчёта по одной книге

Каждый отчёт по одной книге должен ответить как минимум:

1. Почему это произведение — сильный образец, а не обычная популярная книга.
2. В чём именно его основное конкурентное преимущество.
3. О чём говорит его слой рыночных данных: каковы долгосрочная стабильность, коммерческая ценность и ключевой прорыв трафика.
4. Как его слой создания контента формирует конкурентное преимущество в жанровом позиционировании, начале, ритме, персонажах, настройках и языке.
5. Что его слой операционной стратегии сделал для усиления эффекта контента.
6. Каковы сильнейшие точки резонанса, основные придирки и источники чувства принадлежности на слое отклика аудитории.
7. Какие достоинства стоит усвоить текущему проекту.
8. Какие достоинства — лишь индивидуальные условия, временное окно или накопленный запас автора, которые нельзя механически копировать.
9. В каких слепых зонах нет улик и поэтому нельзя делать жёсткие выводы.

- [ ] Выводы переведены в язык действий текущего проекта

## 8. Нормы записи улик

- Все суждения о «сильных сторонах» по возможности опирать на конкретные улики, не писать пустых похвал.
- Все «усваиваемые пункты» писать как исполнимые действия, а не как прилагательные.
- По всем «пунктам, которые нельзя копировать» обязательно писать причину: механизмы платформы, различия жанра, накопленный запас автора, ритм обновлений, личный голос, ожидания читателей и т. п.
- Если цитируются существующие углублённые исследования, сводки глав или заметки из `竞对分析/竞对资料/`, нужно пометить, что это дополнительная справка рабочей области, а не основная внешняя улика.
- По возможности различать:
  - **Факт**: явно видимая информация из рейтингов, оглавлений, основного текста, комментариев;
  - **Вывод**: суждение, сформированное на основе нескольких улик;
  - **Гипотеза**: направление, по которому улик недостаточно, но подозрение разумно.
