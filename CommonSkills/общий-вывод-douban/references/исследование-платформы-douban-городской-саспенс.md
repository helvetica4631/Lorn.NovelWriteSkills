# Дополнение по исследованию платформы: городской саспенс на Douban

- Сильнее подчёркиваются литературная фактура, реальная текстура, сдержанное выражение и послевкусие.
- При переписывании городского саспенса для Douban следует сохранять цепочку дела, но уменьшать прямые жёсткие хуки и грубые стимулы.
- Главное — усилить послевкусие персонажей, отдачу после расследования и плотность реальных деталей.
- Нельзя писать версию для Douban как пустую оболочку, где есть только «литературный дух» и нет продвижения дела.
