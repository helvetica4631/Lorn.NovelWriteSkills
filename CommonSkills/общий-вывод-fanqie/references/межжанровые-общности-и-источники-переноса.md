# общий-вывод-fanqie｜Межжанровые общие правила и источники переноса

В этом файле записаны источники межжанровых общих правил, которые `общий-вывод-fanqie` принимает сейчас, а также границы исполнения на время безущербного переноса.

## Текущие источники

- `городская-магия-и-сверхспособности/.github/prompts/输出番茄版.prompt.md`
- `городской-саспенс/.github/prompts/输出番茄版.prompt.md`

## Общие правила платформы Fanqie, которые сейчас можно стабильно поднять на общий уровень

- В контексте платформы бесплатного чтения: быстрая обратная связь, сильные хуки, короткие абзацы, темп с высокой долей дочитывания
- Структура вывода фиксирована: «основной текст + ## 作者有话说»
- Заголовок должен быть прямее, с большим конфликтом и мотивом продолжать читать
- Гейты по объёму, гейт «слова от автора», гейт против воды и гейт сходства должны согласовываться с SOP для нескольких платформ
- Стиль платформы должен идти раньше снижения сходства; нельзя сначала писать универсальный текст, а потом надевать «оболочку Fanqie»

## Подробные правила, которые пока остаются в исходном Prompt

Пока безущербный перенос не завершён, следующее содержимое по-прежнему опирается на текст исходного Prompt как подробное основание:

- Конкретные пункты усиления по исследованиям каждого жанра на платформе Fanqie
- Запреты, специфичные для жанра, и формулировки патчей
- Тонкие такты внутри главы, шаблоны заголовков, ограничения интонации «слова от автора»

## Границы использования

- При срабатывании `общий-вывод-fanqie` обязательно одновременно загружать `题材名-输出番茄版` соответствующего жанра.
- Если текущая задача всё ещё находится на пилотной стадии переноса, нужно по-прежнему сверяться с исходным Prompt и пилотным реестром и не предполагать, что этот файл уже полностью заменил старый Prompt.
