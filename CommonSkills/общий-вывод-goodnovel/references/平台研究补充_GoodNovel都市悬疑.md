# Дополнение по исследованию платформы: городской саспенс на GoodNovel

- Сильнее подчёркиваются быстрый темп, сильная визуальность, сильные сюжетные точки и прямая эмоциональная награда.
- При переписывании городского саспенса для GoodNovel нужно писать продвижение дела нагляднее и визуальнее.
- В каждой главе желательно видеть заметное изменение, а не одну лишь подготовку атмосферы.
- В версии для зарубежной аудитории не следует оставлять слишком много информации, которую в местном контексте принято опускать по умолчанию.
