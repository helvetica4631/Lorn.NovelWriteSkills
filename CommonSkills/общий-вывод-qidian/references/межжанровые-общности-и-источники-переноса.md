# общий-вывод-qidian｜Межжанровые общие правила и источники переноса

## Пояснение об источниках переноса

Общие правила платформы Qidian в этом Skill происходят из:

1. жёстко прописанных правил, специфичных для Qidian, извлечённых из ключевых Skill вроде `общий-создание-основного-текста` (перенос Phase 2)
2. записи о Qidian в `CommonSkills/общий-адаптация-под-платформы/references/матрица-различий-платформ.md`
3. исследовательских отчётов по платформе Qidian в `写作研究/` разных жанров

## Межжанровые общие правила

Следующие правила применимы ко всем жанрам, публикуемым на Qidian:

- долгосрочное дочитывание, инженерия наград на уровне глав
- система послойной цепляющей силы первых 300/1000/3000 знаков
- сильный хук в конце главы + чередование типов хуков
- золотые три главы: в начале не готовить
- железное правило точки зрения «камеры» (запрещён взгляд бога)
- «слово от автора» для читателя (не интонация разбора)

## Направления дальнейших итераций

- `references/执行细则与题材补丁.md` в каждом `题材名-输出起点中文网版` отвечает за специальные жанровые правила
- общие правила платформы единообразно ведутся в этом Skill
- при добавлении нового жанра прямо переиспользовать этот Skill, не определяя заново общие правила Qidian
