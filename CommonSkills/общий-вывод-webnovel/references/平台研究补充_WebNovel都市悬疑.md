# Дополнение по исследованию платформы: городской саспенс на WebNovel

- Сильнее подчёркиваются сильные сюжетные точки, сильная визуальность, быстрый темп и хуки глав.
- При переписывании городского саспенса для WebNovel нужно яснее писать цель героя, конфликт, аномалию и награду.
- Сложную социальную фактуру следует сжимать до выражений, которые легче понять межкультурно.
- В каждой главе по возможности давать читателю жёсткую причину читать дальше.
