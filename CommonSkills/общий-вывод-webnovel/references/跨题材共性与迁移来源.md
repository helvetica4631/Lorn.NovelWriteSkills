# общий-вывод-webnovel｜Межжанровые общие правила и источники переноса

В этом файле записаны источники межжанровых общих правил, которые `общий-вывод-webnovel` принимает сейчас, а также границы исполнения на время безущербного переноса.

## Текущие источники

- `异能志怪/.github/prompts/输出WebNovel版.prompt.md`
- `都市悬疑/.github/prompts/输出WebNovel版.prompt.md`

## Общие правила платформы WebNovel, которые сейчас можно стабильно поднять на общий уровень

- Межкультурная читаемость для молодых читателей по всему миру, темп для мобильных и англоязычные гейты платформы
- Структура вывода фиксирована: английский основной текст + `## 作者有话说`
- Заголовок должен быть на английском, а в основном тексте, кроме строки с маркером, не должно быть китайского / CJK
- Быстрый захват в начале, высокочастотное продвижение в середине, сильный хук в конце
- Стиль платформы должен идти раньше снижения сходства; нельзя писать WebNovel как общий англоязычный платформенный текст

## Подробные правила, которые пока остаются в исходном Prompt

Пока безущербный перенос не завершён, следующее содержимое по-прежнему опирается на текст исходного Prompt как подробное основание:

- Дополнительные пункты усиления исследований каждого жанра на платформе WebNovel
- Цепочка правил / цепочка улик / якоря реальности / границы межкультурных пояснений, специфичные для жанра
- Тонкие такты, склонность в заголовках, интонация «слова от автора» и патчи правил

## Границы использования

- При срабатывании `общий-вывод-webnovel` обязательно одновременно загружать `题材名-输出WebNovel版` соответствующего жанра.
- Если текущая задача всё ещё находится на пилотной стадии переноса, нужно по-прежнему сверяться с исходным Prompt и пилотным реестром и не предполагать, что этот файл уже полностью заменил старый Prompt.
