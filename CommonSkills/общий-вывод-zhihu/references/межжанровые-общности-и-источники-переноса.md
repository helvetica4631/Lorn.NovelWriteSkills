# общий-вывод-zhihu｜Межжанровые общие правила и источники переноса

В этом файле записаны источники межжанровых общих правил, которые `общий-вывод-zhihu` принимает сейчас, а также границы исполнения на время безущербного переноса.

## Текущие источники

- `异能志怪/.github/prompts/输出知乎版.prompt.md`
- `都市悬疑/.github/prompts/输出知乎版.prompt.md`

## Общие правила платформы Zhihu, которые сейчас можно стабильно поднять на общий уровень

- Высокая концепция, сильное отражение реальности, прослеживаемость логической цепочки и сдержанная острота в контексте Zhihu
- Структура вывода фиксирована: «основной текст + ## 作者有话说»
- Заголовок ближе к фразе-правилу / фразе-цене / фразе-конфликту, но сохраняет ощущение романа
- Улики должны поддаваться разбору, информация — проверке, точки продвижения — высокоплотными и прослеживаемыми
- Стиль платформы должен идти раньше снижения сходства; нельзя писать версию для Zhihu как общий текст для китайских платформ

## Подробные правила, которые пока остаются в исходном Prompt

Пока безущербный перенос не завершён, следующее содержимое по-прежнему опирается на текст исходного Prompt как подробное основание:

- Дополнительные пункты усиления исследований каждого жанра на платформе Zhihu
- Привязка к реальным темам, цепочка правил, границы фольклора / расследования, специфичные для жанра
- Тонкие типы заголовков, интонация «слова от автора» и патчи тактов внутри главы

## Границы использования

- При срабатывании `общий-вывод-zhihu` обязательно одновременно загружать `题材名-输出知乎版` соответствующего жанра.
- Если текущая задача всё ещё находится на пилотной стадии переноса, нужно по-прежнему сверяться с исходным Prompt и пилотным реестром и не предполагать, что этот файл уже полностью заменил старый Prompt.
