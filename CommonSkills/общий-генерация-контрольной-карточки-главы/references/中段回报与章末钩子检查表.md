# Чек-лист награды в середине главы и хука в конце главы

## 1. Проверка награды в середине главы

- [ ] В середине читатель однозначно получает награду определённого вида
- [ ] Награда — не «ещё больше объяснений», а хотя бы одно из: информация / отношения / ресурс / правило / цена
- [ ] Награда меняет читательское впечатление от второй половины главы, а не является необязательной

## 2. Проверка хука в конце главы

- [ ] У хука есть чёткий объект
- [ ] Тип хука прописан (кризис / раскрытие / поворот / незавершённое действие)
- [ ] Хук — не абстрактное восклицание
- [ ] Хук не выдаёт ответ заранее
