# Стандартный шаблон главы и строительная карта ротации хуков

> Источник: `网文技法.md` (стандартный шаблон главы, ротация хуков).

## Стандартный шаблон главы (строительный взгляд)

```text
Первые 200 знаков: хук (конфликт / интрига / аномалия)
Середина A: продвижение основной или побочной линии
Середина B: микро-爽点 (небольшой переворот / информационная асимметрия / небольшой успех)
Середина C: нагнетание давления или эскалация ошибочной оценки
Последние 200 знаков: оставить хук (незакрытый вопрос / новая переменная)
```

## Четыре точки приземления (обязательны в контрольной карточке)

- Хук: почему читатель продолжает читать.
- Накопление: как усиливается конфликт.
- Награда: конкретная выгода, оправдывающая эту главу.
- Оставленный хук: объект передачи эстафеты в следующей главе и движущий вопрос.

## Быстрое определение строительных уровней (новое)

- `上游对齐层 (слой согласования с вышестоящими уровнями)`: какую грань истории продолжает эта глава, на каком участке тома находится, ясны ли роль главы и главный рычаг.
- `章内四拍层 (слой четырёх ударов внутри главы)`: действительно ли хук, накопление, награда и оставленный хук распределены по этой главе, а не сведены к одной абстрактной фразе.
- `跨章接棒层 (слой передачи эстафеты между главами)`: может ли оставленный в этой главе хук быть напрямую подхвачен первой сценой следующей главы, правильно ли чередуются типы хуков.

Порядок по умолчанию: сначала оценить `上游对齐层`, затем `章内四拍层`, и наконец `跨章接棒层`; не нужно сначала писать тип хука, а потом обнаруживать, что в главе вообще нет награды.

## Правила ротации хуков

Избегайте использования однотипных хуков в 3 главах подряд. Рекомендуемая ротация:

```text
хук-интрига → хук-конфликт → хук-аномалия → хук-действие → хук-диалог → хук-интрига...
```

## Чек-лист аудита ротации

- Не повторяется ли тип хука этой главы с двумя предыдущими.
- Соответствует ли хук этой главы её обязанности (глава информации / противостояния / поворота).
- Может ли оставленный в этой главе хук быть напрямую подхвачен первой сценой следующей главы.

## Сигналы тревоги об ошибках

- Только хук без награды: читатель устаёт.
- Только награда без оставленного хука: обрывается желание читать дальше.
- В каждой главе один и тот же тип хука: оцепенение ритма.

## Минимальный исполнимый вывод (внутри контрольной карточки)

```text
Тип хука этой главы: ____
Награда в середине этой главы: ____
Объект оставленного хука в этой главе: ____
Вопрос передачи эстафеты следующей главе: ____
```

## Минимальный артефакт четырёх ударов (новое)

```markdown
【Главный рычаг этой главы】
【Самый весомый из четырёх ударов】хук / накопление / награда / оставленный хук
【Носитель награды в середине этой главы】
【Объект оставленного хука в этой главе】
【Как первая сцена следующей главы подхватывает】
```

## Гейт готовности Green / Yellow / Red (новое)

- `Green`: все три слоя — согласование с вышестоящими уровнями, четыре удара внутри главы, передача эстафеты между главами — ясны, можно сразу переходить к основному тексту контрольной карточки.
- `Yellow`: четыре удара в целом состоятельны, но какой-то слой остаётся пустоватым, например, награда недостаточно ощутима или вопрос передачи эстафеты следующей главе слишком общий.
- `Red`: нет явной награды в середине, объект оставленного хука не формулируется, первая сцена следующей главы не может подхватить, либо хук этой главы не соответствует обязанности главы.

## Метод написания «заданий с пропусками»: второй путь создания контрольной карточки (новое — усвоено из колонки Zhihu «中国网络文学研究» #6)

Помимо стандартного шаблона главы, контрольную карточку можно организовать и в форме «заданий с пропусками». **Ключевая идея метода «заданий с пропусками»**: писать роман — не нащупывать в темноте, а заполнять содержимым уже выстроенную рамку: план — это условие задачи, библиотека паттернов (套路库) — образцы ответов.

### Формат плана в виде «заданий с пропусками»

Дополняя стандартный шаблон «хук — накопление — награда — оставленный хук», план в виде заданий с пропусками сильнее подчёркивает «эмоциональную цель прежде всего». Формат пропусков для каждой главы:

```markdown
Глава X: название главы
【Эмоциональная цель】
【Сюжетный пропуск 1】______ (подсказка: ______)
【Сюжетный пропуск 2】______ (подсказка: ______)
【Сюжетный пропуск 3】______ (подсказка: ______)
【Пропуск 爽点】______ (нужно спроектировать)
【Конец главы】______ (интрига / разрыв / новая цена)
```

### Три типа пропусков и способы заполнения

| Тип пропуска | Основная логика | Способ заполнения | Пример |
| --- | --- | --- | --- |
| Продвигающий сюжет | Причинная логика | Определить финал → вывести начало в обратном порядке → спроектировать шаги | «Как герой получает первый золотой палец (金手指)» → сначала определить, что именно он получает, затем от финала вывести исходные условия и промежуточные шаги |
| Эмоциональный опыт | Задействование чувств | Использовать детали, а не прилагательные | Не писать «он очень зол», а писать «его пальцы глубоко впились в ладонь» |
| Хук-интрига | Обрыв в самый ключевой момент | Оборвать главу в момент наибольшего напряжения / любопытства / неожиданности | Обрыв «чик!» в момент, когда вот-вот раскроется противоречие / вот-вот решится исход боя |

### Примеры библиотеки шаблонов «заданий с пропусками»

Классические сюжетные ходы разбираются на шаблоны-задания с пропусками и сохраняются в библиотеку паттернов (套路库) для использования при написании:

**Шаблон «расторжения помолвки» (退婚流)**:

```text
Героя публично унижает злодей (личность: ______)
Причина унижения (причина: ______)
Герой в тот момент не сопротивляется, а произносит одну фразу (реплика: ______)
Спустя несколько глав герой возвращается с (результатом: ______), заставляя злодея (реакция: ______)
```

### Связь с существующим шаблоном «четырёх ударов»

Метод «заданий с пропусками» не заменяет метод четырёх ударов, а является **дополнительным взглядом**: метод четырёх ударов исходит из «что нужно по структуре» (хук / награда / оставленный хук), метод заданий с пропусками — из «что читатель должен почувствовать в этой главе» (эмоциональная цель прежде всего). При реальном написании рекомендуется использовать обе таблицы вместе:

```markdown
Точки приземления четырёх ударов этой главы: хук___ накопление___ награда___ оставленный хук___
Эмоциональная цель этой главы: заставить читателя почувствовать___
Способ заполнения пропусков этой главы: продвигающий сюжет___ + эмоциональный опыт___ (если есть) + хук-интрига___ 
```
