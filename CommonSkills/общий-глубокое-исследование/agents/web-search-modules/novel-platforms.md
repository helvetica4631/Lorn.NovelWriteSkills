# Стратегия поиска по романным платформам

## Сценарии применения
- Исследование трендов жанра: популярность жанра на определённой платформе, топовые произведения, динамика новинок
- Исследование экосистемы платформы: портрет читателей, механизм рекомендаций, стандарты подписания, правила трафика
- Сбор информации о произведениях конкурентов: данные списков, данные произведений, косвенные сигналы отзывов читателей

## Приоритет источников информации

### Первый приоритет: официальные данные платформы
- **Qidian (起点中文网)**: страницы списков Qidian (список месячных голосов / бестселлеры / новинки / «Саньцзян» / «Цянтуй»), страницы деталей произведения, раздел отзывов / комментарии к главам (本章说) / круг друзей по книге, сторонние агрегаторы данных Qidian (например, qidiantu.com — только для дополнительного подтверждения)
- **Fanqie Novel (番茄小说)**: списки Fanqie, страницы произведений, открытая информация помощника автора Fanqie
- **Qimao Free Novels (七猫免费小说)**: списки Qimao, страницы произведений
- **Zongheng (纵横中文网)**: списки Zongheng, страницы произведений
- **Zhihu Yanxuan (知乎盐选)**: страницы колонок Yanxuan, круглые столы Zhihu
- **Douban Read (豆瓣阅读)**: списки Douban Read, страницы произведений, рецензии Douban
- **WebNovel / GoodNovel / My Fiction**: страницы списков и произведений соответствующих платформ

### Второй приоритет: отраслевой анализ
- Отраслевые отчёты, связанные с Yuewen / IP (годовые отчёты Yuewen, открытые материалы конференций по IP-экосистеме)
- Аналитические статьи отраслевых самомедиа о веб-литературе (например, паблики/колонки Zhihu вроде «Наблюдения за веб-романами», «Разбор хитовых романов»)
- Информация о политике поддержки категорий и конкурсах текстов, публикуемая официально каждой платформой

### Третий приоритет: платформы-агрегаторы данных
- Сторонние сайты-агрегаторы списков (только для дополнительного подтверждения, не должны самостоятельно нести ключевые выводы)
- Платформы статистики данных о романах (обращать внимание на надёжность и актуальность данных)

## Стратегия поиска
1. Сначала искать по официальным каналам: `site:qidian.com {题材} 2026` (`{题材}` — жанр)
2. Затем искать отраслевой анализ: `{平台} {题材} 趋势 2025 2026 分析` (платформа, жанр, тренд, анализ)
3. Дополнительно искать обсуждения читателей: `{作品名} 书评 | {作品名} 怎么样 | {题材} 推荐` (название произведения; отзыв / как оно / рекомендации по жанру)
4. Для зарубежных платформ: сначала искать соответствующий анализ по-китайски, затем искать исходный сайт платформы по-английски

## Требования к качеству
- В первую очередь использовать проверяемые открытые данные
- Косвенные сигналы (например, место в рейтинге вместо средних подписок) обязательно помечать как косвенные, подделывать нельзя
- Чувствительность к актуальности: помечать временное окно данных
- При межплатформенном сравнении использовать единую временную базу
