# общий-глубокое-исследование-добавление-полей

## Способ запуска
`/research-add-fields`

## Процесс выполнения

### Шаг 1: автоматически найти файл Fields
Найти в текущем рабочем каталоге файл `*/fields.yaml`, автоматически прочитать существующие определения fields.

### Шаг 2: получить дополнительные источники
Спросить пользователя о выборе:
- **A. Пользователь вводит напрямую**: пользователь даёт названия и описания полей
- **B. Поиск в Web Search**: запустить web-search-agent, чтобы найти часто используемые в этой области поля

### Шаг 3: показать и подтвердить
- Показать список предлагаемых новых полей
- Пользователь подтверждает, какие поля нужно добавить
- Пользователь указывает категорию полей и detail_level

### Шаг 4: сохранить обновление
Дописать подтверждённые поля в fields.yaml, сохранить файл.

## Вывод
Обновлённый файл `{topic}/fields.yaml` (правка на месте, требуется подтверждение пользователя)
