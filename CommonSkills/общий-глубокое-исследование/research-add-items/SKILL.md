# общий-глубокое-исследование-добавление-тем

## Способ запуска
`/research-add-items`

## Процесс выполнения

### Шаг 1: автоматически найти Outline
Найти в текущем рабочем каталоге файл `*/outline.yaml`, автоматически прочитать.

### Шаг 2: параллельно получить дополнительные источники
Одновременно выполнять:
- **A. Спросить пользователя**: какие items нужно добавить? Есть ли конкретные названия? — в первую очередь учесть, не остались ли не включёнными объекты, имеющие прямую ценность для творца, и какие пробелы информации могут проявиться в персонажах, настройках и плане текущего проекта.
- **B. Спросить, нужен ли Web Search**: запускать ли агента для поиска дополнительных items?

### Шаг 3: объединить и обновить
- Дописать новые items в outline.yaml
- Показать пользователю для подтверждения
- Избегать дубликатов
- Сохранить обновлённый outline

## Вывод
Обновлённый файл `{topic}/outline.yaml` (правка на месте)
