# Стратегия слияния стилей нескольких авторов

> Источник: SKILL.md, раздел «Стратегия слияния стилей нескольких авторов (новое)»

## Когда использовать слияние нескольких авторов

| Сценарий | Пояснение | Рекомендуемое число авторов |
| --- | --- | --- |
| **Взять лучшее в одной дорожке** | У A хорош ритм длины предложений, у B диалог чёткий и острый, у C точные сенсорные описания — берём лучшее у каждого | 2–3 |
| **Закрыть слабое место** | Целевой проект слаб по какому-то измерению (например, диалоговые голоса монотонны) — целенаправленно подключить отпечаток другого автора по этому измерению | 2 |
| **Кросс-стилевая разведка** | Неясно, какой стиль больше подходит, — сначала слить признаки верхнего уровня нескольких авторов-кандидатов в «стилевой прототип» и пробно написать | 2–3 |
| **Поиск наибольшего общего делителя** | Анализ общности слога нескольких авторов-хитов одной дорожки | 3–5 |

## Три стратегии слияния

### Стратегия А: метод основного–вспомогательного (рекомендуется для первого использования)

Выбрать шаблон стиля одного автора как «основной стиль» (базовая линия по измерениям — длина предложения / абзацы / чувства и т. д.), остальные авторы покрывают только отдельные измерения.

```text
Основной стиль: [автор A] — даёт полную базовую линию по 16 измерениям
Вспомогательный стиль: [автор B] — заменяет §4 стиль диалога + §10 дифференциация голосов (отпечаток диалога B лучше)
Вспомогательный стиль: [автор C] — заменяет §3 сенсорные предпочтения (сенсорные описания C лучше соответствуют целевому жанру)
```

**Способ вывода**: один «синтезированный шаблон стиля», незаменённые измерения наследуют значения основного стиля; для заменённых измерений указываются источник и причина замены.

### Стратегия Б: метод по областям (разделение труда на уровне измерений)

Основной стиль не задаётся, авторы дистиллируются раздельно по областям измерений и объединяются в один синтезированный шаблон.

```text
Автор [A] → §1 длина предложения + §2 абзацы + §7 выражение эмоций (область ритма и эмоций)
Автор [B] → §4 диалог + §10 голос + §14-2 тон и стиль речи (область диалога и голоса)
Автор [C] → §3 чувства + §6 метафоры + §11 время + §12 пространство (область восприятия и композиции)
```

**Способ вывода**: один «синтезированный шаблон стиля», в каждом разделе указан автор — источник данных.

### Стратегия В: метод пересечения (приоритет общего)

По каждому измерению отдельно подсчитать данные нескольких авторов и выделить закономерности, «верные для большинства», в качестве синтезированной базовой линии. Конкретный способ тот же, что у метода пересечения для образца произведения, только «образец» заменяется на «автор».

## Арбитраж конфликтов нескольких авторов

| Тип конфликта | Способ обработки |
| --- | --- |
| **Риск сближения голосов** | Если у основного и вспомогательного стиля слабы отпечатки дифференциации голосов (различие длины предложений между персонажами < 0,2), после слияния может возникнуть ещё более сильное сближение голосов. Следует привлечь данные третьего автора по этому измерению в качестве базовой линии либо явно понизить уверенность синтезированного шаблона по этому измерению |

## Именование результата — синтезированного шаблона стиля

Синтезированный шаблон стиля записывается как:

```text
蒸馏产物/作者风格模板/[合成标识]-综合风格模板.md
```

Правила именования: метод основного–вспомогательного — `[主作者]-[辅作者]-综合`; метод по областям — `[赛道名]-[题材]-综合`; метод пересечения — `[赛道名]-共性综合`.

## Регистрация в Agents.md

Синтезированный шаблон стиля регистрируется как группа связанных записей:

```markdown
### 作者风格模板（合成）(шаблон стиля автора, синтезированный)
- 合成标识 (идентификатор синтеза)：[如 "作者A-作者B-综合"]
- 主模板路径 (путь к основному шаблону)：蒸馏产物/作者风格模板/[合成标识]-综合风格模板.md
- 融合策略 (стратегия слияния)：[主辅法 / 分域法 / 交集法]
- 融合日期 (дата слияния)：YYYY-MM-DD
- 适用平台 (применимые платформы)：[平台名] 或 默认
- 源模板 (исходные шаблоны)：
  1. [作者 A] — 路径 (путь)：蒸馏产物/作者风格模板/[作者A]-作者风格模板.md — 贡献维度 (вклад по измерениям)：§1 句长 / §2 段落 / §7 情绪
  2. [作者 B] — 路径 (путь)：... — 贡献维度 (вклад по измерениям)：§4 对话 / §10 声口
```

Синтезированная запись и запись одного автора существуют в `Agents.md` параллельно, различаются суффиксом `（合成）`. При автоматическом обнаружении нижестоящими Skill **синтезированная запись имеет приоритет выше, чем запись одного автора**.

## Связь процесса «дистилляция одного автора → синтезированная дистилляция»

По умолчанию сначала раздельно дистиллируются авторы (каждый регистрирует отдельную запись в Agents.md), затем делается синтез; по требованию можно пропустить отдельную регистрацию и сразу синтезировать, но результат синтеза обязан ссылаться на информацию об исходных шаблонах.
