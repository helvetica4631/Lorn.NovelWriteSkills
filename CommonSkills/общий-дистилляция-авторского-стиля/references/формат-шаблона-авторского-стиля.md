# Определение формата шаблона стиля автора

> Этот файл определяет формат результата `общий-дистилляция-авторского-стиля`. Нижестоящие Skill используют его в этом формате.

---

## Выходной файл

По завершении дистилляции выходной файл записывается в корневой каталог целевого проекта:

```text
蒸馏产物/作者风格模板/[作者名]-作者风格模板.md
```

Если это дистилляция со слиянием стилей нескольких авторов (подробности — в разделе «Стратегия слияния стилей нескольких авторов» SKILL.md), имя файла результата подчиняется правилу синтеза:

```text
蒸馏产物/作者风格模板/[合成标识]-综合风格模板.md
```

### Регистрация одного автора

В `Agents.md` в корне целевого проекта дописать регистрационную запись (если `Agents.md` не существует, создать автоматически), формат:

```markdown
### 作者风格模板 (шаблон стиля автора)
- 名称 (название)：[作者名]
- 路径 (путь)：蒸馏产物/作者风格模板/[作者名]-作者风格模板.md
- 蒸馏日期 (дата дистилляции)：YYYY-MM-DD
- 蒸馏范围 (объём дистилляции)：[作品列表]，[章节/字数范围]
- 适用平台 (применимые платформы)：[番茄 / 起点 / 七猫 / ...] или 默认 (по умолчанию)
```

### Регистрация синтеза нескольких авторов

Регистрационная запись синтезированной дистилляции использует синтезированный формат, название отличается суффиксом `（合成）`:

```markdown
### 作者风格模板（合成）(шаблон стиля автора, синтезированный)
- 合成标识 (идентификатор синтеза)：[如 "作者A-作者B-综合"]
- 主模板路径 (путь к основному шаблону)：蒸馏产物/作者风格模板/[合成标识]-综合风格模板.md
- 融合策略 (стратегия слияния)：[主辅法 / 分域法 / 交集法]
- 融合日期 (дата слияния)：YYYY-MM-DD
- 适用平台 (применимые платформы)：[平台名] 或 默认
- 源模板 (исходные шаблоны)：
  1. [作者 A] — 路径 (путь)：蒸馏产物/作者风格模板/[作者A]-作者风格模板.md — 贡献维度 (вклад по измерениям)：§1 句长 / §2 段落 / §7 情绪
  2. [作者 B] — 路径 (путь)：... — 贡献维度 (вклад по измерениям)：§4 对话 / §10 声口
```

Синтезированная запись и запись одного автора существуют в `Agents.md` параллельно. При автоматическом обнаружении нижестоящими Skill синтезированная запись имеет приоритет выше. Полные правила — в разделе «Стратегия слияния стилей нескольких авторов» SKILL.md.

```markdown

> Способ выборки: [поиск в сети / локальный корпус / смешанный]
```
