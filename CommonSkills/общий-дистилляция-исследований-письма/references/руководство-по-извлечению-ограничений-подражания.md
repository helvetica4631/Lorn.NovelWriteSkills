# Руководство по извлечению ограничений для подражания

> Источник: SKILL.md § «Извлечение ограничений для подражания (новое — специальное извлечение для сценария подражания)»

В отчётах по исследованию письма кроме общих правил письма много выводов о том, «что сейчас может взлететь в данный момент». Если при дистилляции явно известно или можно предположить, что она служит сценарию подражания (например, пользователь просит дистиллировать «исследование топа новичков того же жанра на платформе Fanqie»), обязательно добавлять следующие измерения извлечения.

## Извлечение основного шаблона «дорожки»

Из отчёта извлекать: «какие произведения легче всего проходят отбор / подписываются / набирают обороты в данный момент времени, на данной платформе, в данном жанре» — это не общие правила письма, а **конкретные шаблоны окна рынка**:

| Измерение извлечения | Сигнальные слова в отчёте | Перевод в ограничения |
| --- | --- | --- |
| Сейчас популярный тип главного героя | "底层小人物" (мелкий человек со дна) "穿越者" (попаданец) "重生者" (переродившийся) "系统持有者" (владелец системы) "幕后黑手" (закулисный злодей) | → ограничение типа персонажа (рекомендация текущего окна) |
| Сейчас популярный режим «золотого пальца» | "签到系统" (система отметок) "模拟器" (симулятор) "进化吞噬" (эволюция-поглощение) "身份反转" (смена личности) "幕后操控" (закулисное управление) | → ограничение режима «золотого пальца» (рекомендация текущего окна) |
| Сейчас популярный режим начала | "灵堂受辱" (унижение в траурном зале) "重生回关键节点" (перерождение в ключевой узел) "系统激活" (активация системы) "大逃杀开局" (начало «королевской битвы») | → ограничение режима начала (рекомендация текущего окна) |
| Сейчас популярный режим ритма | "黄金三章" (золотые три главы) "开头 300 字必须..." (первые 300 знаков должны...) | → ограничение ритма начала (жёсткий гейт) |
| Режимы, которые сейчас остывают | "XXX 已经太多" (XXX уже слишком много) "XXX 读者已经审美疲劳" (у читателей XXX вызывает эстетическую усталость) | → ограничение «чего избегать» (текущее окно не рекомендует) |
| Пробелы нынешнего рынка | "目前缺少 XXX 类型的新书" (сейчас не хватает новых книг типа XXX) "XXX 赛道还有空间" (в «дорожке» XXX ещё есть место) | → подсказка о возможности дифференциации |

## Анализ пространства дифференциации

Исходя из многократных упоминаний в нескольких отчётах «схожести», «однородности», «эстетической усталости», «новых находок», извлекать следующую информацию:

| Измерение | Метод извлечения | Результат |
| --- | --- | --- |
| Чрезмерно разработанные схемы | Межотчётная статистика того, на какие приёмы указывают негативные ключевые слова «однородность», «эстетическая усталость», «банальная схема», «затёрто до дыр» | → список схем, которых нужно обязательно избегать |
| Подразделы, где ещё есть пространство | Межотчётная статистика того, на какие приёмы указывают позитивные ключевые слова «новое направление», «есть пространство», «стоит попробовать», «этим занимаются немногие авторы» | → варианты дифференциации на выбор |
| Пробелы в потребностях читательских слоёв | Неудовлетворённые части описаний потребностей разных групп в отчётах — «старые читатели», «широкие читатели», «женщины-читатели», «молодые читатели» | → рекомендации по якорям для слоёв читателей |

## Извлечение режимов слияния жанров и пересечения границ

Дифференциация при подражании часто идёт не от «сделать лучше на уже существующей дорожке», а от «слияния двух не связанных режимов».

### Режим слияния внутри одного жанра

Когда отчёт показывает, что какая-то «дорожка» уже сильно однородна, извлекать из отчёта осуществимые направления «дифференциации внутри класса»:

| Измерение извлечения | Сигнальные слова | Перевод в ограничения |
| --- | --- | --- |
| Слияние извлечением элементов | "把 A 作品的 X 设定 + B 作品的 Y 体系整合" (объединить настройку X произведения A + систему Y произведения B) | → рекомендуемое направление сочетания блюпринтов |
| Перенос механизма конфликта | "把侦探小说的悬疑逻辑嫁接到宫斗文里" (привить логику саспенса детективного романа к придворным интригам) | → рекомендуемое направление механизма конфликта |
| Единство правил мира | "同时有修仙和科技的世界需要统一的力量法则" (мир, где одновременно есть культивация и технологии, требует единого закона силы) | → ограничения проектирования мира |

### Режим слияния через границы жанров

Когда отчёт упоминает концепции «прорыв типа», «выход за круг», «кроссовер», извлекать осуществимые измерения кроссовера:

| Тип кроссовера | Сигнал в отчёте | Перевод в ограничения |
| --- | --- | --- |
| **Научная фантастика + культивация** | "科技修仙" (технологическая культивация) "用科学解释灵力" (объяснять духовную силу наукой) | → подсказка направления кроссовера |
| **Саспенс + романтика** | "推理式恋爱" (любовь в духе расследования) "案件推动关系" (дело двигает отношения) | → подсказка направления кроссовера |
| **История + попаданец + бизнес** | "回到古代搞经济" (вернуться в древность заниматься экономикой) "古代职场文" (офисная проза древности) | → подсказка направления кроссовера |
| **Игра + реальность** | "游戏世界影响现实" (игровой мир влияет на реальность) "现实技能在游戏中有用" (реальные навыки полезны в игре) | → подсказка направления кроссовера |

### Извлечение ограничений правдоподобия кроссовера (обязательно)

Наибольший риск кроссовера — «слишком нелепые настройки». Успех кроссовера зависит от **построения внутренней правдоподобности**. Поэтому при извлечении из отчёта направлений кроссовера обязательно одновременно извлекать следующие ограничения осуществимости:

| Измерение правдоподобия | Метод извлечения | Результат |
| --- | --- | --- |
| **Логическая опора** | Предлагает ли отчёт какую-то «рационализирующую оболочку»? (например, логическая опора «системного потока» — «правила игры вторгаются в реальность») | → ограничение логической опоры кроссовера |
| **Постепенное введение** | Предлагает ли отчёт «не раскрывать все настройки с самого начала»? Каков шаг постепенного раскрытия? | → ограничение ритма раскрытия |
| **Нижняя граница эмоциональной логики** | Подчёркивает ли отчёт, что «как бы необычны ни были настройки, у эмоций должна быть реальная основа»? | → жёсткий гейт эмоциональной правдивости |
| **Когнитивная стоимость читателя** | Оценивает ли отчёт, сколько глав читателю нужно, чтобы понять эту настройку кроссовера? | → предупреждение о когнитивной стоимости |

## Качественный гейт интеграции материала (новое)

При извлечении из нескольких отчётов ограничений-«швов» следующие три принципа подчёркивают «жёсткие условия интеграции материала». Каждое извлечённое ограничение должно пройти проверку тремя вопросами:

| Принцип | Способ проверки | Сигнал непрохождения |
| --- | --- | --- |
| **Единство темы** | Служат ли все ограничения после слияния одной основной теме/одной основной торговой точке? | Ограничения указывают на разные обещания читателю (например, «и саспенс, и сладкая любовь, но ни то ни другое не получилось») |
| **Согласованность стиля** | Нет ли явных стилевых конфликтов между ограничениями после слияния? (например, одновременно появляются «требования стиля — изящная древность» и «требования ритма — скорость короткого видео») | Два ограничения по одному измерению предъявляют непримиримо противоречивые требования |
| **Логическая самосогласованность** | Указывают ли ограничения из разных источников по одному измерению в одну сторону? | Отчёт A говорит «в первых 300 знаках должен быть конфликт», отчёт B — «в начале нужна медленная подготовка»: если противоречие непримиримо, остаётся выбрать одно из двух, одновременно сохранять нельзя |

Все три вопроса пройдены → слияние сохраняется. Любой не пройден → либо отбросить один из источников, либо пометить «конфликт: это ограничение «одно из двух», конкретное исполнение требует решения пользователя».

## Пометка происхождения (обязательно)

Во всех ограничениях типа «сейчас популярно / сейчас остывает / ещё есть место», извлечённых из отчётов, в поле источника обязательно указывать **дату публикации отчёта**, поскольку чувствительность окна рынка ко времени очень высока:

| Метка | Значение |
| --- | --- |
| `[2026年Q1]` | Этот вывод основан на исследовании, опубликованном в первом квартале 2026 года |
| `[2025年]` | Этот вывод основан на отчёте 2025 года, актуальность снижена |
| `[时效不明]` | В отчёте не указано явно время исследования, служит лишь справкой |
