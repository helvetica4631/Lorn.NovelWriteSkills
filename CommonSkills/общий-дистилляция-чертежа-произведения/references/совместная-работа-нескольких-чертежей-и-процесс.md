# Стратегия совместной дистилляции нескольких образцов и процесс исполнения

> Источник: SKILL.md §«Стратегия совместной дистилляции нескольких образцов (новое)» + §«Процесс исполнения»

## Стратегия совместной дистилляции нескольких образцов

### Когда использовать многообразцовый режим

| Сцена | Пояснение | Рекомендуемое число образцов |
| --- | --- | --- |
| **Взять лучшее на одной дорожке** | У A сильная цепкость начала главы, у B хорошая ротация хуков, у C плотные награды в середине | 2–4 |
| **Скрещивание дорожек** | Перенести успешные структуры разных дорожек на целевой жанр | 2–3 |
| **Структурное дополнение охвата** | У одного образца неполные сегменты томов, дополнить другим произведением того же автора | 2 |
| **Поиск наибольшего общего делителя** | Общие закономерности нескольких хитов одной дорожки | 3–5 |

### Три стратегии совместной работы

#### Стратегия A: метод «основной — вспомогательный» (рекомендуется использовать первым)

Выбрать одно произведение как «основной образец» (база структурного каркаса), остальные 1–3 — как «вспомогательные образцы» (покрывают или заменяют только в отдельных измерениях).

#### Стратегия B: метод разделения по областям (разделение труда на уровне измерений)

Основной образец не назначается, образцы дистиллируются раздельно по областям измерений и объединяются в один комплексный образец.

#### Стратегия C: метод пересечения (приоритет общего)

По одному и тому же измерению многих образцов провести раздельную статистику и извлечь общие закономерности, «выполняющиеся у большинства».

### Арбитраж конфликтов нескольких образцов

| Тип конфликта | Способ обработки |
| --- | --- |
| **Числовой конфликт** (у A интервал хуков 2 главы, у B 4) | Ориентироваться на значение, лучше соответствующее целевой платформе, с указанием причины |
| **Конфликт направлений** (у A в основном вступление диалогом, у B в основном интрига в начале) | Ориентироваться на образец, более близкий целевому жанру |
| **Структурный конфликт** (у A один POV, у B несколько POV) | Рекомендация по областям: в главах XX использовать один POV, в главах YY — несколько POV |
| **Конфликт паттернов-套路** (A и B используют взаимоисключающие комбинации паттернов-套路) | Ориентироваться на комбинацию паттернов-套路 основной дорожки |

### Именование комплексного образца на выходе

- Метод «основной — вспомогательный»: `[название основного образца]-[название вспомогательного образца]-综合`
- Метод разделения по областям: `[название основной дорожки]-[целевой жанр]-综合`
- Метод пересечений: `[название дорожки]-共性综合`

## Краткий обзор процесса исполнения

| Phase | Шаги | Ключевые шлюзы/жёсткие правила |
| --- | --- | --- |
| **Phase 0** | Уточнение требований | Подтвердить название произведения, диапазон глав (по умолчанию первые 100 глав или вся книга), приоритетные измерения, пометку платформы, переключатель дистилляции паттернов-套路 |
| **Phase 0.5** | Создание пакета материалов дистилляции | Обязательно создать `[作品名]-作品蓝本档案/`; если есть только оглавление без основного текста, можно выдать лишь «образец уровня оглавления с низкой достоверностью» |
| **Phase 1** | Сбор информации | Собирать 13 измерений + отпечаток паттернов-套路 по приоритету; чёрный список источников информации: Zhihu, WeChat Official Accounts, Baidu Baike |
| **Phase 1.5** | Распознавание сюжетных линий | Разметка повествовательного вопроса по главам → фильтр трёх вопросов → четырёхцветная разметка → отображение начало—конец (подробнее см. `references/стадия-распознавания-сюжетной-линии-phase-1-5.md`) |
| **Phase 2** | Статистика и извлечение | Заполнять по шаблону пункт за пунктом; затем извлечение паттернов-套路 → проверка воспроизводимости между томами → извлечение слоя сущностного сходства → дуга противоречий повествования |
| **Phase 2.5** | Подтверждение извлечения | Вывести структурную сводку (основные отпечатки / количественные поля / поля низкой достоверности / сводка паттернов-套路 / сводка слоя сущностного сходства); только после подтверждения пользователем можно переходить к Phase 3 |
| **Phase 3** | Результат и регистрация | Сгенерировать шаблон `.md` → записать в `蒸馏产物/` → зарегистрировать в `Agents.md` |
| **Phase 4** | Проверка качества | Четыре проверки: обратное тестирование на отложенных главах, тест предсказания позиции, проверка на антиплагиат, тест потерянной главы |
| **Phase 5** | Доводка двумя Agent | Agent A: рецензия исполнимости структуры; Agent B: рецензия границ оригинальности |

### Отслеживание переноса ритма между томами

Для длинных произведений (100+ глав) обязательно явно отслеживать:
1. **Разбивка на стадии ритма**: разделить всё произведение по режиму ритма на 2–4 стадии
2. **Пометка границ стадий**: с точностью до номеров глав
3. **Статистика по стадиям**: по каждой стадии отдельно считать ключевые измерения
4. **Итог режима переноса**: одной фразой обобщить направление переноса ритма
5. **Проверка границ переноса**: сопровождается ли перенос ритма сменой сегмента тома / расширением мироустройства / качественным изменением личности главного героя

### Согласование с пятимерной рамкой профессионального общего плана

| Профессиональное измерение | Соответствующие свидетельства в образце |
| --- | --- |
| **Дизайн начала** | Статистика режима начала главы + хука + награды в первых 3 главах |
| **Плотность тактов** | Плотность функциональных позиций глав + отпечаток награды в середине + отпечаток хука |
| **Четыре слоя противоречий** | Частота появления и модели переплетения внешнего / внутреннего / отношенческого / тематического конфликтов |
| **Дизайн персонажей** | Такты появления персонажей + распределение эмоциональных дуг |
| **Коммерческое мышление** | Отпечаток хука в конце главы + отпечаток награды в середине + такт «сцена — продолжение сцены» |

### Обновление существующего шаблона образца произведения

Инкрементальное обновление: инкрементальная выборка только по новым главам или измерениям, на неточность которых указал пользователь. При сравнении старых и новых выводов: новые образцы подкрепляют старую закономерность → дополнить источник; новые опровергают → пометить «этапное изменение ритма»; новые подтверждаются только в определённом сегменте тома → записать как «локальная закономерность сегмента тома».
