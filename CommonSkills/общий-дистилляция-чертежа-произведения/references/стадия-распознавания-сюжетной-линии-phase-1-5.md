# Этап распознавания сюжетных линий (Phase 1.5)

> Источник: SKILL.md §«Этап распознавания сюжетных линий (Phase 1.5 — новое, обязательно)»

В процесс дистилляции после завершения **Phase 1 (сквозная статистика прочтения)** и до запуска **Phase 2 (три вопроса о сущностном сходстве)** обязательно вставляется подэтап «распознавание сюжетных линий».

## Шаги исполнения

```text
Phase 1.5 — Распознавание сюжетных линий
│
├─ 1.5.1 По главам разметить «повествовательный вопрос» (новый вопрос в конце главы / вопрос, на который ответили в конце главы)
│    └─ Выход: таблица отслеживания повествовательных вопросов
│
├─ 1.5.2 Фильтр трёх вопросов → сформировать перечень кандидатов в сюжетные линии
│    │    ① Есть ли у неё самостоятельная причинная цепочка?  ② Присутствует ли она устойчиво хотя бы в 3 главах?
│    │    ③ Если её убрать, пострадает ли основная линия?
│    └─ Выход: перечень кандидатов в сюжетные линии (с классификацией L1–L5)
│
├─ 1.5.3 Четырёхцветная разметка → по главам отметить участие каждой линии
│    │    🔴 Основная линия / 🔵 Побочная линия + дуга персонажа / 🟢 Линия отношений / 🟡 Закладка и возврат
│    └─ Выход: четырёхцветная схема распределения (состояние присутствия каждой линии по каждой главе)
│
├─ 1.5.4 Отображение начало—конец → обнаружение «ящика»
│    │    · Невозвращённая линия: есть начало, нет конца → пометить
│    │    · Оборванная линия: пропала посередине и дальше нет продолжения → пометить
│    │    · Линия слабой связи: плотность появления < 20 % → пометить
│    └─ Выход: реестр сюжетных линий (с полнотой возврата)
│
└─ 1.5.5 Проверка воспроизводимости между сюжетными линиями событий → включить в существующую рамку тройной проверки
     └─ Выход: вывод проверки (пройдено / понижено / отброшено)
```

## Требования к выходным продуктам

- Обязательно заполнить таблицу «обзор сюжетных линий» в шаблоне **§15 Реестр сюжетных линий** (номер каждой линии, тип, начальная глава, конечная глава, плотность появления, повествовательный вопрос)
- Обязательно заполнить таблицу «оценка сюжетных линий» (разумность числа линий, полнота возврата, плотность переплетения, равномерность распределения, вклад побочных линий в основную)
- Рекомендуется заполнить таблицу «режимы переплетения сюжетных линий» (плетение / чередование / вложение / подчинение)
- Рекомендуется заполнить таблицу «исключение типичных ошибочных суждений» (исключить хотя бы 2 легко путаемых кандидата)

Подробный метод см. в `исследования-письма/写作技法_蒸馏小说时识别与理清故事线的方法.md`.
