# Определение формата шаблона образца произведения

> Этот файл определяет выходной формат `общий-дистилляция-чертежа-произведения`. Нижестоящие Skill потребляют продукт в этом формате.

---

## Выходной файл

По завершении дистилляции выходной файл записывается в корневой каталог целевого проекта:

```text
蒸馏产物/作品蓝本模板/[作品名]-作品蓝本模板.md
```

Для многообразцовой синтезной дистилляции (подробнее см. раздел SKILL.md «Стратегия совместной дистилляции нескольких образцов») именование выходного файла следует правилу синтеза:

```text
蒸馏产物/作品蓝本模板/[合成标识]-综合蓝本模板.md
```

### Регистрация одного образца

В `Agents.md` в корне целевого проекта дописать регистрационную запись (если `Agents.md` не существует, создать автоматически), формат:

```markdown
### 作品蓝本模板 (шаблон образца произведения)
- 名称 (название)：[название произведения]
- 路径 (путь)：蒸馏产物/作品蓝本模板/[作品名]-作品蓝本模板.md
- 蒸馏日期 (дата дистилляции)：YYYY-MM-DD
- 蒸馏范围 (объём дистилляции)：[глава X – глава Y]
- 首发平台 (платформа первой публикации)：[название платформы]
- 适用平台 (применимые платформы)：[番茄 / 起点 / 七猫 / ...] или 默认 (по умолчанию)
```

### Регистрация многообразцового синтеза

Регистрационная запись синтезированной дистилляции использует синтезированный формат, название отличается суффиксом `（合成）`:

```markdown
### 作品蓝本模板（合成）(шаблон образца произведения, синтезированный)
- 合成标识 (идентификатор синтеза)：[например "Qidian-интрига-городской-саспенс-综合"]
- 主模板路径 (путь к основному шаблону)：蒸馏产物/作品蓝本模板/[合成标识]-综合蓝本模板.md
- 合成策略 (стратегия синтеза)：[主辅法 / 分域法 / 交集法]
- 合成日期 (дата синтеза)：YYYY-MM-DD
- 适用平台 (применимые платформы)：[название платформы] или 默认 (по умолчанию)
- 源蓝本 (исходные образцы)：
  1. [произведение A] — 路径 (путь)：蒸馏产物/作品蓝本模板/[作品A]-作品蓝本模板.md — 贡献维度 (вклад по измерениям)：§1 режим начала главы / §2 хук в конце главы
  2. [произведение B] — 路径 (путь)：... — 贡献维度 (вклад по измерениям)：§4 ритм сцен / §9 функциональные позиции
```

Синтезированная запись и запись одного образца существуют в `Agents.md` параллельно. При автоматическом обнаружении нижестоящими Skill приоритет синтезированной записи выше, чем записи одного образца. Полные правила см. в разделе SKILL.md «Стратегия совместной дистилляции нескольких образцов».

## Полный формат шаблона

```markdown
# [название произведения] · Шаблон образца произведения

> 蒸馏日期 (дата дистилляции)：YYYY-MM-DD
> Объём дистилляции: [глава X – глава Y], всего [N] глав
> Способ выборки: [поиск в сети / локальный корпус / смешанный]
> Платформа: [Qidian (起点中文网) / Fanqie / Qimao / Zhihu Yanxuan / другая]

## 15. Реестр сюжетных линий

> В этом разделе записано, сколько сюжетных линий у образца, тип каждой линии, жизненный цикл, режим переплетения и полнота возврата.
> **Определение сюжетной линии**: повествовательная единица, соединённая причинно-следственными связями и продолжающаяся в нескольких главах. Единичное событие, повторяющийся образ, выпуск фоновых настроек не образуют самостоятельной сюжетной линии. Сюжетная линия = цепочка «вопрос — ответ»: она начинается с постановки повествовательного вопроса и заканчивается ответом на него.

### Пятислойная система классификации

При дистилляции классифицировать каждую линию по следующим уровням:

| Уровень | Тип | Определение | Критерии суждения |
| --- | --- | --- | --- |
| **L1** | **Основная линия** (Main Plot) | Самая главная причинно-следственная цепочка всей книги, охватывает начало и конец | ① Без неё вся история не состоится ② Проходит через всю книгу ③ Обещана в названии / аннотации |
| **L2** | **Побочная линия** (Subplot) | Второстепенная причинная цепочка, параллельная основной линии | ① Есть самостоятельная структура «вопрос — ответ» ② Без неё основная линия остаётся, но становится тоньше |
| **L3** | **Дуга персонажа** (Character Arc) | Траектория внутреннего изменения роли от начала до конца | ① Есть измеримое изменение состояния ② Изменение охватывает несколько глав ③ Причинная цепочка полна |
| **L4** | **Линия отношений** (Relationship Arc) | Траектория изменения состояния отношений между двумя персонажами | ① У отношений есть чёткое начальное и конечное состояние ② Изменение постепенно двигают несколько событий |
| **L5** | **Линия закладки / возврата** (Setup & Payoff) | Информационная цепочка, где детали, заложенные раньше, активируются и реализуются позже | ① Интервал между точкой закладки и точкой возврата > 1 тома ② При возврате оказывает существенное влияние на сюжет |

**Приоритет суждения**: одна повествовательная нить может одновременно относиться к нескольким уровням; при дистилляции относить к наиболее выраженному уровню.

| Тип ошибочного суждения | Ошибочно принято за | Фактическая классификация | Метод исключения |
| --- | --- | --- | --- |
| Одиночный флешбэк / сцена воспоминания | Дуга персонажа | Функция сцены (раскрытие предыстории) | Это воспоминание встречается только один раз |
| Повторяющийся образ / мотив | Линия закладки | Элемент повествовательного стиля | Нет продвижения причинности |

| Единичное дело / единичное событие | Сюжетная линия | Локальная дуга события | Закрывается в конце этой главы |

## 16. Отпечаток привлечения и удержания читателя

> **Приоритет дистилляции этого раздела наивысший.** Эти отпечатки прямо отвечают на вопросы «почему читатель открывает эту книгу» и «почему после открытия продолжает читать» — они ближе к сути успеха произведения, чем любая структурная статистика.
