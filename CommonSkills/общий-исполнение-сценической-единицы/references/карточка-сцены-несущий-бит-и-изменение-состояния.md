# Карточка постройки одной сцены — шаблон несущего бита (beat) и изменения состояний

> Используется для сжатия сцены до по-настоящему исполнимой минимальной единицы постройки. Подходит, когда обязанность отдельной сцены «воздушна», цепочка действий есть, но несущий бит (beat) неясен, состояния входа и выхода нестабильны, после написания трудно принять.

## Когда включать

- Если убрать сцену, вы сами не можете сказать, что потеряется.
- Сцена несёт ключевую обязанность, но можно написать лишь «что-то произойдёт».
- Сцене нужен явный несущий бит (beat), чтобы при последующем расширении основного текста не уходить всё дальше в сторону.
- Сцена должна принять от контрольной карточки отдачу середины, цену эскалации или хук в конце главы.

## Минимальные принципы

- Сцена по умолчанию закрепляет **ровно одну единую главную задачу**.
- Сцена по умолчанию обязана чётко прописывать **состояние входа** и **состояние выхода**.
- Несущий бит (beat) по умолчанию нельзя удалять или без причины менять местами.
- Если сцена в основном продвигается диалогом, дополнительно накладывать `субшаблон-диалоговой-сцены-голоса-подтекст-лестница-эскалации.md` (подшаблон диалоговой сцены: разница голосов, подтекст, лестница эскалации).

## Шаблон карточки постройки одной сцены

```markdown

## 1. Положение сцены
- Номер сцены:
- К какой главе относится:
- Единая главная задача этой сцены:
- Что эта сцена нести не должна:
- Обязанность этой сцены: цепляние / продвижение / отдача / эскалация / хук
- POV：
- Соответствующая линия питания:

## 2. Состояние входа
- Положение персонажей:
- Состояние отношений:
- Известная информация:
- Состояние ресурсов:
- Эмоциональный вход читателя:

## 3. Цель и сопротивление
- Что больше всего хочется получить прямо сейчас:
- Источник препятствия: персонаж / правило / время / пространство / эмоция / процедура
- Цена провала:
- Изменение, которое должно произойти не позднее:

## 4. Несущие биты (beat) (1–4)
- Бит 1: тип｜несущий / гибкий｜что делает:
- Бит 2: тип｜несущий / гибкий｜что делает:
- Бит 3 (необязательно): тип｜несущий / гибкий｜что делает:
- Бит 4 (необязательно): тип｜несущий / гибкий｜что делает:

## 5. Действие / диалог / улики
- Первое действие:
- Первая блокировка:
- Первое проявление информации:
- Первая точка приземления реагирующей стороны:
- Ключевой носитель этой сцены: предмет / квитанция / журнал / точка / свидетельство человека / телесная реакция

## 6. Изменение состояний
- Изменение персонажа:
- Изменение отношений:
- Изменение ресурсов:
- Изменение суждения:
- Эмоциональный выход читателя:

## 7. Концовка и передача
- Локальная отдача этой сцены:
- Новая цена / новая проблема этой сцены:
- Условие запуска следующей сцены:
- Отношение к следующей сцене: причинное / контрастное / параллельное / нарастающее
- Способ перехода: скачок во времени / смена пространства / эмоциональный мост / жёсткая склейка

## 8. Приёмка
- Можно ли чётко сказать единую главную задачу:
- Действительно ли состояния входа и выхода различаются:
- Все ли несущие биты (beat) на месте:
- Если убрать эту сцену, что потеряется:
- Не давит ли ещё интонация объяснения на действие:
```

## Проверочные вопросы и ответы

1. Кто в этой сцене больше всего чего хочет?
2. Кто / какая сила ему сейчас мешает?
3. Какое состояние было переписано к концу этой сцены?
4. Если убрать эту сцену, какого такта из четырёх тактов главы не будет?
5. Какой бит (beat) несущий и не подлежит сглаживанию?

## Частые очаги болезни

- Есть только атмосфера, нет главной задачи.
- Есть только информация, нет сопротивления.
- Есть только действие, нет изменения состояния.
- Есть только присутствие сцены, нет обязанности уровня главы.
- Есть только давление, нет точки приземления реагирующей стороны.

## Приоритет отката

Если после написания эта сцена всё ещё «воздушна», по умолчанию откатывать в следующем порядке:

1. Единая главная задача
2. Состояния входа / выхода
3. Несущий бит (beat)
4. Цена провала
5. Условие передачи следующей сцене

## Завершение в одной фразе

**Карточка постройки одной сцены решает вот что: на чём вообще держится эта сцена, что несёт её нагрузку и чем она подталкивает положение к следующей позиции.**
