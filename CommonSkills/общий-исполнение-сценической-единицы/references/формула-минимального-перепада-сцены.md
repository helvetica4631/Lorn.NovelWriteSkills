# Формула минимального подъёма сцены

Подходит для сжатия существующего сюжетного блока до сценической единицы с настоящими подъёмами, смещением, отдачей.

## 1. Затем по схеме «常、境、变» вытянуть минимальный подъём этой сцены

### 常 (норма): сначала дать читателю знать, как всё должно быть в этот момент

- Длинная предыстория не нужна, нужно лишь дать читателю знать, как «в нормальной ситуации» выглядит это место, эти отношения, эта процедура.
- Когда норма установлена, первая аномалия обретает силу.

### 境 (затруднение): довести проблему до затруднительного положения

- Затруднение — не абстрактное «очень трудно», а то, что персонаж действительно застрял, опоздал на шаг, оказался под наблюдением, сорвал действие, ошибся в суждении, не успел.
- Лучше всего, чтобы одновременно были:
  - Одно конкретное сопротивление
  - Одна немедленно ощутимая цена
  - Одно действие проверки или исправления

### 变 (перемена): к концу сцены обязательно должна быть перемена

- Перемена может быть хорошей, а может быть ещё худшей.
- Минимальное требование: как минимум один пункт состояния должен сместиться:
  - Изменились отношения персонажей
  - Изменился уровень риска
  - Изменилась формулировка
  - В руках стало больше или меньше одного ключевого предмета
  - Изменилось понимание проблемы

## 2. Четыре частые формулы сжатия

### Формула A: тип «повседневная трещина»

`Нормальное действие → лёгкая аномалия → персонаж перепроверяет → затруднение состоялось → оставляет новую проблему`

### Формула B: тип «профессиональный прорыв»

`Окружающие ошибаются в суждении → главный герой одной короткой фразой-суждением → немедленное действие → временный прорыв → вызывает более дорогие последствия`

### Формула C: тип «перекошенные отношения»

`Внешнее спокойствие → одна неправильная фраза → обнажается разница позиций → диалог эскалирует → отношения перестраиваются`

### Формула D: тип «подпитка удержания»

`Сначала дать немного отдачи → немедленно поднять цену → снова бросить новую переменную → закончить на незавершённом действии`

## 3. После написания быстро перепроверить по схеме «具、情、简、意»

### Конкретность (具)

- Меньше писать «он очень растерян / очень страдает / очень подавлен», больше писать действия, реплики, предметы и телесные реакции.

### Эмоция (情)

- Лучше всего, чтобы эта сцена делала главным лишь одну эмоциональную ось: страх, гнев, стыд, обида, ожидание, нечистая совесть, облегчение и т. п.

### Простота (简)

- Информацию, которую можно удалить без ущерба цели этой сцены, удалить.
- Термины, процедуры и сеттинг по возможности сжимать до бытовых точек приземления, понятных с первого взгляда.

### Неожиданность (意)

- Хотя бы одно место, где у читателя возникает «оказывается, проблема вот в чём / оказывается, этот человек так ответит / оказывается, дело хуже, чем казалось».

## 4. Сигналы провала

- Персонаж долго суетился, а положение почти не отличается от начала.
- Есть только атмосфера, нет действия проверки.
- Есть только начало, нет заложенного, нет отдачи в середине.
- К концу сцены почти такое же, как в начале.
