# Перечень эскалаций при сбое действий в сцене

## 1. Цель использования

Сбой действия — не затяжка времени, а усилитель.

В по-настоящему эффективной сцене после сбоя положение должно стать хуже, напряжённее или смещённее.

## 2. Четыре эффективных типа сбоев

### 1. Посмотрел, но не разглядел

Подходит для эскалации в:

- информационный разрыв
- Ошибочное суждение

### 2. Попробовал, но обратной связи нет

Подходит для эскалации в:

- эскалацию риска
- проявление правил

### 3. Оставил улику, но улика нестабильна

Подходит для эскалации в:

- вход улики
- Новый риск

### 4. Отступил, но не до конца

Подходит для эскалации в:

- напряжение отношений
- эскалацию риска

## 3. Стандартный путь после сбоя

Рекомендуемые такты:

`сбой действия → суждение застопорилось / суждение ошибочно → появилось новое последствие → вынужденная смена действия`

## 4. Сопоставление сбоя и следующего действия

| Тип сбоя | Последствие, в которое лучше всего перейти | Следующее действие, которое лучше всего вынудить |
| --- | --- | --- |
| Не рассмотрел | Информационный пробел / ошибочное суждение | Сопоставить ещё раз / сменить ракурс / проверить |
| Нет обратной связи | Эскалация риска / проявление правил | Попробовать ещё раз / использовать иной метод |
| Улики сохранены нестабильно | Новый риск / вход улик | Сделать копию / спрятать / дополнить улики |
| Не вышел чисто | Напряжение отношений / эскалация риска | Объяснить / замаскировать / немедленно вернуться |

## 5. Красные линии

- Не допускать, чтобы сбой был просто затяжкой времени
- Не допускать нескольких сбоев подряд без изменения положения
- Не допускать, чтобы после сбоя положение тут же спасало авторское объяснение
- Не допускать, чтобы сбой был написан как «главный герой поглупел»

## 6. Критерий приёмки

Годный сбой действия должен удовлетворять:

- У сбоя есть причина
- Сбой приводит к худшему положению
- Персонаж вынужден сменить действие или суждение
- Сцена от этого становится плотнее, а не водянистее
