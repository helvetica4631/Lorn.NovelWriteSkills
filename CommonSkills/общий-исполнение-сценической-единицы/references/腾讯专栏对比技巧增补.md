## Правило P0: контраст — сильнейший приём проектирования сюжета

### Ключевой вывод

Так называемая «нехватка силы пера» по сути — **проблема проектирования сюжета**, а не проблема мастерства в слоге.

Контраст — важнейший приём проектирования сюжета в веб-новелле: **практически любой эмоциональный эффект можно реализовать дизайном контраста**.

### Два типа контраста

| Тип | Пояснение | Типичный эффект |
| --- | --- | --- |
| Прямое оттенение (正衬) | Подчёркивает то же направление (A силён → B ещё сильнее) | Потрясение, послойное нарастание |
| Обратное оттенение (反衬) | Выделяет противоположное различие (слабость ↔ решимость, бедность ↔ отказ творить зло) | Горячая кровь, трогательность, соблюдение обещаний, доброта |

### Эмоциональная цель → быстрый справочник дизайна контраста

| Эмоциональная цель | Метод дизайна контраста |
| --- | --- |
| Горячая кровь | Враг могуч (подводка прямым оттенением) + главный герой слаб, но воля твёрда (обратное оттенение); многослойное наложение контрастов даёт эффект сильнее |
| Юмор | Возвышенное / серьёзное место + крайне контрастное низкое поведение (например, в 《修真聊天群》 алхимия в рисоварке) |
| Показное превосходство | Все смотрят свысока (подводка) + главный герой проявляет абсолютную силу (перепад рождает 爽) |
| Выплеск гнева | Другая сторона наглая / деспотична (подводка) + главный герой полностью давит и бьёт по лицу (перепад высвобождает гнев) |
| Соблюдение обещаний | Отказ от огромной выгоды (цена) + всё равно приходит на встречу (подчёркивается ценность соблюдения обещания) |
| Чувства | Тяжёлая среда (подводка) + взаимная поддержка (обратное оттенение — теплота) |
| Доброта | Крайняя бедность (обратное оттенение) + отказ от неправедных денег (подчёркивается «золотое содержание» доброты) |

### Пример многослойного контраста (железнодорожный сюжет 《修真四万年》)

Железнодорожный сюжет использовал многослойные вложенные контрасты, достигнув сильнейшего ощущения горячей крови:
1. Сильный враг (третий / четвёртый уровень) vs главный герой (низший первый уровень) → базовое ощущение давления
2. Страх и отчаяние товарищей / народа vs бесстрашное движение главного героя вперёд → обратное оттенение воли героя
3. Контраст с поуровневой эскалацией: победа → появляется более сильный враг → снова победа → ещё сильнее → цикл подъёма → финальный взрыв

→ При наложении многослойных контрастов эмоциональный эффект растёт в геометрической прогрессии.

## Перечень использования контраста при дизайне сцены

Перед исполнением сценической единицы проверить, в достаточной ли мере использован контраст:

- [ ] Какова эмоциональная цель этой сцены (горячая кровь / юмор / трогательность / показное превосходство / соблюдение обещаний)?
- [ ] Спроектированы ли достаточные слои подводки (прямое / обратное оттенение), накапливающие силу для эмоционального пика?
- [ ] Если это сцена горячей крови / показного превосходства, добавлены ли многослойные вложенные контрасты, а не однократный перепад?
- [ ] Юмористическая сцена: использован ли ситуативный контраст (возвышенное место + низкое поведение)?
- [ ] Избежано ли «прямо писать эмоцию» (например, «его кровь кипела») в пользу контраста, чтобы читатель сам почувствовал?
