# Чек-лист исполнения микропространства

- [ ] Повседневное назначение этого пространства ясно
- [ ] Нормальное действие в пространстве ясно
- [ ] В первых 7 строках открытия обозначены пространство, действие персонажа и первое «не так» / приближающийся риск
- [ ] В первых 300 знаках как минимум один раз появился стимул, действительно двигающий действие
- [ ] Аномальная деталь достаточно мелкая, но с одного взгляда «не так»
- [ ] Аномалия не достигает вершины одним шагом, прошла как минимум одну воспринимаемую эскалацию
- [ ] В сцене есть хотя бы один реальный «стежок»
- [ ] В сцене есть хотя бы один функциональный предмет / узел процедуры / реальный шум, поддерживающий ощущение реальности
- [ ] Персонаж не только «чувствует страх», но и совершил действие
- [ ] Действие персонажа немедленно приводит к последствию
- [ ] Основное действие и основное последствие стыкуются плавно, без резкого излома
- [ ] Если действие сорвалось, сам сбой тоже вызвал эскалацию, а не пропал впустую
- [ ] Аномалия может вернуться к цепочке правил, цепочке улик или последующему конфликту
- [ ] В сцене есть хотя бы одно из последствий: ошибочное суждение / информационный разрыв / вход улики / эскалация риска / напряжение отношений / проявление правил
- [ ] Давление и награда не бьются друг с другом, сцена не сводится к давлению без выигрыша
- [ ] Есть хотя бы одна «снимаемая на камеру» фраза-«стежок», не всё продвигается лишь абстрактными суждениями
- [ ] Конец сцены — не вздох, а уход с новым вопросом / новой ценой / незавершённым действием
- [ ] После удаления слов «жуткий / мрачный / угнетающий / тревожный» сцена по-прежнему состоится
- [ ] Персонаж не всё время «ощущает / чувствует / осознаёт», а действительно смотрит, слушает, трогает, сверяет
- [ ] Это место по-прежнему похоже на повседневное пространство, а не на заброшенный дом с привидениями
- [ ] Если сцена включает профессию, процедуру, цеховые правила или цепочку инструментов, профессиональное суждение реализовано действиями, а не осталось пояснением
- [ ] В этой сцене не только давление: персонаж вернул хотя бы немного информации, контроля или цены ошибки
