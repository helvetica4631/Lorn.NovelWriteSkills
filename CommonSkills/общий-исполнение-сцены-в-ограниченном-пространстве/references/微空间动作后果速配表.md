# Таблица быстрого подбора последствий действий в микропространстве (специальное дополнение)

> Общий каркас «действие — последствие» поднят в `общий-исполнение-сценической-единицы/references/场景动作后果速配表.md`.

Этот файл лишь дополняет **более типичные в контексте микропространства** способы приземления.

## Приоритетные способы приземления в микропространстве

| Действие | Основное последствие, более типичное в микропространстве | Типичное приземление в микропространстве |
| --- | --- | --- |
| Подойти ближе | Эскалация риска | Вход в слепую зону / мёртвый угол / смещённый этаж |
| Протянуть руку и коснуться | Проявление правил | Обратная связь не соответствует здравому смыслу |
| Обернуться и проверить | Ошибочное суждение | Сбивается определение направления |
| Приблизиться, чтобы понюхать / прислушаться | Вход улики | Источник звука / запаха становится конкретнее, его можно привязать к носителю |
| Застыть на месте | Информационный разрыв | Временно спасает жизнь, но упускается ключевая точка контакта |
| Выйти / отступить | Напряжение отношений | Спутник / целевой объект неверно понимает |
| Нажать ещё раз / попробовать ещё раз | Эскалация риска | Обратная связь системы ещё хуже, аномалия подтверждается вторично |
| Прокрутить заново / сверить | Вход улики | В кадре / записи появляется расхождение в формулировках |
| Скриншот / фото | Новый риск | Оставляя улику, оставляешь и собственный след |
| Открыть дверь / толкнуть дверь | Проявление правил | Пространство, которое должно быть заперто, открыто, либо открыто неправильно |
| Позвать человека / отправить сообщение | Напряжение отношений | Ответ собеседника не совпадает с обстановкой на месте |

## Дополнительные напоминания по микропространству

- В микропространстве последствия лучше делать ближе к лицу, быстрее и с большими пространственными ограничениями.
- Если одно и то же действие не меняет отношение персонажа и пространства, оно ещё недостаточно похоже на действие в микропространстве.
