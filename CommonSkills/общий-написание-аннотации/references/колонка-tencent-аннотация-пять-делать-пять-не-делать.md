# Колонка Tencent: дополнение «пять „надо“ и пять „не надо“» для аннотации

Область применения: межплатформенный универсальный дизайн аннотации

Источник: «Начальные приёмы веб-романа — внешняя сторона романа» (《网络小说入门技巧——小说的表面文章》), 147 тыс. просмотров, колонка раздела для новичков

## Пояснение о согласовании названия (обязательно)

- «Название книги», упоминаемое в этом файле, везде понимается как целевое название для публикации текущего объекта поставки.
- Роман без частей: по умолчанию понимается как целевое название романа для публикации.
- Роман по частям: по умолчанию понимается как целевое название соответствующей части.

## P0. Ключевое резюме

### Сущностное позиционирование аннотации (самый важный пункт)

> **Истинная суть аннотации — реклама, а не пересказ содержания и не план.**
> Её задача: используя представление произведения, привлечь читателя, чтобы он открыл книгу.

Это позиционирование — коренной критерий для оценки любых проблем аннотации.

---

### Пять «не надо» для аннотации (табу)

1. **Не слишком художественно и непонятно**: аннотация-«туманная поэзия» / полная философии, но непонятная → читатель думает, что и основной текст не понять, и сразу уходит
2. **Не изображать «чистюлю»**: заявления в аннотации вроде «это точно не гаремник» / «никаких YY» → вызывают неприязнь у массового читателя; «чистота» проявляется в содержании, а не в надрывных заявлениях
3. **Не банально и не пресно**: заурядная аннотация в духе традиционного уся-сериала → читатель думает, что произведение столь же скучно, хуже, чем без аннотации
4. **Не вешать баранью голову, продавая собачье мясо**: аннотацию можно умеренно обработать и приукрасить, но если она совсем не связана с основным текстом, это вызовет отторжение читателей и отток
5. **Не слишком подробно**: выложить весь сюжет → читатель теряет любопытство и интерес читать дальше

**Примечание**: отсутствие аннотации = шестое табу. Аннотация — бесценная возможность привлечь внимание.

---

### Пять «надо» для аннотации (стандарт хорошей аннотации)

1. **Просто**: аннотация должна быть «простой» — при условии, что мысль ясна, чем меньше слов, тем лучше; длинная аннотация = нет аннотации
2. **Красиво**: аккуратная вёрстка, без «сплошной стены»; избегать кракозябр и спецсимволов (исключение — символы единого стиля)
3. **Показывать тип произведения**: попаданец / перерождение / сверхспособности / коммерческая война / чиновничество / железная кровь / юмор — чтобы читатель заранее знал, что собирается читать
4. **Показывать главную торговую точку (золотой палец)**: у произведения должна быть одна главная торговая точка, в аннотации она должна дать читателю понять, «в чём здесь YY»
5. **Первая фраза показывает суть**:

   Первая фраза аннотации — это «аннотация внутри аннотации», особая форма представления между названием и аннотацией.

   Причина: системы крупных платформ автоматически считывают первую фразу аннотации как идентификатор произведения при показе; если первая фраза — номер QQ-группы или «новая книга загружается», то привлекательность нулевая.

---

## Связь с существующими правилами

- Ядро этого дополнения — рамка позиционирования «суть аннотации — реклама», она может служить арбитром для оценки любых проблем аннотации
- Пять «надо» и пять «не надо» дают полный контрольный список проверки аннотации (дополнение к круглому столу из партии 3)
- Правило «первая фраза показывает суть» прямо соответствует техническому принципу, по которому системы межплатформенной дистрибуции захватывают первую фразу аннотации
