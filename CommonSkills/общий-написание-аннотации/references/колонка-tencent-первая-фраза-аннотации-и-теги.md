## Пояснение о согласовании названия (обязательно)

- «Название книги», упоминаемое в этом файле, везде означает название, фактически используемое для публикации текущего объекта поставки.
- Роман без частей: по умолчанию понимается как целевое название романа для публикации.
- Роман по частям: по умолчанию понимается как целевое название соответствующей части.

## Жёсткие правила аннотации (P0)

1. У аннотации одна функция: усилить привлекательность, а не рассказать полное краткое содержание.
2. Первая фраза должна выполнять как минимум две из трёх функций: «дополнение названия + распознавание жанра + хук входа».
3. Аннотация должна ясно показывать: положение персонажа, основной конфликт, постоянную интригу.
4. Аннотация должна быть направлена в ту же сторону, что и название, нельзя привлекать «не тех» читателей.

## Рекомендации по структуре (P1)

1. Можно добавить слова-ярлыки (жанр, отношения, стиль), чтобы помочь быстро отфильтровать читателей.
2. Сначала показать торговую точку, затем контролировать информацию; не начинать с энциклопедии фона.
3. Можно использовать «маленький театр» (для романов об отношениях между персонажами) или краткое изложение сюжета (для сильно сюжетных романов), но интонация должна быть согласована с основным текстом.
4. Интригу создавать можно, но нельзя выложить ключевые последующие повороты.

## Запреты аннотации

1. Вписывать план в аннотацию.
2. Пустая первая фраза, не дающая читателю видимого хука.
3. Только нагромождение терминов сеттинга, без дилеммы персонажа.

## Список самопроверки

- [ ] Ясно ли написано, «кто в какой безвыходной ситуации»
- [ ] Написан ли вопрос, который читатель хочет досмотреть до конца?
- [ ] Согласуется ли с обещанием названия?
