# Напоминание о различиях аннотаций на разных платформах

- Платформы с публикацией по главам: сильнее подчёркивать хук входа в переплёт, постоянное обещание и причины читать дальше.
- Соцсети / рекламные платформы: сильнее подчёркивать торговую точку одной фразой и «передаваемую» фразу.
- В длинной аннотации можно добавить ещё один слой обещания основной линии; в короткой в первую очередь сохраняйте «человек + переплёт + риск».

## Нижняя граница читаемости

- Одна версия сохраняет единый голос повествования
- Каждое предложение по умолчанию несёт только 1 основной информационный пункт
- Каждый абзац — 2–4 предложения, не менее 1 короткого «ножевого» гвоздя-предложения
- В одной версии оставлять не более 1 системы обратного отсчёта
- Метафор — по возможности не более 1, и она должна сводиться к фактическому кадру

## Напоминания по платформенной адаптации

- Платформенная адаптация в первую очередь подгоняет «форму основного хука», а не просто заменяет слова
- Не пишите для всех платформ одну и ту же заготовку с урезанным числом слов
- Целевой читатель после прочтения должен суметь пересказать: «кто столкнулся с какой аномалией / ценой»
