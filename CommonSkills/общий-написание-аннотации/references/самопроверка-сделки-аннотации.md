# Самопроверка сути сделки в аннотации

> Этот файл — вспомогательные данные для `общий-написание-аннотации`, вынесенные из SKILL.md.

## Самопроверка сути сделки в аннотации (новое — на основе лучшего из начала Zhihu)

Закончив аннотацию, спросите себя: **«Если читатель здесь пролистнёт, что он потеряет?»**

- Если ответ «ничего» или «абзац с предысторией» — аннотация не завершила сделку.
- Если ответ «он упустит вопрос, на который хочется узнать ответ» — аннотация годна.
- Если ответ «он упустит сцену / персонажа / отношения, от которых невозможно оторваться» — аннотация отличная.

> **Каждая фраза должна иметь ценность. Нельзя позволять читателю бесплатно прочитать ни одной „неважной“ фразы.**
