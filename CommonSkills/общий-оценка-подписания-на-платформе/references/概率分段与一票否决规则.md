# Правила вероятностных диапазонов и единоличного вето

## Сначала определить единоличное вето

Если выполняется любая из следующих проблем, то, как правило, следует прямо написать «сейчас подавать не рекомендуется» или дать вывод об очень низкой вероятности:

- Жанр не поддаётся классификации
- Продающий пункт нельзя объяснить одним предложением, критерии названия / аннотации / первого экрана долго конфликтуют между собой
- В начале нет эффективного конфликта / нет опоры главного героя / нет первой отдачи
- В первых 1000 знаках главный герой всё ещё не стал центром чтения, либо аномалия / механика всё ещё не проявлена явно
- В первых 3000 знаках нет первой эффективной отдачи, и не видно заложенного места под дизайн отдачи
- Есть явный риск нарушений
- Персонажи, механика и жанр долго не связаны: главный герой не привязан к ключевому продающему пункту, и история была бы состоятельна при замене сеттинга
- Есть только атмосфера, нет устойчивой платёжной ценности, которую получает читатель (компенсация / идентификация / контроль — все заметно слабы)
- Долгосрочная структура явно недостаточна
- Явное несоответствие платформе

## Правила записи вероятностных полей по этапам (обязательно)

### Ограничение сверху при предварительной оценке шлюза общего плана

- Основное вероятностное поле по умолчанию записывается как: **вероятность допуска к продвижению к плану тома**
- Если пользователь также хочет знать перспективы итогового подписания, можно дополнительно дописать: **оценка верхнего предела итогового подписания (низкая уверенность)**
- Нельзя выдавать суждение стадии общего плана за «основной текст уже прошёл планку» или «подавать можно прямо сейчас»

### Ограничение сверху при предварительной оценке шлюза тома

- Основное вероятностное поле по умолчанию записывается как: **вероятность допуска к продвижению к основному тексту глав**
- Можно дополнительно дописать: **оценка верхнего предела итогового подписания (низкая уверенность)**
- Нельзя выдавать суждение стадии томов за «текущая вероятность подписания уже стабильно состоялась»

### Ограничение сверху при оценке допуска основного текста

- Основное вероятностное поле по умолчанию записывается как: **вероятность допуска к продолжению написания / входу в официальную оценку подачи**
- Если пороги подачи в основном выполнены, одновременно можно дописать: **диапазон текущей вероятности подписания**
- Если материалов вышестоящих слоёв явно недостаточно, диапазон вероятности подписания обязательно сопровождается понижением уверенности, а суждение о долгосрочной линии ограничивается сверху

### Полная оценка подписания

- Основное вероятностное поле по умолчанию записывается как: **текущая вероятность подписания / прохождения модерации**

## Градации допуска текущего уровня

- **70%–100%**: допускается продвижение к следующему уровню; всё равно нужно чётко записать крупнейший риск переделки
- **55%–69%**: условный допуск; по умолчанию сначала дополнить 1 раунд минимального исправления, затем продвигаться к следующему уровню
- **35%–54%**: пока не допускать; остановиться на текущем уровне и продолжать исправлять
- **0%–34%**: не допускать; если проблема коренится в вышестоящем слое, необходимо чётко вернуться на уровень общего плана или томов

> Пояснение: здесь оценивается, «стоит ли текущему уровню продолжать продвижение вниз», а не итоговый абсолютный процент подписания.

## 【起点口径 (критерий Qidian)】Ограничения сверху / пересмотр суждения из-за жёстких порогов Qidian по умолчанию

> Нижеследующее действует только тогда, когда целевая платформа — Qidian или по умолчанию используется откат на Qidian. Для других платформ оценка проводится по процессу проверки соответствующей платформы.

Следующие проблемы не обязательно все означают немедленное вето и не должны напрямую подниматься до высокоранговых дефектов содержания произведения; они в основном меняют итоговую рекомендацию, уверенность, момент подачи или допустимость входа в полную оценку:

- При цели самостоятельной заявки на подписание порог основного текста для текущего жанра / настройки платформы ещё не достигнут.
- При цели внутренней подачи через редактора единая линия подачи Qidian для внутренней подачи (не менее `30000` знаков непрерывного основного текста + `общий план для внутренней подачи (минимум 5000 знаков)` + `план 1-го тома для внутренней подачи` + `аннотация для внутренней подачи`) ещё не достигнута.
- Даже если единая линия подачи достигнута, но соответствие шаблону, эффективность «парадной двери», долгосрочная подпитка, готовность к исполнению или разрыв с конкурентами по-прежнему явно недостаточны, по умолчанию также нельзя выдавать «рекомендуется внутренняя подача сейчас».
- Запас явно меньше `15` глав (по обычному критерию Qidian в `2000` знаков / главу — около `30` тысяч знаков) либо нет заслуживающего доверия плана восполнения.
- Невозможно доказать способность стабильно обновляться по 4000 знаков в день, либо уже есть явные признаки перерывов / нестабильности более 3 дней.
- Есть только концепт, аннотация или разрозненные фрагменты, но хотят сразу прийти к выводу «рекомендуется подавать немедленно».

### Дополнительные напоминания об ограничении сверху

- Нет названия / аннотации или оба явно не работают: по умолчанию нельзя переходить к высокоуверенным суждениям высокого уровня.
- Нет первых 3 глав / первых 6000 знаков: измерения, связанные с началом и удержанием на уровне глав, по умолчанию ограничиваются сверху.
- Нет общего плана / томов / битов первых 10 глав: долгосрочные измерения по умолчанию ограничиваются сверху.
- Нет материалов по персонажам / механике, и основной текст тоже не в состоянии их подтвердить: измерения персонажей или механики по умолчанию ограничиваются сверху.

## Правила ограничения сверху по этапам

### Предварительная оценка шлюза общего плана

- Есть только общий план, нет томов: `вероятность допуска к продвижению к плану тома` по умолчанию имеет верхнюю границу **70%**, уверенность не выше «средней».
- Общий план есть, но одна из трёх линий — главный герой / механика / долгосрочная линия — явно «воздушна»: по умолчанию верхняя граница **54%**.
- Есть только абстрактная предпосылка (premise), нет «торгуемого» продающего пункта в одно предложение: по умолчанию верхняя граница **35%**.
- Если нужно дописать «оценку верхнего предела итогового подписания», то при **отсутствии томов и материалов по исполнению начала** по умолчанию она не должна превышать **12%–15%**.

### Предварительная оценка шлюза тома

- Общий план + тома в наличии, но нет битов первых 10 глав / стартовой таблицы тома / микросценария начала: `вероятность допуска к продвижению к основному тексту глав` по умолчанию имеет верхнюю границу **60%**.
- Общий план + тома + биты глав в наличии, но не видно дизайна первой эффективной отдачи в первых трёх главах: по умолчанию верхняя граница **54%**.
- Если отсутствует любое из трёх — обещание первого тома, этапная цель, более дорогой разрыв в конце тома — по умолчанию нельзя переходить в диапазон «допускается прямое продвижение».
- Если нужно дописать «оценку верхнего предела итогового подписания», то при **отсутствии пробных глав основного текста** по умолчанию она не должна превышать **18%**.

### Оценка допуска основного текста

- Есть только основной текст, нет общего плана / томов: «парадную дверь» оценивать можно, но долгосрочная линия и итоговая вероятность подписания обязательно ограничиваются сверху.
- Основной текст есть, но в первых 3000 знаках всё ещё не видно первой эффективной отдачи, либо видны доказательства необходимости переделки общего плана / томов: `вероятность допуска к продолжению написания / входу в официальную оценку подачи` по умолчанию не должна переходить в высокий диапазон.
- Основной текст есть, но минимальный порог пути подачи не достигнут: нельзя выдавать «рекомендуется подавать сейчас».

### Критерий ограничения сверху для рекомендаций

- Путь подачи не удовлетворяет минимальному порогу: по умолчанию нельзя переходить к «рекомендуется подавать сейчас».
- Нет запаса уровня 15 глав или заслуживающего доверия плана обновлений: указывать отдельно как риск исполнения, рекомендацию по подаче нельзя писать как «рекомендуется подавать сейчас».
- Стабильность обновлений не удаётся подтвердить: уверенность не должна быть высокой, но нельзя только по этому одному основанию напрямую давить основное суждение о содержании произведения до низкого диапазона.
- Продающий пункт можно записать лишь как абстрактную тематическую фразу и невозможно свести к «главный герой + механика / аномалия + текущая проблема»: комплексная вероятность по умолчанию не должна переходить в высокий диапазон.
- Есть только взрывная точка начала, нет этапного замыкания в первых тридцати тысячах знаков или обещания первого тома: долгосрочные измерения не могут быть высокими, комплексная вероятность тоже должна быть заметно понижена.

## Принципы пересмотра суждения при предварительных оценках этапа

Если данный раунд относится к предварительной оценке шлюза общего плана или предварительной оценке шлюза тома:

- `Жанр не поддаётся классификации`, `явный риск нарушений`, `недостаточность долгосрочной структуры` по-прежнему могут служить прямым основанием для вето
- Проблемы категории «начало» переосмысляются как «предупреждение на уровне дизайна», а не как однозначный провал основного текста
- Отсутствие инженерии удержания на уровне глав и первой отдачи также следует в первую очередь переосмысливать как «не реализовано на уровне исполнения», а не прямо как провал основного текста
- Но если ключевые узлы «парадной двери» всё ещё не закреплены в битах глав / стартовой таблице / микросценарии, комплексная оценка тоже не должна переходить в высокий диапазон
- Если план показывает, что «стоит писать дальше», это лишь означает наличие потенциала, а не то, что жёсткие пороги подачи уже выполнены
- Если в данном раунде уже можно чётко определить, что «писать дальше означает лишь увеличивать затраты на переделку», необходимо прямо написать «следующий уровень не допускается», а не уходить от суждения формулировкой «сначала попробуем писать»

## Принципы пересмотра уровня доработки

- Проблема коренится в жанровой классификации, основном продающем пункте, мотивации главного героя, самой долгосрочной подпитке -> по умолчанию вернуть на доработку на **уровень общего плана**
- Проблема в основном коренится в обещании первого тома, этапных целях, битах первых 10 глав, дизайне первой эффективной отдачи -> по умолчанию вернуть на доработку на **уровень томов**
- Проблема в основном коренится в ритме, подаче информации, письме сцен, продвижении абзацев, хуке в конце главы -> по умолчанию определить как **доработку уровня основного текста**

Пока доказательства не показали чётко, что «ошибочен сам вышестоящий дизайн», нельзя прямо повышать проблемы исполнения основного текста до «общий план нужно переписать».

## Типичная логика ограничения сверху

- Жанр ясен, но реалистичная опора или профессиональная опора «воздушна» → можно ограничить сверху
- Начало в основном проходит планку, но в пределах 3000 знаков нет первого малого замыкания → можно ограничить сверху
- В названии / аннотации есть идея, но на первом экране не удаётся чётко «продать» продающий пункт → можно ограничить сверху
- Главный герой и ключевая механика по отдельности неплохи, но между ними нет реальной связи → можно ограничить сверху
- Общий план есть, но этапные цели, хуки томов, путь эскалации неясны → можно ограничить сверху
- План обновлений, запас, пакет заявки явно недостаточны → можно указать отдельно как риск исполнения и пересмотреть рекомендацию по подаче / момент подачи

## Правила вывода вероятности

- Вероятность необходимо давать диапазоном, а не «мистическим» точным значением
- Необходимо давать уверенность
- Необходимо давать вывод о действии: подавать немедленно / подавать после усиления / сначала публикация напрямую для наблюдения / отложить / рекомендуется сменить платформу
- На неполных стадиях оценки необходимо дополнительно указывать: допускается ли текущий уровень к следующему
- По умолчанию выводить консервативно по критерию реально низкой доли подписания; высокая оценка означает лишь относительное преимущество, а не высокий абсолютный процент прохождения
- Если в имитации быстрой проверки на любом из слоёв `30 секунд / 3 минуты / 30 тысяч знаков` есть явный разрыв, вероятность должна в первую очередь подчиняться слою с разрывом, а не «вытягиваться вверх» другими сильными сторонами

## Сопряжённое ограничение сверху по измерению конкурентов (обязательно)

- Измерение сопоставления с конкурентами по умолчанию входит в основную оценку содержания в размере `25` баллов; если это измерение не достигает планки, вероятность обязательно должна быть ограничена сверху.
- Если измерение конкурентов `<15/25`: диапазон основной вероятности текущего уровня по умолчанию имеет верхнюю границу **54%**.
- Если измерение конкурентов `<12/25`: диапазон основной вероятности текущего уровня по умолчанию имеет верхнюю границу **34%**, и следует прямо давать вывод с уклоном «пока не допускать следующий уровень» или «сейчас подавать не рекомендуется».
- Если не завершено сведение пула кандидатов TopN того же трека (по критерию Qidian — по стандарту Топ-10), четырёхслойная глубокая разборка `3–5` основных подавляющих образцов, либо отсутствует единая количественная карта с «разницей + доказательствами + патчем на 72 часа + чего не стоит копировать»: измерение конкурентов по умолчанию не может быть выше `10/25`, и применяется ограничение сверху **54%**.
- Только когда измерение конкурентов `>=20/25` и нет пунктов единоличного вето, основная вероятность текущего уровня может переходить в высокий диапазон.

## Как использовать градацию доли успеха из исследовательских материалов

- Если исследовательские материалы дают условную градацию «высокая / средняя / низкая доля успеха», по умолчанию рассматривать её как **якорь зрелости**, а не напрямую копировать как итоговый вывод вероятности.
- В этом проекте итоговая вероятность по-прежнему подчиняется консервативному диапазону по критерию «реально низкой доли подписания».
- То есть:
  - «условия высокой доли успеха» в исследовании = могут поддерживать выход в относительно высокий диапазон в этом проекте;
  - но не означают, что можно прямо писать сверхвысокую абсолютную долю подписания.
