# Контроль качества и процесс проверки

## Критерии успеха

- В зоне заголовка отмечен тип персонажа, для ключевых / важных персонажей по умолчанию также указаны число шагов психологической дуги, версия биографии и последнее обновление
- Биография персонажа сверх существующей детальной структуры чётко сводится к четырём базовым графам — фон, характер, внешность, прочее, и ни одна из четырёх категорий не отсутствует
- Блок передачи рычагов письма полон, как минимум может быть приземлён в ключевых полях шести категорий: «присказки / речевые привычки, привычные действия и микрореакции, триггеры, границы / переключатели, предпочтения оставления следов, шаблоны контрдействий»
- Нулевые противоречия с планом
- Мотивы персонажа ясны и сопровождаются ценой
- Временная линия роста объясняет нынешние выборы, ошибочные оценки и источники ран персонажа
- Внешняя цель / внутренняя потребность / ценности / ложные убеждения не конфликтуют друг с другом
- Сеть отношений способна порождать события
- Между публичным образом и самопознанием есть пригодная для написания разница, а не два повторяющихся изложения
- Рычаги письма можно прямо прикреплять к основному тексту
- В основной информации ключевых / важных персонажей уже дополнены траектория профессии / личности, семейные связи / исходные отношения, библиотека деталей для разбора и структурная функциональная позиция
- Есть как минимум один отсылаемый предмет / обращение / якорь места
- У психологической дуги есть триггерные события, последствия и точки отсылки, у ключевых / важных персонажей лучше явно пометить общее число шагов
- Индекс может служить входом для перекрёстной проверки
- Действия, временная линия и описание отношений персонажа в плане можно по пунктам сверить с биографией
- У главных персонажей есть три рычага узнавания: черты внешности, знаковые действия, языковые особенности
- Траектория роста важных персонажей включает «исходный недостаток → триггерное событие → изменение познания → проявление роста»
- Если в этот раз «дополнение / расширение», а не полная переписка, в файле сохранена `本轮修订（YYYY-MM-DD）` (правка этого раунда) как вход для заплаток
- Если ключевой персонаж несёт долгосрочное питание или давление правил, по умолчанию также должны быть ключевые модули из «кризис идентичности / система внутренних конфликтов / цепочка эмоциональных изменений / эволюция ценностей»

## Трёхслойное отображение критериев успеха (новое)

- `结构完整层 (слой структурной полноты)`: полны ли четыре базовые графы, мотив и цена, временная линия роста, сеть отношений, индекс, самопроверка.
- `动态一致层 (слой динамической согласованности)`: согласованы ли текущее состояние, записи поведения по главам, общий обзор отношений, информация о версии и последнее обновление.
- `正文调用层 (слой вызова в основном тексте)`: действительно ли можно прикрепить к основному тексту рычаги письма, запоминающиеся точки, символические предметы, языковые особенности, реакции на давление.

## Процесс проверки

1. Завершить основную часть биографии
2. Проверить зону заголовка и информацию о версии: тип персонажа, число шагов психологической дуги, версия биографии, последнее обновление записаны ли полностью по уровню персонажа
3. Сначала проверить, размещены ли все четыре базовые графы — фон, характер, внешность, прочее, и не склеены ли они насильно из разрозненных предложений
4. Проверить, приземлён ли `写作抓手交付 (передача рычагов письма)` группой: как минимум можно напрямую извлечь присказки, микрореакции, триггеры, границы / переключатели, предпочтения оставления следов, шаблоны контрдействий
5. Сверить согласованность с общим планом / планом тома
6. Сверить отношения с биографиями других персонажей
7. Проверить, имеют ли траектория профессии / личности, семейные связи / исходные отношения, якоря давления жанра или эпохи, библиотека деталей для разбора ценность для вызова на стороне автора
8. Проверить, пригодны ли для прямого использования рычаги письма, реакции на давление, механизм утешения и предметы-якоря
9. Проверить, могут ли внешняя цель / внутренняя потребность / ценности / ложные убеждения взаимно объяснять друг друга, а не быть четырьмя параллельными лозунгами
10. Проверить, есть ли у секрета хотя бы один проверяемый или приземляемый в сюжет пункт
11. Проверить, есть ли в психологической дуге откаты, неудачи и ошибочные оценки, а также этапные потери / приобретения / точки пробития ложных убеждений; у ключевых / важных персонажей выборочно проверить отсылаемые носители ключевых шагов
12. Дополнить индекс, обеспечить возможность обратной проверки
13. Сверить с общим планом / планом тома / списком глав, согласуются ли события персонажа с возрастом, опытом, сетью отношений, общественным положением и источниками ресурсов в биографии
14. Выборочно проверить, есть ли у персонажа пригодные для прямого приземления в основной текст запоминающиеся точки, разница публичного образа, подтверждение этапов дуги роста и необходимый вход для заплаток (например, `本轮修订`)

## Проверка взаимосвязи с планом

### Проверка соответствия биографии персонажа

- Каждое событие персонажа в плане должно быть согласовано с соответствующей биографией
- Поведение персонажа в плане должно соответствовать чертам характера, описанным в биографии
- Возраст персонажа, время опыта и изменения отношений должны быть едины с временной линией в биографии
- Описания отношений между персонажами должны согласовываться с записями в биографиях каждого
- Общественное положение, ресурсные полномочия, публичный образ в плане и настройки в биографии должны взаимно подтверждаться

### Требования к усилению формирования персонажей

- **Черты внешности**: 1–2 ярких внешних признака
- **Знаковые действия**: 1–2 устойчивые поведенческие привычки
- **Присказка / языковые особенности**: чётко описать манеру выражения, часто употребляемые слова или ритм речи
- **Реакция на давление / механизм утешения**: как минимум по 1 действию или поведенческой реакции, которую можно снять в кадре
- **Символический предмет / якорь памяти**: как минимум 1 предмет, место или обращение, которые можно многократно вызывать в дальнейшем тексте

### Проектирование динамической дуги роста

- **Исходный недостаток**: недостаток характера, когнитивное ограничение или нехватка способностей персонажа в начале
- **Внешняя цель vs внутренняя потребность**: к чему персонаж стремится на поверхности и чего ему на самом деле не хватает
- **Триггерное событие**: ключевое событие или поворотная точка, побуждающая персонажа начать меняться
- **Изменение познания**: конкретный процесс изменения ценностей, мировоззрения, ложных убеждений или моделей поведения персонажа
- **Проявление роста**: конкретное проявление и применение нового познания в последующем сюжете
- **Отсылаемый носитель**: лучше всего привязать к ключевым этапам предмет, обращение, место, номер, метку времени или узел отношений

### Обнаружение и разрешение противоречий

- Места, конфликтующие с биографией персонажа, помечать `⚠️ 人物矛盾：[具体描述]` (⚠️ противоречие персонажа: [конкретное описание])
- Давать конкретный план «правка плана / обновление биографии / двусторонняя калибровка»
- После правки плана соответствующие биографии персонажей тоже следует обновить синхронно, чтобы не образовалось двойной формулировки

## Частые причины переделки

- Много меток, мало рычагов письма
- У рычага есть заголовок без содержания, или лишь одно-два шаблонных действия, нельзя прикрепить к основному тексту
- Много внешней идентификации, нет разницы между публичным образом и самопознанием
- Психологический рост выглядит как резюме, а не как траектория событий
- В психологической дуге отмечено число шагов, но нет ключевых триггеров, последствий и отсылаемых носителей
- В сети отношений нет структуры власти
- Не прописаны границы способностей, персонаж выглядит всемогущим инструментом
- Есть лишь настройки персонажа, нет траектории профессии / личности, библиотеки деталей для разбора и структурной функциональной позиции, из-за чего трудно сопровождать дальше

## Минимальный артефакт проверки (новое)

```markdown
【结构完整层 (слой структурной полноты)】
【动态一致层 (слой динамической согласованности)】
【正文调用层 (слой вызова в основном тексте)】
【Текущая оценка】Green / Yellow / Red
```

## Оценка проверки Green / Yellow / Red (новое)

- `Green`: все три слоя пройдены, можно использовать как долгосрочный арбитражный источник напрямую для письма и рецензирования.
- `Yellow`: основная часть годна, но на слое динамической согласованности или вызова в основном тексте остаются пробелы, нужно продолжать добавлять «гвозди».
- `Red`: структуру можно прочесть, но нельзя использовать, либо она годна только для знакомства с персонажем и не может по-настоящему поддерживать основной текст и долгосрочное сопровождение.
