# Правила проектирования грани истории

## 1. Минимальное определение грани истории

Грань истории — это не ярлык жанра и не краткое изложение концепции.

Она должна одновременно быть:

- двигателем конфликта уровня всей книги
- гранью питания уровня тома
- пулом рычагов глав
- таблицей арбитра рецензирования

## 1.6. Быстрое суждение по слоям-источникам (новое)

- `Слой запуска конфликта`: состоятельны ли загадка в одной фразе, шесть элементов, жёсткие рычаги, ответственность узлов и отголосок цены.
- `Слой питания уровня тома`: состоятельны ли продвижение на уровне тома, 4A / 4B, якоря питания, постоянная реализация основной торговой точки.
- `Слой разбираемости на тома`: способна ли грань истории действительно опуститься до основного вопроса тома, гвоздя в конце тома, точек приземления групп глав и рычагов основного текста.

Порядок по умолчанию: сначала выстроить `Слой запуска конфликта`, затем оценить `Слой питания уровня тома`, в конце посмотреть `Слой разбираемости на тома`; нельзя говорить о питании, когда двигатель конфликта ещё не установлен.

## 1.5. Граница с `小说总大纲.md` (обязательно)

- Грань истории по умолчанию в основном несёт побочные истории; это не страница комментариев, не страница резюме и не разбитая копия `小说总大纲.md`.
- Хорошая грань истории должна уметь рассказываться как самостоятельная полная история и в то же время объяснять, как она двигает главную линию и как главная линия подталкивает её в ответ.
- Совместное использование персонажей, событий, зацепок, узлов этапов с главной линией обычно считается нормальным взаимодействием; избыточным это становится только при механическом повторении одной и той же информации без добавления различий в функциях.
- Если грань истории может лишь пересказывать узлы главной линии, но не может назвать собственный двигатель конфликта, победу/поражение этапа, цену и гвоздь передачи, значит, эта побочная линия ещё не спроектирована.

## 2. Фиксированный скелет

1. Загадка в одной фразе
2. Шесть элементов
3. Ограждения и приёмка
4. Продвижение на уровне тома
5. 4A Тома появления и общий обзор передачи
6. 4B Полная история внутри тома
7. Якоря питания
8. Чек-лист письма

## 3. Необходимые элементы и их роли

### 1. Жёсткие рычаги

Без жёстких рычагов грань истории не может войти в основной текст.

Типичные жёсткие рычаги включают: журнал, хеш, номер, реестр, использование печати, приложение, рабочий наряд, метаданные, штрихкод, номер версии, след входа, опечатанный пакет, фиксацию присутствия.

### 2. Ответственность узлов

Не ругать абстрактную систему, а преследовать «кто подписал, кто поставил печать, кто экспортировал, кто пропустил, кто вернул».

### 3. Отголосок цены

В каждом томе писать цену, чтобы главный герой не продвигался с нулевыми издержками, а антагонист не творил зло с нулевыми издержками.

### 4. Жёсткие точки передачи

Грань истории не завершается в этом томе — она передаёт тот гвоздь, за которым пойдёт следующий том.

### 5. Структура, пригодная для письма

Главный том расписывать подробно, второстепенный коротко, чтобы не получилось «общий план сильный, а основной текст теряет скорость».

## 4. Уроки опыта

- Концепцию немедленно прижимать к носителю.
- Провал превращать в улику.
- Не давать противнику неограниченно «читерить».
- В основном томе писать полную кампанию, во второстепенном — оставлять лишь задачи.
- Материал типа «остаточной боли» должен быть мало, но жёстко.

## 5. Критерии приёмки

Грань истории проходит приёмку, если как минимум удовлетворяет:

- Видно, какую победу/поражение контролирует эта грань
- Есть чёткие слои рычагов A/B/C/D
- Есть пролом (брешь) ≤ 3 главы
- Есть главный том / этап появления и второстепенный том / этап появления
- Есть как минимум 3 линии жёстких рычагов, идущих через тома
- Можно чётко объяснить её интерфейс передачи с `小说总大纲.md`, а не просто сделать краткое изложение главной линии
- Есть как минимум 1 главный том, который можно прямо разбить на главы
- Есть чек-лист, которым можно пользоваться снова и снова

## 5.5. Минимальный артефакт грани истории (новое)

```markdown
【Слой запуска конфликта】загадка в одной фразе / шесть элементов / жёсткие рычаги / отголосок цены
【Слой питания уровня тома】продвижение на уровне тома / 4A4B / якоря питания / реализация торговой точки
【Слой разбираемости на тома】основной вопрос тома / основной рычаг / гвоздь в конце тома / точки приземления групп глав
【Текущая оценка】Green / Yellow / Red
```

## 6. Оценка грани истории Green / Yellow / Red (новое)

- `Green`: все три слоя состоятельны, грань истории может и самостоятельно рассказываться как история, и постоянно питать тома и основной текст.
- `Yellow`: концепция и питание есть, но разбираемость или несущая способность уровня тома ещё слабы, нужно продолжать уплотнять.
- `Red`: есть только проблематика / настройки / эмоции, нет настоящего запуска конфликта, механизма питания или интерфейса тома.
