# Шаблон мастер-схемы события-дела

## Метод заполнения мастер-схемы в три слоя (новое)

- `Слой запуска аномалии`: название дела, сигнал аномалии, реальная сцена, реальное трение, первое ошибочное суждение.
- `Слой игры улик`: носитель улики, порядок выхода улик, цепочка ложных ходов, точка опровержения, изменения пула подозреваемых.
- `Слой питания и последствий`: питание главной линии, цена для персонажа, последствия дела, разбиение на главы и приёмка перед строительством.

## Минимальный артефакт мастер-схемы (новое)

```markdown
【Слой запуска аномалии】
【Слой игры улик】
【Слой питания и последствий】
【Текущая оценка】Green / Yellow / Red
```

## Оценка мастер-схемы Green / Yellow / Red (новое)

- `Green`: все три слоя заполняются, можно напрямую переходить к контрольной карточке и разбиению тома.
- `Yellow`: мастер-схема годится для старта, но хотя бы один слой всё ещё расплывчат, нужно продолжить детализацию.
- `Red`: в мастер-схеме есть только название дела и атмосфера, нет исполнимой структуры аномалии, улик или последствий.
