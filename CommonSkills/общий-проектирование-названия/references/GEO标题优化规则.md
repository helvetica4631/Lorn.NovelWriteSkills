# Правила GEO-оптимизации названия книги

## Механизм семантического соответствия ИИ-поиска

Когда большие модели ИИ отвечают на вопросы вида «порекомендуй роман», они обрабатывают названия иначе, чем традиционные поисковые системы:

- **Семантическое соответствие > соответствие по ключевым словам**: ИИ не ищет, «есть ли в названии ключевое слово», а понимает, «какие сигналы жанра / эмоции / типа передаёт название»
- **Контекстная связь**: ИИ определяет отнесение по общему смыслу «название + аннотация + теги»
- **Многоисточниковая перекрёстная проверка**: ИИ сравнивает информацию об одном и том же названии на разных платформах, при несовпадении понижает вес

## Стратегия ключевых слов жанра / типа в названии

| Стратегия | Пояснение | Пример | Эффект GEO |
|------|------|------|---------|
| Основное название содержит слово жанра | Название прямо содержит ключевое слово типа | 《法医密档》 («Тайное досье судмедэксперта»), 《星穹裂变》 («Раскол звёздного свода») | Наивысший — семантическое соответствие ИИ попадает напрямую |
| Подзаголовок содержит слово жанра | Основное название литературное, подзаголовок дополняет информацию о типе | 《深渊之眼：一个刑侦专家的笔记》 («Око бездны: записки одного эксперта-криминалиста») | Высокий — ИИ читает подзаголовок |
| Название серии содержит слово жанра | Название серии отвечает за жанровое позиционирование | 《XX 悬疑系列》 («Серия интриги XX») | Средний — ИИ нужно связывать при чтении |
| Чисто образное название | Не содержит никаких сигналов типа | 《黄昏》 («Сумерки»), 《白夜》 («Белая ночь») | Низкий — ИИ трудно самостоятельно отнести к жанру |

**Основной принцип**: не заставляйте ИИ «угадывать», какого жанра ваша книга. В названии должно быть хотя бы одно чёткое ключевое слово, позволяющее ИИ завершить семантическое отнесение за 0,1 секунды.

## Нормы согласованности названия между платформами

ИИ определяет достоверность, перекрёстно проверяя информацию о названии на нескольких платформах:

| Пункт проверки | Требование | Почему |
|--------|------|--------|
| Основное название | На Qidian / Fanqie / Douban / Zhihu и других платформах полностью совпадает | Несовпадение, обнаруженное ИИ = ненадёжный сигнал |
| Подзаголовок | Сохраняется единым или явно помечается «又名» («также известна как») | Снижает затраты ИИ на объединение |
| Имя автора | Единый псевдоним, запрещено использовать разные имена на разных платформах | Имя автора — ключевой якорь, по которому ИИ связывает произведения |
| Система тегов | Теги категорий на всех платформах охватывают одни и те же ключевые слова жанра | Согласованность тегов усиливает суждение ИИ о жанре |

## Измерения оценки видимости в ИИ-поиске

В «Процессе проектирования названия и измерениях оценки», помимо уже имеющихся трёх измерений, добавляется четвёртое измерение:

### Измерение 4: видимость в ИИ-поиске (новое)

| Показатель | Отлично (+2) | Удовлетворительно (+1) | Не проходит (0) |
|------|-----------|-----------|-----------|
| Явность ключевых слов жанра | В названии явно содержатся слова жанра / типа | Название намекает, но не содержит слово жанра прямо | Название совершенно не раскрывает жанр |
| Способность семантического соответствия | ИИ может завершить отнесение к жанру за 0,1 секунды | Нужно судить вместе с аннотацией | Информация названия расплывчата, ИИ трудно отнести |
| Согласованность между платформами | Информация на всех платформах полностью совпадает | Основное название совпадает, подзаголовки слегка различаются | Информация на разных платформах не совпадает |
| Использование подзаголовка / названия серии | Есть подзаголовок со словом типа | Есть подзаголовок, но без слова типа | Нет подзаголовка, чисто образное название |
| Соответствие когнитивного разрыва | Интрига названия имеет высокую распознаваемость при семантическом поиске ИИ | У названия есть определённая распознаваемость | Название — обычное сочетание слов, при поиске ИИ легко путает |

### Новая формула привлечения трафика эпохи GEO

Традиционная формула привлечения трафика: `привлечение = когнитивный разрыв × эмоциональное возбуждение × ясность жанра`

Новая формула эпохи GEO: `привлечение в ИИ-поиске = степень семантического соответствия × согласованность данных × структурная полнота`

- **Степень семантического соответствия**: семантическое расстояние между ключевыми словами названия и вопросом пользователя к ИИ
- **Согласованность данных**: согласованность названия на разных платформах (перекрёстная проверка ИИ)
- **Структурная полнота**: название + подзаголовок + теги образуют полный смысловой пакет

> Две формулы не противоречат друг другу, но обслуживают разные входы трафика. Традиционная формула ориентирована на «человека, пробегающего взглядом по рейтингу», формула GEO — на «ИИ, ищущего в семантической библиотеке». Успешной книге нужно удовлетворять обеим формулам одновременно.

## Контрольный перечень GEO-самопроверки названия

- [ ] Содержит ли название (с подзаголовком) ключевое слово жанра / типа?
- [ ] Можно ли по названию за 0,1 секунды определить, какой это жанр?
- [ ] Полностью ли совпадают название, имя автора и теги на всех платформах?
- [ ] Полон ли смысловой пакет «название + аннотация» (может ли ИИ, читая одно только название, догадаться о примерном типе)?
- [ ] Содержит ли название временную метку «год + жанр» (например «2026 интрига»)?
- [ ] Можно ли сопоставить когнитивный разрыв в названии при семантическом поиске ИИ (а не игра слов, понятная только людям)?
