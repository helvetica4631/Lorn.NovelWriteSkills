# Шаблон файла кандидатов названий

> Применимо к: `общий-проектирование-названия`
>
> Назначение: превратить результат проектирования названия в файл варианта, который можно пересматривать, записывать обратно и закрывать.
>
> Пояснение: этот шаблон подчёркивает «пул кандидатов + оценка + причины выбора + вывод о рекомендации + запись дедупликации + самопроверка». Нельзя сдавать только один перечень названий.

---

## 0. Метаинформация файла

- Название произведения: `{{название произведения}}`
- Уровень проектирования: `{{вся книга / часть / том}}`
- Целевые платформы: `{{платформа 1, платформа 2, платформа 3……}}`
- Целевое число кандидатов: `{{по 10 на платформу / другое}}`
- Настроение именования: `{{коммерческий клик / репутационная фактура / издательская рецензия / зарубежное распространение / другое}}`
- Текущая версия: `v{{YYYY-MM-DD}}-r{{N}}`
- Перезаписывается ли старая версия: `{{да / нет}}`
- Требуется ли глобальная дедупликация: `{{да / нет}}`
- Исходные материалы: `{{исследование письма / план / грань истории / старый вариант / другое}}`
- Время создания: `{{YYYY-MM-DD HH:MM}}`
