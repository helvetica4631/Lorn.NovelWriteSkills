## Правило P0: рамка шести шагов открытия книги

### Основные принципы

У веб-романа есть паттерны (套路) — по сути, он удовлетворяет точки эмоциональных потребностей читателя. Перед открытием книги следует сначала прояснить шаги, а не писать «что получится на каждом шаге».

### Шесть шагов

```text
Шаг 1: выбрать жанровое направление
Шаг 2: определить способ написания (изучить точки 爽 популярных книг того же направления)
Шаг 3: определить личность героя
Шаг 4: спроектировать сюжет (сначала написать обзор, затем подробный план)
Шаг 5: запросить мнение редактора (написать 10–20 тыс. знаков и отправить редактору)
Шаг 6: опубликовать
```

### Шаг 1: жанровое направление

- Мейнстримные направления (проверенные жанры) предпочтительнее самостоятельно придуманного фона
- Измерение оценки жанра: «каковы элементы этого произведения» — первый вопрос открытия книги
- Справочник популярных жанровых направлений (2020 год): профессиональное направление (шоу-бизнес / врачи / предприниматели / спорт), фанфик-направление (японские манга-аниме / исторический фон / поток множества миров (万界流) / «Путешествие на Запад» и «Возведение в ранг богов» и «Первозданный хаос»), элементы горячих тем (отметки о ежедневных визитах / закулисье / додумывание и т. п.)

### Шаг 2: определить способ написания

- Найти несколько популярных книг того же направления, сравнить, перечислить сюжетные направления и основные точки 爽
- Не брать для справки только одну книгу, а сравнивать несколько и искать закономерности

### Шаг 3: личность героя

**Основные принципы, которые необходимо выполнить**:

1. У героя должно быть конкретное жизненное состояние (его текущее положение и бытовые детали)
2. Герой не может быть в положении «одинокого отшельника» — чем изолированнее, тем труднее развивать сюжет
3. Стартовая личность по возможности равна читателю или даже ниже его исходной точки (источник вживания)

**Справочник стартовых личностей по категориям**:

- Проза о врачах: старт — врач-интерн
- Проза об актёрах: старт — статист / малоизвестный актёр
- Историческая проза (Мин): только что взошедший на трон император Чжэнде (с особенностями и сталкивающийся с трудным положением)
- Игровая проза: запасной игрок / униженный мастер

### Шаг 4: проектирование сюжета (рекомендуется сначала обзор, затем подробный план)

**Как писать обзор (обзор первых 60 тыс. знаков)**:
Сначала абзацами изложить основное направление сюжета, первую точку ритма-кульминации и момент появления золотого пальца.

**Затем подробный план** (резюме уровня глав для нескольких первых сюжетов).

### Стандартный ритм начала:

```text
Герой в низкой позиции (формируется читательское ожидание) → одновременно появляется золотой палец → ожидание читателя на максимуме → герой действует → окружающие потрясены → герой получает аплодисменты
```

## Правило P0: ритм-письмо «нанизывание танхулу»

### Основные принципы

**Один сюжет — одна точка ритма-кульминации**, продвижение подряд, как нанизывание танхулу.

Такой способ письма:
- Ритм простой, не развалится
- Подходит для большинства ритмичной прозы
- Поддерживает у читателя постоянную движущую силу чтения

### Модель ритма танхулу

```text
Первая сюжетная кульминация → развёртывание нового сюжета → вторая кульминация → развёртывание нового сюжета → третья кульминация → ...
```

Каждая точка ритма-кульминации может быть:
- Красование героя и удар по лицу
- Раскрытие важной информации
- Снятие кризиса
- Повышение уровня отношений
- Демонстрация навыка

## Дополнительные пункты проверки при проектировании общего плана

- [ ] Подтверждены ли перед открытием книги конкретное жанровое направление и точки 爽 популярных книг того же направления?
- [ ] Есть ли у героя конкретные бытовые детали и вживание (не изолирован от мира)?
- [ ] Спланированы ли основные этапы книги по принципу «нанизывания танхулу» с точками ритма-кульминации?
- [ ] Есть ли в каждом этапе чёткая ощутимая кульминация / точка 爽?
- [ ] Выполнено ли до написания основного текста двухслойное планирование «обзор + подробный план»?
