# Универсальный скелет трёх томов

> **Источник**: избранная публикация Zhihu «Как написать качественный длинный роман?» (摘星, 2026-06-17). Этот шаблон — универсальная трёхтомная структура для любых жанров, его можно использовать как отправной скелет для проектирования общего плана, а затем накладывать конкретные шаблоны по особенностям жанра.
>
> **Позиционирование**: этот шаблон — «минимальный универсальный скелет»: он не заменяет жанровые шаблоны из `CommonSkills/исследования-письма/шаблоны-qidian/шаблоны-общего-плана/`, а гарантирует, что общий план имеет хотя бы базовую рамку ритма до выбора главного шаблона или когда главный шаблон не определён. После выбора жанрового главного шаблона ориентируйтесь на главный шаблон, а этот скелет служит структурным ориентиром.

## Пропорции распределения трёх томов

| Положение тома | Доля объёма | Основная задача | Ключевые контрольные точки |
| --- | --- | --- | --- |
| **Том 1 (зачин)** | **25%** | Показать положение героя → запустить поворотное событие → установить основную цель → первая неудача / рост | ✅ Первые 3 главы нарастают «старт с конфликта → неудача в реакции → более глубокий конфликт» |
| | | | ✅ В конце главы чёткий хук продолжения чтения |
| | | | ✅ В пределах первых 25% читатель ясно понимает «чего хочет герой, что ему мешает» |
| **Том 2 (середина)** | **50%** | Параллельное продвижение нескольких линий → всестороннее повышение конфликта → крупный переворот / разбитое сердце на нижней точке → полное преображение героя | ✅ Нет отрезков «чистого продвижения» длиннее 4 глав подряд |
| | | | ✅ Событие переворота / нижней точки достаточно сильно, чтобы разрушить ожидания читателя |
| | | | ✅ У преображения героя есть конкретная заплаченная цена |
| **Том 3 (финал)** | **25%** | Развязка завязок основной линии → итоговое противостояние → судьбы всех персонажей → замыкание темы | ✅ Короткие завязки развязаны до этого тома или включены в цепочку завершения |
| | | | ✅ Большой финал не опирается на информацию, впервые появляющуюся в последней главе |
| | | | ✅ У второстепенных персонажей (включая злодея) есть самостоятельная судьба |

> **Пояснение о пропорциональном масштабировании**: если книга запланирована на 4 или 5 томов, число томов распределяется в пропорции «группа зачина ≈ 25%, группа середины ≈ 50%, группа финала ≈ 25%», а не жёстко навязываются три физических тома. Например, книга из 6 томов → тома 1–2 — группа зачина, тома 3–5 — группа середины, том 6 — группа финала.

## Универсальные шаблоны ритма для каждого тома

### Том 1 (зачин 25%) · базовый ритм

```text
Главы 1–3 («золотые три главы»): старт с конфликта / аномалии → герой реагирует и сталкивается со стеной → обнаруживается более глубокая проблема
Главы 4–8 (утверждение личности): герой постепенно узнаёт правила мира / расклад сил → ставится этапная цель → получает первого небольшого союзника или небольшой ресурс
Главы 9–12 (первая крупная неудача): первая попытка достичь основной цели заканчивается провалом → цена заплачена → остаётся осознание «оказывается, всё не так просто»
Глава 13 и до конца тома (новое направление): после неудачи получает новую информацию / способность / союзника → заново фиксирует направление → хук конца тома указывает на более крупный конфликт середины
```

### Том 2 (середина 50%) · базовый ритм

```text
Начало тома (около 10%): подхватывает хвост первого тома → разворачивает новую карту / новую силу / новое противоречие → ритм ускоряется
Середина тома (около 30%): параллельные линии → конфликт непрерывно повышается → каждые 5–8 глав — средняя точка стимуляции (переворот / прорыв в отношениях / раскрытие ключевой информации)
Вторая половина середины тома (около 10%): крупный переворот / разбитое сердце на нижней точке → ожидания читателя разрушены → вера героя подвергается наибольшему испытанию
Конец тома (около 10%): герой делает ключевой выбор / полностью преображается → пробуждается новая способность или новое осознание → хук конца тома указывает на финал
```

### Том 3 (финал 25%) · базовый ритм

```text
Начало тома (около 5%): окончательная ситуация установлена → все силы на местах → раскрыт последний кусок пазла
Середина тома (около 15%): финальное противостояние / итоговый конфликт → плотная развязка завязок → цена реализуется полностью
Конец тома (около 5%): пыль осела → судьбы всех персонажей → тематическая фраза / послевкусие
```

## Предварительное подтверждение трёх ключевых элементов

Перед проектированием томов необходимо сначала зафиксировать следующие три вопроса — они определяют, будет ли трёхтомный скелет направлен на одну и ту же книгу:

```text
Тема (ядро): что в итоге хочет выразить эта книга? Не жанр, а ядро
Общий конфликт (движущая сила): внешние обиды / кризис + внутренний изъян / одержимость героя
Конечная цель (финал): что герой должен совершить от начала до конца — всё время не отклоняясь
```

Если ответ на любой из трёх вопросов расплывчат, трёхтомный скелет станет формальностью — ведь неясно, «куда должен повернуть поворот первого тома».

## Связь с существующими шаблонами общего плана

- **Приоритет — жанровому шаблону**: этот скелет — минимальный универсальный запасной вариант. Если главный шаблон уже выбран через `CommonSkills/исследования-письма/шаблоны-qidian/шаблоны-общего-плана/`, ориентируйтесь на главный шаблон.
- **Применимые сценарии этого скелета**:
  - Позиционирование проекта пока не настолько ясно, чтобы выбрать главный шаблон (основное обещание ещё не видно)
  - Нужно быстро выстроить исполнимую трёхтомную рамку, чтобы затем детализировать
  - В качестве эталона проверки чернового общего плана — проверить, не отклоняется ли существующий общий план от базовой пропорции 3 : 5 : 2
- **После выбора главного шаблона**: слить ключевые узлы уровня томов этого скелета с основными полями главного шаблона; ориентироваться на главный шаблон, а скелет — структурный ориентир.
