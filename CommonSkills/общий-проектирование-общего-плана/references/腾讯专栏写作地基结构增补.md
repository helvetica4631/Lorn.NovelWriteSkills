## Правило P0: основные аксиомы (базовые закономерности истории по мнению автора 子良)

1. **В истории самое важное — структура**
2. **Душа истории — персонажи**
3. Общие черты бестселлеров — с большой вероятностью необходимое условие успеха произведения (структуре нужно учиться у бестселлеров)
4. Правильная теория применима ко всем объектам; теорию, применимую к подавляющему большинству объектов, можно приближённо считать правильной
5. Приёмы и содержание независимы друг от друга, но связаны

## Правило P0: основная модель структуры истории

### Цель — действие — награда — демонстрация важности награды

Базовая единица структуры историй мужского канала Qidian:

```
Цель → действие → награда → демонстрация важности награды (мгновенная положительная обратная связь)
```

Ключевое: **демонстрация важности награды** (показ ценности награды) — шаг, который чаще всего опускают, но который нельзя опускать ни в коем случае.

Это аналог «мгновенной положительной обратной связи» в игровом дизайне — игрок (читатель) должен ощущать, что действие принесло реальную выгоду.

### Структурные формы по категориям

| Категория | Конкретная структурная форма |
| --- | --- |
| Проза о прокачке | Затруднение → тренировки → повышение уровня → подавление, разрешающее затруднение |
| Городская бытовая проза | Быт / затруднение → использование золотого пальца для улучшения → повышение способностей / социального статуса → разрешение затруднения |
| Саспенс | Интрига → исследование → улика → интрига разрешена |
| Проза об управлении силой | Затруднение → построение → усиление силы → разрешение затруднения |

## Правило P0: основные обязанности глав зачина

### Три шага зачина

1. **Определить образ персонажа** + появление золотого пальца + начало исследования (глава 1)
2. **Подробно изложить процесс подготовки**, детализировать настройки, получить первый предмет / улику (глава 2)
3. **Подчеркнуть превосходство золотого пальца в реальной жизни** (глава 3)

### Источник ощущения реальности

**Детали создают ощущение реальности**:

- Подробный процесс подготовки → ощущение реальности
- Подробные настройки → ощущение реальности (Qidian предъявляет высокие требования к ощущению реальности)
- Внимание: «слишком много настроек» выглядит старомодно, нужно контролировать количество

### Роль мгновенной положительной обратной связи

Самая типичная структура мгновенной положительной обратной связи в прозе о прокачке:

```
Побои до тренировки (формируется ощущение проблемы) → тренировки → бой с монстром после тренировки (ответ показан)
```

Эта структура направлена на **чувство приобретения** у читателя и является основным механизмом поддержания движущей силы чтения глав.
