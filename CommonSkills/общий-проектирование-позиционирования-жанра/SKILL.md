Жанровое позиционирование — это не написать одну фразу «чем является эта книга», а прежде всего намертво зафиксировать, почему эта книга состоятельна, почему она может продолжаться и почему читатель будет читать дальше.

## Одной фразой определить всю книгу: три ключевых элемента (предварительное подтверждение)

> **Источник**: избранная статья Zhihu «Как написать качественный длинный роман?» (Чжайсин, 2026-06-17).

Перед входом в любой процесс позиционирования необходимо сначала зафиксировать следующие три вопроса — они «центр круга» всей книги, и все последующие решения (выбор жанра, калибровка платформы, позиционирование паттернов (套路), проектирование компенсации) обязаны отсылаться к этим трём элементам. Если любой из них расплывчат, дальнейшее проектирование будет дрейфовать:

| Элемент | Определение | Критерий приёмки |
| --- | --- | --- |
| **Тема (ядро)** | Ядро, которое книга в итоге хочет выразить — не жанр («саспенс»), а ядро («как оклеветанный человек возвращает своё имя») | Можно ли одной фразой сказать, «о чём в итоге книга»? Если можно сказать лишь «саспенс + перерождение», стандарт не достигнут |
| **Общий конфликт (движущая сила)** | Внешние обиды / кризис + внутренний недостаток / одержимость героя. Оба должны существовать одновременно, ни одного нельзя убрать | Можно ли одновременно написать «каков внешний кризис» и «какая внутренняя преграда, через которую герой не может переступить»? Если нет любого, цепочка конфликта неполна |
| **Итоговая цель (финал)** | То, что герой должен совершить от начала до конца — мерило, не позволяющее сбиться с пути | После удаления итоговой цели может ли цепочка действий героя остаться состоятельной? Если может, значит, итоговая цель ещё не зафиксирована |

### Взаимная блокировка трёх элементов

- Три элемента должны **взаимно поддерживаться**: тема определяет направление итоговой цели, общий конфликт даёт непрерывное сопротивление продвижению основной цели, итоговая цель не позволяет общему конфликту скатиться в простую «прокачку с боями».
- Если заменяется любой из элементов, два других тоже должны быть скорректированы — нельзя менять только «итоговую цель», сохраняя прежние тему и конфликт.
- Метод приёмки: если после записи трёх элементов заменить один из них произвольно (например, «оклеветанный полицейский» на «преданный агент»), и история всё ещё кажется состоятельной, значит, три элемента недостаточно конкретны, нужно продолжать сужать, пока не станет «состоятельно только для этого героя и этого положения».

### GEO-ценность трёх элементов (новое)

Структурированная форма трёх элементов (тема / общий конфликт / итоговая цель) сама по себе — высокоценная структурированная информация для ИИ-поиска:

- **Формулировку «одной фразой определить всю книгу» ИИ может напрямую процитировать** как «это роман о ___»
- Чем жёстче зафиксированы три элемента, тем точнее ИИ классифицирует жанр этого произведения
- Публикация структурированного заявления о позиционировании (с тремя элементами) в открытых каналах (аннотация / рецензии / личный блог) — одно из самых дешёвых GEO-действий

> Подробные принципы см. в `../../исследования-письма/GEO小说项目核心参考.md`.

## Источники вдохновения — сначала впитать, затем создавать (обязательно)

> **Основной принцип**: самые прибыльные идеи историй никогда не придумываются из воздуха — они «вырастают» из множества конкурентов, эталонов, материалов и исследований. Первое действие жанрового позиционирования — не «придумать идею», а **сначала открыть все источники вдохновения, которые можно впитать**.

Перед выполнением жанрового позиционирования или фабрики концепций обязательно сначала просканировать и загрузить все доступные источники вдохновения ниже. **Только после загрузки минимум трёх видов источников можно переходить к этапу генерации концепций**, иначе признаётся «закрытое творчество», и выдаваемое позиционирование, скорее всего, будет неконкурентоспособным.

### Источник 1: сетевой поиск — захват последних трендов (новое, ставится наверху)

> **Основной принцип**: тренды веб-романов меняются помесячно. Выводы локальных файлов (анализ конкурентов, исследования письма и т. п.) отражают **состояние рынка на момент сбора данных** и не могут охватить новые ветры, новые хиты и новые паттерны (套路) последних недель. **Первым шагом всей работы по позиционированию должно быть открытие сетевого поиска для захвата свежих сигналов.**

Перед выполнением жанрового позиционирования необходимо сначала сетевым поиском захватить актуальные тренды, не проектируя на устаревших данных и вышедших из моды паттернах:

| Направление поиска | Цель поиска | Как использовать на этапе позиционирования |
| --- | --- | --- |
| **Новейшие ветры трека** | Искать «{целевой жанр} + веб-роман + {текущий год} + тренд / хит / новая книга» | Проверить, находится ли выбор V1 (жанр) всё ещё в фазе подъёма, а не в уже вышедшем из моды треке; если результаты поиска расходятся с локальными выводами исследования, ориентироваться на последние выводы поиска |
| **Разбор новых хитов** | Искать «{целевой жанр} + недавно завершённые / выходящие + хит / тёмная лошадка / высокие закладки» | Дополнить новейшие образцы конкурентов, не охваченные локальным анализом конкурентов; особое внимание новым книгам, взлетевшим за последние 1–3 месяца |
| **Проверка своевременности паттернов** | Искать «{название паттерна} + веб-роман + насыщен / устарел / читатели устали» | Проверить, не отброшено ли рынком планируемое сочетание паттернов или не устали ли от него читатели; избегать использования в 2026 году популярных паттернов 2023 года |
| **Новейшие тенденции платформы** | Искать «{целевая платформа} + новая политика / конкурс / программа поддержки + {текущий год}» | Подтвердить, есть ли у платформы недавно поддержка жанров, конкурсы или корректировки правил, откалибровать V2 (формулировки платформы) |
| **Миграция эмоций читателей** | Искать «{целевой жанр} + читатели / рецензии + хотят видеть / эстетика / усталость» | Уловить тонкие миграции предпочтений читателей — например, «читатели устали от паттерна XX, смещаются к направлению YY» |
| **Межотраслевые сигналы** | Искать «короткие драмы / кино + {целевой жанр} + тренд + {текущий год}» | Априорный сигнал направления IP-производных: оценить, продолжает ли расти межмедийная популярность жанра |

> **Источник поиска**: можно использовать любые доступные в среде инструменты поиска (например, Bing, поиск Zhipu, поиск Alibaba Bailian и т. п.), выбирая подходящий по доступности и актуальности. Выводы поиска обязательно помечать источником и временем поиска (с точностью до месяца), чтобы нижестоящие этапы могли судить о своевременности информации. Нельзя принимать непроверенные сводки поиска за решающее доказательство.

## Измерения микроинноваций (новое — этап фабрики концепций / отбора PK)

> **Источник**: избранный пост форума авторов Qimao #34903 «Как писать микроинновации? Как выделиться среди многих типов романов?» (редактор 云杉, в закладках 14, просмотров 10888). Обобщённая здесь рамка микроинноваций оформлена в `references/рамка-микроновации-и-новизна-образов-и-сюжета.md`.

Измерение «инновационного сочетания» жанрового позиционирования нельзя оценивать лишь интуицией. Рамка микроинноваций вводится как инструмент оценки на этапе фабрики концепций:

### Основные ограничения микроинноваций

1. **Не идти по пути «создания направления»**: инновация с ограниченной аудиторией — не нужная микроинновация. Самое эффективное — инновировать внутри существующих паттернов (套路).
2. **Не стремиться, чтобы каждый сюжет отличался**: зрелые паттерны — ключ к стабильному качеству в поздней части. Микроинновации касаются лишь **зачина** и **основного образа персонажа**.
3. **Инновацию должно быть можно «объяснить одной фразой»**: если нельзя одной фразой сказать «в чём новизна», микроинновация не приземлена.

### Два направления микроинноваций в образе персонажа

| Направление | Тип | Ключевые пункты операции |
| --- | --- | --- |
| **Инновация в отношениях персонажей** | ① Чистая инновация в отношениях героя и героини; ② инновация в отношениях героя и героини с участием второстепенных; ③ инновация в отношениях важных второстепенных | На стандартный образ накладывается слой нестандартных отношений, отношения должны прямо влиять на продвижение сюжета |
| **Инновация в личности и профессии** | ① Необычная для жанра личность; ② особая личность / профессия | Выбрать профессию, редко встречающуюся в этом жанре, но имеющую повествовательную ценность; способности должны продвигать основную линию |

### Два направления микроинноваций в сюжете

| Направление | Суть | Применимые жанры |
| --- | --- | --- |
| **Инновация сюжета в духе быта** | Тонкое пробуждение эмоций в повседневных деталях | Городская проза, брачно-любовная, сладкая |
| **Инновация сюжета в духе гиперболы** | Мелодраматические («собачья кровь») драматические сцены, затрагивающие жизнь и смерть / крайние выборы | Историческая женская проза (古言), мучительные романы, сюаньхуань |

### Критерии приёмки (применимы и к генерации концепций, и к PK)

1. Можно ли одной фразой сказать «в чём новизна этой книги»?
2. Вызывает ли инновация интерес у большинства целевых читателей, а не ощущение «как странно»?
3. Можно ли инновацию повествовательно использовать — многократно применять в сюжете, а не просто метка?
4. Совместима ли инновация с основной «фишкой» продаж?
5. Можно ли показать читателю эту инновацию в первых 1–3 главах зачина?

Подробную рамку см. в `references/рамка-микроновации-и-новизна-образов-и-сюжета.md`.

### Источник 6: сетевой поиск (глубокое дополнительное подтверждение)

Когда захвата трендов (источник 1) и локальных источников всё ещё недостаточно для принятия решения, глубокое дополнительное подтверждение выполняется сетевым поиском:

- **Профессиональные детали**: искать «{профессиональный срез} + реальный рабочий процесс / внутренние термины», чтобы проверить реальную приземляемость V8
- **Перекрёстная проверка насыщенности паттернов**: искать «{название паттерна} + веб-роман + насыщен / устарел», чтобы проверить суждение R2 о насыщенности трека и перекрёстно сверить с выводами источника 1
- **Исследование малоизвестных направлений**: искать «{жанр} + малоизвестное / нишевое / никто не писал», чтобы обнаружить пространство для дифференциации

> Источник 1 отвечает за «захват новейших трендов», источник 6 — за «глубокое дополнительное подтверждение». Направления поиска у них разные, они не могут заменять друг друга.

> **Связь библиотек тегов и позиционирования паттернов (套路)**: теги «сюжета» (например, «перерождение», «система», «扮猪吃虎») платформенных библиотек тегов сильно пересекаются с тегами четырёхуровневой классификации позиционирования паттернов (套路), но назначение у них разное — библиотека тегов предоставляет информацию о том, **существует ли уже проверенный платформой элемент**, позиционирование паттернов предоставляет метод проектирования того, **как выбранные элементы сочетаются и работают**. Первое отвечает на вопрос «что есть для использования», второе — «как использовать».
>
> **GEO-перспектива (новое)**: платформенные теги — не только инструмент классификации: когда теги вашего произведения единообразны и полны на всех платформах, **ИИ-поиск использует эти теги как структурированные метаданные** для классификации жанра. Единая система тегов (название книги + тип + теги, покрывающие одни и те же ключевые слова на Qidian / Fanqie / Douban и т. п.) может заметно повысить видимость в ИИ-поиске. Подробнее см. `../../исследования-письма/GEO小说项目核心参考.md`.

### Приоритет загрузки источников

**Шаг первый: сетевой поиск захватывает новейшие тренды (источник 1)** — сначала подтвердите последние ветры текущего рынка веб-романов, не проектируйте на устаревших данных. Выводы поиска обязательно помечать источником и временем поиска.

**Шаг второй: параллельная загрузка локальных активов** — отчёты анализа конкурентов (источник 2), образцы произведений (источник 3), исследования письма (источник 4), библиотека материалов (источник 5), сетевое глубокое подтверждение (источник 6), библиотеки тегов платформ (источник 7). Локальная загрузка и загрузка библиотек тегов могут идти параллельно.

**Шаг третий: источник 7 (библиотеки тегов платформ) загружается только при запуске фабрики концепций или позиционирования паттернов (套路)**, на этапе чистой диагностики позиционирования можно пропускать.

**Правило конфликта свежести**: когда результаты сетевого поиска источника 1 расходятся с выводами локальных файлов (источники 2–7), ориентироваться на последние выводы поиска источника 1, но в отчёте о позиционировании обязательно явно пометить «старый вывод перекрыт новым трендом».

Только после загрузки минимум трёх видов источников переходить к генерации концепций.

## Формат вывода внешнего PK (этап фабрики концепций · обязательно)

Использовать `references/шаблон-вывода-внешней-оценки-pk.md` как скелет шаблона. Этот файл содержит полную структуру файла, правила заполнения полей и ограничения использования.

- Нужно «сцепить» «профессиональный срез / общественное давление / материнский механизм / городское пространство / систему правил» в единую «фишку» продаж.

## Основная задача этого Skill

Этот Skill применяет **архитектуру «двух шагов»**: сначала с помощью PK фабрики концепций зафиксировать одну лучшую концепцию истории, затем существующей рамкой слой за слоем углубить её на основе этой концепции.

> **Почему «два шага» сильнее, чем любой из шагов по отдельности?**
> - Если использовать только фабрику концепций: можно выбрать «самую правильную концепцию», но в ней не хватает глубинного проектирования — калибровки формулировок платформы, фиксации реальной цены, проверки исполнимости «золотых трёх глав» — к стадии общего плана она легко становится пустоватой.
> - Если использовать только существующую рамку: можно зафиксировать формулировки платформы / реальные якоря / цепочку цены, но «в какую сторону класть стену обложки» ещё не определено, а уже начинают клеить плитку — направление неверно, чем крепче фиксация, тем больше потерь.
> - **Два шага = сначала выбрать направление (фабрика концепций), затем класть стену (углубление рамки). Без любого шага неполно.**

### Шаг первый: PK фабрики концепций — зафиксировать лучшую концепцию

Выполнить модуль **фабрики концепций**: комбинаторикой элементов × многораундовым PK среди 30–80 кандидатов зафиксировать одну концепцию истории с наибольшим коммерческим потенциалом. Подробнее см. ниже в главе **«Фабрика концепций»**.

### Шаг второй: углубление рамки — зафиксировать детали

По решающей концепции, выданной фабрикой концепций, ответить и записать конкретно следующие вопросы:

1. Каковы **основная «фишка» продаж и первая точка новизны** этой книги.
2. **Выбор паттернов (套路)**: какое сочетание паттернов использует эта книга (основная настройка + отношения персонажей + продвижение сюжета + эмоциональная награда)? Почему выбрано именно это сочетание — стандартный набор трека, проверенная конкурентами эффективная комбинация или собственная инновация? Почему не используются некоторые популярные паттерны?
3. Почему герой обязан войти в игру.
4. Почему загадка основной линии способна выдержать длинный роман.
5. За счёт чего в середине и поздней части непрерывная награда чередуется и повышается, продолжая реализовывать «фишку».
6. Образовали ли основные формулировки платформы, реальные якоря, якоря цены и инновационное сочетание замкнутый контур.

## Пять элементов коммерческого мышления — от самолюбования к точному удару (обязательно)

Любительский план думает: «что я хочу написать», «мне кажется, эта настройка крутая». Профессиональный план думает о рынке, читателях, конкуренции, коммерческих узлах и резерве данных. При жанровом позиционировании необходимо по очереди ответить на следующие пять элементов:

### 1. Позиционирование на рынке
- Насыщен ли этот жанр на целевой платформе? Голубой или красный океан?
- Если красный океан, какова точка дифференциации? Если голубой — почему раньше никто не добился успеха?
- Пример: «город + сверхспособности + групповой портрет, избегая чисто сюаньсяньного красного океана» — одной фразой чётко сказать о выборе трека.

### 2. Портрет читателя
- Кто основные читатели? Возрастной диапазон? Читательские предпочтения?
- Какие группы — первая целевая читательская группа и вторая целевая читательская группа?
- Пример: «в основном мужчины 18–25 лет, любят быстрый ритм, сильное противостояние» — портрет обязан быть конкретным настолько, чтобы направлять творческие решения.

### 3. Конкурентная дифференциация
- Что сделали правильно хиты того же периода? В каких измерениях мы можем сделать принципиально иначе?
- Дифференциация не может быть лишь «я пишу лучше» — она должна быть «я предлагаю читательский опыт, которого нет у конкурентов».
- Пример: «не писать личный героизм, а писать „командную работу людей со сверхспособностями“» — дифференциация должна быть ощутима читателю уже в аннотации и первых 3 главах.

### 4. Коммерческие узлы
- На каком объёме знаков можно разместить первую точку оплаты / первый сильный хук?
- Когда уместно открыть интерфейс побочных линий или внешних историй персонажей для IP-производных?
- Какой персонаж легче всего «выйдет в мемы» или станет «мемом» и «смайликом»?
- Пример:
  - В главе 30 разместить первую небольшую кульминацию, стимулирующую первую оплату
  - В главе 80 спроектировать кризис раскола команды, создавая тему обсуждения
  - В главе 150 ввести настройку «государственного ведомства сверхспособностей», оставляя пространство для расширения IP

### 5. Резерв данных (знаменитые сцены и точки распространения)
- В какой точке сюжета разместить «знаменитую сцену», стимулирующую читателей делиться и распространять скриншоты?
- Как спроектировать «тематический сюжет», вызывающий обсуждение в комментариях и выбор сторон в «本章说»?
- Когда лучше всего выбрасывать интригу для повышения желания читать дальше?
- Настроены ли у ключевых персонажей фирменные реплики, легко распространяемые?
- Учтена ли для важных сражений / сцен сложность визуализации (резерв для адаптации в короткие драмы / аниме)?
- Пример:
  - Каждые 15 глав — «звёздный час команды», подходящий для нарезки коротких видео
  - Ключевым персонажам настроить фирменные реплики, легко распространяемые
  - Для важных боевых сцен учесть сложность визуализации

### Правила приёмки коммерческого мышления

- Рамка жанрового позиционирования обязана полностью ответить как минимум на четыре из пяти элементов; если можно ответить лишь «что я хочу написать» и нельзя ответить «где рынок, кто читатель, как дифференцироваться», признаётся отсутствие коммерческого мышления.
- Коммерческие узлы и резерв данных можно пометить как «не определено» (особенно на раннем этапе проекта), но нельзя оставлять совсем пустыми; при пометке «не определено» нужно пояснить, на каком этапе ожидается дополнение (общий план / план тома / том X основного текста).

## Позиционирование паттернов (套路) — определение формульного повествовательного шаблона произведения

> Жанровое позиционирование не может останавливаться на «какой жанр писать» — необходимо ещё ответить «по какой группе паттернов (套路) писать». «先婚后爱» (брак по расчёту с последующей любовью) — не жанр (это паттерн отношений персонажей в современной / исторической женской прозе), «扮猪吃虎» (притворяться свиньёй, чтобы съесть тигра) — не жанр (это паттерн продвижения сюжета в сюаньхуане / городской прозе). Жанр определяет трек, паттерн определяет **читательские ожидания**.
>
> **Ортогональность паттернов и нарративной архитектуры**: один и тот же паттерн можно рассказывать в разном ритме («追妻火葬场» можно в быстром ритме, можно медленно разогревающимся), один и тот же ритм подходит для разных паттернов. Позиционирование паттернов определяет «какую историю рассказываем», проектирование ритма — «как рассказываем» — два независимых решения с перекрёстным потреблением.

### Контракт жанровой грамматики — сначала овладеть, потом нарушать (новое — усвоено из «семислойной модели» с Zhihu)

> **Источник**: Zhihu · 虎兔阅读, «Китаизация голливудской „семислойной модели“: почему ваш веб-роман быстро взлетает и ещё быстрее остывает?» (2026-07-18, слой 6: двадцатилетняя эволюция жанров веб-романов).

За двадцать лет веб-романы сформировали собственную жанровую грамматику — это не паттерны (套路), а „система расшифровки“, к которой читатели уже приучены. Нарушите её — читателю неуютно; овладеете — сможете и нарушить.

**Основной принцип: жанровая грамматика — „контракт“, а не „оковы“.** Как братья Коэн, овладев грамматикой вестерна, смогли снять антивестерн вроде «Старикам тут не место», так и автору веб-романа сначала нужно стать экспертом жанра, чтобы потом стать отступником жанра.

#### Основная грамматика и читательские ожидания пяти больших жанров

| Жанр | Основная грамматика | Читательские ожидания | Предпосылки для нарушения грамматики |
| --- | --- | --- | --- |
| **Сюаньхуань (玄幻)** | Система рангов (Ци боя → воин боя → зонг боя), техники и секретные книги, борьба сект, исследование тайных миров | Удовольствие от прокачки, вызовы через ранги, 扮猪吃虎 | «Ночь Цзяна» (《将夜》) добавляет в сюаньхуань историческую интригу — при условии, что базовая линия удовольствия от прокачки не теряется |
| **Сянься (仙侠)** | Система культивации — закладка основы → золотое ядро → зарождающаяся душа, правая и левая стороны пути, преодоление небесной кары и вознесение, магические сокровища и пилюли | Одержимость долголетием, закон причин и следствий, колесо перерождений, безжалостность великого Пути | «Сорок тысяч лет культивации» (《修真四万年》) добавляет в сянься элементы НФ — при условии, что скелет системы культивации цел |
| **История (历史)** | Перемещение → преимущество предвидения → земледелие → борьба за господство → реформы → объединение | Компенсаторное удовольствие от изменения истории, институциональные выкладки | На стандартную линию борьбы за господство накладывается структурная трудность управления династией (как в «Великой династии Мин 1566» (《大明王朝1566》)) |
| **Город (都市)** | Перерождение → восполнение сожалений → коммерческая империя → защита рода → восстановление чувств | Восполнение сожалений, классовое возвышение, эмоциональное искупление | На стандартную линию возвышения вносится китайская тревога социальной мобильности (как в «Великих реках» (《大江大河》)) |
| **Бесконечный поток (无限流)** | Подземелье → задание → выживание → обмен → усиление → пространство главного бога | Выживание на пределе, ресурсная борьба, доверие в команде | На стандартную структуру подземелья накладываются жанровые стили разных томов (например, том 1 — саспенс, том 2 — война) |

#### Правила операций с жанровой грамматикой

1. **Выбор жанра — подписание контракта**: выбрав основной жанр, нужно понять „систему расшифровки“ читателей этого жанра по умолчанию — чего они ждут, открывая книгу, и что заставит их почувствовать „что-то не так“.
2. **Сначала приземлить базовую линию, потом говорить об инновации**: прежде чем проектировать любое слияние жанров или антижанровую операцию, необходимо подтвердить, что в произведении выполнена базовая линия основной грамматики жанра — читатель должен сначала почувствовать „это годный роман жанра X“, и только тогда примет последующее нарушение.
3. **Нарушать можно только один слой**: за раз нарушается лишь одно измерение жанровой грамматики (например, добавление интриги в сюаньхуань), нельзя одновременно нарушать несколько измерений (одновременно опрокидывать систему рангов + мироустройство + отношения персонажей) — читатель потеряет якорь „к какому жанру относится эта книга“.
4. **У нарушения должна быть повествовательная функция**: нарушение жанровой грамматики — не ради „выглядеть уникально“, а потому что оно позволяет основному напряжению достичь максимума — как «У меня есть дом приключений» (《我有一座冒险屋》), добавляющий в город фольклорный хоррор, потому что хоррор-элементы прямо служат ядру интриги этой книги.

#### Связь жанровой грамматики и позиционирования паттернов (套路)

- Жанровая грамматика определяет базовое восприятие читателем „чем является эта книга“ — позиционирование паттернов должно проводиться в рамках, допускаемых жанровой грамматикой.
- Столбец „читательские ожидания“ жанровой грамматики напрямую служит стандартом проверки совместимости при выборе паттернов — выбранные паттерны не должны конфликтовать с жанровой грамматикой (например, выбор „быта / реальности“ в качестве основной настройки в сюаньхуане разрушит базовую линию удовольствия от прокачки).
- Когда „инновационное сочетание“ в позиционировании паттернов затрагивает слияние жанров, необходимо по пунктам проверить его по правилам операций с жанровой грамматикой №2–4.

### Четырёхуровневая система классификации паттернов (套路) (полная версия)

На основе анализа множества систем тегов веб-романов, читательских обсуждений, рекомендательных систем и разборов конкурентов паттерны веб-романов можно свести к **четырём уровням**, при выборе каждого уровня **обязательно выбрать из таблицы как минимум один**:

#### Первый уровень: тип основной настройки — «исходная конфигурация» истории

Определяет «чем этот мир / герой отличается». Это первый сигнал, который читатель получает, открыв книгу.

| Паттерн | Определение | Читательские ожидания | Типичные жанровые области | Жизненный цикл |
| --- | --- | --- | --- | --- |
| **Перемещение (穿越)** | Герой перемещается из современности / иного мира в целевой мир | Преимущество информационной асимметрии + понижающий удар современными знаниями | Историческая женская проза (古言), история, фэнтези | Через всю книгу, но преимущество знаний убывает после тома 2–3 |
| **Перерождение (重生)** | Герой после смерти возвращается в прошлое и живёт заново | Предвидение будущего + восполнение сожалений + месть + предвидение | Город, любовь, сюаньсянь | Через всю книгу, преимущество предвидения исчерпывается после тома 3 → нужно переключиться на движущую силу „эффекта бабочки“ |
| **Система (系统)** | Герой получает игровую вспомогательную систему | Цифровой рост + управление заданиями + удовольствие от панели | Все жанры (часто в сюаньхуане / городе / саспенсе) | Через всю книгу, но линия повышения системы не должна отрываться от основной линии |
| **Попадание в книгу (穿书)** | Герой перемещается внутрь некоего романа | Предвидение сюжета + изменение судьбы + борьба с оригиналом | Женская любовная проза | Через всю книгу, преимущество предвидения исчерпывается в середине → нужно перейти к „обратному удару сюжета“ |
| **Пробуждение сверхспособностей (异能觉醒)** | Герой в реальном мире получает сверхъестественные способности | Необычное в повседневности + скрытая личность | Городские сверхспособности, саспенс | Через всю книгу, линия роста способностей заменяет традиционную прокачку |
| **Быт / реальность (日常/现实)** | Нет сверхъестественных настроек, фокус на реальной жизни | Достоверность + вживание + фактура жизни | Город, офис, реалистичные жанры | Через всю книгу, движется отношениями персонажей и общественным давлением |

**Правило выбора**: выбрать и выбрать только одну в качестве исходной конфигурации героя. При наложении (например, «перерождение + система») в проверке совместимости R1 фабрики концепций нужно пояснить логику взаимодействия двух конфигураций.

#### Второй уровень: тип отношений персонажей — напряжение конфигурации между ролями

Определяет «почему читателю важно взаимодействие этих людей». **В мужском канале этот слой можно ослабить (выбрать «нет основной движущей силы отношений»), в женском — обязательно выбрать.**

| Паттерн | Основное напряжение отношений | Типичная цепочка событий | Основные жанровые области | Жизненный цикл |
| --- | --- | --- | --- | --- |
| **Брак с последующей любовью (先婚后爱)** | Помолвка есть, чувств нет | Вынужденный брак → притирка → рождение настоящих чувств | Женская историческая / современная любовь | Через всю книгу, линия потепления чувств естественно поддерживает длинную линию |
| **Погоня за женой на пепелище (追妻火葬场)** | Одна сторона предаёт, потом раскаивается | Самоотдача → предательство → уход → возвращение | Женская любовная проза | Первые 30 глав мучение → средние 30 глав самостоятельный рост → последние 30 глав возвращение |
| **Проза о заменах (替身文学)** | Одну сторону принимают за замену другого | Замена → обнаружение правды → пробуждение личности | Женская любовная проза | Первые 20 глав период замены → середина пробуждение → поздняя часть переворот |
| **Белая луна / родинка цвета киновари (白月光/朱砂痣)** | В сердце есть незаменимый человек | Сравнение → боль → падение белой луны / освобождение | Женская любовная проза | Первые 15 глав подавление белой луной → середина падение → поздняя часть освобождение |
| **Разбитое зеркало, вновь склеенное (破镜重圆)** | Встреча после расставания | Расставание / развод → каждый растёт → встреча | Женская любовная проза | Первые 10 глав конфликт встречи → середина узнавание заново → поздняя часть повторный выбор |
| **Любовь наставника и ученика (师徒恋)** | Ощущение запретности в отношениях учитель — ученик | Обучение → зависимость → преступание границ → конфликт позиций | Сянься, сюаньхуань | Первые 30 глав добрый учитель и почтительный ученик → середина преступание границ → поздняя часть противостояние внешнему миру |
| **Брак по контракту (契约婚姻)** | Фиктивный брак, каждый берёт своё | Подписание контракта → фиктивные супруги → настоящие чувства | Женская современная / историческая любовь | Напряжение поддерживается на всём протяжении (движется обратным отсчётом расторжения контракта) |
| **Контрольная группа / удар по лицу (对照组/打脸)** | Презирают → доказывает себя | Презрение → терпение → взрыв и удар по лицу | Все жанры | Может проходить через всю книгу, по объекту удара по лицу на том |
| **Отношения найма (雇佣关系)** | Разница положения нанимателя и работника и постепенное выравнивание | Привязка интересов → взаимное узнавание → переворот положения | Город, офис | Первые 20 глав давление найма → середина переворот → поздняя часть равенство |
| **Нет основной движущей силы отношений** | Основная линия не зависит от напряжения отношений, отношения лишь как приправа | N/A | Сюаньхуань-прокачка, жёсткий саспенс | Паттерн отношений можно пропустить, но нельзя обнулить (как минимум оставить одну линию отношений) |

#### Третий уровень: тип продвижения сюжета — шаблон событий, движущий историю

Определяет «чем в каждой главе / каждом томе читатель мотивируется листать дальше». **Нужно выбрать 1–2: первый двигатель и второй двигатель.**

| Паттерн | Определение | Типичный ритм | Основные жанровые области | Жизненный цикл |
| --- | --- | --- | --- | --- |
| **Прокачка и бои с монстрами (升级打怪)** | Постепенное усиление через бои / испытания | Встреча с врагом → бой → повышение → более сильный враг | Сюаньхуань, фэнтези, сюаньсянь | Через всю книгу, но нужно учитывать «инфляцию боевой силы» — прирост за том должен убывать |
| **Раскрытие загадок и расследования / единичные дела (解密探案/单元案)** | Решение дел / загадок поодиночке с продвижением основной линии | Приём дела → расследование → раскрытие → выход на основную линию | Саспенс, детектив, город | Через всю книгу, модель «замыкание единичных дел + тёмная основная линия» естественно поддерживает длинный роман |
| **扮猪吃虎 (притворяться свиньёй, чтобы съесть тигра)** | Герой намеренно скрывает силу и потом поражающе взрывается | Скромность → провокация → подавление противника → шок окружающих | Все жанры | Основная движущая сила — цикл «удар по лицу → новая личность → большая сцена», может поддерживаться на всём протяжении |
| **Срыв масок (掉马甲)** | Скрытая личность героя постепенно раскрывается | Скрытая личность → следы → разоблачение → шок | Все жанры (часто в мужском канале) | Первые 30 глав прячется → средние 30 глав постепенно просачивается → поздняя часть полное разоблачение |
| **Поток расторгнутой помолвки (退婚流)** | Расторжение помолвки в начале / рано запускает основную линию | Расторжение и унижение → клятва → ответный удар | Сюаньхуань, историческая женская проза | Обычно держит лишь первые 30–50 глав, затем нужно переключиться на новый двигатель |
| **Поток никчёмного (废材流)** | Героя считают никчёмным, а на деле он необыкновенен | Презрение → скрытая сила → шок всех | Сюаньхуань, сюаньсянь | Первые 20 глав период никчёмного → середина начинает раскрываться → поздняя часть возвращение короля |
| **Закулисный вдохновитель (幕后黑手)** | Герой втайне управляет ситуацией | Расстановка → ходы фигур → затягивание сети | Интеллектуальные игры, интриги, город | Через всю книгу, период накопления долог — в первых 3 главах нужна компенсирующая замена награды |
| **Земледелие / инфраструктура (种田/基建)** | С нуля строить силу / территорию | С голых рук → развитие → расширение → угроза | История, фэнтези, НФ | Через всю книгу, двухлинейное продвижение «линия строительства + линия внешнего врага» |
| **Поток мести (复仇流)** | Модель продвижения, где месть — итоговая цель героя | Выявление врагов → поочерёдное уничтожение → финальная схватка | Город, уся, сюаньсянь | Через всю книгу, объекты мести распределяются по уровням сложности |

#### Четвёртый уровень: тип эмоциональной награды — обещание эмоционального опыта читателя

Определяет «какова основная эмоциональная ценность, которую читатель получает, дочитав главу». **Нужно выбрать и выбрать только одно основное обещание.**

| Паттерн | Обещание читателю | Противоположность | Подходящий архетип компенсации | Основной приём |
| --- | --- | --- | --- | --- |
| **爽-проза (爽文)** | Непрерывное удовольствие от ударов по лицу / возвышения | Сдавленность (взрыв после сдавленности) | Тип «восхождение со дна», тип «недооценённый мститель» | Цикл «сначала подавить, потом высвободить», объём подавления ≤ объёма взрыва |
| **Сладкая проза (甜宠)** | Тёплая сладость в отношениях | Мучение сердца, недоразумения | Тип «героиня-главная в контратаке» (поздняя часть) | Продвижение отношений устойчиво растёт, конфликты идут снаружи, а не изнутри |
| **Мучительная проза (虐文)** | Эмоциональная разрядка, заставляющая читателя плакать / жалеть | Лёгкость и юмор | Тип «героиня-главная в контратаке» (ранняя часть) | Реальное изображение эмоции преданности, после плача обязательно дать надежду |
| **Саспенс (悬疑)** | Непрерывное ощущение неизвестного и желание разгадать | Спойлер, слишком раннее раскрытие | Все архетипы (склонность к медленному разогреву) | Высвобождение информации по циклу «задать интригу → постепенно раскрывать → новая интрига» |
| **Исцеляющая проза (治愈)** | После прочтения тепло / освобождение | Депрессия, тяжесть | Тип «героиня-главная в контратаке» (период финала) | Полная психологическая дуга «травма → понимание → принятие» |

### Матрица совместимости сочетаний паттернов

Не все паттерны можно произвольно накладывать. Матрица ниже помечает частые конфликтные пары и золотые сочетания:

| Сочетание | Совместимость | Пояснение |
| --- | --- | --- |
| Погоня за женой на пепелище + сладкая проза (одновременно) | 🔴 Конфликт | Первое — «сначала мучение, потом сладость», второе — «непрерывная сладость», одновременно читатель запутывается. Стратегия решения: **по этапам** — первые 30 глав мучительная проза + затем переход к сладкой |
| 爽-проза + саспенс | 🟢 Золотое сочетание | После удара по лицу сразу выбрасывается новая интрига, рывок и недосказанность чередуются, желание читать дальше очень сильное |
| Перерождение + раскрытие загадок и расследование | 🟢 Золотое сочетание | Преимущество предвидения перерожденца и интрига «знает убийцу, но нет улик» естественно сцеплены |
| Система + быт / реальность | 🟡 Нужна заплатка | Появление системной панели в чисто реалистичном жанре требует разумного механизма скрытия / объяснения |
| Поток расторгнутой помолвки + сладкая проза | 🟡 Нужна заплатка | После расторжения помолвки нужна замещающая эмоциональная линия, иначе линия чувств вращается вхолостую |
| Закулисный вдохновитель + 爽-проза | 🟢 Золотое сочетание | В период накопления даётся небольшая победа (爽), в период затягивания сети — большая победа (ещё 爽) |
| Попадание в книгу + брак с последующей любовью | 🟢 Золотое сочетание | Попавшая в книгу знает «ледяной» финал отношений в оригинале → старается изменить → отношения теплеют |
| Земледелие и инфраструктура + саспенс | 🔴 Конфликт | Медленное накопление земледелия и частое высвобождение информации саспенса принципиально конфликтуют по ритму |
| Восхождение со дна + мучительная проза | 🟡 Нужна заплатка | Дно и так достаточно тяжело, добавление мучительной прозы вызовет у читателя отчаяние, а не компенсацию — нужно обеспечить, чтобы после каждого мучения был реальный рост |
| Прокачка и бои с монстрами + раскрытие загадок и расследование | 🟢 Золотое сочетание | С открытием каждого уровня → соприкосновение со всё более сложными делами → звенья цепляются друг за друга |

> **Золотое сочетание** означает, что между двумя паттернами есть естественное повествовательное сцепление, дополнительного проектирования стыка не нужно.
> **Нужна заплатка** означает, что реализовать можно, но требуется дополнительная работа по проектированию, чтобы сгладить конфликт.
> **Конфликт** означает, что прямое наложение не рекомендуется, если только нет чёткого плана смены этапов.

### Спектр чистоты паттерна-套路

После завершения выбора паттернов необходимо пометить **позицию чистоты** каждого паттерна:

```text
чистый паттерн-套路 ←——— смешанная вариация ———→ анти-套路
```

| Позиция | Особенности | Восприятие читателя | Применимые сценарии |
| --- | --- | --- | --- |
| **Чистый паттерн** | Стандартная цепочка событий + стандартная конфигурация отношений, читателю понятно с первого взгляда | «Вот классический способ писать XX-прозу» | Вход для новых авторов, объём на платформе, зрелые треки с высокой лояльностью читателей |
| **Смешанная вариация** | Каркас основного паттерна + элементы других паттернов | «Хотя это XX-проза, но добавлена новизна от YY» | Оптимальный выбор для большинства коммерческих веб-романов — есть узнаваемость, но не слишком незнакомо |
| **Антипаттерн** | Сначала формируется ожидание читателя относительно паттерна, в ключевой момент оно ломается | «Постойте, разве не должно быть иначе?» | Читатель должен знать «здравый смысл паттернов», чтобы оценить антипаттерн — не подходит для треков новичков |

### Межжанровый перенос паттернов

Один и тот же паттерн в разных жанрах проявляется в разных формах. При позиционировании нужно учитывать форму приземления после переноса:

| Паттерн | Версия сюаньхуань | Городская версия | Женская версия | Версия саспенса |
| --- | --- | --- | --- | --- |
| 扮猪吃虎 | Никчёмный скрывает культивацию → подавление на большом состязании секты | Босс работает охранником → в критический момент действует | Притворяется некрасивой / глупой → в ключевой момент проявляет силу | Новичок-полицейский → на месте преступления демонстрирует профессиональные знания |
| Брак с последующей любовью | Союз школ бессмертных → чувства рождаются в совместной борьбе с врагом | Семейный союз → случайное сожительство → влечение | Историческая: императорский указ о браке → почтительная вежливость → общие невзгоды | Договорной брак для защиты свидетеля → игра становится настоящей |
| Закулисный вдохновитель | Скрытый великий мастер управляет расстановкой сект | Закулисный инвестор управляет коммерческой войной | Мастер-стратег глубинного дворца управляет властью в гареме | Организатор серии дел втайне управляет направлением расследования |

> Правило оценки: при межжанровом переносе нужно обеспечить, чтобы **абстрактная структура отношений** паттерна (исходная конфигурация отношений + основная цепочка событий + обещание эмоциональной награды) оставалась неизменной, менялась лишь жанрово-специфическая форма проявления.

### Склонность связи «паттерн — ритм»

Некоторые паттерны естественно тяготеют к определённому нарративному ритму — не абсолютная привязка, но статистически высокая корреляция:

| Паттерн-套路 | Склонный режим начала главы | Склонная плотность хуков | Склонный тип награды в середине |
| --- | --- | --- | --- |
| 追妻火葬场 | Вступление внутренним монологом (от лица героини) | Высокая плотность (в каждой главе эмоциональный хук) | Продвижение отношений / смещение отношений |
| Прокачка и бои с монстрами | Вход через действие | Средняя плотность (большой хук каждые 3–4 главы) | Повышение статуса / демонстрация способностей |
| Раскрытие загадок и расследование | Аномалия / интрига вперёд | Средне-высокая плотность (новая интрига каждые 2 главы) | Открытие информации / проявление улик |
| 甜宠日常 (сладкий быт) | Вступление диалогом или средой | Низкая плотность (хук может быть, а может не быть) | Продвижение отношений |
| Закулисный вдохновитель | Внутренний монолог или вход через информацию | Низко-средняя плотность | Контрудар в ситуации / переворот ситуации |

> При позиционировании нужно проверять: согласуется ли естественная ритмическая склонность выбранного паттерна с требованиями ритма V2 (формулировки платформы). Если не согласуется, в «трёхконтурной калибровке платформа — позиционирование — ритм» необходимо чётко дать план корректировки.

### Четыре решения выбора паттернов

При выполнении жанрового позиционирования необходимо выбрать минимум по одному из вышеуказанной четырёхуровневой классификации и явно выполнить следующие решения:

| Решение | Откуда выбирать | Вопрос | Пример |
| --- | --- | --- | --- |
| **Выбор основной настройки** | Уровень 1: тип основной настройки | Перемещение / перерождение / система / попадание в книгу / быт / пробуждение сверхспособностей? Выбрать одно как исходную конфигурацию | «Перерождение + система» двойное наложение |
| **Конфигурация отношений персонажей** | Уровень 2: тип отношений персонажей | Брак с последующей любовью / погоня за женой на пепелище / разбитое зеркало / брак по контракту / контрольная группа с ударом по лицу / наставник и ученик? Выбрать одно как двигатель отношений | «Брак с последующей любовью» как основная конфигурация отношений |
| **Шаблон продвижения сюжета** | Уровень 3: тип продвижения сюжета | 扮猪吃虎 / прокачка и бои с монстрами / раскрытие загадок и расследование / земледелие и инфраструктура / закулисный вдохновитель / расторгнутая помолвка / никчёмный? Выбрать 1–2 как способ продвижения событий | «扮猪吃虎 + срыв масок» двойное продвижение |
| **Обещание эмоциональной награды** | Уровень 4: тип эмоциональной награды | 爽-проза / сладкая проза / мучительная проза / саспенс / исцеляющая проза? Выбрать одно как эмоциональный контракт с читателем | «爽-проза» как основное обещание |

### Проверка разумности сочетания паттернов

После выбора сочетания обязательно выполнить следующие шесть проверок (по сравнению с прежними четырьмя добавлены №5 и №6):

1. **Совместимость**: нет ли конфликта между выбранными паттернами? Сверить по **матрице совместимости**. Если попадает в «конфликтное» сочетание, обязателен план смены этапов или выбор одного из двух.
2. **Насыщенность трека**: не используется ли выбранное сочетание паттернов на целевой платформе слишком массово. Если сочетание сильно насыщено (например, «перемещение + дворцовые интриги + удар по лицу»), нужен чёткий план дифференциации; если насыщенность низкая (например, «перерождение + инфраструктура + реалистичная ориентация»), нужно суждение, почему раньше никто не сделал это хорошо.
3. **Окно первого раскрытия «фишки»**: смогут ли ключевые элементы сочетания паттернов быть воспринятыми читателем в первых 3 главах? Если основной паттерн — «закулисный вдохновитель» (долгий период накопления), в первых 3 главах обязательна компенсирующая замена награды.
4. **Способность непрерывного питания**: способно ли выбранное сочетание паттернов поддерживать долгое повествование в 100+ глав? Сверить по столбцу **жизненный цикл**: если основной паттерн держит лишь 30 глав (например, поток расторгнутой помолвки), необходимо спланировать двигатель-переключатель после главы 30.
5. **Согласованность ритма**: согласуется ли **естественная ритмическая склонность** выбранного паттерна с требованиями ритма V2 (формулировки платформы)? Если не соответствует, в «трёхконтурной калибровке платформа — позиционирование — ритм» нужно дать план корректировки.
6. **Осуществимость чистоты**: если помечено позиционирование «антипаттерн», нужно подтвердить: ① знакома ли целевым читателям паттерн, который переворачивается; ② в какой главе читатель сможет распознать проект как «антипаттерн» (если спрятан слишком глубоко, стратегия антипаттерна не работает).

### Связь позиционирования паттернов и жанрового позиционирования

| Сценарий | За что отвечает жанр | За что отвечает паттерн |
| --- | --- | --- |
| Городская проза о перерождении на Qidian | «Город» определяет фон, «перерождение» — исходную способность | «扮猪吃虎» определяет способ продвижения событий, «爽-проза» — эмоциональное обещание |
| Женская историческая проза «брак с последующей любовью» | «Историческая женская проза (古言)» определяет временную рамку | «Брак с последующей любовью» определяет начало отношений, «погоня за женой на пепелище» — эмоциональную траекторию |
| Сюаньхуань: никчёмный перерождается в силу | «Сюаньхуань» определяет мироустройство | «Поток никчёмного» определяет исходную личность, «прокачка и бои с монстрами» — способ продвижения, «爽-проза» — эмоциональное обещание |
| Городской саспенс с разгадкой | «Город» определяет пространство, «саспенс» — атмосферу | «Перерождение» + «раскрытие загадок и расследование» определяют двухлинейное продвижение, «саспенс» — эмоциональное обещание |

Если уже существует продукт дистилляции текущего произведения или образца того же трека (включая §18 «Отпечаток паттернов-套路»), следует напрямую читать его перечень паттернов и рекомендации по межжанровому переносу как ориентир; если несколько образцов используют одно и то же сочетание паттернов и все достигли успеха, это сочетание можно признать «проверенным эффективным сочетанием» трека; если в отчёте анализа конкурентов этого трека уже охвачено измерение паттернов, позиционирование паттернов может напрямую ссылаться на его выводы, избегая повторов.

## Проектирование обещания компенсации читателю — основной двигатель жанрового позиционирования (новое)

> **Ключевое открытие**: читатели веб-романов следят за книгой не ради «сюжета», а ради «воображаемого переворота подавленного положения». Герой-бедняк, который переворачивается, привлекает сильнее богатого наследника от рождения не потому, что «настройка бедняка реальнее», а потому что «восхождение со дна» от природы даёт большее **пространство компенсации** — читатель в реальной жизни находится в подавленном низком положении, а в чтении переживает переворот власти «снизу вверх». Это и есть базовая движущая сила веб-романов.
>
> Исследование «Chinese Book Review» 2025 года указывает: причина беспрецедентно огромной системы тегов в веб-романах — не потребность платформ в классификации, а скрытый двигатель культурной логики «爽»: теги обозначают символическую систему, организованную ради обозначения точек 爽 и повествующую о подавленном жизненном опыте.

### Перечень основных архетипов компенсации (обязательно)

Перед определением жанрового позиционирования необходимо сначала определить **основной архетип компенсации** текущего произведения. Архетип компенсации определяет не «сюжет истории», а «какие психологические потребности читатель компенсирует, читая эту книгу».

**Четыре основных архетипа компенсации:**

| Архетип | Что читатель компенсирует | Исходное положение персонажа | Структура власти | Основная модель читательского ощущения | Типичные жанры |
| --- | --- | --- | --- | --- | --- |
| **Тип «восхождение со дна»** | «Вы все ошиблись, а я прав» — недооценён → доказывает | Статус / ресурсы / способности полностью в низкой позиции; вытеснен, высмеян, презираем | Верхи подавляют низы; через усилия + золотой палец осуществляется классовый переворот | Накопление → удар по лицу → прокачка → снова накопление → больший удар по лицу | Сюаньхуань: поток никчёмного, городской бедняк-возвышающийся, поток простого смертного в сюаньсянь |
| **Тип «недооценённый мститель»** | «Оказывается, он настоящий босс» — терпение → раскрытие козырей → подавление | Скрытая сила / личность; на поверхности слаб, на деле есть козыри | Поверхностные отношения подавления (сильный давит слабого) vs реальный переворот (слабый на деле силён) | Презрение → терпение без выплеска → в ключевой момент раскрытие козырей → шок всех | 扮猪吃虎, срыв масок, возвращение со скрытой личностью, поток зятя-домоседа |
| **Тип «героиня-главная в контратаке»** | «Ты меня не достоин» — предана → пробуждение → ответный удар → заставляет другого пожалеть | Низкая позиция в чувствах / отношениях / социальном статусе; самоотдача не замечена, предана, заменена | Эмоциональный вакуум власти (отдававшую предали) → переворот власти после пробуждения | Самоотдача → предательство → пробуждение → самостоятельный рост → подавление и сожаление другого | Погоня за женой на пепелище, ошеломляющая после развода, перерождённая мстительница, мамочка с ребёнком в бегах |
| **Тип «непобедимое подавление»** | «Я и есть правила» — легко → подавление → радость мести и благодарности | Пик с самого начала (перерождение / система / скрытая сила), либо быстро достигается пик | Герой от природы на вершине власти; правила мира служат герою | Лёгкое справление → непринуждённость → подавление и удар по лицу → радость мести и благодарности | Проза о перерождении (знает будущее), системная 爽-проза, проза о внезапном богатстве (神豪文), поток непобедимого героя |

**Правила выбора:**
- Каждое произведение может **выбрать и выбрать только один основной архетип компенсации**. Смешение двух заставляет читателя не понимать, «в чём же эта книга хочет мне дать 爽».
- Допускается переключать архетип компенсации в **поздней части длинного романа** (например, от «восхождения со дна» к «непобедимому подавлению» в большой поздней части), но первые 500 тыс. знаков основной архетип должен оставаться стабильным.
- Архетип компенсации должен соответствовать выбору жанра: тип «героиня-главная в контратаке» нельзя накладывать на хардкорную военную научную фантастику; тип «восхождение со дна» не подходит для медленно разогревающихся литературных жанров.

### Оценка пространства компенсации — на каком основании ваши настройки заставляют читателя «爽» сильнее, чем у конкурентов

В одном жанре много конкурентов, и ключевой разрыв позиционирования возникает не из «разницы жанров», а из **величины пространства компенсации**.

**Пространство компенсации = исходная низкая позиция персонажа × высота итогового подавления**

| Настройка персонажа | Исходная низкая позиция | Итоговая высота | Пространство компенсации | Коммерческий потенциал (оценка) |
| --- | --- | --- | --- | --- |
| Баловень-«второе поколение богачей» | 4/10 (с рождения на высоком положении) | 9/10 (сохраняет высокое положение) | 5 баллов | Низкий — читатель не может вжиться по принципу «да это же я» |
| Отвергнутый семьёй внебрачный сын | 2/10 (с рождения подавляем) | 10/10 (возвышение до наследника) | 8 баллов | Высокий — большой компенсационный перепад даёт топливо для ударов по лицу |
| Обычный человек, переродившийся в прошлое | 1/10 (плачевное положение) | 10/10 (предвидение будущего, переворот судьбы) | 9 баллов | Чрезвычайно высокий — предельно низкая позиция + предельное подавление |
| Домохозяйка, брошенная после измены и развода | 1/10 (тройная низкая позиция: чувства / экономика / общество) | 9/10 (успех в карьере + бывший муж жалеет) | 8 баллов | Чрезвычайно высокий — архетип компенсации точно попадает в определённую аудиторию |

**Правила проектирования:**
- В рамке позиционирования обязательно явно оценить пространство компенсации произведения (1–10 баллов) и пояснить источник пространства компенсации (достаточно ли низка исходная позиция, достаточно ли высоко подавление или то и другое вместе).
- Произведения с пространством компенсации ≤5 баллов, при отсутствии других подавляющих «фишек» продаж (например, очень сильного потенциала IP-адаптации, очень высокой редкости жанра), по умолчанию признаются недостаточными по коммерческому потенциалу и не должны напрямую входить в проектирование общего плана.
- «Исходная низкая позиция» пространства компенсации не может быть абстрактной («ей так плохо»), а должна быть конкретна до положения, которое можно вписать в аннотацию («после развода с ребёнком на руках, без жилья, бывший муж женился на её подруге»).

### Правила передачи архетипа компенсации нижестоящим Skill

После определения архетипа компенсации рамка жанрового позиционирования обязана передать следующие параметры всем нижестоящим проектировочным Skill:

| Параметр | Нижестоящий Skill | Способ использования |
| --- | --- | --- |
| Основной архетип компенсации | общий-проектирование-общего-плана | Управляет проектированием типа основного конфликта системы M0/X/C |
| Оценка пространства компенсации | общий-проектирование-общего-плана, общий-оценка-подписания-на-платформе | В качестве эталонной линии оценки коммерческого потенциала |
| Предварительная оценка ритма компенсационной награды | общий-проектирование-плана-тома | Проектирование битов цикла «удар по лицу / ответный разгром» |
| **Ожидаемый уровень эмоциональной плотности** | общий-проектирование-общего-плана, общий-проектирование-плана-тома | Проектирование плотности эмоциональной стимуляции общего плана и базовая линия формулы золотого ритма плана тома |
| **Тип основной эмоциональной награды** | общий-проектирование-общего-плана, общий-проектирование-плана-тома, общий-проектирование-граней-истории | Выбор точек эмоциональной стимуляции на каждом уровне и способ реализации «фишки» |
| **Вывод трёхконтурной калибровки «платформа — позиционирование — ритм»** | общий-проектирование-общего-плана, общий-оценка-подписания-на-платформе | Суждение о соответствии формулировкам платформы и проектирование коммерческого ритма |
| **Вывод об исполнимости «золотых трёх глав»** | общий-проектирование-плана-тома, общий-создание-основного-текста | Жёсткие ограничения структурного проектирования первых трёх глав |
| Проектирование исходной низкой позиции персонажа | общий-проектирование-биографии-персонажей | Параметры исходного состояния персонажа и структуры власти |
| Тип рычага компенсации | общий-проектирование-настроек-истории | Тип и путь роста способностей / золотого пальца |
| Потребность в компенсационной синергии | общий-проектирование-граней-истории | Выбор типа компенсации побочных линий |

Если в ходе проектирования нижестоящего Skill обнаруживается принципиальный конфликт архетипа компенсации с жанром / персонажами / настройками, следует вернуться к слою рамки жанрового позиционирования для повторной калибровки, нельзя принудительно латать на нижестоящем уровне.

## Обещание ритмической плотности при жанровом позиционировании (новое)

> **Диагностика проблемы**: многочисленная практика показывает, что на этапе жанрового позиционирования произведение выбирает позиционирование (например, «женский канал, ориентированный на реалистическую литературу, о браке и любви», «городской саспенс с медленным разогревом»), но в описании позиционирования ни разу не отмечено, «какова читательски ожидаемая ритмическая плотность этого позиционирования». В результате нижестоящие Skill пишут по литературному инстинкту, а читатели читают по ожиданиям ритма веб-романа — рассогласование между ними порождает системную негативную обратную связь «слишком медленно, слишком вязко, нет точек 爽 и мучительных точек».
>
> **Принцип в одну фразу**: **позиционирование определяет не только „что писать“, но и „насколько быстрым должен быть ритм, насколько густой эмоция“**. Выбор позиционирования A (爽-проза «погоня за женой на пепелище») равен обещанию «каждые 500 знаков одна эмоциональная стимуляция, плотный конфликт в первых трёх главах»; выбор позиционирования B (реалистичная литературность) не позволяет маскироваться под 爽-прозу — но ценой может стать неприглядная статистика удержания первых недель, а редактор может отвергнуть рукопись.

### Отображение архетипа компенсации на эмоциональную плотность

Каждый архетип компенсации от природы склоняется к разной плотности эмоциональной стимуляции. При жанровом позиционировании в описании обязательно указывать ожидаемую плотность, соответствующую выбранному архетипу:

| Архетип компенсации | Естественная эмоциональная плотность | Читательский ожидаемый ритм | Частые жанры | Требования к плотности зачина |
| --- | --- | --- | --- | --- |
| **Тип «восхождение со дна»** | **Средне-высокая плотность** (средняя точка 爽 каждые 2–3 главы) | Накопительное удовольствие «посмотрим, как он шаг за шагом пробивается» | Сюаньхуань: поток никчёмного, поток простого смертного в сюаньсянь, городской бедняк | В первых трёх главах как минимум завершить цикл «пренебрегают → первая небольшая победа → более крупная цель» |
| **Тип «недооценённый мститель»** | **Высокая плотность** (переворот / удар по лицу каждые 1–2 главы) | Непрерывный сюрприз «какой козырь он покажет в этот раз» | 扮猪吃虎, срыв масок, возвращение со скрытой личностью, поток зятя-домоседа | В первых трёх главах как минимум один полный цикл удара по лицу «презирают → раскрытие козыря → шок» |
| **Тип «героиня-главная в контратаке»** | **Чрезвычайно высокая плотность** (не менее 1 точки эмоциональной стимуляции в каждой главе) | Чередование мучения и 爽 «отболело — и пора 爽» | Погоня за женой на пепелище, ошеломляющая после развода, перерождённая мстительница | **В первых трёх главах каждые 500–800 знаков должна быть мучительная точка**, и после каждых 3 мучительных точек вставлять 1 небольшую точку 爽 (увидеть правду / получить доказательства / появился новый выбор) |
| **Тип «непобедимое подавление»** | **Средняя плотность** (кульминация каждые 3–4 главы), но плотность первой главы очень высока | Ощущение непринуждённости «посмотрим, как он будет красоваться в этой главе» | Проза о внезапном богатстве, системная 爽-проза, проза о перерождении | В первой главе в пределах 8–1200 знаков завершить показ золотого пальца + первое подавление |

**Правила проектирования**:
- В описании позиционирования обязательно явно отметить «ожидаемый уровень эмоциональной плотности» произведения (чрезвычайно высокий / высокий / средне-высокий / средний / низкий) и пояснить основание — это основание происходит из выбора архетипа компенсации.
- Если в позиционировании выбран «тип героини-главной в контратаке», но отмечена «средняя плотность», позиционирование и обещание плотности противоречат друг другу, нужно либо скорректировать обещание плотности, либо заново оценить выбор архетипа компенсации.
- «Низкая плотность» не равна «отсутствию плотности». Позиционирование низкой плотности (например, медленно разогревающийся реализм, литературный саспенс) должно иметь одно из двух компенсирующих условий: ① явно заявлено как «не быстрый ритм веб-романа», целевые читатели — особая нишевая группа; ② есть стабильная база читателей или издательский / IP-канал, не зависящий от рекомендательных алгоритмов платформы.

### Трёхконтурная калибровка «платформа — позиционирование — ритм»

Одно и то же жанровое позиционирование на разных платформах предъявляет резко различающиеся требования к ритмической плотности. Рамка позиционирования должна одновременно завершить калибровку формулировок платформы, иначе «позиционирование верно, а платформа выбрана неверно = данные-яд».

| Платформа | Оценка требований к ритмической плотности | Влияние на калибровку позиционирования |
| --- | --- | --- |
| **Qidian (起点中文网)** | Логика платных подписок; «старые» читатели терпят 2–3 главы накопления, но требуют логической самосогласованности и убедительности переворота после подготовки | Допускает позиционирование «средней плотности» (тип «восхождение со дна» и тип «непобедимое подавление» естественно подходят), но чрезвычайно высокая плотность типа «героиня-главная в контратаке» столь же популярна на быстром женском треке |
| **Qimao (七猫)** | Бесплатная модель + реклама, удержание — основной KPI, по зачину можно определить жизнь или смерть; подписывающий редактор смотрит первые три главы и решает судьбу | **Обязательное позиционирование чрезвычайно высокой / высокой плотности**: «героиня-главная в контратаке» и «недооценённый мститель» естественно подходят; «восхождению со дна» необходимо вкладывать небольшие стимуляции на базе средней плотности; «непобедимому подавлению» в первой же главе нужно завершить показ золотого пальца |
| **Fanqie (番茄小说)** | Дебют определяет жизнь или смерть, в период новой книги большой охват, но лояльность читателей низкая; в первых 10 главах обязательно выбить самую сильную «фишку» | Обязательное позиционирование высокой плотности; период накопления первых трёх глав «восхождения со дна» на Fanqie слишком долог, его нужно сжать до одной главы, завершив «старт с конфликта → получение способности → первая небольшая победа»; плотность мучительных точек в первых трёх главах «героини-главной в контратаке» нужно ещё удвоить |
| **Jinjiang (晋江文学城)** | Двигатель — эмоциональный резонанс, медленно разогревающуюся прозу можно разжечь молвой; точность тегов важнее быстроты ритма | Допускает позиционирование средней / средне-низкой плотности, но нужно заплатить временем «медленного ожидания» — читатель может определить, продолжать ли читать, лишь после 30 тыс. знаков |

**Правила проектирования**:
- В описании позиционирования обязательно должен быть «вывод трёхконтурной калибровки платформа — позиционирование — ритм»: какова целевая платформа, каковы требования платформы к ритму позиционирования, соответствует ли плотность текущего позиционирования этим требованиям.
- Если трёхконтурная калибровка обнаруживает конфликт (например, «Qimao + восхождение со дна + средняя плотность» = ритм слишком медленный для бесплатной платформы), обязательно дать план корректировки: либо сменить платформу, либо повысить плотность, либо доказать наличие базы.
- Если основная платформа вывода не настроена, по умолчанию калибровать по стандарту Qidian.

### Проверка исполнимости «золотых трёх глав» для позиционирования

Самая смертельная ловушка жанрового позиционирования: **позиционирование звучит верно, но первые три главы вообще невозможно исполнить**. Можно написать на карточке позиционирования «это быстрая 爽-проза „погоня за женой на пепелище“», но если реально спроектированные первые три главы целиком состоят из описаний среды и психологической подготовки, позиционирование — пустой чек.

Перед выдачей рамки позиционирования обязательно завершить одну проверку — **проверку исполнимости позиционирования по золотым трём главам**:

| Пункт проверки | Критерий прохождения |
| --- | --- |
| Есть ли в первых 300 знаках конфликт / аномалия / сигнал давления, согласованные с позиционированием | В первых 300 знаках быстрого позиционирования обязателен чёткий старт с конфликта; медленно разогревающееся позиционирование не должно прятать конфликт до главы 3 |
| Завершена ли в первых 1000 знаках первая стимуляция, обещанная позиционированием | Тип «героиня-главная в контратаке» должен уже в первом абзаце показать мучительную точку «предана / ранена»; тип «восхождение со дна» в пределах 800 знаков должен дать читателю сигнал «я сильнее, чем вы думаете» |
| Соответствует ли тип хука в конце первых трёх глав повествовательному типу позиционирования | «Героиня-главная в контратаке» должна завершаться эмоциональным хуком «ещё мучительнее / ещё 爽»; позиционирование саспенса — информационным хуком «ещё загадочнее»; позиционирование 爽-прозы — хуком ожидания «ещё более ощутимый удар по лицу» |
| Соответствует ли доля диалогов ритмической плотности позиционирования | Для позиционирования чрезвычайно высокой / высокой плотности доля диалогов в первых трёх главах рекомендуется ≥40% (женский канал ≥50%); для средней плотности — ≥30% |
| Может ли основная точка отличия позиционирования быть естественно воспринята читателем как минимум в 2 местах первых трёх глав | Если «инновационное слияние A+B» лишь упомянуто в аннотации, а в первых трёх главах основного текста вообще не отражено → точка отличия ложная |

**Правила исполнения**:
- При выдаче рамки позиционирования обязательно должен быть вывод проверки «исполнимости золотых трёх глав» (пройдено / пройдено условно / не пройдено).
- Если не пройдено, обязательно пояснить: какой тип читателей или редакторов, скорее всего, определит несоответствие позиционирования уже при чтении первых нескольких абзацев.
- Разрыв между позиционированием и проектированием («хотел написать быстро, а реально получилось медленно») нельзя обнаруживать лишь на стадии тома или основного текста — на уровне жанрового позиционирования его нужно заранее выявить проверкой исполнимости.

### Заявление о типе эмоциональной награды (новое)

При выдаче рамки позиционирования, помимо жанра, паттернов (套路) и архетипа компенсации, обязательно чётко прописать **тип эмоциональной награды** — основное позиционирование эмоциональной ценности, которую читатель получает после прочтения главы.

| Тип эмоциональной награды | Ощущение читателя после прочтения главы | Подходящий архетип компенсации | Подходящие жанры |
| --- | --- | --- | --- |
| **Тип «интеллектуальное подавление»** | «Какой умный, я кое-чему научился» | Тип «недооценённый мститель», тип «непобедимое подавление» | Интеллектуальные игры, интриги, закулисный вдохновитель, раскрытие загадок |
| **Тип «рост ресурсов»** | «Снова стал сильнее, активов больше» | Тип «восхождение со дна» | Сюсянь-прокачка, системный поток, земледелие и инфраструктура |
| **Тип «перетягивание отношений»** | «Их чувства наконец сдвинулись / наконец треснули» | Тип «героиня-главная в контратаке» | Погоня за женой на пепелище, разбитое зеркало, брак с последующей любовью |
| **Тип «шок идентичности»** | «Оказывается, он / она настоящий босс» | Тип «недооценённый мститель» | Срыв масок, возвращение со скрытой личностью, проза о заменах |
| **Тип «выбор стороны по ценностям»** | «Этот поступок — такое удовлетворение / такая гадость» | Все архетипы | Удар по лицу, политические игры, конфликт позиций |
| **Тип «информационный саспенс»** | «Постойте, что-то не так……» | Все архетипы (склонность к медленному разогреву) | Саспенс-разгадка, теории заговора, жуткие истории о правилах |

**Правила проектирования**:
- Каждое позиционирование обязано выбрать **1 основной тип эмоциональной награды** + максимум **1 вспомогательный тип** (например, «интеллектуальное подавление как основной, шок идентичности как вспомогательный»).
- Основной тип эмоциональной награды должен проходить через всю книгу и не переключаться после первого тома. Вспомогательные типы можно чередовать в середине.
- В позиционировании обязательно указать «в какой главе основной тип эмоциональной награды впервые реализуется для читателя» — если ответить нельзя, значит, на уровне позиционирования ещё не продумано, «в чём в итоге читателю 爽».

### Трёхуровневая оценка инновационности жанра

При проектировании жанрового позиционирования необходимо по следующим трём измерениям дать суждение о текущем состоянии и причину выбора:

1. **Рыночная насыщенность**: традиционные паттерны «поток расторгнутой помолвки», «поток отметок о визитах» насыщены, хитом стать трудно; если основная «фишка» зависит от уже массово повторенных паттернов, зрелость позиционирования по умолчанию понижается.
2. **Способность к инновационному слиянию**: например, «Дафэнский ночной страж» (《大奉打更人》) — новая категория «сюсянь-расследование», сталкивающая научное расследование и сюаньхуань-культивацию. Рамка позиционирования обязана записать минимум одну формулу слияния «A+B» и пояснить, какой читательский опыт, которого раньше не было в этом же треке, возник после слияния.
3. **Соответствие эпохе**: в 2026 году популярны не традиционные «прокачка и бои с монстрами», а антипаттерн-проза (система — злодей, герой побеждает умом), реалистичное возвышение «маленького человека», приземлённость, побеждающая господство над миром. Если позиционирование остаётся на уровне «чит подавляет всё» и не даёт герою реального сопротивления, оно считается оторванным от текущих читательских вкусов.

| Пункт проверки | Критерий прохождения |
| --- | --- |
| Составляет ли жанр в TOP50 рейтинга Qidian ≥30% и активно ли обновление, постоянно ли выходят новые произведения | Если ниже 15% или рейтинг стареет, нужно доказать, почему можно прорваться против течения |

### Калибровка целевого читателя и сценариев платёжного триггера (новое)

- По стандарту Qidian текст позиционирования обязан явно записать «первую целевую читательскую группу» и «вторую целевую читательскую группу» и пояснить, почему эти два типа читателей будут продолжать следить за обновлениями, а не только смотреть на концепцию.
- По умолчанию дополнительно ответить на три вопроса:
	1. Чей и какой читательский импульс бьёт эта книга (интеллектуальная игра, возвышение, эмоциональная компенсация, выбор стороны в отношениях, разгадка механизма и т. п.);
	2. Чем читатель мотивируется продолжать платить в томе `1` и томе `2` соответственно;
	3. Если не опираться на сильную базу автора, за счёт чего само произведение удерживает читателей.
- Если позиционирование пишет лишь «жанр очень популярен», но не может чётко написать «кто целевой читатель, за что платит, где непрерывное питание», по умолчанию признаётся незавершённым.

## Фабрика концепций — генерация нескольких вариантов и отбор PK (вход по умолчанию)

> Этот модуль — **вход по умолчанию** в `общий-проектирование-позиционирования-жанра`. Роль фабрики концепций — не «необязательный предварительный модуль», а **мозг этого Skill**. Фабрика концепций определяет, «в какую сторону идти», последующее углубление рамки определяет, «как проложить этот путь». Вместе они образуют полный процесс позиционирования.
>
> **Изменение позиционирования рабочего процесса**: в прежних версиях фабрика концепций была необязательной, а рамка углубления концепции — по умолчанию. С этой правки **фабрика концепций — по умолчанию, рамка углубления концепции — после неё**. Получив этот Skill, автор первым делом запускает фабрику концепций.

### Когда использовать (сценарии по умолчанию)

- **Стандартное действие перед открытием книги** — сначала прогнать PK фабрики концепций, затем углублять
- Есть смутная идея, но неуверенность «верное ли направление» — поместить имеющуюся идею в пул PK как одного из кандидатов и посмотреть, какое место она займёт в PK с другими вариантами
- У команды / отдельного человека несколько вариантов жанровых / паттерновых треков, нужно принять решение о приоритетах

### Исключения, когда можно пропустить фабрику концепций

- **Уже вошли в стадию проектирования общего плана / томов** → пропустить фабрику концепций, сразу использовать процесс углубления рамки
- **Чисто личное выражение / литературное творчество** → коммерческая ориентация метода PK исказит творческий замысел, пропуск оценить самостоятельно
- **Концепция в основном определена, нужны только калибровка и фиксация деталей** → пропустить PK, сразу использовать процесс углубления рамки
- **Есть выход предыдущей фабрики концепций, подкреплённый данными конкурентов / образцов** → напрямую переиспользовать решающую концепцию предыдущего раза и перейти к углублению рамки

### Основной метод: комбинаторика элементов × многораундовый PK

Ключевые элементы, затронутые жанровым позиционированием, раскладываются на **8 независимых переменных**. После выбора предварительных ограничений (жанр + платформа) остальные 6 переменных комбинируются, массово порождая кандидатные концепции, затем пятью последовательными раундами PK поэтапно отсеиваются, и в итоге фиксируется **одна решающая концепция**.

#### 8 ключевых переменных

| Переменная | Пояснение | Примеры типичных вариантов |
| --- | --- | --- |
| **V1 Жанр** | Мир / эпоха, в которой происходит история (предварительное ограничение) | Город / сюаньхуань / саспенс / история / НФ / офис |
| **V2 Формулировки платформы** | Целевая платформа и стиль ритма (предварительное ограничение) | Qidian / Qimao / Fanqie / Jinjiang / Zhihu / несколько платформ |
| **V3 Архетип компенсации** | Способ психологической компенсации читателя | Восхождение со дна / недооценённый мститель / героиня-главная в контратаке / непобедимое подавление |
| **V4 Основная настройка** | Исходная конфигурация истории | Перерождение / перемещение / система / попадание в книгу / быт / пробуждение сверхспособностей |
| **V5 Отношения персонажей** | Исходное напряжение отношений | Брак с последующей любовью / брак по контракту / контрольная группа с ударом по лицу / наставник и ученик / найм |
| **V6 Продвижение сюжета** | Шаблон событий, движущий историю | 扮猪吃虎 / раскрытие загадок / прокачка и бои с монстрами / земледелие и инфраструктура / закулисный вдохновитель |
| **V7 Эмоциональная награда** | Эмоциональный контракт читателя | 爽-проза / саспенс / сладкая / мучительная / исцеляющая |
| **V8 Профессиональный срез** | Конкретный профессиональный рычаг героя | Судмедэксперт / программист / риелтор / курьер службы доставки / управляющая компания / охранник |

> V1 (жанр) и V2 (платформа) должны быть выбраны первыми — они предварительные ограничения для последующей комбинаторики. Для остальных 6 переменных каждая даёт минимум **3 варианта** (рекомендуется 4–6), и после комбинаторики получается **не менее 30 исходных кандидатных концепций**, только тогда можно входить в R1. Если меньше 30, необходимо дополнять варианты переменных из **источников вдохновения**, пока не достигнут норматив. Верхний предел не ограничен, но рекомендуется держать исходный пул кандидатов в пределах **30–80**, при превышении случайно / расслоённо выбрать 80 для входа в R1 (80 достаточно для покрытия эффективного разнообразия, большее число, напротив, снижает сопоставимость каждого раунда PK).

> **Источник вариантов переменных**: «примеры типичных вариантов» в таблице выше — лишь умолчательные предустановки при запуске. При реальном выполнении фабрики концепций конкретные варианты переменных **обязательно** должны дополняться и обогащаться из **источников вдохновения** (перечня паттернов из отчётов анализа конкурентов, отпечатков паттернов из продуктов дистилляции образцов, сюжетных ходов / переворотов / настроек персонажей из библиотеки материалов, трендов жанров и данных платформ из отчётов исследований письма, популярных элементов, найденных сетевым поиском). Например, варианты V4 (основная настройка) могут найти в разборах конкурентов такие вариации, как «откат во времени» и «прививка памяти»; V8 (профессиональный срез) можно «выкопать» из библиотеки материалов — свежие варианты вроде «диспетчер скорой помощи», «хозяин букинистической лавки», «водитель такси онлайн». **Чем богаче и ближе к реальным рыночным данным библиотека вариантов переменных, тем конкурентоспособнее концепции, отобранные PK.**

#### Общее правило PK: принцип «пороха»

> PK фабрики концепций — не вялая оценка в духе «ты хорош, я хорош, все хороши», а **яростная творческая схватка гладиаторов**. Каждый раунд — «допрос, бьющий в сердце»: спрашивается не «хороша ли эта идея», а «на каком основании эта идея в первые десять глав прибьёт читателя к креслу и заставит редактора хлопнуть по столу и добавить подпись».
>
> **Железные правила PK**:
> - Для каждой кандидатной концепции сначала нужно найти её «смертельное место», и лишь потом говорить о достоинствах — **сначала негатив, затем позитивное подкрепление**
> - «Нормально», «неплохо», «сойдёт» = **сразу понижение**. Только «это просто бомба» и «это очень сильное направление» достойны продвижения
> - Судьи в каждом раунде обязаны играть три лица: **придирчивый редактор** (можно ли это подписать), **вспыльчивый читатель** (стоит ли за это платить и следить), **хладнокровный оператор** (выдержит ли это 200 глав)
> - Если после раунда PK не было ссор, никто не хлопал по столу, никто не сказал «я не согласен» — значит, огня недостаточно, начинать заново

#### 6 последовательных раундов PK

##### Нулевой раунд: ядерный взрыв идей (R0 · новое)

> **Взрыв с самого начала**. До того как все кандидатные концепции войдут в проверку совместимости, сначала проводится один раунд крайнего «стресс-теста идеи». Этот раунд не отсеивает концепции, но обязательно должен пометить каждой концепции «уровень идеи» и «смертельную слабость».

**Три допроса, бьющих в сердце**:

1. **«Что в этом такого особенного?»** — Какова «незаменимость» этой концепции? Говоря проще: если эту идею возьмёт писать другой человек, убрав название книги и имена персонажей, сможет ли читатель по самой истории узнать, что «это та самая особенная книга»? Если нет — **у вашей идеи ещё нет настоящей личности**.
2. **«Почему это не кусок дерьма?»** — Это допрос в форме самоатаки. Не защищайте свою идею, активно подумайте о самой плохой её возможности: не превратится ли она в безликий шаблон «перемещение + система + удар по лицу»? Не заставит ли читателя уже в главе 3 подумать «а, опять эта схема»? Если вы сами не находите её смертельной слабости, значит, вы ещё не по-настоящему её рассматривали.
3. **«Как вас обругает тот, кто уже написал в этом жанре, увидев эту идею?»** — Взгляните с позиции дочитанных вами хитов того же жанра: автор той книги, увидев вашу идею, подумает «чем-то интересно» или «ещё один примазывающийся к популярности»? Ответ на этот вопрос прямо определяет, **осваиваете ли вы новые земли или подбираете чужое**.

**Определение уровня идеи**:

| Уровень | Метка | Критерии определения | Действие R0 |
| --- | --- | --- | --- |
| **Уровень S** | «Ничего себе, и так можно?» | Все три допроса пройдены, и как минимум на один ответ судьи удивлены | Пометка ⭐ + прямое направление в R3 (пропуск R1–R2) |
| **Уровень A** | Это очень сильное направление | Все три допроса получили разумные ответы, явной смертельной слабости нет | Нормальный вход в R1 |
| **Уровень B** | Направление верное, но недостаточно | Ответ на один из допросов заметно пустоват | Входит в R1 с пометкой слабости, в R1–R2 приоритетно исправить эту слабость |
| **Уровень C** | Слишком гладко, слишком гладко | Как минимум на один допрос совсем нельзя ответить — на «что в этом такого особенного?» нечего сказать, или на «почему это не кусок дерьма» не удаётся найти ни одной слабости | **Прямое исключение**. Если идея не может сказать даже «в чём особенность», дальнейшее PK не имеет смысла |

**Суть R0**: чем постепенно обнаруживать в последующих раундах, что концепция посредственна, лучше с первой секунды вонзить самый жёсткий нож. **Хорошая идея выдерживает самую злобную самоатаку. Не выдерживающая — чем раньше умрёт, тем лучше.**

Процент исключения около 10–15% (прямое отсеивание концепций уровня C). Но важнее то, что — **каждая выжившая концепция помечена смертельной слабостью**, и последующие R1–R4 обязаны лицом к лицу столкнуться с этими слабостями для исправления или защиты.

##### Первый раунд: удушение совместимостью (R1)

> R1 прошлой версии назывался «фильтрация совместимости». R1 этой версии называется «удушение совместимостью». Фильтрация — лишь отбор, удушение — **ножом логики отсекаются все сочетания, которые «на вид вроде допустимы, а на деле не держатся»**.

**Четыре смертельных удара ножом**:

| Лезвие | Допрос, бьющий в сердце | Сценарий единоличного вето |
| --- | --- | --- |
| Компенсация и эмоциональный конфликт | «Дочитав эту главу, читатель в итоге получил 爽 или сладость? Если нужно и то и другое, как в вашей главе распределяется объём?» | «Героиня в контратаке» + «сладкая проза» без чёткого плана разделения на этапы «мучительно-爽 чередование» → исключить |
| Отношения персонажей и эмоциональный конфликт | «В истории преданного человека в первых трёх главах они сразу устраивают сладкое взаимодействие — это то, что хочет видеть читатель?» | «Погоня за женой на пепелище» + «сладкая проза» без предварительной стадии «мучения» минимум в 5 глав → исключить |
| Самосогласованность настроек и жанра | «Системная панель в реалистичном офисе — редактор, открыв главу 3, видит, что герой проверяет панель атрибутов, о чём он подумает?» | «Система» + чисто реалистичный жанр без разумного механизма «скрытия / объяснения» → исключить |
| Разрыв профессии и сюжета | «Основная работа судмедэксперта — вскрытие и отчёты, а вы заставляете его заниматься земледелием — могут ли эти две вещи одновременно происходить в одной главе без фальши?» | Между методологией профессии и способом продвижения сюжета нет никаких точек пересечения → исключить |

**Критерии судей, хлопающих по столу**:
- ✅ **Решительно может продвигаться**: все четыре пункта пройдены, и как минимум по одному пункту в защите есть блестящая деталь, заставляющая подумать «это продумано неплохо»
- ⚠️ **Ожидание, нужен ещё удар**: один пункт не пройден, но есть чёткий план заплатки (например, «брак с последующей любовью + сладкая» спроектировано как «сначала поженились, потом полюбили, первые 5 глав пишем холодную войну, с 6-й главы отношения начинают оттаивать») → отметить план заплатки и продвинуть
- ❌ **Красная карточка — удаление**: любой пункт не пройден и план заплатки тоже неубедителен → прямое исключение. **Нельзя говорить „пока оставим, потом посмотрим“**

Процент исключения около 30–40%.

##### Второй раунд: тест концентрации инноваций (R2 · сильно усилен)

> R2 прошлой версии назывался «проверка насыщенности трека» — слишком мягко. R2 этой версии называется «тест концентрации инноваций». Смотрится не только «делали ли уже этот паттерн», но и **„чем ваша версия новее, сильнее существующих, на каком основании читатель выбирает вас, а не тех трёх“**. Наличие конкурентов на рынке у идеи не страшно, страшно **не уметь сказать, на каком основании читатель перевернёт вашу карту, а не карту конкурента**.

**Три обязательных вопроса**:

**① Сопоставление с конкурентами**: «Вы говорите, что у вашей идеи есть дифференциация — перечислите 3 произведения на целевой платформе за последние 12 месяцев, с пересечением ≥70% по основному сочетанию паттернов этой концепции, и затем по пунктам скажите, в каких измерениях ваша концепция сильнее побуждает читателя кликнуть, чем они».

> Если не удаётся найти 3 произведения — значит, исследование трека недостаточно; понизить «уверенность суждения о треке» этого кандидата, отметить как «нужно дополнительное исследование» и ожидать продвижения.
> Если удалось найти 3 произведения, но не удаётся назвать как минимум 2 принципиальных отличия — **красная карточка — удаление**. Столкновение с конкурентами не страшно, самое смертельное — столкнуться и не иметь дифференциации.

**② Смещение читательских ожиданий**: «На сколько ваша концепция изменила читательские ожидания?»

| Степень смещения | Пояснение | Решение |
| --- | --- | --- |
| Уровень переворота | Прочитав первые три главы, читатель воскликнет «веб-романы можно писать и так?» | ✅ Прямое продвижение, пометка ядерного уровня |
| Уровень итерации | Читатель скажет «это сочетание интересно, раньше не видел» | ✅ Нормальное продвижение |
| Уровень микроподстройки | Читатель скажет «ну, эта настройка просто сменила оболочку» | ⚠️ Нужны доказательства дифференциации |
| Уровень копии | Читатель скажет «это же просто XXX под другим названием» | ❌ Красная карточка — удаление |

**③ Оценка барьера**: «Есть ли у вашей идеи барьер на уровне исполнения?»

- **Положительный барьер** (плюс): требуются особые профессиональные знания (например, судмедэксперт / криминалист / программирование / финансы), особые приёмы письма (например, многолинейное повествование / управление временной линией), особые ресурсы (например, полевое исследование / интервью с экспертами) — **барьер = легко имитируется = долгосрочная конкурентоспособность**
- **Отрицательный барьер** (минус): «если слог не слишком плох, написать может кто угодно» — **концепция без барьера в красном океане не проживёт и трёх глав**
- **Единоличное вето**: если идея проходит R3 (пространство компенсации) и R4 (коммерческая оценка), но «нет барьера» + «инновация уровня копии» — взгляд редактора: «подписывать вас лучше, чем ту уже вышедшую книгу не стоит» → **красная карточка — удаление**

Процент исключения около 25–35% (выше прежнего из-за добавленных смещения читательских ожиданий и оценки барьера).

##### Третий раунд: ядерная оценка компенсации (R3 · повышен)

> Оценка компенсации прошлой версии была формулой. Эта версия не только сохраняет количественную формулу, но и проводит **стресс-тест эмоций** — имитирует реальную реакцию читателя после прочтения первых трёх глав.

**Количественная формула** (сохранена):

```text
Пространство компенсации = исходная низкая позиция персонажа (1–10) × высота итогового подавления (1–10) × коэффициент читательского резонанса (0,8–1,2)
```

**Критерий прохождения** (сохранён): ≥60 баллов — продвижение, 40–59 — повторная оценка после повышения, <40 — исключение.

**Новое: тест эмоциональной имитации первых трёх глав**

Судьи по очереди играют целевого читателя и отвечают на следующие вопросы:

1. **Первые 500 знаков главы 1**: «Когда я дочитал до 500-го знака, меня зацепило или захотелось свайпнуть? Какое именно действие / какая фраза заставили меня читать дальше? Если нельзя найти конкретную фразу — значит, захват зачина недостаточно конкретен, недостаточно конкретен = недостаточно силён».
2. **Конец главы 1**: «Почему я должен открыть главу 2? „Хочу знать, что дальше“ или „всё равно нечем заняться“? Второе = сигнал исключения».
3. **Конец главы 3**: «Знаю ли я к этому моменту, что собирается делать герой? Если ещё не знаю — читатель бесплатной платформы уже свайпнул. Если знаю, но не жду — читатель платной платформы не откроет следующую главу».
4. **Ощутимость компенсации**: «В какой главе, в какой сцене „爽“, обещанное этой концепцией, впервые реализуется для читателя? Если не можете сказать — значит, обещание компенсации лишь лозунг, а не проектирование».

**Критерии судей, хлопающих по столу**:

- ✅ **Эмоциональная бомба**: имитация первых трёх глав полностью пройдена, и как минимум в одном месте у судей возникло желание «эту сцену я хочу видеть» → продвижение
- ⚠️ **Есть яма, которую можно заполнить**: один пункт не пройден, но структурного дефекта нет → пометить проблему и продвинуть
- ❌ **Пустая оболочка компенсации**: не пройдены два и более пункта, либо на 4-й вопрос совсем нельзя ответить → **красная карточка — удаление**

Процент исключения около 20–30%.

##### Четвёртый раунд: коммерческий песочный стол (R4 · замена)

> R4 прошлой версии назывался «многомерная коммерческая оценка» — статическое выставление баллов. Эта версия заменена на **«коммерческий песочный стол»** — имитируются реальная конкурентная среда и путь коммерциализации этой книги от открытия до 100 глав.

**Сценарии вывода** (судьи по очереди играют следующие роли):

**Сценарий 1: 30-секундная вычитка редактора (вес 40%)**

> «Я не смотрю на описание вашей концепции. Я посмотрел только название книги и аннотацию. За 30 секунд я должен принять решение: подписать или не подписать?»
>
> - Судья обязан за 30 секунд вынести суждение «подписать / не подписать / посмотреть ещё» и пояснить причину
> - Если за 30 секунд не удаётся ясно объяснить причину → по умолчанию понижение

**Сценарий 2: 3-секундное решение читателя в рейтинге (вес 30%)**

> «Ваша книга стоит в одном рейтинге категории в ряду конкурентов. Взгляд читателя скользит — почему название + аннотация вашей книги заставляют его остановиться, а не пролистнуть?»
>
> - Если судье нужно думать более 3 секунд, чтобы ответить на «почему кликнули именно вас» → снятие баллов
> - Если судья говорит «если бы я увидел это название в рейтинге, возможно, не кликнул бы» → **предупреждение о едином вето**

**Сценарий 3: держится ли на 50-й главе (вес 20%)**

> «Ваша концепция на главах 1–10 достаточна. Допустим, написано уже до главы 50 — вы сменили как минимум два двигателя? Когда закончилось топливо первого двигателя? Когда подключился второй? Как выглядит третий?»
>
> - Умеет чётко назвать «план смены двигателей» → балл ≥7
> - Может сказать лишь пустое «держимся на основной линии» или «на росте персонажа» → балл ≤5
> - Совсем не думал об этом вопросе → **предупреждение о едином вето**

**Сценарий 4: где ваша точка распространения (вес 10%)**

> «Есть ли в этой книге сцена / реплика / настройка отношений, подходящая для нарезки коротких видео, распространения скриншотов или спора читателей в разделе рецензий? Если совсем нет — у вашего произведения в эпоху соцсетей 2026 года нет гена самораспространения».

**Итоговое решение**:

- Общий балл имитации ≥ 7,5 → входит в финальный короткий список
- 6,0–7,4 → входит в короткий список с пометкой «можно оптимизировать»
- < 6,0 → исключение
- Если в любом сценарии появляется «предупреждение о едином вето» и группа судей не может прийти к единой защите → прямое исключение

Процент исключения около 30–40%.

##### Пятый раунд: убийственная фраза (R5 · финал)

> Четыре предыдущих раунда отсекли минимум 70% кандидатных концепций. Теперь в коротком списке остаётся 2–5, каждая по отдельности — хорошая идея. Но **чемпион может быть только один**. В финале оружие одно: **одна фраза**.

**Тест убийственной фразы**:

1. Сжать каждую кандидатную концепцию в **одну фразу (≤50 знаков)** — это должен быть человеческий язык, «заставляющий захотеть кликнуть», а не резюме жанра
2. Дать эту фразу послушать трём типам людей:
   - **Человек, не знающий этого жанра** (имитация случайного читателя): если собеседник уточняет «и что дальше?» → +2 балла. Если «а» → 0 баллов
   - **Человек, знающий этот жанр** (имитация основного читателя): если собеседник говорит «этот ракурс интересен» → +2 балла. Если «это же просто XXX» → −1 балл
   - **Редактор / опытный автор** (имитация лица, принимающего решение о подписании): если собеседник говорит «это годится» → +3 балла. Если «посмотрим ещё» → 0 баллов. Если «не очень» → −3 балла
3. Набравший наибольшую сумму баллов — **концепция-чемпион**
4. Если у лидеров одинаковое число баллов → побеждает та, у которой выше балл песочного стола R4

**Проверка чемпиона на отсутствие сожалений**:

- [ ] Если сейчас «первое место» заставляет вас самого сказать «а может, лучше посмотреть на второе» — значит, первое место не вызывает у вас самих уверенности, **фабрика концепций не дошла до конца, нужно расширить варианты переменных и заново сгенерировать пул кандидатов**
- [ ] Если «второе место» заметно сильнее «первого» по какому-то измерению (например, выше балл R4, но фраза R5 не написана) → **допускается объединить карточку концепции второго места с аннотацией первого места, оптимизировать и выдать в качестве чемпиона**

> **Расстояние между „а“ и „и что дальше?“ — это расстояние между бестселлером и провалом.**

### Внешнее ИИ-вспомогательное PK (режим слепой оценки внешнего ума)

> **Зачем внешнее PK?** Кандидатные концепции, сгенерированные одним ИИ, а затем оцененные тем же ИИ в роли судьи, легко попадают в «мыслительное близкородственное скрещивание» — предпочтения судьи к кандидатным концепциям и логические предпочтения при генерации высоко согласованы, не хватает силы удара внешнего ракурса. Привлечение внешнего ИИ для независимой оценки равно приглашению ещё одного редактора, чтобы хлопнуть по столу.
>
> **Когда использовать внешнее PK?** ① Внутренние R0–R5 этого ИИ уже прогнаны один раз, но неуверенность, действительно ли чемпион сильнейший; ② хочется проверить объективность вывода PK этого ИИ; ③ в пуле кандидатов 2–3 концепции набрали близкие баллы во внутреннем PK, нужен внешний ракурс для выхода из тупика.
>
> **Основной принцип внешнего PK**: внешний ИИ получает только список кандидатных концепций и правила PK, **не знает** результатов и склонностей внутреннего PK этого ИИ — гарантия независимости слепой оценки.

#### Порядок операций внешнего PK

1. В этом ИИ сначала завершить **генерацию пула кандидатов + нулевой раунд ядерного взрыва идей (R0)** фабрики концепций (поскольку ядерный взрыв идей — уникальная методология этого Skill, внешний ИИ не обязательно с ней справится)
2. Пользователь отдаёт команду **«сгенерируй промпт внешнего PK»** или **«экспортируй пул кандидатов для внешнего PK»**
3. Этот ИИ упаковывает список кандидатных концепций + правила внешнего PK в один **самодостаточный промпт** (читаемый текст, не зависящий от контекста этого Skill)
4. Пользователь копирует этот промпт во внешний ИИ и запускает
5. Внешний ИИ выполняет процесс PK R1–R5, выводит выбранного им чемпиона и причины
6. Пользователь возвращается с результатом внешнего ИИ в этот диалог и сообщает, кто победил
7. Этот ИИ перекрёстно сопоставляет результат внешнего PK с результатом внутреннего PK и окончательно фиксирует концепцию-чемпиона

#### Нормы генерации промпта внешнего PK

Когда пользователь просит внешнее PK, обязательно сгенерировать **самодостаточный промпт, который можно прямо скопировать и выполнить в другом ИИ**. Напрямую использовать `references/шаблон-вывода-внешней-оценки-pk.md` как скелет шаблона для заполнения.

Правила заполнения:

- **Задача оценки**: напрямую применить «измерения оценки» и «требования к формату вывода» из шаблона. Внешнему ИИ нужна лишь **быстрая оценка по 6 измерениям** (определение жанра / цепкость с первого взгляда / вживание в героя / долговременная выносливость / главный риск / рекомендации по улучшению), не нужно повторять полный процесс R0–R5 этого Skill — это методология внутреннего PK, у внешнего ИИ нет такого же контекста и предварительных данных, эффективно выполнить её он не может
- **Кандидатные концепции**: перечислить каждого кандидата в табличном формате шаблона (замысел / «фишка» одной фразой / целевая платформа / первая точка новизны / рычаг героя / основная эмоциональная ось / долгосрочная структура)
- **Дополнительная информация**: справка по трендам, сопоставление с конкурентами, целевой читатель
- **Не** подмешивать в промпт внешнего PK метки R0 внутреннего PK или причины победы — внешнему ИИ нужна **независимость слепой оценки**

#### Обработка возврата результата внешнего PK

Когда пользователь возвращается с результатом внешнего PK:

1. **Прочитать отчёт PK внешнего ИИ**, особенно его выбор чемпиона и ключевые определения
2. **Перекрёстно сопоставить с результатом внутреннего PK этого ИИ**:
   - Внутренний и внешний чемпионы совпадают → двойная уверенность, сразу входить в этап углубления рамки
   - Внутренний и внешний чемпионы не совпадают → проанализировать причину расхождения (разные предпочтения весов R4? или разница версий фразы R5?)
   - Если расхождение примиримо (например, внешний чемпион во внутреннем PK — второе место, и причины убедительны) → **заново назначить чемпиона по оценке внешнего ИИ**
   - Если расхождение непримиримо (причины обеих сторон состоятельны) → показать пользователю причины двух чемпионов, попросить пользователя принять окончательное решение
3. Окончательно определённую концепцию-чемпиона **записать обратно в `故事框架/` по правилу сохранения результатов**
4. Если внешнее PK дало ценные замечания по оценке (например, у какой-то исключённой концепции есть особая изюминка), синхронно записать в архивный файл `概念库/`

### Формат результатов фабрики концепций

После завершения PK выдаётся **трёхслойная карточка концепции**.

#### Правила сохранения результатов (обязательно)

Все результаты фабрики концепций **нельзя оставлять только в диалоге** — они обязательно записываются обратно в файлы. Конкретные правила сохранения:

| Результат | Место сохранения | Нормы именования файла | Пояснение |
| --- | --- | --- | --- |
| **Карточка решающей концепции** (обязательно) | `{корень проекта}/故事框架/` | `{жанр}_{ключевое слово ядра концепции в одну фразу}.md` | Включает полное содержание трёхслойной карточки концепции, **обязательно создаётся после выполнения фабрики концепций** |
| **Архив всего процесса PK** (необязательно) | `{корень проекта}/故事框架/` | `{жанр}_{ключевое слово концепции}_PK记录.md` | Включает полный список пула кандидатов, ситуацию отсева и детали баллов по каждому раунду |
| **Архив библиотеки концепций** (обязательно) | `{корень проекта}/概念库/` | `{жанр}_{платформа}_{дата}.md` | Кандидатные концепции, отсеянные PK, архивируются в этот каталог по классификации жанр × платформа для повторного использования между проектами |

> `故事框架/` — каталог верхнего уровня в корне проекта (на одном уровне с `素材库/`, `调研报告/`, `исследования-письма/`). Если не существует, создаётся автоматически. Карточка решающей концепции — **единственный обязательный к записи** результат; даже если PK-записи и архив библиотеки концепций пропущены, запись карточки решающей концепции пропускать нельзя.

#### Формат файла карточки решающей концепции

```text
# {Концепция в одну фразу}

> {Аннотация в один абзац}

## Карточка причин победы

- Уровень идеи R0 {S/A/B} + смертельная слабость {одной фразой}
- Удушение совместимостью R1 {результаты по четырём пунктам} + решение судей {решительное продвижение / ожидание нового удара / красная карточка}
- Концентрация инноваций R2 {результат сопоставления с конкурентами} + {уровень смещения читательских ожиданий} + {определение барьера}
- Ядерная компенсация R3 {количественный балл} + {результат эмоциональной имитации первых трёх глав}
- Коммерческий песочный стол R4 {общий балл вывода} + {самый сильный из четырёх сценариев}
- Убийственная фраза R5 {сумма баллов трёх типов людей} + {прямая цитата собеседников}
```

**Пример вывода** (записывается в `故事框架/都市悬疑_重生法医查悬案.md`):

> **Концепция в одну фразу** (30 знаков):
> Переродившийся судмедэксперт возвращается в время до убийств и обнаруживает, что каждое тело заставляет его заново расследовать то давнее нераскрытое дело.
>
> **Аннотация в один абзац** (120 знаков):
> Переродившись в год выпуска, Гу Шэнь по собственной инициативе просится в самый непопулярный судебно-медицинский отдел уездного управления. Коллеги думают, что он хочет «лечь и ничего не делать», и только он знает — в ближайшие три года в этом маленьком городе произойдут семь, казалось бы, не связанных убийств, и в заключении вскрытия каждого скрыта одна и та же нить: она указывает на дело двадцатилетней давности, наспех закрытое с ложной квалификацией. Тогда он был ребёнком, а теперь он судмедэксперт. Трупы не лгут, но живые — лгут.
>
> **Карточка причин победы**:
>
> - Уровень идеи R0 ⭐ уровень S, смертельная слабость: «В жанре судмедэкспертизы нужен прочный профессиональный барьер знаний, на уровне настроек обязательно добавить подробные рабочие процессы судмедэксперта»
> - Удушение совместимостью R1 ✅ все четыре пункта пройдены, блестящая деталь по решению судей: «Три переменные — перерождение + профессиональный срез + раскрытие загадок — естественно сцеплены, не выглядят склейкой»
> - Концентрация инноваций R2 ⭐ уровень итерации; сопоставление с конкурентами: комбинация «перерождённый судмедэксперт» на Qidian за последние 12 месяцев — лишь 2 книги, из которых 1 тяготеет к линии чувств, 1 — к групповому портрету уголовного розыска; эта концепция, сфокусированная на «движении по уликам от трупов + ракурс одного судмедэксперта», — пустое место дифференциации; барьер: профессиональные знания судмедэксперта — положительный барьер
> - Ядерная компенсация R3 количественно 8,2 балла; имитация первых трёх глав: хук «обнаружение первого трупа» на 500 знаках главы 1 состоятелен, конец главы 3 «схема нитей семи убийств» уже сформировал ожидание чтения дальше
> - Коммерческий песочный стол R4 8,6 балла (30-секундная вычитка редактора пройдена 9/10, 3-секундное решение в рейтинге 9/10, план смены двигателей к 50 главам ясен 8/10, потенциал мема «каждый труп оставляет координату» как точки распространения 7/10)
> - Убийственная фраза R5 суммарно +7 баллов (случайный читатель «и что дальше?» +2, основной читатель «открывать саспенс с ракурса судмедэксперта интересно» +2, редактор «такой ракурс годится» +3)

### Связь фабрики концепций с существующей рамкой

Выход фабрики концепций — не конечная точка, а **вход существующего анализа рамки**:

```text
Фабрика концепций → выдаёт карточку решающей концепции (одна фраза + аннотация в один абзац + причины победы)
    ↓ даёт «направленческое» ограничение
【Слой формулировок платформы】 → детальная калибровка существующей рамкой (таблица проверки позиционирования платформы и обещания желания читать дальше)
【Слой рычагов „фишки“】 → детальное проектирование существующей рамкой (четыре вопроса сохранения точности)
【Слой реальной цены】 → детальное сохранение существующей рамкой (матрица якорей)
【Слой инновационного сочетания】 → детальное развёртывание существующей рамкой (шаблон записи инновационного сочетания)
    ↓
Проектирование общего плана
```

То есть: **фабрика концепций определяет „в какую сторону идти“, существующая рамка определяет „как проложить этот путь“**.

### Повторное использование библиотеки концепций между проектами

Кандидатные концепции, отсеянные PK, не следует выбрасывать — из 30–80 кандидатов, порождённых каждым PK, после отбора остаётся немало концепций «сойдёт, но не победила».

Рекомендуется в корне проекта создать `概念库/`, архивируя по классификации жанр × платформа кандидатные концепции и результаты оценки каждого PK. При необходимости открыть новую книгу сначала просмотреть в библиотеке концепций историю кандидатов того же жанра × платформы, чтобы не генерировать заново повторы — также можно на основе старой концепции делать микроитерации «замена одной переменной».

## Порядок выполнения (два шага)

### Процесс по умолчанию: фабрика концепций → углубление рамки

**Шаг 1: PK фабрики концепций**

1. Загрузить источники вдохновения (минимум три) → обогатить библиотеку вариантов переменных
2. Выбрать предварительные ограничения V1 (жанр) + V2 (платформа)
3. Комбинаторикой V3–V8 сгенерировать пул кандидатов (≥30)
4. Выбрать режим PK:
   - **Внутреннее PK** (по умолчанию): выполнить весь процесс R0–R5 в этом ИИ
   - **Внешнее PK** (необязательно): по требованию пользователя этот ИИ завершает генерацию пула кандидатов + ядерный взрыв идей R0, экспортирует промпт внешнего PK, пользователь завершает R1–R5 во внешнем ИИ
5. Выдать карточку решающей концепции **и записать обратно в `故事框架/`**
6. Кандидатные концепции, отсеянные PK, архивировать в `概念库/`
7. Перенести решающую концепцию на шаг 2

**Шаг 2: углубление рамки**

1. Вокруг решающей концепции сначала с помощью «метода калибровки по четырём вопросам» из правил сохранения точности дать резюме позиционирования
2. Затем чётко определить: основные формулировки платформы, рычаг героя, источник матрицы, реальные якоря, якоря цены, инновационное сочетание
3. Затем с помощью таблицы проверки позиционирования платформы, матрицы якорей, обещания ритмической плотности и других модулей слой за слоем проверить на искажения
4. В конце **синхронно обновить** углублённые выводы позиционирования **обратно в соответствующий файл карточки концепции в `故事框架/`**

### Ускоренный процесс с пропуском фабрики концепций

При выполнении любого из условий в «исключениях, когда можно пропустить фабрику концепций»:

1. Прочитать существующие аннотацию, общий план, связанные настройки и входные файлы персонажей произведения.
2. Сначала с помощью «метода калибровки по четырём вопросам» из правил сохранения точности дать резюме позиционирования.
3. Затем чётко определить: основные формулировки платформы, рычаг героя, источник матрицы, реальные якоря, якоря цены, инновационное сочетание.
4. Затем таблицей проверки позиционирования платформы и матрицей якорей проверить на искажения.
5. При выдаче результата в первую очередь давать текст рамки позиционирования, который можно напрямую записать обратно в файл карточки концепции `故事框架/`.
   - **Выводы позиционирования обязательно записываются обратно в `故事框架/`**, формат имени файла `{жанр}_{ключевое слово основной «фишки»}.md`.
   - Если в `故事框架/` уже есть карточка концепции с таким именем — перекрыть обновлением, сохраняя согласованность с текущими выводами позиционирования.

## Формулировки вывода по умолчанию

- По умолчанию выдавать текст рамки позиционирования, который можно напрямую записать обратно в файл карточки концепции `故事框架/`.
- По умолчанию одновременно давать основную «фишку», формулировки платформы, реальные якоря и якоря цены.
- **Весь вывод обязательно записывается обратно в соответствующие файлы каталога `故事框架/`**, нельзя оставлять только в диалоге.

## Минимальная поставка

- Умеет чётко сказать основную «фишку», основные формулировки платформы и рычаг героя.
- Умеет указать реальные якоря, якоря цены и инновационное сочетание.
- Умеет объяснить, почему эту книгу стоит читать дальше.
- **Эти выводы уже записаны обратно в файл карточки концепции в `故事框架/`**.

## Жёсткие правила

- Запрещены расплывчатые формулировки платформы, в итоге превращающиеся в «каждой платформы понемногу».
- Запрещено, чтобы у героя были лишь титулы, но не было методологического рычага.
- Запрещено, чтобы механизм / сверхъестественное было всемогущим инструментом без условий срабатывания, цены и границ.
- Запрещено, чтобы реалистичная тема оставалась лишь тематическим словом, не входя в цепочку событий, цепочку улик и цену для персонажей.
- Запрещено, чтобы «фишка» оставалась на концептуальном уровне, не входя в аннотацию, зачин, общий план и последующий основной текст.
- При позиционировании на Qidian или без указания платформы запрещено писать без оценки рынка жанра; как минимум нужно ответить: насколько активен этот жанр в TOP50 рейтинга Qidian сейчас, есть ли признаки выхода из моды, есть ли окно платформенной поддержки, обойдены ли явно вышедшие из моды жанры.
- Формула инновационного слияния (A+B) обязана быть конкретной до уровня читательского опыта, нельзя писать расплывчатые сочетания вроде «сюаньхуань + саспенс», «город + НФ»; нужно прописать, какое читательское ощущение, которого раньше не было в этом же треке, возникло после слияния.
- Если данные по общему рынку жанров показывают, что трек уже высоко «внутренне конкурентен» (например, традиционный поток расторгнутой помолвки, поток отметок о визитах, безмозглая система), рамка позиционирования обязана явно доказать, почему эта книга сможет создать дифференциацию в «внутренне конкурентном» треке; если доказать не удаётся, признаётся незавершённой.
- Запрещено давать только метку жанра без портрета читателя; запрещено давать только лозунг «фишки» без сценария платёжного триггера.
- **Адаптация к базовому уровню удержания**: на этапе жанрового позиционирования обязательно предварительно оценить базовый уровень удержания текущей темы на целевой платформе (по `CommonSkills/исследования-письма/网文留存模型.md` §3 «Различия базового уровня удержания на платформах»). Если естественная плотность стимуляции жанра ниже платформенной нижней границы удержания, в позиционировании обязательно пояснить, чем компенсируется (например, более плотным проектированием наград, более сильным вживанием).
