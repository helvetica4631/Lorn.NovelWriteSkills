# Шаблон вывода для внешней оценки PK

> **Назначение**: после того как «фабрика концепций» сгенерировала концепты-кандидаты, выдать самодостаточную инструкцию, которую можно напрямую скопировать внешнему ИИ (ChatGPT/Claude/DeepSeek и др.) для независимой оценки.
> **Основной принцип**: у внешнего ИИ нет контекста этого проекта, поэтому файл должен быть самодостаточным — роль, задача оценки, концепты-кандидаты и формат вывода записаны в одном файле.
> **Рабочий процесс**: пользователь копирует весь текст → вставляет внешнему ИИ → внешний ИИ возвращает оценку → пользователь вставляет её обратно в этот диалог → этот Agent итерирует направление по обратной связи.

## 1. Задача оценки

Сыграйте роль опытного редактора веб-романов, специализирующегося на треке 【{{тематика}}】. Ваша задача — оценить коммерческий потенциал приведённых ниже концептов-кандидатов.

### Критерии оценки (по приоритету)
1. **Можно ли эту книгу продать** (подписание контракта / прохождение рецензии / потенциал монетизации)
2. **Будут ли читатели следить** (удержание в чтении / дочитываемость / конверсия в оплату)
3. **Можно ли писать на длинной дистанции** (сколько знаков выдержит без развала / повторов / воды)

### Измерения оценки
1. **Определение тематики**: что это за трек? Какова текущая «горячесть» трека и насыщенность?
2. **Сила первого взгляда**: нажмёт ли читатель, увидев аннотацию / первые 3 главы? Почему?
3. **Вовлечённость в главного героя**: способны ли затруднение / статус / цель героя вызвать сочувствие у целевого читателя?
4. **Долговечность на длинной дистанции**: сколько знаков выдержит эта задумка / этот паттерн (套路) без развала? Чем держится середина?
5. **Главная точка риска**: где эта книга легче всего потерпит крах? (Приоритет — язвительность, не щадите)
6. **Предложения по улучшению**: как минимум одно конкретное, исполнимое направление улучшения.

### Требования к формату вывода

Верните результат оценки в следующем формате JSON. Если оцениваются несколько концептов-кандидатов, выводите для каждого отдельный набор.

## Ограничения при использовании

- Каждый внешний PK-файл оценивает только разные направления-кандидаты в рамках **одного и того же актива мира** (общие установки / персонажи / мир); нельзя ставить на PK полностью не связанные концепты
- Рекомендуется **3–5** концептов-кандидатов: при слишком малом числе нет сравнения, при слишком большом внешний ИИ легко что-то упускает
- Объём текста концептов-кандидатов не должен превышать контекстное окно внешнего ИИ (рекомендуется суммарно < 4000 знаков)
- Требование формата JSON нужно для того, чтобы этому Agent было удобно разбирать и сравнивать; если внешний ИИ привык выводить таблицами или Markdown, формат не-JSON тоже приемлем — достаточно чёткой структуры
- Выводы внешнего PK служат лишь ориентиром направления и не заменяют решений внутренней рецензии
