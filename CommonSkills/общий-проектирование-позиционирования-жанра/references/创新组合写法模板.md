# Шаблон записи инновационных комбинаций

## Слой источника комбинации (новое)

- `Слой профессионального среза`: почему к этой теме должна подступаться именно эта профессия / этот статус.
- `Слой социального давления`: почему эта аномалия или этот конфликт могут вырасти только в такой городской / институциональной щели.
- `Слой запуска правил`: каким способом главный герой продвигается, когда берётся за это, и какую цену платит.

```markdown
## Описание инновационной комбинации

- Профессиональный срез:
- Источник социального давления:
- Материнский источник:
- Способ запуска правил:

### Логика комбинации
1. Почему именно эта профессия легче всего сталкивается с такой аномалией:
2. Почему такая аномалия может вырасти только в такой городской / институциональной щели:
3. Почему главный герой обязан платить цену, когда с ней разбирается:
4. Главное отличие этой комбинации от распространённых шаблонов:
```

## Минимальный инновационный артефакт (новое)

```markdown
【Слой профессионального среза】
【Слой социального давления】
【Слой запуска правил】
【Текущая оценка】Green / Yellow / Red
```

## Вердикт об инновации Green / Yellow / Red (новое)

- `Green`: три слоя — профессиональный срез, социальное давление и запуск правил — сцеплены, инновация не является пустым ассорти.
- `Yellow`: идея комбинации есть, но какой-то один слой пока абстрактен, до устойчивой «подпитки» остаётся один шаг.
- `Red`: просто свалены в кучу несколько тегов, не сложился по-настоящему уникальный двигатель постоянного конфликта.
