# Колонка Tencent: дополнительные правила соответствия стиля письма и платформы

Область применения: одна экосистема, много платформ — платные длинные платформы (Qidian / Zongheng и др.)

Источник: 《嘿，编辑，你跟我说说，为啥我的书没人看啊》 («Эй, редактор, скажи-ка, почему мою книгу никто не читает?»)
Автор: «Помощник писателя» (круглый стол нескольких редакторов: Мумянь / Бэйхэ / Епао / Хую / Хуйхуй / Сунлу / Сюнмао / Синчэнь / Цилинь / Цинтянь / Тан Юань / Шуйсин)
Прочтений: 380 тыс.

## Правило P0: стиль письма должен соответствовать сайту публикации

**Основной путь диагностики (редактор Сунлу):**
- Сначала проверьте: соответствует ли стиль письма предпочтениям читателей сайта публикации?
- Литературный, зрелый стиль на сайте текстов 爽 = естественный недостаток; слабые результаты — это нормально
- Не пишите в неверном стиле на неверной платформе; либо меняйте стиль, либо меняйте платформу — одно из двух

**Конкретный порядок диагностики (редактор Синчэнь):**
1. Проверьте, соответствует ли стиль письма сайту
2. Проверьте название + аннотацию + начало (триада первого впечатления)
3. Сравнительный анализ с хитами продаж того же типа

## Правило P0: чек-лист самопроверки при плохих результатах (консенсус нескольких редакторов)

| Пункт самопроверки | Пояснение |
|--------|------|
| Стабильные обновления | Задача номер один, подчёркивают почти все редакторы |
| Соответствие стиля письма сайту | Несоответствие — естественный недостаток |
| Название + аннотация + начало | Первое впечатление, больше всего влияет на клики |
| Достаточно ли точек 爽 | Разумна ли сюжетная схема, правильно ли выдержаны точки 爽 |
| Больше читать «горячие» книги / хиты продаж | Просматривать рейтинги, «горячие» книги, «красные» книги, учиться на успешных примерах |

---

## Правило P0: трёхшаговая формула повышения качества

**Больше читать + больше писать + больше подводить итоги**

- Больше читать: просматривать рейтинги, «горячие» книги, «красные» книги (хиты продаж)
- Больше писать: упорствовать; слабые результаты новичка — это нормально, количество обменивается на качество
- Больше подводить итоги: переход от чтения книг к размышлению; «Не бывает успешных людей, не умеющих подводить итоги, бывают лишь неудачники, которые раз за разом падают на одном месте»

---

## Правило P0: суждение перед сопоставлением стиля платформы

- После определения тематики / позиционирования стиля сначала подтвердите, совпадают ли предпочтения читателей целевой платформы
- Если популярная тематика не соответствует стилю вашей книги, приоритетно рекомендуется писать популярную тематику (рекомендация редактора Сунлу)
- Нельзя выкладывать книгу своего особого стиля на платформе с малой читательской базой, а потом жаловаться, что нет читателей
