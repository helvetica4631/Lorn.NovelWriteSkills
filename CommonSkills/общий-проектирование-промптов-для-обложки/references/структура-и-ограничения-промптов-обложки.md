# Структура и ограничения промпта обложки

## Рекомендуемая структура

1. Основной объект: кто / что в первом фокусе.
2. Сцена: пространство, погода, время или атмосфера опасности.
3. Композиция: крупный план / по пояс / диагональ / центральный фокус и т. п.
4. Гамма: основной цвет, контрастный цвет, направление света.
5. Стиль: реализм, иллюстрация, кинематографичность, «госстиль» (国潮), зарубежный коммерческий и т. п.
6. Резерв зоны текста: не загораживать зону заголовка наглухо.

## Правила входа

### Обязательный вход

- `platform`: целевая платформа
- `title`: название книги, которое нужно показать на обложке; несегментированный роман всегда использует целевое название романа для публикации, роман по частям — целевое название соответствующей части

### Необязательный вход

- `genre`
- `hook`
- `theme`
- `protagonist`
- `mustInclude`
- `mustAvoid`
- `plannedText`
- `styleBias`
- `variants` (по умолчанию `2`)

## Правила выбора названия книги (обязательно)

- `title` — не любое общее название книги, внутреннее рабочее название или родительское название серии, встречающееся в контексте, а **главный заголовок, который реально попадает на обложку**.
- Несегментированный роман: `title` всегда использует целевое название романа для публикации.
- Роман по частям: `title` всегда использует целевое название соответствующей части.
- Если у одной и той же книги одновременно есть общее название, название части и несколько платформенных названий для публикации, в приоритете название, реально используемое для публикации на целевой платформе в этот раз; нельзя ошибочно ставить общее название на обложку части.

### Нормализация псевдонимов платформ

- `起点` / `起点中文网` / `Qidian`
- `番茄` / `番茄小说` / `番茄小说网`
- `知乎` / `知乎盐选` / `盐选`
- `豆瓣` / `豆瓣阅读`
- `微信` / `微信订阅号` / `公众号`
- `百度百家号` / `百家号` / `百度号`
- `小红书` / `rednote` / `RED`
- `B站` / `哔哩哔哩` / `bilibili`
- `新浪微博` / `微博` / `weibo`
- `WebNovel` / `webnovel`
- `GoodNovel` / `Goodnovel`
- `My Fiction` / `MyFiction` / `my fiction`

## Контекст, который нужно прочитать в первую очередь

Информацию о произведении в первую очередь извлекать из следующих мест:

1. `小说简介/`
2. `小说大纲/`
3. `小说正文/`
4. `故事设定/`
5. `人物传记/`

Если рабочее пространство не позволяет определить конкретную историю, можно сделать консервативное направление обложки на основе **целевого названия для публикации + портрета читателя платформы**, но обязательно явно указать основание вывода.

## Ключевые шаги размышления

1. Определить, что больше любит читатель этой платформы: жёсткие настройки мира / сильное ощущение аномалии конфликта / реалистичность документальности / литературные недосказанности / эмоциональные отношения и опасные персонажи
2. Выделить три ядра:
   - **визуальное ядро**
   - **эмоциональное ядро**
   - **ядро узнавания жанра**
3. Определить ведущий путь обложки: персонаж-ведущий / сцена-ведущая / предмет-ведущий / напряжение отношений
4. Сначала подтвердить формулировку названия для публикации, используемого в главном заголовке обложки: несегментированный роман берёт целевое название романа для публикации, роман по частям — целевое название соответствующей части.
5. Решить вёрстку заголовка: положение главного заголовка, положение имени автора, характер шрифта

## Структура вывода

Каждый вариант рекомендуется давать в следующем порядке:

1. Оценка платформы
2. Краткое описание направления обложки
3. Основной промпт
4. Negative Prompt
5. Пояснение по вёрстке

## Типичные ограничения

- Приоритет основного объекта выше фона.
- Приоритет узнаваемости на миниатюре выше нагромождения деталей.
- Стилевые слова должны служить жанру и не бороться друг с другом.
