# Полный шаблон рецензии общего плана (универсальный скелет)

Подходит для: общего плана, общего плана всей книги, группы файлов стратегического уровня, общей панели граней истории (故事面), общей панели загадки основной линии.

## 1. Принцип разделения общего слоя и жанрового слоя (обязательно)

- Этот файл содержит только **универсальный скелет рецензии общего плана**, повторно используемый между жанрами.
- Каждый жанровый Skill обязан поверх этого скелета дописать собственные «проверку жанровой привлекательности и дифференциации», «жанровые специальные пункты оценки», «акценты жанрового вывода».
- Жанровый Skill **не имеет права сокращать** основной общий скелет этого шаблона, он может лишь дописывать и заменять пункты-заполнители в жанровых специальных разделах.
- Если объект — не один файл, а пакет общего плана, отчёт обязан явно записать охваченную группу файлов и неохваченные объекты.
- При рецензировании пакета общего плана по умолчанию `小说总大纲.md` считается базисом основной сюжетной линии, а `故事面/` — группой законченных файлов историй преимущественно побочных линий; их переплетение и связка не есть дублирующее сопровождение.

## 2. Место сохранения и формат имени файла (обязательно)

- Отчёт рецензии общего плана находится прямо в корне `审阅意见/`, отдельный специальный подкаталог для общего плана не создаётся.
- Примеры имён файлов:

`审阅意见/总纲审阅报告_[名称或编号]_[审阅日期].md`

## 5. Инструкция по использованию (обязательно)

- Если текущая задача — исполнение жанровым Skill, необходимо дописать в разделы-заполнители выше жанровые специальные пункты проверки, жанровые специальные пункты оценки и акценты жанрового вывода.
- Если жанровый Skill выводит лишь краткую версию или удаляет любой из основных разделов, это считается незавершённой верной миграцией.
- Если объект общего плана на самом деле — «пакет общего плана», нельзя писать вывод по одному файлу, в начале отчёта обязательно назвать охват.
- Если объект общего плана — «пакет общего плана», сначала необходимо оценить границу обязанностей между `小说总大纲.md` и `故事面/`, нельзя прямо признавать преднамеренно спроектированную двухколейную структуру основной и побочных линий дублирующим сопровождением.
- Если отдельно не оценены основная платформенная подача, обещание первого тома и выносливость длинного романа, это считается незавершённой рецензией стратегического уровня веб-романа.
- Если не написано «что заимствовано у какого конкурента, чем слабее какой конкурент, что править в этом раунде в первую очередь», это считается незавершённым подключением конкурентов.
