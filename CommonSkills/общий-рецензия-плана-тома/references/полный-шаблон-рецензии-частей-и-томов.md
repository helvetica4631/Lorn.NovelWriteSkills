# Полный шаблон рецензии части и тома (универсальный скелет)

Подходит для: плана части, плана тома, списка глав, исполнительной версии дела-единицы.

## 1. Принцип разделения общего слоя и жанрового слоя (обязательно)

- Этот файл содержит только **универсальный скелет рецензии части / тома**, повторно используемый между жанрами.
- Каждый жанровый Skill обязан поверх этого скелета дописать собственные «проверку жанровой привлекательности и дифференциации», «специальные разделы по ритму / сценам / платформе», «жанровые специальные пункты оценки».
- Жанровый Skill **не имеет права сокращать** основной общий скелет этого шаблона, он может лишь дописать в жанровых специальных разделах критерии арбитража своего жанра.
- Если у объекта есть источник распределения вышестоящего уровня, отчёт обязан сначала записать диагностику «распределение вышестоящего уровня реализовано / отсутствует / висит в воздухе», и только затем переходить к суждениям о ритме и хуках.

## 2. Место сохранения и формат имени файла (обязательно)

- Отчёты рецензии плана части и плана тома находятся прямо в корне каталога `审阅意见/`.
- Отчёт рецензии дела-единицы, если его выводит этот Skill, по умолчанию также следует схеме корня `审阅意见/`.
- Примеры имён файлов:
  - `审阅意见/分部审阅报告_[名称或编号]_[审阅日期].md`
  - `审阅意见/分卷审阅报告_[名称或编号]_[审阅日期].md`
  - `审阅意见/单元案审阅报告_[名称或编号]_[审阅日期].md`

## 9. 🧭 Проверка инженерии сверхдлинных романов (с точки зрения части/тома)
- [ ] Стыковка четырёх уровней плана: гладко ли состыкованы общий план / часть / том / дело-единица (или эквивалентные уровни); если уровень отсутствует, есть ли заменяющий критерий.
- [ ] Соотношение основной / побочной линий: не размывается ли продвижение основной линии побочными надолго; служат ли побочные линии основной или дуге персонажа, а не просто набирают объём.
- [ ] Пирамида конфликтов: усиливаются ли слой за слоем личная дилемма → сопротивление сети отношений → давление системы/механизма; нет ли краха боевой мощи, когда противостояние «пишется всё легче».
- [ ] Цепочка интриги и развязки: оставляют ли завязки прослеживаемый след; завершаются ли развязки цепочкой улик / процедур / причинности; нет ли ям, которые невозможно засыпать, или бесшумно испарившихся.
- [ ] Поэтапное нарастание: чётки ли границы «проба → расширение → сведение → финал» (или эквивалентного деления на периоды); берёт ли этот том / эта часть на себя положенные новые конфликты / новую цену / новое повышение.

## 10. ⏱️ Проверка ритма и структурного планирования (обязательно для части/тома)

- Если отдельно не оценены цепочка следования за первыми 5 главами, плотность наград в середине тома и сила докупки в конце тома, это считается незавершённой рецензией уровня тома веб-романа.
