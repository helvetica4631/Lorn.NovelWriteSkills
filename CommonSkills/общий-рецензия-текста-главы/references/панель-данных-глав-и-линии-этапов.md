# Панель данных главы и линии достижения по этапам

> Источник критериев: статистика данных из `经验总结.md` + эталоны качества из `修订体系.md`.

## Цель

Поднять рецензирование глав от «суждения по читательскому ощущению» до двухтрековой оценки «ощущение + данные».

## Основные показатели панели

| Показатель | Базовое достижение | Продвинутая цель | Примечание |
| --- | --- | --- | --- |
| BodyCJK основного текста | Диапазон платформы по умолчанию | Рекомендуемый диапазон платформы | В шлюзе участвует только `BodyCJK` |
| Покрытие хуком первых 200 знаков | 100% | 100% | Отсутствие — структурный риск |
| Покрытие оставленным хуком последних 200 знаков | ≥90% | 95%+ | Ниже базовой линии — риск удержания |
| Доля диалога | 25%–55% | 30%–45% | Слишком мало — повествование давит, слишком много — пустые реплики |
| Доля возвратов предзнаменований (по этапу) | ≥80% | ≥95% | По статистике журнала учёта |
| Доля глав с повторяющимся описанием | ≤20% | ≤10% | Сканирование высокочастотных слов |
| Длина непрерывного поясняющего абзаца | ≤200 знаков | ≤150 знаков | При превышении разбивать |
| **Доля сильных хуков (первые 30 глав)** | **≥80%** | **≥90%** | Сильный хук = раскрытие информации / раскол отношений / воплощение цены / новый кризис; суммарно 2 главы со слабыми хуками — риск удержания |
| **Предел периода холодной травмы** | **≤2 главы (мучительная любовь) / ≤3 главы (рабочее место)** | **≤1 глава** | Предел числа глав подряд «только тепло, без боли» — после превышения чувство срочности следования падает |
| **Соотношение чередования «вред — награда»** | **1:1 (основной режим начала)** | **≥1:1 (в каждой главе обязательно продвижение)** | 2 главы подряд вреда без награды → оценка P1; 2 главы подряд награды без вреда → оценка P0 (превышен период холодной травмы) |
| **Период охлаждения главного антагониста** | **≤15 глав** | **≤10 глав** | Отсчёт периода охлаждения идёт, пока лобовой противник не появляется; после превышения устрашающая сила антагониста слабеет |
| **Нижняя граница демонстрации оружия** | **Глава 3** | **Глава 1** | Читатель должен не позднее главы 3 знать, «за счёт чего героиня способна победить» |

## Линии достижения по этапам (с точки зрения рецензии)

### Линия достижения партии A

- Цепкость начала главы состоялась (эффективный хук в первых 200 знаках).
- Движущая сила в конце главы состоялась (в последних 200 знаках есть незакрытое давление).
- Конфликт в диалоге состоялся (не чистые информационные вопросы и ответы).

### Линия достижения партии B

- Цепочка предзнаменований «выдвинуто — усилено — возвращено» прослеживаема.
- Золотой палец не всемогущ, цена и триггеры видны.
- Избыточное описание и длина поясняющих абзацев достигают нормы.

### Линия достижения партии C

- Улучшение телесного ощущения читателя: точки запоминания лучше видны, порыв перелистнуть стабильнее.
- Усилен отклик предметов и улик, это не разовый расход.
- Конструкции ИИ, метаповествование, тон путеводителя заметно сокращены.

## Рекомендуемые поля вывода рецензионного отчёта

- Основные показатели этой главы (BodyCJK / доля диалога / покрытие хуков).
- Вердикт по партии для этой главы (какой слой A/B/C не достигнут).
- Уровень риска этой главы (P0/P1/P2) и минимальное место патча.
- Приоритет доработки следующего раунда (сначала структура или сначала язык).

## Правила градации рисков

- **P0**: риск разрыва удержания (нет хука в начале главы, нет движущей силы в конце, пропала основная точка продажи).
- **P1**: риск потери опыта (слабый конфликт в диалоге, нет награды в середине, слишком толстый поясняющий абзац).
- **P2**: пункты оптимизации фактуры (единство лексики, тонкая правка вёрстки, шлифовка тона).

## Критерий вывода

Вывод должен содержать две фразы:

1. Достигнут ли шлюз этого этапа текущей версией.
2. Если не достигнут, каков следующий минимальный исполнимый патч.
