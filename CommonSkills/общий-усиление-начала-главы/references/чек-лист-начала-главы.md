# Контрольный список начала главы

## 1. Объём

- [ ] Обрабатываются только первые 150–300 знаков или первые 2–3 абзаца
- [ ] Не повреждена основная структура последующего текста

## 2. Тест 30 секунд

- [ ] Есть ли в первых 2–3 абзацах как минимум два из: аномалия / конфликт / интрига-пробел?
- [ ] Может ли читатель сразу ощутить, что «с этим делом прямо сейчас что-то не так»?

## 2.5 Тест способа входа

- [ ] Относится ли текущее начало к одному из следующих семи эффективных входов: действие / диалог / аномальная ситуация / интрига / кризис / открытие / **ясное пошаговое пробуждение**
- [ ] Избежано ли слабое начало: начало с погоды / вставание, еда, ходьба / обзор прошлой главы / большие куски предыстории / светская болтовня без информации
- [ ] Позволяют ли первые 20% читателю узнать как минимум два из «кто, где, что происходит»

## 2.6 Проверка «ясного пошагового пробуждения» (специально для начал типа «попаданец в книгу / перерождение / пробуждение после аварии»)

Подходит для сцен, где главный герой пробуждается из спутанного состояния. Правильная последовательность восстановления сознания: **смутное телесное ощущение → мысль «это сон» / попытка вернуться в безопасное состояние → вторичное прерывание внешним насилием → полное пробуждение → постепенное построение пространства**.

- [ ] Приходится ли первый слой привязки на телесные ощущения (боль / холод / тяжесть / бессилие), а не на зрение?
- [ ] Пытается ли главный герой сначала объяснять аномалию фразами «это сон», «посплю ещё немного», а не мгновенно приходит в себя?
- [ ] Происходит ли внешнее насилие (пощёчина / рывок / удар / звук) после того, как главный герой пытался уйти от него, а не до?
- [ ] Строится ли пространство от ближнего к дальнему (рука / колено / запах → предмет перед глазами → люди вдали), а не панорамным пояснением?
- [ ] Избежано ли повествовательное вводное предложение пассивного залога вроде «её разбудила боль»?

Отрицательный пример: `疼。沈昭宁是被疼醒的。左脸颊像被火燎过……她费力地睁开眼——蜡烛、白幔、人影。` («Больно. Шэнь Чжаонин разбудила боль. Левая щека словно обожжена огнём… Она с трудом открыла глаза — свечи, белый траурный полог, силуэты.») (первая и вторая фразы избыточны; зрение и вторая фраза появляются одновременно, не оставляя места для «думала, что это сон»)

Положительный пример: `疼。她试着睁开眼——没力气。左脸火辣辣地烧，耳膜嗡嗡响。有人在哭，有人含混地念着什么——很远。不对。她应该在加班……太困了。闭上眼。一道声音从头顶劈下来。` («Больно. Она попыталась открыть глаза — не было сил. Левая щека горела огнём, в ушах гудело. Кто-то плакал, кто-то невнятно что-то бормотал — далеко. Не то. Она должна быть на сверхурочной работе… так хочется спать. Закрыть глаза. Голос рубанул сверху.») (сначала замешательство и бегство, затем внешнее прерывание)

## 3. Тест действия

- [ ] Совершает ли главный герой действие, которое необходимо выполнить прямо сейчас?
- [ ] Привязано ли давление к действию, а не абстрактно висит?

## 3.5 Тест отклика на предыдущую главу (в приоритете для неперовых глав)

- [ ] Откликается ли начало этой главы на хук в конце предыдущей главы: напрямую / косвенно / с намеренной отсрочкой
- [ ] Если отсрочка намеренная, чётко ли определено последнее окно возврата (обычно не стоит тянуть дольше 3 глав)

## 4. Тест вживания

- [ ] Приземлена ли эмоция на телесные реакции, микродействия, предметы или смещение окружения?
- [ ] Избежано ли начало в виде чистого пояснения предыстории?
- [ ] Если начало с диалога, позволяют ли первые несколько фраз уже различить идентичность / степень знакомства / разницу позиций?
- [ ] Если начало с диалога, есть ли хотя бы одна фраза, выдающая, что персонаж сейчас защищает, чего боится или что хочет отнять?

## 5. Цепкость и ритм

- [ ] Предшествует ли первая волна действий большим пояснениям?
- [ ] Есть ли хотя бы одна аномальная деталь, которую можно снять на камеру?
- [ ] Меняется ли длина фраз, не похоже ли на ровный объяснительный текст?
- [ ] Способна ли последняя фраза начала подтолкнуть читателя к следующему абзацу?

## 6. Тест удержания

- [ ] Захочется ли читателю, прочитав эти 150–300 знаков, естественно спросить «почему так?»
- [ ] Достаточно ли конкретен этот вопрос, а не большой и пустой?
- [ ] Сформировал ли читатель через диалог или действие с персонажем хотя бы одну связь: согласие / сочувствие / симпатия / любопытство?

## 7. Повторная проверка красных линий

- [ ] Ответ не выдан прямо заранее
- [ ] Нет новых ключевых фактов
- [ ] Отдача последующих частей не истощена заранее
- [ ] Начало главы не отполировано до одного тона с остальными главами

## 8. Суждение об откате

- [ ] Если после правки начала вторая сцена всё ещё не принимает эстафету, определено ли, нужно ли откатить обязанности сцены?
- [ ] Если для цепляния начало должно истощить отдачу середины, определено ли, нужно ли откатить в контрольную карточку главную опору / позицию отдачи середины?
- [ ] Если начало уже цепляет, но оторвано от главной линии продвижения данной главы, определено ли, это проблема начала главы или проблема дизайна вышестоящего слоя?
