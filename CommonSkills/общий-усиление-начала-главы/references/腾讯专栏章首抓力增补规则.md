## Сильные правила P0 начала главы

1. Главный герой обязан как можно раньше быть на сцене; по умолчанию не принимается вариант «первые несколько абзацев — сплошь фоновые персонажи или закадровый текст».
2. Запрещено нагромождать в начале сеттинг, существительные и термины; сеттинг нужно вплетать в действие, а не рассказывать отдельно от событий.
3. Начало по умолчанию должно удовлетворять минимальной единице «действие + реакция», иначе это лишь дневник, а не история.
4. В начале конфликт в приоритете «бытовой реальный конфликт»; избегать жёстких конфликтов без реальной основы и избитых «ядовитых точек».
5. Первые три главы по умолчанию продвигаются по обязанностям:
   - Глава 1: выстроить опору главного героя и текущий тупик;
   - Глава 2: главный герой обязан совершить эффективное действие в ответ на тупик;
   - Глава 3: дать ощутимую отдачу или более сильный хук удержания.

## Пункты оптимизации P1 начала главы

1. Одна фраза — одна функция: первый абзац не должен одновременно нести объяснение мироустройства, энциклопедию отношений персонажей и разъяснение ценностей.
2. Приоритет информации со стороны читателя: сначала дать читателю знать «что сейчас происходит», затем дополнить «почему так».
3. Начало со сложным золотым пальцем нужно упрощать при подаче: первый экран выдаёт лишь «что умеет + какую цену платит + почему сразу применяется».
4. Начала главы следует избегать «лишь отмечать 爽 без приземления»: главное действие героя обязано вызывать видимую реакцию — только тогда оно состоятельно.

## Список самопроверки (перед откатом начала)

- [ ] Явно ли присутствует главный герой на первом экране?
- [ ] Появились ли видимое действие и реакция внешних / других людей?
- [ ] Есть ли реальное, пригодное для вживания немедленное затруднение?
- [ ] Удалены ли большие куски сеттинга, которые можно отложить?
- [ ] Выровнено ли с обязанностями золотых трёх глав, а не правятся только фразы?
