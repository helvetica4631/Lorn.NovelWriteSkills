# Перечень замен ИИ-оборотов и заменителей через действия

> Источник критерия: правила устранения «духа» партии C из `修订体系.md` (система правок) / `使用说明.md` (инструкция по использованию).

## Цель

- Распознавать высокочастотные универсальные ИИ-обороты.
- Без потери информации переписывать в человеческий текст «действие + физиология + решение».

## Частые обороты и замены

| Частый оборот | Риск | Рекомендуемая замена |
| --- | --- | --- |
| 他眸中闪过一丝 X («в его глазах мелькнуло нечто X») | Шаблонность, пустое описание | Он **[конкретное действие]** — на мгновение, движение руки замерло |
| XX 缓缓说道 («XX медленно произнёс») | Пустая семантика, тянет ритм | **[Ведущее действие]** — «……» |
| XX 心中暗道 («XX подумал про себя») | Сильное ощущение авторского пересказа | Прямо писать внутреннюю фразу вплотную, без ведущего слова |
| 总而言之 / 可以说 / 值得注意的是 («в итоге / можно сказать / стоит отметить») | Лекционная интонация | Прямо дать вывод или факт |
| 他非常 X («он очень X») | Абстрактная оценка | Действие + физиологическая реакция + решение |
| 突然 / 忽然 / 猛地 (высокая частота) («вдруг / внезапно / резко») | Движение наречием, а не событием | Создавать неожиданность порядком слов и очерёдностью событий |
| 他深吸一口气 (высокая частота) («он глубоко вдохнул») | Шаблонность эмоций | Оставлять только в ключевых узлах, в остальных менять на последствия поведения |
## Специальная замена высокочастотных логических связок ИИ (новое)

> **Источник**: исследовательский отчёт этого репозитория «Механизм обнаружения ИИ Zhuque и меры противодействия», раздел 2.5. Следующие связки встречаются в тексте, сгенерированном ИИ, значительно чаще, чем в человеческом письме, и относятся к чувствительным для обнаружения признакам.

| Слово-триггер | Вариант замены | Приоритет замены |
|--------|---------|-----------|
| 然而 («однако») | → «可» («но»), «但» («но»), либо перейти действием / диалогом, прямо разорвав фразу | Обязательная замена |
| 此外 / 除此之外 («кроме того / помимо этого») | → прямо удалить, либо «还有» («ещё»), «再说» («к тому же») | Обязательная замена |
| 因此 / 因而 («поэтому / вследствие этого») | → «所以» («так что»), «结果» («в итоге»), либо подразумевать причину без явной пометки | Обязательная замена |
| 值得注意的是 («стоит отметить») | → прямо удалить, если информация сама ценна — изложить отдельно | Обязательная замена |
| 不可否认的是 («нельзя отрицать, что») | → «当然» («конечно»), «说实话» («честно говоря») | Рекомендуемая замена |
| 总的来说 / 总而言之 («в целом / в итоге») | → прямо удалить, дать абзацу естественно закончиться | Обязательная замена |
| 换句话说 / 换言之 («иными словами») | → заменить абстрактное объяснение конкретным примером | Рекомендуемая замена |
| 毫无疑问 («без сомнения») | → «显然» («очевидно») или прямо изложить факт | Рекомендуемая замена |
| 一定程度上 («в известной степени») | → удалить либо дополнить конкретной мерой степени | Замена по выбору |
| 不仅…而且… («не только… но и…») | → разбить на две фразы либо использовать лишь одно из нарастаний | Рекомендуемая замена |

**Правила использования**:
- Позиции обязательной замены: во всём тексте не более 1 появления на тысячу знаков
- Позиции рекомендуемой замены: во всём тексте не более 2 появлений на тысячу знаков
- Если после замены фраза стала более обрывистой — это, наоборот, ближе к человеческой разговорной речи, склеивать заново в круглое не нужно

## Специальная замена четырёх классов ИИ-шаблонной лексики веб-новелл (новое)

> **Источник**: идея Zhihu «网文老刀17年实战» (опыт 17 лет веб-новелл): почему при написании романов не рекомендуется использовать слова вроде «攥紧, 后背发凉, 眸光微沉» («сжал, спина похолодела, взгляд слегка потемнел»)? 2026-07-08.

Четыре самых типичных и сильнее всего снижающих фактуру класса шаблонных «гнилых» слов в ИИ-письме веб-новелл. Эти слова многократно переиспользуются в миллионах ИИ-рукописей по всей сети и являются наиболее наглядным сигналом распознавания болезни ИИ-письма. Направление замены — не «поменять на синоним», а «вернуть размытое называние эмоций к конкретным телесным реакциям и выбору поведения».

### Класс 1: шаблоны движений рук — 攥紧, 指节发白, 指尖微颤 («сжал, костяшки побелели, кончики пальцев слегка дрожат»)

Это крупнейший очаг воды во всей сети. ИИ не различает движения по образу и эмоции — стоит персонажу разгневаться / напрячься / сдержаться, он унифицированно выдаёт «сжал кулаки, костяшки побелели, молчит».

**Направления дифференцированной замены**:

| Эмоциональное состояние | Заменяющее письмо | Логика за этим |
| --- | --- | --- |
| Ярость | Вздутые жилы, тяжёлое дыхание, размашистые движения, швырнуть / грохнуть / хлопнуть | Ярость — эмоция высвобождения, тело расширяется вовне |
| Напряжение | Вспотевшие ладони, окоченевшие пальцы, глотание, взгляд, которому некуда деться | Напряжение — эмоция подавления, тело стягивается внутрь, но без приложения силы |
| Обида и сдержанность | Поджатые кончики пальцев, сила, чтобы подавить эмоцию, стиснутая челюсть, покрасневшие глаза, но без слёз | Сдержанность — «подавление вместо выпуска вовне», у тела лёгкая дрожь, но движение сдержано |

**Критерий оценки**: один и тот же персонаж при одной и той же эмоции не должен подряд 2 и более раз использовать один и тот же набор описаний рук. Разные эмоциональные состояния обязаны использовать разные телесные сигналы.

### Класс 2: шаблоны ощущения эмоционального кризиса — 后背发凉, 心头一沉, 浑身一僵 («спина похолодела, на сердце упало, всё тело оцепенело»)

Почти во всех текстах ИИ ощущение кризиса выражается лишь одним способом. В книге на несколько сотен тысяч знаков главный герой «холодеет спиной» десятки раз, все кризисы / зацепки / внезапные ситуации используют одно и то же описание телесного ощущения.

**Направление замены** — по типу кризиса выбирать разные физиологические сигналы:

- **Тип внешнего нападения** (внезапная опасность / атака): кожа стягивается, волоски встают дыбом, зрачки резко сужаются, дыхание на мгновение замирает
- **Информационный кризис** (обнаружение улики / осознание, что обманут): пальцы замирают, сердце пропускает удар, желудок сжимается, действие заклинивает
- **Межличностный кризис** (опасность в диалоге / отношениях): уголки губ держатся, но взгляд изменился, ритм речи замедлился, намеренно делается малое движение для маскировки
- **Кризис окружения** (давление атмосферы): звон в ушах, окаменевшая шея сзади, непроизвольно приглушённые шаги, задержка дыхания

**Жёсткое правило**: «спина похолодела» во всей книге не более 2 раз — лишь в высших кризисах, реально затрагивающих нижнюю границу выживания, в повседневной интриге / малых поворотах везде заменять дифференцированными телесными ощущениями.

### Класс 3: универсальные шаблоны мимики — 眸光微沉, 眼底一暗, 神色复杂 («взгляд слегка потемнел, дно глаз потемнело, выражение лица сложное»)

Знаковый «приём слова 微» («слегка») веб-новеллового «водоналива». Все эмоции без разбора — радость, гнев, печаль, веселье, опаска, насмешка — одним штрихом «слегка потемнел, слегка померк, слегка изменился». Главный изъян — расплывчатость и пустота, без информации: после прочтения читатель не знает, какая настоящая эмоция у персонажа, знает лишь, что «настроение у него изменилось».

**Направление замены**:

| Шаблонная запись | Проблема | Направление замены |
| --- | --- | --- |
| 眸光微沉 («взгляд слегка потемнел») | Читатель не знает, какая эмоция «потемнела» | Писать конкретное изменение выражения: губы вытянулись в линию, надбровные дуги опустились, взгляд ушёл и вернулся |
| 眼底一暗 («дно глаз потемнело») | Слишком абстрактно | Писать физиологическую реакцию: изменение зрачков, замедление частоты моргания, слегка опущенные веки |
| 神色复杂 («выражение лица сложное») | Самый пустой универсальный наполнитель | Выбрать 1–2 наблюдаемые эмоции и написать их, не стремиться обобщить «всё» |

**Жёсткое правило**: в основном тексте запрещено по отдельности использовать «微沉, 微暗, 微变, 神色复杂» для сообщения эмоции — либо не писать эмоцию, либо писать конкретный сигнал.

### Класс 4: психологические пустые слова и нагромождение служебной лексики — 欲言又止, 五味杂陈, 悄然, 骤然 («хотел сказать, но осёкся; смешанные чувства; тихо; внезапно»)

В малом количестве проблем нет, при высокочастотных повторах — стандартная вода. У персонажа явно есть метания, опасения, психологическая игра, а автор не пишет конкретных мыслей, а лишь резюмирует фразой «欲言又止, 百感交集» («хотел сказать, но осёкся, нахлынуло столько чувств»).

**Направление замены**:

- **欲言又止** → писать конкретное действие «подступило к губам и снова проглочено» (губы шевельнулись, раскрыл рот и снова закрыл, на полуслове сменил тему)
- **五味杂陈** → писать «ту из нескольких эмоций, что сейчас преобладает» (под гневом придавлена обида, в тревоге — ниточка ожидания)
- **悄然 / 骤然** → удалять либо использовать конкретную временную последовательность («门开了» («дверь открылась») вместо «门悄然打开» («дверь тихо отворилась»); «他站起来» («он встал») вместо «他骤然起身» («он внезапно поднялся»))

**Стандарт частоты для самопроверки (общий со слоем рецензирования)**:

- 1–2 раза за главу: нормальное письмо
- 3 и более подряд слов одного класса шаблонов: тяжёлая шаблонность, нужна замена
- 5 и более раз: ИИ-конвейерная вода, обязательно разобрать всю главу

## Шаблон трёхчастной замены

```text
Исходная фраза (абстрактная): 他非常愤怒。 («Он очень зол.»)
Переписанная (через действие): 他把杯子往桌沿一磕，玻璃沿裂开一道白线； («Он стукнул стаканом о край стола, по краю стекла пошла белая трещина;»)
                 呼吸压得很低，下一句出口前先把手机锁屏。 («дыхание придавлено очень низко, прежде чем произнести следующую фразу, он сначала заблокировал экран телефона.»)
```

## Порог устранения «духа» в группах фраз

- На одной странице (около 800–1200 знаков) один и тот же шаблонный оборот не должен повторяться более 2 раз.
- Если подряд 3 абзаца заканчиваются «фразой-психологическим итогом», как минимум 2 абзаца необходимо переписать на концовку видимым действием.
- Если в диалоговой сцене более 5 реплик подряд без вкрапления действий, необходимо вставить как минимум 1 действие или помеху окружения.

## Повторная проверка перед записью обратно

- Нулевая ли потеря информации.
- Не испорчен ли порядок причин и следствий.
- Не «сглажены» ли цепкость начала главы / отдача в середине / хук в конце главы.

## Сжатие описаний: контроль высокочастотных избыточных слов

> Источник: `修订体系.md` §партия B · контроль сжатия описаний; `经验总结.md` §7.

### Класс описаний пейзажа (лунный свет / осенний ветер / закат / раннее утро……)

- Каждое слово о пейзаже сохранять во всём тексте максимум **2–3 раза**, остальное удалять или заменять конкретным действием.
- Критерий оценки: если удалить эту фразу, потеряет ли читатель восприятие сцены? Если не потеряет — удалить.

### Звукоподражания (叮叮当当 / 嗡嗡 / 嘎吱……) («дзынь-дзынь / жжж / скрип……»)

- Верхний предел числа появлений одного и того же звукоподражания во всём тексте **≤5 раз**.
- При первом появлении: полное описание. При последующих: оставлять только действие, не повторять звукоподражание.

### Наречия степени

| Избыточное слово | Направление замены |
| --- | --- |
| 突然 / 忽然 / 猛地 («вдруг / внезапно / резко») | Создавать срочность порядком слов, переносить вперёд содержание после «突然» |
| 非常 / 很 / 极其 («очень / весьма / крайне») | Удалять, вместо этого писать прямо конкретными деталями |
| 缓缓 / 慢慢 / 渐渐 («медленно / постепенно / понемногу») | Заменять разбивкой на шаги (сначала…… потом…… затем……) |

### Повествовательные паузы (большие куски пейзажа / психологии / предыстории)

- Подряд более 200 знаков абзаца без диалога и без действия: **разбить**, вставить действие или диалог.
- Фоновая информация (мироустройство / история персонажей): **рассредоточить** на 3–5 мест, не более 3 строк на каждое.
- Абзацы со сплошным нагромождением предыстории: рассмотреть переписывание в стиле «вспоминать в процессе какого-то дела».
