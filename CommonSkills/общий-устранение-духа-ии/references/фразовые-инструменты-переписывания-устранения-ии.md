# Инструмент переписывания на уровне фраз для устранения «духа ИИ»

В приоритете обрабатывать следующие объекты:

- Клише: 值得注意的是 / 不难看出 / 首先其次最后 / 从某种意义上说 («стоит отметить / нетрудно заметить / во-первых, во-вторых, наконец / в некотором смысле»)
- Абстрактные эмоции: 他很压抑 / 她非常害怕 / 气氛诡异 («он очень подавлен / она очень боится / атмосфера жутковатая»)
- Ложные профессиональные фразы: нагромождение терминов без действий и последствий
- Ложные хуки: пустые вздохи, пустые вопросительные знаки, пустые анонсы кризиса

Рекомендуемые способы правки:

- Фраза об абстрактной атмосфере → сцена + предмет + телесная реакция
- Объяснительная фраза → действие + свидетельство + последствие
- Ложная профессиональная фраза → сохранить необходимые термины, остальное переделать в действия и сопротивление
- Пустая вздыхающая концовка → незавершённое действие / новая информация / конкретная опасность

## Типичные действия по правке

### 1. Фраза с абстрактной эмоцией

- «他很紧张» («он очень напряжён») → телесная реакция / действие рук / мелкий стресс на месте

### 2. Аналитическая фраза

- «这一刻意味着……» («этот момент означает……») → последствие действия / невысказанные слова / пауза

### 3. Ложная профессиональная фраза

- Нагромождение нескольких терминов подряд → оставить 1 необходимый термин, остальное переделать в процедурные последствия или порог действий

### 4. Фраза с ложным хуком

- «更大的风暴还在后面» («большая буря ещё впереди») → вход конкретной опасности / запись аномалии / прерывание действия

## Принцип сохранения профессиональных слов

При выполнении любого из следующих условий не удалять прямо профессиональные или институциональные слова:

- Без них читатель не поймёт логику действий
- Без них ощущение профессионализма явно опустеет
- Без них границы правил размоются
- Без них оборвётся цепочка цены или цепочка улик
