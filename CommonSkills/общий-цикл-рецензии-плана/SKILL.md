  2. Если оценка 8-го раунда, напротив, ниже 7-го, принудительно остановить
  3. Для признания плато необходимо, чтобы **разница оценок в двух парах подряд была < 0,15**: если разница оценки раунда N и раунда N-1 < 0,15, нельзя сразу останавливать — **обязательно выполнить ещё один раунд «шлифовка + независимое повторное рецензирование»** и получить оценку раунда N+1. Только если одновременно выполняются |Score(N)−Score(N-1)| < 0,15 **и** |Score(N+1)−Score(N)| < 0,15, считается, что наступило плато, и принудительно останавливаем. Если разница при повторном рецензировании ≥ 0,15, плато не признаётся, продолжается обычный цикл доработки
  4. Нельзя просто повторять цикл «правка → рецензирование»
- «Дополнительный раунд проверки устойчивости после первого прохождения порога» не входит в лимит 8 раундов — раунд проверки — необходимый дополнительный шаг ради достигнутого порога, а не продолжение доработки из-за недостижения.
