# Вывод путей глав и именование артефактов

## Платформа по умолчанию и каталог основного текста по умолчанию

- Если пользователь явно не указал другую версию платформы, по умолчанию пишется `оригинальная версия главы для Qidian (起点中文网)`.
- Если пользователь явно не указал другой целевой путь, `CHAPTER_FILE` по умолчанию попадает в `小说正文/` в корне рабочей области.
- Когда пользователь указывает только номер главы, заголовок, сведения о томе / части тома и явно не называет путь основного текста, необходимо в первую очередь выводить `CHAPTER_FILE` в соответствующий каталог `小说正文/`, а не принимать за место основного текста по умолчанию каталоги Fanqie, Douban, Zhihu, WeChat Official Accounts, GoodNovel, My Fiction, WebNovel или издательства.

## Требования инициализации Step 0

- Обязательно проверить, существует ли `OUTLINE_FILE` и доступен ли для чтения.
- Если каталог, где лежит `CHAPTER_FILE`, не существует, создать каталог, но не записывать заранее содержимое основного текста.
- Обязательно по `CHAPTER_FILE` сгенерировать:
  - `CONTROL_CARD_FILE` (потребляется `общий-генерация-контрольной-карточки-главы`)
  - `REVIEW_REPORT_FILE`
  - `DESAI_REPORT_FILE` (удаление ИИ-привкуса на шаге 4 принудительно сохраняется по одиннадцатому шагу `общий-устранение-духа-ии`)
  - `READER_NOTE_FILE`
  - `BOOK_REVIEW_FILE`
- В пакетном режиме также нужно для каждой главы вывести соответствующие артефакты и создать расположение по умолчанию для `CONTINUITY_LEDGER_FILE`.

## Вывод нумерации глав и каталогов

- `第X部`: в первую очередь извлекать начальное число `X` из названия каталога части, находящегося в первых двух уровнях каталога `CHAPTER_FILE`
- `第Y卷`: в первую очередь извлекать `B` из `A.B.` в названии каталога тома
- `第X.Y.Z章`: в первую очередь извлекать `X.Y.Z` из имени файла главы
- Для `REVIEW_REPORT_FILE`, если не удаётся устойчиво извлечь часть / том, нельзя откатываться на `审阅意见/未分类/` или корень `审阅意见/`; нужно сначала дополнить информацию о положении из `OUTLINE_FILE`, каталога тома или пути целевой главы, а потом формировать путь отчёта

## Рекомендуемое именование

- Основной текст: `小说正文/第X部目录/第Y卷目录/X.Y.Z 标题.md`
- Контрольная карточка главы: `写作控制卡/第X部/第Y卷/控制卡_第X.Y.Z章_<YYYY-MM-DD>.md`
  - Понижение (без части и тома): `写作控制卡/未分类/控制卡_第X.Y.Z章_<YYYY-MM-DD>.md`
- Отчёт рецензии (с частью): `审阅意见/第X部/第Y卷/章节审阅报告_第X部_第Y卷_第Z章_<YYYY-MM-DD>.md`
- Отчёт рецензии (без части): `审阅意见/第X卷/章节审阅报告_第X卷_第Y章_<YYYY-MM-DD>.md`
- Отчёт об удалении ИИ-привкуса: `去AI化报告/第X部/第Y卷/去AI化报告_第X.Y.Z章_<YYYY-MM-DD>.md`
  - Понижение (без части и тома): `去AI化报告/去AI化报告_第X.Y.Z章_<YYYY-MM-DD>.md` (напрямую в корень `去AI化报告/`, `未分类/` не использовать)
- Читательские заметки: `阅读笔记/第X部/第Y卷/阅读笔记_第X.Y.Z章_<YYYY-MM-DD>.md`
- Рецензия на главу: `书评/第X部/第Y卷/<имя файла главы без расширения>_书评_<YYYY-MM-DD>.md`

## Запасной вариант «未分类» («без классификации»)

Если не удаётся устойчиво извлечь `第X部` или `第Y卷`, следующий запасной вариант «未分类» **применим только к артефактам, не являющимся отчётами рецензии глав**:

- `阅读笔记/未分类/`
- `书评/未分类/`

Отчёт рецензии главы обязательно сохранять только после дополнения положения части / тома; не использовать `未分类/`, чтобы скрыть нехватку информации о пути.

## Контроль соответствия путей (обязательно)

**Цель**: не допустить ошибочной записи при исполнении производных продуктов — отчёта рецензии, читательских заметок, рецензии и т. п. — в каталог `小说正文/`.

### Правила вывода производных путей

При генерации `CONTROL_CARD_FILE` / `REVIEW_REPORT_FILE` / `READER_NOTE_FILE` / `BOOK_REVIEW_FILE` / `CONTINUITY_LEDGER_FILE` обязательно следовать такой логике вывода:

1. В первую очередь извлечь сведения `第X部` и `第Y卷` из пути `CHAPTER_FILE` (правила см. в «Вывод нумерации глав и каталогов»)
2. По формату из «Рекомендуемого именования» сформировать полный целевой путь
3. **Нельзя использовать каталог, где лежит `CHAPTER_FILE`, напрямую как базовый каталог других артефактов** — даже если CHAPTER_FILE находится в `小说正文/第1卷/`, REVIEW_REPORT_FILE обязан идти в `审阅意见/`, а не наследоваться в `小说正文/审阅报告/`

### Проверка допустимости

После формирования производных путей обязательно проверить по пунктам:

| Артефакт | Целевой путь обязан начинаться с | Действие при несоответствии |
| --- | --- | --- |
| CONTROL_CARD_FILE | `写作控制卡/` | **Блокировка**: контрольная карточка не должна находиться в таких каталогах, как `小说正文/` |
| REVIEW_REPORT_FILE | `审阅意见/` | **Блокировка**: откатиться и исправить путь, ни по какой причине не писать в другие каталоги |
| DESAI_REPORT_FILE | `去AI化报告/` | **Блокировка**: откатиться и исправить путь, ни по какой причине не писать в `小说正文/`, `审阅意见/` и подобные каталоги |
| READER_NOTE_FILE | `阅读笔记/` | **Блокировка**: откатиться и исправить путь, ни по какой причине не писать в другие каталоги |
| BOOK_REVIEW_FILE | `书评/` | **Блокировка**: откатиться и исправить путь, ни по какой причине не писать в другие каталоги |
| CONTINUITY_LEDGER_FILE | `SOP执行日志/` | **Блокировка**: откатиться и исправить путь, ни по какой причине не писать в другие каталоги |

### Примеры типичных ошибок (запрещено)

```text
CONTROL_CARD_FILE  = 小说正文/控制卡_...md               ← ❌ контрольная карточка не должна быть в 小说正文/
REVIEW_REPORT_FILE = 小说正文/章节审阅报告_...md       ← ❌ отчёт рецензии не должен быть в 小说正文/
DESAI_REPORT_FILE  = 小说正文/去AI化报告_...md        ← ❌ отчёт об удалении ИИ-привкуса не должен быть в 小说正文/
READER_NOTE_FILE   = 小说正文/阅读笔记_...md            ← ❌ читательские заметки не должны быть в 小说正文/
BOOK_REVIEW_FILE   = 小说正文/书评_...md                ← ❌ рецензия не должна быть в 小说正文/
CONTINUITY_LEDGER  = 小说正文/连续性台账_...md           ← ❌ реестр не должен быть в 小说正文/
```

### Примеры правильного оформления

```text
CONTROL_CARD_FILE  = 写作控制卡/第1部/第2卷/控制卡_1.2.3章_2026-06-11.md                 ✓
REVIEW_REPORT_FILE = 审阅意见/第1部/第2卷/章节审阅报告_第1部_第2卷_第3章_2026-06-11.md  ✓
DESAI_REPORT_FILE  = 去AI化报告/第1部/第2卷/去AI化报告_1.2.3章_2026-06-11.md          ✓
READER_NOTE_FILE   = 阅读笔记/第1部/第2卷/阅读笔记_1.2.3章_2026-06-11.md                ✓
BOOK_REVIEW_FILE   = 书评/第1部/第2卷/1.2.3 深夜来访_书评_2026-06-11.md                   ✓
CONTINUITY_LEDGER  = SOP执行日志/撰写章节/连续章台账/连续性台账_第1部_第2卷_2026-06-11.md    ✓
```

### Ответственность жанровой обёртки за маршрутизацию путей

Жанровый обёрточный Skill замкнутого цикла главы (например `都市悬疑-章节创作闭环`) при маршрутизации в эти references дополнительно обязан:

- Проверить, существуют ли в корневом каталоге его жанрового проекта каталоги `小说正文/`, `写作控制卡/`, `审阅意见/`, `阅读笔记/`, `书评/`, `SOP执行日志/` и т. п.
- Если при исполнении выяснится, что каталога вроде `审阅意见/` нет, **нельзя молча откатываться на складывание отчётов в `小说正文/`**, а нужно самостоятельно создать недостающие каталоги
- В фазе инициализации пакетного режима сначала полностью создать всю необходимую структуру каталогов, затем начинать исполнение по главам

## Расположение реестра непрерывности по умолчанию

- В приоритете: `SOP执行日志/撰写章节/连续章台账/连续性台账_第X部_第Y卷_<YYYY-MM-DD>.md`
- Если не удаётся вывести часть и том: `SOP执行日志/撰写章节/连续章台账/连续性台账_未分类_<YYYY-MM-DD>.md`

В реестр записывается только структурированная информация, нельзя вставлять абзацы основного текста.

## Номера управления не допускаются в читательский текст

- Номера вида `C01`, `FB-01`, `SL-02`, `R3`, `M0`, которые служат только автору для управления дизайном в плане, реестре, отчёте рецензии, послесловии к главе, нельзя прямо писать в основной текст главы, эпиграф главы или `## 作者有话说`.
- Если нужно, чтобы читатель ощутил соответствующую информацию, её обязательно нужно переписать в естественное повествование, реплики, действия, воспоминания персонажей или реально существующие в сюжете носители улик.
- Номера дел, номера квитанций, номера точек наблюдения, тайм-коды, номера документов и прочие реально существующие внутри сюжета номера под этот запрет не подпадают.
