# общий-шлифовка-основного-текста
> **Жанровая маршрутизация**: если в каталоге .github\题材专用Skills\ есть соответствующий Skill <жанр>-正文润色 (шлифовка основного текста), то:
> - жанровые особенности направлять в <жанр>-正文润色, этот Skill находится в каталоге .github\题材专用Skills\.
> - при срабатывании этого навыка обязательно принудительно загружать в первую очередь текущий Skill и <жанр>-正文润色.


Цель шлифовки основного текста — не просто сделать фразы красивыми, а довести **уже написанную главу** до состояния «глаже, точнее, цепче, но без искажений».

Когда жанровый Skill вызывается вместе с этим Skill:

- `общий-шлифовка-основного-текста` (общая шлифовка основного текста) отвечает за общие процессы, выдачу по умолчанию, маршрутизацию слабых мест, фразовые действия и контроль погружения
- жанровый Skill отвечает за границы жанра, проектные особенности и дополнения источников вердикта

## Пояснение об оптимизации кэша

Структура этого Skill следует принципу оптимизации префиксного кэша. Шлифовка — высокочастотная задача (на одну главу возможно несколько раз), при вызове:

- **Кэш-слой (неизменный навсегда)**: frontmatter + общие принципы шлифовки + библиотека фразовых действий + стандарты заместителя главного вердикта + правила маршрутизации слабых мест → при каждом вызове абсолютно одинаков, тарифицируется по базовой цене
- **Проектный слой (неизменный в рамках проекта)**: перечень references + требования к перепроверке источников вердикта перед шлифовкой + правила автообнаружения шаблона стиля/чертежа + правила автообнаружения конфигурации языкового стиля → меняется только при смене проекта или регистрации нового шаблона
- **Изменяемый слой (меняется каждый раз, в этот файл не записывается)**: путь к файлу целевой главы, объём шлифовки (вся глава / абзац), особые ограничения на этот раз → задаются пользователем при каждом вызове
- Судейские источники — биографии персонажей, сеттинг истории и т. п. — принудительно загружаются через объявление references, их фиксированная часть вместе с этим Skill попадает в префикс кэша

## Перепроверка источников вердикта перед шлифовкой (обязательно)

- Перед тем как приступить к шлифовке, необходимо внимательно прочитать биографии персонажей, фактически появляющихся в этой главе, и документы сеттинга, связанные с фоном, технологиями, правилами, уликами, процессуальными цепочками, мироустройством этой главы.
- Нельзя идти на правку, опираясь лишь на готовый основной текст, следы прошлого раунда шлифовки или рецензионную сводку; для любых фрагментов, затрагивающих мотивы персонажей, границы способностей, состояние отношений, цену сеттинга, механизмы улик, необходимо вернуться к источникам вердикта на стороне автора и сверить, и только затем править.
- Если у одной и той же биографии персонажа или сеттинга несколько версий, сначала нужно подтвердить текущую исполнимую актуальную версию; если ключевой источник вердикта отсутствует, сначала нужно его восполнить, найти или явно заблокировать, нельзя шлифовать, гадая.
- Если этот раунд шлифовки затронет арку персонажа, цену правил, цепочку улик, положение в отношениях или фоновые факты, перед записью обратно необходимо ещё раз перепроверить соответствующие источники вердикта и убедиться, что основной текст не искажён шлифовкой.

  - **Следы правок (точка контакта S3, неосознанный вкус)**: когда после записи обратно отшлифованного варианта автор делает review, сравнить diff до и после правки — предложения, которые автор **восстановил / отстоял / удалил**, пословно попадают в библиотеку образцов (шаблон L2, с пометкой точки контакта S3 + предварительная причина), для последующего обратного заполнения дистилляцией языковой библиотеки / слоя синтаксиса; изменённая исходная фраза — сильнейшее свидетельство «настоящих предпочтений автора», выбрасывать нельзя
- Источник данных не зарегистрирован или автор явно пропустил: пропустить захват и потребление профиля, без ошибки, без блокировки

## Общий порядок исполнения

Справочные файлы этого Skill вызываются в следующем порядке. Если нет пометки «читать всегда в первую очередь», читать по необходимости.

1. **Сначала прочитать источники вердикта**: внимательно прочитать биографии персонажей, документы сеттинга / фона, контрольную карточку и последние выводы рецензии, имеющие отношение к этой главе, подтвердить, какие «гвозди» нельзя трогать, что можно усилить и чего нельзя переступать.
2. **Подтвердить объём и интенсивность**: чётко определить объём этого раунда шлифовки (вся глава / сцена / абзац), интенсивность (лёгкая / средняя / тяжёлая) и неизменяемые пункты. → Если есть сомнения по принадлежности к фазе, всегда в первую очередь прочитать `references/единый-ритм-phase0-3-создание-и-правка.md`, подтвердить, на какой фазе правки сейчас находимся, затем исполнять по шлюзам соответствующей фазы.
3. **Сначала сохранить информацию**: обеспечить, чтобы факты, причинность, точка зрения, структурные функции не пострадали от шлифовки. → Всегда в первую очередь прочитать `references/правила-переноса-с-сохранением-достоверности.md` (в нём ясно указаны обязательно сохраняемое, допустимые для оптимизации объекты и запрещённые операции); параллельно читать `references/двухдорожечные-запреты-и-контроль-погружения.md` (понять принцип раздельных дорожек функциональной линии и линии фактуры, обеспечить, чтобы сначала стабилизировалась функциональная линия, а затем оптимизировалась фактура).
4. **Сначала починить цепь дочитывания**: сначала цепкость начала главы, затем награду в середине, затем хук конца главы. → Всегда в первую очередь прочитать `references/процесс-шлифовки.md` (общий порядок исполнения). На каждом шаге, если встретится конкретная проблема исполнения, требующая расширенных приёмов, обращаться к `references/приёмы-усиления-шлифовки-и-читательские-механизмы.md` (специальные приёмы цепкости начала главы, награды в середине, хука конца главы, вовлечения персонажей, читательских механизмов).
5. **Затем обработать по маршрутизации слабых мест**: диалог, действие, психология, портрет, пейзаж, статика или сцена. → Всегда в первую очередь прочитать `references/расширенная-маршрутизация-справок-шлифовки.md` (отображение «симптом → способ ремонта», разветвление по категориям слабых мест). Когда слабое место определено, читать по необходимости соответствующий файл руководства по письму (`语言/行动/心理/肖像/景物/静态/场面写作指导与好词好句好段.md`). При следующих проблемах дополнительно читать соответствующие файлы усиления:
   - Пустое описание чувств → читать по необходимости `references/усиление-цепочки-чувств-и-физиологических-реакций.md`
   - Абстрактная информация/термины/данные кажутся пустыми при чтении → читать по необходимости `references/усиление-лестницы-абстракции-и-перевода-фактов.md`
   - Сдвиг контроля дистанции повествования (авторская точка зрения подменяет точку зрения персонажа) → читать по необходимости `references/коррекция-точки-зрения-и-дистанции-повествования.md`
   - Неточное суждение о дистанции абзаца (вплотную / средняя дистанция / мост) → читать по необходимости `references/карточка-действий-для-абзацев-вплотную-средней-дистанции-и-моста.md`
   - Нужно сжать поясняющее содержание с сохранением информации → читать по необходимости `references/карточка-сжатия-убрать-объяснение-сохранить-информацию.md`
   - Функциональные фразы нужно сохранить функцию и оживить → читать по необходимости `references/карточка-примеров-переписывания-функциональных-фраз.md`
   - **Проблемы плавности чтения (новое — заимствовано у автора ответов Zhihu «好难说故事»)**: когда при шлифовке ощущаешь «со словами вроде всё в порядке, но читать тяжело», в первую очередь диагностировать следующие три вида происшествий плавности, затем решать способ ремонта.
     - **Принудительное объяснение**: поясняющие абзацы слишком плотные/длинные, часто встречаются маркеры «原来 / 其实是 / 实际上 / 也就是说» (оказывается / на самом деле это / фактически / то есть). → Ремонт: удалить маркерные слова, сжать фоновую информацию до 1–2 фраз, естественно вплетённых в сцену; отдельное пояснение длиннее 150 знаков обязательно разбить.
     - **Аномалии разбивки на абзацы/пунктуации**: ① одна фраза в абзац (смысл не договорён, а строка уже сменилась) → слить с предыдущим или следующим абзацем, пока смысл не станет полным; ② аномальная плотность знаков (знак препинания на каждые 2–3 знака) → удалить лишние знаки, пересобрать в естественный речевой поток; ③ диалог и описание действия разорваны → объединить реплику и действие одного и того же человека в один абзац.
     - **Скачки точки зрения**: в одном абзаце несколько воспринимающих субъектов, в сцене беспорядочная смена нескольких точек зрения. → Ремонт: зафиксировать основную точку зрения, удалить показ восприятия неключевых персонажей, добавить сигналы перехода.
6. **Фразовая доводка и повторная проверка цепочки**:
   - Использовать «карточку повторной проверки сохранения ответственности цепочки после шлифовки», чтобы подтвердить, что продающие точки, награда, хук и ответственность сцены не сглажены.
   - При фразовой доводке: `references/библиотека-фразовых-действий-шлифовки.md` даёт общие справочные приёмы фразовой правки (сжатие абстрактных слов, переделка обобщающего продвижения, разбор поясняющих фраз, различие голосов в диалоге и т. д.).
   - Убрать шаблонный тон ИИ / следы «топора и стамески» → читать по необходимости `references/карточка-снятия-следов-топора-и-прозрачного-повествования.md`
   - Нужно повысить плавность текста → читать по необходимости `references/колонка-tencent-четыре-уровня-плавности-текста.md`
   - Нужно усилить чувство ритма и краткость → читать по необходимости `references/колонка-tencent-чувство-письма-и-лаконичный-ритм.md`
   - Нужно усилить образность → читать по необходимости `references/приёмы-усиления-образности.md` (см. раздел «Специальное усиление образности» выше)
   - Эффект погружения и эмоциональный опыт читателя → читать по необходимости разделы «Напоминания о читательских механизмах» и «Красные линии» в `references/приёмы-усиления-шлифовки-и-читательские-механизмы.md`
7. **Проверка читательской рентабельности (общая для всех платформ)**: сославшись на раздел «Проверка читательской рентабельности» в `references/контрольный-список-шлифовки.md`, провести по всей главе самопроверку «три вопроса к каждой фразе» — к каждой неразговорной/недейственной повествовательной фразе спросить: потеряется ли информация, если убрать? Оборвётся ли цепь эмоций, если убрать? Рухнет ли сопереживание сцене, если убрать? Фразы, которых «может и не быть», удалять прямо. Доля чисто описательных фраз об окружении / атмосфере во всей главе — ≤ 5%. **Применимо ко всем платформам веб-новелл, на бесплатных платформах (Qimao/Fanqie и др.) исполнять особенно строго. Можно дополнительно применять метод самопроверки в четыре шага из `references/дополнение-читательская-рентабельность-и-телефон.md`.**

## Новые пункты внимания этого раунда доводки (новое)

- По умолчанию в первую очередь оценивать, доставили ли первые `300` знаков зацепку по персонажу, первое давление и вопрос, ради которого читатель продолжит читать.
- **Проверка входа в начало главы по «методу трёх фраз» (из «包罗万象»)**: при шлифовке начала главы проверить, выполнили ли первые три фразы три задачи — «вопрос + эмоция + вовлечение». Если в трёх фразах только «пояснение информации», а не «приманка для читателя», пометить как ключевую проблему начала главы и в первую очередь переделывать первые 1–3 фразы, а не шлифовать последующие абзацы.
- **Распознавание «начала-среза» (из «包罗万象»)**: если нынешнее начало главы — обобщающее повествование («стиль конспекта», например «главный герой — такой-то, с такими-то задатками, как он будет делать то-то»), нужно в первую очередь переписать его в «срез» — вырезать самый напряжённый/самый аномальный/самый драматичный момент героя как якорь начала. Сначала решить, нужно ли целиком перекроить начало, затем определять силу шлифовки. **Обобщающее начало шлифовкой не спасти, его нужно переписывать, а не шлифовать.**
- Шлифовка середины не должна лишь делать фразы глаже; нужно убедиться, что в главе есть хотя бы одна существенная награда на уровне эмоций, отношений, информации, действия или статуса.
- При доводке в первую очередь переписывать абстрактные суждения в действия, ощущения, предметы, паузы, конкретные выборы и видимые последствия, сокращая итоги автора за персонажа.
- По умолчанию считать самоссылки на главы, тон сериального путеводителя и интонацию авторского разбора происшествиями погружения: при появлении «这几章» (эти несколько глав), «前几章» (первые несколько глав) и их вариантов «前面几章 / 前面这几章», «后几章» (последние несколько глав) и вариантов «后面几章 / 后面这几章», «整章» (вся глава) и вариантов «这整章 / 这一整章», «上一章» (предыдущая глава), «下一章» (следующая глава), «本章 / 这章» (эта глава), «后文会» (дальше будет), «我们会看到» (мы увидим), «读者会发现» (читатель обнаружит) и т. п. в первую очередь переписывать их в ощущаемые персонажем в данный момент последствия, воспоминания, отголоски отношений или конкретные действия.
- Если исходный черновик на большом протяжении усреднён, группы фраз одинаковой ширины, абзацы слишком толстые, по умолчанию попутно сделать удобное для телефона сжатие, но нельзя сжимать информацию и ритмические биты.
- Обаяние и уязвимость важного персонажа должны быть видны одновременно; шлифовка не должна превращать настоящие слабости в «безупречный блеск».- **Повышение выражения эмоций (новое — заимствовано у автора ответов Zhihu «小恐龙»)**: при доводке фразы, где «прямо пишутся слова эмоций» (гнев/печаль/страх/радость и т. п.), в первую очередь поднимать до уровня поведения/мимики/действия — «他很愤怒» (он очень зол) → «他砸了电话» (он швырнул телефон), «他握着手机的手指节发白» (костяшки пальцев, сжимающих телефон, побелели). Принцип градации выражения эмоций по умолчанию: чем дальше способ письма от базовой эмоции, тем он выше. Подробнее см. `../общий-исполнение-сценической-единицы/references/избранное-zhihu-четыре-измерения-слога-и-рамка-взаимодействия.md`, раздел третий.
- **Проверка взаимодействия окружения и персонажа (новое)**: при шлифовке абзацев об окружении проверять, вступил ли персонаж во взаимодействие с окружением (испытал влияние окружения, использовал предметы обстановки, сделал суждение из-за окружения). Если персонаж и окружение похожи на две параллельные прямые, не касающиеся друг друга, по умолчанию нужно добавить взаимодействующее действие. «Описание окружения без взаимодействия не стоит сохранять» (слова «小恐龙»).
- **Диагностика замены прилагательных глаголами (новое — заимствовано у «喷神 · 好难说故事» с Zhihu)**: когда основной текст при чтении «слова верны, но картины нет», в первую очередь диагностировать «слишком много прилагательных, не хватает глаголов». Направление шлифовки:
   - Искать в тексте входы в сцены, обобщённые абстрактными прилагательными («一道清亮的女声响起» (раздался чистый женский голос), «一个安静的午后» (тихий полдень), «一张帅气的脸» (красивое лицо) и т. п.), заменять на «базовое описание + глагол + слова-опоры».
   - Количественная проверка соотношения глаголов/прилагательных: если в первых 300 знаках число прилагательных больше 1/3 числа глаголов, это считается избытком прилагательных, нужно заменять пофразно.
   - Тест замкнутого цикла: после написания отшлифованного абзаца «закрыть глаза и представить» — складывается ли из этого абзаца картина в голове? Если нет, значит, слишком много украшающего языка и недостаточно глагольной тяги.
- **Тест входа в первый абзац начала (новое — заимствовано у «喷神 · 好难说故事» с Zhihu)**: при шлифовке начала главы провести с первым абзацем основного текста «тест картины с закрытыми глазами» — закрыть глаза: складывается ли из этого текста сцена в голове? Если нет, значит, язык первого абзаца «не имеет опоры», нужно в первую очередь заменить абстрактные прилагательные на глагол + конкретное поведение. Подробнее см. «железные законы оживления письма» в `общий-создание-основного-текста`.
- **Метод принудительных самовопросов об удалении (новое — заимствовано у «执光赴君 · опыт автора 24 книг с контрактами» с Zhihu)**: при шлифовке к каждому абзацу основного текста применять самопроверку «обточка до кости»:
   - Можно ли удалить эту фразу?
   - Нужна ли эта деталь?
   - Можно ли сжать этот эпизод?
   - Что можно удалить — удалить, что можно сжать — сжать, убрав лишнее, оставить только ключевую информацию и ключевые точки 爽.
   - Особо чувствительная зона: когда описание/пояснение превышает 3 фразы и читатель уже понял замысел, по умолчанию нужно сжать до 1–2 фраз.
- **Правило ограничения тонкого описания тремя местами (новое — заимствовано у «执光赴君»)**: тонкое описание (нагнетание эмоций, прорисовка деталей, нагнетание окружением) используется лишь в следующих трёх местах, любое лишнее место — излишне:
   1. **Ключевая эмоция**: момент контратаки героя, успешной мести, потери важного человека — тонким описанием усилить эмоцию, вызвать сопереживание у читателя.
   2. **Ключевой персонаж**: ключевая черта героя, коварство и хитрость злодея — тонкими деталями прорисовать, сделать персонажа объёмнее.
   3. **Ключевой узел**: крупный поворот сюжета, момент взрыва кульминации — тонким описанием нагнести атмосферу, придать сюжету больше удара.
   - Помимо этого основной текст всегда писать кратко. Многословная тонкость по сути затягивает ритм. Если при шлифовке встретится тонкое описание «не в трёх местах», по умолчанию сжимать.
- **Проверка единой задачи абзаца (новое — заимствовано у «白菜对我笑» с Zhihu)**: после шлифовки каждого абзаца присвоить абзацу «задачу абзаца»:
   - Этот абзац выдвигает суждение?
   - Этот абзац объясняет причину?
   - Этот абзац приводит пример?
   - Этот абзац даёт метод?
   - Если для абзаца не удаётся указать «чем именно занят этот абзац», скорее всего, это лишний абзац, в первую очередь рассмотреть слияние или удаление.
   - Способ исполнения: прочитать всю главу, после каждого абзаца кратко пометить в скобках тип задачи. Абзацы, для которых тип не помечается, отметить как «без ясной задачи» и включить в список кандидатов на удаление.
- **Метод тренировки «абстрактное слово → действие» (новое — заимствовано у «白菜对我笑» с Zhihu)**: при шлифовке основного текста обвести абстрактные слова (старание, рост, разбитость, трезвость, страдание, чувство гнёта и т. п.), затем заставить себя сделать трёхслойную переписку:
   - Если это состояние превратить в действие, каким оно будет?
   - Если эту эмоцию превратить в выражение лица, каким оно будет?
   - Если эти отношения превратить в одну реплику диалога, какой она будет?
   - Не обязательно переписывать каждое место, но в ключевых позициях (начало главы, первое появление персонажа, абзац кульминации, точка эмоционального взрыва) хотя бы раз обязательно выполнить превращение «абстракция → действие».
   - Пример: «他很愤怒» (он очень зол) → «他把杯子放下时，杯底磕在桌上，茶水溅出来一圈。他没擦。» (Он поставил чашку, донышко стукнуло о стол, чай расплескался кругом. Он не вытер.)
- **Метод проверки «ну и что?» в причинной цепи (новое — заимствовано у «白菜对我笑» с Zhihu)**: при шлифовке логических связей между абзацами после каждого абзаца задавать вопрос «ну и что?». Если абзац не может ответить на «ну и что?», значит, это лишь нагромождение информации, а не причинное продвижение.
   - Способ исполнения: дописав/отшлифовав абзац, рядом записать самовопрос «ну и что?». Если ответ после самовопроса повторяет вывод предыдущего абзаца, этот абзац нужно слить или прямо удалить.
   - Идеальное состояние: между абзацами всей главы образуется причинная цепь замков «потому что A → поэтому B → потому что с B возникла проблема → поэтому нужно C → если C сделано плохо → угодим в яму D → поэтому в конце нужно проверять через E», а не рыхлый перечень «сначала высказать мнение → затем привести пример → затем дать метод».
- **Многословная тонкость затягивает ритм — самопроверка числа знаков при шлифовке (новое — синтез мнений нескольких авторов Zhihu)**: если при шлифовке обнаруживается, что где-то описание/лирика/нагнетание окружением превышает 100 знаков и не продвигает сюжет и не меняет состояние персонажа, в первую очередь определить: какой вклад вносит этот отрывок в то, «что нового узнал читатель, прочитав его»? — если после удаления понимание сюжета/персонажей читателем не страдает, значит, это «тонкость, затягивающая ритм», нужно прямо сжать или удалить.
- **Метод канцелярского ножа — быстрая самодиагностика перед взрывной точкой (новое — заимствовано у «我的世界» с Zhihu)**: когда кажется, что написано очень много подводки, а взрывная точка не выходит, использовать метод канцелярского ножа для самодиагностики:
   - Закрыть абзац, который сейчас шлифуется, и смотреть только на последнюю строку.
   - Спросить себя: если всю предшествующую подводку удалить целиком и читатель начнёт читать сразу с этой строки, не станет ли острее?
   - Если ответ «станет», значит, всю подводку выше можно сжать или даже прямо удалить, оставив только последнюю строку.
   - Стратегия исполнения при шлифовке: найти абзацы, где «самая яркая часть спрятана в воде», вынести яркую фразу в начало абзаца, подводку сжать или удалить абзац целиком.
- **Соразмерность подробности и краткости — проверка «одним штрихом» для непродающих абзацев (новое — заимствовано у «半盏清茶煮春秋» с Zhihu)**: при шлифовке просмотреть распределение объёма по всей главе и проверить, «не получают ли продающие и непродающие точки несоразмерное отношение»:
   - Пометить абзацы основных продающих точек/ярких моментов/точек 爽 этой главы и убедиться, что их доля объёма ≥ 30% от всей главы. Если суммарная доля знаков продающих абзацев < 30%, значит, самое привлекательное место главы не получило достаточного пространства для развёртывания.
   - Выявить «важные, но скучные» эпизоды (герой в дороге, покупка снаряжения, скучные собрания, повседневные повторяющиеся действия и т. п.) и убедиться, что эти абзацы сжаты до 1–3 фраз «одним штрихом». Если такой абзац превышает 3 фразы или разворачивается как самостоятельная сцена, сжать до 1–2 фраз или прямо удалить.
   - Подсказка по исполнению: повествование в духе «на Восточном рынке купил скакуна» — признать, что это произошло, но не нужно показывать, как это произошло.
- **Метод шлифовки через удаление мусорных слов — десять мусорных слов на первоочередное удаление (новое — заимствовано у «顾里木图的小酒馆» с Zhihu)**: первый ход шлифовки — не менять строение фраз, а вычистить следующие частые мусорные слова. В подавляющем большинстве случаев после удаления этих слов фраза становится сильнее:
   - **Приоритет удаления**: 非常 > 很 > 特别 > 真的 > 其实 > 我觉得 > 突然 > 然后 > 那么 > 就这样 (очень > весьма > особенно > правда > на самом деле > мне кажется > вдруг > потом > тогда > вот так)
   - **Правило**: искать в тексте перечисленные слова; за исключением тех, что в диалоге оставлены для передачи интонации персонажа (нужно судить, является ли это чертой голоса персонажа), остальные удалять без исключения.
   - **Исключение**: когда «突然» (вдруг), «很» (весьма), «非常» (очень) несут ритмическую функцию (например «突然» в «他突然停住了脚步» (он вдруг остановился) служит созданию ощущения паузы), можно сохранить и провести тест — страдает ли ритм после удаления. Если не страдает — удалить, если страдает — оставить.
   - **Принцип**: после удаления наречий, прилагательных, связок оставшиеся существительные и глаголы — это и есть кость и плоть. Нельзя нагромождением украшательств изображать хороший слог.
- **Приёмка шлифовки чтением вслух (новое — заимствовано у «顾里木图的小酒馆» с Zhihu)**: по завершении шлифовки обязательно **прочитать отшлифованный основной текст вслух** (чтение про себя не считается). Чтение вслух — итоговый способ приёмки качества шлифовки:
   - **Пункты проверки при чтении вслух**:
     1. **Читается ли гладко** — любые места, где язык заплетается, трудно перевести дыхание, трудно выговорить, отметить как фразовую проблему и вернуться к шагу 6 на фразовую доводку.
     2. **Не плоский ли ритм** — если от начала до конца читается одной интонацией, значит, ритм не обработан — должна быть стремительность в напряжении и расслабленность в спокойствии. Отметить проблему ритма и вернуться к шагу 4 «ремонт цепи дочитывания».
     3. **Не звучит ли фальшиво** — если диалог при чтении вслух похож на «зачитывание отчёта», а не на «речь людей», отметить проблему диалога и вернуться к маршрутизации слабых мест.
   - **Критерий приёмки**: после чтения вслух те места, где «только при чтении вслух поняла, что не так», — это места, где шлифовка ещё не доведена. Чтение вслух заставляет столкнуться с реальным ритмом текста — это то, что чтение про себя никогда не обнаруживает.

7. **Проверка читательской рентабельности (добавлена 2026-06-22 · специально для Qimao/бесплатных платформ)**: сославшись на раздел «Проверка читательской рентабельности» в `references/контрольный-список-шлифовки.md`, провести по всей главе самопроверку «три вопроса к каждой фразе» — к каждой неразговорной/недейственной повествовательной фразе спросить: потеряется ли информация, если убрать? Оборвётся ли цепь эмоций, если убрать? Рухнет ли сопереживание сцене, если убрать? Фразы, которых «может и не быть», удалять прямо. Доля чисто описательных фраз об окружении / атмосфере во всей главе — ≤ 5%.
Образность — это не «пышные красоты», а «читатель может в голове увидеть, что именно происходит». Каждое действие при шлифовке основного текста служит этой цели. В этом разделе даётся быстрая диагностика усиления образности и указания к действию, полная система приёмов — в `references/приёмы-усиления-образности.md`.

### Шестишаговая диагностика образности

Когда абзац при чтении «вся информация на месте, но картины нет», проверять в следующем порядке:

1. **Есть ли видимый предмет?** → Может ли читатель представить хотя бы один конкретный предмет / часть тела / сцену? Если нет — добавить.
2. **Точны ли глаголы?** → Нет ли слабых глаголов, которые можно заменить сильными? Нет ли ярлыков эмоций вместо действий?
3. **Ясны ли пространственные отношения?** → Где персонаж? Где предметы? Как далеко? Как перемещаются?
4. **Есть ли свет?** → День или ночь? Светло или темно? Что свет делает с персонажем?
5. **Есть ли смена чувств?** → Нет ли 3 и более фраз подряд только со зрением? Не нужно ли добавить слух/осязание/обоняние?
6. **Есть ли запоминающаяся деталь?** → Есть ли в 100 знаках деталь, которую читатель запомнит? Если нет — убрать избыточное украшательство, заменить информативной деталью.

### Формулы быстрого ремонта образности

```
Слишком много информации, нет картины → найти один конкретный предмет-опору
Слишком пустое действие, нет картины → точнее подобрать глагол
Слишком пустое окружение, нет картины → добавить пространственную координату + свет
Психология слишком глубока, нет картины → сначала превратить психологию в телесную реакцию
Эмоция слишком густая, нет картины → заменить прилагательные действием
Диалог слишком сухой, нет картины → добавить паузу + мелкое действие + пространственные отношения
```

### Сознание камеры

При шлифовке выстраивать сознание камеры «текст — это кинокамера»:

- **Крупный план** (предмет / выражение лица / деталь) → ключевые улики, ключевые эмоции, ключевые повороты
- **Средний план** (действие / взаимодействие) → главная камера, продвигающая сюжет
- **Общий план** (окружение / пространственные отношения) → установление сцены, изложение обстановки

Когда 3 и более фраз подряд используют один и тот же план, рассмотреть смену дистанции камеры, чтобы нарушить монотонность.

### Направленная активация чувств

Не равномерно распределять пять чувств, а выбирать 1–2 ведущих чувства в зависимости от сцены:

- **Страх/напряжение**: осязание (холод на затылке) + слух (звук дыхания/шагов), избегать множества зрительных описаний
- **Интрига/тревога**: слух (необычные звуки/внезапная тишина) + обоняние (странный запах)
- **Гнев/конфликт**: зрение (красное/белое) + осязание (сжатый кулак/дрожь)
- **Гнёт/тяжесть**: осязание (температура/фактура) + слух (низкочастотные звуки)

## Справка по температуре модели по умолчанию (новое)

Шлифовка основного текста — операция правки в рамках уже определённого направления, рекомендуется использовать среднюю температуру, чтобы избежать чрезмерной переписки.

| Этап | Рекомендуемая температура | Пояснение |
|---|---|---|
| Шлифовка всей главы / доводка | 0.45 | Направление определено, умеренные ограничения |
| Локальное переписывание / локальное усиление | 0.45 | То же |

## Дополнение: границы шлифовки, порядок обработки и защита эмоциональной арки (новое)

- Если в этом раунде одновременно присутствуют проблемы устранения «духа ИИ», диалога, описаний, ритма и формулировок, приоритет обработки по умолчанию такой: **устранение «духа ИИ» → правка диалога → очистка описаний → микронастройка ритма → оптимизация формулировок**.
- Критерий шлифовки — «как писать», а не «что писать»; если проблема затрагивает добавление/удаление сцен, перестановку событий, изменение выбора персонажа, добавление интриг, добавление несущих битов или перестройку причинности, обязательно явно вернуть её на `writer / контрольную карточку / слой основного текста`, а не продолжать тащить шлифовкой.
- Правка диалога по умолчанию режет только на уровне формулировок, пометок, различия голосов и согласования с действиями, не меняя фактическое содержание, которое несёт диалог; если для состоятельности необходимо менять содержание диалога, значит, выход за границу шлифовки.
- Очистка описаний по умолчанию следует принципам «вынесение эмоции вовне / контроль фокуса / активация чувств / сдержанность метафор», не принимая плотность и пышность за качество.
- Микронастройка ритма по умолчанию в первую очередь делается длиной абзацев, длиной фраз, переходами, короткими обрывами и точками дыхания, нельзя сглаживать награду в середине исходной главы, пик кульминации или хук конца главы.
- После шлифовки обязательно явно перепроверить эмоциональную арку: остаются ли состоятельными запланированные вход / выход, не ослаблен ли пик, не усилена ли впадина; если вход ≈ выход и нет разумного нового замысла, пометить как структурный риск и вернуть выше по цепочке.
- В конце раунда по умолчанию выдавать краткую справку о шлифовке: какие проблемы обработаны, сохранена ли эмоциональная арка, какие проблемы вышли за границы шлифовки и должны быть переданы `writer`.

## Правила маршрутизации слабых мест

- Диалог прямолинеен, интонации смешаны, сильный объяснительный тон → путь ремонта «языкового типа»
- Действие пустое, продвижение держится на обобщениях → путь ремонта «типа действия»
- Психология пустая, эмоция умеет только называться прямо → путь ремонта «психологического типа»
- Лицо персонажа расплывчато, у мимики нет опоры → путь ремонта «портретного типа»
- Окружение не стоит, атмосфера не втягивает → путь ремонта «типа пейзажа»
- Комнатные предметы и улики написаны мёртво → путь ремонта «статического типа»
- Многолюдная сцена не горячая и не напряжённая, нет фокуса → путь ремонта «типа сцены»

Конкретное разветвление и ключевые моменты обработки исполнять по `references/расширенная-маршрутизация-справок-шлифовки.md`.

Когда слабое место чётко попадает в определённое измерение описания, читать по необходимости соответствующие файлы руководства по письму из «Продолжить чтение references > Маршрутизация по слабым местам — библиотека приёмов описания (по выбору)». Эти файлы относятся к общей библиотеке приёмов описания, используются только для извлечения углов наблюдения, синтаксических действий, способов организации чувств и опор описания, готовые отрывки из них прямо копировать запрещено.

Когда пользователь явно требует любой из следующих высокоинтенсивных рамок, дополнительно читать `references/продвинутые-приёмы-усиления-шлифовки.md` (этот файл также заранее зарегистрирован в «Продолжить чтение references > Фразовая доводка и общие приёмы»):

- Доводка по рамке полной версии
- Начало с более сильным эффектом удара молнии
- Середина цепче, не проседает
- Хук конца главы смертоноснее
- Сериальность, чувство дочитывания, внутритомная движущая сила сильнее

## Выдача по умолчанию

- Если пользователь говорит «отшлифуй эту главу / доведи основной текст», по умолчанию обрабатывать как формальную шлифовку с записью обратно.
- Только если пользователь явно требует «сначала показать пример / сначала посмотреть план / не записывать в файл», переходить в режим примера.
- По завершении кратко изложить, какие именно пункты были усилены: начало / середина / хук / диалог / действие / эмоции / атмосфера.

## Правила шлифовки основного текста для предельно быстрого ритма и предельно сильного конфликта (новое)

### Основное направление шлифовки быстрого ритма

**1. «Разнообразие длины фраз и абзацев»**
Основной текст быстрого ритма должен создавать изменения длины фраз и абзацев, избегая монотонности ровности:
```
Исходный черновик: Чэнь Мянь вошёл в комнату. В комнате было очень темно. Он увидел силуэт, сидящий на стуле напротив. Сердце Чэнь Мяня забилось быстрее. Он медленно пошёл к стулу. Силуэт вдруг встал.

Направление шлифовки: смена длины фраз + плотность коротких фраз
Чэнь Мянь толкнул дверь. В комнате было черным-черно. Из темноты поднялась фигура. Нет. Это не поднялась — это рванулась из тьмы. Шаг Чэнь Мяня запнулся.

[Чередование «короткая — короткая — средне-длинная — короткая» создаёт ощущение ускорения]
```

**2. «Активизация глаголов» и «мгновенность временных сигналов»**
Основной текст быстрого ритма должен по возможности использовать «глаголы мгновенного действия» вместо «происходящей психологии» или «предположений о возможном»:
```
❌ Чэнь Мянь вспомнил, как в прошлый раз видел этого человека. Тогда тот сказал, что если встретятся снова, то больше не друзья. Чэнь Мянь осознал, что ему, возможно, грозит какая-то опасность.

✅ Чэнь Мянь узнал его. «Если встретимся снова, больше не друзья». Прошлые слова всплыли в голове. Опасность была уже совсем рядом.
```

Быстрая версия использует мгновенные глаголы «узнал, всплыли, совсем рядом» вместо «вспомнил, осознал, возможно».

**3. «Намеренная расстановка поворотных точек и разрывов ритма»**
Основной текст быстрого ритма должен сознательно создавать несколько «разрывов» или «поворотов», чтобы психологический ритм читателя колебался вместе с ними:
```
Исходный черновик: Чэнь Мянь вошёл и обнаружил в комнате человека, он удивился, но подумал, как следует реагировать.

Шлифовка:
Чэнь Мянь толкнул дверь.
В комнате кто-то был.
Это был — невозможно.
Он должен быть в больнице.
```

Разрывы, создаваемые короткими обрывами, заставляют ритм колебаться.

### Основное направление шлифовки сильного конфликта

**1. «Конкретизация противостояния» и «мгновенность столкновения позиций»**
Основной текст сильного конфликта должен превращать любое «противостояние» в конкретное, видимое, мгновенно происходящее столкновение, а не в абстрактную угрозу или пустое напряжение:
```
❌ Чэнь Мянь и человек напротив оказались в противостоянии. Они хотели разного. Чэнь Мянь очень боялся, но не хотел отступать.

✅ Чэнь Мянь уставился на человека напротив. «Положи деньги», — сказал тот. «Сначала отпусти человека», — сказал Чэнь Мянь. Два взгляда столкнулись в воздухе. Две линии, не способные к компромиссу.
```

Сильная версия дала «противостоянию» тело, речь и ощутимое столкновение.

**2. «Овеществление цены» и «телесность последствий»**
Основной текст сильного конфликта должен переписывать любую цену в конкретные последствия, которые «можно увидеть, услышать, ощутить»:
```
❌ Она осознала, что совершила огромную ошибку. Ошибка приведёт к каким-то страшным последствиям.

✅ Нажатая ею кнопка не вернулась. Свет погас. Внизу раздался чудовищный взрыв. Сквозь щель окна просочился пепел.
```

Сильная версия показывает «огромную ошибку» через конкретные действия, звуки, зрительные образы.

**3. «Действенное выражение» власти и разницы положения**
Основной текст сильного конфликта должен выражать неравенство власти через действия, позы, пространственное положение персонажей, а не прямо говорить «он перехватил инициативу»:
```
❌ Похититель получил абсолютную инициативу. Он мог решать жизнь и смерть заложника. Чэнь Мянь чувствовал свою беспомощность.

✅ Похититель откинулся на стуле, закинув ноги на стол, и крутил в руке нож. Чэнь Мянь стоял в пяти шагах, опустив руки вдоль тела. «Говори», — сказал похититель.
```

Сильная версия показывает неравенство власти через стул, ноги, нож, расстояние, команду.

**4. «Информационная асимметрия» в диалоге и деталях**
Основной текст сильного конфликта должен в полной мере использовать то обстоятельство, что «разные персонажи владеют разной информацией», выражая эту асимметрию в диалоге и деталях:
```
Чэнь Мянь не знал, что полиция уже оцепила здание. Поэтому он всё ещё вёл переговоры с похитителем. А похититель знал, что полиция снаружи, поэтому каждая его фраза была зондированием: «Скажи мне, сколько людей снаружи?»

[Из диалога видно: Чэнь Мянь гадает, похититель подтверждает. Это и есть информационная асимметрия.]
```

### Основное направление шлифовки медленного ритма (дополнение — заимствовано из «Приёмы письма — как управлять ритмом романа?» на Zhihu)

Правила шлифовки быстрого ритма решают «как ускорить», следующие правила решают «как замедлить». Медленный ритм — это не «писать хуже», а сознательно заставлять читателя замедлить скорость чтения, усиливая погружение и эмоциональную вовлечённость. Следующие правила действуют на абзацы медленного ритма (воспоминания, одиночество, тонкие чувства, подводка окружения):

**1. «Метод наполнения чувственными деталями»: добавить осязание, запахи и мелкие действия**
Основной текст медленного ритма должен переключиться из режима «продвижения информации» в режим «создания присутствия». Направление шлифовки:
```text
Исходный черновик: Она сидела у окна и думала о прошлом.
Шлифовка: Её пальцы медленно скользили по трещине подоконника. Ощущение заноз под подушечкой пальца вернуло её на десять лет назад. Запах того дня — прогретое на солнце одеяло, ржавчина и мыло, которым пахло от него — будто разом опрокинулся.
```
Ключевой приём: превратить «думать» в «телесное ощущение присутствия» — осязание пальцев, запах носом.

**2. «Растягивание времени камеры»: расписывать мелкие действия подробно, создавая ощущение расширения времени**
Суть медленного ритма — «заставить читателя задержаться в одном мгновении дольше». Направление шлифовки:
```text
Исходный черновик: Он положил фотографию в ящик.
Шлифовка: Его рука зависла над ящиком на две секунды. Человек на фотографии всё ещё смеялся. Он медленно перевернул фотографию и положил лицом вниз на дно ящика, потом закрыл. Язычок замка с «щёлк» вошёл на место.
```
Ключевой приём: разбить одно действие на 2–3 микродействия (зависание → переворот → закрытие → замок), к каждому действию добавить деталь (смеющееся лицо на фото, звук язычка замка).

**3. «Приёмка чередования напряжения и расслабления»: убедиться, что каждый абзац медленного ритма состоятелен в контексте**
После шлифовки абзаца медленного ритма обязательно проверить его положение в ритме всей главы:
- Предыдущий абзац — конфликт быстрого ритма? → Абзац медленного ритма сыграл роль буфера, состоятелен.
- И предыдущий, и следующий абзацы — медленного ритма? → Если подряд 3 и более абзацев медленного ритма и главная линия не продвигается, пометить «ритм слишком медленный», нужно вложить в медленный ритм продвижение информации (даже небольшое: новая зацепка в воспоминании, тонкое изменение отношений).

### Контрольный список для быстрого ритма + сильного конфликта

[ ] Есть ли явные изменения длины фраз (не ровный ритм)?
[ ] Есть ли сознательные колебания длины абзацев (короткие абзацы создают ускорение, длинные — тяжесть)?
[ ] Все ли глаголы мгновенного действия (а не «воображение», «предположение», «возможно»)?
[ ] Ясны ли и продвигаются ли временные сигналы (какой момент, сколько времени, обратный отсчёт)?
[ ] Конкретизировано ли противостояние (не просто «противостояние», а конкретные действия, речь, пространственная конфронтация)?
[ ] Телесна ли цена (не просто «есть последствия», а конкретные последствия, которые можно увидеть, услышать, ощутить)?
[ ] Выражено ли распределение власти через действия и позы (а не прямым повествованием «кто у власти»)?
[ ] Отражена ли информационная асимметрия в диалоге и деталях (чтобы читатель мог заметить «этот человек знает, а тот — нет»)?
[ ] Избежаны ли психологические итоги, авторские реплики «от автора» и абстрактные описания?
[ ] Сохранена ли в целой главе двойная интенсивность «быстро + конфликт», а не откат какого-то абзаца к прежнему ритму?

### Определение подлинности ритма при шлифовке (новое — заимствовано у «丁文韬» и «流浪的蛤蟆» с Zhihu)

> **Основной принцип**: при шлифовке «ритм» легче всего оценить ошибочно. Абзац, который «читается быстро», не означает «хороший ритм» — это может быть просто прямое перечисление событий. Шлифовка должна сначала различить **настоящий ритм** и **ложный ритм (перечень событий)**, затем решать, как править.

#### Суждение при шлифовке: настоящий ритм против ложного

| Сравниваемый пункт | Настоящий ритм | Ложный ритм (перечень событий) |
| --- | --- | --- |
| Ощущение при чтении | У читателя возникает психологическая деятельность «что же будет дальше?», «вот-вот случится?» | Читатель пассивно получает информацию, ожидания нет |
| Структура | Есть интервал «накопление силы — ожидание — отсрочка» | Идёт прямо, A→B→C линейно |
| Высвобождение информации | Выбирается «самый дразнящий момент» для высвобождения | Выбирается «самый удобный момент» для изложения |
| Особенности слога | При быстром ритме плотные короткие фразы, при медленном — погружающие длинные | Длина фраз ровная, нет колебаний ритма |
| Форма обобщения | «Читатель ждёт X → дождался X → начал ждать Y» | «Герой сделал A → сделал B → сделал C» |

#### Пять правил «защиты» ритма при шлифовке

**Правило 1: не смывать структуру «анонс — исполнение» ради «гладкости»**
- Самая частая ошибка при шлифовке: ради более естественных переходов и плавности текста сократить или удалить тот интервал отсрочки, когда «читатель знает, что это придёт, но оно ещё не пришло»
- ❌ Ошибочная шлифовка: «Он толкнул дверь. Директор Ван сидел внутри. „Ты пришёл“. Чэнь Мянь подошёл и сел». (Напряжение интервала отсрочки смыто)
- ✅ Верная шлифовка: «Он толкнул дверь. Директор Ван был здесь — в это время он должен быть в отделе по экономическим преступлениям. „Ты пришёл“. Тон был слишком спокойным. Настолько спокойным, что Чэнь Мянь застыл в дверях». (Сохранён предупреждающий сигнал «что-то не так» и задержка реакции персонажа)

**Правило 2: не подменять «ускорение ритма» «сжатием информации»**
- ❌ Ошибочная шлифовка: решив, что оригинал «слишком многословен», сжать абзац накопления силы и ожидания в одну фразу «он осознал, что ситуация хуже, чем он думал» — информация осталась, но ритма больше нет
- ✅ Верный подход: сохранить объём абзаца накопления силы, направить усилия на повышение информационной плотности и чувственной активации каждой фразы, а не на сокращение знаков

**Правило 3: интервал «читатель знает, что придёт, но ещё не пришло» обязательно сохранять**
- Если в оригинале выявлен такой интервал («читатель уже угадал исход, но история всё ещё размеренно продвигает детали, раз за разом дразня»), это самая ценная зона ритма
- При шлифовке этот интервал **можно только усиливать, нельзя сжимать** — слова удалять, смысл не удалять, длину абзаца можно слегка подправлять, но нельзя срезать абзац целиком

**Правило 4: различать «медленное продвижение» и «хороший ритм»**
- «Медленное продвижение» = низкая информационная плотность, в 600 знаках ничего существенного не продвинулось → нужно сжать или переписать
- «Хороший ритм» = высокая информационная плотность, но с намеренной отсрочкой ключевого раскрытия → ни в коем случае не сжимать
- Критерий: извлечь «объём новой информации» из этого оригинального отрывка; если после удаления отсрочки объём информации почти не изменился → это хороший ритм; если отсрочка повторяет ранее сказанное → это медленное продвижение

**Правило 5: после шлифовки перепроверить, «не смыта ли цепочка анонсов точек 爽»**
По завершении шлифовки ответить по пунктам:
1. Ясно ли позиционирование анонса точек 爽 этой главы (глава-анонс / глава накопления силы / глава исполнения / переходная глава)? Если позиционирование размылось → цепочка анонсов смыта
2. Остаётся ли в начале главы сигнал анонса «скоро будет хорошее/плохое»? Если сигнал анонса ослаблен шлифовкой → цепкость начала главы упала
3. Есть ли в середине ясный интервал «накопление силы → ожидание»? Если абзац накопления сжат → ритм стал плоским
4. Продолжает ли конец главы создавать ожидание «в следующей главе будет жарко»? Если конец главы превращён в итоговую концовку → движущая сила перелистывания упала

**Шлюз исполнения**: если по двум и более из четырёх пунктов выше ответ «да (смыто)», шлифовка требует переплавки — защита ритма не обеспечена.

## Жёсткие правила

- Не добавлять ключевые факты, не убирать ключевую информацию.
- Пока не внимательно прочитаны биографии персонажей и документы сеттинга / фона, относящиеся к этой главе, нельзя прямо переписывать мотивы персонажей, состояние отношений, проявление правил, положение улик или фоновые факты.
- Нельзя превращать основной текст в инструкцию, эссе или пустую лирику.
- Нельзя «зашлифовать» награду в середине и хук конца главы.
- **Приоритет доводки на удержание**: в первую очередь исправлять проблемы «читатель может бросить» (слишком медленное начало / плоская середина / слабый хук), затем проблемы «написано недостаточно хорошо» (формулировки / микронастройка ритма). По завершении шлифовки самопроверка: сохранилась ли плотность эмоциональных раздражителей на уровне исходного черновика? Если после устранения «духа ИИ» / сглаживания точек эмоционального стимула стало меньше, часть правок обязательно откатить.
- **Защита плотности глаголов** (новое): в процессе шлифовки нельзя ради «гладкости», «плавности», «устранения духа ИИ» заменять ключевые глаголы действия прилагательными/абстрактными выражениями.
