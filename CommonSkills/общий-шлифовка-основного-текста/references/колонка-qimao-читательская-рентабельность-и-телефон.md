## P0. Ключевое резюме

### Определение читательской рентабельности

«Читательская рентабельность» на Qimao/бесплатных платформах — это: **объём сюжетной информации продвижения, который несёт каждая фраза, против времени пролистывания читателем, которое эта фраза занимает**.

```
Читательская рентабельность = объём сюжетной информации продвижения (конфликт + информация + изменение отношений + эмоциональный поворот + продвижение интриги)
              ────────────────────────────────────────────────
              число пролистываний экрана телефона этим абзацем (оценка: каждые 60 знаков / полэкрана)
```

- Чистое нагнетание атмосферы / описание окружения / затягивание внутреннего мира → **высокая стоимость, низкая отдача** (знаменатель велик, числитель мал)
- Конфликт / диалог / получение информации / изменение отношений → **высокая отдача** (числитель велик)
- Если при каждом пролистывании экрана читатель не видит продвижения сюжета, вероятность ухода удваивается

### Базовая линия читательского поведения на Qimao

| Показатель поведения | Данные |
|:---|:---:|
| Длительность одного чтения | 5–15 минут урывками (дорога / обед / перед сном) |
| Скорость чтения одной главы | 30–45 секунд на главу (с пролистыванием и паузами) |
| Способ получения информации | В основном беглое чтение — взгляд сканирует «кто что говорит + что происходит» |
| Порог терпения к информации | 3 абзаца подряд (около 200–300 знаков) без «сигнала продвижения» → пролистывание или уход |
| Частота эмоциональных стимулов | Нужен как минимум 1 стимул на каждые 300–500 знаков (конфликт / крылатая фраза / разворот / сигнал отношений / интрига) |

### Четырёхшаговый метод самопроверки читательской рентабельности для Qimao

#### Шаг 1: диагностика типа начального абзаца главы

Проверить тип первых 3 абзацев главы. Ранжирование допустимых на Qimao типов начала главы (от лучшего к худшему):

| Приоритет | Тип начала главы | Пример | Соответствие Qimao |
| :---: | :--- | :--- | :---: |
| 1 | **Прямой конфликт** | «Когда он толкнул дверь, я как раз подписывала соглашение о разводе». | ⭐⭐⭐⭐⭐ |
| 2 | **Разрыв-интрига** | «На экране телефона всего три знака: Четвёртый цех». | ⭐⭐⭐⭐⭐ |
| 3 | **Начало с диалога** | «„Говорят, ты только что развелась“. Она сказала это с улыбкой». | ⭐⭐⭐⭐ |
| 4 | **Начало с действия** | «В три часа ночи она переворачивала седьмой договор». | ⭐⭐⭐⭐ |
| 5 | **Аномалия / нелогичность** | «Будильник не прозвенел. Но экран её телефона светился». | ⭐⭐⭐ |
| 6 | **Начало с окружения** | «Солнце светило в окно, листья платана колыхались на ветру». | ❌ **Недопустимо** |

> **Принцип**: на Qimao в первых 200 знаках основного текста не допускается начало с чистого описания окружения/атмосферы. Описание окружения может появляться после события для эмоционального закрепления, но не до события для нагнетания атмосферы.

#### Шаг 2: три вопроса к каждой фразе всей главы

К каждой повествовательной фразе, не являющейся диалогом и не продвигающей действие, задать три вопроса:

| # | Вопрос | Ответ = удалить | Ответ = оставить |
|:---:|:---|:---|:---|
| 1 | Если удалить эту фразу, упустит ли читатель сюжетную информацию? | Нет → удалить | Да → оставить |
| 2 | Если удалить эту фразу, оборвётся ли цепь эмоций читателя? | Нет → удалить | Да → оставить |
| 3 | Если удалить эту фразу, рухнет ли сопереживание сцене? | Нет → удалить | Да → оставить |

**Ключевые принципы суждения**:
- «Эта фраза написана неплохо» ≠ причина оставить
- «После удаления этой фразы теряется ключевая информация или эмоциональный якорь» = причина оставить
- Если после удаления «атмосфера лишь чуть пожиже», но «продвижение сюжета не страдает» → обязательно удалить
- Если после удаления «читатель не знает, где находится персонаж» (например, пространственные отношения) → оставить (но сжать до 1 фразы)
- Если после удаления «эмоциональный разрыв слишком велик» → оставить (но можно добавить до или после якорное действие вместо чистого описания)

#### Шаг 3: обнаружение костыля OS-повествования

Для OS героини, попавшей в книгу / холодноюморных реплик за кадром / внутренних OS в основном тексте:

**Критерий костыля**: если убрать эту OS, сможет ли читатель всё равно полностью понять происходящее продвижение сюжета?

- Может понять → OS не костыль, а стилистический инструмент, можно оставить (но контролировать объём)
- Не может понять → OS есть повествовательный костыль, обязательно исправить

**Исправление костыля**: преобразовать информацию из OS в естественное повествование «поведение + суждение + контраст с окружением». Не просто удалить — вернуть основному тексту работу, которую выполняла OS.

**Пример исправления костыля**:

```
# До исправления (OS-костыль)
OS попаданки: *Страница 72 исходной книги. Число знаков не сходится. Ты сказал реплику, которой в исходной книге нет.*
→ Без этой OS читатель не узнает, что «его слова отклонились от исходной книги»

# После исправления (поведение вместо OS)
Она не села сразу. Она думала об одном: на странице 72 исходной книги написано: «Он сказал „Этим займусь я“ и ушёл». Но „займусь я“ он не говорил. Он сказал: «Я переоценил себя».
→ Читатель получает информацию об «отклонении» естественно, через процесс внутреннего рассуждения героини, OS не нужно выкрикивать
```

```
# До исправления (OS-костыль)
OS попаданки: *Страница 94 исходной книги. Пропало. Это я сама написала.*
→ Без этой OS читатель не узнает, что «исходная книга отклонилась»

# После исправления (поведение + контраст вместо OS)
Она сидела в темноте. Той аварии не было. Она сама её переписала — никто не знал, включая её саму, которая такого не предполагала.
→ Пространство действия (темнота) + контраст (не было) заменяют прямое объявление в OS
```

#### Шаг 4: оценка удержания через пересчёт скорости чтения

Выбрать из всей главы абзацы «чистого описания окружения/атмосферы», подсчитать общее число знаков и подставить в следующую формулу:

```
Общее число знаков абзацев атмосферы ÷ 60 знаков/экран = число пролистываний экрана, занятых абзацами атмосферы
Число пролистываний, занятых абзацами атмосферы × доля ухода на абзацах атмосферы (≈15%/экран) = ожидаемый процент ухода из-за абзацев атмосферы
```

**Пример**: глава целиком ~2000 знаков, чистое описание окружения/атмосферы ~180 знаков
```
180 ÷ 60 = 3 пролистывания (читатель пролистал 3 экрана ради атмосферы)
3 × 15% = 45% (дополнительный риск ухода из-за описания атмосферы в этой главе)
```

**Цель Qimao**: чистое описание окружения/атмосферы ≤ 5% всей главы, превышение обязательно сжать или преобразовать в абзац продвижения.

## Количественный стандарт плотности абзацев основного текста на Qimao

| Показатель | Стандарт Qimao | Способ проверки |
|:---|:---:|:---|
| Длина абзаца | ≤ 3 строк (экран телефона) | Достаточно на глаз, при превышении разбить абзац |
| Плотность полезной информации одного абзаца | Каждый абзац содержит как минимум 1 «сигнал продвижения» | Беглым чтением определить положение «сигнала продвижения» (сигнал продвижения = конфликт / информация / изменение отношений / решение / эмоциональный поворот / продвижение интриги) |
| Интервал между последовательными сигналами продвижения | ≤ 300 знаков | Взять из текста любые 300 знаков и проверить, есть ли ≥ 1 сигнал продвижения |
| Доля чистого описания окружения | ≤ 5% всей главы | Подсчитать после выделения |
| Тип начала | Не начало с окружения | Проверить, начинаются ли первые 3 абзаца главы с события |

## Связь с существующими правилами

Это дополнение даёт специализированные для платформы Qimao средства диагностики читательской рентабельности. Когда целевая платформа шлифовки — Qimao, **обязательно накладывать четырёхшаговый метод этого дополнения** на шаг 7 «Проверка читательской рентабельности» общего процесса шлифовки:

1. Диагностика типа начального абзаца главы → проверка первых 200 знаков главы
2. Три вопроса к каждой фразе всей главы → этап пофразной самопроверки
3. Обнаружение костыля OS-повествования → повторная проверка на устранение «духа ИИ»
4. Оценка удержания через пересчёт скорости чтения → количественная оценка общей доли абзацев атмосферы
