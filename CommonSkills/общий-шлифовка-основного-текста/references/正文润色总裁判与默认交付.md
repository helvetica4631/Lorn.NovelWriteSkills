# Общий вердикт шлифовки основного текста и выдача по умолчанию

## Порядок вердиктов

1. Не терять объём информации, не менять фактические рамки
2. Не нарушать временную линию, цепочку улик, границы правил и отношения персонажей
3. Сначала спасти цепкость начала главы, затем награду в середине, затем намертво закрепить хук конца главы
4. Приоритет — усиление вживания, а не нагромождение красивостей
5. Приоритет — вернуть абстрактные суждения в кадр, а не уводить их всё дальше в пустоту по мере правки

## Цели по умолчанию

- Довести существующий черновик до состояния, в котором его удобнее дочитывать, а не до большей похожести на эссе
- Довести текст «вся информация есть, но похоже на инструкцию» до «вся информация есть и похоже на основной текст»
- Сделать так, чтобы читателю легче было ощутить продвижение, награду, опасность и импульс к следующей главе

## Источник-слой и быстрое определение границ (новое)

- `结构职责层` (слой структурной ответственности): остаются ли состоятельными цепкость начала главы, награда в середине, хук конца главы, основная продающая точка, эмоциональная арка, несущие биты.
- `场景兑现层` (слой исполнения сцены): остаются ли ясными цепочка действий, проявление информации, изменения отношений, цена правил, носитель улик.
- `表达提纯层` (слой очистки выражения): улучшились ли длина фраз, длина абзацев, чувства, действия, паузы, различие голосов, опыт чтения на мобильном.

Порядок по умолчанию: сначала сохранить `结构职责层`, затем `场景兑现层`, наконец править `表达提纯层`; нельзя наоборот, ради гладкости фраз сглаживая первые два слоя.

## Выдача по умолчанию

- По умолчанию записывать обратно прямо в исходный файл
- По умолчанию давать только сводку изменений, не вставлять всю главу в чат
- По умолчанию пояснять: какая глава изменена, полная замена или локальная, какие ключевые точки усилены

## Шаблон справки о шлифовке по умолчанию (новое)

```markdown
【本轮主要处理层】结构职责层 / 场景兑现层 / 表达提纯层 (【Основной обработанный слой этого раунда】слой структурной ответственности / слой исполнения сцены / слой очистки выражения)
【保住的硬钉子】 (【Сохранённые жёсткие гвозди】)
【本轮强化点】章首 / 中段 / 章末 / 对话 / 动作 / 情绪 / 氛围 (【Усиленные точки этого раунда】начало главы / середина / конец главы / диалог / действие / эмоции / атмосфера)
【放行判定】Green / Yellow / Red (【Вердикт допуска】Green / Yellow / Red)
【超出润色边界需回退 writer 的项】 (【Пункты, вышедшие за границы шлифовки и подлежащие возврату writer】)
```

## Стандарт выдачи по образности (новое)

Проверка выдачи после специального усиления образности:

- [ ] Картина первой главы поднята с «информационного слоя» хотя бы до «слоя картины»
- [ ] Достигают ли ключевые сцены (начало / кульминация / поворот) «слоя погружения»
- [ ] Точность глаголов проверена: слабые глаголы → сильные, ярлыки эмоций → действия
- [ ] Чувственная плотность проверена: удовлетворяют ли основные абзацы образности ≥ 2 видам чувств
- [ ] Пространственные отношения проверены: читатель с закрытыми глазами видит «кто где, предмет где»
- [ ] Для абстрактной информации найден хотя бы один видимый носитель
- [ ] Нет ли во всей главе необработанных абзацев «нулевой картины» длиной 300 знаков подряд

## Чего не делать по умолчанию

- Не добавлять из ничего ключевые сюжетные линии и новые сеттинги
- Не переделывать главу целиком в другой стилистический проект
- Не стирать голоса персонажей и реальную фактуру ради «высокого класса»
- Не жертвовать ритмом ради образности — при напряжении ритм образов должен быть быстрым
- Не добавлять многословные описания ради заполнения картины — одна хорошая деталь-якорь > трёх строк общих описаний

## Вердикты допуска Green / Yellow / Red (новое)

- `Green`: глаже, точнее, цепче, при этом структурная ответственность, исполнение сцены и фактические рамки не пострадали.
- `Yellow`: уровень выражения заметно улучшен, но локально ещё нужен один раунд повторной проверки сцены / хука / награды.
- `Red`: после шлифовки появились ложные улучшения вроде «глаже, но слабее», «красивее, но меньше похоже на эту главу», «естественнее, но меньше событий» либо затронуты фактические и структурные границы.
