# общий-эволюция-авторского-стиля

> **Маршрутизация жанров**：универсальное межжанровое тело способности, на него по имени ссылаются внешние Skill каждого жанра (жанровая обёртка несёт лишь жанровые границы; общие методы эволюции всегда возвращаются в этот Skill). **Разделение труда с общий-дистилляция-авторского-стиля**: 蒸馏作者文风 = статическое одноразовое, извлекает «ДНК письма» из уже имеющихся произведений и строит **портрет-семя**; этот Skill = динамическое постоянное, фиксирует оригинальный голос через интервью для **долгой эволюции** и обратной записи в портрет. Они взаимно калибруют: первый отвечает «как автор писал в прошлом», второй — «как автор хочет писать сейчас и каков вкус его речи».

## Применимые сценарии / триггерные фразы

- Чтобы роман «всё больше походил на самого автора», имел уникальные взгляды и вкус повествования: `进化我的文风` (эволюционировать мой стиль), `越写越像我` (чем дальше пишу, тем больше похоже на меня), `挖我的创作观` (выкопай мои творческие взгляды), `再来一轮风格回访` (ещё раунд опроса о стиле), `更新我的风格画像` (обнови мой портрет стиля)
- Калибровка реальных суждений о сюжетных конфликтах: `主角该不该原谅他` (должен ли герой простить его), `反派要不要写成值得同情` (писать ли антагониста достойным сочувствия), `这个结局爽还是苦` (этот финал сладкий или горький)
- Дополнить позицию по теме / мотивы / повествовательный оригинальный голос: `挖我'背叛'的看法` (выкопай мой взгляд на «предательство»), `给我讲讲你构思的一个小场景` (расскажи мне о задуманной тобой маленькой сцене)
- Перед планом / основным текстом / шлифовкой / рецензированием портрет отсутствует или устарел: `风格画像多久没更新了` (как давно не обновлялся портрет стиля), `先按我的风格写这章` (сначала напиши эту главу в моём стиле)
- **Режим встраивания (запускается автоматически, ручной запрос автора не нужен)**: Skill звеньев — замысел темы / анализ конкурентов / проектирование плана / проектирование персонажей / проектирование фона / создание глав — автоматически вызывают этот Skill до начала звена, чтобы собрать обратную связь автора

## Основные ограничения / жёсткие правила

1. **Выкапывать взгляды ≠ спрашивать взгляды**: прямой вопрос о взглядах обычно приводит к повторению общих мест; обязательно сократическими вопросами / лестницей Laddering спускаться слой за слоем, пока не получим конкретное суждение с позицией, пригодное для письма.
2. **Стиль растёт только из свободного ввода, не из вариантов**: варианты придуманы ИИ (представляют выражение ИИ, не фиксируются); если автор отвечает не просто выбором — дописывает текст, пишет абзац, использует «другое» — этот текст и есть самое естественное выражение автора, **в любом случае попадает в очередь фиксации оригинального голоса и не отбрасывается**.
3. **Взгляды можно пересказывать, оригинальный голос — ни одного знака не менять**: при отложении взглядов в портрет допускается обобщающий пересказ (но обязательно цитировать слова автора, не выдумывать позицию за автора); слова автора попадают в библиотеку образцов **дословно, ИИ запрещено переписывать**.
4. **Обратная очистка (защита от самодеятельности ИИ)**: описания стиля в портрете, **для которых не находится ≥ 2 подтверждающих образцов** → понижаются или удаляются. Портрет растёт только из библиотеки образцов, не из воображения ИИ.
5. **Обязательный четырёхчастный вопрос (фон → вопрос → зачем спрашиваю → варианты)**: любой вопрос нельзя задавать «голым»; варианты обязательно «основная фраза + (пояснение в скобках)» целым абзацем, автор должен понимать без каких-либо свёрнутых пояснений.
6. **В каждом повторном опросе ≤ 4 вопросов**, ограниченное число углублений (слишком длинные раунды утомляют автора); достаточно, чтобы «ответ можно было написать как взгляд / удалось зафиксировать оригинальный голос»; **в каждом повторном опросе минимум 1 слот класса A (повествовательный голос)**.
7. **Разделение оригинального голоса на классы A/B**: класс A = **повествовательный оригинальный голос** автора **при рассказывании истории** (единственный авторитетный источник повествовательного голоса); класс B = **оригинальный голос автора при обсуждении творческих суждений** (источник взглядов и мотивов). Оба класса попадают в библиотеку образцов: класс A в основном питает слой повествовательного синтаксиса, класс B — слой сюжетной этики / ценностных мотивов.
8. **Запрещено «стирать» антиконсенсусные суждения автора до мейнстрима**: когда автор действительно говорит нестандартное, антишаблонное, уважать суждение автора, делать слова автора каркасом.
9. **Облегчённый режим встраивания (при вызове Skill звеньев)**: в низкочастотных обязательных звеньях (инициализация проекта / позиционирование жанра / конкуренты / общий план / план тома / персонажи / настройки / дело / зацепки / пакетное создание глав) перед каждым звеном предварительно собирать ≤ 2 вопросов (по умолчанию 1 вопрос); в высокочастотных звеньях черновика (контрольная карточка / сцена / диалог / усиление / заголовок / многоплатформенность и т. п.) **только читать и потреблять портрет, не задавать вопросов**; если по той же тематической области за 7 дней уже есть позиция → не повторять вопрос, сразу возвращать краткую выжимку портрета; образцы, полученные при встраивании, засчитываются в счётчик запуска периодической дистилляции.
10. **Фиксация рассеянных точек касания (бессознательные сигналы ≥ вопросы)**: ① точка касания «следы правки» — diff правок автора над ИИ-правкой / текстом после удаления привкуса / отшлифованным текстом (какую фразу вернул, какую удалил, на какой настоял) = бессознательная эстетика, по пунктам в библиотеку образцов; ② точка касания «обратный поток рецензирования» — выбор автора по замечаниям рецензии (какие принял, на каких настоял и возразил) = лучшее поле творческих суждений; ③ точка касания «окно автора» — слова автора в «слове от автора» / рецензии / аннотации / общении с читателями = единственный источник слоя ведения отношений с читателями; ④ точка касания «транскрипция устного рассказа» — устный рассказ автора о сцене / прошлом → дословная транскрипция в библиотеку = сильнейший источник повествовательного оригинального голоса (класс A).

## Правила автоматического обнаружения файлов данных

- Файлы данных (библиотека образцов оригинального голоса автора / портрет стиля автора) размещаются в `蒸馏产物/作者风格进化/` в корне романного проекта и регистрируются в `Agents.md` в корне проекта как потребляемый источник данных этого Skill; нижестоящие Skill написания/рецензирования/правки через `Agents.md` автоматически обнаруживают «приращение портрета стиля автора».
- Порядок обнаружения: ① путь записи «作者风格进化» (эволюция стиля автора), зарегистрированной в `Agents.md` → ② путь по умолчанию `蒸馏产物/作者风格进化/` → ③ если нет ни того ни другого: сначала вызвать `общий-дистилляция-авторского-стиля` для построения портрета-семени (извлечь ДНК письма из уже имеющихся произведений), затем начать первый повторный опрос этого Skill; **без портрета-семени «портрет стиля автора» с нуля генерировать нельзя**.
- Импорт семени: «шаблон стиля автора», выданный `общий-дистилляция-авторского-стиля`, может служить начальным значением портрета (его статистические выводы — черновик слоя повествовательного синтаксиса), после дистилляции эволюции перезаписывается / дополняется по пунктам оригинальным голосом из интервью.

## Основная выходная платформа (неприменимо)

Этот Skill не затрагивает различия платформенного вывода, платформенные ограничения передаются `общий-адаптация-под-платформы`. Когда многоплатформенному переписыванию нужен «вкус автора», Skill платформенного вывода читает слой повествовательного синтаксиса и авторскую языковую библиотеку этого портрета.

## Процесс выполнения

### Шаг 0: считывание текущего состояния (чтобы не повторять вопросы)
- Прочитать `作者原声样本库.md` (последние N записей из скользящей зоны образцов) + `作者风格画像.md` (текущее состояние каждого слоя) + уже зарегистрированные записи `Agents.md` в корне проекта
- Выдать «имеющуюся инвентаризацию»: по каким темам уже есть позиция / мотив (не спрашивать повторно), какие пробелы (копать в первую очередь), накопленное число образцов и число дней с последней дистилляции (определяет, запускать ли в этом раунде периодическую дистилляцию)
- Если портрет пуст, но в проекте есть продукты `общий-дистилляция-авторского-стиля`: сначала выполнить импорт семени, затем переходить к шагу 1

### Шаг 1: проектирование вопросов (по файлу методики, ≤ 4 вопросов)
- По 7 слотам `references/访谈挖观点与挖声口方法.md` выбрать ≤ 4, подогнать под тему дня
- Каждый вопрос в четырёхчастной форме: ① фон (контекст события/сюжета/персонажа, ≤ 80 знаков) → ② вопрос (с позицией) → ③ зачем спрашиваю (≤ 40 знаков) → ④ варианты (3–4 пункта «основная фраза + пояснение в скобках»)
- Предпочтения охвата: ① калибровка по сегодняшнему / недавнему творчеству; ② пустые темы; ③ добыча повествовательного голоса (класс A) — повествовательный голос — самая узнаваемая черта романного стиля, **в каждом повторном опросе минимум 1 слот класса A**

### Шаг 2: интерактивное выполнение + фиксация оригинального голоса
- Запускать через AskUserQuestion, порядок каждого вопроса = фон → вопрос → зачем спрашиваю → варианты, допускается свободный ввод
- Правило уточняющих вопросов: если за вариантом стоит более глубокий взгляд — углубляться (сначала дать фон, затем спрашивать)
- Если автор в недоумении («не понимаю, о чём спрашивают») → считать, что фона недостаточно, дополнить временной линией событий или цитатой из произведения и спросить заново
- **Фиксация (обязательно)**: каждый ответ проверять по пунктам, любой с компонентом свободного ввода (не чисто текст варианта) → добавлять в очередь фиксации, на месте записывать полный текст слов + контекст + первичное суждение о стилевых признаках (чтобы не забыть, сначала сохранить во временный черновик, на шаге 3.5 единообразно архивировать)

### Шаг 3: дистилляция (обработка ответов в основание взглядов)
- Выдать «карту творческих суждений автора»:
  - ① основные творческие суждения (позиции по персонажам / сюжету / мотивам, с пометкой источника слов автора)
  - ② мотивы и распределение ценностей (классифицировать по слою ценностных мотивов портрета; повторяющиеся по лестницам Laddering = основные мотивы)
  - ③ пригодные для письма установки (к какой школе автор склоняется, какой способ письма ему претит, какую антиконсенсусную сюжетную компоновку он готов сделать)
  - ④ кандидаты в слой стиля (1–2 фразы из оригинальных голосов A/B, наиболее похожие на автора, дословно, для обратной записи в портрет)
- Запрещено: выдумывать позицию за автора; «стирать» антиконсенсусные суждения автора до мейнстрима

### Шаг 3.5: архивация оригинального голоса в библиотеку образцов (взгляды в портрет, оригинальный голос в библиотеку образцов — две линии идут раздельно)
- По шаблону L2 `references/原声样本库归档模板.md` по пунктам архивировать в верх «скользящей зоны образцов» библиотеки: слова (дословно) / контекст / первичное стилевое суждение (метки по шести слоям портрета) / кандидаты в цитируемые афоризмы; пометить класс A или B
- Если свободного ввода нет — пометить `N/A（本轮全为选项作答）` (N/A: в этом раунде все ответы — выбором вариантов), образцы не выдумывать
- Ключевая фраза, добавленная автором при ответе чисто вариантом: если содержит позицию, в той же записи одновременно попадает в библиотеку образцов (по характеру A/B) + отложение взглядов (шаг 4)

### Шаг 4: отложение в портрет (обязательно)
- **Тематическая система, не датируемая**: добавить в `作者风格画像.md` раздел (`## {YYYY-MM-DD}：{новая особенность}`) или пересмотреть имеющийся слой; дата — метаданные, не имя файла
- При пересмотре имеющегося слоя размещать по шести слоям `references/作者小说风格画像卡.md` (повествовательный синтаксис / проявление сюжетной этики / эмоциональная эстетика / авторская языковая библиотека / ценностные мотивы / голоса персонажей)
- Если в этом раунде появились предложения оригинального голоса автора / новые афоризмы / разговорные названия → обязательно обратная запись в соответствующий слой (языковая библиотека / слой синтаксиса / библиотека голосов персонажей), растёт только из слов автора
- Если у выбранной темы есть соответствующий каталог замысла / файл плана, синхронно записать результат дистилляции обратно в его «основание творческих суждений автора» для потребления нижестоящими

### Шаг 5: подтверждение замыкания + проверка периодической дистилляции
- Проверить, что новые взгляды / новый оригинальный голос можно найти поиском (ключевые слова находятся в портрете / библиотеке образцов)
- Выдать «сводку дистилляции этого раунда»: выявленные новые суждения, усиленные мотивы, изменения повествовательного голоса, прирост числа образцов
- **Проверка запуска периодической дистилляции**: прирост библиотеки образцов ≥ 10 записей или ≥ 7 дней с последней дистилляции (что наступит раньше)
  - Запуск → прочитать все новые оригинальные голоса → подсчитать повторяющиеся модели оборотов / лексики / аргументации / эмоций / афоризмов / сравнений → обратная запись новых моделей в соответствующие слои портрета → **обратная очистка** (описания портрета без ≥ 2 подтверждающих образцов понижать / удалять) → пометить «дистиллировано из N записей библиотеки образцов, {дата}»
  - Не запущено → в сводке записать «накоплено N образцов, d дней с последней дистилляции», дистилляцию не проводить, метку не ставить

## Протокол режима встраивания (автоматически вызывается Skill каждого звена)

> Полный повторный опрос (выше, Шаг 0–5) запускается автором вручную или по периоду; **режим встраивания** автоматически вызывается Skill звеньев — замысел темы / анализ конкурентов / план / персонажи / фон / создание глав — до начала звена, это канал автоматического сбора по полному процессу этого Skill. Соответствие звено → слот → потребляемый слой см. в `references/环节嵌入点映射.md`.

### Запуск и вход
- Запуск: до начала процесса выполнения вызывающего Skill (во всех случаях не блокирует основной процесс; при незарегистрированном источнике данных пропускается)
- Вход: название звена + тема решения этого звена (вызывающий Skill берёт из таблицы соответствия рекомендуемые слоты и передаёт)

### Выполнение (облегчённый повторный опрос)
1. **Удаление дублей**: проверить библиотеку образцов / «записи дистилляции» портрета, если по той же тематической области за 7 дней уже есть позиция → не задавать вопрос, сразу возвращать краткую выжимку портрета
2. **Вопрос**: ≤ 2 вопросов, по-прежнему четырёхчастная форма, но [фон] можно сократить до одной фразы о сцене этого звена; приоритет рекомендуемым слотам таблицы соответствия звеньев
3. **Фиксация**: свободный ввод оригинального голоса как обычно попадает в очередь фиксации (A/B по характеру), записывать на месте, чтобы не забыть
4. **Отложение**: ответ сразу архивируется (шаблон L2, примечание `嵌入模式·{环节名}` (режим встраивания · название звена)) → позиция прямо записывается в раздел соответствующего слоя портрета — полную глубокую обработку шагов 3 / 4 не повторять
5. **Обратная подача**: выдать «карточку-выжимку портрета» этого звена (= текущая выжимка потребляемого слоя, ≤ 1 страницы), для вызывающего Skill как авторское ограничение при выполнении

### Ограничения
- Режим встраивания не заменяет полный повторный опрос: периодическая дистилляция (≥ 10 записей или ≥ 7 дней), глубокое углубление, обратная очистка по-прежнему ложатся на полный повторный опрос
- Образцы, зафиксированные в режиме встраивания, засчитываются в счётчик запуска периодической дистилляции (суммируются с образцами повторного опроса)
- В каждом встраивании ≤ 2 вопросов; при попадании дедупликации не задавать вопрос насильно, сразу возвращать выжимку

## Протокол аудита «похоже ли на автора» (проверка, что «применение» достигнуто)

> Всё «ощущение автора», что отложено, в итоге должно проявиться в готовом основном тексте. Аудит выполняет `общий-рецензия-текста-главы` в проектах с **источником данных эволюции стиля автора**, числовые показатели обязаны браться из скрипта `scripts/voice_audit_novel.py` (Anti-Cheat: запрещено вручную писать вывод о достижении).

| Показатель | Определение | Планка |
| --- | --- | --- |
| Доля предложений оригинального голоса | Предложения основного текста, прямо цитирующие / адаптированные из библиотеки образцов оригинального голоса ÷ общее число предложений | ≥ 15% |
| Доля попадания привычных выражений автора | Фразы в кавычках карточки портрета (язвительные названия / привычные выражения / присказки), попавшие в основной текст ÷ число глав | ≥ 1 раз/главу |
| Доля прослеживания проявления позиции | Сюжетные эпизоды с позицией, прослеживаемые к слою ценностных мотивов / слою проявления ÷ утверждающие эпизоды | ≥ 80% |
| Обнаружение дрейфа стиля | Отклонение длины предложений / меток диалогов / повествовательной дистанции от базовой линии повествовательного синтаксиса | Отклонение > 30% → повторная проверка |

- Не достигнуто → найти дрейфующий пункт, вернуться к `общий-шлифовка-основного-текста` / `общий-устранение-духа-ии` для целенаправленного исправления; всё достигнуто → портрет в этом раунде эмпирически подтверждён
- Результат аудита записывается в подраздел «аудит „похоже ли на автора“» отчёта рецензирования; без источника данных пропускается, ошибка не выдаётся

## Обязательные требования / защита исполнения

| Пункт проверки | Критерий достижения |
| --- | --- |
| У вопроса есть позиция | Каждый вопрос вынуждает суждение «за / против / писать так / писать иначе», а не открытая болтовня |
| Полный фон | В каждом вопросе есть абзац [фон]; варианты — «основная фраза + пояснение в скобках» (не голые метки) |
| Есть углубление | ≥ 1 вопроса доведён по Сократу / Laddering до слоя ценностей / мотивов |
| Добыча повествовательного голоса | В каждом повторном опросе ≥ 1 слот класса A (повествовательный оригинальный голос) |
| Суждение прослеживается | Каждое творческое суждение помечено словами автора, не сочинено за него |
| Оригинальный голос обязательно архивируется | Все ответы этого раунда со свободным вводом дословно заархивированы (с контекстом + первичным суждением + пометкой A/B); раунды с одними вариантами помечены `N/A` |
| Периодическая дистилляция | При выполнении условия запуска — дистиллировано с обратной записью + обратной очисткой; при незапуске записано накопленное число |
| Соответствие режима встраивания | При вызове звеном ≤ 2 вопросов, в высокочастотных звеньях черновика только читать без вопросов, при попадании дедупликации не спрашивать насильно, оригинальный голос как обычно архивируется с пометкой звена встраивания, возвращается карточка-выжимка портрета |
| Фиксация рассеянных точек касания | diff правок / выбор в рецензировании / слова из окна автора / транскрипция устного рассказа помечены по точкам касания и занесены в библиотеку образцов (без событий точки касания — пометка N/A) |
| Аудит «похоже ли на автора» | В проектах с источником данных при рецензировании запущен `voice_audit_novel.py` для снятия данных, вручную писать вывод о достижении запрещено |
| Повторное использование | Слои портрета могут напрямую потребляться и списываться в `общий-создание-основного-текста`/`общий-шлифовка-основного-текста`/`общий-устранение-духа-ии`/`общий-рецензия-текста-главы` |
