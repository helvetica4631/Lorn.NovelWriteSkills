# Карточка романного портрета стиля автора · методический шаблон (структура и правила)

> **Граница обязанностей**: этот файл — **методический шаблон**, а не данные автора. Этот файл определяет **десятислойную структуру, смысл полей, правила дистилляции, протокол потребления и аудит «похоже ли на автора»** «романного портрета стиля автора» — он не содержит какого-либо конкретного содержимого автора (примеры предложений / афоризмы / интонации — всё в `蒸馏产物/作者风格进化/作者风格画像.md` в корне романного проекта).
> ⚠️ **Место данных**: конкретное содержимое стиля автора всегда читается из `作者风格画像.md` (правила после дистилляции) и `作者原声样本库.md` (исходные слова) в корне проекта — ежедневный / каждый раунд повторного опроса только дописывает файлы данных, в этот шаблон не пишет (skill = метод, корень проекта = данные автора, механизм содержимого не несёт).
> **Вышестоящее**: исток — интервью-оригинальный голос и рассеянные точки касания `общий-эволюция-авторского-стиля` (следы правки / обратный поток рецензирования / окно автора / транскрипция устного рассказа); начальным значением как семя может служить «шаблон стиля автора», выданный `общий-дистилляция-авторского-стиля`.

---

## 1. Десятислойная структура (романный портрет стиля автора = десять групп полей + чек-лист самопроверки)

> Каждая группа полей при извлечении / обратной записи дистилляции из библиотеки образцов размещается по этой структуре в соответствующий раздел `作者风格画像.md` в корне проекта. Десять слоёв = исходные шесть слоёв (1–6) + расширенные четыре слоя (7–10). Источник расширенных слоёв — прежде всего **эмпирика рассеянных точек касания**, вопросы — вспомогательно.

### 1. Слой повествовательного синтаксиса (как говорит рассказчик)

- Поля: `句长基线` (базовая длина предложений) `断句习惯` (привычка членения) `对话标签偏好` (предпочтения меток диалога) `心理描写密度` (плотность психологических описаний) `留白率` (доля недосказанности) `人称与叙事距离` (лицо и дистанция повествования) `常用连接词 / 语气词` (частые союзы / модальные частицы)
- Пример значений поля: {много коротких предложений, в метках диалога только «сказал» без украшений / психологический монолог длинный и плотный / холодный повествовательный кадр / любит «на самом деле», «проще говоря» }
- Ключевое при дистилляции: повествовательный голос = признак с наивысшей узнаваемостью, извлекать в первую очередь; источник — повествовательный оригинальный голос класса A

### 2. Слой проявления сюжетной этики (как мировоззрение автора «проявляется» без проповеди)

- Поля: `谁遭殃` (кто страдает) `谁得救` (кто спасён) `谁被讽刺` (кто высмеян) `报应如何兑现` (как реализуется воздаяние) `作者站队` (чью сторону занимает автор) `反说教落地方式` (способ приземления без проповеди)
- Ключевое при дистилляции: в романе автор прямо не говорит «я считаю X», а проявляется через **распределение** (чей финал, кто в выигрыше, кому сочувствуют). Этот слой отвечает на вопрос «в какое место сюжета падает ценностное суждение автора»
- Подсказка по выделению: одно и то же суждение повторяется в ≥ 2 разных сюжетах — только тогда это закон проявления (разовая случайная компоновка не считается)

### 3. Слой эмоциональной эстетики (какой вкус при чтении)

- Поля: `基调` (тон) (стужа / теплота / чёрный юмор / абсурд / сострадание / драйв-удовольствие) `情绪在何处抬升回落` (где эмоции поднимаются и спадают) `叙述者对惨事是熨帖还是旁观` (рассказчик к ужасному — утешает или наблюдает) `讽刺的落点` (точка приземления сатиры)
- Ключевое при дистилляции: эмоциональная поза определяет общий тон текста, её нужно разводить с эмоциональными требованиями жанра и платформы (этот слой служит «вкусу автора», платформенные предпочтения передаются Skill платформ)

### 4. Авторская языковая библиотека (слова, которые можно унести с собой)

- Поля: `原声金句` (афоризмы оригинального голоса) `比喻原型` (прототипы сравнений) (какой источник сравнений любит автор: деньги, еда, машины, погода…) `惯用意象` (привычные образы) `口头禅式描写器` (описатели в духе присказок)
- Ключевое при дистилляции: афоризм должен быть разговорным, близким к жизни, антиконсенсусным; позиция = хвост абзаца / хвост всего текста / завершение сцены; **всё растёт только из оригинального голоса автора**

### 5. Слой ценностных мотивов (костяк и мотивы)

- Поля: `反复母题清单` (список повторяющихся мотивов) (например предательство / справедливость / выжить / труд) `价值底线` (ценностная нижняя граница) (суждения, которые нельзя поколебать) `世界观假设` (мировоззренческие допущения) (чем, по мнению автора, движется мир)
- Ключевое при дистилляции: мотив = обобщение позиции, многократно возникавшей при повторных опросах, а не разовый ответ; при возвышении не превращать в лозунг

### 6. Библиотека голосов персонажей (новое для романа: речевой рецепт, который автор назначает персонажам)

- Поля: `角色声口标签` (метка голоса персонажа) (на каждого основного героя одна фраза: хладнокровный бухгалтер / вспыльчивый / язвительный) `声口差分策略` (стратегия различения голосов) (различие длины предложений / лексики между персонажами, защита от схождения) `作者表达DNA借位` (заимствование ДНК выражения автора) (какому персонажу можно одолжить собственные афоризмы / язвительность автора)
- Ключевое при дистилляции: голоса персонажей берутся из ДНК выражения персонажей в общий-проектирование-биографии-персонажей + оригинальных голосов «автор говорит за персонажа» слота 3 этого Skill; **личную языковую библиотеку автора заимствовать только персонажам, «близким автору по мировоззрению», антагонистов / инакомыслящих намеренно разводить**

### 7. Слой повествовательного метода (ДНК ремесла: как автор рассказывает сцену — расширенный слой)

- Поля: `信息释放习惯` (привычка высвобождения информации) (прямо vs прятать нить vs наживка) `留白率` (доля недосказанности) `镜头偏好` (предпочтения кадра) (сценический / психологический / монтаж) `推进方式` (способ продвижения) (доли продвижения диалогом / действием / повествованием) `首尾处理习惯` (привычки обработки начала и конца)
- Ключевое при дистилляции: соответствует «слою педагогики» teacher-voice — в отличие от слоя синтаксиса, отвечающего «как сказать одну фразу», этот слой отвечает «как разложить сцену / поток информации»; источник = основа устного оригинального голоса транскрипции + статистика моделей утверждённого основного текста + следы правки
- Подсказка по выделению: одна и та же привычка обработки повторяется в ≥ 2 сценах — только тогда это отпечаток метода

### 8. Слой предпочтений материалов (что автор любит писать — расширенный слой)

- Поля: `反复进入的素材类型` (повторяющиеся типы материалов) (какие осколки жизни / профессии / топонимы / эпохи) `惯用意象` (привычные образы) (дождь / дым / уличный фонарь / весы…) `人设原型偏好` (предпочтения архетипов персонажей) `桥段原型偏好` (предпочтения архетипов эпизодов)
- Ключевое при дистилляции: соответствует «предпочтениям выбора образцов» teacher-voice — «материал», который автор раз за разом помещает в истории, — вход во внутренний мир автора; источник = записи выбора в библиотеке материалов + образы настроек + устные фрагменты
- Обратная подача: потребитель `общий-пополнение-библиотеки-материалов` целенаправленно пополняет материалы по этому слою

### 9. Слой читательских представлений (для кого пишет автор — расширенный слой)

- Поля: `目标读者的默认画像` (типичный портрет целевого читателя) (кто такой «читатель» в голове автора) `市场 vs 自我的天平` (весы рынок vs себя) `对读者反馈的态度` (отношение к обратной связи читателей) `平台的取舍底线` (нижняя граница компромиссов платформы)
- Ключевое при дистилляции: соответствует «оценке обратного потока» teacher-voice — выбор автора между коммерцией и самовыражением — это долгое суждение, а не разовый ответ; источник = выбор в обратном потоке рецензирования + выбор в коммерческих звеньях (заголовок / аннотация / платформенное переписывание) + интервью
- Для потребления в коммерческих звеньях: `общий-проектирование-названия` / `общий-написание-аннотации` / `общий-адаптация-под-платформы` и т. п.

### 10. Слой ведения отношений с читателями (как автор разговаривает с читателями — расширенный слой)

- Поля: `作者有话说风格` (стиль «слова от автора») (мини-спектакль / отчётный / стиль ехидного друга) `互动原话` (слова в общении) («本章说» / комментарии / оригинальный голос в групповом чате) `距离感` (ощущение дистанции) (дружелюбная / отстранённая / холодная) `更新习惯相关表达` (выражения, связанные с привычками обновления)
- Ключевое при дистилляции: соответствует «записи ответов на вопросы» teacher-voice — как автор непосредственно разговаривает с читателями вне произведения; источник = исходные тексты «слова от автора» / **дословные слова** взаимодействия автора (точка касания S4)
- Потребители: `общий-шлифовка-слова-автора` / `общий-написание-рецензии-на-книгу` подражают тону автора при разговоре с читателями по этому слою

### Приложение · чек-лист самопроверки письма (проверять в любой момент во время письма)

- [ ] Повествовательный голос ≥ 2 раза соответствует отпечатку слоя повествовательного синтаксиса?
- [ ] Ценности автора «проявляются», а не «проповедуются» (никто не выкрикивает лозунги за автора)?
- [ ] Есть разговорные афоризмы, которые можно унести с собой, и они стоят в хвосте абзаца / сцены?
- [ ] Мотив проявлен в сюжете ≥ 1 раз (не прямым изложением)?
- [ ] Голос главного героя / близкого автору персонажа ≠ голос антагониста (различение состоялось)?
- [ ] Способ разложения сцены соответствует отпечатку слоя повествовательного метода (прямота / недосказанность / продвижение в этой сцене похожи на автора)?
- [ ] Выбранные материалы / образы в пределах слоя предпочтений материалов (или намеренный выход за них)?
- [ ] Тон «слова от автора» соответствует слою ведения отношений с читателями?
- [ ] Интонация «сам автор», а не «учебник / пресс-релиз / универсальная ИИ-манера»?

## 2. Правила дистилляции (данные библиотеки образцов → портрет)

1. **Запуск**: в `作者原声样本库.md` добавлено ≥ 10 записей или прошло ≥ 7 дней с последней дистилляции (что наступит раньше, проверяется на Шаге 5 `общий-эволюция-авторского-стиля`)
2. **Действие**: прочитать все новые слова → подсчитать повторяющиеся модели оборотов / лексики / аргументации / эмоций / афоризмов / сравнений → новые модели обратно записать в соответствующий слой `作者风格画像.md` (новые или усиленные); **образцы рассеянных точек касания (следы правки / выбор в рецензировании / окно автора / транскрипция устного рассказа) в первую очередь обратно записывать в расширенные слои (7–10)** и рядом с записью помечать источник точки касания
3. **Обратная очистка**: описания стиля в портрете, **для которых не находится ≥ 2 подтверждающих образцов** → понижать или удалять (защита от самодеятельного стиля ИИ)
4. **Пометка происхождения**: в местах обновления портрета помечать «дистиллировано из {N} записей библиотеки образцов, {дата}»
5. **Критерий измерения**: чем толще библиотека образцов, тем точнее портрет — конечная цель: «афоризмы слов автора можно прямо использовать как афоризмы романа / реплики персонажей, без правки»

## 3. Протокол потребления (портрет → написание / рецензирование / переписывание)

> Список — поверх краткого изложения протокола потребления в `общий-эволюция-авторского-стиля/SKILL.md`, детализирован до обязательных точек списания нижестоящих Skill. Нижестоящие Skill через `Agents.md` в корне проекта автоматически обнаруживают «приращение портрета стиля автора».

| Потребитель | Что использует | Обязательная точка списания |
| --- | --- | --- |
| `общий-создание-основного-текста` | Слой повествовательного синтаксиса + авторская языковая библиотека + слой ценностных мотивов | Перед написанием прочитать портрет: повествовательный голос откликается ≥ 2 раза, языковая библиотека использована ≥ 1 раз, мотив проявлен в сюжете ≥ 1 раз (не прямым изложением) |
| `общий-цикл-создания-главы` | Все слои | Шаг 0 — прочитать выжимку портрета; после завершения шаг 12.5 — собрать обратную связь по продукту автора (оригинальный голос класса B) в библиотеку образцов |
| `общий-шлифовка-основного-текста` | Железное правило сохранения стиля + авторская языковая библиотека | Афоризмы слов автора шлифуются только по заусенцам, каркас не меняется; повествовательный голос нельзя «сглаживать шлифовкой»; **фиксация diff правок** (предложения, возвращённые / отстоянные автором, дословно в библиотеку образцов, S3) |
| `общий-устранение-духа-ии` | Слой повествовательного синтаксиса + авторская языковая библиотека (возврат человеческого голоса) | При возврате голоса автора брать модель оригинального голоса из портрета, а не из универсальной шаблонной интонации; **фиксация diff текста после удаления привкуса** (сохранение / возврат автором = бессознательная эстетика, S3) |
| `общий-рецензия-текста-главы` | Слой повествовательного синтаксиса + слой проявления сюжетной этики + библиотека голосов персонажей + расширенные слои | Новый пункт списания «четыре показателя: похоже ли на автора» (данные из скрипта, Anti-Cheat); проверка объединяется с имеющимся «аудитом исполнения персонажей · согласованность голосов»; перед публикацией вывода рецензирования собрать выбор автора (S5) |
| `общий-рецензия-общего-плана` / `общий-рецензия-плана-тома` / `общий-цикл-рецензии-плана` | Слой мотивов + слой проявления | Обратный поток рецензирования (S5): замечания, на которых автор настоял / которые отверг, — в библиотеку образцов и слой мотивов |
| `общий-рецензия-биографии-персонажей` | Библиотека голосов персонажей | Метки голоса персонажей перекрёстно сверяются с «ДНК выражения» биографии, состоялось ли различение |
| `общий-исполнение-диалога-конфликта` / `общий-исполнение-сценической-единицы` | Библиотека голосов персонажей + слой эмоциональной эстетики + слой повествовательного метода | Диалог пишется с различением голосов, способ разложения сцены соответствует отпечатку слоя повествовательного метода (только чтение) |
| `общий-усиление-начала-главы` / `общий-усиление-хука-конца-главы` | Авторская языковая библиотека + слой повествовательного синтаксиса | Завершение афоризмами автора / начало с кадровым ощущением автора (только чтение) |
| `общий-проектирование-биографии-персонажей` | Библиотека голосов персонажей (обратное внедрение) | При создании «речевого рецепта» нового персонажа ориентироваться на имеющуюся библиотеку голосов, чтобы избежать схождения |
| `общий-шлифовка-слова-автора` | Слой ведения отношений с читателями + авторская языковая библиотека | «Слово от автора» пишется в манере разговора автора с читателями, без универсальной интонации мини-спектакля |
| `общий-написание-рецензии-на-книгу` | Слой ценностных мотивов + острота повествования + авторская языковая библиотека | Рецензия — текст взглядов автора: позицию брать из слоя мотивов, афоризмы — из языковой библиотеки |
| `общий-написание-аннотации` | Слой ценностных мотивов + острота повествования + слой читательских представлений | Предпочтения главной фразы аннотации калибруются в пределах слоя читательских представлений |
| `общий-проектирование-названия` | Слой читательских представлений + авторская языковая библиотека | Выбор «раскрывать тему или намекать» в заголовке соответствует нижней границе рыночных взглядов автора |
| `общий-адаптация-под-платформы` / `общий-очистка-мастер-черновика` / `общий-оркестрация-вывода-на-платформы` | Слой повествовательного синтаксиса + авторская языковая библиотека | Платформенное переписывание сохраняет «основу со вкусом автора»: при очистке мастер-рукописи афоризмы оригинального голоса автора не теряются, исправление платформенных столкновений не смывает отпечаток автора |
| `общий-пополнение-библиотеки-материалов` | Слой предпочтений материалов | Целенаправленно пополнять материалы по тем материалам / образам, в которые автор раз за разом возвращается |

> **Арбитраж конфликтов**: при конфликте портрета стиля автора и шаблона `общий-дистилляция-авторского-стиля` **приоритет у портрета** (динамический оригинальный голос интервью > статическая историческая статистика); при конфликте с жёстким порогом платформы **приоритет у жёсткого порога платформы** (платформенная читабельность не жертвуется ради медленного разгона автора). Конфликт фиксируется явно, без тайного выбора.
