# Шаблон архивации библиотеки образцов оригинального голоса (структура файлов данных и нормы архивации)

> **Граница обязанностей**: этот файл — **методический шаблон**, определяет **каркас начала шаблона, формат архивации, замкнутый цикл дистилляции** двух файлов данных — «библиотеки образцов оригинального голоса автора» и «портрета стиля автора» — и не содержит какого-либо конкретного содержимого автора (в примерах плейсхолдеры, при внедрении захватывается повторным опросом `общий-эволюция-авторского-стиля`).
> **Место данных**: два файла данных размещаются в `蒸馏产物/作者风格进化/` в корне романного проекта; кто пишет / кто потребляет — см. таблицу ниже.

---

## 1. Трёхслойный замкнутый контур (фиксация → архивация → дистилляция)

```text
L1 Фиксация (на месте повторного опроса)  →  L2 Архивация (верх скользящей зоны образцов, дословно)  →  L3 Периодическая дистилляция (≥ 10 записей или ≥ 7 дней) → обратная запись в портрет стиля автора
```

### L1 Фиксация: любой свободный ввод — образец стиля

- **Условие запуска**: если ответ автора — не «просто выбор варианта» — выбрал вариант и дописал текст, прямо написал абзац, использовал «другое» для свободного ввода — этот текст и есть самое естественное выражение автора, содержание стиля в нём самое высокое.
- **Разделение классов A/B (обязательно)**:
  - **Класс A · повествовательный оригинальный голос**: **интонация автора при рассказывании истории** (рассказ о воспоминании, о задуманной маленькой сцене, устный рассказ сюжета) → питает слой повествовательного синтаксиса + слой повествовательного метода + авторскую языковую библиотеку
    - A1 · повествовательный оригинальный голос интервью: фиксируется слотом 6 повторного опроса
    - A2 · оригинальный голос транскрипции устного рассказа: устный рассказ автора → дословная транскрипция в библиотеку (сильнейший повествовательный оригинальный голос; при первом устном рассказе ≥ 10 записей → немедленная дистилляция)
  - **Класс B · оригинальный голос творческих суждений**: **слова автора при обсуждении творческих суждений** (позиция по персонажам / сюжету / мотивам, ворчание, занятие стороны) → питает слой проявления сюжетной этики + слой ценностных мотивов
- **Пометка источника рассеянной точки касания (обязательно для каждого образца, S1–S6)**:

| Точка касания | Источник | Типичный образец |
| --- | --- | --- |
| S1 Интервью | Повторный опрос / встроенный вопрос | Свободный ввод в четырёхчастном вопросе |
| S2 Транскрипция устного рассказа | Транскрипция записи устного рассказа автора | Устный рассказ о сцене / прошлом / замысле, ручной грубый отбор «эта фраза похожа на его речь» |
| S3 Следы правки | diff ИИ-правки / текста после удаления привкуса / отшлифованного текста | Предложения, возвращённые / отстоянные / удалённые автором (бессознательная эстетика) |
| S4 Окно автора | «Слово от автора» / рецензия / аннотация / общение с читателями | Слова автора, обращённые наружу |
| S5 Обратный поток рецензирования | Выбор по отчёту рецензирования | Слова автора о замечаниях, на которых он настоял и которые отверг / охотно принял |
| S6 Выбор образцов материалов | Выбор материалов / образы настроек / устные фрагменты | Ответ на «почему ты всё время берёшь такие материалы» |

- **Время фиксации**: на месте повторного опроса (сразу после завершения интерактива шага 2) или при наступлении события точки касания (на месте после окончания правки / рецензирования / взаимодействия), не ждать окончания всего раунда; сначала сохранить во временный черновик, чтобы не забыть.
- **Содержимое фиксации**: полный текст слов (ни одного знака не менять) + контекст (какой вопрос / какое звено / какая сцена) + первичное суждение о стилевых признаках + номер точки касания.

### L2 Архивация: один образец = одна полная запись

По следующему шаблону дописывать в верх «скользящей зоны образцов» файла `作者原声样本库.md`:

```markdown
### {YYYY-MM-DD} · {слот запуска / тема / звено}（{A1/A2 или B} · {точка касания S1–S6} · {свободный ввод / вариант+дополнение / сохранено при правке / транскрипция устного рассказа / выбор в рецензировании / окно автора}）
- **Слова**："{ответ автора / исходный текст сохранённой при правке фразы, дословно.}"
- **Контекст**：{какой вопрос задан, о каком сюжете / теме шла речь, что автор опровергал / поддерживал}
- **Первичное суждение о стиле**：синтаксис=[длинные предложения/короткие/риторический вопрос/вопрос с ответом самому себе/контраст]｜проявление=[кто страдает/кто в выигрыше/кого высмеивают]｜эмоции=[язвительность/сдержанность/теплота/стужа]｜афоризм=[антитеза/жаргон/суждение/риторический вопрос]｜сравнение=…
- **Кандидаты в цитируемые афоризмы**：{"..."}（если есть, можно прямо в основной текст / реплики персонажей / «слово от автора»）
```

- Слова: дословно, без переписывания ИИ; если ответ перемешан с текстом вариантов, архивируется только добавленная спонтанная часть.
- Если свободного ввода нет: пометить `N/A（本轮全为选项作答）` (N/A: в этом раунде все ответы — выбором вариантов), образцы не выдумывать.
- Ключевая фраза, добавленная автором при ответе чисто вариантом: если содержит позицию («我补充一句：…» («добавлю одну фразу: …»)), та же фраза одновременно попадает в библиотеку образцов (A/B по характеру) + отложение взглядов (шаг 4, портрет).

### L3 Периодическая дистилляция: обобщение с обратной записью в портрет

- **Запуск**: прирост ≥ 10 записей или ≥ 7 дней с последней дистилляции (что наступит раньше, проверяется на Шаге 5 `общий-эволюция-авторского-стиля`).
- **Действие**: прочитать все новые образцы → подсчитать повторяющиеся модели оборотов / лексики / аргументации / эмоций / афоризмов / сравнений → новые модели обратно записать в соответствующий слой `作者风格画像.md` → **обратная очистка** (описания портрета без ≥ 2 подтверждающих образцов понижать / удалять) → пометить источник «дистиллировано из {N} записей библиотеки образцов, {дата}».
- **Критерий измерения**: чем толще библиотека образцов, тем точнее портрет — конечная цель: «афоризмы слов автора можно прямо использовать как афоризмы основного текста / реплики персонажей, без правки».

## 4. Сотрудничество по семени с общий-дистилляция-авторского-стиля

- **Холодный старт**: перед первой эволюцией стиля, если в проекте нет портрета, сначала запустить `общий-дистилляция-авторского-стиля`, построив из уже имеющихся произведений автора «шаблон стиля автора» как семя (его выводы типа [статистика] — черновик слоя повествовательного синтаксиса), затем начать первый повторный опрос.
- **Ежедневное сохранение**: дальнейшая эволюция идёт на оригинальных голосах интервью, больше не зависит от выборок из произведений; `общий-дистилляция-авторского-стиля` можно в любой момент перезапустить для калибровки (если стиль автора сильно изменился).
- **Правило конфликтов**: портрет и статический шаблон конфликтуют → приоритет у портрета (динамический оригинальный голос интервью > статическая историческая статистика); жёсткий порог платформы → приоритет у жёсткого порога платформы.
