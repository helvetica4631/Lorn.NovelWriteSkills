# Соответствие точек встраивания по звеньям (таблица диспетчеризации автоматического сбора по полному процессу)

> **Граница обязанностей**: этот файл — **методический шаблон**, определяет, как каждое творческое звено автоматически вызывает режим встраивания `общий-эволюция-авторского-стиля`: когда спрашивать, какие слоты, какой слой портрета потреблять, где откладывать. Не содержит конкретного содержимого автора.
> **Потребители**: Skill звеньев (общий-проектирование-позиционирования-жанра, общий-анализ-конкурирующих-произведений, общий-проектирование-общего-плана, общий-проектирование-биографии-персонажей, общий-проектирование-настроек-истории, общий-создание-основного-текста и т. п.) перед началом этого звена читают эту таблицу и вызывают режим встраивания.

---

## 1. Краткий обзор протокола встраивания

| Измерение | Правило |
| --- | --- |
| Момент запуска | До начала процесса выполнения Skill звена (предварительный сбор), во всех случаях не блокирует основной процесс |
| Число вопросов | В обязательных звеньях ≤ 2 вопросов (по умолчанию 1 вопрос); **в высокочастотных звеньях черновика только читать и потреблять портрет, не спрашивать** |
| Удаление дублей | Если по той же тематической области за 7 дней уже есть позиция → не спрашивать, сразу возвращать краткую выжимку портрета |
| Формат вопроса | Четырёхчастный (фон → вопрос → зачем спрашиваю → варианты), фон можно сократить до одной фразы о сцене этого звена |
| Фиксация | Свободный ввод оригинального голоса как обычно попадает в очередь фиксации (A/B по характеру), примечание `嵌入模式·{环节名}` |
| Отложение | Ответ сразу архивируется в библиотеку образцов (шаблон L2) + позиция прямо записывается в раздел соответствующего слоя портрета, глубокую обработку не повторять |
| Обратная подача | Выдать «карточку-выжимку портрета» = текущая выжимка потребляемого слоя (≤ 1 страницы), как авторское ограничение для этого звена |
| Статистика образцов | Образцы встраивания включаются в счётчик запуска периодической дистилляции (суммируются с образцами повторного опроса ≥ 10 записей или ≥ 7 дней) |
| Понижение | Проект не зарегистрировал источник данных эволюции стиля автора / автор явно пропустил → откат к имеющимся шаблонам и базовой линии по умолчанию, без ошибки |

## 3. Детали исполнения встраивания

### 3.1 Способ подключения вызывающей стороны (написание хука)

Skill каждого звена объявляют в разделе «Правила автоматического обнаружения» (единое название раздела `## 作者风格画像嵌入`):

```markdown
## Встраивание портрета стиля автора (автоматический сбор обратной связи автора)
- Если в `Agents.md` в корне проекта зарегистрирован источник данных «作者风格进化» (作者风格画像.md и 作者原声样本库.md в `蒸馏产物/作者风格进化/`):
  - Предварительно (до начала этого звена): по режиму встраивания `общий-эволюция-авторского-стиля` собрать ≤ 2 суждений (слоты этого звена / примеры вопросов см. в его references/环节嵌入点映射.md), оригинальный голос и позиции сразу откладывать
  - При выполнении: прочитать слой {соответствующий слой} из 作者风格画像.md как авторское ограничение этого звена
- Не зарегистрировано или автор пропустил: откат к имеющимся шаблонам и базовой линии по умолчанию, без ошибки, без блокировки
```

### 3.2 Формат обратной подачи (карточка-выжимка портрета)

«Карточка-выжимка портрета», потребляемая вызывающим Skill при выполнении, выдаётся по следующей структуре (≤ 1 страницы):

```markdown
### Карточка-выжимка портрета · {название звена}（{дата}）
- Выжимка потребляемого слоя：{3–5 текущих правил соответствующего слоя, по каждому пометка числа подтверждающих образцов}
- Авторские ограничения этого звена：{правила уровня предложения / сюжета, которые можно сразу исполнять}
- Непокрытые пробелы：{пункты, по которым в этом слое пока нет подтверждающих образцов — при выполнении откат к универсальным значениям по умолчанию, стиль автора не выдумывать}
```

### 3.3 Защита от утомления и удаление дублей

- По той же тематической области за 7 дней уже есть отложенная позиция → дедупликация сработала, пропустить вопрос, сразу обратная подача
- Слишком высокая накопленная частота вопросов режима встраивания (за день > 3 звеньев попали в одну тематическую область) → объединить в один вопрос, остальные звенья только обратная подача
- Автор в 2 раундах встраивания подряд без свободного ввода и отвечал вариантами → в следующие 3 дня это звено понижается до «без вопросов» (только обратная подача), чтобы снизить механическое взаимодействие

## 4. Разделение труда с полным повторным опросом

| Измерение | Режим встраивания | Полный повторный опрос |
| --- | --- | --- |
| Запуск | Автоматический вызов Skill каждого звена (предварительно) | Вручную автором / по периоду |
| Число вопросов | ≤ 2 вопросов | ≤ 4 вопросов + углубление |
| Цель | Мгновенный сбор позиции, относящейся к решению этого звена | Глубокое выявление мотивов, повествовательного голоса, панорамы по разным темам |
| Отложение | Мгновенная архивация + обратная запись в раздел соответствующего слоя | Полная карта + периодическая дистилляция + обратная очистка |
| Контроль частоты | Дедупликация + механизм понижения | Каждый раз ≥ 1 слот класса A |
