# Методология разбора книги: приёмы разбора на уровне сцен

> **Источник**: Zhihu · Daodao Liehuo «Как именно делается «разбор книги» (拆书) в веб-романах?» (2026-07-01)
> **Область применения**: критерии по умолчанию (Qidian / платформа не указана), универсально для разных жанров
> **Отношение к этому Skill**: этот файл — дополнительный микроаналитический инструмент «слоя создания контента»: в слое создания контента четырёхслойного разбора можно применять метод разбора книги для глубокого поэпизодного разбора, улавливая структуру эмоций, а не только пересказ

## Основная идея

Конечная цель разбора книги — не копировать сюжет, а **изучать структуру, по которой мастера проектируют историю**, чтобы при письме у автора было направление, принимаемое рынком, и стоимость проб и ошибок была ниже.

> Структура эмоций и закономерности частоты их изменений — вот что стоит повторно использовать. Сюжет и действия-реакции персонажей — лишь «кожа» на эмоциональном каркасе.

## Четырёхшаговый процесс разбора книги

### Шаг 1: разобрать на сцены

Разбить основной текст произведения на «естественные сцены». Одна сцена = одна непрерывная пространственно-временная единица, включающая:

- Единственное пространственное положение
- Непрерывное течение времени
- Взаимодействие группы присутствующих персонажей

Ориентир по грануляции разбиения на сцены: границей сцены считать «смену пространства» или «вход / выход персонажа».

### Шаг 2: разобрать цепочки действие—реакция персонажей внутри сцены

Для каждой сцены отслеживать **последовательность действий и реакций всех присутствующих персонажей**, а не только главного героя:

```text
[Персонаж A] делает действие X → [Персонаж B] делает реакцию Y → [Персонаж C] делает реакцию Z → [Персонаж A] снова реагирует……
```

Ключевые принципы:

- **Действия главного героя обязательно должны быть засвидетельствованы второстепенными героями**. Эмоции читателя возникают не напрямую от действий главного героя, а передаются по цепочке «действие главного героя → реакция / осмысление второстепенного героя».
- **Одновременно записывать условие запуска действия** (какое внешнее событие / внутренний мотив его вызвал) и **непосредственное последствие действия** (какую реакцию дала другая сторона, какие изменения произошли в среде).

### Шаг 3: по действиям вывести эмоции

Из цепочки действие—реакция обратным ходом вывести колебания эмоций каждого:

- Какая эмоция скрыта за каждым действием? (гнев, нетерпение, спокойствие, насмешка, страх……)
- Каково **направление изменения** эмоции? (от спокойствия к гневу / от страха к лёгкости / от сомнения к уверенности……)
- В чём **различия проявления** одной и той же эмоции у разных персонажей? (в одном и том же кризисе: главный герой действует хладнокровно vs второстепенный теряется в панике)

### Шаг 4: последующее повторное использование изменений эмоций

Самый ценный продукт разбора книги — не пересказ сюжета, а **структура эмоций**, то есть:

- Кривая колебаний эмоций этой главы / этого тома (тип эмоции → сила → длительность → узлы изменения)
- **Частота** и **ритм** изменений эмоций
- «Формулы», где определённые комбинации эмоций проверены рынком (например: низ → ожидание → напряжение → освобождение → удовлетворение)

## Шаблон анализа на уровне сцен (можно использовать прямо в отчёте о конкурентах)

Для каждой разбираемой сцены записывать по следующему шаблону:

```markdown
### Сцена N: [положение / название сцены]

**Краткое содержание сцены**
(2–3 предложения о том, что происходит в этой сцене)

**Цепочка действий и реакций персонажей**
(записывать по персонажам и по действиям, отмечая условие запуска и непосредственное последствие)

**Колебания эмоций персонажей**
- [Персонаж A]: от [начальной эмоции] → [изменение] → [конечной эмоции]
- [Персонаж B]: от [начальной эмоции] → [изменение] → [конечной эмоции]

**Цель истории**: функциональное позиционирование этой сцены в главе / томе
**Цель персонажей**: чего хочет достичь каждый появившийся в сцене персонаж
**Степень достижения**: цель достигнута / частично достигнута / не достигнута
**Текущая дилемма**: новая ситуация / давление, с которой персонажи сталкиваются после конца сцены
**Основной конфликт**: тип противоречия, движущего напряжением этой сцены
```

## Основные продукты разбора книги

1. **Перечень сцен**: номера, названия и положение сцен всего произведения / всего тома
2. **Сеть действий и реакций**: цепочка действие—реакция каждой сцены (с условиями запуска и последствиями)
3. **Кривая колебаний эмоций**: тип—сила—направление изменения эмоции каждой сцены, соединяются в кривую эмоций всей главы
4. **Измерение частоты ритма**: число знаков между изменениями эмоций, средняя длина одной сцены, интервал между кульминационными сценами
5. **Разделение «кожи» и «каркаса»**: определить, что является «заменяемой сюжетной кожей» (настройки, объект конфликта, детали мироустройства), а что — «повторно используемым эмоциональным каркасом» (ритм изменений, интервал наград, режим освобождения)

## Сценарии использования в этом Skill

| Сцена | Как использовать метод разбора книги |
| --- | --- |
| Глубокий разбор «слоя создания контента» в отчёте о конкурентах | Для ключевых глав основного образца (золотые три главы / первая кульминация / конец тома) провести поэпизодный разбор книги и извлечь отпечаток эмоционального ритма |
| Проверка того, состоятелен ли паттерн-套路 | Методом разбора книги проверить, соответствует ли «эмоциональный каркас» образца ожидаемой кривой эмоций этого паттерна-套路 |
| Горизонтальное сравнение различий ритма | Разобрав ключевые главы нескольких основных образцов, сравнить частоту и плотность изменений эмоций |
| Поиск ритмического ориентира для текущего проекта | Выделив эмоциональный ритм образца, сопоставить его с ритмом глав текущего проекта и найти разницу как направление оптимизации |

## Произведения для практики разбора, подходящие новичкам

> Следующие произведения обладают весьма ясной эмоциональной структурой, пригодной для разбора, и подходят как вводная практика по разбору книг:

- **《斗破苍穹》 («Битва за небеса»)**: эталон ритма сюаньхуаня — прокачка и «понты», эмоциональная структура исключительно стройна
- **《我真是大明星》 («Я правда звезда»)**: эталон ритма городской прозы «литературного заимствования и понтов», подходит для проверки модели «действие главного героя → реакция второстепенных → передача эмоций»
