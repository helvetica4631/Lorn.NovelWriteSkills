# Карточка исполнения четырёх тактов главы и написания ротации хуков

> Источник критериев: `网文技法.md` (стандартный шаблон главы, ротация хуков) + `使用说明.md` (хуки в первых и последних 200 знаках).

## Четыре такта при написании (обязательно проходить при фиксации текста)

```text
Хук (первые 200 знаков) → накопление силы (конфликт усиливает давление) → награда (ощутимое воплощение в середине) → оставление хука (в последних 200 знаках остаётся незакрытое)
```

## Требования к исполнению каждого такта

- **Хук**: в первых 200 знаках должен появиться как минимум 1 из: конфликт / интрига / аномалия / действие / диалог.
- **Накопление силы**: в середине должно быть видно рост давления, нельзя ограничиваться переносом информации.
- **Награда**: в этой главе как минимум 1 ощутимая награда (одно из: отношения, положение, информация, действие, статус).
- **Оставление хука**: в последних 200 знаках сохраняется незакрытый вопрос или новая переменная; запрещено заменять хук анонсирующим тоном.

## Ротация хуков (между главами)

Избегайте 3 глав подряд с однотипными хуками; рекомендуется ротация:

```text
хук-интрига → хук-конфликт → хук-аномалия → хук-действие → хук-диалог → хук-интрига...
```

## Стиль ритма внутри главы (можно применять напрямую)

```text
Первые 200: хук
Середина A: продвижение главной / побочной линии
Середина B: микроточка 爽 (малый разворот / информационный разрыв)
Середина C: снова добавить давление или повысить ошибку в суждении
Последние 200: оставление хука
```

## Самопроверка при написании (минимальный список)

- Эффективно ли первые 200 знаков цепляют.
- Есть ли в середине явная награда, «оправдывающая билет».
- Формируют ли последние 200 знаков движущую силу «следующую главу обязательно нужно смотреть».
- Не слишком ли повторяется тип хука этой главы с двумя предыдущими.
