# Карточка соответствия перехода от первого лица к третьему и первого появления отношений

> Источник критериев: `经验总结.md` (систематизация перехода от первого лица к третьему).

## Сценарии применения

- Превратить черновик в стиле Zhihu / устного рассказа (первое лицо) в романный стиль (ограниченное третье лицо).
- При переписывании старого черновика завершить преобразование повествовательного ракурса без искажения и потери информации.

## Базовая таблица соответствия (примеры)

| Указание в оригинале | После преобразования (рекомендация) |
| --- | --- |
| Я | Имя главного героя / он (выбирать по позиции во фразе) |
| Моя жена | Имя (первый раз) / она (далее) |
| Моя дочь | Имя (первый раз) / его дочь (второй раз) / она (далее) |
| Мой дед | Имя (первый раз) / его дед (далее) |
| Мой второй дядя | Второй дядя (при первом появлении с указанием отношения) |
| Мой друг детства А-бяо | Его друг детства А-бяо (первое появление) / А-бяо (далее) |
| Ироничные реплики в скобках | Вплести в повествование или удалить |

## Жёсткое правило первого появления

- При первом появлении персонажа обязательно один раз сопоставить «**отношение + имя**».
- При втором появлении можно упростить до «имени» или «местоимения», но нельзя создавать неоднозначность местоимений.
- Когда в сцене несколько персонажей, приоритетно закреплять именем, затем вести местоимением.

## Процесс преобразования (четыре шага)

1. Сначала выполнить «замену лица», не меняя порядок сюжета.
2. Затем выполнить «дополнение отношений при первом появлении», восполнив первый якорь отношений.
3. Затем выполнить «разбор и очистку разговорных реплик», заменив иронию в скобках действием/эмоциональной реакцией.
4. Наконец выполнить «повторную проверку неоднозначности местоимений», обеспечив, что к каждому «он / она» можно сделать обратную отсылку.

## Типичные ошибки и исправление

- **Ошибка**: во всей главе «он» повсюду, читатель не знает, кто это.
  **Исправление**: в ключевых абзацах вернуть якоря имён.
- **Ошибка**: «мне кажется» жёстко заменили на «ему кажется», всё равно остаётся пояснительный тон.
  **Исправление**: переписать в видимое действие или телесное ощущение.
- **Ошибка**: разговорная ирония сохранена как есть.
  **Исправление**: разобрать на конфликт в диалоге, реакцию действием или аномалию сцены.

## Критерии завершения

- Ракурс стабильно ограниченное третье лицо.
- При первом появлении персонажа отношения ясны, последующие указания не путаются.
- Информация без потерь, и не остаётся явного тона самоповествования.
