# Схема противодействия статистическим паттернам и финальной редакторской проверки «человечности»

> **Назначение**: этот файл — дополнение-оптимизация для `通用-去AI味重写`. На базе существующей диагностики 11 крупных структурных отпечатков + 5 количественных показателей + 8-шагового процесса исполнения добавляются два самостоятельных измерения:
> - **Слой противодействия статистическим паттернам**: системное противодействие многомерным статистическим признакам инструментов обнаружения ИИ
> - **Слой финальной редакторской проверки «человечности»**: замкнутый контур итогового ручного вердикта, независимый от технического устранения «духа ИИ»
>
> **Связь с существующей системой**: эта схема не заменяет существующую систему диагностики/исполнения/повторной проверки, а **добавляет над ней слой «осознанного противодействия» и слой «финального контроля»**.

## II. Новое: слой противодействия статистическим паттернам

### 2.1 Основная идея

Цель устранения «духа ИИ» на статистическом уровне — не «стать похожим на человека», а **системно снизить детектируемость по измерениям оценки инструментов обнаружения ИИ**. Для этого нужно:
1. Знать, на что смотрит инструмент обнаружения (полный перечень измерений статистических признаков)
2. Знать «оценку подозрения на ИИ» своего текста по каждому измерению
3. Знать, какова операция противодействия по каждому измерению
4. После противодействия заново измерить и убедиться, что оценка упала

### 2.2 Панорама десяти статистических измерений инструментов обнаружения

Следующие десять измерений охватывают ключевые измерения оценки основных инструментов обнаружения ИИ (Zhuque, GPTZero, Originality.ai, GLTR и др.):

| № | Статистическое измерение | Принцип обнаружения | Сигнал высокого риска в ИИ-тексте | Направление противодействия |
| --- | --- | --- | --- | --- |
| **D1** | Перплексия (Perplexity) | Измеряет «предсказуемость» каждого слова в контексте — много слов высокой вероятности = низкая перплексия = предсказуемо = ИИ | Выбор слов слишком «безопасный», сплошь частые обычные слова | **Вводить маловероятные слова**: диалектизмы, жаргон, редкие, но точные глаголы |
| **D2** | Всплесковость (Burstiness) | Дисперсия длины фраз — у ИИ длина фраз сосредоточена в 12–18 знаках, у человека колебания 2–40 знаков | Стандартное отклонение длины фраз < 5 знаков | **Активно создавать дисперсию длины фраз**: короткие фразы 2–5 знаков ≥ 10%, длинные 25+ знаков ≥ 15% |
| **D3** | Лексическая энтропия (Entropy) | Разнообразие лексики — ИИ избегает редких слов, у человека естественное лексическое разнообразие | Слишком бедный словарь, механическая ротация синонимов | **Допускать естественные повторы + изредка редкие слова**: где нужно повторить — повторять, где ротация не нужна — не ротировать |
| **D4** | Разнообразие N-грамм | Модели сочетаний из 2–4 подряд слов — в ИИ-тексте некоторые N-граммы повторяются | Частые 3-граммы/4-граммы вроде «值得注意的是» (стоит отметить), «通过……实现» (достигается посредством…) | **Разрывать частые N-граммы**: заменять связки, перестраивать порядок фраз |
| **D5** | Семантическая связность | Логическая цепочка ИИ-текста слишком линейно полна (A→B→C→D без скачков) | На каждом шаге причинность проговорена, нет информационных скачков | **Намеренно создавать информационные пробелы**: опустить шаг рассуждения, оставить один пробел |
| **D6** | Распределение служебных слов | ИИ злоупотребляет некоторыми функциональными словами (然而 / 因此 / 此外 / 值得注意的是 — однако / поэтому / кроме того / стоит отметить) | Плотность служебных слов > человеческого среднего | **Удалять служебные слова, переходить естественно действием/сценой** |
| **D7** | Паттерн пунктуации | Предпочитаемое ИИ распределение знаков (слишком много тире, длинные абзацы на запятых) | Тире > 2,5%, запятые связывают 3 и более фраз подряд | **Тире заменять точками, запятые заменять точками** |
| **D8** | Распределение длины абзацев | У ИИ дисперсия длины абзацев мала (в каждом по 3–5 фраз) | Мало стандартное отклонение длины абзацев, нет абзацев из 1 фразы | **Вставлять абзацы из 1 фразы и длинные абзацы из 8–10 фраз** |
| **D9** | Плоскостность эмоциональной кривой | Концентрация эмоций ИИ равномерна по всему тексту (в каждом абзаце «эмоция», но без подъёмов и спадов) | Равномерная плотность слов эмоций, нет резко контрастных абзацев | **Создавать пики и впадины эмоций**: в напряжённых абзацах плотная эмоция, в переходных почти нет эмоции |
| **D10** | Соотношение диалога/повествования | Доля повествования у ИИ слишком высока, доля диалога аномальна | Доля диалога < 30% либо диалог слишком шаблонный | **Увеличивать долю настоящего диалога, сокращать повествовательные объяснения** |

### 2.3 Замкнутый трёхшаговый контур статистического противодействия

```text
┌─────────────────────────────────────────────────────────┐
│  Шаг 1: полное сканирование по всем измерениям до противодействия (диагностика) │
│  → Прогнать целевой текст через количественное обнаружение по D1–D10            │
│  → Отметить уровень риска ИИ по каждому измерению (высокий/средний/низкий)     │
│  → Вывести «ТОП-3 измерения, которые инструмент обнаружения вероятнее всего помечает красным» │
├─────────────────────────────────────────────────────────┤
│  Шаг 2: целевое исполнение противодействия                                       │
│  → По ТОП-3 высокорисковым измерениям исполнить операции противодействия по одному │
│  → Одновременно выполнить «впрыск человеческого отпечатка» (см. §III)           │
│  → Сохранять ограничения охранных красных линий (информация не теряется, хук не рушится, голоса не смешиваются) │
├─────────────────────────────────────────────────────────┤
│  Шаг 3: проверка после противодействия                                          │
│  → Повторно прогнать количественное обнаружение по D1–D10                       │
│  → Сравнить изменения оценок по измерениям до и после противодействия           │
│  → Подтвердить, подействовал ли «впрыск человеческого отпечатка» (см. §III)     │
│  → Если любое высокорисковое измерение не опустилось до «среднего» и ниже → вернуться к Шагу 2 для этого измерения │
└─────────────────────────────────────────────────────────┘
```

### 2.4 Методы количественного обнаружения десяти измерений

Для каждого измерения даётся конкретный **практический метод обнаружения** (когда не нужно реально запускать код — даются быстрые методы ручного подсчёта):

#### D1: перплексия (Perplexity) — предсказуемость лексики

**Быстрый метод обнаружения**: взять первые 500 знаков основного текста и подсчитать плотность следующих «безопасных слов»:
- Частые безопасные глаголы: `进行`, `实现`, `完成`, `使用`, `发生`, `出现`, `感到`, `注意到` (осуществлять, реализовывать, завершать, использовать, происходить, появляться, чувствовать, замечать)
- Частые безопасные наречия: `非常`, `十分`, `极其`, `特别`, `相当` (очень, весьма, крайне, особенно, довольно)
- Частые безопасные прилагательные: `重要`, `关键`, `显著`, `有效`, `明显` (важный, ключевой, существенный, эффективный, очевидный)

| Плотность безопасных слов (на тысячу знаков) | Вердикт |
 --- | --- |
| ≤ 5 раз | Низкий риск |
| 5–10 раз | Средний риск |
| > 10 раз | Высокий риск |

**Операции противодействия**:
1. По одному заменить безопасные глаголы более конкретными: «进行» → конкретное действие; «感到» → удалить, прямо писать содержание ощущения
2. Удалить не менее половины «非常/十分/极其»
3. Ввести 3–5 «редких, но точных» слов: диалектизмы, отраслевой жаргон, термины конкретной сцены

#### D2: всплесковость (Burstiness) — дисперсия длины фраз

**Метод обнаружения**: подсчитать число знаков в каждой фразе всего текста, вычислить стандартное отклонение.

| Стандартное отклонение длины фраз | Вердикт |
| --- | --- |
| ≥ 8 знаков | Низкий риск |
| 5–8 знаков | Средний риск |
| < 5 знаков | Высокий риск |

**Операции противодействия** (уже охвачены в SKILL.md, принцип 6, измерение B, здесь добавлены точные количественные цели):
- Цель дисперсии длины фраз ≥ 9 знаков
- Короткие фразы в 2–5 знаков составляют ≥ 10% общего числа фраз текста
- Длинные фразы в 25–40 знаков составляют ≥ 12% общего числа фраз текста
- При каждом абзаце из 10 и более фраз близкой длины вставить посередине абзац из 1 фразы

#### D3: лексическая энтропия (Entropy) — разнообразие лексики

**Быстрый метод обнаружения**: взять первые 500 знаков, подсчитать число неповторяющихся полнозначных слов (существительные + глаголы + прилагательные) / общее число полнозначных слов.

| Повторяемость полнозначных слов | Вердикт |
| --- | --- |
| ≥ 70% (то есть 70% полнозначных слов не повторяются) | Низкий риск |
| 50%–70% | Средний риск |
| < 50% | Высокий риск |

**Операции противодействия**:
1. Проверить ротацию синонимов: если один и тот же объект в тексте последовательно называют тремя и более разными именами («главный герой → персонаж → центральная фигура → герой»), вернуть единое наименование — реальный человек так не ротирует
2. Допускать естественный повтор ключевых слов: в одной главе имя ключевого персонажа и название ключевого предмета могут повторяться 5–10 раз, не менять слова «ради избегания повтора»
3. При описании ключевых сцен использовать 3–5 существительных, специфичных для этой сцены (например для сцены суда «судейский молоток, скамья истца, секретарь, перекрёстный допрос, перерыв в заседании»)

#### D4: разнообразие N-грамм

**Быстрый метод обнаружения**: просканировать число появлений следующих высокочастотных 3-грамм/4-грамм:

| Паттерн N-граммы | Число появлений/тысяча знаков |
| --- | --- |
| `值得注意的是` (стоит отметить) | ≤ 0,3 |
| `通过……实现` (достигается посредством…) | ≤ 0,3 |
| `不是……而是` (не…, а) | ≤ 0,5 |
| `从……到……` (от… до…) | ≤ 0,3 |
| `一方面……另一方面` (с одной стороны… с другой стороны) | ≤ 0,2 |
| `不仅仅……更` (не только… но ещё и) | ≤ 0,2 |
| `除此之外` (помимо этого) | ≤ 0,3 |
| `总的来说` (в целом) | ≤ 0,2 |

Если любой из перечисленных паттернов > порога → эта N-грамма — сигнал высокого риска, нужна глобальная замена.

**Операции противодействия**: прямое удаление или замена фрагментарными выражениями. Подробнее см. `AI句式替换与动作化替代清单.md`.

#### D5: семантическая связность — линейность логики

**Метод обнаружения**: в основном тексте по абзацам отметить «причинные связки» (因为 / 所以 / 因此 / 于是 / 导致 / 从而 / 进而 / 由此 / 可见 — потому что / поэтому / вследствие этого / и вот / приводит к / тем самым / далее / отсюда / видно). Подсчитать плотность причинных связок на тысячу знаков.

| Плотность причинных связок (на тысячу знаков) | Вердикт |
| --- | --- |
| ≤ 2 раз | Низкий риск |
| 2–4 раза | Средний риск |
| > 4 раз | Высокий риск |

**Операции противодействия**:
1. Удалить не менее половины причинных связок, пусть причинность подразумевается в порядке событий
2. Намеренно оставить один логический скачок «персонаж ошибся в рассуждении, но читателя не поправили» — ИИ так писать не смеет
3. Вставить в причинную цепочку один фрагмент информации, «внешне не относящийся к делу, связь которого раскрывается позже»

#### D6: распределение служебных слов

**Метод обнаружения**: подсчитать суммарную плотность следующих служебных слов (на тысячу знаков):

`然而`, `此外`, `因此`, `不过`, `但是`, `虽然`, `因为`, `所以`, `于是`, `从而`, `进而`, `同时`, `另外`, `另一方面`, `在这种情况下`, `基于此`, `值得注意的是`, `不可否认` (однако, кроме того, поэтому, впрочем, но, хотя, потому что, так что, и вот, тем самым, далее, одновременно, а также, с другой стороны, в этой ситуации, исходя из этого, стоит отметить, нельзя отрицать)

| Суммарная плотность служебных слов (на тысячу знаков) | Вердикт |
 --- |--- |
| ≤ 3 раз | Низкий риск |
| 3–6 раз | Средний риск |
| > 6 раз | Высокий риск |

**Операции противодействия** (уже охвачены в SKILL.md `AI句式替换与动作化替代清单.md`, здесь добавлены количественные цели):
- Цель суммарной плотности служебных слов ≤ 2 раза/тысячу знаков
- Слова принудительной замены вроде «然而/此外/因此» → цель: ноль

#### D7: паттерн пунктуации

**Метод обнаружения**: подсчитать долю тире в общем числе знаков препинания + число фраз, связанных запятыми (доля случаев, когда 3 и более фраз подряд соединены только запятыми).

| Доля тире | Доля связывания запятыми | Вердикт |
| --- | --- | --- |
| ≤ 1,5% и доля связывания < 30% | — | Низкий риск |
| 1,5%–2,5% или доля связывания 30%–50% | — | Средний риск |
| > 2,5% или доля связывания > 50% | — | Высокий риск |

**Операции противодействия**:
1. Тире → в первую очередь заменять точкой или запятой
2. В каждой цепочке из 3 запятых хотя бы одну заменить точкой
3. Намеренно в 1–2 местах использовать редкий паттерн пунктуации (например китайское многоточие `……` для обозначения проглоченных слов)

#### D8: распределение длины абзацев

**Метод обнаружения**: подсчитать стандартное отклонение числа фраз в абзацах.

| Стандартное отклонение числа фраз в абзаце | Вердикт |
| --- | --- |
| ≥ 2,5 | Низкий риск |
| 1,5–2,5 | Средний риск |
| < 1,5 | Высокий риск |

**Операции противодействия**:
1. Цель стандартного отклонения числа фраз в абзаце ≥ 3,0
2. Не менее 3 абзацев из 1 фразы во всём тексте
3. Не менее 2 длинных абзацев из 8 и более фраз во всём тексте
4. Не допускать 5 и более подряд «стандартных абзацев» по 3–5 фраз

#### D9: плоскостность эмоциональной кривой

**Метод обнаружения**: разбить основной текст по абзацам, каждому абзацу проставить интенсивность эмоции (1–5). Вычислить амплитуду изменения эмоции между соседними абзацами.

| Средняя амплитуда изменения эмоции между соседними абзацами | Вердикт |
| --- | --- |
| ≥ 1,5 | Низкий риск |
| 1,0–1,5 | Средний риск |
| < 1,0 | Высокий риск |

**Операции противодействия**:
1. Убедиться, что есть как минимум один «резкий скачок эмоции вверх» (скачок абзаца с 2→5)
2. Убедиться, что есть как минимум один «заметный спад эмоции» (скачок абзаца с 5→2)
3. В переходных абзацах намеренно понижать эмоцию (пометка 1–2), не требуя «чувства в каждом абзаце»

#### D10: соотношение диалога/повествования

**Метод обнаружения**: подсчитать долю строк диалога в общем числе строк текста.

| Доля диалога | Вердикт |
| --- | --- |
| 30%–60% | Низкий риск |
| 20%–30% или 60%–70% | Средний риск |
| < 20% или > 70% | Высокий риск |

**Операции противодействия**:
1. Если диалог < 20%: добавить не менее 2 отрывков настоящего диалога (не информационно-объяснительного), чтобы персонажи взаимодействовали в сцене
2. Если диалог > 70%: добавить описание действий и сценические переходы, избегать ощущения сценария «сплошные реплики»
3. Проверить, нет ли в диалоге «все говорят на одном стандартном китайском» — если есть, добавить хотя бы двум персонажам речевую привычку

### 2.5 Матрица приоритетов статистического противодействия

Когда одновременно несколько высокорисковых измерений из десяти, обрабатывать послойно по следующему приоритету:

```
Первый приоритет (напрямую запускает тревогу обнаружения):
  D2 (дисперсия длины фраз) > D7 (паттерн пунктуации) > D8 (распределение длины абзацев)
  → Эти три измерения — прямое отражение «равномерности» и легче всего улавливаются инструментами обнаружения

Второй приоритет (измерения с наибольшим сопутствующим влиянием):
  D1 (перплексия) > D6 (служебные слова) > D4 (разнообразие N-грамм)
  → Улучшение этих трёх измерений одновременно снижает D2/D7/D8

Третий приоритет (тонкая оптимизация):
  D3 (лексическая энтропия) > D5 (семантическая связность) > D9 (эмоциональная кривая) > D10 (доля диалога)
  → У этих измерений при обнаружении меньший вес, но они влияют на общее ощущение «человечности»
```

## III. Новое: активный впрыск человеческих отпечатков

### 3.1 Основная идея

Оборонительная логика устранения «духа ИИ» — «устранить следы ИИ»; наступательная логика статистического противодействия — «сделать так, чтобы инструмент обнаружения не мог различить».
Но у обоих общая слепая зона: **можно добиться «не похоже на ИИ», но всё ещё нельзя добиться «похоже на речь конкретного человека».**

Впрыск человеческих отпечатков — третье измерение: помимо устранения следов, активно вживляются не подделываемые человеческие черты.

### 3.2 Четыре вида человеческих отпечатков

| Вид отпечатка | Определение | Метод впрыска | Слепая зона инструментов обнаружения |
| --- | --- | --- | --- |
| **Физиологический отпечаток** | Свойственные автору ритм, дыхание, предпочтения в конструкциях | Сознательно сохранять/воспроизводить «несовершенные» привычки автора: многословные переходные фразы, любимые связки поворота, устойчивое дыхание абзацев | Инструмент обнаружения не различает «авторский стиль» и «не ИИ», а лишь выносит вердикт «низкая вероятность ИИ» |
| **Опытный отпечаток** | Детали, которые можно написать, лишь действительно пережив | Вживить в основной текст не менее 1 «детали, которую нельзя нагуглить» — конкретное время, конкретное место, чувственный осколок, который помнит только очевидец | ИИ не может сгенерировать детали, на которых его не обучали |
| **Отпечаток предубеждения** | Иррациональные предпочтения и слепые зоны персонажа/рассказчика | Дать хотя бы одному персонажу «необоснованное» суждение — не оптимальное по логике, но соответствующее его опыту и характеру | ИИ склонен делать суждение каждого персонажа «оптимальным при текущей информации» |
| **Отпечаток ошибки** | Контролируемое несовершенство: опечатка, оговорка, неверная память, ошибочное суждение | Оставить не менее 1 места «верного рассуждения персонажа на основе ошибочной предпосылки» либо «тогдашнего суждения, позже опровергнутого» | Цепочка рассуждений ИИ не работает «при заведомо ошибочной предпосылке» — он по природе стремится к правильности |

### 3.3 Контрольный список впрыска

По завершении устранения «духа ИИ» по списку пункт за пунктом подтвердить, внесены ли человеческие отпечатки:

- [ ] **Физиологический отпечаток**: сохранена ли в главе хотя бы одна «личная привычка» автора (определённое присловье, предпочтение конструкции, способ дыхания абзацев)?
- [ ] **Опытный отпечаток**: содержит ли глава хотя бы одну «деталь, которую нельзя нагуглить» (конкретное время, конкретное место, чувственный осколок, который помнит только очевидец)?
- [ ] **Отпечаток предубеждения**: выразил ли хотя бы один персонаж в этой главе «необоснованное, но соответствующее образу» суждение?
- [ ] **Отпечаток ошибки**: есть ли в главе хотя бы одно место «рассуждения персонажа на основе ошибочной информации» или «позже опровергнутого суждения»?
- [ ] **Языковой отпечаток**: сохранены ли в главе лексические поля автора, привычки конструкций и риторические отпечатки (см. SKILL.md «Правила защиты языкового отпечатка»)?
- [ ] **Сохранение шероховатости**: намеренно ли оставлен один «не слишком красивый, но информативный» переходный абзац?
- [ ] **Информационный пробел**: есть ли хотя бы одна недосказанность «читатель хочет спросить, но в этой главе ответа нет»?

## IV. Новое: финальная редакторская проверка «человечности»

### 4.1 Позиция

«Финальная редакторская проверка „человечности“» — это **звено итогового контроля**, независимое от существующего 8-шагового процесса исполнения, выполняется после шага 8 «повторная проверка и вывод».

Её отличие от существующей повторной проверки:

| Измерение | Существующая повторная проверка (шаг 8) | Финальная редакторская проверка «человечности» (новое) |
| --- | --- | --- |
| Цель проверки | Полна ли ответственность главы (хук, питание, голоса) | Может ли текст пройти «ручную редакторскую рецензию» |
| Точка зрения проверки | Исходит из творческих норм | Исходит из интуиции рецензирующего редактора/читателя |
| Способ проверки | Пункт за пунктом по списку | Ролевая имитация + интуитивное суждение |
| Выход | Повторная проверка пройдена/запись обратно вверх по цепочке | Вердикт финальной проверки: пройдено / подозрительные абзацы отмечены / на переплавку |

### 4.2 Имитация финальной проверки с трёх точек зрения

При финальной проверке прочитать весь текст по очереди с тремя точками зрения:

#### Точка зрения 1: редактор, подписывающий контракт

> «Это присланная рукопись. Смотрю глазами редактора — эта глава похожа на написанную человеком? Или заставит меня подозревать, что автор использовал ИИ?»

**Контрольный список**:

1. **Согласованность логики главной линии** (наибольший вес)
   - [ ] Самосогласованы ли события до и после? Нет ли логического разрыва «в тексте выше сказано A, ниже стало B»?
   - [ ] Полно ли сквозное проведение линий? Нет ли «какая-то линия вдруг исчезла и вдруг появилась»?
   - [ ] ИИ легче всего теряет линии в длинных произведениях — выборочно проверить 1–2 межглавные линии и убедиться, что они не оборваны

2. **Устойчивость образа персонажа**
   - [ ] Согласованы ли слова и поступки одного персонажа в рамках главы?
   - [ ] Нет ли дрейфа характера «в первой половине главы интеллигентный, во второй — бойкий»?
   - [ ] Основаны ли решения персонажа на мотивах из его биографии, а не на «нужде сюжета»

3. **Естественность диалога**
   - [ ] Если убрать пометки диалога, можно ли различить, кто говорит, только по репликам?
   - [ ] Различаются ли у всех персонажей лексика, конструкции и тон?
   - [ ] Нет ли унификации интонации «все говорят на одном стандартном китайском»?

4. **Естественность переходов**
   - [ ] Не нарочиты ли смены сцен? (особо обращать внимание на частые переходные слова ИИ вроде «转眼间» (в мгновение ока), «片刻后» (спустя миг), «与此同时» (в то же время))
   - [ ] Подхвачены ли скачки времени износом сцены или сезонными приметами?
   - [ ] Нет ли «эмоции предыдущей сцены, прямо брошенной следующей сценой»?

5. **Эффективность описаний**
   - [ ] Служат ли все описания продвижению сюжета?
   - [ ] Нет ли «очень красиво написанного, но не двигающего сюжет ИИ-расширения»?
   - [ ] Разумна ли плотность информации — где нужно густо, там густо; где нужно редко, там редко?

6. **Общее впечатление**
   - [ ] Прочитав главу, чувствуете ли вы, что «это написал живой человек из плоти и крови»?
   - [ ] Не вызвал ли какой-то абзац инстинктивное «этот абзац слишком похож на ИИ»?

#### Точка зрения 2: давний читатель

> «Я постоянный читатель. Приятно ли читать эту главу? Не застряну ли? Не захочется ли бросить?»

**Контрольный список**:

1. **Цепкость начала**
   - [ ] Удерживают ли первые 150 знаков внимание?
   - [ ] Нет ли начала с «пояснения сеттинга»? (если есть → высокий риск ИИ)
   - [ ] Не заменено ли действие словами «он почувствовал / она осознала»? (если да → высокий риск ИИ)

2. **Дыхание чтения**
   - [ ] Есть ли абзацы, на которых нужно остановиться и перевести дух? Или плотность одинакова от начала до конца?
   - [ ] Не «соскользнёт» ли середина главы — читаешь-читаешь, и вдруг не хочется читать?
   - [ ] Есть ли естественный ритм «информации ровно столько, читать приятно»?

3. **Управление ожиданиями**
   - [ ] Прочитав главу, хочется ли узнать, «что будет в следующей главе»?
   - [ ] Нет ли «ложного хука» — выглядит остро, но при размышлении нет существенного содержания?
   - [ ] Нет ли «чрезмерного замыкания» — все интриги объяснены дочиста?

4. **Эмоциональный отклик**
   - [ ] Был ли момент, когда вы волновались/жалели/радовались за персонажа?
   - [ ] Эмоция показана действиями и сценой или прямо сообщена фразой «он почувствовал себя очень X»?

#### Точка зрения 3: инструмент обнаружения ИИ

> «Я притворяюсь детектором ИИ. Сколько баллов я поставлю этому тексту? Какие абзацы пометлю красным?»

**Контрольный список**:

1. **Сканирование равномерности**
   - [ ] Есть ли заметная дисперсия распределения длины фраз? (D2)
   - [ ] Есть ли колебания длины абзацев? (D8)
   - [ ] Нормально ли распределение знаков препинания? (D7)

2. **Сканирование частых паттернов**
   - [ ] Не слишком ли высока плотность служебных слов? (D6)
   - [ ] Нет ли в N-граммах явных шаблонов? (D4)
   - [ ] Не превышена ли плотность частых слов ИИ? (D1)

3. **Сканирование логической цепочки**
   - [ ] Не слишком ли плотны причинные связи? (D5)
   - [ ] Нет ли чрезмерного рассуждения «каждый шаг разъяснён»?

4. **Общее суждение**
   - [ ] Если бы я был инструментом обнаружения, какую вероятность ИИ я поставил бы этому тексту?
   - [ ] Какие 3 абзаца самые рискованные? Почему?
   - [ ] Можно ли дополнительно оптимизировать эти 3 абзаца, не трогая информацию?

### 4.3 Вердикт финальной проверки и вывод

По завершении финальной проверки вывести следующий вердикт:

```markdown
## Отчёт финальной редакторской проверки «человечности»

### Сводный вердикт по трём точкам зрения
- Точка зрения редактора, подписывающего контракт: пройдено / подозрительно (с отметкой абзацев) / на переплавку
- Точка зрения давнего читателя: пройдено / подозрительно (с отметкой абзацев) / на переплавку
- Точка зрения инструмента обнаружения ИИ: пройдено / подозрительно (с отметкой абзацев) / на переплавку

### Комплексная оценка
- 🟢 Зелёный: все три точки зрения пройдены → можно публиковать
- 🟡 Жёлтый: на любой точке зрения есть подозрение, но можно починить локально → отметить подозрительные абзацы, после локальной правки выпускать
- 🔴 Красный: любая точка зрения вынесла «на переплавку» → вернуться в процесс устранения «духа ИИ» с указанием измерения для переплавки

### Отметка подозрительных абзацев (если есть)
| Положение абзаца | Причина подозрения | Измерение | Рекомендация по исправлению |
| ---  --- 
| Абзац X | …… | D2/D5/… | …… |

### Подтверждение впрыска человеческих отпечатков
- [ ] Физиологический отпечаток ✓ / ✗
- [ ] Опытный отпечаток ✓ / ✗
- [ ] Отпечаток предубеждения ✓ / ✗
- [ ] Отпечаток ошибки ✓ / ✗
- [ ] Сохранение шероховатости ✓ / ✗
- [ ] Информационный пробел ✓ / ✗
```

### 4.4 Что делать, если финальная проверка не пройдена

Если вердикт финальной проверки 🔴 красный:

1. **Определить измерение переплавки**: проблема на статистическом уровне (оценка какого-то измерения D1–D10 слишком высока) или на уровне «человечности» (одна из трёх точек зрения вынесла «не похоже на написанное человеком»)?
2. **Стратегия переплавки**:
   - Проблема статистического уровня → вернуться к §2.3 Шаг 2, провести целевое противодействие по указанному измерению
   - Проблема уровня «человечности» → вернуться к §3 «Впрыск человеческих отпечатков», восполнить недостающие виды отпечатков
   - Обе → сначала статистическое противодействие, затем впрыск человеческих отпечатков, наконец заново финальная проверка
3. **Лимит раундов переплавки**: не более 2 раундов. Если и после 2 раундов не пройдено → пометить «оптимальная версия при нынешних технических условиях» и отметить нерешённые измерения

### 7.2 Предупреждение о рисках

1. **Риск чрезмерного противодействия**: статистическое противодействие может заставить чрезмерно сосредоточиться на «снижении оценки детектора» и игнорировать «повышение качества текста». Необходимо помнить принцип 8, представление 1 — хорошее устранение «духа ИИ» одновременно повышает долю прохождения обнаружения и читательский опыт.

2. **Ограниченность имитации финальной проверки**: «редакторская рецензия», имитируемая ИИ, не может полностью заменить суждение настоящего редактора. Финальная проверка с трёх точек зрения — страховочный механизм, а не заменяющий.

3. **Ручные затраты на обнаружение по десяти измерениям**: полное сканирование по всем измерениям для короткой главы (<3000 знаков) занимает около 15–20 минут, для длинной главы (5000–8000 знаков) — около 30–45 минут. Рекомендуется применять в первую очередь к «главам, помеченным красным инструментом обнаружения», а не гонять полное сканирование для каждой главы.
