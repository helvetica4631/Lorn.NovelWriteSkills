# Карточка якорей впрыска стиля

> Этот файл определяет, как `通用-去AI味重写` в «слое возвращения человеческого голоса» переводит поля шаблона авторского стиля в фразовые ограничения после устранения «духа ИИ». Когда в `Agents.md` проекта зарегистрирован шаблон авторского стиля, эта карточка якорей действует автоматически.

---

## Основная логика

«Возвращение человеческого голоса» после устранения «духа ИИ» возвращает не универсальную естественную разговорную речь, а **«настоящую человечность» конкретного автора**. Таблицы отображения ниже определяют правила перевода каждого поля шаблона → фразового ограничения при устранении.

---

## Таблица отображения полей

### I. Базовая линия длины фраз → ограничение при устранении

| Поле шаблона | Пример значения | Фразовое ограничение после устранения |
| --- | --- | --- |
| Доля коротких фраз | Короткие фразы составляют 60% | После разбиения ровных групп фраз при перестройке распределения длины в первую очередь обеспечить долю коротких фраз в диапазоне 55–65% |
| Модель длины фраз в сценах действия | «Подряд 4–6 коротких фраз, затем вставка 1 средней фразы» | Ритм длины фраз в абзацах действия перестраивать строго по этой модели |
| Запрет по длине фраз | «Никогда не использует подряд более 3 длинных фраз по 35+ знаков» | Категорически запрещено в тексте после устранения появление 3 и более длинных фраз по 35+ знаков подряд |

**Порядок действий**:

1. После разбиения ровных групп фраз при устранении подсчитать распределение длины фраз текущего текста
2. Сверяясь с базовой линией длины фраз шаблона, заново отрегулировать распределение: если коротких фраз мало — добавить короткие/разбить длинные, если длинных слишком густо — слить/сократить
3. Для разных типов сцен перестраивать отдельно по модели длины фраз для сцен в шаблоне

---

### II. Ритм абзацев → ограничение при устранении

| Поле шаблона | Пример значения | Фразовое ограничение после устранения |
| --- | --- | --- |
| Доля абзацев из одной фразы | 15% | Обеспечить, чтобы на каждые 6–8 абзацев приходился хотя бы 1 абзац из одной фразы в качестве ритмического ударения |
| Доля коротких абзацев | 50% | Основная линия абзацев для телефона, не допускать подряд более 3 средне-длинных абзацев |
| Модель начального абзаца | «Сначала абзац из одной фразы, закрепляющий эмоцию → 2 средних абзаца развёртывания → короткие абзацы с ускорением» | Начальные абзацы главы перестраивать строго по этой модели |
| Запрет по ритму абзацев | «Никогда не начинает длинным абзацем» | Если первый абзац главы превышает 4 фразы, обязательно разбить |

**Порядок действий**:

1. Подсчитать распределение типов абзацев текста после устранения
2. Сверяясь с ритмом абзацев шаблона, переставить абзацы по модели чередования шаблона
3. «Запреты» в шаблоне напрямую служат жёсткими ограничениями — при попадании править

### III. Чувственные предпочтения → ограничение при устранении

| Поле шаблона | Пример значения | Фразовое ограничение после устранения |
| --- | --- | --- |
| Доля осязания | 25% | При добавлении чувственных деталей после устранения в первую очередь добавлять осязание (температура/фактура/давление) |
| Слепая зона обоняния | «Почти не использует обоняние» | После устранения не добавлять описание обоняния по своей инициативе |
| Закономерность использования чувств | «Зрение главное 60%, в ключевые моменты вставляются осязание/телесные ощущения» | Когда чувственных описаний становится больше, распределять в этих пропорциях |

**Порядок действий**:

1. «Абстрактные прилагательные», удалённые при устранении, нужно заменить «чувственными деталями»
2. При замене выбирать чувственные каналы в пропорциях чувственных предпочтений шаблона
3. Чувственные слепые зоны шаблона по своей инициативе не использовать

### IV. Конфигурация стиля диалога → ограничение при устранении

| Поле шаблона | Пример значения | Фразовое ограничение после устранения |
| --- | --- | --- |
| Предпочтение пометок диалога | «Школа пометок-действий 70%» | В пометках диалога после устранения в первую очередь использовать пометки-действия или опускать пометки, ограничивая «XX сказал» |
| Плотность перебиваний | 3 раза/тысячу знаков | Вставлять в диалог перебивания/перехваты/уход от темы с частотой ≈ не реже 1 раза на каждые 300–400 знаков |
| Особенность длины фраз диалога | «Короткие фразы 80%» | После устранения длина фраз диалога не более 20 знаков (если только голос персонажа сам не является типом длинных фраз) |
| Глубина подтекста | Глубокая | Обеспечить, чтобы сказанное персонажем ≠ истинный смысл, сохранить хотя бы 1 слой несказанной информации |

**Порядок действий**:

1. Проверить распределение типов пометок диалога после устранения → скорректировать по предпочтениям шаблона
2. Проверить «слишком гладкие» абзацы в диалоге → вставить перебивания/уходы/встречные вопросы по плотности перебиваний шаблона
3. Проверить длину фраз диалога → править по ограничениям шаблона

### V. Отпечаток метафор → ограничение при устранении

| Поле шаблона | Пример значения | Фразовое ограничение после устранения |
| --- | --- | --- |
| Распределение источников метафор | Мир природы 40%, быт/еда 30% | При добавлении новых метафор после устранения в первую очередь выбирать образы из областей с высокой долей |
| Запретные области метафор | «Никогда не использует метафоры из современных технологий» | Категорически запрещено появление метафор с образами из современных технологий (код/чип/алгоритм/ИИ/интернет) |
| Плотность метафор | 1,5 места/тысячу знаков | Плотность метафор после устранения держать в пределах 1–2 мест/тысячу знаков, не нагромождать и не исчезать |

**Порядок действий**:

1. Когда «шаблонные метафоры», удалённые при устранении, нужно заменить → выбирать образы по распределению областей в шаблоне
2. Запретные области шаблона — жёсткое ограничение: при попадании заменять

---

### VI. Способы выражения эмоций → ограничение при устранении

| Поле шаблона | Пример значения | Фразовое ограничение после устранения |
| --- | --- | --- |
| Доля телесного выражения | 60% | После устранения в первую очередь заменять прямые слова эмоций телесными реакциями |
| Доля прямого называния эмоций | < 5% | После устранения почти не использовать прямые слова эмоций вроде «страшно/грустно/гнев» |
| Запрет по выражению эмоций | «Никогда не заставляет погоду плакать за персонажа» | Категорически запрещено прямое отображение эмоций персонажа через погоду/среду |

**Порядок действий**:

1. «Прямое называние эмоций», удалённое при устранении, нужно заменить «выражением эмоций»
2. Выбирать способ замены по пропорциям шаблона — сначала телесное, затем вынесение вовне действием
3. Запреты шаблона — жёсткое ограничение

---

### VII. Список запретов → жёсткие ограничения при устранении

Каждый пункт списка запретов шаблона §VIII после устранения категорически запрещён.
По завершении устранения обязательно просканировать пункт за пунктом, при попадании править.

**Запреты на конструкции** → после устранения сканировать весь текст, при попадании заменять конструкцию
**Запреты на риторику** → после устранения сканировать весь текст, при попадании удалять или заменять риторический приём
**Запреты на повествование** → при устранении обходить, не использовать намеренно
**Запреты на лексику** → после устранения искать и заменять по всему тексту

## Логика деградации

| Ситуация | Обработка |
| --- | --- |
| В `Agents.md` не зарегистрирован шаблон авторского стиля | Откат к универсальному возвращению человеческого голоса по стандартному процессу устранения «духа ИИ» (текущий режим по умолчанию) |
| Шаблон есть, но по какому-то измерению пометка «недостаточно информации» | Для этого измерения впрыск пропускается, откат к универсальному режиму |
| Поля шаблона отсутствуют | Пропущенные поля пропускаются при впрыске, откат к универсальному режиму |

## Пример использования

**Сцена**: переписать по устранению «духа ИИ» отрывок сцены действия, в проекте зарегистрирован «шаблон авторского стиля 猫腻» («Мао Ни»)

Ключевые поля шаблона «Мао Ни»:

- Базовая линия длины фраз: сцены действия «подряд 4–6 коротких фраз, затем вставка 1 средней фразы»
- Чувственные предпочтения: зрение 55%, осязание 28%, телесные ощущения 15%
- Отпечаток метафор: предпочитает области еды/цвета/древней утвари, запрет на область современных технологий
- Список запретов: не использовать «突然/猛地/竟然» (вдруг / резко / неожиданно), не использовать «标志着/体现了» (знаменует / воплощает)

Ограничения после устранения:

1. Длину фраз в абзацах действия перестраивать в ритме «4–6 коротких + 1 средняя»
2. При добавлении чувственных деталей: в первую очередь осязание (холод рукояти оружия, ломота мышц руки) + телесные ощущения (стеснение во внутренностях)
3. Если нужна метафора: выбирать образ из областей еды/цвета/древней утвари, ни в коем случае не из технологий
4. Просканировать весь текст и удалить «突然/猛地/竟然»
5. Просканировать весь текст и убедиться, что нет возвышенного тона вроде «标志着/体现了»
