# Дополнение к отчёту рецензии части и тома

## Предварительные требования к отчёту

- Сначала чётко написать: из содержимого, распределённого вышестоящим уровнем этому уровню, что реализовано, что отсутствует, что лишь упомянуто формально без реализации.

## Что в отчёте нужно прописать особенно подробно

### 1. Исполнимость и разбиваемость на главы

- Может ли автор на этой основе напрямую разбить на главы
- Какие отрывки всё ещё представляют собой план-комментарий, а не исполнительный план

### 2. Ритм и стратегия хуков

- Положение малых / больших кульминаций
- Чередуются ли типы хуков
- Какие главы чаще всего «сильное начало главы, но провал в середине»
- Какого типа награды в середине рекомендуется добавить

### 3. Диагностика удержания первых пяти глав, наград в середине тома и докупки

- Образуют ли первые 5 глав непрерывную цепочку следования
- Где в середине тома находятся группы глав, которые быстрее всего остывают, и почему
- Способно ли дело-единица и самостоятельно существовать, и питать основную линию
- Оставлен ли в конце тома более дорогой новый пробел, способный подтолкнуть читателя к следующему тому

### 4. Ритм платформы и пригодность для разбиения на главы

- К какому классу платформенного готового продукта том склоняется больше и почему
- Соответствуют ли длина тома / длина главы / плотность хуков целевой платформе
- Нет ли риска «структура смотрится, но при разбиении на главы остывает»

### 5. Конкретные рекомендации по правкам

Рекомендуется формат «место вставки + патч для группы глав + ожидаемая выгода», например:

- В [некоей группе глав] добавить [награду в середине], чтобы этот отрезок не вращался вхолостую.
- Заменить [текущий хук] на [поворот / раскрытие / кризис], чтобы избежать усталости от непрерывного однотипного.
- В [списке принятого этой частью / этим томом] дописать [отсутствующие пункты распределения вышестоящего уровня] и привязать их к [соответствующей группе глав / артефакту].
- В [конце тома] добавить [более дорогой новый пробел / межтомное последствие], чтобы повысить движущую силу докупки следующего тома.
- В [первых 5 главах] добавить цепочку следования «ответ на старый вопрос + новый, более опасный вопрос», чтобы не держаться лишь на первой главе.

### 6. Количественная карточка разрыва с конкурентами (обязательно прописывать подробно)

В отчёте нельзя писать только «этот том слабее конкурентов»; по умолчанию писать в порядке единого шаблона:

1. `Свёртка пула кандидатов Топ-10`
2. Экспресс-обзор четырёхслойного глубокого разбора `3–5` основных образцов-«подавителей»
3. `统一量化卡`
4. `Сводное суждение / самый опасный отстающий пункт / позиция для первоочередного превосходства / пояснение о слепых зонах`

При этом в «единой количественной карточке» обязательно сохранить фиксированные столбцы:

- Наша текущая оценка (0–5)
- Средняя оценка конкурентов (0–5)
- Разница (мы − конкуренты)
- Ключевые доказательства
- Патч на 72 часа
- Чего не следует копировать

Основные измерения уровня тома по умолчанию квантифицируются:

- Цепочка следования за первыми 5 главами
- Плотность наград в середине тома
- Ротация типов хуков
- Сила докупки в конце тома
- Сила точек приземления торговой точки
- Эффективность питания основной линии делом-единицей

По каждому пункту нужно написать: нашу текущую оценку, среднюю оценку конкурентов, разницу, ключевые доказательства, патч на 72 часа, чего не следует копировать.

И после количественной карточки добавить:

- Общее суждение о разрыве с конкурентами: опережаем / на уровне / отстаём
- Два самых опасных отстающих пункта (`2`)
- Два измерения, где нужно превзойти в первую очередь (`2`)
- Точки блокировки / слепые зоны суждения

### 7. Правила потолка высоких оценок (обязательно указать)

- Если количественная карточка конкурентов не завершена: комплексная оценка по умолчанию не выше `7.0/10`
- Если пункт конкурентов ниже `7.0/10`: комплексная оценка по умолчанию не выше `8.4/10`
- Если пункт конкурентов ниже `6.0/10`: комплексная оценка по умолчанию не выше `7.4/10`
- Если отсутствует любой из: `пул кандидатов Топ-10`, экспресс-обзор четырёхслойного глубокого разбора `3–5` основных образцов-«подавителей» или единая количественная карточка, либо любой фиксированный столбец, модуль конкурентов считается незавершённым, комплексная оценка по умолчанию не выше `7.0/10`
- Если по трём пунктам — удержание первых 5 глав, награды в середине тома, докупка в конце тома — `2` и более пунктов заметно слабее конкурентов, нельзя писать «можно сразу пропускать в основной текст»
