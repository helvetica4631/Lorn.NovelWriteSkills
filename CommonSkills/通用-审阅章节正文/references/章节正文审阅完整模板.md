# Полный шаблон рецензии текста главы (общий каркас)

Подходит для: текста главы, главы-текста, рецензии исполнительного слоя одной главы.

## 1. Принцип разделения общего слоя и жанрового слоя (обязательно)

- Этот файл содержит только **общий каркас рецензии текста главы**, переиспользуемый между жанрами.
- Жанровые Skill обязаны на этом каркасе дописать свои «специальную проверку жанровой притягательности», «жанровые специальные пункты оценки», «акценты жанрового вывода».
- Жанровые Skill **не вправе сокращать** общий главный каркас этого шаблона, могут лишь заменять или дописывать жанровые разделы.
- Отчёт по умолчанию пишется «на слое текста главы, видимом читателю»; `## 作者有话说`, `## 章节后记`, пояснения по полировке и прочее, находящееся в том же файле, по умолчанию отдельно не выделяются как происшествия, если только не вторглись в основной текст либо пользователь не требует строго оценивать по окончательной версии.
- Выводы вида «можно публиковать / можно допускать / не рекомендуется публиковать прямо» по умолчанию относятся только к слою, видимому читателю; если в этом раунде дополнительно проверяется, можно ли исходный рабочий файл публиковать без обработки, необходимо выделить «дополнительный вывод» отдельно, нельзя смешивать с выводами о качестве текста.

## 2. Место сохранения и формат имени файла (обязательно)

- Если у произведения есть части:

`审阅意见/第X部/第Y卷/章节审阅报告_第X部_第Y卷_第Z章_[审阅日期].md`

- Если у произведения нет частей:

`审阅意见/第X卷/章节审阅报告_第X卷_第Y章_[审阅日期].md`
