## 10. Части, которые обязательно писать весомо

- Вывод о читательском опыте должен быть сформулирован короткими фразами, чётко указывая «главную награду» и «главную причину следовать»
- Если в этой главе большая доля диалога, необходимо отдельно выделить, состоятельны ли «разница голосов / лепка персонажей / связь», нельзя включать их в расплывчатую оценку слога
- Согласованность биографий — пункт проверки высокого приоритета, нельзя проходить мимо одним штрихом
- Минимальные предложения по обратной записи по возможности формулировать в виде «позиция + действие патча + ожидаемая выгода»
- Если вынесен вердикт о рассогласовании цепи, необходимо чётко написать «приоритетно возвращать какой слой», нельзя давать лишь общие рекомендации по полировке
- Модуль конкурентов по умолчанию пишется по единой матрице: `Пул кандидатов Top 10 → экспресс-обзор четырёхслойного глубокого разбора 3–5 основных образцов подавления → единая количественная карточка → сводное суждение / пояснение о потолке`; нельзя вырождаться до «перечень 1–3 конкурентов + урезанная таблица»
- Постоянные столбцы единой количественной карточки должны сохраняться: `наша текущая оценка (0–5) / среднее конкурентов (0–5) / разница (мы − конкуренты) / ключевое доказательство / 72-часовой патч / что не следует копировать`
- Нельзя записывать совместное присутствие `## 作者有话说`, `## 章节后记` и текста в одном файле как проблему «выбивания читателя»; повышать уровень обработки можно лишь тогда, когда они фактически примешались в основной текст
- По умолчанию нельзя писать «весь файл не рекомендуется публиковать напрямую», «файл не может быть опубликован напрямую» или синонимичные выводы; если пользователь явно требует оценить исходный рабочий файл на возможность публикации без обработки, необходимо выделить «дополнительный вывод» отдельно и написать, что он не перекрывает выводы о качестве текста
