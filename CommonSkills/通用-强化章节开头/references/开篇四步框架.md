# Четырёхшаговая рамка начала

> **Источник**: избранный пост зоны общения авторов Qimao №26099, редактор: 纵横年糕. Ключевая структурная формула подходит для быстрого построения начала сюжетной направленности.

## Ключевая формула: цель → действие → препятствие → разворот / успех

| Шаг | Функция | Масштабируемость |
| --- | --- | --- |
| **Запускающее событие** (установление цели) | Событие, запускающее ключевое желание главного героя (например, расторжение помолвки, истребление рода, пробуждение после перерождения). Не обязательно подавать сценой, иногда повествование эффективнее | Одно запускающее событие может двигать ключевую цель всей книги |
| **Развёртывание действия** (постановка подцелей) | Для достижения большой цели главный герой раскладывает её на несколько малых целей. **Это стадия, на которой можно писать дольше всего** — можно и дальше использовать «цель → действие → препятствие → разворот → успех» для трёхуровневой вложенности | Структура расторжения помолвки в «斗破苍穹» напрямую выдержала 334 главы |
| **Препятствие** (создание колебаний) | Главный герой не может идти гладко. Ракурсы препятствий должны быть разнообразны (убрать лестницу после подъёма на крышу, перехват ключевого ресурса, предательство отношений и т. п.) | Качество препятствия определяет амплитуду взлётов и падений истории |
| **Разворот и успех** | Использовать заложенные ранее зацепки, чтобы перевернуть ситуацию против ветра. Нужен не только сюжетный разворот, но и можно добавить разворот образа персонажа | Чем больше сопротивление, тем сильнее ощущение 爽 от разворота |

## Расширение трёхуровневой вложенностью

Четырёхшаговая рамка используется не только для скелета всей книги, но и может вкладываться. Каждая стадия малой цели сама может применять трёхуровневую структуру «цель → действие → препятствие → разворот → успех».

**Пример**: «斗破苍穹» (Битва над небесами)

```text
Уровень всей книги: расторжение помолвки (запуск) → тренировка, становление сильнее (действие) → трёхлетнее соглашение (препятствие) → победа над Нанься Яньжань в школе Юньлань (разворот)
  ↓
Уровень тома: принятие в ученики Яо Лао (запуск) → алхимия и тренировка (действие) → испытание в горах Мошоу (препятствие) → поглощение необычного пламени, успех (разворот)
  ↓
 Уровень главы: обнаружение монстра (запуск) → подготовка к бою (действие) → сила монстра превосходит ожидания (препятствие) → победа на волосок новым освоенным навыком (разворот)
```

Чем яснее цель и чем больше уровней, тем сильнее ожидание читателя. Одна ясная «цель уровня всей книги» способна поддерживать ожидание на протяжении всей книги.

## Отношение к существующим рамкам начала

Этот файл — дополнительный справочник к `通用-强化章节开头/SKILL.md` и не заменяет в этом SKILL идейные пласты вроде «трёхслойной воронки», «цепкости начала главы» и «начала-среза».

- **Трёхслойная воронка** отвечает на вопрос «почему читатель кликает» — фокус на трёх составляющих: название / аннотация / начало
- **Четырёхшаговая рамка начала** отвечает на вопрос «как писать начало» — фокус на сюжетной структуре первых глав
- **Начало-срез / правило трёх фраз** отвечает на вопрос «как писать первый экран» — фокус на способе подачи первых 300 знаков

Эти три дополняют друг друга, они не заменяют друг друга.

## Сценарии применения

| Сценарий | Рекомендация по использованию |
| --- | --- |
| Нужно быстро построить сюжетный скелет начала | Прямо использовать четырёхшаговую формулу: сначала определить цель → затем разложить действия → затем спроектировать препятствия → затем расположить развороты |
| Темп начала слишком медленный | Проверить, не слишком ли поздно появляется «запускающее событие» — в первых 300 знаках должен быть явный сигнал цели |
| Начало слишком плоское, нет подъёмов и спадов | Проверить, не слишком ли слаб дизайн «препятствия» — чем сильнее препятствие вгоняет читателя в отчаяние, тем сильнее 爽 от разворота |
| Сюжет начала слишком тонок, не хватает на написание | Использовать расширение трёхуровневой вложенностью — каждая подцель может независимо применять четырёхшаговую рамку |
