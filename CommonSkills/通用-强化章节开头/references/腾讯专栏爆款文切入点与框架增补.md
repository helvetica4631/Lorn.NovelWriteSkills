## P0. Ключевое резюме

### Формула большой рамки хита

> Чёткая линия роста + извилистая линия чувств + быстрый темп + новая точка входа (трюк начала) + новизна образа / новизна линии противоречия / новизна фона

- Достаточно реализовать **несколько пунктов** — и получится неплохое произведение; ему легче «выстрелить»
- Не нужно удовлетворять всем; учитывая собственный жанр, выбирать пункты, в которых можно лучше всего проявить себя

---

### Первое. Точка входа (трюк начала)

**Определение:** вход в начало, способный вызвать эмоции читателя (смех / грусть / гнев / страх / недоумение) и дать читателю ощущение ожидания

**Принципы выбора:**
- Выбирать из основной линии; ориентироваться на мышление «кликбейтного заголовка», в начале сначала выбросить трюк
- Хорошая точка входа должна как можно скорее выбросить краткосрочную / среднесрочную / долгосрочную цель героя
- Должна быть срочность или достаточная сила, чтобы устойчиво двигать сюжет

**Имеет срок годности:** популярные в ранний период «обижаемый» / «роман на одну ночь» и т. п. больше не хорошие точки входа, нужно идти в ногу со временем

**Типы примеров точки входа с трюком:**
- Главный герой только очнулся и обнаружил, что у него есть жена и ему наставили рога (затруднение идентичности)
- Уже первая фраза начала намекает на опасность («Мне кажется, мой парень хочет меня убить»)
- Сразу сильный сюжетный конфликт (перед всей армией стянуть штаны с второстепенной героини)
- Центр противоречия, зажатый столкновением фонов (восьмидесятые годы: внешний мир предпочитает сыновей дочерям vs своя семья балует дочь)

**Функции точки входа:**
- Ввести читателя в состояние, подготовить почву для последующей рамки
- Сделать целевой конфликт точкой ритма — **размер целевого конфликта = высота точки ритма; длина объёма, на которой происходит конфликт, = быстрота ритма**

### Второе. Три измерения повышения новизны (выбрать одно из них или сочетать)

#### Новизна образа
- Характер, идентичность, особые навыки; или «очарование» (цундере / потемнение / странные привычки)
- У главного героя есть изъян характера → противоположная сторона может его успокоить → линия чувств тоньше и узнаваемее
- Пример: главный герой чрезвычайно смел, бегает за привидениями (противоречащий шаблону образ); вечно юная прародительница спускается с горы и идёт в старшую школу (образ со смещением идентичности)
- Критерий оценки: **способен ли образ двигать развитие чувств главных героев** (анорексия + еда героини vs спать, обнимая героиню: что сильнее двигает чувства?)

#### Новизна фонового сеттинга
- Новый фон может бесконечно порождать для произведения новые события
- Пример: по всей стране никто не смеет сделать героине операцию (фон — ребёнок президента) → в начале «подавление» в подводке, у героя случаются сильные эмоциональные колебания

#### Новизна линии противоречия (ключевой механизм: создание «дисгармонии»)
- Сломать некую устоявшуюся общественную логику → читатель: «Почему так, это нелогично!» → возникает эмоциональное колебание
- Можно брать материал из выдающихся сплетен и горячих событий, после переработки использовать в сюжете
- Дисгармония = непрерывный двигатель, возбуждающий эмоции читателя; **непрерывно создавать дисгармонию — значит непрерывно возбуждать эмоции читателя**

---

### Третье. Суть ритма

- Ритм = порядок стыковки и объём блоков
- Размер целевого конфликта (сцены) → высота ритма
- Длина объёма, на которой происходит целевой конфликт → быстрота ритма
- Начало с трюком + выстроенная рамка + управление ритмом = уже неплохое произведение
