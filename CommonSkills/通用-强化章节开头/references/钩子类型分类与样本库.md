# Классификация типов хуков и библиотека образцов

> Базовая формулировка: по умолчанию Qidian (платформа не указана — та же формулировка).

## Инструкция по использованию

- Сначала определить обязанность данной главы (подача информации / эскалация конфликта / продвижение кризиса / эмоциональный поворот).
- Затем из шести классов хуков выбрать 1 класс основного хука, при необходимости наложить 1 класс вспомогательного хука.
- Смежные главы по возможности избегать непрерывного повторения хуков одного класса.

## Шесть классов хуков

### 1) Хук конфликта

**Определение**: цели персонажей прямо противоположны.

**Образец для начала главы**:

```text
«Этот дом тебе трогать нельзя.»
«С какой стати?»
```

**Образец для конца главы**:

```text
Дверь открылась, тот, кто был внутри, не уступил дорогу.
```

### 2) Хук интриги

**Определение**: выбросить естественный вопрос, но пока не отвечать на него.

**Образец для начала главы**:

```text
На двери висели три куриных пера.
```

**Образец для конца главы**:

```text
На столе появилась миска тёплой воды, никто не признался, что поставил её.
```

### 3) Хук аномалии

**Определение**: появляется деталь, противоречащая норме или правилу.

**Образец для начала главы**:

```text
Трижды спускался с горы — и трижды возвращался к одному и тому же дереву.
```

**Образец для конца главы**:

```text
Камень в кармане сам собой перевернулся на другую сторону.
```

### 4) Хук сильной эмоции

**Определение**: эмоция под высоким давлением приземляется телесной реакцией.

**Образец для начала главы**:

```text
Рука, державшая телефон, дрожала — не от страха, от злости.
```

**Образец для конца главы**:

```text
Она погасила экран, через три минуты подняла голову — взгляд стал другим.
```

### 5) Хук действия

**Определение**: действие высокого напряжения обрывается на ходу.

**Образец для начала главы**:

```text
Он нёс коромысло и бежал на заднюю гору, шаги позади становились всё ближе.
```

**Образец для конца главы**:

```text
Дверь закрывалась сама, а он не успел крикнуть.
```

### 6) Хук диалога

**Определение**: одна реплика переписывает представление читателя.

**Образец для начала главы**:

```text
«Твой дед перед смертью оставил слова: берегись людей из семьи Чжао.»
```

**Образец для конца главы**:

```text
«С самого начала ты всё знал.»
```

## Правила выбора (краткая версия)

- Глава подачи информации: в приоритете хук интриги / хук диалога.
- Глава эскалации противостояния: в приоритете хук конфликта / хук действия.
- Глава проявления правил: в приоритете хук аномалии / хук интриги.
- Глава поворота персонажа: в приоритете хук сильной эмоции / хук конфликта.

## Частые ошибки применения

- Использовать лишь вопросительный знак как хук (без носителя-события).
- Заменять хук интонацией авторского анонса (например, «в следующей главе…»).
- Хуки начала и конца главы оторваны от обязанности данной главы.

## Проверка прохождения планки

- В первых 200 знаках срабатывает как минимум 1 класс эффективного хука.
- В последних 200 знаках остаётся как минимум 1 незавершённая точка давления.
- Хук обязан опираться на один из пунктов: «действие / предмет / отношения / последствия правил».
