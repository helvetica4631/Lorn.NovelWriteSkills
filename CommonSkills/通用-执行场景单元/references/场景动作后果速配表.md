# Быстрая сопоставительная таблица «действие сцены — последствие»

## 1. Цель использования

Ценность действия не в том, что «персонаж двинулся», а в том, что «положение немедленно переписано».

Эффективное действие должно как можно скорее принести хотя бы одно из следующего:

- Проявление информации
- эскалацию риска
- Состоятельность ошибочного суждения
- напряжение отношений
- проявление правил
- Принуждение к следующему действию

## 2. Базовые принципы

### 1. Одно действие в приоритете сопровождается одним главным последствием

### 2. Последствие должно быть конкретнее действия

### 3. Последствие лучше всего изменяет следующий выбор

## 3. Частые действия → главное последствие

| Действие | Главное последствие, которое лучше всего подключить | Типичный способ приземления |
| --- | --- | --- |
| Подойти ближе | Эскалация риска | Дистанция сокращается, обнажается больше переменных |
| Протянуть руку / прикоснуться | Проявление правил | Обратная связь не соответствует ожиданию |
| Оглянуться / перепроверить | Ошибочное суждение | Нарушено суждение о направлении, объекте или времени |
| Остановиться | Информационный пробел | Временно спасает жизнь, но теряется точка контакта |
| Отступить / выйти | Напряжение отношений | Поняли неверно, стали расспрашивать, упущен момент |
| Попробовать ещё раз | Эскалация риска | Вторая обратная связь хуже или яснее |
| Сопоставить / воспроизвести заново | Вход улик | Всплывает новое расхождение в формулировках или деталь |
| Сделать скриншот / запись | Новый риск | Оставляя след, одновременно обнажаешь себя |
| Открыть дверь / толкнуть дверь | Проявление правил | Состояние двери, способ открывания, отскок — не те |
| Позвать человека / отправить сообщение | Напряжение отношений | Внешняя обратная связь не совпадает с обстановкой на месте |

## 4. Приоритетные пути после провала действия

- Провал подтверждения → информационный пробел
- Провал прощупывания → эскалация риска
- Провал сохранения улик → углубление ошибочного суждения
- Провал просьбы о помощи → напряжение отношений

Провал действия не может быть напрасным провалом, сам провал тоже должен создавать продвижение.

## 5. Критерии приёмки

Годная связь «действие — последствие» должна удовлетворять:

- У действия есть ясная цель
- Последствие приходит быстро
- Последствие способно вынудить следующее действие
- Сцена действительно движется вперёд, а не топчется на месте, встряхивая атмосферу
