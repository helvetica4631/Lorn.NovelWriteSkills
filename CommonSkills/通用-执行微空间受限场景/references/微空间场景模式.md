# Модели сцен в микропространстве

## 1. Типичные типы микропространств

- Лестничная клетка / лестничный пролёт
- Лифт / тамбур перед лифтом
- Дежурка / будка охраны / задняя часть ресепшена
- Подземный паркинг / техническое помещение
- Съёмная квартира / общая зона в коммуналке
- Больничный коридор / зона ожидания / окно выдачи лекарств
- Задняя часть офиса / чайная комната / серверная

Можно также разделить по функции на четыре класса:

- **Транзитные пространства**: лестничная клетка, лифт, паркинг, подземный переход метро, галерея-переход
- **Жилые пространства**: съёмная квартира, общая зона в коммуналке, дверь санузла, кухня, балкон
- **Профессиональные пространства**: дежурка, будка охраны, серверная, архив, служебная часть ритуальных услуг, лаборатория
- **Полупубличные пространства**: зона ожидания, окно выдачи лекарств, чёрный вход магазина у дома, перед доской объявлений района, задняя часть ресепшена управляющей компании

## 2. Рекомендуемая структура

### 1. Норма пространства

Сначала дать читателю понять, для чего это место служит в обычное время.

Как минимум нужно ответить:

- кто обычно сюда приходит
- какое действие здесь самое типичное в обычное время
- какой порядок здесь в обычное время должен стабильно существовать

### 2. Микроаномалия

Не начинать сразу с большой странности, приоритет:

- Свет загорелся со смещением по ступеням
- Дверь неплотно закрыта
- Неправильный ракурс камеры наблюдения
- Задержка звукового сигнала пропуска
- Запах, которого не должно быть, но он есть
- Положение какого-то предмета слегка изменено

Также можно выбирать первую аномалию по функции пространства:

- **Транзитное пространство**: свет загорелся со смещением по ступеням, ракурс камеры сместился, дверь выхода отскакивает ненормально, направление следа обуви не такое
- **Жилое пространство**: в кастрюле пар, но никого нет, тапочки влажные, компрессор холодильника остановился, но слышен гул, замок на двери провёрнут в обратную сторону
- **Профессиональное пространство**: в журнале регистрации появилась лишняя строка, записи пропуска с неверным временем, передача дежурства не сошлась, порядок возврата инструментов тронут
- **Полупубличное пространство**: табло вызова застыло на каком-то числе, угол бумаги на доске объявлений влажный, на стекле окна выдачи лекарств дыхательный налёт, направление следа на пластиковом стуле обратное

### 3. Действие персонажа

Заставить персонажа:

- подойти ближе / протянуть руку / обернуться / проверить / выйти / застыть

Без действия давление остаётся лишь словами об атмосфере.

Если сцену нужно сделать ближе к лицу, приоритет действиям с ощущением проверки:

- нажать ещё раз
- скриншот / прокрутить заново / сверить
- подсветить телефоном
- понюхать / потрогать / пробно сдвинуться
- пойти другим маршрутом

### 4. Последствие

Аномалия должна немедленно принести последствие:

- ошибочное суждение
- информационный разрыв
- вход улики
- эскалацию риска

Можно детализировать далее:

- **Последствия процедуры**: упущенное окно, срыв передачи, блокировка пропуска, обрыв линии
- **Последствия отношений**: принять спутника за аномалию, принять аномалию за спутника, прерванное взаимное доверие
- **Последствия правил**: первое осознание, что здесь есть запретные действия, запретное время, запретные прикосновения

## 3. Шаблоны общих моделей

### Модель A: повседневный рабочий процесс слегка прерван

`дежурство / обход здания / выдача лекарств / возвращение домой / получение посылки → какое-то звено процедуры «не так» → персонаж перепроверяет → обнаруживает, что аномалия — не неисправность → в этой сцене остаётся улика или цена`

### Модель B: ошибочное повторение в знакомом пространстве

`персонаж во второй раз проходит то же место → замечает, что предмет, число, звук или запах повторяются неправильно → персонаж сверяет и подтверждает → аномалия подтверждена → возникает новый риск`

### Модель C: сначала подтвердить норму, затем дать норме отказать

`сначала написать, как это место обычно стабильно работает → написать первое слабое отклонение → персонаж пытается восстановить норму → провал, напротив, выявляет проблему покрупнее`

### Модель D: профессиональная процедура подавляет страх, затем получает ответный удар реальности

`главный герой подавляет обстановку профессиональной процедурой → временно возвращает контроль → новая деталь доказывает, что процедура подавила лишь поверхность → в этой сцене поднимается более глубокая проблема`
