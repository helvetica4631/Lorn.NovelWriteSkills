# Чек-лист очистки мастер-рукописи для нескольких платформ

## 1. Сохранение каркаса

- [ ] Цепочка событий цела
- [ ] Цель и цена персонажа целы
- [ ] Изменение отношений цело
- [ ] Правила и ключевые точки улик целы
- [ ] Захват начала главы, награда в середине, хук в конце главы на месте

## 2. Базовая устойчивость

- [ ] Ключевые факты ясны и не двусмысленны?
- [ ] У ключевых улик / ключевых точек правил есть носитель, действие, сопротивление?
- [ ] Время, номера, отношения персонажей устойчивы и пригодны для повторного использования?

## 3. Давление на персонажа

- [ ] Достаточно ли конкретно, чего главный герой в этой главе спешит достичь, чего боится, что может потерять?
- [ ] Противник или сопротивление — не чистая абстракция, а нечто с реальным порогом и формулировкой?

## 4. Эффект очистки

- [ ] Одноплатформенная «полость» снизилась
- [ ] Групп предложений, повторно компенсирующих ту же информацию, стало меньше
- [ ] Объясняющей оболочки стало меньше
- [ ] Текст лучше подходит для дальнейшего расхождения между платформами

## 5. Пространство для дифференциации

- [ ] Ясно ли, какие слои позже можно безопасно менять под платформу?
- [ ] Не заперта ли нынешняя мастер-рукопись в «полости» одной платформы?
- [ ] Не стёрта ли она до слишком нейтрального белого текста?

## 6. Дисциплина первоисточника

- [ ] Действительно ли обрабатываемый объект — исходная мастер-рукопись?
- [ ] Не правили ли мастер-рукопись по платформенной версии, из-за чего формулировки смешались?
- [ ] Лежит ли очищенная мастер-рукопись в `提纯母稿/`, а не в `小说正文/`?
- [ ] После очистки по-прежнему ли она годится как вышестоящий исходник многоплатформенного процесса?

## 7. Красные линии

- [ ] Ключевой сюжет не удалён
- [ ] Ключевые улики или границы правил не удалены
- [ ] Текст не очищен до безвкусной белой основы
- [ ] Очищенная мастер-рукопись не оказалась в папке `小说正文/`
- [ ] Заодно не превращена в финал какой-либо платформы
