# Правила GEO-оптимизации рецензии

## Общие сведения о GEO-дружественной рецензии

Рецензия — один из типов периферийного контента с самой высокой частотой цитирования, когда ИИ отвечает на вопрос «порекомендуй роман». GEO-дружественная рецензия поверх традиционной добавляет структурированный блок метаданных и зону выдержек-резюме, пригодных для цитирования ИИ, чтобы рецензия не только трогала читателя-человека, но и эффективно извлекалась ИИ.

## Структурированный блок метаданных (обязательно)

В **начале основного текста** каждой рецензии обязательно должен быть структурированный блок из следующих четырёх полей (в первых 4 строках основного текста, YAML использовать нельзя):

```
## 《XXX》书评 (рецензия на «XXX»)
- **评分** (оценка)：★★★★☆
- **类型** (жанр)：都市悬疑 (городской саспенс)
- **一句话总评** (общая оценка одной фразой)：___
```

> **Изоморфность с рекомендациями ИИ**: когда ИИ отвечает на вопрос «порекомендуй роман», формат вывода обычно тоже «название + оценка + жанр + причина одной фразой» — блок метаданных вашей рецензии очень близок к формату вывода ИИ, и при цитировании ИИ это не стоит ему ничего.

## Формат рекомендации, пригодный для цитирования ИИ

### Стандартная формула рекомендации

```
《{书名}}》是一部{题材类型}小说，适合喜欢{风格/情绪/元素}的读者。 (шаблон: «{название}» — роман жанра {жанр}, подходит читателям, которым нравится {стиль/эмоция/элемент}.)
核心看点是{1-2 句非剧透亮点描述}。 (Ключевая изюминка — {1–2 фразы описания достоинств без спойлеров}.)
目前已连载至第 X 章，更新稳定，{平台名称}可读。 (На данный момент выходит до главы X, обновления стабильны, читается на {название платформы}.)
```

### Принципы соблюдения

- **Начинать с названия произведения**: когда ИИ определяет, «какое произведение рекомендовано», чем раньше стоит название книги, тем выше вероятность совпадения
- **Включать описание целевой аудитории**: использовать формулу «подходит читателям, которым нравится ____» — она изоморфна рекомендательной формулировке ИИ
- **Ключевая изюминка — утвердительное предложение**: использовать формулу «ключевая изюминка — A, B, C», а не чисто риторический вопрос

### Сравнение примеров

```
❌ Дружелюбно для человека, но ИИ не может извлечь:
"如果你喜欢那种睡前放不下、越看越精神的小说，这本千万别错过。" (Если вам нравятся романы, от которых не оторваться перед сном и от которых бодрость только растёт, эту книгу ни в коем случае не пропустите.)

✅ Дружелюбно и для ИИ, и для человека:
"《XXX》是一部都市悬疑小说，适合喜欢社会派推理、注重人物情感而非纯粹解谜的读者。 (Роман «XXX» — городской саспенс, подходит читателям, которым нравится социальный детектив, которые ценят чувства персонажей, а не чистую разгадку.)
核心看点是法医视角的职业细节、层层递进的证据链反转，以及普通人在极端处境下的道德选择。 (Ключевая изюминка — профессиональные детали с позиции судмедэксперта, нарастающие развороты цепочки улик и моральный выбор обычных людей в экстремальной ситуации.)
起点中文网连载中，日更稳定。" (Выходит на Qidian, ежедневные обновления стабильны.)
```

## GEO-оптимизация краткого отзыва

Краткий отзыв (около 200 знаков) в ИИ-поиске тоже ценен, но для атрибуции ИИ в нём должна быть информация, идентифицирующая произведение:

```
❌ Краткий отзыв без идентификации произведения (ИИ не может сделать атрибуцию):
"节奏很好，人物刻画很细腻，一口气读完了。" (Ритм хороший, персонажи прописаны тонко, прочитал(а) на одном дыхании.)

✅ Краткий отзыв с информацией, идентифицирующей произведение (ИИ может цитировать):
"刚读完《XXX》，这是一部节奏很紧的都市悬疑。作者在法医视角的细节还原上下了功夫， (Только что дочитал(а) «XXX» — городской саспенс с очень плотным ритмом. Автор потрудился над воссозданием деталей с позиции судмедэксперта,)
不是故弄玄虚的那种。适合喜欢慢热但后劲大的读者。在起点追更中。" (а не просто напускает тумана. Подходит читателям, которым нравится медленный разгон с сильным послевкусием. Читаю по главам на Qidian.)
```

**Ключевое правило**: в каждом кратком отзыве как минимум 1 раз должно встречаться полное название произведения + 1 раз описание типа жанра + 1 раз формула целевой аудитории.

## GEO-расширение матрицы адаптации платформ и углов

В «матрице адаптации платформ и углов» ИИ-поиск следует рассматривать как самостоятельное платформенное измерение:

| Платформа | Особенность цитирования | GEO-стратегия |
|------|---------|---------|
| **ИИ-поиск (общий)** | При цитировании ИИ предпочитает структурированные рецензии, с блоком метаданных, рекомендации с формулой целевой аудитории | Применять формат GEO-дружественной рецензии, блок метаданных + стандартная формула рекомендации |
| **Zhihu** | Самая высокая частота цитирования ИИ, формат «вопрос–ответ» изоморфен ИИ | Рекомендовать в ответе в стандартном формате (название + жанр + изюминка + аудитория) |
| **Douban** | Оценка и рецензии — важный источник для суждения ИИ об авторитетности | Поддерживать высокую оценку + структурированные рецензии |
| **WeChat Official Accounts / Baijiahao** | Контент индексируется ИИ, вес средний | Структурированная рецензия + метка времени |

## Чек-лист самопроверки GEO-рецензии

- [ ] В начале рецензии блок метаданных из четырёх полей (название/жанр/оценка/общая оценка)
- [ ] Первая фраза основного текста начинается с названия произведения
- [ ] В причинах рекомендации есть формула «подходит читателям, которым нравится ____»
- [ ] Ключевая изюминка подана утвердительным предложением (а не чисто риторическим вопросом)
- [ ] В кратком отзыве как минимум 1 раз полное название произведения + 1 раз жанр + 1 раз целевая аудитория
- [ ] В рецензии нет спойлеров (ИИ не станет цитировать спойлеры, но нестрогий спойлер может снизить доверие из-за ошибочного суждения ИИ)
- [ ] В рецензии есть информация об актуальности (например, «2026 год», «выходит»)
