# Ограничения сохранения рецензии в файл и сдачи

## Формат входа

Пользователь может указать:

- Тип рецензии: вся книга / часть / том / глава
- Заголовок соответствующего диапазона (например: название части, название тома, номер главы и заголовок)
- Целевая платформа (необязательно, по умолчанию Qidian)
- Угол письма (необязательно, по умолчанию комплексный угол)
- Краткое пояснение творческого замысла, основного конфликта, линий персонажей, тематических меток и т. п. для этого диапазона (необязательно)

## Соглашение о месте хранения файла

Рабочий каталог по умолчанию фиксирован: `书评/`.

### Рецензии на всю книгу, часть, том

Хранятся единообразно прямо в корне рабочего каталога `书评/`.

Имя файла должно содержать следующие пять частей:

1. Диапазон / заголовок
2. Платформенная адаптация
3. Фокус угла
4. Дата написания
5. Суффикс `.md`

Формат даты единообразно `YYYY-MM-DD`.

Для платформенной адаптации и фокуса угла рекомендуется использовать краткие, стабильные, читаемые названия, например:

- Платформа: `起点`, `番茄`, `百家号`, `七猫`, `知乎盐选`, `豆瓣`, `小红书`, `微博`, `B站`, `MyFiction`, `WebNovel`
- Угол: `综合` (комплексный), `设定` (настройки), `节奏` (ритм), `人物` (персонажи), `氛围` (атмосфера), `议题` (тематика), `情绪` (эмоции), `口碑` (репутация)

Пример пути:

- `书评/全书书评_起点_综合_2025-12-08.md`
- `书评/全书书评_百家号_口碑_2025-12-08.md`
- `书评/第1部·日常裂缝_起点_节奏_2025-12-08.md`
- `书评/第1卷·消失的门禁记录_知乎盐选_议题_2025-12-08.md`
- `书评/第1卷·消失的门禁记录_小红书_情绪_2025-12-08.md`

### Рецензия на главу

Хранятся по структуре романа: если у произведения есть части — в `书评/第X部/第Y卷/`; если частей нет — в `书评/第X卷/`.

Имя файла должно содержать следующие пять частей:

1. Номер главы и заголовок
2. Платформенная адаптация
3. Фокус угла
4. Дата написания
5. Суффикс `.md`

Формат даты единообразно `YYYY-MM-DD`.

Пример пути:

- `书评/第1部/第1卷/1.1.1 半夜有人刷了我家门禁_起点_综合_2025-12-11.md`
- `书评/第1部/第1卷/1.1.1 半夜有人刷了我家门禁_B站_情绪_2025-12-11.md`
- `书评/第1卷/1.1 半夜有人刷了我家门禁_起点_综合_2025-12-11.md`
- `书评/第1卷/1.1 半夜有人刷了我家门禁_B站_情绪_2025-12-11.md`

## Формат сдачи по умолчанию

- Сначала 1–2 фразами указать «какой тип рецензии + соответствующий диапазон + целевая платформа + угол письма».
- Затем дать заголовок, начинающийся с метки `#` с одним пробелом после метки.
- Затем основной текст.
- Затем добавить раздел `# 短评`.

## Стратегия записи обратно и версий

- По умолчанию сохранять независимым файлом.
- Если пользователь не сказал, перезаписывать ли старую версию, по умолчанию консервативно добавлять новую версию, не перезаписывая прямо старый черновик.
- В диалоге как минимум указать: в какой файл записано, какое именование использовано, перезапись или добавление.
- Только если пользователь явно сказал «только набросать, не трогать файлы», допускается не сохранять в файл.

## Минимальная самопроверка

Перед сохранением в файл как минимум подтвердить следующие четыре пункта:

1. Заголовок использует формат заголовка первого уровня Markdown.
2. После основного текста добавлен `# 短评`.
3. В имени файла отражены платформа, угол и дата.
4. Рецензия не превратилась из-за сжатия в краткое содержание сюжета или пояснение со спойлерами.
