# Группа шаблонов рекомендательных рецензий по платформам

## Рекомендательный шаблон для Qidian

- Сначала написать зацепку для чтения по главам
- Затем написать зацепку главного героя / удовольствие от правил / долгий хук
- В конце подчеркнуть «подходит читателям, любящим читать по главам»

## Рекомендательный шаблон для Fanqie

- Сначала написать самую прямую точку, которая «затягивает»
- Затем написать телесное ощущение «не оторваться» и непрерывную стимуляцию
- В конце подчеркнуть «легко читается на одном дыхании»

## Рекомендательный шаблон для Douban

- Сначала написать сцену или ощущение персонажа с самым сильным послевкусием
- Затем написать реальную фактуру, правдоподобие разворотов, сложность человеческой природы
- В конце подчеркнуть «после закрытия книги будешь думать очень долго»

## Рекомендательный шаблон для Zhihu

- Сначала бросить опасный вопрос
- Затем написать, как система / отношения / реальная дилемма затягивают этот вопрос
- В конце подчеркнуть «стоит обсуждать»

## Рекомендательный шаблон для WeChat Official Accounts

- Сначала дать срез, пригодный для распространения
- Затем дать 2–3 детали, способные зацепить человека
- В конце дать лёгкий интерактивный стимул читать по главам

## Рекомендательный шаблон для Zongheng

- Сначала написать правдоподобие реального входа и аномальных улик
- Затем написать трение процедур, цену человеческой природы и послевкусие долгой загадки
- В конце подчеркнуть «не нагромождением разворотов, а тем, что чем дальше копаешь, тем глубже, чем дальше читаешь, тем устойчивее»

## Рекомендательный шаблон для издательства

- Сначала написать ценность чтения и уникальный характер
- Затем написать толщину персонажей, завершённость структуры, долгое послевкусие
- В конце подчеркнуть читабельность при перечитывании и послевкусие

## Рекомендательный шаблон для зарубежных платформ

- Сначала наглядно написать аномалию, профессию или основной конфликт
- Затем написать цену персонажей, конфликт отношений и продвижение событий
- В конце подчеркнуть binge-read / next-click / emotional payoff
