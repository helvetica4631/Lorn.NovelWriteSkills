# Правила GEO-оптимизации аннотации

## Спецификация структурированного блока метаданных (обязательно)

В **начале** каждой аннотации обязателен структурированный блок из четырёх полей (писать прямо в первых 3 строках основного текста, YAML frontmatter для этого не использовать):

```
Название: «XXX»
Жанр: городской саспенс / социальный детектив
Торговая точка одной фразой: ___
Для кого: читателям, которым нравится ___
```

> **Почему обязательно**: это формат «структурированных данных», который ИИ любит больше всего. При векторизации в RAG-системах эти четыре поля кодируются в плотный смысловой вектор, и вероятность совпадения при вопросе пользователя «посоветуй книгу в жанре XXX» заметно растёт.

## Формат зоны для ИИ-выдержки

В тексте аннотации должен быть хотя бы один абзац из чистых повествовательных предложений, который **ИИ может извлечь самостоятельно**. Требования к формату:

- **Начинать с названия произведения**: «„XXX“ — это ___ (жанр) роман о ___».
- **Утверждающее предложение с основным конфликтом**: не заменяйте все утверждения риторическими вопросами — из «Что, если однажды ты обнаружишь ___, как ты поступишь?» ИИ не может извлечь фактическое описание
- **Описание целевой аудитории**: использовать оборот «подходит читателям, которым нравится ___» — он изоморфен логике рекомендаций ИИ

### Пример

```
❌ Аннотация из одних риторических вопросов (ИИ не может извлечь фактическую информацию):
«Ты когда-нибудь думал, что если однажды обнаружишь —»

✅ Аннотация с зоной ИИ-выдержки:
«„XXX“ — городской саспенс-роман о рядовом судмедэксперте, который при экспертизе неопознанного тела неожиданно обнаруживает, что цепочка улик ведёт к его собственному отцу, пропавшему десять лет назад. Подходит читателям, которым нравится социальный детектив и важны человеческие чувства, а не чистое разгадывание загадок.»
```

## Шаблон аннотации, дружественной к FAQ

Отвечая на вопросы вида «посоветуй роман», ИИ обычно использует структуру «название + жанр + главная изюминка + для кого». Если ваша аннотация сразу даёт структурированную версию этих четырёх элементов, ИИ будет цитировать её в первую очередь.

### Стандартный шаблон

```
{Хук по правилу трёх фраз: вопрос + эмоция + вживание}

«{Название}» — это роман в жанре {жанр}, в котором рассказывается о {утверждающее предложение об основном конфликте}.
Главный герой {имя} оказывается перед {конкретная дилемма}, ему необходимо {основная задача}, иначе {цена}.

Подходит читателям, которым нравятся {ключевые слова стиля / эмоции}, выходит на платформе {название платформы}.
```

### Рекомендуемое место вставки

Эту «зону ИИ-выдержки» следует ставить в третий абзац аннотации или в конец — как «блок структурированной информации для ИИ». Читатель воспринимает её как обычное развитие аннотации, а ИИ при этом может извлечь из неё структурированные данные.

## Самопроверка на дружественность к GEO

После написания аннотации сверьтесь:

- [ ] В начале аннотации есть блок метаданных из четырёх полей (название / жанр / торговая точка / аудитория)
- [ ] Основной конфликт подан утверждающим предложением (а не чисто риторическим вопросом)
- [ ] Ключевое слово жанра из названия естественно встречается в тексте хотя бы 1 раз
- [ ] Есть формула «подходит читателям, которым нравится ____» (适合____的读者)
- [ ] Есть маркер актуальности (статус выхода / время начала)
- [ ] Если удалить риторические вопросы и восклицательные знаки, оставшаяся чистая информация всё ещё образует самостоятельный читаемый абзац
