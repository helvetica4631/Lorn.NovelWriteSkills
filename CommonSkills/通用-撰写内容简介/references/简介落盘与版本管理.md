# Сохранение аннотации в файл и управление версиями

## Аннотации обязательно сохраняются по уровням в отдельные файлы

По умолчанию для каждого из следующих уровней должен быть свой отдельный файл:

- Аннотация ко всей серии / ко всей книге
- Аннотация к части / к тому
- Аннотация к главе

Если существуют файлы «общей библиотеки / сборника / библиотеки черновиков для нескольких платформ», по умолчанию они выполняют только роль:

- Индекс
- Каталог версий
- Ссылки и инструкции по использованию

В них больше не хранится полный текст аннотации к какому-либо тому / главе.

## Рекомендации по рабочему каталогу и именам файлов по умолчанию

- Рабочий каталог по умолчанию фиксирован: `小说简介/`.
- Вся серия / вся книга: `小说简介/《目标投放名》- 系列全书内容简介_vYYYY-MM-DD-rN.md`
- Аннотация к части: `小说简介/第XX部《目标投放名》- 内容简介_vYYYY-MM-DD-rN.md`
- Аннотация к тому: `小说简介/第XX卷《目标投放名》- 内容简介_vYYYY-MM-DD-rN.md`
- Аннотация к главе:
  - С частями: `小说简介/第X部/第Y卷/{章节号与标题}_章节简介_vYYYY-MM-DD-rN.md`
  - Без частей: `小说简介/第X卷/{章节号与标题}_章节简介_vYYYY-MM-DD-rN.md`

Если в проекте уже есть принятая система именования, она имеет приоритет.

## Правила согласования названия (обязательно)

- Если в имени файла, заголовке версии или основном тексте нужно название произведения, везде используется целевое название для публикации текущего объекта поставки.
- Роман без частей: используется целевое название романа для публикации.
- Роман по частям: во всех аннотациях к частям, томам, главам и их платформенных вариантах везде используется целевое название соответствующей части; нельзя перекрывать название части общим названием книги.
- Если в этот раз явно поставляется общая аннотация ко всему произведению, можно использовать целевое название самого произведения целиком, но оно должно быть согласовано внутри всей версии.

## Стратегия перезаписи / дозаписи

- Пользователь явно требует «перезаписать текущую аннотацию» → заменить старую версию в соответствующем отдельном файле
- Пользователь явно требует «начать новую версию / сохранить старую версию» → дописать раздел с датой и меткой версии
- Пользователь ничего не уточнил → по умолчанию консервативная дозапись: сохранить исходный текст и добавить «версия, созданная в этом раунде (YYYY-MM-DD)»

## Минимальная квитанция со стороны диалога

Как минимум сообщить:

- Какие версии записаны в этом раунде
- В какой файл записано
- Перезапись или дозапись
- Синхронно ли записан результат Rubric / самопроверки

## Исключение: только черновик без сохранения

Только когда пользователь явно говорит «только набросать, файлы не трогать», разрешается не сохранять в файл.
