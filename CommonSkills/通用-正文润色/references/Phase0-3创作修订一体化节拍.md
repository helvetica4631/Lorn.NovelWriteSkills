# Единый ритм Phase 0–3: творчество и правка

> Рамка источников: `经验总结.md` (итоги опыта, улучшенный процесс) + `修订体系.md` (система правок, партии A/B/C).

## Обзор четырёх фаз

```text
Phase 0 Сеттинг и планирование → Phase 1 Написание черновика → Phase 2 Три партии правок → Phase 3 Итоговая проверка и вывод
```

## Phase 0 (сеттинг и планирование)

- Завершить общий план (мироустройство / персонажи / главная линия).
- Завершить цели томов и уровни конфликтов.
- Планирование по главам одновременно писать: хук начала, хук-оставление в конце главы, позиции точек 爽, позиции предзнаменований.

## Phase 1 (написание черновика)

- Двигаться по плану глав, не полировать чрезмерно на стадии черновика.
- Написал главу — зарегистрировал предзнаменования главы.
- Каждые 5 глав быстро просматривать: число знаков, доля диалога, хуки в первых и последних 200 знаках.
- При затыке допускается продвигаться с заглушками, чтобы не останавливался весь проект.

## Phase 2 (три партии правок)

### Партия A: персонажи / хуки / диалог

- Цель покрытия хуком первых 200 знаков: 100%.
- Цель покрытия хуком-оставлением последних 200 знаков: 90%+.
- Целевая доля диалога: 25%–55%.
- У второстепенных персонажей должна быть самостоятельная мотивация, нельзя превращать их в функции.

### Партия B: предзнаменования / золотой палец / сокращение

- Перечень предзнаменований полон и отслеживаем.
- У золотого пальца есть «рост + триггер + цена».
- Поясняющие абзацы в 200 знаков подряд обязательно разбивать.
- Частые избыточные слова, звукоподражания, повторяющиеся образы обрабатывать контролем частоты.

### Партия C: «вебновеллизация» / перекличка реквизита / стиль

- Тип хука конца главы определён чётко (интрига / выбор / кризис).
- Ключевой реквизит образует сквозную межглавную арку переклички.
- Убирать метаповествование и ИИ-универсальные конструкции.
- Единый стандарт именования одного и того же понятия.

## Phase 3 (итоговая проверка и вывод)

- Сквозное прочтение (особое внимание началам, концам и узлам смены томов).
- Итоговая проверка предзнаменований: чтобы не было пропусков и ложных развязок.
- Унификация формата (знаки препинания, разбивка на абзацы, вёрстка).
- Вывод финальной версии и сохранение записи рецензирования.

## Правила стыковки с шлифовкой основного текста

- `通用-正文润色` по умолчанию работает между Phase 2 и Phase 3.
- Если обнаружены структурные проблемы (нет хука / нет награды / оборвана цепь предзнаменований), нужно записать обратно выше по цепочке, нельзя ограничиваться фразовой полировкой.
- Если проблема относится к ошибке порядка фаз (например, проблема партии C решается в партии A), сначала исправить партию, затем шлифовать.

## Принцип исполнения одной фразой

Сначала исправить «о чём рассказывать», затем довести «как рассказывать»; сначала пройти шлюзы, затем гнаться за слогом.
