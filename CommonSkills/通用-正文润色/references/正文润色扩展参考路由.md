# Расширенная маршрутизация справок по шлифовке основного текста

Этот файл единообразно собирает общую маршрутизацию слабых мест шлифовки основного текста, чтобы жанровые Skill не вели параллельно каждый свой одинаковый набор отображений симптомов.

## Принципы использования

- Сначала прочитать общий процесс, контрольный список, общий вердикт
- Затем определить, в какую категорию в основном попадает слабое место этого раза
- Одновременно можно попасть в несколько категорий, не нужно насильно выбирать лишь одну
- Если на жанровом слое есть собственные особые границы, общие способы правки подчиняются жанровому вердикту
- После попадания в какую-либо категорию в первую очередь продолжать читать соответствующий одноимённый расширенный справочный файл в этом каталоге, а не откатываться искать параллельную копию в каталоге жанра

## Когда в приоритете языковой тип

При следующих проблемах текста в первую очередь править по языковому типу:

- Реплики слишком полные, слишком правильные, как зачитывание
- Все говорят на один вкус
- В диалоге информация есть, но нет искры
- Персонаж умеет лишь «говорить выводы», не умеет «обнаруживать интонацию»

Если проблема уже ясно сводится к тому, что «диалог не справляется с созданием образа / связи / продвижения», параллельно ссылаться на:

- `..\..\通用-执行对话冲突\references\对话冲突结构与潜台词规则.md`
- `..\..\通用-执行对话冲突\references\高压对话中的秘密交换与关系翻面.md`

В первую очередь добавить следующие три пункта:

- **Различие голосов**: после удаления пометок всё ещё можно примерно понять, кто говорит
- **Создание образа**: реплика обнаруживает уязвимую точку, слабость, профессиональный инстинкт или старую рану персонажа
- **Связь**: в диалоге есть хотя бы один вход для читателя — отождествление / сочувствие / симпатия / любопытство

Продолжить чтение: `语言写作指导与好词好句好段.md`

### Типичная обработка языкового типа

- Сократить фразы
- Добавить паузы, поправки, перехват реплик, давление словом, уклонение
- Пусть статус, близость, эмоция влияют на интонацию

## Когда в приоритете тип действия

- Весь большой абзац говорит «что сделано», но процесса нет
- Конфликт есть, но читатель не видит, как движется человек
- Только пустые глаголы вроде «смотреть, идти, думать»

Продолжить чтение: `行动写作指导与好词好句好段.md`

### Типичная обработка типа действия

- Добавить ключевые узлы действий
- Выверить порядок действий
- Нести суждение и эмоцию через действие

## Когда в приоритете психологический тип

- В оригинале часто используется «ему очень грустно / ей очень тревожно / он в ярости»
- У эмоции есть имя, но нет близости к телу
- Читатель знает, о чём думает персонаж, но не чувствует

Продолжить чтение: `心理写作指导与好词好句好段.md`

### Типичная обработка психологического типа

- Вернуть эмоцию в дыхание, жесты, ошибочные суждения, уклонение, монолог
- Реже прямо называть, больше косвенно изображать реакцию

## Когда в приоритете портретный тип

- Главные персонажи после появления всё ещё трудно различимы
- Внешность — лишь пустые слова вроде «высокий / красивый / худой»
- Реакции мимики слишком одинаковы

Продолжить чтение: `肖像写作指导与好词好句好段.md`

### Типичная обработка портретного типа

- Найти одну-две локальные черты, на которые можно ссылаться
- Вписать профессию, возраст, усталость в лицо и осанку

## Когда в приоритете тип пейзажа

- Сцена похожа на съёмочный павильон, а не на реальное пространство
- Погода написана, но атмосфера не вошла в положение персонажа
- Главе нужно создать ощущение давления, холода, духоты или пустоты, а носитель недостаточен

Продолжить чтение: `景物写作指导与好词好句好段.md`

### Типичная обработка типа пейзажа

- Пусть звук, свет, запах, осязание участвуют в повествовании
- Пусть пейзаж служит конфликту, а не самостоятельной лирике

## Когда в приоритете статический тип

- Комната, архив, утварь, улики, стол, коридор написаны как инвентаризация
- Статические предметы хотя и важны, но нет повествовательного давления

Продолжить чтение: `静态写作指导与好词好句好段.md`

### Типичная обработка статического типа

- Сначала общий контур, затем ухватить самую полезную часть
- Писать только предметы, влияющие на суждение, действие или эмоцию персонажа

## Когда в приоритете тип сцены

- Многолюдное противостояние, обыск, погоня, толпа зевак, собрание, хаос на месте без иерархии
- Читатель знает лишь «много людей», но не чувствует фокуса

Продолжить чтение: `场面写作指导与好词好句好段.md`

### Типичная обработка типа сцены

- Сначала задать атмосферу всей сцены
- Затем ухватить одного-двух ключевых персонажей / точки действия
- Затем вернуться к общему звуковому фону, изменению порядка, давлению

## Рекомендуемые сочетания

### По положению абзаца

- Окостенение начала главы: пейзаж + действие
- Проседание середины: действие + психология + сцена
- Побледнение персонажей: язык + портрет + психология
- Пустота конца главы: действие + психология, при необходимости немного пейзажа для завершения

### По сочетанию слабых мест

- Диалог + проблема эмоций: сначала исправить сбой в диалоге, затем телесные эмоции
- Диалог + побледнение персонажей: сначала добавить различие голосов, затем уязвимые точки персонажа / слабости / цену
- Действие + проблема конфликта: сначала исправить цепочку действий, затем точку приземления награды
- Пространство + проблема атмосферы: сначала добавить функциональные детали пространства, затем «ненормальные стежки»
- Побледнение персонажей само по себе: сначала добавить голос персонажа, затем профессиональные / бытовые следы

## Напоминание о вызове

- Эти расширенные справки — библиотека приёмов «читать по необходимости», а не обязательные для сплошного прочтения при каждой шлифовке.
- Основной упор при заимствовании — углы наблюдения, синтаксические действия, организация чувств и опоры описания, а не выписывание «хороших слов, хороших фраз, хороших абзацев».
- Если один отрывок попадает сразу в несколько категорий, обычно достаточно прочитать 1–2 наиболее подходящих файла.

## Итоговый принцип

Все расширенные способы правки служат тому, чтобы:

- Не терять информацию
- Не ломать структуру
- Не терять жанровые рамки
- Читателю хотелось читать дальше
