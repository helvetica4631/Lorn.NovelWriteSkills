# Стратегия поиска по читательским инсайтам

## Сценарии применения

- Исследование читателей / рынка: читательские предпочтения, привычки оплаты, сценарии чтения, причины отказа от книги
- Исследование трендов жанра: миграция читательских вкусов, эволюция популярных элементов
- Исследование экосистемы платформы: различия портретов читателей разных платформ
- Исследование писательской техники: выводить эффективные приёмы из читательской обратной связи

## Приоритет источников информации

### Первый приоритет: читательская обратная связь внутри платформы

- **Комментарии к главам / к абзацам (本章说/段评) Qidian**: мгновенная реакция читателей по абзацам / предложениям — самые реальные и самые детальные данные об эмоциях читателей. Способ поиска: открыть страницу пробного чтения произведения, посмотреть популярные комментарии к абзацам
- **Круг друзей по книге / раздел отзывов Qidian**: обсуждения читателей на уровне главы / произведения
- **Книжные подборки Qidian**: рекомендательные списки, собранные самими читателями, по ним видно, как читатели классифицируют произведения
- **Комментарии бесплатных платформ Fanqie / Qimao и др.**: особенности обратной связи бесплатных читателей

### Второй приоритет: обсуждения читателей в социальных платформах

- **Zhihu**: `{作品名} 怎么样`, `{题材} 推荐`, `网文 书荒 推荐` (как произведение / рекомендации по жанру / «книжный голод», рекомендации веб-романов) — различать настоящие читательские рекомендации и маркетинговую рекламу
- **Xiaohongshu**: впечатления читателей / посты-«эй, читайте» — в основном взгляд женщин-читательниц
- **Супертемы Weibo**: обсуждения для фанатов — можно наблюдать, на что обращают внимание ключевые читатели
- **Tieba**: обсуждения читателей в баре произведения, в баре веб-романов
- **Douban**: рецензии, читательские заметки — склонность к литературным оценкам

### Третий приоритет: отраслевой/медиа анализ

- **Отраслевые медиа по веб-литературе**: аналитические статьи о читательских трендах
- **Отчёты с данными**: годовые отчёты о чтении, портреты читателей, публикуемые платформами
- **Научные статьи**: научные результаты исследований читателей интернет-литературы

### Четвёртый приоритет: косвенные сигналы

- **Тренды поисковых систем**: Baidu Index, WeChat Index — показывают тренд общественного внимания к жанру / произведению
- **Платформы электронной коммерции**: продажи и отзывы на бумажные книги / аудиокниги — другая группа читателей
- **Зарубежные читатели**: обратная связь зарубежных читателей на WebNovel / GoodNovel

## Стратегия поиска

1. Обратная связь на уровне произведения: `{作品名} 书评 | {作品名} 好看吗 | {作品名} 剧透` (отзыв / стоит ли читать / спойлеры)
2. Предпочтения на уровне жанра: `{题材} 推荐 书单 | {题材} 最好看 | {题材} 书荒` (рекомендации / подборки / лучшее / «книжный голод»)
3. Анализ отказа от книги: `{题材} 看不下去 | 网文 踩雷 | 小说 弃文 原因` (невозможно читать / «наступить на грабли» / причины отказа)
4. Сравнительные обсуждения: `{作品A} vs {作品B} | {题材} 天花板` (потолок жанра)
5. Ощущение трендов: `2025 网文 读者 喜欢 | 2026 网文 流行` (что нравится читателям / что популярно)

## Перевод ценности для романиста

Результаты поиска необходимо переводить в выводы, пригодные для творца, а не останавливаться на «что нравится читателям»:
- **Положительные предпочтения → переносимое проектирование**: «читателям нравится дизайн XX в некоем произведении» → «каков механизм за этим? можно ли добиться такого же рода удовлетворения другими настройками?»
- **Отрицательная обратная связь → список ловушек**: «читатели ненавидят XX» → «в чём глубинная причина? это проблема исполнения или настроек?»
- **Спорные точки → творческий выбор**: «у читателей разногласия по XX» → «это риск или возможность? как отсеять нецелевых читателей уже в начале?»

## Требования к качеству

- Различать «высокочастотную общую обратную связь» и «единичные крайние оценки» — не реагировать чрезмерно на один яростный отрицательный отзыв
- Различать «обратную связь платных читателей» и «обратную связь бесплатных читателей» — причины отказа платных читателей справочно ценнее
- Помнить о «постфактум-рационализации» читательской обратной связи — названная читателем причина отказа может не быть реальной причиной отказа
- Для обратной связи из единственной платформы / сообщества проводить межплатформенную перекрёстную проверку
- Помечать актуальность и размер выборки информации
