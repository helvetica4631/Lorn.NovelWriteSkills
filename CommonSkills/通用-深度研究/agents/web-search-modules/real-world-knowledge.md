# Стратегия поиска знаний реального мира

## Сценарии применения

- Исследование профессиональных знаний: реальные детали профессии, технологии, процедуры, научного принципа
- Исследование сцены / среды: особенности реальных мест, эпох, зданий, городского пространства
- Исследование прототипов персонажей: реальное поведение, речь, психологические особенности определённой группы людей
- Исследование настроек истории: вымышленные настройки, которым нужна опора на реальные знания

## Приоритет источников информации

### Первый приоритет: профессиональные первичные материалы

- **Официальные сайты государственных органов / учреждений**: тексты законов и нормативных актов, стандарты профессиональной квалификации, описания административных процедур
- **Отраслевые ассоциации / научные сообщества**: отраслевые «белые книги», технические стандарты, научные статьи
- **Профессиональные медиа**: глубокие репортажи и портретные очерки вертикальных отраслевых медиа
- **Документальные фильмы / документальные произведения**: систематические записи о конкретных профессиях, сценах, событиях

### Второй приоритет: рассказы очевидцев

- **Zhihu / Douban**: реальные рассказы о конкретных профессиях и опыте (нужно отбирать ответы с высокой достоверностью)
- **Bilibili / подкасты**: влоги профессионального опыта, раскрытие отрасли, интервью с очевидцами
- **Автобиографии / мемуары**: записи личного опыта определённых групп людей
- **Портретные очерки в новостных репортажах**: глубокие описания людей определённых профессий

### Третий приоритет: научные исследования

- **CNKI (知网) / Wanfang (万方)**: научные исследования социологии, антропологии, криминологии конкретных групп людей / сцен
- **Google Scholar / Semantic Scholar**: англоязычные научные статьи
- **Диссертации**: обычно содержат более подробные полевые исследования и первичные данные
- **Baidu Scholar (百度学术)**: дополнительный источник китайских статей

### Четвёртый приоритет: сводные энциклопедии/руководства

- **Wikipedia / Baidu Baike**: каркас базовых знаний (только для вхождения, не полагаться)
- **Профессиональные справочники / учебники**: учебные материалы профессиональных навыков, отраслевые руководства по эксплуатации
- **Открытые государственные данные**: демографическая статистика, экономические данные, географическая информация

## Стратегия поиска

1. Структурированный поиск: `{职业} 工作流程 | {职业} 日常 | {职业} 术语` (профессия: рабочий процесс / будни / термины)
2. Поиск деталей: `{场景} 细节 描述 | {地点} 环境 特征` (сцена: описание деталей / место: особенности среды)
3. Поиск процедур: `{程序} 步骤 | {程序} 流程 | {程序} 规定` (процедура: шаги / процесс / правила)
4. Поиск очевидцев: `{职业} 真实经历 | 我是一名{职业}` (реальный опыт / «я — ...»)
5. Научный поиск: `{关键词} site:cnki.net | {keyword} site:scholar.google.com`

## Особая ценность для романиста

Результаты этого поиска должны служить настройкам истории, описанию сцен, лепке персонажей или проектированию сюжета романа. При поиске в первую очередь собирать:
- **Пригодные для повествования детали**: не абстрактные понятия, а конкретные действия / сцены / диалоги, которые можно прямо показать в тексте
- **Цепочку процедуры**: полную цепочку шагов профессии / процедуры и места, где на каждом шаге можно ошибиться
- **Термины и жаргон**: язык, который реально используют практики
- **Цену и трение**: узкие места процедуры, типичные ошибки, серые зоны, этические дилеммы
- **Сенсорные детали**: звук, запах, осязание, свет, температура и другая пригодная для письма сенсорная информация

## Требования к качеству

- Различать «официальный процесс» и «реальное исполнение» (между ними часто есть разрыв, и сам разрыв — хороший материал)
- Помечать пространственно-временные координаты информации (практики в разных местах, годах, отраслях могут различаться)
- В первую очередь собирать цепочки причин «почему так», а не только статическое описание «что это»
- Неопределённую информацию о праве / процедурах обязательно помечать, нельзя давать автору ошибочные «факты»
