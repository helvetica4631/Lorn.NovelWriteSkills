# Стратегия поиска по писательским сообществам

## Сценарии применения

- Исследование писательской техники: методология творчества, обсуждение приёмов, обмен опытом
- Исследование трендов жанра: творческие тенденции авторских групп, обсуждения популярных тем
- Исследование экосистемы платформы: репутация платформ среди авторов, опыт подписания, рассказы о доходах
- Читательские инсайты: анализ читательской обратной связи с авторской точки зрения

## Приоритет источников информации

### Первый приоритет: китайские писательские сообщества

- **Форум «Небо дракона» (龙的天空论坛, Longkong)**: самое плотное сообщество авторов веб-романов, охватывает обсуждение творческой техники, отраслевые новости, оценки платформ, анализ читательской обратной связи. Пример ключевых слов для поиска: `site:lkong.com {技法关键词}` (ключевые слова техники)
- **Zhihu**: качественные обсуждения в темах по написанию веб-романов. Пример ключевых слов для поиска: `site:zhihu.com 网文 {技法} | site:zhihu.com 小说创作 {话题}` (веб-роман, техника / творчество романа, тема)
- **Писательские группы Douban**: обсуждения в различных группах по письму

### Второй приоритет: профессиональные творческие платформы

- **Сообщество помощника писателя (作家助手)** (официальное Qidian): официальная зона обсуждений подписанных авторов Qidian
- **Помощник автора Fanqie**: авторское сообщество платформы Fanqie
- **Авторские форумы платформ / открытые группы**: публично видимые обсуждения авторов

### Третий приоритет: международные писательские сообщества

- **Reddit**: писательские субфорумы r/writing, r/fantasywriters, r/selfpublish и др.
- **Форум NaNoWriMo**: международное сообщество Месяца написания романа
- **Kboards / Writer's Cafe**: сообщества независимых авторов
- **Absolute Write Water Cooler**: универсальный писательский форум

### Четвёртый приоритет: общие сообщества создателей контента

- **Bilibili**: видео о творческих приёмах, UP-мастера отраслевого анализа
- **Jike / Sspai**: обмен и обсуждения создателей
- **Супертемы Weibo**: обсуждения тем, связанных с письмом

## Стратегия поиска

1. Точный поиск: `site:{домен сообщества} {ключевое слово}`
2. Тематический поиск: `{技法} 写作 技巧 | {平台} 签约 经验` (техника, письмо, приёмы / платформа, подписание, опыт)
3. Поиск трендов: `2025 2026 网文 {话题} 趋势` (веб-роман, тема, тренд)
4. Поиск кейсов: `{作品名} 拆解 | {作品名} 为什么火` (разбор / почему стало популярным)

## Требования к качеству

- Различать «обмен авторским опытом» и «субъективные оценки читателей» — первое ценнее для творческого исследования
- Помнить об ошибке выжившего в постах сообщества (успешные охотнее делятся)
- Помечать форум / уровень пользователя источника информации (начинающий автор vs зрелый автор vs взгляд редактора)
- Снижать вес анонимных / малодостоверных источников
