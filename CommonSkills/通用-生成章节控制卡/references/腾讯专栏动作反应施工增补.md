## Новые поля контрольной карточки (P0)

Каждая контрольная карточка главы по умолчанию получает два новых пункта:

1. `动作-反应链 (цепочка «действие — реакция»)`: как минимум два удара
   - Первый удар: действие (создаёт дисбаланс) -> реакция (сомнение / подавление / шок)
   - Второй удар: действие (контратака / продвижение) -> реакция (удар по лицу / выгода / изменение ситуации)
2. `不平衡设计说明`
   - За счёт какой информационной, статусной или сценической разницы в этой главе нарушается баланс
   - Как после нарушения возвращается новый этапный баланс и порождается следующий удар

## Жёсткие требования к строительству главы (P0)

1. В любом небольшом сюжете внутри главы должны быть «действие + реакция»; отсутствие любого из них считается холостым ходом.
2. Действие должно влиять хотя бы на одну из тем основной линии героя (репутация, статус, богатство, отношения, цель).
3. Реакция должна быть видимой, а не просто «самолюбованием» во внутреннем мире героя.
4. Награда в середине главы должна быть записана как «видимое читателю изменение», запрещается писать абстрактное продвижение.

## Запреты контрольной карточки (P1)

1. Запрещено считать «подготовку» медленным повествованием без цели; подготовка обязана поднимать ожидания.
2. Запрещено считать «завязку» (伏笔) украшением; завязка должна быть привязана к окну развязки (回收).
3. Запрещено подряд несколько сцен-моноспектаклей «герой действует, но никто не реагирует».
4. Запрещено ограничиваться перечислением сюжета без описания эмоциональной функции каждого удара.

## Чек-лист самопроверки (перед сдачей контрольной карточки)

- [ ] Прописана ли цепочка «действие — реакция» из двух ударов?
- [ ] Определён ли источник дисбаланса этой главы?
- [ ] Видима, измерима и пересказуема ли награда в середине?
- [ ] Развязывает или продвигает ли эта глава хотя бы одну существующую линию?
