# Контроль доступа шага 2: четыре такта основного текста и ротация хуков

> Место применения: проверка сразу после выполнения шага 2 (`通用-创建小说正文`) в `通用-章节创作闭环`.

## Цель

Поднять «дописали главу» до «дописали и прошли контроль ритма».

## Контроль четырёх тактов (одна глава)

```text
Хук (первые 200) → накопление (давление в середине) → награда (реализация в середине) → оставленный хук (последние 200)
```

### Критерии прохождения

- Первые 200 знаков: как минимум 1 действенный хук (конфликт / интрига / аномалия / действие / диалог).
- Середина: как минимум 1 ощутимая награда (отношения, положение, информация, действие или идентичность — что-то одно).
- Последние 200 знаков: есть незамкнутая точка давления, нельзя подменять её тоном анонса.

### Проверка провала из-за непрерывных внутренних сегментов (новое)

**Определение проблемы**: после сильного хука в начале подряд идут три и более сегментов «внутренней обработки» (внутренний монолог / обратный ход памяти / упорядочивание информации / переваривание эмоций), между которыми нет внешних прерываний (диалог / действие / смена среды / вмешательство третьей стороны). После пощёчины / конфликта читателя оставляют в голове героя и возвращают в текущую сцену только в конце главы. Динамика начала постепенно спускается.

**Метод обнаружения**:
- [ ] После первого внешнего действия в начале главы есть ли ≥3 подряд чисто внутренних абзацев (без диалога, без действия, без вмешательства третьей стороны)?
- [ ] Если да, составляет ли общее число знаков этих чисто внутренних абзацев ≥800?
- [ ] Есть ли между внутренними сегментами внешние прерывания (вошедший новый человек, внезапный звук, давление, на которое нужно ответить сейчас)?

**Типичный отрицательный пример**:
```
Пощёчина (внешний конфликт) → узнаёт госпожу Се и Мин-чжу (внешнее → информация) →
упорядочивание основной линии оригинальной книги (чисто внутреннее) →
воспоминание о шестнадцатилетней истории отравления (чисто внутреннее) →
список известного / неизвестного (чисто внутреннее) →
«Я не умру за тебя» (внутренняя решимость) →
нянюшка Ван приносит лампу (внешнее снова появляется)
```
— посередине подряд три сегмента внутренней обработки, более 1000 знаков без внешних событий. Уже на втором внутреннем сегменте читатель чувствует «сколько можно думать».

**Способ расчистки**:
1. **Вырезать**: целиком убрать самый тяжёлый сегмент накачки информацией (например, введение в основную линию всей книги), перенести в последующие главы с естественным раскрытием
2. **Прервать**: между внутренними сегментами вставить микровнешнюю угрозу (приближающиеся шаги / тень в щели двери / вдали кто-то зовёт её по имени), вынуждающую героя прервать размышления и вернуться в текущую сцену
3. **Сжать + фрагментировать**: большой плавный кусок воспоминаний разбить на 2–3 фрагмента и вплести между разными внешними действиями, чтобы читатель, следя за историей, сам собирал информацию, а не получал всё залпом

## Контроль ротации хуков (между главами)

- Нельзя использовать хуки одного типа 3 главы подряд.
- Если 2 главы подряд использовали хуки одного типа, 3-я глава обязана принудительно сменить тип.

Рекомендуемая ротация:

```text
хук-интрига → хук-конфликт → хук-аномалия → хук-действие → хук-диалог → хук-интрига...
```

## Поля записи в журнал (обязательно)

В каждой главе записывать как минимум:

- `HookType`: тип хука главы
- `MidPayoff`: фраза награды в середине главы (на которую можно сослаться)
- `TailDriver`: вопрос-эстафета в конце главы
- `RotationCheck`: нет ли повторяющейся перегрузки относительно двух предыдущих глав (Yes/No)
- `GatePass`: пройден ли контроль четырёх тактов (Pass/Fail)

## Обработка провала

- `GatePass=Fail`: нельзя переходить к итоговой рецензии; сначала нужно вернуться к шагу 2 или к специализированному патчу (начало / конец главы / награда в середине).
- `RotationCheck=Yes`: в контрольной карточке следующей главы обязательно предусмотреть хук другого типа и пометить как высокоприоритетный.
