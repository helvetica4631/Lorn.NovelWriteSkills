# Шаблон самопроверки сборки и шаблон матрицы рисков

Подходит для авторской внутренней сверки согласованности и отсутствующих файлов пакета для подачи; **нельзя использовать как материал для редактора и нельзя выносить суждения вместо редактора.**

Рекомендации:

- На общем слое по умолчанию записывать этот шаблон в авторский внутренний файл `05_组包自检.md`.
- Если на жанровом слое есть специальный шаблон, нужно накладывать жанровый арбитраж поверх этого шаблона, не удаляя само тело матрицы рисков.
- В этом шаблоне запрещены предложения вроде `当前最强一环` («текущее сильнейшее звено»), `当前最弱一环` («текущее слабейшее звено»), `当前结论` («текущий вывод»), `建议现在投稿 / 内投` («рекомендуется подавать сейчас»), `编辑会喜欢` («редактору понравится»), `可以直接进入编辑内投` («можно прямо подавать редактору») и другие суждения вместо редактора.

## Пояснение к использованию уровней риска

- `P0`: блокирует формальную сборку, в принципе сначала вернуть на доработку.
- `P1`: заметно снижает вероятность прохождения подачи, можно делать предварительную версию, но формальную подачу не рекомендуется.
- `P2`: пункты для оптимизации, не обязательно блокируют, но влияют на готовность редактора продолжать оценку.
