## P0. Ключевое резюме

### Технические нормы подачи по e-mail (консенсус нескольких редакторов)

#### Объём основного текста

- **10–30 тыс. знаков** — оптимально (консенсус нескольких редакторов)
- Нижняя граница: около 10 тыс. знаков, то есть появление золотого пальца + первое небольшое событие
- Верхняя граница: для произведений с особенно медленным ритмом можно больше, но обычно не более 30 тыс. знаков
- Формат: достаточно, чтобы редактор получил представление об основной манере письма книги

#### Формат документа

- Формат: **Word / WPS** (не TXT)
- Шрифт: **Songti размера 4–5**, аккуратная вёрстка, **без цветного фона, без вычурных шрифтов**
- Структура документа: рекомендуется два вложения (одно — основной текст, другое — план) либо один объединённый документ с чёткой разметкой каждой главы
- Названия документов: прямо **названием книги** (например, «Основной текст ХХХ», «План ХХХ»)

#### Формат темы письма

- Рекомендуемый формат: **название книги + имя автора** (иногда можно добавить намерение продажи: гарантированный выкуп / долевое)
- Ни в коем случае не писать только слово «подача»; хорошее название книги уже в теме подачи оставляет у редактора первое впечатление

#### Требования к плану

- План обязателен (отсутствие плана — одна из главных мучительных проблем редакторов)
- Тип плана: **предварительный замысел сюжета**, а не план-аннотация
- Запрещено писать: `Как он будет справляться? Какое у него будет будущее?` (вопросительный план)
- Запрещено писать: `Основная линия — перепады чувств героя и героини` + далее «будет определено» (план без содержимого)
- Нужно писать: для детективов — ясно указать улики, основания, концовку; для других жанров — объяснить направление сюжета первых томов и изюминки

#### Сопутствующая информация

- В начале документа указать: **название книги + категория + аннотация + прошлые достижения автора** (опытным авторам с прошлыми достижениями обязательно)
- Рекомендуется указать предполагаемый объём к завершению
- Если есть ранее подписанные произведения, можно приложить адрес страницы книги для подтверждения идентичности

#### Дисциплина подачи

- **Ни в коем случае не подавать одну рукопись многим** (редакторы видят друг друга)
- **Ни в коем случае не рассылать всем сразу** (непрофессиональный сигнал)
- После подачи редактор обычно отвечает на e-mail в течение 7 дней
- Добавляя редактора в QQ после прохождения: в примечании писать **название книги + время прохождения**, нельзя писать только «подача»
