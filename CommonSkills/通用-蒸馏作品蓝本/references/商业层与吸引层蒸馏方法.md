# Методы дистилляции коммерческого слоя и слоя привлечения

> Источник: SKILL.md §«Обзор методов дистилляции коммерческого слоя (новое)» + §«Обзор методов дистилляции слоя привлечения»

## Методы дистилляции коммерческого слоя

### Извлечение плотности эмоциональных стимулов и отпечатка точек удовлетворения и мучения

**Статистика точек удовлетворения**
- Пройти по главам образца и отметить количество и типы «точек удовлетворения» в каждой главе (пощёчина / ответный удар / повышение уровня / информационное превосходство / прорыв в отношениях и т. п.)
- Рассчитать: среднее число точек удовлетворения на главу, распределение типов точек удовлетворения, интервал между точками удовлетворения (одна средняя точка каждые N глав)
- Записать номера глав и механизм запуска «больших точек удовлетворения» (кульминаций уровня тома) образца
- Отметить соотношение удовлетворение : мучение (статистика по сегментам томов)

**Статистика точек мучения** (обязательно для женской эмоциональной линии)
- Пройти по главам образца и отметить количество и типы «точек мучения» (преданность / недоразумение / ущерб / замещение и т. п.)
- Рассчитать: среднее число знаков на одну точку мучения, распределение типов точек мучения, зоны сгущения точек мучения
- Записать режим «точка удовлетворения внутри мучения»

**Интервал между точками эмоциональных стимулов**
- Рассчитать средний интервал между точками эмоциональных стимулов по всему произведению
- Отметить, есть ли в образце «зоны потери тепла» вида «N глав подряд без стимулов»

**Ротация типов стимулов**
- Отметить, чередуются ли типы стимулов в последовательных главах
- Записать типичный режим ротации образца (например 5-главный цикл «мучение → удовлетворение → разгадка → чувства → мучение»)

### Извлечение доли диалогов и отпечатка скорости ритма

- По главам оценить долю диалогов (строки диалогов / все строки), отметить среднее значение и диапазон колебаний
- По типам сцен подсчитать различия доли диалогов: кульминационные главы vs переходные главы vs главы о чувствах vs главы разгадки
- Отнести каждую главу образца к шаблону ритма (завязка–развитие–поворот–удовлетворение / американские горки / нарастание раскрытия информации)

### Количественный разбор золотых трёх глав (усилено)
- Появляются ли в первых 300 знаках первой главы сигналы конфликта / аномалии / давления
- Показан ли золотой палец / основная способность в первых 1000 знаках первой главы
- Оценочное значение доли диалогов в первых трёх главах
- Тип и сила хука в конце первой главы
- Оценка полноты «завязка–развитие–поворот–удовлетворение» в первых трёх главах

### Извлечение отпечатка адаптации под платформу

| Наблюдаемый пункт | Сигнал предпочтения Qidian | Сигнал предпочтения Qimao | Сигнал предпочтения Fanqie |
| --- | --- | --- | --- |
| Число знаков в главе | 2000–3000 знаков | 2500–4000 знаков | 2000–3500 знаков |
| Среднее доли диалогов | ≥35 % | ≥40 % | ≥45 % |
| Эмоциональная плотность первых трёх глав | Допускается 2–3 главы накопления | Высокая плотность, стимул на каждые 500 знаков | Самые сильные торговые точки выкладываются все |

### Выявление точек риска потери тепла
- Пройти по образцу, отметить диапазоны глав, где «легче всего теряются читатели»
- Проанализировать, что образец сделал в этих точках риска потери тепла, чтобы не потерять читателя
- Записать режимы таких «пожарных мер»

### Оценка воспроизводимости обновлений

| Сигнал | Тип «легко пакетировать» (ежедневные выпуски 6000+) | Тип «трудно поддерживать» (ежедневные выпуски менее 3000) |
| --- | --- | --- |
| Основной способ продвижения | В основном диалоги + продвижение событиями | В основном среда + психология + литературные красоты |
| Доля сцен высокой интенсивности | ≥40 % глав — плотные диалоги / конфликтные сцены | ≤20 % глав — сцены высокой интенсивности |
| Закономерности структуры глав | Есть явный повторно используемый шаблон ритма | Структуру каждой главы нужно придумывать заново |

### Итог коммерческой структурной ДНК одной фразой

```markdown
[Коммерческая структурная ДНК]
Режим эмоциональных стимулов:
- Основное удовлетворение: [одной фразой]
- Соотношение удовлетворение : мучение: [например «начало 3:7 / середина 5:5 / конец 7:3»]
- Интервал эмоциональных пиков: [в среднем раз в N глав]
- Стратегия доли диалогов: [например «среднее 45 %, в кульминационных главах снижается до 30 %»]

Дизайн инженерии удержания:
- Цепочка дочитывания первых 3 глав: [завершены ли три такта «конфликт → столкновение с преградой → эскалация»]
- Окно золотого пальца в первых 1000 знаках: [дано ли ожидание награды в пределах 1000 знаков]
- Тип хука в конце главы: [например «тип новой угрозы 40 %, тип эмоциональной бомбы 30 %»]

Адаптация под платформу:
- Основная платформа успеха: [название платформы]
- Атрибуция ритма платформе: [насколько успех образца зависит от особенностей платформы]
- Межплатформенная переносимость: [высокая/средняя/низкая]

Воспроизводимость обновлений:
- Оценка сложности письма: [легко/средне/сложно]
- Оценка среднесуточного числа знаков: [X] знаков/день
- Основной шаблон ритма: [завязка–развитие–поворот–удовлетворение / американские горки / другое]
```

## Методы дистилляции слоя привлечения

### Извлечение стратегии названия
- Найти названия, под которыми образец опубликован на разных платформах
- Сопоставить с названиями конкурентов той же дорожки и определить точки дифференциации стратегии названия
- По пунктам записать по рамке оценки `通用-设计标题`

### Извлечение аннотации
- Собрать оригинальные тексты аннотаций образца на разных платформах
- По стандарту «метода трёх предложений / принципа среза / сути сделки» из `通用-撰写内容简介` оценить источники цепкости аннотации

> **Запись видимости GEO (новое)**: при дистилляции слоя привлечения дополнительно записать, как образец проявляется в ИИ-поиске.

### Извлечение первой главы начала
- Разобрать по предложениям первые 300 знаков первой главы, оценить по «методу трёх предложений»
- Записать первый вопрос, положение первого конфликта, положение выхода золотого пальца, рычаг персонажа

### Извлечение заголовков глав по главам
- Пройти по заголовкам глав образца, классифицировать и подсчитать по шести типам стратегий
- Отметить закономерности ротации стратегий и участки подряд одной стратегии
