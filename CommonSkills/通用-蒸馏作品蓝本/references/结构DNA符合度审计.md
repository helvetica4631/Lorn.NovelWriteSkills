# Аудит соответствия структурной ДНК

> Источник: SKILL.md §«Аудит соответствия структурной ДНК (новое)»

## Момент аудита

Если и только если:
1. В текущем проекте уже есть **шаблон образца произведения**, прошедший проверку качества Phase 4
2. Нижестоящий Skill уже выдал готовый продукт для сравнения (общий план + планы томов ≥ 10 глав или ≥ 5 глав основного текста подряд)
3. Пользователь явно требует аудит

## Измерения аудита

### A. Измерения аудита на уровне плана

| Измерение | Базис сравнения (шаблон образца) | Способ расчёта расхождения |
| --- | --- | --- |
| Распределение функциональных позиций | §9 Плотность функциональных позиций глав | Дивергенция JS; предел подряд ≤ значения, указанного в образце |
| Интервал кульминаций / «вспышек» | §4 Распределение ритма сцен + §3 Отпечаток награды в середине | Расхождение среднего ≤ ±1 глава; расхождение стандартного отклонения ≤ ±30 % |
| Перенос ритма между томами | §12 Перенос ритма между томами | Расхождение значений ключевых измерений по стадиям ≤ ±20 % |
| Планирование появлений персонажей | §11 Такты появления персонажей | Расхождение среднего интервала ≤ ±20 % |
| Ритм выпуска информации | §7 Ритм выпуска информации | Расхождение среднего ≤ ±1 глава |

**Веса уровня плана**: функциональные позиции 25 %, интервал кульминаций 25 %, перенос между томами 20 %, появление персонажей 15 %, выпуск информации 15 %

### B. Измерения аудита на уровне основного текста

| Измерение | Базис сравнения (шаблон образца) | Способ расчёта расхождения |
| --- | --- | --- |
| Режим начала главы | §1 Отпечаток режимов начала главы | Дивергенция JS |
| Хук в конце главы | §2 Отпечаток хуков в конце главы | Дивергенция JS + отклонение периода ротации ≤ ±1 глава |
| Награда в середине | §3 Отпечаток награды в середине | Расхождение интервала наград ≤ ±1 глава |
| Такты «сцена — продолжение сцены» | §10 Такты «сцена — продолжение сцены» | Расхождение доли эскалации конфликта ≤ ±15 % |
| Плотность диалогов | §6 Распределение плотности диалогов | Расхождение среднего ≤ ±10 % |
| Смена POV | §5 Закономерности смены POV | Дивергенция JS |
| Появление персонажей | §11 Такты появления персонажей | Расхождение среднего интервала ≤ ±20 % |

**Веса уровня основного текста**: начало главы 15 %, хук в конце главы 20 %, награда в середине 20 %, сцена—продолжение 15 %, диалоги 10 %, POV 10 %, появление персонажей 10 %

## Расчёт комплексного соответствия

```text
Комплексное соответствие = Σ(оценка измерения × вес измерения) / Σ(вес измерения)
Оценка по измерению: пройдено = 100; при непрохождении линейно отображается на 0–100 по пропорции отклонения
```

## Градация соответствия

| Комплексное соответствие | Уровень | Смысл | Пропускать ли |
| --- | --- | --- | --- |
| ≥ 90 % | Уровень S | Структурная ДНК в высокой степени совпадает | ✅ Пропуск |
| 80 %–89 % | Уровень A | Основные структурные отпечатки совпадают | ✅ Пропуск |
| 70 %–79 % | Уровень B | Частичные измерения заметно отклоняются | ⚠️ Пропуск с обязательным исправлением |
| 60 %–69 % | Уровень C | Многие измерения значительно отклоняются | ❌ Доработка |
| < 60 % | Уровень D | Структурная ДНК не совпадает | ❌ Возврат на этап дистилляции |

## Формат отчёта аудита

Результат аудита записывается в `风格审计/作品蓝本/[作品名]/blueprint_audit_[审计对象]_YYYY-MM-DD.md`.

Полный шаблон отчёта включает: метаинформацию аудита, таблицу сопоставления по измерениям, сравнение измеренных и базовых значений по каждому измерению, комплексное соответствие и уровень, приоритетные пункты исправления.
