# Определение формата шаблона исследования письма

> Источник: SKILL.md § «Формат результата»
> Этот файл определяет формат результата `通用-蒸馏写作研究`. Нижестоящие Skill потребляют результат в этом формате.

---

## Выходной файл

По завершении дистилляции выходной файл записывается в корневой каталог целевого проекта:

```text
蒸馏产物/写作研究模板/[题材名]-[平台名]-写作研究模板.md
```

Правила имени файла: `[题材名]` (название жанра) извлекается из заголовка отчёта (например «异能志怪», «都市悬疑»), `[平台名]` (название платформы) извлекается из заголовка отчёта (например «番茄», «起点»). Если один шаблон объединяет несколько отчётов (например, одновременно дистиллированы исследования Fanqie и Qidian), в названии платформы пишется «综合» (комплексный).

Если источник дистилляции — указанный URL, название жанра/платформы выводится из содержимого отчёта исследования.

## Формат регистрации в Agents.md

В `Agents.md` в корневом каталоге целевого проекта добавить запись регистрации (если `Agents.md` не существует — создать):

```markdown
### 写作研究模板 (шаблон исследования письма)
- 名称 (название)：[题材名]-[平台名]
- 路径 (путь)：蒸馏产物/写作研究模板/[题材名]-[平台名]-写作研究模板.md
- 蒸馏日期 (дата дистилляции)：YYYY-MM-DD
- 素材来源 (источники материала)：[N] шт. (отчёты исследований/отчёты разведки/страницы сетевого поиска)
- 提取约束数 (число извлечённых ограничений)：[N] (письмо [N] + структура [N] + персонажи [N] + запреты [N])
- 适用平台 (применимые платформы)：[番茄 / 起点 / 七猫 / ...] или 默认 (по умолчанию)
```

Значения `适用平台` (применимые платформы):

- `默认`: платформа не ограничена, универсально для всех платформ
- Конкретное название платформы (например `番茄`, `起点`, `知乎`, `豆瓣` и т. п.): шаблон извлечён специально для указанной платформы
- Несколько названий платформ (например `番茄，起点`): шаблон объединяет исследования нескольких платформ, применим к перечисленным платформам

### Логика регистрации платформы (обязательно выполнять)

- Если при дистилляции отчёт естественно указывает на какую-то платформу (например «исследование番茄小说...»), `适用平台` автоматически записывается как соответствующее название платформы
- Если при дистилляции отчёт — комплексное межплатформенное исследование, `适用平台` записывается как `默认` или список платформ, указанный пользователем
- Если в `Agents.md` целевого проекта нет поля `主输出平台` (основная выходная платформа), но платформа, записываемая в этом раунде, ясна и регистрируется впервые, рекомендовать пользователю указать основную выходную платформу (необязательно, не принудительно)
