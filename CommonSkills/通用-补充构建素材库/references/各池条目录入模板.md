# Шаблоны ввода записей для каждого пула

> Этот файл содержит шаблоны ввода записей и примеры заполнения для каждого пула материалов.
> Перед занесением каждой записи в библиотеку нужно сверить полноту полей по этому шаблону.

---

## Шаблон записи пула 01_情节桥段池 (пул сюжетных эпизодов)

### Шаблон сюжетного пула

```markdown
### [номер] [заголовок]
- **Количество знаков**：[число]–[число] знаков
- **Эмоциональный якорь**：[основное слово эмоции]
- **Краткое содержание**：[1–3 абзаца с описанием полного контура сюжета]
- **Логика проектирования**：[почему этот эпизод эффективен] (необязательно, но рекомендуется)
- **Подходящая лицевая сторона истории**：[код лицевой стороны истории] (необязательно, но рекомендуется)
```

### Пример сюжетного пула (из A_职场商战桥段.md)

```markdown
### A01-03 Тактика молчания в ценовых переговорах
- **Количество знаков**：2000–4000 знаков
- **Эмоциональный якорь**：психологическая война
- **Краткое содержание**：Соперник называет цену, превышающую нижнюю границу, Су Тан не отвечает, берёт стакан и пьёт воду. Соперник добавляет условие, она всё равно молчит. Соперник начинает нервничать: «Что вам кажется неподходящим?» Она ставит стакан: «Я жду, пока вы назовёте цену, о которой действительно можно говорить».
- **Логика проектирования**：Молчание — самое сильное оружие переговоров: пусть соперник не выдержит первым
```

### Пример настроек персонажа

```markdown
### C01 Сдержанный босс-президент

- **Ключевое противоречие**：Крайне жаждет быть понятым, но по привычке всё держит в себе
- **Контрастные детали**：① на собрании акционеров излучает ауру, дома разговаривает с котом; ② подписывая контракт на десятки миллионов, не дрогнет рукой, но сообщение ей удаляет три раза
- **Особенности голоса**：по делу — короткие командные фразы; в частной обстановке невольно замедляет речь и понижает голос
- **Арка роста**：от изолированного «я сам всё решу» → к растущему «ты мне нужна»
```

## Шаблон записи разбора конкурентов

> Черновики разбора конкурентов — **не** прямые записи материалов. Повторно используемые эпизоды/приёмы/афоризмы, извлечённые из разбора, после очистки нужно отнести в соответствующие пулы материалов 01-05.
> Этот шаблон нужен лишь для записи черновиков анализа в каталоге разбора конкурентов.

### Шаблон

```markdown
### [номер] [название произведения] [описание извлечённого отрывка]
- **Отрывок оригинала**：[отобранный фрагмент оригинала]
- **Разбор**：[какой приём использовал автор, почему этот отрывок цепляет, что можно позаимствовать]
- **Подходящая сцена**：[для какого типа сюжета/сцены можно повторно использовать этот отрывок]
```

### Пример

```markdown
### J01 «Фэн-цзун S1» (《封总S1》) Цепь удержания на первых трёх главах
- **Отрывок оригинала**：（содержание отобранных первых трёх глав）
- **Разбор**：① в первых 500 знаках первой главы заложены три крючка интриги (загадка личности + конфликт + эмоциональное напряжение); ② концовка каждой главы — пик эмоций, не оставляет читателю передышки; ③ в каждой из первых пяти глав есть по маленькой точке удовлетворения
- **Подходящая сцена**：проектирование ритма начала в жанре «президентской» новеллы/«погони за женой в огне»
```

## Шаблон записи новых пулов жанра (06+ / пользовательская нумерация)

> Когда жанру нужно создать пулы за пределами общей системы 01-05, используется следующий шаблон.
> Нумерация пулов продолжается с 06, название пула — произвольное.

### Универсальный шаблон нового пула

```markdown
### [номер] [заголовок]
- **Количество знаков**：[число]–[число] знаков
- **Эмоциональный якорь**：[основное слово эмоции]
- **Краткое содержание**：[1–3 абзаца с описанием полного контура записи]
- **Ключевой механизм**：[ключевой принцип проектирования/техническая логика/пространственная структура записи]
- **Зацепка для письма**：[элементы описания/цепочка действий/сенсорные детали, которые автор может конкретно использовать при письме]
```

### Различия полей по типам новых пулов

| --- | --- | --- | --- |
| Архив настроек истории | 06 | **Ключевой механизм**, **Границы и цена**, **Способ подтверждения уликами** | Как записать технический принцип в повествование, какие ограничения, как показать уликами |
| Библиотека пространственных сцен | 06/07 | **Сенсорный перечень**, **Норма пространства и микроаномалия** | Визуальные/слуховые/обонятельные детали пространства и то «не так», что нарушает норму |
| Библиотека приёмов-трюков | 06/07 | **Логика приёма**, **Необходимые условия**, **Лазейка/способ разгадки** | Полный замысел детективного трюка и его разгадываемость |
| Библиотека настроек способностей | 06 | **Правила способности**, **Цена/перезарядка**, **Путь эволюции** | Конкретный эффект, ограничения и рост сверхспособностей/магии |
| Библиотека имплантов | 06/07 | **Часть тела**, **Функция**, **Последствия/риск** | Технические параметры киберимплантов и человеческая цена |

### Пример нового пула: архив настроек истории (06_故事设定档案库)

```markdown
### 06-01 Ограничение «ненаблюдаемости» прыжкового двигателя
- **Количество знаков**：2000–3000 знаков
- **Эмоциональный якорь**：технический трепет + саспенс
- **Краткое содержание**：Пока прыжковый двигатель работает, корабль находится в состоянии «ненаблюдаемости» — никакие датчики не могут его отследить. Но это означает, что каждый прыжок корабля — прыжок веры: ты не знаешь, безопасна ли точка выхода, потому что в процессе перехода нельзя ощутить изменения снаружи.
- **Ключевой механизм**：Во время прыжка корабль полностью выходит из текущего пространства-времени и лишь по достижении заданных координат появляется снова. В этот период невозможно принимать или посылать никакие сигналы.
- **Границы и цена**：① каждый прыжок потребляет много энергии, подряд не более 3 прыжков; ② ошибка координат растёт с расстоянием (0,1 парсека ошибки на сто световых лет); ③ если при выходе координаты заняты, последствия необратимы.
- **Способ подтверждения уликами**：кривая энергии в журнале прыжков, индикатор «ненаблюдаемости» на мостике, отчёт о калибровке координат после прыжка.
- **Зацепка для письма**：обратный отсчёт перед прыжком — молчание на мостике — все смотрят на пустой экран — миг выхода, пронзительный сигнал о столкновении (если на точке выхода кого-то поджидают).
```

### Пример нового пула: библиотека пространственных сцен (07_星舰场景库)

```markdown
### 07-01 Мостик — пересечение власти и информации
- **Количество знаков**：500–1500 знаков
- **Эмоциональный якорь**：давление + ощущение порядка
- **Краткое содержание**：Мостик — центр всего корабля: кресло капитана на верхнем ярусе, ниже три оператора — тактика/навигация/связь. Изогнутый главный экран в реальном времени показывает звёздную карту и данные датчиков. Освещение приглушённое, лишь свет экранов и индикаторов кнопок. В воздухе лёгкий запах озона (тепло электроники).
- **Сенсорный перечень**：① зрение — в полумраке холодный синий свет экранов, непрерывно обновляющиеся потоки данных; ② слух — низкочастотное гудение оборудования, щелчки клавиатуры, сжатая речь в каналах связи; ③ обоняние — озон + поток воздуха из кондиционера + изредка запах кофе; ④ осязание — холодный металл поверхности пульта, давление спинки кресла при ускорении.
- **Норма пространства**：упорядоченная занятость — каждый знает своё место и обязанности.
- **Микроаномалия**：① тактический пост вдруг затих (он увидел то, чего не должно быть); ② запах озона внезапно усилился (перегрузка цепей); ③ кресло капитана повернулось в сторону, куда не должно.
```
