# Шаблон записи журнала поиска

> После каждого сетевого поиска его нужно сразу записать в файл журнала в `搜索日志/`.
> Файл журнала — жизненная артерия устойчивости библиотеки материалов: не записать журнал поиска — всё равно что не искать.

---

## Формат добавления в журнал поиска

После каждого поиска дописывать одну строку в таблицу записей поиска файла журнала:

```markdown
| [№] | [Ключевые слова поиска] | [Инструмент поиска] | [Число полезных результатов] | [Примечание] |
```

### Пояснение полей

| Поле | Обязательно | Пояснение |
| --- | --- | --- |
| № | Да | Возрастающий порядковый номер в том же файле |
| Ключевые слова поиска | Да | Фактически использованные поисковые слова |
| Инструмент поиска | Да | Tavily / Bing / Zhipu Search (智谱搜索) / другое |
| Число полезных результатов | Да | Число записей, фактически попавших в библиотеку после очистки |
| Примечание | Рекомендуется | Оценка качества поиска (например «ушёл в сторону», «высокое качество», «нужно искать ещё») |

### Пример записи поиска

```markdown
| 1 | 总裁豪门言情小说 经典桥段 女主逆袭 追妻火葬场 名场面盘点 | Tavily | 8 записей | высокое качество, пригодно прямо |
| 2 | 网文 总裁文 写作素材 剧情桥段 打脸反杀 高能情节 | Tavily | 6 записей | среднее качество, нужна вторичная обработка |
| 3 | 追妻火葬场 小说 名场面 虐男主经典桥段 盘点 | Bing | 0 записей | ушёл в сторону, результаты поиска не по теме |
```

## Формат добавления сводки результатов поиска

Если результаты поиска имеют ценность для цитирования, под таблицей записей поиска добавить абзац со сводкой:

```markdown
### [Название направления]
**Источник**：[описание источника]
**Ключевые моменты**：
- [Ключевая находка 1]
- [Ключевая находка 2]
- [Ключевая находка 3]

---

```

### Пример

```markdown
### Структура классических схем «погони за женой в огне» (追妻火葬场)
**Источник**：глубокий анализ Tencent News / Jiemian News
**Ключевые моменты**：
- Основная предпосылка: сильный мужчина и слабая женщина → герой мучает героиню → утрата → раскаяние → погоня за женой
- Базовая формула комбинированных схем: брак перед любовью + литература о замене + побег с ребёнком + перерождение с местью + погоня за женой в огне
- Тенденция итераций: в 2025–2026 годах «погоня за женой в огне» переживает «момент пересмотра» — одно лишь мучение больше не пользуется популярностью, нужны две параллельные линии: «рост героини» и «искупление героя»
```

## Управление файлами журнала

### Дописывание в уже имеющийся файл

Если объём поиска < 10, дописывать в конец уже имеющегося файла журнала в `搜索日志/`.

### Создание инкрементального файла

Если объём поиска ≥ 10, создать новый файл журнала:

```text
搜索日志/NN_增量搜索_YYYYMMDD.md
```

Структура файла:

```markdown
# Журнал инкрементального поиска YYYYMMDD

> **Дата поиска**：YYYY-MM-DD
> **Направление поиска**：[название направления пополнения]
> **Раундов поиска**：[N]
```
