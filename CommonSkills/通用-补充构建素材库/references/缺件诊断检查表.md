# Чек-лист диагностики нехватки

> Перед пополнением библиотеки материалов использовать эту таблицу для системной диагностики нехватки.
> Вывести пользователю на подтверждение стандартизированный отчёт о нехватке.

---

## Шаги диагностики

### Шаг A: прочитать общий индекс

Из `00_素材库总索引.md` извлечь следующую информацию:

- **Текущее число записей по пулам** в сравнении с **целевой плотностью материалов по томам**
- **Направления поиска, охваченные в этом раунде**
- **Дата последнего обновления общего индекса**
- **Номера и имена файлов пулов, заявленные в общем индексе**

### Шаг A1: проверка гейта структурной адаптации (обязательна при первой инвентаризации текущего жанра)

Если у текущего проекта есть явный жанр (зарегистрированный в `题材名_索引.md`), сначала проверить, существует ли уже раздел «Решения по структурной адаптации» этого жанра:

- **Есть** → прочитать его, подтвердить состояние «сохранить/отключить/добавить» по пулам, дальнейшая инвентаризация только по сохранённым пулам
- **Нет** → выполнить «гейт структурной адаптации» (см. раздел «Расширяемость — слой жанра» в SKILL.md), вывести таблицу решений по структурной адаптации и записать в `题材名_索引.md`

> **Ключевое**: не инвентаризировать общие пулы, отключённые для жанра — например, если научная фантастика отключила 05_冷幽默毒舌池, число его записей проверять не нужно.

### Шаг B: фактическая инвентаризация пулов

Объекты инвентаризации ограничены «пулами, помеченными как сохранённые в решениях по структурной адаптации текущего жанра» + «новыми пулами жанра».

| Пункт проверки | Метод проверки | Запись |
| --- | --- | --- |
| Фактическое число записей пула 01 (сюжетные эпизоды) | Прочитать последние номера в подфайлах | |
| Фактическое число записей знаковых сцен 02 | Прочитать последний номер в файле пула знаковых сцен | |
| Пуст ли пул настроек персонажей 03 | Проверить число файлов в 03_人物设定池/ | |
| Фактическое число записей в подфайлах персонажей 03 | Прочитать последние номера в подфайлах | |
| Фактическое число записей саспенс-переворотов 04 | Прочитать последний номер в файле пула лёгких саспенс-переворотов (если сохранён) | |
| Фактическое число записей холодного юмора и острого языка 05 | Прочитать последний номер в файле пула холодного юмора и острого языка (если сохранён) | |
| Число записей **новых пулов жанра** 06+ | Прочитать подфайлы новых пулов в жанровой подбиблиотеке | |
| Число разборов конкурентов | Проверить число файлов в 竞品拆解/ | |
| Раундов журнала поиска | Прочитать файлы в 搜索日志/ | |
| Проверка структуры жанровой подбиблиотеки | Сверить с таблицей решений гейта, проверить, соответствует ли реальная структура каталогов (у отключённых пулов не должно быть каталогов) | |

> Если у текущего жанра нет `题材名_索引.md` (не зарегистрирован по процессу создания), сразу идти по диагностике нехватки общих пулов 01-06/07 и одновременно напомнить пользователю о необходимости выполнить «гейт структурной адаптации» и зарегистрировать жанр.

### Шаг C: анализ пробелов в журнале поиска

Прочитать все файлы в `搜索日志/`, извлечь ключевые слова поисков по строкам, подсчитать охваченные направления. Сопоставить с таблицей «покрытие поиска этого раунда», заявленной в общем индексе.

**Частые модели пробелов**:

- Какой-то тип эмоционального якоря совсем не охвачен (например, по классу «слёзы» нет записей поиска)
- По направлению какого-то пула искали, но число полезных результатов 0 (случай «ухода в сторону» поиска Bing)
- По какому-то подклассу (например, пулу настроек персонажей) совсем нет записей поиска

### Шаг D: проверка полноты индекса эмоциональных якорей

В общем индексе ведётся таблица «индекс эмоциональных якорей». Проверить:

- Не пуста ли эта таблица и не устарела ли она (совпадает ли дата обновления с заявленной в общем индексе)
- Есть ли эмоциональные якоря с частотой ≥ 3, не попавшие в индекс (сканировать поля `**情绪锚**：` в файлах пулов)
- Не забыли ли обновить эту таблицу после последнего пополнения

### Шаг E: проверка порога разделения файлов

Проверить, не приблизились ли файлы пулов к порогу разделения или не превысили его:

| Пункт проверки | Порог | Текущее состояние |
| ------ | ---- | -------- |
| Число записей 01A (эпизоды офисных войн) | >100 → разделить | |
| Число записей 01B (эпизоды внутрисемейных распрей) | >100 → разделить | |
| Число записей 01C (эпизоды продвижения отношений) | >100 → разделить | |
| Число записей пула знаковых сцен 02 | >100 → разделить | |
| Число записей пула холодного юмора и острого языка 05 | >100 → разделить | |
| Число подклассов `##` в каждом файле | >5 → разбить на подфайлы | |

### Шаг F: проверка реестра жанровых подбиблиотек

- Зарегистрированы ли в «реестре подбиблиотек материалов» в конце общего индекса все существующие жанровые подбиблиотеки
- Соответствует ли `_索引.md` каждой жанровой подбиблиотеки структуре `00_素材库总索引.md`

### Шаг G: проверка пустых пулов/пустых подфайлов

- Созданы ли подфайлы в `03_人物设定池/`?
- Есть ли в каждом подфайле реальные записи или только заголовок?
- Есть ли содержимое во всех файлах в `竞品拆解/`?

## Формат вывода отчёта о нехватке

По завершении диагностики вывести пользователю отчёт в следующем формате:

```text
## Отчёт о нехватке в библиотеке материалов
- Дата диагностики: YYYY-MM-DD

### 1. Сравнение плотности материалов
| Пул материалов | Текущих записей | Целевая плотность | Оценка нехватки |
|--------|---------|---------|---------|
| 01A офисные войны | [N] | [N] | достаточно/нужно пополнить/сильно недостаточно |
| 01B внутрисемейные распри | [N] | [N] | достаточно/нужно пополнить/сильно недостаточно |
| ... | ... | ... | ... |

### 2. Пробелы в покрытии поиска
- Охваченные направления: [список]
- Неохваченные направления: [список]
- Поиски с нулевой эффективностью: [список]

### 3. Пробелы в индексе эмоциональных якорей
- Дата последнего обновления индекса эмоциональных якорей: [дата]
- Пропущенные эмоциональные якоря: [список]
- Нужно ли перестроить индекс: да/нет

### 4. Предупреждение о разделении файлов
- Файлы, приближающиеся к порогу 100 записей: [имя файла] (сейчас [N] записей)
- Файлы с более чем 5 подклассами: [имя файла] (сейчас [N] заголовков ##)

### 5. Пустые пулы/пустые файлы
- [Название пула]: [пустой пул/файл есть, но содержимого нет/уже наполнен]
- [Название пула]: [пустой пул/файл есть, но содержимого нет/уже наполнен]

### 6. Состояние гейта структурной адаптации
- Текущий жанр: [название жанра]
- Таблица решений по структурной адаптации: существует/не создана
- Нужно создать пулы: [список]
- Нужно отключить пулы: [список]
- Система эмоциональных якорей: общая годится/нужно перестроить частный индекс жанра

### 7. Рекомендации по приоритетам
1. **Высокий приоритет**: [название пула] — [причина]
2. **Средний приоритет**: [название пула] — [причина]
3. **Низкий приоритет**: [название пула] — [причина]
```
