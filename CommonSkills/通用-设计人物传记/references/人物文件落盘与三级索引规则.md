# Правила сохранения файлов персонажей и трёхуровневого индекса

## Позиционирование на стороне автора

Биография персонажа по умолчанию — это на стороне автора:

- Арбитражный источник по персонажам
- Справочник вызова
- Вход для перекрёстной проверки

Это не краткая биография для читателей и не абзац основного текста.

## Стратегия записи по умолчанию

### Изменение существующего файла

- Пользователь говорит «переписать / переписать с нуля» → полное перекрытие
- Пользователь говорит «дополнить / расширить» → дописать в соответствующем подразделе или добавить в конце «Запись дополнения (YYYY-MM-DD)»
- Пользователь не уточняет → по умолчанию консервативно добавлять «Правку этого раунда (YYYY-MM-DD)» и встраивать подробное содержание в соответствующую структуру

### Новый персонаж

- По умолчанию создавать в: `人物传记/人物名.md`
- Обязательно записывать полный скелет, а не просто несколько абзацев описания
- Ключевые / важные персонажи по умолчанию должны встраивать новые модули прямо в основную структуру, нельзя оставлять временную линию роста, ценности или разницу публичного образа «плавающими» в чате

## Порядок структуры по умолчанию (в первую очередь для ключевых / важных персонажей)

- Заголовок + метаданные заголовка: `人物类型 / 心理弧线步数 / 传记版本 / 最后更新` (тип персонажа / число шагов психологической дуги / версия биографии / последнее обновление)
- `## 写作抓手交付（正文可直接调用）` (передача рычагов письма — напрямую вызываемых в основном тексте)
- `## 基本信息` (основная информация)
- `## 详细内容` (подробное содержание)
- `## 完整心理弧线` (полная психологическая дуга)
- `## 身份认同危机 / 内在冲突体系 / 情感变化链条 / 价值观演进` (кризис идентичности / система внутренних конфликтов / цепочка эмоциональных изменений / эволюция ценностей) (по уровню персонажа и адаптации к жанру)
- `## 三级大纲情节对应索引` (индекс соответствия сюжета трёхуровневому плану)
- `## 本轮修订（YYYY-MM-DD）` (правка этого раунда)
- `## 心理弧线验证（自检）` (проверка психологической дуги, самопроверка)

Если уровень персонажа ниже, можно сжать середину и поздние части анализа, но по возможности сохранять эти входы структуры для удобства последующих дополнений.

## Рычаги автора, которые нужно явно записать

- Эти рычаги по умолчанию собираются в блоке `## 写作抓手交付（正文可直接调用）`, в первую очередь записываются списками, чтобы не разбросаны в длинных абзацах.
- Присказки / речевые привычки
- Привычные действия / микрореакции
- Триггеры
- Границы / переключатели
- Предпочтения оставления следов
- Шаблоны контрдействий

Ключевым / важным персонажам по умолчанию также следует явно записать:

- Временную линию ключевого опыта
- Публичный образ vs самопознание
- Ценности / ложные убеждения
- Текущую внешнюю цель / внутреннюю потребность
- Реакции на давление / механизм утешения
- Символический предмет / якорь памяти / пространственный якорь
- Библиотеку деталей для разбора
- Якорь жанра / эпохи / реального давления
- Историческое положение / структурную функцию
- Кризис идентичности / систему внутренних конфликтов / цепочку эмоциональных изменений / эволюцию ценностей (по уровню)

Эти материалы должны быть записаны в тексте файла, нельзя оставлять только в чате.

## Правила сохранения трёхуровневого индекса

В конце биографии персонажа обязательно сохранять «индекс соответствия сюжета трёхуровневому плану», содержащий как минимум:

- Уровень источника: общий план / часть / том / глава
- Номер
- Временной узел
- Описание события
- Степень важности
- Психологический этап / номер шага
- Последствия этого события для персонажа

## Маркировка противоречий

Если обнаруживается конфликт биографии персонажа с системой трёхуровневого плана, необходимо явно пометить:

- `⚠️ 潜在矛盾：[具体描述矛盾内容及所在大纲层级]` (⚠️ потенциальное противоречие: [конкретное описание содержания противоречия и уровня плана])

и дать:

- Правку плана
- Обновление биографии
- Двустороннюю калибровку

Выбор одного из вариантов или их сочетание.
