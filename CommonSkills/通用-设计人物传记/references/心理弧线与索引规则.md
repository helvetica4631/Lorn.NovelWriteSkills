# Психологическая дуга и правила индекса

## Психологическая дуга — не список эмоций

Годная психологическая дуга должна удовлетворять:

- На каждом шаге есть триггерное событие
- Каждый шаг можно увидеть в основном тексте
- Ключевые шаги по возможности отсылаются к некоему носителю, предмету, обращению, месту или событию
- Продвижение дуги меняет отношения, выбор и цену
- В каждом этапе лучше всего прописать: что персонаж потеряет, что получит, какое ложное убеждение или предубеждение будет пробито

## Рекомендуемое число шагов

- Ключевой персонаж: 30–40 шагов
- Важный персонаж: 20–30 шагов
- Второстепенный персонаж: 10–20 шагов

## Формулировка четырёх этапов

1. Исходное состояние
2. Удар и пробуждение
3. Глубинное исследование
4. Пробуждение и перерождение

Дополнительная рекомендация: не писать лишь четыре заголовка этапов; как минимум дополнить для каждого этапа ключевое триггерное событие, последствия этапа и соответствующий якорь.

## Правила индекса

В конце биографии персонажа следует сохранять поля индекса:

- Уровень источника: общий план / часть / том / глава
- Номер
- Временной узел
- Описание события
- Психологический этап / номер шага
- Последствия этого события для персонажа

## Частые ошибки

- Пишут лишь озарения, не пишут триггерное событие
- В индексе только номера, нет роли события
- Рост персонажа слишком чистый, нет откатов, неудач и ошибочных оценок
- Пишут только четыре больших заголовка, не пишут для каждого этапа, что потеряно / получено / пробито
