## Справочник частых триггерных слов / формулировок пользователя

- Помоги сделать промпт обложки
- Как сгенерировать обложку для этой книги
- Дай мне два варианта промпта для генерации обложки
- Этот промпт умеет только нагромождать материал
- Помоги сделать вариант обложки, удобный для показа на платформе

## Когда использовать

- Для новой книги нужен промпт обложки первой версии.
- Существующий промпт умеет лишь нагромождать материал и не управляет композицией, основным объектом и показом на платформе.
- Нужно сравнить несколько стилевых направлений в формате A/B-вариантов.

## Порядок выполнения по умолчанию

Фиксированный приоритет: сначала обеспечить узнаваемость персонажа / жанра в среде миниатюры, затем попадание в эмоцию и устойчивость визуального ядра, и лишь в последнюю очередь — стилевое украшение, A/B-варианты и структуру сохранения в файл.

1. Сначала определить среду миниатюры платформы, первое впечатление целевого читателя, допустимые текстовые элементы и формулировку главного заголовка обложки: для несегментированного романа используется целевое название романа для публикации, для романа по частям — целевое название соответствующей части.
2. Затем прочитать материалы по произведению, зафиксировать визуальное ядро, эмоциональное ядро и ядро узнавания жанра.
3. Затем зафиксировать основной объект: персонаж, предмет, ориентир, источник света или символ опасности, и определить основную линию: персонаж / сцена / предмет / отношения.
4. Затем по платформенной матрице написать композицию, гамму, ограничения стиля, ограничения безопасности текста и запрещённые элементы.
5. Наконец, выдать не менее двух (A/B) основных промптов, негативные промпты, пояснение по вёрстке и схему сохранения в файл по умолчанию.

## Дополнение о миниатюре на первом экране (новое)

Оценка обложки по умолчанию ранжируется только по следующим приоритетам: 1) жанр узнаваем; 2) основной объект узнаваем; 3) попадание в эмоцию; 4) бонус от стилевого украшения и атмосферы.

- Вариант обложки по умолчанию должен сначала ответить на три вопроса: кого / что видно первым на миниатюре, какую эмоцию чувствуешь первой, какой жанр узнаёшь первым; если остаётся лишь «красиво», но не узнаётся — это провал.
- Если торговая точка произведения сильно зависит от отношений персонажей, эмоционального температурного перепада или противостояния статусов, хотя бы один вариант должен вложить эту информацию в дистанцию между персонажами, взгляд, позу или структуру света и тени, а не просто нагромождать фоновый материал.
- Если на миниатюре основной объект, зона заголовка и яркий образ борются друг с другом, по умолчанию жертвуют декоративным слоем, а не узнаваемостью жанра и эффективностью клика на платформе.

## Формулировки вывода по умолчанию

- По умолчанию выдавать не менее двух (A/B) готовых к сдаче вариантов промпта обложки.
- По умолчанию одновременно давать основной промпт, негативный промпт, пояснение по композиции и напоминание о показе на платформе.

## Минимальная поставка

- Не менее 2 основных промптов с чёткой разницей.
- Каждый содержит негативные ограничения / ловушки, которых нужно избегать.
- Каждый объясняет основной объект, композицию, гамму, стиль, иерархию текста и читаемость на миниатюре.
- Каждый обязан чётко указывать целевое название для публикации, используемое в главном заголовке этой обложки; нельзя смешивать общее название книги, название части и платформенное название для публикации.
- По умолчанию содержит именование файла и структуру сдачи, пригодные для сохранения в файл.

## Жёсткие правила

- Запрещено, чтобы обложка была лишь красивой и не узнавалась по жанру.
- Запрещено, чтобы на миниатюре основной объект тонул в пёстром фоне.
- Запрещено, чтобы лицо, руки персонажа, зона текста и зона заголовка бились друг с другом.
- Главный заголовок обложки несегментированного романа — всегда целевое название романа для публикации; главный заголовок обложки романа по частям — всегда целевое название соответствующей части; нельзя продолжать подставлять общее название книги.
- Запрещено, чтобы в основном промпте слова жанра, слова торговых точек, слова эмоций ошибочно писались так, что модель перепишет их на картинку как лишний текст.

## Границы с другими Skill / Prompt

- Этот Skill отвечает за сам промпт обложки и структуру сдачи.
- Не отвечает за проектирование названия книги, написание аннотации или сборку материалов для платформы.
