# Трёхэтапный рост золотого пальца и шлюзы цены

> Источник формулировок: `修订体系.md`, партия B (проверка дуги золотого пальца).

## Трёхэтапная модель

| Этап | Ориентир по главам / объёму | Целевая функция | Обязательные ограничения |
| --- | --- | --- | --- |
| Начальный | Главы 1–20 / первые 80 тыс. | Обнаружение способности, нащупывание правил | Цена неудачи видна; нельзя стабильно выдавать результат |
| Средний | Главы 21–60 / 80–180 тыс. | Повышение способности, расширение сцен | Обязательно должны появиться проявление цены и узкое место |
| Поздний | С главы 61 / 180–250 тыс. | Зрелость способности, финальная проверка | Нужно ответить «почему не всемогуща» и дать отголоски финала |

## Жёсткие правила проектирования

- Не допускается «в середине уже непобедим» без цены.
- Не допускается «повышение без условий срабатывания».
- Не допускается «потеря способности в финале» без предварительной подготовки.

## Шлюзы цены (должен быть задет хотя бы один)

- Цена для жизненных показателей (истощение, слабость, последствия боли).
- Познавательная цена (провалы памяти, смещение суждений, информационный шум).
- Цена в отношениях (потеря доверия, ошибочная оценка персонажей, общественные последствия).
- Ресурсная цена (материалы, временные окна, полномочия, процедурные следы).

## Триггеры повышения (должен быть задет хотя бы один)

- Условный триггер: определённое время-пространство / порог / объект.
- Триггер ценой: сначала платится стоимость, затем получается прирост.
- Триггер заданием: разблокируется после выполнения некоей цепочки улик или процедур.
- Триггер потери контроля: следующий уровень способности обнаруживается только после высокорискового использования.
