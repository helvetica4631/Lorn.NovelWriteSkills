# Частые ошибки грани истории и исправления

## 1. Только тема, нет цепочки действий

Исправление: дописать загадку в одной фразе, цепочку действий HOW, ключевые действия каждого тома.

## 2. Только эмоции, нет носителя

Исправление: немедленно дописать послойность A/B/C/D, приземлить ключевой конфликт в то, что можно сфотографировать, подписать, экспортировать.

## 3. Только размах общего плана, нет рычага для основного текста

Исправление: для основного тома появления написать полный 4B, для каждого тома дополнить «возникновение — развитие — кульминация — развязка — передача».

## 4. Антагонист слишком силён, как бог, а не как человек

Исправление: добавить ограничение цены действий антагониста, пометить узлы, уже израсходованные в этом томе.

## 5. Каждый том говорит об одном и том же

Исправление: чётко определить единственную задачу каждого тома, записать различия этапов: проявление, формирование, распространение, откат, слушания и т. п.

## 6. Нет передачи, питание прерывается

Исправление: в 4A записать линии жёстких рычагов, в 4B в конце каждого тома записать передачу.

## 7. Умеют только ругать систему, не умеют преследовать узлы

Исправление: в каждом томе преследовать хотя бы одну ответственность узла.

## 8. Накоплено слишком много остаточной боли, потеряна убойность

Исправление: применять «мало, но жёстко» — в каждом томе максимум 1–2 удара, закреплённых за персонажем + сценой + видимым носителем.

## 9. Слой D использован как улика

Исправление: слой D может лишь запускать действие, ключевая квалификация обязательно возвращается к A/B/C.

## 10. Чек-лист слишком пустой, по нему нельзя рецензировать

Исправление: переписать в исполнимые вопросы, например: есть ли жёсткий рычаг, есть ли пролом (брешь) ≤ 3 главы, есть ли ответственность узла, указывает ли хук в конце главы на следующее действие.

## 11. Сопоставление слоёв-источников ошибок (новое)

| Ошибка | Слой, где вероятнее проблема | Первое средство |
| --- | --- | --- |
| Только тема, нет цепочки действий | `Слой запуска конфликта` | Дописать загадку в одной фразе, цепочку действий HOW, ключевые действия уровня тома |
| Только эмоции, нет носителя | `Слой запуска конфликта` | Дописать рычаги A/B/C/D и ключевые носители |
| Только размах общего плана, нет рычага для основного текста | `Слой разбираемости на тома` | Сначала полностью написать 4B основного тома, затем дополнить точки приземления групп глав |
| Каждый том говорит об одном и том же | `Слой питания уровня тома` | Написать единственную задачу каждого тома и различия этапов |
| Нет передачи, питание прерывается | `Слой питания уровня тома` + `Слой разбираемости на тома` | Дополнить передачу в 4A / 4B и гвоздях в конце тома |
| Умеют только ругать систему, не умеют преследовать узлы | `Слой запуска конфликта` | Для каждого тома забить хотя бы одну ответственность узла |

## 12. Оценка ошибок Green / Yellow / Red (новое)

- `Green`: в основном локальная забивка гвоздей, все три основных скелета грани истории на месте.
- `Yellow`: уже видно основной слой ошибки, но питание уровня тома или интерфейс тома всё ещё колеблются, нужна дополнительная калибровка.
- `Red`: ошибка уже повредила основной скелет хотя бы одного из слоёв — запуск конфликта, цепь питания, разбираемость, нельзя ограничиваться поверхностной шлифовкой.
