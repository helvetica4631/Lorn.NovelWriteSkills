# Дополнение: управление интригой и ритм цепи хуков

> Усвоены правила внешнего `hook-techniques` — хуки одной главы, соединения между главами и возврат завязок; реестр зацепок и завязок усилен до долговременной системы управления «вопрос — продвижение — возврат — снова открыть новый вопрос».

## 1. Часто используемые типы хуков одной главы

- Внезапное раскрытие
- Срочный кризис
- Незавершённое действие
- Переворот личности
- Дилемма выбора
- Таинственный предмет или зацепка
- Ограничение по времени
- Обещание или угроза
- Загадочное исчезновение
- Подтекст

При выборе в первую очередь спрашивать:

- Изменит ли это понимание читателем уже известных событий
- Изменит ли это следующий выбор персонажа
- Заставит ли это читателя немедленно захотеть перелистнуть к следующей главе

## 2. Управление интригой между главами

### Общие принципы

- В каждой главе как минимум ответить на одну старую интригу, затем выдвинуть одну новую интригу
- Малую интригу лучше вернуть в пределах `1–3` глав
- Среднюю интригу лучше вернуть в пределах `5–8` глав
- Большая интрига может идти через тома / через всю книгу

## II.5. Быстрое определение слоя источника (новое)

- `Слой хука одной главы`: выходной хук этой главы, уровень силы этой главы и осознанность вариативности типов хуков.
- `Слой отклика между главами`: ясны ли выходной хук предыдущей главы, входной отклик этой главы и ожидаемый отклик следующей главы.
- `Слой активной нагрузки`: управляемы ли число, сила, порядок ротации и риск дисбаланса одновременно активных линий интриги.

### Сигналы дисбаланса

- Несколько глав подряд лишь открываются новые вопросы, старые не получают ответа
- В одной главе возвращается слишком много интриг, читатель не успевает переварить
- Какая-то линия долго не продвигается, читатель уже её забыл

## 3. Параллельные линии интриги

Активные линии интриги рекомендуется держать на уровне `3–4`:

- Интрига главной линии
- Интрига персонажей
- Интрига отношений
- Интрига времени
- Интрига мира

Разные линии должны продвигаться поочерёдно, нельзя надолго оставлять какую-то линию в забвении.

## 4. Проверка цепи хуков

В каждой главе можно быстро проверить по следующим четырём пунктам:

| Пункт | Содержание |
| --- | --- |
| Выходной хук предыдущей главы | Вопрос или действие, оставленное предыдущей главой |
| Входной отклик этой главы | Прямой / косвенный / отсрочен / обрыв |
| Выходной хук этой главы | Новый хук, оставленный этой главой |
| Ожидаемый отклик следующей главы | Как предполагается ответить |

### Модели отклика

- Прямое продолжение
- Косвенная связь
- Намеренная отсрочка
- Обрыв (обычно ошибка)

Намеренную отсрочку обычно лучше вернуть к этой линии в пределах `3` глав.

## 5. Уровни силы интриги

- Уровень любопытства
- Уровень беспокойства
- Уровень неотложности
- Уровень выживания
- Предельный уровень

В разных позициях глав использовать разную силу, непрерывное высокое давление вызывает у читателя онемение.

## 6. Закладка и возврат завязок

### Приёмы закладки

- Встраивать в бытовые сцены
- Отвлекать внимание более броским событием
- Дать детали текущую поверхностную функцию
- Многократное естественное появление, снижающее настороженность

### Частые способы возврата

- Симметричная сцена
- Повтор диалога
- Возвращение предмета
- Перекомпоновка информации

## 7. Запреты

- Ложная интрига: результат — лишь несущественное недоразумение
- Deus ex machina: решение опирается на информацию / способность, которых ранее никогда не упоминали
- Чрезмерная недосказанность: слишком много вопросов без продвижения
- Хук с малым риском: концовка, которая по-настоящему не волнует ни персонажей, ни читателя

## 8. Рекомендации по дополнительным полям реестра

Кроме существующих номера, состояния, окна, рекомендуется явно записывать:

- Сила интриги
- Текущее состояние отклика
- Глава последнего продвижения
- Ожидаемый диапазон глав возврата
- Способ возврата
- Последствия после возврата
- Пересекается ли с другими линиями интриги

## Красные линии

- Нельзя записывать только «что заложено», не записывая «как вернуть»
- Нельзя записывать только «вернули», не записывая «эффект возврата»
- Нельзя допускать бесконечного разрастания активных линий интриги
- Нельзя несколько глав подряд использовать один тип хука без осознания вариативности

## Минимальный артефакт интриги (новое)

```markdown
【Слой хука одной главы】выходной хук этой главы / тип / сила
【Слой отклика между главами】выход предыдущей главы / отклик этой главы / ожидаемый отклик следующей
【Слой активной нагрузки】число линий с высоким вниманием сейчас / главные и второстепенные / порядок ротации / риск дисбаланса
【Текущая оценка】Green / Yellow / Red
```

## Оценка интриги Green / Yellow / Red (новое)

- `Green`: все три слоя — хук одной главы, отклик между главами, активная нагрузка — ясны, цепь интриги ритмична и не утомляет.
- `Yellow`: интрига ещё работает, но какой-то слой начинает терять баланс, например, отклик замедлен или хуков одного типа слишком много.
- `Red`: умеет только открывать новые вопросы и не умеет возвращать старые, либо активные линии бесконечно разрастаются — система интриги вошла в состояние неуправляемости.
