# Библиотека тегов произведений платформы Qimao (сырьё для «фабрики концепций»)

> **Источник**: система «тегов произведений» в авторском разделе Qimao (七猫中文网), выгрузка 2026-06.
> **Назначение**: пул творческих материалов для «фабрики концепций». Каждый тег — это **элемент истории**, уже проверенный платформой: личность персонажа, движущая сила сюжета, стилевое обещание или фон. Комбинируя теги из разных категорий, можно массово генерировать истории с коммерческой основой.
> **Примечание**: тег — это «элемент, проверенный рынком», а не «готовая идея». Главная работа «фабрики концепций» — делать из этих элементов **свежие комбинации**, а не использовать их по отдельности.

### Приёмы расширения «фабрики концепций»

1. **Комбинация разных категорий**: помещайте сочетание «персонаж» + «сюжет» в необычный «фон» (например, «赘婿 (зять в доме жены) + 无限流 (бесконечный поток) + 星际 (межзвёздное)»)
2. **Наложение ограничений**: теги стиля можно вкладывать как ограничивающие условия (например, «暗黑 + 系统 + 医生 + 规则怪谈 + 都市»)
3. **Управление через компенсацию**: сначала определите прототип компенсации (подъём со дна / месть недооценённого / реванш большой героини / подавляющее превосходство), затем подбирайте теги
4. **Согласование с платформой**: Qimao предпочитает сочетания с быстрым темпом и сильной стимуляцией (爽文 / 扮猪吃虎 / город); при работе для других платформ ориентируйтесь на их критерии
5. **Наложение двух тегов**: внутри сюжета и персонажа допустимо накладывать по 2 тега (например, «扮猪吃虎 + 掉马甲» как двойная движущая сила)

## Приложение: пояснение об источнике тегов

Все теги этой библиотеки взяты из **системы «тегов произведений» в авторском разделе Qimao (七猫中文网)** (выгрузка 2026-06-14). Теги — это стандартизированная классификация элементов веб-романов, принятая платформой Qimao; они проверены редакционной системой платформы и обладают следующими свойствами:

- **Подтверждённость рынком**: каждый тег соответствует классу элементов истории, уже проверенных читателями платформы
- **Совместимость с рекомендательной системой**: теги напрямую влияют на логику распределения в рекомендательной системе Qimao
- **Ценность для поискового индекса**: читатели находят произведения по тегам
- **Универсальность между тематиками**: большинство тегов можно переносить между разными тематиками

> **Примечание**: библиотека построена преимущественно на системе тегов Qimao, но при использовании в «фабрике концепций» не стоит ограничиваться одной платформой. Для расширения пула материалов можно дополнить его перекрёстно системами тегов платформ Qidian / Fanqie / Jinjiang и других.
