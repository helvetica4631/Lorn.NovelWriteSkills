# 通用-输出今日头条版｜Сопоставление посекционного исправления и возврат подробных правил

## Сценарии применения

Этот документ — справочник и план локального исправления на случай, если при переписывании под Toutiao какое-то место главы не соответствует требованиям к стилю платформы, плотности хуков, драйверу взаимодействия или среднему темпу.

## I. Недостаточная плотность хуков начала

### Симптомы
- В первых 500 знаках начала нет прироста информации или интриги.
- Слишком большой интервал между хуками (более 250 знаков без нового хука).
- Читатель в начале может «потерять фокус» и не понимать, о чём речь.

### План исправления

| Место проблемы | Причина | Стратегия исправления |
| ------- | ---- | ------ |
| Начало, абзацы 1–3 | Слишком много фона | Срезать фон, сразу входить в «уже случившееся или вот-вот случающееся» событие; фон вкраплять небольшими порциями через «размышления героя» |
| Начало, абзацы 2–5 | Слишком низкая информационная плотность (чистые пейзажи, чистая психология) | Переплетать «информацию + конфликт», каждая фраза должна иметь направленность (улика указывает на ложь, действие указывает на эмоцию, диалог указывает на правду) |
| Середина (500–1500 знаков) | Избыточные диалоги или размышления | Диалог идёт прямо к сути, удалять «болтовню»; психологию переводить в «действие + деталь» (например, думая о страшном, вместо «в душе очень страшно» писать «тело дрожит») |
| Конец главы (после 1500 знаков) | Нет неразрешённого хука | В последних 100–200 знаках добавить «новую улику / обнаруженную аномалию / внезапную реакцию персонажа», чтобы читатель «не мог не продолжить» |

## II. Неудачное соотношение сюжета и избыточности

### Симптомы
- Медленная скорость продвижения сюжета (должно быть 50 % сюжета, а фактически 35 %).
- Слишком много избыточных описаний (слишком много психологических монологов, нагромождения пейзажей, болтовни в диалогах).
- У читателя «ощущение, что прогресс медленный», доля дочитывания может упасть.

### План исправления

| Проблемное место | Исходная структура | Как переделать для Toutiao |
| ---- | ------ | --------- |
| Абзацы психологических монологов | Целый абзац с мыслями героя | Разбить на «действие + диалог + детали среды», одновременно выражая психологию |
| Абзацы описания пейзажа | 3–5 фраз подряд описывают одну сцену | Выделить 1–2 самые ключевые чувственные детали, остальное удалить; пейзаж подавать способом «герой обнаруживает аномалию» |
| Диалоги персонажей | Бытовая болтовня или слишком много объяснений | Превратить диалог в напряжение «обе стороны что-то скрывают»; каждая реплика раскрывает улику или двигает событие |
| Переходные абзацы | «Через два дня Линь Юй снова пришёл на место происшествия» | Начинать прямо с «Линь Юй толкнул дверь», а момент времени естественно проявлять в диалоге или действии |

## III. Недостаточно точек драйвера взаимодействия

### Симптомы
- Содержание главы с трудом побуждает «захотеть прокомментировать».
- Нет точки темы «а вы как считаете?».
- Желание делиться низкое, ожидаемое число комментариев не достигается.

### План исправления

| Проблема | Стратегия исправления |
| ---- | ------ |
| Интрига не вызывает обсуждения | Интригу превратить в «допускающую несколько прочтений», а не «с единственной разгадкой»; например, «эта записка — угроза или просьба о помощи?», а не «кто оставил эту записку?» |
| У выбора персонажа нет морального двойного выхода | У каждого важного выбора задавать «две дороги, у каждой свои резоны», чтобы читателю хотелось комментировать «как бы выбрал я» |
| У улики нет «пространства для разворота» | Задавать улики с противопоставлением «поверхностный смысл vs истинное значение», например, «алиби выглядит безупречным, но если подумать…» |
| В конце нет неразрешённого | В последних 2–3 фразах главы обязательно оставить «новую информацию / новое недоумение», чтобы читатель «обязательно комментировал и обсуждал» |

## IV. Отсутствует опора точки зрения

### Симптомы
- Появляется информация «с позиции бога» (то, чего герой знать не может).
- Размытая опора восприятия (в описании не сказано явно, «кто воспринимает»).
- Снижается погружение, пропадает эффект присутствия.

### План исправления

| Проблема | Как переделать |
| ---- | ---- |
| «В комнате странный запах» | Переделать в «он толкнул дверь, и в лицо ударил неправильный запах» |
| «Далёкий маяк в ночи выглядит жутко» | Переделать в «он сквозь темноту увидел мерцающий свет далёкого маяка, и вдруг возникло дурное предчувствие» |
| «Он не заметил камеру наблюдения в углу» | Сохранить границу познания «он не заметил», позже дать ему обнаружить; не говорить читателю в этой же главе, что там камера |
| Повествовательное прошедшее («до этого…») | Переделать в «он вспомнил…» или «он вдруг вспомнил…», добавив субъект восприятия |

## V. Не удаётся удержать средний темп

### Симптомы
- Вся глава предельно напряжённая (читатель легко утомляется).
- Недостаточные перепады темпа (вся глава пресная).
- Нарушено соотношение быстрых и медленных фрагментов.

### План исправления

| Проблема | Стратегия исправления |
| ---- | ------ |
| Вся глава в быстром темпе | В точке 40–60 % вставить «диалоговый буфер» или фрагмент «воспоминание и размышление», чтобы читатель перевёл дух; но этот буфер всё равно должен раскрывать улики |
| Вся глава в медленном темпе | В точках 20 %, 50 %, 80 % разместить по быстрому продвижению «эскалация конфликта» или «появление новой улики» |
| Скачки темпа неестественны | Между быстрыми и медленными фрагментами делать естественный переход через «реакцию-действие героя» или «изменение среды» |
| Проседание в середине (период вялости) | В середине обязательно задать «выброс новой интриги» или «разворот предыдущего фрагмента», чтобы снова натянуть напряжение |

## VI. Человеческая опорная точка недостаточно выражена

### Симптомы
- История превращается в чистое «расследование дела».
- Персонажи выглядят «раскрывающими дело ради раскрытия дела», бескровные.
- У читателя нет эмоционального отклика, есть лишь удовольствие «разгадывания».

### План исправления

| Проблема | Стратегия исправления |
| ---- | ------ |
| Антагонист слишком абсолютно плох | В мотив или выбор антагониста добавить каплю «понятной причины», чтобы даже после приговора он не оставался «глупым злодеем» |
| Положительный герой слишком абсолютно хорош | Ввести в выбор героя «двойственность» или «изъян», например, «чем пожертвовал ради раскрытия дела?» |
| В расследовании нет человечности | В процесс обнаружения или проверки улики добавить связь с чьими-то «чувствами / воспоминаниями / выбором» |
| В истории нет ощущения социальной реальности | Связать деталь дела с реальными социальными темами (утечка информации, давление на работе, травля в сети), добавляя эффект присутствия |

## VII. Загрязнение нетекстовыми блоками (обнуление шаблонных фраз)

### Жёсткие запреты
- Запрещено появление в тексте шаблонных метафраз вроде «对照项落在…», «先把同一句话拆碎…», «只求能追溯…».
- Запрещено появление подряд двух фраз вида «с моей стороны… + 把… + 对齐… + союз… + слово-формулировка» — мусорной группы фраз.
- Запрещено появление корпоративного жаргона вроде «校准, 锁死, 拆开, 同步».

### План обнуления
Если обнаружено загрязнение, приводить в порядок по следующей стратегии:

| Тип загрязнённого абзаца | Способ обнуления |
| -------- | ----- |
| «对照…口径…对齐…» | Удалить целиком, заменить повествовательным выражением или диалогом |
| Расчленяющее «先把…再把…» | Слить в одну фразу или один абзац естественного повествования |
| Нагромождение «я в душе… с моей стороны… мои ощущения…» | Переделать в «действие + детали среды», убрать повтор слова «я» |
| Сохранение «只求…不求…» | Удалить такую метаинтонацию, заменить конкретным выбором-действием |
