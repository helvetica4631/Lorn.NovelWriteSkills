# 通用-输出起点中文网版｜Сопоставление посекционного исправления и возврат подробных правил

> Этот документ — посекционное сопоставление исправлений для вывода на платформу Qidian. Если после платформенного переписывания в тексте главы возникают структурные проблемы (недостаток объёма, недостаточная сила хука, вялое начало и т. п.), нужно выполнять целевое исправление по этому сопоставлению, избегая слепого переписывания.

## Сопоставление исправлений при недостатке объёма

| Очаг проблемы | Направление исправления | Запрещённые действия |
| --- | --- | --- |
| Основной текст ниже нижней границы платформы | Добавить цепочку действий в сцене + микрокадры реакций персонажей | Вода, нагромождение шаблонных фраз, бессмысленные повторы |
| «Слово от автора» ниже нижней границы платформы | Добавить мелкие детали отголосков главы + лёгкий вопрос | Писать пояснение настроек, анонс следующей главы, итоговую интонацию |

## Сопоставление исправлений при вялом начале

| Очаг проблемы | Направление исправления |
| --- | --- |
| В первых 200 знаках нет конфликта | Прямо в первую фразу вынести самое взрывное противоречие / аномалию / сигнал этой главы |
| В первых 300 знаках у читателя нет вопросов | Обеспечить хотя бы одно из: внезапная неожиданность / сильный контраст / сигнал опасности |
| В первых 1000 знаках нет ожидания награды | Показать «золотой палец» или чёткий сигнал «на чём держится победа героя» |

## Сопоставление исправлений при недостаточном хуке в конце главы

| Очаг проблемы | Направление исправления |
| --- | --- |
| Концовка как итог | Заменить на одно из: новый пробел / новая цена / незавершённое действие / более опасное новое объяснение |
| Тип концовки повторяет предыдущую главу | Чередовать по схеме «завершение → зависание → раскрытие → поворот → кризис → исполнение» |
| В концовке нет драйвера следующей главы | Обеспечить, чтобы читатель ясно знал: «следующая глава будет сложнее» или «следующая глава откроет больше» |

## Сопоставление исправлений при пустой «прокрутке» в середине

| Очаг проблемы | Направление исправления |
| --- | --- |
| В середине нет награды | Добавить хотя бы одну ощутимую читателем этапную награду (раскрытие информации / изменение отношений / эскалация риска) |
| В середине подряд пустая подготовка | Сжать подготовительные абзацы, вложив в подготовку маленькие награды, ощутимые сразу |
