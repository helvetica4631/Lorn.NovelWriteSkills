# Вывод версии для WebNovel

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-вывод-webnovel`.

## Обязанности, которые остаются только у этого Prompt

- Сохранить обнаруживаемость платформенного входа
- Сохранить минимальный корневой каталог вывода и структурные ограничения
- Направить общие положения английских платформ и жанровые патчи в соответствующие Skill

## Минимальные ограничения совместимости

- Корень каталога вывода: `WebNovel/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)
- Основной текст `Len >= 6500`
- Кроме строки `## 作者有话说`, китайского / CJK быть не должно
- Нельзя писать «городскую магию и сверхспособности» как detached lore dump или английскую оболочку с одной лишь странностью

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `городская-магия-и-сверхспособности-вывод-webnovel` и её общую основу:

- Общие ограничения английских платформ
- Границы жанра и источники
- Детали исполнения и жанровые патчи
- Отображение исправлений на уровне разделов и возврат детальных правил
- Функция раньше названий, кросс-культурная читаемость, эмпатия к профессиям на краю реальности и краткие пояснения фольклорных правил

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящие правила платформы WebNovel и английские жанровые патчи «городской магии и сверхспособностей» нужно читать в соответствующих Skill и исполнять там.
