# Единый промпт вывода «версии для WeChat Official Accounts» романа в жанре «городская магия и сверхспособности»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【городская магия и сверхспособности】, лучше подходящую контексту сериала в WeChat Official Accounts: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя интригу правил, опорные точки реальности и мотивацию следить за обновлениями.

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `общий-вывод-wechat` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку правил, опорные точки реальности и нулевое добавление фактов, затем усилить для аккаунтов плавное чтение, микро-крючки и ощущение сопровождения в сериале.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов портить опыт сериального чтения.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `微信订阅号/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `общий-вывод-*/SKILL.md`
- Нельзя писать «городскую магию и сверхспособности» как оболочку «горячего поста» паблика или лёгкий контент.

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».

В этом проходе дополнительно усвоены ключевые моменты: привязка к офисному микропространству, ощущение сериала на микро-крючках, плавное скольжение при чтении и тон лёгкого сопровождения.
