# Каркас жанрового позиционирования

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-проектирование-позиционирования-жанра`.

Этот Prompt — единый вход жанрового позиционирования «городской магии и сверхспособностей». Жанровый Skill отвечает за загрузку специфичных для жанра нишевых профессий, фольклорных искусств, трения с реальностью, цены способностей и основного платформенного канона, а затем направляет в `общий-проектирование-позиционирования-жанра` для исполнения общей способности позиционирования.

Prompt не вправе в обход жанрового Skill напрямую использовать общие правила позиционирования.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом жанрового позиционирования «городской магии и сверхспособностей»
- Сохраняет минимальный вход, норму по умолчанию, минимальные ограничения исполнения и минимальное пояснение сдачи
- Направляет основные правила каркаса позиционирования в `общий-проектирование-позиционирования-жанра` → `общий-проектирование-позиционирования-жанра`

## Минимальный вход

- Название текущего произведения (если уже есть)
- Целевая платформа (по умолчанию из `Agents.md` в корне проекта берётся основная платформа вывода)
- Имеющиеся черновые материалы: набросок аннотации, продающая точка одной фразой, общий план или вход в ключевой сеттинг (достаточно хотя бы одного)
- Если есть: отчёт анализа конкурентов, общий план, биографии персонажей, сеттинг истории и т. п. — их тоже нужно процитировать

## Канон по умолчанию

- По умолчанию одновременно проверяются: основной платформенный канон, крючок главного героя, опорные точки реальности, опорные точки цены и инновационная комбинация
- По умолчанию выводится текст каркаса позиционирования, который можно напрямую записать обратно в файлы концепт-карт в `故事框架/`
- По умолчанию исполняется в порядке «быстрая оценка слоя источника → калибровка четырьмя вопросами → пять коммерческих элементов → позиционирование по шаблону → оценка рынка Qidian»

## Минимальные ограничения исполнения

- Сначала нужно прочитать имеющиеся в рабочей области материалы, относящиеся к данному произведению: общий план, анализ конкурентов, исследования письма и т. п.
- Сначала нужно закрепить главную продающую точку, основной платформенный канон и крючок главного героя, и лишь затем разворачивать инновационную комбинацию и опорные точки цены
- Если резюме позиционирования не позволяет незнакомцу в нескольких фразах понять «что в этой книге стоит открыть», позиционирование считается незавершённым
- Для жанра «городская магия и сверхспособности» по умолчанию требуется, чтобы вход через профессию сцеплялся с фольклорными искусствами; нельзя давать лишь сеттинг способностей без трения с реальностью и цены способностей
- Только если пользователь явно сказал «только набросать, файлы не трогать», разрешается не записывать на диск

## Выдача по умолчанию

- Текст каркаса позиционирования записан или перезаписан по соответствующему пути текущего проекта
- В диалоге как минимум пояснить: завершено ли позиционирование, закреплены ли главная продающая точка и основной платформенный канон, каков главный риск
- Если вынесено заключение Yellow или Red, нужно явно указать слабые места и путь их восполнения

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `городская-магия-и-сверхспособности-проектирование-позиционирования-жанра` и её общую основу `общий-проектирование-позиционирования-жанра`, а основной текст в этом Prompt параллельно больше не сопровождается:

- Требования к верному переносу и обязательный список чтения references
- Требования к сохранению продающих точек
- Пять элементов коммерческого мышления
- Четыре решения по позиционированию по шаблону и проверка обоснованности
- Оценка жанрового рынка платформы Qidian
- Границы жанра и описание входа, позиционирование городской магии и сверхспособностей и источник проектных арбитров
- Правила верности жанрового позиционирования, чек-лист платформенного позиционирования, матрица опорных точек и шаблон инновационной комбинации
