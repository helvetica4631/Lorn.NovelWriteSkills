# Дизайн ИИ-промпта генерации изображения для обложки романа

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-проектирование-промптов-для-обложки`.

Если жанровая главная ось обложки пока не ясна, можно дополнительно вызвать: `общий-проектирование-позиционирования-жанра`.

Если нужно визуально развести одну и ту же книгу по нескольким платформам, можно дополнительно вызвать: `общий-адаптация-под-платформы`.

Prompt не вправе пропускать жанровый Skill и напрямую собирать общий платформенный визуальный словарь.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом «проектирования промптов генерации изображений для обложки»
- Сохраняет обнаруживаемость жанра и платформы и описание минимального ввода
- Сохраняет маршрутизацию по умолчанию, минимальную сдачу и ограничения записи на диск по умолчанию
- Сообщает, какие основные правила перенесены в жанровый Skill / общий Skill / references

## Минимальный вход

### Обязательный вход

- `platform`: целевая платформа
- `title`: название романа, отображаемое на обложке

### Необязательный вход

- `genre`
- `hook`
- `theme`
- `protagonist`
- `mustInclude`
- `mustAvoid`
- `plannedText`
- `styleBias`
- `variants` (по умолчанию `2`)

## Минимальные ограничения исполнения

- Обложка по умолчанию — **вертикальная обложка романа**, в первую очередь обрабатывается в соотношении `3:4`
- Название нужно сохранять дословно, нельзя самовольно переписывать, сокращать или переименовывать
- Главный заголовок должен быть самым крупным и самым заметным текстом на картинке
- Имя автора на китайских платформах по умолчанию: `产品经理独孤虾`
- Имя автора на английских платформах по умолчанию: `lornshrimp`
- Кроме названия книги, имени автора и текста, явно запланированного к размещению в изображении в `plannedText`, в кадре не должно быть другого читаемого текста
- Нельзя добавлять логотип платформы, логотип APP, водяные знаки, QR-коды, угловые рекламные слоганы
- Нельзя делать в стиле киноафиши, игнорируя читаемость обложки книги
- Если информации недостаточно, можно выбрать осторожное направление на основе «названия + портрета читателя платформы», но нужно указать основание вывода и нельзя подделывать сюжет

## Требования к сдаче по умолчанию

Каждый раз по умолчанию выводятся **2 варианта**:

- `方案A`: ориентация на массовый хит платформы
- `方案B`: ориентация на дифференциацию / фактуру

Каждый вариант содержит как минимум:

1. Оценка платформы
2. Краткое описание направления обложки
3. Основной промпт
4. Negative Prompt
5. Пояснение по вёрстке

## Требования к сохранению в файл по умолчанию

- Результат по умолчанию не только показывается в диалоге, но и оформляется в Markdown-файл на диске
- Каталог сохранения по умолчанию: `小说简介/`
- Рекомендуемое имя файла по умолчанию:
  - Одна платформа: `《书名》{平台名}封面生图提示词_vYYYY-MM-DD-r1.md`
  - Несколько платформ: `《书名》{平台A}与{平台B}封面生图提示词_vYYYY-MM-DD-r1.md`
- Если за тот же день уже есть файл с таким именем, увеличивается `rN`, старая версия не перезаписывается
- Если это правка существующего плана, также в первую очередь создаётся файл новой версии правки

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `городская-магия-и-сверхспособности-проектирование-промптов-для-обложки` и связанные с ним общие / жанровые references, а основной текст в этом Prompt параллельно больше не сопровождается:

- Нормализация ввода, псевдонимы платформ, порядок чтения контекста
- Основные шаги мышления: предпочтения читателей платформы, визуальное / эмоциональное / жанрово-опознающее ядро, ведущий тип обложки, суждение о наборе заголовка
- Матрица стратегий обложек по платформам
- Правила безопасности текста, шаблон формулировки основного промпта, самопроверка на случайное попадание лишнего текста
- Структура вывода, требования к вариантам A/B, минимальные пункты Negative Prompt, нормы записи на диск по умолчанию
- Визуальные якоря жанра «городская магия и сверхспособности», платформенные визуальные стратегии жанра, жанровые запреты

## Пояснение миграции

- Исходный Prompt сохранён как входной Prompt, не удаляется
- Общая основа способности принадлежит `общий-проектирование-промптов-для-обложки`
- Визуальные границы жанра «городская магия и сверхспособности» и платформенные жанровые различия принадлежат `общий-проектирование-промптов-для-обложки`
- Если позже этот Prompt будет сокращаться дальше, повторяющееся содержимое можно удалять только после подтверждения, что соответствующие правила уже попали в Skill / references; запрещено «сначала удалить, потом дополнить»

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящие платформенные стратегии обложек, правила безопасности текста, шаблоны вывода и жанровые визуальные правила нужно читать в соответствующем жанровом Skill и исполнять там.
