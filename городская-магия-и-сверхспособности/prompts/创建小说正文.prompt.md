# Городские тайные искусства и сверхспособности ｜ Создание основного текста

## Входной навык (обязательно)

При срабатывании этого Prompt необходимо сначала загрузить и использовать: `通用-创建小说正文`

Этот жанровый Skill принял основные правила прежнего толстого Prompt, ограничения входа / выхода, нормы записи файлов, шаблоны `## 作者有话说` («Слово от автора») / эпиграфа главы / `## 章节后记` («Послесловие к главе»), а также специфичные жёсткие ограничения жанра и примеры приёмов.

## Цепочка комбинирования по умолчанию

- Контроль перед письмом и непрерывность: `通用-管理连续性冷热线` + `通用-生成章节控制卡`
- Постановка основного текста: в первую очередь принимает `通用-执行场景单元`; для глав с плотными диалогами дополнительно `通用-执行对话冲突`; для глав с «прилипанием к лицу» в микропространстве дополнительно `通用-执行微空间受限场景`
- Локальное усиление: по необходимости вызывать `通用-强化章节开头`, `通用-强化章末钩子`
- Очистка чистового текста: по необходимости вызывать `通用-正文润色`
- При явном шаблонном тоне / «неживом голосе»: дополнительно вызывать `通用-去AI味重写`

Prompt не может в обход жанрового Skill напрямую вызывать общий Skill.

## Использование по умолчанию

- Задача по умолчанию: написать с нуля / переписать / расширить основной текст сериальных глав жанра городских тайных искусств и сверхспособностей / чудес
- Продукт по умолчанию: основной текст главы + `## 作者有话说` + `## 章节后记`
- Запись по умолчанию: прямая запись обратно в целевой файл Markdown; если пользователь не уточнил, перезаписывать или дописывать, придерживаться консервативной стратегии
- Каталог основного текста по умолчанию: `小说正文/`; если пользователь указал другой каталог или платформенную версию, ориентироваться на требование пользователя

Если пользователю нужно лишь локальное спасение, не обязательно гнать всю цепочку:

- Исправить только начало → `通用-强化章节开头`
- Исправить только концовку → `通用-强化章末钩子`
- Только тщательная доводка всей главы → `通用-正文润色`
- Главная проблема — дух ИИ / шаблонный тон → `通用-去AI味重写`
