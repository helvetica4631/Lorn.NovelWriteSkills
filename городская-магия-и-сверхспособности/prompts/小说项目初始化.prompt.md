# Инициализация романного проекта

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-小说项目初始化`.

Этот Prompt — единый вход инициализации жанра «городская магия и сверхспособности». Жанровый Skill загружает специфичную для жанра систему сверхъестественных правил, проектирование якорей реальности, деление уровней силы и платформенные предпочтения адаптации, затем маршрутизирует в `通用-小说项目初始化` для исполнения семимерной общей рамки.

Prompt не имеет права, минуя жанровый Skill, «голо» использовать общие правила инициализации.

## Обязанности, которые остаются только у этого Prompt

- Единый вход инициализации жанра «городская магия и сверхспособности»
- Сохраняет минимальный вход, норму по умолчанию, минимальные ограничения исполнения и минимальное пояснение сдачи
- Маршрутизирует основные правила инициализации в `通用-小说项目初始化` → `通用-小说项目初始化`

## Минимальный вход

- Название текущего произведения (если уже есть)
- Целевая платформа (по умолчанию из `Agents.md` в корне проекта берётся основная платформа вывода)
- Имеющиеся зачаточные материалы: черновик аннотации, вход в ключевой сеттинг, черновик сверхъестественного сеттинга или черновик плана (предоставить как минимум один из них)
- Если есть: отчёт анализа конкурентов, отчёт исследования письма и т. п. — также следует процитировать
