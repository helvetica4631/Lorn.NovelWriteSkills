# Написание биографии персонажа

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-设计人物传记`.

Если биографии персонажа нужно сначала свериться с позиционированием жанра или обязанностями грани истории, можно по необходимости дополнительно вызвать: `通用-设计题材定位框架`, `通用-设计故事面`.

Prompt отвечает только за вход и требования записи на диск, а общие способности биографий персонажей и границы жанра единообразно принимает жанровый Skill.

## Обязанности, которые остаются только у этого Prompt

- Единый вход задач биографий персонажей
- Сохраняет авторское позиционирование, минимальный вход, стратегию записи и требования записи на диск трёхуровневого индекса
- Маршрутизирует основные правила в `通用-设计人物传记`

## Минимальный вход

- Имя персонажа
- Уровень персонажа: ключевой / важный / второстепенный
- Путь к текущему файлу или намерение «создать нового персонажа»
- Реальная личность / профессия
- Ключевой мотив и цена (если известны)

## Минимальные ограничения исполнения

- Биография по умолчанию — авторский источник суждения / руководство по вызову, а не краткая биография для читателя
- По умолчанию записывать в `人物传记/имя персонажа.md`
- Если пользователь не уточнил, по умолчанию консервативно дописывать «Правка этого раунда (YYYY-MM-DD)»
- Обязательно реально записывать в файл зацепки письма и индекс трёхуровневого плана, а не только показывать в чате
- При обнаружении конфликта с трёхуровневым планом обязательно явно пометить `⚠️ Потенциальное противоречие`

## Выдача по умолчанию

- Файл биографии персонажа создан или обновлён
- Пояснено, принята ли стратегия перезаписи или дописывания
- Пояснено, обновлён ли индекс соответствия сюжета трёхуровневого плана
- В диалоге только структурированная квитанция, без длинной вставки основного текста биографии

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `异能志怪-设计人物传记` и его общее ядро, и больше не ведётся параллельно в этом Prompt:

- Полный структурный шаблон биографии персонажа
- Перечень авторских зацепок и правила записи файла на диск
- Психологическая арка, трёхуровневый индекс и процесс проверки
- Дополнения по новаторскому проектированию персонажей, жанровые зацепки и точки приземления тревоги эпохи
- Правила проверки согласованности жанровых персонажей с планом / реестром

## Напоминание одной фразой

Этот Prompt сейчас — **слой входа**; настоящие шаблоны биографий персонажей, правила индекса, зацепки письма и патчи жанра необходимо читать и исполнять в соответствующих Skill.
