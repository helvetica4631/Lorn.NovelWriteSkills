# Единый промпт вывода «версии для Qimao» романа в жанре «городская магия и сверхспособности»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【городская магия и сверхспособности】, лучше подходящую контексту платформы Qimao: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя цепочку правил, быструю обратную связь и ощущение цены.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/创建小说正文.prompt.md`
- `.github/prompts/正文润色.prompt.md`
- `.github/prompts/去AI味.prompt.md`

### 1.2 Жанровый вход

- `.github/skills/异能志怪-输出七猫版/SKILL.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出七猫版` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку правил, опорные точки реальности и нулевое добавление фактов, затем усилить для Qimao: сильное продвижение, быструю обратную связь и цепкость продолжения чтения.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов ломать цепочку правил и цепкость платформы.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `七猫/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Нельзя писать «городскую магию и сверхспособности» как парящую сюаньхуань-爽-прозу или пустую рукопись без цены.

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».

В этом проходе дополнительно усвоены ключевые моменты: эмпатия к низам, управляемые способности, точки 爽 с ценой и более плотные поэтапные награды.
