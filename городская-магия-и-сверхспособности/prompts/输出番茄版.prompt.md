# Вывод версии для Fanqie

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-输出番茄版`.

## Обязанности, которые остаются только у этого Prompt

- Сохранить обнаруживаемость платформенного входа
- Сохранить минимальный корневой каталог вывода и структурные ограничения
- Направить общие положения платформы и жанровые патчи в соответствующие Skill

## Минимальные ограничения совместимости

- Корень каталога вывода: `番茄小说/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Руководствоваться «диапазоном знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`- Сначала нужно адаптировать под платформу, и лишь затем снижать схожесть
- Нельзя писать «городскую магию и сверхспособности» как парящую сюаньхуань-прозу или 爽-прозу без цены

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `异能志怪-输出番茄版` и её общую основу:

- Общие ограничения платформы
- Границы жанра и источники
- Детали исполнения и жанровые патчи
- Отображение исправлений на уровне разделов и возврат детальных правил
- Для Fanqie: семисекундная цепкость, вынос аномалии вперёд в первые 300 знаков, лёгкая стимуляция при сильной эмпатии и усиление цепочки цены

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящие правила платформы Fanqie и жанровые патчи «городской магии и сверхспособностей» нужно читать в соответствующих Skill и исполнять там.
