## Статус миграции (жёстко)

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【городская магия и сверхспособности】, лучше подходящую контексту Baidu Baijiahao: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя цепкость распространения, чувство правил и опорные точки реальности.

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出百度百家号版` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку правил, опорные точки реальности и нулевое добавление фактов, затем усилить для Baijiahao цепкость распространения и плавность подачи информации.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов писать в тоне новостной сводки.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `百度百家号/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».

В этом проходе дополнительно усвоены ключевые моменты: проявление ценных слов, удобных для поиска, региональные опорные точки, аномалия, пригодная для распространения, и плавный ритм сканирующего чтения.
