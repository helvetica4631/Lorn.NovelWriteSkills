# Вывод версии для Zhihu

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-输出知乎版`.

## Обязанности, которые остаются только у этого Prompt

- Сохранить обнаруживаемость платформенного входа
- Сохранить минимальный корневой каталог вывода и структурные ограничения
- Направить общие положения платформы и жанровые патчи в соответствующие Skill

## Минимальные ограничения совместимости

- Корень каталога вывода: `知乎/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Руководствоваться «диапазоном знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`- Заголовок должен соответствовать склонности Zhihu к постановке вопроса / фразе-правилу / фразе-цене
- Нельзя писать «городскую магию и сверхспособности» как текст-объяснение концепции или каталог странных историй

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `异能志怪-输出知乎版` и её общую основу:

- Общие ограничения платформы
- Границы жанра и источники
- Детали исполнения и жанровые патчи
- Отображение исправлений на уровне разделов и возврат детальных правил
- Ощущение личного опыта от первого лица / глубокой ограниченной точки зрения, приоритет повышения познания, проверяемая фактура и привязка к реальным профессиям

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящие правила платформы Zhihu и жанровые патчи «городской магии и сверхспособностей» нужно читать в соответствующих Skill и исполнять там.
