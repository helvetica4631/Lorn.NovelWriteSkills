# Единый промпт вывода «версии для Douban» романа в жанре «городская магия и сверхспособности»

## Статус миграции (жёстко)

Переписать входную главу в версию 【городская магия и сверхспособности】, лучше подходящую контексту Douban Read: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя фольклорную фактуру, опорные точки реальности и послевкусие.

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出豆瓣版` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку правил, опорные точки реальности и нулевое добавление фактов, затем усилить для Douban послевкусие, недосказанность и фольклорную фактуру.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов разрушать костяк жанра.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `豆瓣/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Нельзя писать «городскую магию и сверхспособности» как текст с одной лишь литературностью, без каркаса правил

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».

В этом проходе дополнительно усвоены ключевые моменты: ощущение старых вещей региональных обычаев, вход через микроаномалию, приоритет повышения познания и лёгкая недосказанность при работе с реальными общественными темами.
