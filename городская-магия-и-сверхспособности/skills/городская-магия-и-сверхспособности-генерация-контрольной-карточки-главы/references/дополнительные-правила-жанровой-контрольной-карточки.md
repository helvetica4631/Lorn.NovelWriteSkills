# Дополнительные правила жанровой контрольной карточки

## I. Минимальные поля контрольной карточки для «Городской магии и сверхспособностей»

Помимо общих полей контрольной карточки, в главах жанра «Городская магия и сверхспособности» по умолчанию нужно явно прописывать ещё и:

- **Якорь реальности**: в каком профессиональном действии / бытовом пространстве / институциональной процедуре разворачивается эта глава.
- **Сигнал аномалии**: то «не то», что читатель замечает с первого взгляда.
- **Носитель доказательства**: самая важная в этой главе вещдок-улика / документ / запись / номер / журнал.
- **Эскалация цены**: что именно теряет в этой главе главный герой / команда / связанные персонажи.
- **Ошибка в правиле / проверка правила**: откуда берётся интеллектуальная награда главы.

## II. Приоритеты награды в середине главы для контрольной карточки

Выбирайте из следующих четырёх типов, не рекомендуется оставлять пусто:

1. Награда за продвижение информации
2. Награда за то, что правило проверено или получило контрудар
3. Награда за смену позиций в отношениях
4. Награда за поэтапное смягчение тупика реальности

Если в середине главы только «продолжаем расследовать / продолжаем нагнетать», этого, как правило, недостаточно.

## III. Формула разбиения на сценические единицы (жанровая версия)

Если в главе 3–5 сценических единиц, разбивайте в первую очередь по такой формуле:

1. Вход через знакомое действие из реальности
2. Проявление микроаномалии
3. Первое суждение / ошибочное суждение
4. Продвижение доказательства или правила
5. Цена и завершение крючком

Не требуется, чтобы в каждой главе были все пять частей, но должно быть видно, что давление меняется, а не размазано ровным слоем.

## IV. Места, где проще всего рухнуть

- Есть одна атмосфера, нет доказательств.
- Есть одна аномалия, нет почвы реальности.
- Есть один крючок в конце главы, нет выплаты в середине.
- Есть одно продвижение основной линии, нет возвращения холодной линии или касания отношений.
- Есть одни термины правил, нет действий и последствий.
