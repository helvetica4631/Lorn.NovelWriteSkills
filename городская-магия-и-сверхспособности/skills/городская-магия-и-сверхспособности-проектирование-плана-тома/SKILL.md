# Проектирование плана части / плана тома

Это жанровая обёртка и совместимый вход. При срабатывании этого навыка **в первую очередь обязательно принудительно загрузить** текущий жанровый Skill и `общий-проектирование-плана-тома`; текущий жанровый Skill отвечает за жанровые критерии и границы вердикта, `общий-проектирование-плана-тома` — за общий каркас и общий процесс.

## Жанровые дополнительные границы

- Помимо «полной реализации», уровень тома должен продолжать в первую очередь прописывать: сцены реальности, сигналы аномалии, прослеживаемые доказательства, эскалацию цены и непрерывную награду внутри тома.
- План главы по умолчанию должен учитывать городские микропространства и отказ знакомых систем, а не только абстрактную детективную структуру.
- Если внутри тома есть лишь продвижение событий, но нет чувственных зацепов, контрдействий правил, раскола отношений или награды за цену, норма жанра «Городская магия и сверхспособности» ещё не закреплена.
- Том — это не просто нарезка общего плана на мелкие кусочки, а подлинный перевод общего плана на язык «зачем этот том читать, чем он будет болеть, какую награду принесёт».
## Дополнение по развёртыванию схем уровня тома в жанре «Городская магия и сверхспособности»

- Классический ритм томов **единица-дело + повышение правил**: том 1 — «первое дело + вход в правила» (замкнуть первое сверхъестественное событие, утвердить существование системы правил и базовый способ работы с ней), том 2 — «сложное дело + углубление правил» (события сложнее, система правил раскрывает больше слоёв), том 3 — «личное дело + проявление цены» (события бьют прямо по самому герою, цена применения правил растёт), финальный том — «развязка + окончательное проявление правил».
- **Ярлыки схем каждого тома**: том 1 в основном «расшифровка и расследование» (формирует профессиональные способности героя и познание правил), средние тома могут переключаться на «повышение и зачистку монстров» (главы с наслаждением от подавления правилами) и «закулисного злодея» (продвижение основной линии), финальный том возвращается к ядру «разгадывания загадки».
- **Межтомное продвижение на уровне «правил»**: каждый том должен продвигать систему правил на шаг вперёд — том 1 раскрывает правило A, том 2 раскрывает цену / ограничения правила A, том 3 раскрывает правило B (связанное с A, но не просто его повышение).
- Если зарегистрирован шаблон-образец произведения (с §18 «отпечатки схем»), развёртывание схем уровня тома должно в первую очередь опираться на временную линию схем образца, особенно на моменты переключения образца между четырьмя этапами «раскрытие правила → применение правила → цена правила → преодоление правила».
## Обязательные требования

- Нельзя в обход `общий-проектирование-плана-тома` писать другой параллельный набор общих правил.
- При ссылке на общие способности ссылаться только по названию, без пути.
- Если внутри тома задача затрагивает ещё и согласованность персонажей, увязку с журналами или питание единицами-делами, при необходимости продолжайте загружать `городская-магия-и-сверхспособности-проектирование-биографии-персонажей`, `городская-магия-и-сверхспособности-проектирование-реестра-улик-и-завязок`, `городская-магия-и-сверхспособности-проектирование-движка-событий-и-дел`.
- Из каждого тома как минимум должно получаться спустить цепочку продолжения чтения первых 5 глав и несколько контрольных карточек глав; если это невозможно, значит, план тома по-прежнему остаётся на уровне обзора.

## Справочник частых триггерных слов / формулировок пользователя

## Когда использовать

Когда задача относится к любому из следующих случаев, загрузить и следовать этому Skill:

- Проектирование подробного плана какой-то части.
- Проектирование плана тома, карты тома, списка глав какого-то тома.
- Разбиение общего плана на блоки сюжета, сюжетные линии, сюжетные точки.
- Проектирование цепочки запуска внутри тома, таблицы расстановки точек 爽, таблицы ритма 5/15, микросценариев глав.
- Изменение `小说大纲/故事面/*.md`, файлов плана частей, файлов плана томов, файлов типа «список глав».

> Сначала соблюдайте общие правила входного Prompt; структура, шаблоны и пункты проверки, специфичные для уровня части / тома, определяются этим Skill.

## Разделение обязанностей с общим Skill

- Полная реализация вышестоящего уровня, послойное принятие норм, источник целевого объёма, пересчёт «около 3000 знаков на главу», единственность списка глав как чертежа, строгая согласованность микросценариев по главам, основной шаблон тома и список аудита — всё единообразно по `общий-проектирование-плана-тома` и его общим references.
- Этот жанровый слой по-прежнему лишь дополняет специальные границы жанра «Городская магия и сверхспособности»: сцены реальности, сигналы аномалии, прослеживаемые доказательства, чувственные зацепы, тройную связку правило / доказательство / цена, давление городских микропространств, непрерывную награду внутри тома.
- `references/migrated-part-volume-outline-rules.md` сохраняется как верная копия исходного текста; если в ней встречается жанро-независимый общий каркас, при исполнении сущностью способности считается общий основной шаблон, а границами оболочки — жанровые дополнительные правила.
- Если новое правило можно использовать между жанрами, его необходимо в первую очередь вернуть в `общий-проектирование-плана-тома`, а не продолжать параллельно вести на жанровом уровне.

## Минимальная поставка

- Уровень части: на базе общего каркаса дополнительно ответить, как эта часть распределяет по блокам сюжета и межтомному продвижению якоря реальности, сигналы аномалии, проявление правил, продвижение доказательств и эскалацию цены.
- Уровень тома: на базе общего основного шаблона дополнительно ответить, как для каждой главы складываются сцена реальности, укол аномалии, прослеживаемое доказательство, эскалация цены и непрерывная награда внутри тома.
- Ключевые главы должны допускать дальнейший спуск до микросценариев по главам; если нужно продолжать работу, ниже по цепочке можно комбинировать `общий-исполнение-сценической-единицы`, `городская-магия-и-сверхспособности-генерация-контрольной-карточки-главы`.
- Из каждого тома как минимум должно получаться спустить цепочку продолжения чтения первых `5` глав и несколько контрольных карточек глав; если это невозможно, значит, план тома по-прежнему остаётся на уровне обзора.

## Запреты

- Нельзя восстанавливать в этом Skill целый параллельный общий шаблон.
- Нельзя писать лишь абстрактную детективную структуру, не прописывая якоря реальности, сигналы аномалии, прослеживаемые доказательства и эскалацию цены.
- Нельзя допускать, чтобы внутри тома было лишь продвижение событий, без чувственных зацепов, контрдействий правил, раскола отношений или награды за цену.
- Нельзя писать микросценарии по главам лишь парой фраз краткого содержания, не формируя исполнимую версию, которую можно дальше воплотить в тексте.

## Граница с Skill общего плана

Этот Skill отвечает лишь за жанровую **обёртку уровня кампании / тактики и граничные дополнения**:

- План части
- План тома
- Список глав
- Микросценарии глав
- Цепочка продолжения чтения уровня тома, таблица точек 爽, таблица ритма

Если пользователь просит спроектировать:

- Продающие точки всей книги
- Основную загадку `M0`
- Важные побочные линии `X01-XNN`
- Матрицу единиц-дел `C01-CNN`
- Финальное замыкание и межтомный общий баланс

Переключитесь на `городская-магия-и-сверхспособности-проектирование-общего-плана`.
