# Таблица заезженных слов жанров «культивация / фэнтези»

> Источник: усвоено из железных языковых правил InkOS `xuanhuan.md` + `xianxia.md` и исследования высокочастотных слов «машинного» письма
> Область применения: жанры «Городская магия и сверхспособности», «культивация / фэнтези»
> Способ использования: при создании активно избегать, при рецензировании сканировать превышения
> Норма контроля: не более 2 раз на тысячу знаков

## Усталые слова первого уровня (высокий приоритет, по возможности не использовать)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| 暴涨 («резко вырос») | Универсальное слово повышения, прямо запрещённое InkOS | Писать конкретный прирост или телесное ощущение (с двенадцати нитей до восемнадцати / даньтянь распирает до боли) |
| 海量 («огромное количество») | Костыль, позволяющий пропустить расчёт чисел | Писать конкретное число и бремя (мешок для хранения забит до отказа / переплавка идёт три дня, а осталась ещё половина) |
| 难以估量 («не поддаётся оценке») | То же, нулевая информативность | Передавать через реакцию окружающих или среды (зеваки втянули воздух сквозь зубы / земля треснула на три чи) |
| 恐怖如斯 («до чего страшен») | Шаблон восклицания, уже сильно заезженный | Удалить всю фразу, выразить через конкретное последствие |
| 一声冷哼 («холодное фырканье») | Стандартный выход в жанре «фэнтези», одинаков везде | Писать конкретную деталь лица или голоса (из носа вырвался короткий звук / слова будто выдавливались сквозь зубы) |

## Усталые слова второго уровня (средний приоритет, контролировать частоту использования)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| 嘴角溢出鲜血 («из уголка рта хлынула кровь») | Шаблонность описания ранения | Писать конкретное ранение (половина рукава пропиталась кровью / губы сплошь в кровавых трещинах) |
| 身形一闪 («фигура мелькнула») | Лень в описании действия | Писать конкретный путь движения и эффект (под ногой разбилась синяя плитка / остаточный образ ещё стоял на месте) |
| 一股强大的气息 («мощная аура») | Абстрактное объявление силы | Писать конкретный чувственный удар (воздух вдруг стал тяжёлым / в дыхании появился привкус ржавчины) |
| 灵魂深处 («глубины души») | Универсальное слово | Конкретизировать (даньтянь / море сознания / самая нижняя картина памяти) |
| 无法想象 («невозможно представить») | Костыль, позволяющий пропустить описание | Прямо описывать конкретную картину, которую читатель может представить |

## Усталые слова третьего уровня (вспомогательный, обрабатывать только при плотном появлении)

| Усталое слово | Пояснение |
| -------- | ------ |
| 竟然/居然 («неожиданно / вопреки ожиданиям») | Маркер чрезмерного удивления, в главе не следует употреблять более 2 раз |
| 突然/猛地 («вдруг / резко») | Маркер дешёвого поворота; при подряд идущем употреблении обнажается потеря контроля над ритмом |
| 瞬间/顷刻 («мгновенно / в одно мгновение») | Слишком частые временные маркеры ослабляют ощущение времени |
| 滔天/滔天巨浪 («до небес / исполинские волны до небес») | Чрезмерная образность, заменить конкретным масштабом |
| 毁天灭地 («разрушить небо и землю») | Гиперболическое выражение уже утратило силу удара |

## Запретная зона чисел в «фэнтези» (производное от числовых правил InkOS)

Следующие три типа выражений запрещено использовать в тексте вместо расчёта чисел:

1. **Расплывчатый прирост**: «暴涨» («резко вырос»), «飙升» («взлетел»), «剧增» («резко возрос») → обязательно давать конкретное число
2. **Расплывчатый запас**: «海量» («огромное количество»), «海量资源» («огромные ресурсы»), «无尽» («бесконечный») → обязательно давать конкретную партию / количество
3. **Расплывчатое сравнение**: «远超» («намного превосходит»), «难以企及» («недосягаемо») → должно быть прослеживаемо и проверяемо

## Принципы обработки усталых слов

1. **Слов первого уровня в основном тексте должно быть близко к нулю**.
2. **Слов второго уровня — не более 1 раза на тысячу знаков**.
3. **Слова третьего уровня обрабатываются только при непрерывном плотном появлении**.
4. **Не дублировать правоприменение «запретной зоны чисел»**: числовые проблемы — структурные, они решаются числовыми правилами `правила-жанров-культивации-и-фэнтези-inkos.md`.
