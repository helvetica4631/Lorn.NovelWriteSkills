# Дополнение карточки исполнения удаления ИИ-привкуса (городская магия и сверхспособности)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/общий-устранение-духа-ии/references/шаблон-многораундовой-диагностики-устранения-ии.md`

## 1. Пункты дописывания для городской магии и сверхспособностей

- Термины границ правил и цены не должны быть стёрты при удалении привкуса.
- Опорные точки реальности (профессия / пространство / институты) не должны абстрагироваться.
- Поля улик, награда в середине, крючок конца главы — жёстко сохраняемые «гвозди».

## 2. Дополнительные пункты приёмки

- [ ] После удаления привкуса по-прежнему с первого взгляда читается двойная дорожка «городская реальность + аномальный механизм».
- [ ] Голоса персонажей разведены, нет отката к единому объясняющему тону.
- [ ] Полнота информации не принесена в жертву ради выкрутасов предложений.
