# Шлифовка основного текста: городские сверхспособности / мистика

Это жанровая обёртка и совместимый вход. При срабатывании этого навыка **в первую очередь обязательно принудительно загрузить** текущий жанровый Skill и `общий-шлифовка-основного-текста`; текущий жанровый Skill отвечает за жанровую рамку и границы вердикта, `общий-шлифовка-основного-текста` — за общий каркас и общий процесс.

## Жанровые дополнительные границы

- При шлифовке обязательно продолжать защищать швы реальности, профессиональные действия, границы правил и сверхъестественную цену, нельзя гнаться лишь за гладкостью.

- Если основной текст написан по контрольной карточке, при шлифовке также нужно проверять, не вымыты ли и не искажены ли цель главы, награда в середине и крючок конца главы из контрольной карточки.

## Требования к исполнению после подъёма общего (обязательно)

При попадании в задачу «шлифовка основного текста / тонкая доводка глав» **обязательно в первую очередь принудительно загрузить**:

- `общий-шлифовка-основного-текста`
- `references/project-specific-polish-rules.md`
- Перед тем как приступать к шлифовке, обязательно внимательно прочитать биографии персонажей, фактически появляющихся в этой главе, а также документы настроек истории / фоновых настроек, связанные с фоном, техникой, правилами, уликами, процедурной цепочкой и цепочкой способностей этой главы.
- Нельзя «рубить» лишь по жанровому чутью, следам прошлого раунда правки, отдельным фрагментам или резюме рецензии; если ключевой источник вердикта отсутствует, сначала нужно его восполнить, найти или явно заблокировать, и лишь затем продолжать шлифовку.

Из них:

- `общий-шлифовка-основного-текста` отвечает за общий процесс, общие проверки, действия на уровне предложений, расширенную маршрутизацию и контроль погружения
- `project-specific-polish-rules.md` отвечает за швы реальности, границы правил, городскую фактуру и интонацию городских аномальных техник в жанре городской магии и сверхспособностей

- «Тонко доведи слог, не отшлифуй в инструкцию»

## Когда использовать

Когда задача относится к любому из следующих случаев, загрузить и следовать этому Skill:

- Структура главы в основном пригодна, но язык, ритм, кадровость ещё недостаточно сильны.
- Нужно повысить фактуру основного текста **без добавления фактов и без изменения ключевого сюжета**.
- Нужно усилить хватку начала главы, награду в середине, крючок конца главы и голоса персонажей.
- Нужно превратить «пояснения настроек / эмоциональные обобщения / объяснения процедур» в более естественный и пригодный для съёмки текст.

## Случаи, когда не применяется

Следующие задачи не должны выполняться этим Skill в одиночку:

- **Чистая диагностика / осмотр / решение о переделке** → передать `городская-магия-и-сверхспособности-рецензия-текста-главы`
- **Чистое удаление ИИ-привкуса / удаление шаблонного тона / ревизия достоверности** → передать `городская-магия-и-сверхспособности-устранение-духа-ии`
- **Структурная перестройка плана / переделка дела единицы / изменение ритма уровня тома** → передать Skills по плану или проектированию дел

## Основная задача этого Skill

1. При **нулевой потере информации** сделать основной текст глаже, точнее, более цепляющим.
2. Защищать и выпячивать:
   - Аномалию / конфликт / разрыв интриги в первых 2–3 абзацах
   - Хотя бы одно реальное продвижение / награду в середине
   - Крючок конца главы подписочного уровня
3. Повышать кадровость, швы реальности, действия персонажей и узнаваемость диалога.
4. Пусть правила, улики, процедуры и цена появляются так, чтобы «читатель мог ощутить», а не писать как инструкцию.
5. Когда слабое место абзаца очевидно, вызывать соответствующие справочные материалы по слабому месту, а не прочитывать все справочные файлы разом.

## Принципы использования расширенных справочников

- Общие слабые места — язык / действие / психика / сцена / пейзаж / статика / портрет — единообразно идут через расширенную маршрутизацию `общий-шлифовка-основного-текста`.
- Жанровый слой отвечает лишь за суждение, не задевают ли эти общие способы исправления швы реальности, границы правил и интонацию городских аномальных техник жанра.
- Запрещено возвращать общие проблемы на жанровый слой параллельного сопровождения.

## Порядок выполнения

1. **Сначала подтвердить охват и интенсивность**: вся глава / сцена / абзац; лёгкая / средняя / тяжёлая шлифовка; какие предложения или информацию ни в коем случае нельзя трогать.
2. **Сначала определить тип слабого места, затем решить, читать ли расширенные справочники**:
   - Окоченевший диалог / однообразная лексика → идти по ветке «язык»
   - Пустое действие / сцена не движется → идти по ветке «действие»
   - Слишком понятийные эмоции / психика не прилегает → идти по ветке «психика»
   - Групповая сцена / конфликт на месте беспорядочный или плоский → идти по ветке «сцена»
   - Пространство не состоялось / атмосфера слишком пуста → идти по ветке «пейзаж» или «статика»
   - Внешность персонажа, усталость, профессиональные следы бледны → идти по ветке «портрет»
   - Если нужна конкретная соответствие, прочитать `references/extended-reference-routing.md`
3. **Первый проход: калибровка содержания и обещания**
   - Сверить факты, обращения, время, поля улик и границы правил.
   - Определить, какова основная награда, обещанная главой читателю, нельзя, чтобы шлифовка делала всё пустее.
4. **Второй проход: ритм и проявление награды**
   - Усилить хватку начала главы.
   - Проявить уже имеющиеся награды в середине, бреши, ответные удары, сборку улик.
   - Сделать крючок конца главы конкретнее, а не лиричнее.
5. **Третий проход: тонкая доводка на уровне предложений и голоса персонажей**
   - Переписать пояснительные, обобщающие, пустые эмоциональные предложения в действия, ощущения, предметы, паузы.
   - Растянуть ритм длинных и коротких предложений, избегая, чтобы абзац походил на инструкцию или дикторский текст.
   - Пусть способы речи разных персонажей действительно разойдутся.
6. **Четвёртый проход: повторная проверка деталей и красных линий выпадения из погружения**
   - Проверить, не вымыты ли швы реальности, профессиональные действия, термины правил.
   - Очистить авторские номера, выражения вроде «в предыдущих главах / в следующей главе» на уровне повествования и другие выбивающие из погружения выражения.
   - Проверить, сохранился ли в основном тексте ритм продолжения чтения серийного выпуска Qidian.

## Требования к сверке с контрольной карточкой

- Если у главы есть готовая контрольная карточка, при шлифовке по умолчанию нужно оглянуться: не ушла ли цель главы, не ослабла ли награда в середине, не закруглён ли крючок конца главы.
- Шлифовка — не превращение стройплощадки в образцовую квартиру, а усиление функции и повышение достоверности фактуры.

## Формулировки вывода по умолчанию

- Если пользователь просит «отшлифуй эту главу / тонкая доводка основного текста» без ограничения локального охвата, по умолчанию обрабатывать как **формальную шлифовку всей главы с записью обратно в файл**, а не просто выкладывать в чате целый готовый вариант.
- Если пользователь явно говорит «сначала покажи образец / не записывай в файл», выполнять лишь шлифовку уровня образца.
- При выводе резюме в первую очередь пояснять:
  - Какую главу / какой абзац отшлифовали
  - Какие зацепки в основном усилены (начало / середина / крючок / эмоции / диалог)
  - Обновлены ли синхронно пояснительные подразделы в исходном файле

## Границы с другими Skill / Prompt

- Этот Skill отвечает за **тонкую доводку главы**, а не за чистую рецензию и не за чистое удаление ИИ-привкуса.
- Когда основная проблема текста — «фальшивый тон, тяжёлый шаблон, реалистичность вымыта», нужно увязать с `городская-магия-и-сверхспособности-устранение-духа-ии`.
- Когда основная проблема текста — «структура не работает, остов главы сам не состоятелен», сначала сделать рецензию или переделку, не шлифовать насильно.
