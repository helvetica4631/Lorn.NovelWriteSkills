## Статус миграции (жёстко)

Этот Prompt теперь — тонкий вход и напоминание об оркестрации. При срабатывании этого входа дополнение платформенных исследований, детали исполнения, отображение исправлений на уровне разделов, канон слова от автора и границы жанра обязательно должны дальше маршрутизироваться и диспетчеризироваться через `общий-вывод-webnovel`; этот файл больше не несёт роль основного носителя платформенных деталей.

Переписать входную главу в английскую версию 【Городская офисная проза】, лучше подходящую для WebNovel: сохранить ключевую информацию, соблюдать шлюзы английской платформы, выводить в правильный каталог, сохраняя цепочку замыкания причинности, ощущение давления реальности и кросс-культурную читаемость.

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `общий-вывод-webnovel`; этот общий Skill принудительно продолжает чтение своих жанровых references и соответствующих общих Skill.
3. Через жанровый Skill зафиксировать цепочку расследования, реальные процедуры, честность доказательств и жанровые патчи, одновременно унаследовав общие положения и шлюзы английской платформы.
4. Сначала сохранить жанровый каркас и нулевое добавление фактов, затем заняться англизацией и усилением ритма, и лишь в последнюю очередь — снижением схожести.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `WebNovel/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)
- `Len` основного текста не ниже 6500
- Кроме строки `## 作者有话说`, китайского / CJK быть не должно
- Нельзя писать «Городскую офисную прозу» как английскую триллерную оболочку с одной лишь атмосферой, без каркаса расследования
