# Единый промпт вывода «версии для издательства» романа жанра «Городская офисная проза»

## Статус миграции (жёстко)

Этот Prompt теперь — тонкий вход и напоминание об оркестрации. При срабатывании этого входа дополнение платформенных исследований, детали исполнения, отображение исправлений на уровне разделов, канон слова от автора и границы жанра обязательно должны дальше маршрутизироваться и диспетчеризироваться через `общий-вывод-издательство`; этот файл больше не несёт роль основного носителя платформенных деталей.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【Городская офисная проза】, ближе к вкусу издательской рецензии: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя логическое замыкание, фактуру реального расследования и нагрузку на персонажей.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/создание-основного-текста.prompt.md`
- `.github/prompts/шлифовка-основного-текста.prompt.md`
- `.github/prompts/устранение-духа-ии.prompt.md`

### 1.2 Жанровый вход (дальше маршрутизируется через Skill)

- `.github/skills/городской-офис-вывод-издательство/SKILL.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `общий-вывод-издательство`; этот общий Skill принудительно продолжает чтение своих жанровых references и соответствующих общих Skill.
3. Сначала сохранить цепочку дела, реальную логику и нулевое добавление фактов, затем усилить сдержанное выражение в издательском духе, жанровость и удобство для рецензента.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов ломать устойчивость структуры.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `出版社/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `общий-вывод-*/SKILL.md`
- Нельзя писать «Городскую офисную прозу» как пустую рукопись с одной лишь издательской интонацией, без каркаса дела

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, дополнение платформенных исследований, патчи исполнения, отображение исправлений на уровне разделов, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
