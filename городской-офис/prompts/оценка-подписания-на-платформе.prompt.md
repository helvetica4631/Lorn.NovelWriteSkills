# Оценка вероятности подписания контракта с платформой

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-оценка-подписания-на-платформе`.

Если вход-Prompt противоречит правилам этого Skill, приоритет имеют правила оценок, вето и потолков из Skill и его references.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом оценки вероятности подписания контракта с платформой
- Сохраняет режим оценки, минимальный перечень материалов, запись основного отчёта на диск и минимальный порядок вывода
- Направляет основные правила оценивания в `общий-оценка-подписания-на-платформе`

## Минимальный вход

- Название произведения / продающий пункт одним предложением / аннотация
- Материал начала: пробные главы основного текста или план начала
- Настройки главного героя
- Механика аномалий / технологий / правил
- Материалы плана
- Если есть: биографии персонажей / сеттинг героев, ритм первых 10 глав / таблица запуска тома / микросценарии начала, имеющиеся выводы рецензий
- Информация об исполнении сериала (обновления / запас глав / способ подачи)
- **【Канон Qidian】** Если цель — внутренняя подача редактору Qidian, лучше дополнительно предоставить: ключевой образ героя / таблицу образов, а также достигнута ли уже единая линия подачи Qidian (`30000` знаков связного основного текста + `内投版总大纲〈最低5000字〉` + `内投版第1卷卷纲` + `内投版简介`).

## Минимальные ограничения исполнения

- Сначала обязательно определить: формальная оценка по основному тексту / предварительная оценка по плану
- При нехватке материалов обязательно заметно пометить «предварительная версия» и снизить уверенность
- Предварительная оценка по плану не вправе принимать «по замыслу будет написано» за «в основном тексте уже сделано»
- Пока материалы существуют, обязательно перекрёстно учитывать: название / аннотацию, пробные главы, персонажей, технологии / процедуры / правила, общий план / планы томов / ритм первых 10 глав, исполнение обновлений и имеющиеся выводы рецензий
- Вероятность обязательно давать диапазоном и по умолчанию выводить консервативным каноном реально низкой доли подписаний
- Отчёт по умолчанию обязательно записывается на диск в `审阅意见/{目标平台}/评估/`
- По умолчанию в первую очередь поддерживается один основной отчёт по одному и тому же произведению: обновлять с перезаписью, а не создавать параллельные ответвления
- При выводе сначала обязательно дать: сводный балл, диапазон вероятности, уверенность, рекомендацию по подаче
- При выводе сначала обязательно завершить: суждение быстрой оценки за 30 секунд / 3 минуты / 30 тысяч знаков, суждение о классификации дорожки, проверку вето / потолка, и лишь затем разворачивать подпунктные оценки
- **【Канон Qidian】** Нельзя прямо писать «достигнута единая линия подачи Qidian» как «рекомендуется подавать сейчас»; эти два утверждения нужно различать.

## Выдача по умолчанию

- Основной отчёт оценки подписания контракта с платформой записан или перезаписан по соответствующему пути
- В диалоге как минимум пояснить: какие ключевые материалы прочитаны, куда записан отчёт
- В отчёте обязательно должны быть: основа доказательств и слепые зоны суждения, имитация быстрой оценки платформы, проверка вето / потолка, подпунктные оценки, минимальный замкнутый цикл исправлений, чёткий вывод о действиях, рекомендации по пути подачи

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `городской-офис-оценка-подписания-на-платформе` и его общее ядро, и больше не ведётся параллельно в этом Prompt:

- Режим оценки и суждение о полноте материалов
- Общие измерения оценки, сегментация вероятности и правила вето
- Границы дорожки «Городской офисной прозы» на целевой платформе, золотые три главы, питание длинной линии и канон низкой доли подписаний
- Перекрёстная сверка доказательств, имитация быстрой оценки платформы, сохранение продающих точек, диагностика персонажей / доказательств / процедур / обещания первого тома
- Шаблон отчёта, правила записи на диск и канон квитанции
- Различение режимов: первая оценка после плана, повторная оценка основного текста и скрининг при нехватке материалов

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящий каркас оценки (общие правила платформы загружаются по целевой платформе), жанровый арбитражный канон и шаблон отчёта нужно читать в соответствующих Skill и исполнять там.
