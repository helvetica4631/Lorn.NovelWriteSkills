# Входной Prompt «проектирование сеттинга истории» жанра «Городская офисная проза»

## Маршрутизация жанровых навыков (обязательно)

Этот Prompt теперь отвечает лишь за **распознавание входа + маршрутизацию по умолчанию + минимальные ограничения записи обратно + пояснение о совместимости**.

При срабатывании этого Prompt необходимо сначала вызвать: `通用-设计故事设定`.

Если в этом проходе данных, поддерживающих сеттинг, недостаточно (нет конкурентов, нет знаний предметной области), по необходимости дополнительно вызвать: `通用-分析竞对作品`, `通用-深度研究`.

Если в этом проходе также затрагиваются питание единиц-событий, материнская схема аномальных событий, цепочки ложных следов и опровержений, по необходимости дополнительно вызвать: `通用-设计事件案件引擎`, `通用-设计线索伏笔与回收台账`. Prompt не вправе в обход жанрового Skill напрямую писать общие правила.

## Обязанности, которые сохраняются за этим Prompt

- Стабильно направлять задачу в `通用-设计故事设定` и при необходимости дополнительно подключать жанровые Skill продвижения событий / реестров.
- Закреплять, что продукт по умолчанию — **справочный документ авторской стороны**, а не научно-популярное пояснение для читателя.
- Закреплять, что результат по умолчанию записывается обратно в реальный справочный файл, а не остаётся длинным текстом в чате.
- Закреплять, что в чате делается лишь краткий отчёт: какой файл записан, перезапись или дополнение, согласовано ли с общим планом / реестром основной линии.

## Минимальные пункты подтверждения

Если пользователь не разъяснил, в первую очередь выяснить следующее:

1. Путь к целевому справочному файлу или название файла сеттинга, который нужно создать в этом проходе
2. Способ обработки: полная переработка / локальное дополнение / правка с исправлением
3. Нужно ли дополнительно увязывать питание единиц-событий или реестр зацепок и развязок
4. Разрешена ли запись обратно в файл напрямую (по умолчанию разрешена; исключение — только когда пользователь явно сказал «сначала обсудить, без записи в файл»)

## Основное содержимое, перенесённое в Skill

Следующие основные правила уже перенесены, и основной текст в этом Prompt параллельно больше не сопровождается:

- Каркас документа сеттинга истории, формулировка одной фразой, пакет кадров, пары «ложный след и опровержение»
- Цепочки доказательств, процедурное трение, канон полей, возможность подделки и границы безопасности
- Библиотека инновационных элементов, красные линии по этапам, развитие в длинной форме и логика развязок
- Китайский городской контекст, проверка согласованности между документами, стандарты качества и процесс верификации
- Дополнения жанра «Городская офисная проза»: процедурное трение, цепочки доказательств, канон нумерации, городское давление, ограждения увязки с питанием единиц-событий / реестрами

## Минимальные требования к исполнению

- В целевом файле как минимум должны появиться: формулировка одной фразой, ключевые пункты правил, путь ложного следа и опровержения, видимая цена, пригодный для написания пакет кадров.
- Если этот сеттинг входит в основную линию длинной формы, нужно также чётко прописать способ развития и развязки.
- При затрагивании высокорискованных деталей реальности необходимо использовать нарративизированное, оставляющее пробелы выражение, избегая формата учебника.
- Если пользователь явно не просит ограничиться обсуждением, формальный результат обязательно записывается в целевой Markdown-файл.

## Пояснение о сохранении верности при переносе

- Этот Prompt по-прежнему сохраняется как жанровый входной Prompt и не удаляется.
- Основные правила перенесены в `都市职场-设计故事设定` и `通用-设计故事设定`; если позже понадобится ещё сократить, повторяющиеся формулировки можно удалять только после подтверждения, что правила уже внесены в библиотеку.
- Если обнаружено, что правила жанровой стороны и общего слоя не согласуются, приоритет имеют действующие Skill / references, на которые ведёт маршрутизация жанрового Skill, и больше не нужно опираться на статический список путей из старого Prompt.
