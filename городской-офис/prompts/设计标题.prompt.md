# Проектирование заголовка

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-设计标题`.

Если для текущего варианта названия книги сначала нужно откалибровать жанровое позиционирование или главную ось граней истории, по необходимости можно дополнительно вызвать: `通用-设计题材定位框架`, `通用-设计故事面`; но итоговый процесс наименования должен идти через `通用-设计标题` как вход по умолчанию.

Prompt не вправе в обход жанрового Skill напрямую использовать общие правила названий.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом задач по названию книги жанра «Городская офисная проза»
- Сохраняет минимальный ввод, параметры по умолчанию, минимальное условие прерывания и напоминание о записи на диск
- Маршрутизирует основные правила в `通用-设计标题`

## Минимальный вход

- Название произведения (если уже есть)
- Уровень проектирования: `вся книга / часть / том`
- Целевая платформа (необязательно; если не указана — по умолчанию все платформы)
- Число кандидатов (необязательно; если не указано — по умолчанию по 10 на каждую платформу)

## Значения по умолчанию

- По умолчанию обработка по всем платформам: Qidian, Fanqie Novel, Douban Read, Zhihu Yanxuan, традиционное издательство, WeChat Official Accounts, WebNovel, MyFiction, GoodNovel
- По умолчанию включены оценка по Rubric, ранжирование и пояснения об отсеве
- По умолчанию выводится полный вариант; по явной просьбе пользователя можно переключиться на shortlist или финальную версию

## Минимальные ограничения исполнения

- Название книги сначала должно пройти проверку «похоже ли это на книгу»: оно не должно быть похоже на фразу аннотации, рекламный слоган, заголовок главы или заголовок поста.
- По умолчанию требуется, чтобы главные рекомендации для разных платформ разводились по основной оси, а не были лишь версиями одной и той же фразы с заменой слов.
- Уточнять следует лишь тогда, когда из контекста нельзя вывести следующие три пункта: уровень, нужны ли несколько платформ, набрасывать ли только в чате.
- Если пользователь явно не сказал «только набросок, файлы не трогать», по умолчанию запись в репозиторий.

## Выдача по умолчанию

- Выдать как минимум главную рекомендацию и ключевой shortlist
- Пояснить, записано ли в файл, в какой именно файл, перезапись это или дополнение
- Если Rubric включён, в чате показать как минимум пример оценки топ-3 для одной платформы

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `都市职场-设计标题` и его общее ядро, и больше не ведётся параллельно в этом Prompt:

- Применимые / неприменимые сценарии, канон ввода по умолчанию и порядок чтения контекста
- Процесс выделения материнского ядра заголовка, дисциплина именования на уровне серии, суждение «похоже на название книги», правило единой оси и правила сжатия длинных фраз
- Дедупликация между платформами, разведение главных рекомендаций и матрица стратегий именования по платформам
- Измерения оценки Rubric, веса, канон пояснения оценок, правила ранжирования, правила отсева и правила shortlist
- Структура вывода, чек-лист самопроверки, стратегия записи обратно, сдача в чате и критерии успеха
- Для жанра «Городская офисная проза»: примеры входа через профессию, аномальных доказательств, процедурного трения, городского давления и долгой «внутренней кухни»

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящий процесс наименования, Rubric, платформенную матрицу, правила записи обратно и жанровый патч «Городской офисной прозы» нужно читать в соответствующих Skill и исполнять там.
