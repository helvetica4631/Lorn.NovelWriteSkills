# Единый промпт вывода «версии для My Fiction» романа жанра «Городская офисная проза»

## Статус миграции (жёстко)

Этот Prompt теперь — тонкий вход и напоминание об оркестрации. При срабатывании этого входа дополнение платформенных исследований, детали исполнения, отображение исправлений на уровне разделов, канон слова от автора и границы жанра обязательно должны дальше маршрутизироваться и диспетчеризироваться через `通用-输出My Fiction版`; этот файл больше не несёт роль основного носителя платформенных деталей.

## 0. Ваша задача (одной фразой)

Переписать входную главу в английскую версию 【Городская офисная проза】, лучше подходящую для My Fiction: сохранить ключевую информацию, соблюдать английские шлюзы, выводить в правильный каталог, сохраняя продвижение дела, тягу отношений и мотивацию продолжать читать.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/创建小说正文.prompt.md`
- `.github/prompts/正文润色.prompt.md`
- `.github/prompts/去AI味.prompt.md`

### 1.2 Жанровый вход (дальше маршрутизируется через Skill)

- `.github/skills/都市职场-输出My Fiction版/SKILL.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出My Fiction版`; этот общий Skill принудительно продолжает чтение своих жанровых references и соответствующих общих Skill.
3. Сначала сохранить цепочку расследования, реальные процедуры и нулевое добавление фактов, затем усилить английское ощущение интерактивного следования за обновлениями и тягу отношений.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов портить «липкость» глав.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `My Fiction/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)
- `Len` основного текста не ниже 6500
- Кроме строки `## 作者有话说`, китайского / CJK быть не должно
- Нельзя писать «Городскую офисную прозу» как английский текст с одним лишь продвижением отношений, без каркаса расследования

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, дополнение платформенных исследований, патчи исполнения, отображение исправлений на уровне разделов, детальные правила заголовка, английские шлюзы, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
