# Единый промпт вывода «версии для WeChat Official Accounts» романа жанра «Городская офисная проза»

## Статус миграции (жёстко)

Этот Prompt теперь — тонкий вход и напоминание об оркестрации. При срабатывании этого входа дополнение платформенных исследований, детали исполнения, отображение исправлений на уровне разделов, канон слова от автора и границы жанра обязательно должны дальше маршрутизироваться и диспетчеризироваться через `通用-输出微信订阅号版`; этот файл больше не несёт роль основного носителя платформенных деталей.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【Городская офисная проза】, лучше подходящую контексту сериала в WeChat Official Accounts: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя давление расследования, сериальное напряжение и плавный опыт чтения.

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出微信订阅号版`; этот общий Skill принудительно продолжает чтение своих жанровых references и соответствующих общих Skill.
3. Сначала сохранить цепочку дела, продвижение отношений и нулевое добавление фактов, затем усилить для аккаунтов плавное чтение, микро-крючки и ощущение сопровождения в сериале.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов портить опыт сериального чтения.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `微信订阅号/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Нельзя писать «Городскую офисную прозу» как оболочку «хита» паблика или лёгкий контент

Общие положения платформы, границы жанра, дополнение платформенных исследований, патчи исполнения, отображение исправлений на уровне разделов, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
