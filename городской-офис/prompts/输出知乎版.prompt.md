# Единый промпт вывода «версии для Zhihu (Yanxuan / колонки / сериал)» романа жанра «Городская офисная проза»

## Статус миграции (жёстко)

Этот Prompt теперь — тонкий вход и напоминание об оркестрации. При срабатывании этого входа дополнение платформенных исследований, детали исполнения, отображение исправлений на уровне разделов, канон слова от автора и границы жанра обязательно должны дальше маршрутизироваться и диспетчеризироваться через `通用-输出知乎版`; этот файл больше не несёт роль основного носителя платформенных деталей.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【Городская офисная проза】, лучше подходящую контексту Zhihu: сохранить ключевую информацию, соблюдать платформенные шлюзы, выводить в правильный каталог, сохраняя высокую концепцию, отображение на реальность, логику расследования и чувство участия читателя.

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出知乎版`; этот общий Skill принудительно продолжает чтение своих жанровых references и соответствующих общих Skill.
3. Через жанровый Skill зафиксировать реальные общественные темы, логику дела, цепочку доказательств и жанровые патчи, одновременно унаследовав общие положения платформы Zhihu.
4. Сначала сохранить жанровый каркас и нулевое добавление фактов, затем усилить в духе Zhihu, и лишь в последнюю очередь — снижение схожести.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `知乎/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Заголовок должен соответствовать склонности контекста Zhihu к фразе-правилу / фразе-цене / постановке вопроса
- Нельзя писать «Городскую офисную прозу» как текст-объяснение концепции, рассуждение или текст с одними лишь мнениями без дела

## 4. Пояснение о текущем состоянии

Текущий Prompt синхронизирован с основной цепочкой жанровых Skill / references.

- Дополнение платформенных исследований, детали исполнения, отображение исправлений на уровне разделов и границы жанра определяются спущенной вниз цепочкой `通用-输出知乎版`.
- Prompt сохраняет лишь вход, напоминания об оркестрации, минимальные ограничения совместимости и описание каталога вывода.
- При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
