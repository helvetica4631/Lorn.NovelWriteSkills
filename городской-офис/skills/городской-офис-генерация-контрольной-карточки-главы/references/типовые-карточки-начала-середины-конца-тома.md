# Дополнение к карточкам типов (начало / середина / конец тома) («Городская офисная проза»)

## Дополнение для начала тома

- Первый затык процесса
- Первое проверяемое доказательство
- Первое место организационного давления

## Дополнение для середины

- Приоритет типа награды: процедурное продвижение / переворот доказательств
- Изменение положения дел должно быть проверяемым (а не устным суждением)

## Дополнение для конца тома

- Выплата обещания тома + системный разрыв следующего тома
- Приземление цены хотя бы на одно из: должность / отношения / ресурсы
