# Согласованность содержания и проверка рисков

## Согласование с планом

Биография персонажа обязана одновременно согласовываться с:

- Ключевым сюжетом уровня общего плана
- Поэтапными функциями части / тома
- Исполнимым поведением в конкретных главах

## Ключевые пункты проверки

- Согласованы ли возраст, временная линия, профессиональная траектория
- Совпадает ли описание отношений с другими биографиями персонажей
- Согласуется ли содержание, затрагивающее приёмы / процедуры / улики, с настройками истории
- Едино ли позиционирование роли персонажа в планах разных уровней

## Способ отметки противоречий

При обнаружении конфликта в первую очередь отмечать:

- Уровень конфликта
- Номер конфликта
- Тип конфликта (время / отношения / мотивация / способность / критерии улик)
- Минимальное предложение по исправлению

## Усиление множественных точек зрения

Важным персонажам лучше одновременно иметь:

- Различия поколенческой точки зрения
- Чувство классового положения
- Функциональную позицию в групповом повествовании
- Различия поведения под тройным давлением процедур / отношений / общественного мнения
