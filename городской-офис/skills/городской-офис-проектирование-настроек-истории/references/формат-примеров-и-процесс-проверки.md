# Формат примеров и процесс проверки

## Скелет примера

```markdown
# [Название элемента] — документ материалов об приёме/процедуре/улике/настройке

## Основная информация
## Механизм/процедура
## Сценарии применения
## Общественное влияние
## Эволюция и развязка
## Роль в долгом романе
## Проверка достоверности
```

## Процесс проверки

1. Завершить черновик настроек.
2. Проверить, можно ли разбить правила на пункты.
3. Проверить, есть ли следы, границы, цена, лазейки, контрмеры.
4. Проверить соответствие ресурсам персонажей, временной линии, городской экосистеме.
5. Проверить, можно ли написать это кадрами, а не остаться в тоне инструкции.

## Частые причины переделки

- Настройка крутая, но в сюжете не пригождается
- Есть механизм, нет следов
- Есть следы, нет сложности получения
- Есть правила, но нет персонажей и социальной цены
