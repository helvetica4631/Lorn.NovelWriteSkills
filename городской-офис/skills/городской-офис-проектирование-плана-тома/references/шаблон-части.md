## 1. Дополнительные правила частей «Городской офисной прозы»

- В перечне преемственности частей обязательно выделять отдельно:
  - Задачи конфликтов организационного уровня
  - Задачи цепочки процедур
  - Задачи цепочки доказательств
- При разбиении целевого числа знаков части в первую очередь гарантировать «цепкость первого тома + плотность наград в середине».

## 2. Дополнительные пункты приёмки

- [ ] В каждом блоке сюжета есть как минимум 1 узел доказательства, поддающийся аудиту.
- [ ] Ключевая сюжетная линия может быть приземлена на один из трёх якорей реальности — «должность / процесс / подотчётность».
