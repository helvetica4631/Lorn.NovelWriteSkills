# Дополнение к шаблону записи материалов внутренней подачи Qidian на диск («Городская офисная проза»)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон сборки находится в:
>
> - `CommonSkills/общий-сборка-материалов-для-подачи/references/шаблон-самопроверки-сборки-и-матрицы-рисков.md`

## Дополнительно заполняемые поля «Городской офисной прозы»

- Можно ли проверить профессиональный зацеп (обязанности должности + путь действий)
- Можно ли проверить цепочку процедур (узлы процесса + расписки-доказательства)
- В матрице рисков в первую очередь следить за: искажением процессов, парящими доказательствами, остыванием середины

## Жанровая формулировка вывода

- Позиционирование текущего пакета: предварительная версия с недостающими элементами / предварительная версия подаваемого пакета / официальная версия подачи
- При режиме каталогов версий жанровый вывод следует синхронно записывать обратно в `当前版本索引.md` или `00_版本说明.md`
- Нужно явно различать: достижение единой линии подачи ≠ рекомендация немедленно подавать
- Указанная жанровая формулировка вывода допускается лишь во внутренних файлах на стороне автора и не может включаться в четыре внешних документа, сдаваемых редактору.
- Во внешних сдаваемых документах запрещены любые авторские самооценки, самовосхваление, самое сильное / самое слабое звено сейчас, комментарии об остаточных рисках или слова, подменяющие суждение редактора.
