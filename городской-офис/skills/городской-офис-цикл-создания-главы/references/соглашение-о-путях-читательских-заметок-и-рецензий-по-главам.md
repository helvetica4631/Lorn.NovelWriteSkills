# Дополнение о соглашении о путях читательских заметок и рецензий по главам

## Пути по умолчанию

- Читательские заметки: `阅读笔记/第X部/第Y卷/阅读笔记_第X.Y.Z章_<YYYY-MM-DD>.md`
- Рецензия на главу: `书评/第X部/第Y卷/<имя файла главы без расширения>_书评_<YYYY-MM-DD>.md`

## Когда часть / том не удаётся определить однозначно

- Читательские заметки записывать в `阅读笔记/未分类/` (читательские заметки / без категории)
- Рецензии по главам записывать в `书评/未分类/` (рецензии / без категории)
- Но в резюме обязательно заметно указать «путь ждёт исправления»

## Момент генерации

- Генерировать только на основе последнего финального основного текста
- Как только основной текст после финальной рецензии изменён снова, читательские заметки и рецензии по главам считаются устаревшими продуктами
