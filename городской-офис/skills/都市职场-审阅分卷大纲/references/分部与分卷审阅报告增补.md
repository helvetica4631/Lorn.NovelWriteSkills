# Дополнение к отчёту рецензии части и тома

> Это «дополнительные критерии для уровня части / тома / события единицы» к общему шаблону отчёта во входном Prompt. Публичный шаблон остаётся во входном Prompt; здесь дополняются написание и акценты оценки, которые необходимо усилить при послойных объектах.

## 0. Предварительное требование к отчёту: сначала написать «приземлено ли вышестоящее распределение в полном объёме»

- До входа в анализ ритма и хуков отчёт по части / тому обязан сначала изложить: **какое из содержимого, распределённого этому слою вышестоящим уровнем, приземлено, какое отсутствует, какое лишь значится по имени и не реализовано.**
- Вышестоящее содержимое здесь включает, но не ограничивается: главную сюжетную линию, побочные линии, грани истории, сюжетные линии, предзнаменования и переклички, цену персонажей, мозаику главной линии, ограничения временной оси / реестра.
- Без этого шага нельзя считать, что структурная рецензия объекта «часть / том» завершена.

## I. Рекомендуемый путь сохранения в базу (слой части / тома)

В первую очередь использовать:

- `审阅意见/小说大纲审阅报告_分部_【名称】_YYYY-MM-DD.md`
- `审阅意见/小说大纲审阅报告_分卷_【名称】_YYYY-MM-DD.md`
- `审阅意见/小说大纲审阅报告_单元事件_【名称】_YYYY-MM-DD.md`

Если в проекте уже есть собственная норма, можно придерживаться её, но имя файла должно позволять найти уровень объекта.

## II. Что в отчёте по части / тому нужно прописать особенно тщательно

### 1) Для автора: ценность руководства письмом (P0)

Для объектов «часть / том» здесь особо пояснить:

- Полностью ли подхвачено содержимое, распределённое этому слою вышестоящим уровнем;
- Может ли автор прямо по нему разбить главы;
- Какие отрывки всё ещё «комментирующий план», а не «исполнимый план»;
- Ясно ли определена форма награды каждой главы / каждой группы глав.

### 2) Стратегия ритма и крючков (обязательно для тома / события единицы)

Под `## ⏱️ 节奏与钩子策略` (ритм и стратегия хуков) входного шаблона прописать как минимум:

- Положение малой кульминации / положение большой кульминации;
- Как сейчас распределены три типа хуков (поворот / раскрытие / кризис);
- Есть ли подряд усталость;
- В каких главах легче всего появляется «начало мощное, середина проваливается»;
- Какой тип награды в середине рекомендуется добавить.
- Исполнены ли обещания первых 3 глав / первых 5 глав / первого тома.
- На какой тип ритма платформы больше похож, не расходится ли с целевой платформой.

### 3) Проверка инженерной структуры и исполнимости (P0)

Для объектов «часть / том» нельзя ограничиваться словами «структура ясна», нужно указать:

- Какие вышестоящие распределённые пункты приземлены реально;
- Какие вышестоящие распределённые пункты всё ещё отсутствуют или висят в воздухе;
- Какая группа глав уже может быть написана прямо;
- Какая группа глав всё ещё остаётся функциональным ярлыком;
- Какой функциональный сегмент события единицы разорван;
- Какой отрывок вставить / заменить при исправлении.

### 4) Конкретные рекомендации по правке (можно прямо записывать обратно)

Рекомендации для объектов «часть / том» должны в основном быть «заплатками групп глав / заплатками ритма / заплатками хуков». Рекомендуемые формулировки:

- В `【本部 / 本卷承接清单】` (перечень подхвата этой части / тома) дописать `【缺失的上游分配项】` (недостающие вышестоящие распределённые пункты) и приземлить их на `【对应章组 / 工件 / 伏笔表】` (соответствующая группа глав / артефакт / таблица предзнаменований).
- В `【章段 / 章组 / 单元事件节点】` (сегмент главы / группа глав / узел события единицы) добавить `【中段回报】` (награда в середине), чтобы этот сегмент не шёл вхолостую.
- Заменить `【当前钩子】` (нынешний хук) на `【转折/揭露/危机】` (поворот / раскрытие / кризис), чтобы избежать подряд усталости одного типа.
- В `【某章或某章组】` (некая глава или группа глав) явно привязать `【上游任务 / 主线拼图 / 人物代价】` (вышестоящая задача / мозаика главной линии / цена персонажей), чтобы предотвратить «этот том только суетится и не продвигается».
- Заменить `【功能标签式表述】` (формулировка в виде функционального ярлыка) на `【具体场景 / 动作 / 证据载体 / 冲突事件】` (конкретная сцена / действие / носитель улик / конфликтное событие), устранив ИИ-привкус.
- В `【前3章/前5章/首卷结尾】` (первые 3 главы / первые 5 глав / конец первого тома) добавить `【强承诺 / 强揭露 / 强危机】` (сильное обещание / сильное раскрытие / сильный кризис), чтобы реалистично прописать цепкость втягивания.

## III. Центр тяжести оценки части / тома

Перед комплексной оценкой рекомендуется предварительно откалибровать:

- Исполнимость и возможность записи обратно: наивысший приоритет
- Возможность разбиения на главы и чёткость тактов: наивысший приоритет
- Ритм и стратегия хуков: высокий приоритет
- Ясность ожидаемого эффекта для читателя: высокий приоритет
- Цепкость начала и удержание дочитывания: высокий приоритет
- Против духа ИИ и приземление сцен: средне-высокий приоритет
- Сериальная связность: средне-высокий приоритет
- Новизна и узнаваемость: второстепенный приоритет

## IV. Идеи оптимизации уровня части / тома для рывка к 9.2+

### Направления стратегического приоритета

- Каждые 3–5 глав должна быть одна ощутимая награда, нельзя обманывать перелистыванием лишь хуком конца главы.
- Типы хуков должны чередоваться, чтобы «поворот / раскрытие / кризис» образовали ритмическое дыхание.
- Событие единицы должно не только замыкаться, но и питать главную линию и цену для персонажей.
- Награды в середине глав должны быть привязаны к уликам, отношениям, ресурсам или риску, избегая чисто эмоционального продвижения.
- Начало обязано в первых 3 главах поставить зацепку, в первых 5 главах — обещание, в первом томе — дать исполнение.
- Превращать функциональные ярлыки в конкретные сцены, чтобы автор, получив, сразу мог писать, а не переводить второй раз.

### Рекомендуемый формат примерной записи обратно

> Пример (место вставки: после некоей группы глав):
>
> - **Патч награды в середине**: этот сегмент не может лишь заставлять персонажа продолжать поиски; в середине необходимо дать явную награду: либо получить `【证据载体】` (носитель улик), либо подтвердить `【嫌疑/关系变化】` (подозрение / изменение отношений), либо заплатить `【资源/名誉/程序代价】` (цену ресурсами / репутацией / процедурой). Иначе в главе останутся лишь аномалия в начале и жёсткий крючок в конце, и читатель почувствует, что его тянут за собой.
> Пример (место вставки: после планирования первых 5 глав первого тома):
>
> - **Заплатка обещания начала**: в главе 1 обязательно показать аномалию и зацепку героя, до главы 3 обязательно выдать первую проверяемую улику, до главы 5 обязательно сформировать одно сильное раскрытие / сильный кризис / сильный поворот; иначе первый том можно считать лишь «стартом», но не «втягиванием».
