# 都市职场-审阅总大纲

Это жанровая обёртка и совместимый вход. При срабатывании этого навыка **в первую очередь обязательно принудительно загрузить** текущий жанровый Skill и `通用-审阅总大纲`; текущий жанровый Skill отвечает за жанровую рамку и границы вердикта, `通用-审阅总大纲` — за общий каркас и общий процесс.

## Обязанности слоя

- Маршрутизировать общий каркас рецензирования слоя общего плана в `通用-审阅总大纲`.
- Продолжать сохранять жёсткие нормы жанра «Городская офисная проза» при рецензировании общего плана: питание основной линии, нарастание механизмов, цепочка доказательств, причинно-следственное замыкание, система процедур и номеров.

## Дополнение жанра «Городская офисная проза» (продолжает сохраняться)

- При рецензировании общего плана смотреть не только на структурную замкнутость, но и на взаимосвязь файловой группы слоя общего плана, питание главной линии, долгое нарастание механизма и возможность записи обратно.
- Если рецензировался только `小说总大纲.md`, а `故事面/`, `伏笔与回收总纲.md`, `故事多面体大纲.md` не проверялись, обязательно явно написать, что объём рецензии ограничен.
- Отчёт должен указывать, какой механизм оборван, какого куска мозаики главной линии не хватает, в какой объект слоя общего плана добавить, а не давать лишь абстрактные похвалы или рекомендации уровня глав.

## Обязательные требования

- Нельзя в обход `通用-审阅总大纲` писать параллельный набор общих правил.
- При ссылке на общие способности ссылаться только по названию, без пути.
- При рецензировании общего плана обязательно явно судить, замкнуты ли уже на слое общего плана грани истории, обещание первого тома, платформенная рамка и долгое питание.

## Исходное жанровое инженерное определение (сохранено)

- «Общий план», о котором говорит этот Skill, **по умолчанию не означает единственный** `小说大纲/小说总大纲.md`.
- Это взаимосвязанная **файловая группа слоя общего плана**, как минимум включающая:
	- `小说大纲/小说总大纲.md`
	- `小说大纲/故事面/`
	- `小说大纲/伏笔与回收总纲.md`
	- `小说大纲/故事多面体大纲.md`
	- а также другие связанные файлы слоя общего плана, такие как `时间轴_总表.md`, индекс общего плана, матрицы / реестры уровня общей таблицы и т. п.
- Поэтому, когда пользователь говорит «отрецензируй общий план», по умолчанию следует рецензировать **файловую группу слоя общего плана и её взаимосвязи**, если пользователь явно не ограничил только одним файлом.
- Если пользователь устно употребляет формулировки вроде «общий план предзнаменований и перекличек», в текущем репозитории единообразно обрабатывать как `小说大纲/伏笔与回收总纲.md`.

## Когда использовать
- Пользователь хочет отрецензировать общий план всей книги, указатель общего плана, многогранник истории или сводную таблицу основного конфликта основной линии.
- Целевой файл принадлежит файловой группе уровня общего плана, например `小说总大纲`, `故事面/`, `伏笔与回收总纲`, `故事多面体大纲`, сводные таблицы основного конфликта основной линии `M0` / граней побочных линий `Xxx` / матрицы единиц-событий `Cxx`.
- Задача сосредоточена на нарастании механизма уровня общего плана, питании главной линии, долгой связности, условиях замыкания и отчёте о рецензии общего плана.

## Разделение с входным Prompt
- Входной Prompt продолжает отвечать за **общие правила**: определение цели рецензии, подтверждение перед началом, цепочку чтения, общий инженерно-структурный аудит, общие нормы причинно-следственной замкнутости и сквозной связности серий, общий каркас отчёта, правила записи в базу.
- Этот Skill отвечает только за **специальные правила рецензирования общего плана**, чтобы не продолжать нагромождать нарастание механизма слоя общего плана, специальную оценку общего плана и дополнения к отчёту по общему плану во входном Prompt.

## Порядок выполнения по умолчанию
1. Сначала по входному Prompt подтвердить целевой файл, тип объекта, стратегию вывода.
2. Подтвердить, что текущая задача действительно относится к «слою общего плана», не принимать проблемы ритма тома за главную проблему общего плана.
3. В сочетании с `写作研究/` и `调研报告/` дополнительно определить платформенную адаптацию, обещание начала, выносливость длинного романа, борьбу с духом ИИ и связь с общественными темами.
4. Исполнить [Специальный контрольный список рецензии общего плана](references/总纲审阅专属检查清单.md).
5. При формировании отчёта сверяться с [Дополнением к отчёту рецензии общего плана](references/总纲审阅报告增补.md), дополняя суждения, специфичные для слоя общего плана, оценку и рекомендации по записи обратно.
5. Если пользователь затем просит продолжить рецензирование части / тома, вызвать `都市职场-审阅分卷大纲`.

## Акценты усиления этого раунда (новое для слоя общего плана)
- При рецензировании общего плана смотреть не только «замыкается ли», но и «способен ли он поддержать длинную сериализацию без вялости».
- Дополнительно обязательно судить:
	- Прописаны ли уже на слое общего плана заранее обещания первых 3 глав / первых 5 глав / первого тома;
	- Не сводится ли средний блок томов лишь к нагромождению единиц-событий или он способен непрерывно питать основную линию;
	- Образовалась ли ясная платформенная склонность (Qidian / Fanqie / Douban / Yanxuan / печатные СМИ / зарубежье и т. п.);
	- Нет ли явной «болезни общего плана в духе ИИ»: концепций много, действий пусто, персонажи все как функциональные кнопки.
- Когда исследовательские материалы расходятся с нынешним общим планом, в первую очередь указать, «на какой тип произведения / платформы нынешний общий план больше похож», затем дать минимальную заплатку, а не сносить всё одним махом.

## Минимальная выдача рецензии общего плана
- Чётко указать, какие файлы слоя общего плана охвачены этой рецензией и какие взаимосвязи проверены.
- Полно ли нарастание механизма главной линии: период пробы → период расширения → период свёртывания → финальный период.
- Матрица единиц-событий стабильно питает основную линию, и каждое событие продвигает как минимум один кусок пазла основной линии.
- Состоятельны ли серийные якоря, вехи главной линии, кривая цены персонажей, условия замыкания.
- Прошли ли порог платформенная адаптация, обещание начала, выносливость длинной вещи, борьба с машинным привкусом и якоря реальности.
- Отчёт рецензии общего плана, который можно прямо сохранить в `审阅意见/`, с минимальной записываемой обратно заплаткой.

## Запреты
- Писать рецензию общего плана как комментарий к ритму томов.
- Говорить только «масштабно структурировано / тема глубокая», не указывая, какой механизм оборван, какого куска мозаики не хватает, куда добавить.
- Подменять исправляющие действия уровня общего плана рекомендациями уровня глав.
- Не определив, ясна ли вышестоящая рамка, сразу давать рекомендации по разбиению нижестоящего.
