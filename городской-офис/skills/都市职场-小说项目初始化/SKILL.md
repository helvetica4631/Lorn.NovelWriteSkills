## Дополнение к инициализации «Городской офисной прозы»

### 1. Дополнения по адаптации под платформы

| Платформа | Ключевые моменты адаптации «Городской офисной прозы» |
| --- | --- |
| **Qidian** | Основной плацдарм офисных / бизнес-романов. Читатели предпочитают реальные отраслевые детали и стройную логику бизнес-игры. Подходят типы «раскрытие отрасли», «бизнес-игра», «профессиональный рост». Порог подписания высок, нужен отраслевой разрез с достаточной профессиональной глубиной. |
| **Fanqie Novel** | Подходит для быстрых офисных 爽-романов типа «удар по лицу и реванш». Склоняется к классическим повествованиям вроде «扮猪吃虎» и «презирали → сила доказана». Профессиональные детали можно упрощать, приоритет — ощущение 爽. |
| **Qimao** | Склоняется к традиционной «мобильной» офисной прозе; схемы вроде «зять-примак возвращается» (赘婿逆袭) и «президент возвращается» всё ещё работают. Ритм должен быть быстрым, конфликты — прямыми. |
| **Zhihu Yanxuan** | Подходит для реалистичных офисных историй, отраслевых секретов, содержания о внутренних секретах профессии. Сильное ощущение реальности, сильные эмоции, допустимо первое лицо. |
| **Jinjiang Literature City** | Женская офисная любовная проза. Двойное продвижение — офисная линия + линия чувств. Подходят сочетания «служебный роман», «элита отрасли», «профессиональный рост + любовь». |

### 2. Напоминание о сочетании приёмов

«Городская офисная проза» — типичный жанр, движимый «прорывом через классы», с ключевой эмоцией компенсаторного удовлетворения:

- **Рекомендуется для слоя основного конфликта**: бизнес-игра / раскрытие отрасли / профессиональный рост / увольнения и защита прав
- **Рекомендуется для слоя запуска повествования**: перерождение (возврат в ключевой узел офисной карьеры), попадание в книгу (попасть в роль массовки и взлететь), обычный старт (шаг за шагом подниматься силой)
- **Рекомендуется для слоя непрерывного драйва**: повышение и зачистка монстров (профессиональное повышение вместо силового), цикл ударов по лицу (по технике / способностям)
- **Слой эмоциональных зацепов**: для женской офисной прозы эмоциональная линия обязательна; для мужской офисной прозы в основном линия карьеры, чувства — дополнительно
- **Антишаблонные новшества**: разрез редких отраслей (похоронное дело / ломбард / таможня / археология и т. п.); слияние «офис + детектив»

### 3. Элементы, требующие специализации на стадии инициализации

| Элемент | Значение в «Городской офисной прозе» | Пункт проверки инициализации |
| --- | --- | --- |
| **Отраслевой разрез** | В какой конкретно отрасли? Интернет / финансы / право / фармацевтика / производство / недвижимость и т. п. | Есть ли у отрасли достаточная база познания у читателей? Достаточно ли она «нова» или «глубока»? |
| **Плотность профессиональных деталей** | Достоверность отраслевых терминов, рабочих процессов, внутренних правил | Платным платформам нужна высокая плотность; бесплатные могут слегка упрощать, но логика не должна быть несогласованной |
| **Путь прорыва через классы** | Путь повышения главного героя «откуда → куда» | Ясен ли путь, ощутим ли? Вызывает ли у читателей компенсаторное удовлетворение? |
| **Логика бизнес-игры** | Приёмы, ставки и конструкция информационной асимметрии в коммерческой конкуренции | Выдерживает ли логика критику? Не слишком ли проста или слишком сложна? |
| **Якорь реальной цены** | Что главный герой теряет при офисном подъёме? Семья / здоровье / моральная планка / человеческие отношения | Достаточно ли цена, чтобы поддержать эмоциональное перетягивание? |

### 4. Значение эмоциональной оси по умолчанию

Основная эмоциональная ось «Городской офисной прозы» — главное обещание **компенсаторного удовлетворения от прорыва через классы**:

```
Подавлен / недооценён (душевная теснота 憋屈) → терпение / скрытое накопление сил (предвкушение) → небольшая демонстрация силы (точка 爽) → снова придавлен / новая трудность (снова теснота) → больший прорыв (ещё больше 爽)
```

- Платные платформы (Qidian): акцент на реальный процесс бизнес-игры, плотность точек 爽 может быть чуть ниже, но надёжность логики должна быть высокой
- Бесплатные платформы (Qimao / Fanqie): акцент на радость удара по лицу и реванша, плотность точек 爽 должна быть высокой

### 5. Дополнения по красным линиям платформ

- Все платформы: избегать затрагивания реальных коммерческих тайн, нераскрытых отраслевых чёрных схем (можно сделать вымышленными)
- Офисная проза Qidian: отраслевые знания должны быть подтверждаемыми, рекомендуется провести отраслевое исследование (вызвать `通用-深度研究`)
- Qimao / Fanqie: избегать конфликтов типа «понижение интеллекта» (слишком глупый противник снижает ощущение 爽)
- Все платформы: чувствительные темы вроде дискриминации на работе / сексуальных домогательств следует обрабатывать осторожно
