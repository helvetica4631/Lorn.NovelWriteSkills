# Дополнение к шаблону отчёта оценки вероятности подписания на Qidian («Городская офисная проза»)

> Этот файл **не является полным главным шаблоном**. При выполнении обязательно сначала использовать:
>
> - `CommonSkills/通用-平台签约评估框架/references/平台签约评估报告模板.md`

## 1. Способ использования (обязательно)

1. Сначала по общему главному шаблону завершить весь отчёт об оценке.
2. Затем дописать пункты этого файла в соответствующие разделы общего шаблона.
3. Если имена полей совпадают с общим шаблоном, считать по схеме «общие поля — каркас, поля „Городской офисной прозы“ — жанровые дополнения».

## 2. Специальные поля жанрового дополнения

### 2.1 Оценочная задача и полнота материалов (дописать)

- Норма целевой платформы: мужская проза Qidian (Городская офисная проза)
- Дополнительная проверка материалов внутренней подачи:
  - Может ли основной образ персонажа / таблица образов приземляться на схему «профессиональная позиция — позиция власти и ответственности — позиция „крайнего“ — позиция контрдействия»
  - Есть ли исполнимое обещание начала (первые 3 главы / первые 6000 знаков)

### 2.2 Специальные красные линии «Городской офисной прозы» (дописать)

- Реально ли ощущаются институты и цепочка процедур офиса (а не пустое выкрикивание «в компании всё плохо»)
- Поддаются ли носители доказательств аудиту (номера расписок / записи OA / заявки / пропускная система / протоколы совещаний)
- Исходит ли эскалация давления из «отказа реальных процессов», а не из чисто концептуального вывода

### 2.3 Продающие точки и платная ценность (дописать)

- Складывается ли однофразовая продающая точка в «профессиональный зацеп + реальная цена + путь контрдействия»
- Обладает ли платная ценность устойчивостью, свойственной «Городской офисной прозе»: как минимум по одной оси из компенсации / идентификации / контроля проходит порог

### 2.4 Минимальный замкнутый контур исправления (дописать)

- Приоритетный 72-часовой патч обязан включать как минимум:
  1. Патч достоверности профессионального процесса
  2. Патч видимости цепочки доказательств
  3. Патч защиты от остывания середины (награда в середине главы)

## 3. Шаблон жанровых итоговых фраз (можно использовать напрямую)

- Вывод о пропуске текущего уровня (норма «Городской офисной прозы»):
  - Пройдено / пройдено условно / не пройдено
- Наибольший риск доработки в данный момент (норма «Городской офисной прозы»):
  - Обычно «процессы нереальны, доказательства не приземлены, цена не болит, награды нестабильны»
