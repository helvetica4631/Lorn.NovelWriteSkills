# Дополнительный шаблон контрольной карточки («Городская офисная проза»)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/通用-生成章节控制卡/references/章节控制卡模板.md`

## 1. Способ использования (обязательно)

1. Сначала по общему шаблону контрольной карточки заполнить полную главную карточку.
2. Затем дописать поля этого файла в соответствующие разделы.

## 2. Поля дополнения «Городской офисной прозы»

- Доказательства и процедуры: номер расписки / процесс в OA / состояние заявки / версия протокола совещания
- Эскалация риска: риск «крайнего», риск подотчётности, риск отказа процесса
- Награда в середине: как минимум одно «продвижение на институциональном уровне», а не только продвижение эмоций

## 3. Дополнительные пункты приёмки

- [ ] Если «награда в середине» пуста, эта глава не допускается к написанию.
- [ ] Крючок конца главы должен указывать на системный разрыв, а не на единичный эмоциональный вопрос.
