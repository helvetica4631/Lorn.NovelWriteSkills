# Дополнительные правила жанровой контрольной карточки

## Обязательно указывать вышестоящий источник

При генерации контрольной карточки сначала обязательно чётко написать, откуда происходит эта глава:

- Из какой поверхности истории / пазла основной линии
- Из какой задачи тома
- Из какого окна возврата старого вопроса

## Обязательные пункты контрольной карточки «Городской офисной прозы»

1. На какой старый вопрос отвечает эта глава.
2. Какие новые улики / квитанции / номера / записи входят в эту главу.
3. С каким процедурным или институциональным сопротивлением встречается эта глава.
4. Каково явное вознаграждение середины этой главы.
5. Кого концовка главы подталкивает в худшую ситуацию.

## Жанровый приоритетный порядок контрольной карточки

- Сначала намертво зафиксировать основную линию продвижения
- Затем закрепить действие входа улик
- Затем закрепить процедурное сопротивление
- Затем зафиксировать вознаграждение середины
- В последнюю очередь зафиксировать нарастание опасности в конце главы

## Подсказки о рисках уровня главы

- Если контрольная карточка не может ясно сказать, «из какой вышестоящей задачи опущена эта глава», значит, вышестоящая цепочка не подключена.
- Если не может ясно сказать вознаграждение середины, значит, середина этой главы, скорее всего, провалится.
- Если хук конца главы сводится к одной фразе «стало опаснее», значит, опасность ещё не конкретизирована.
