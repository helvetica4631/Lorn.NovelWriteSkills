# 都市职场-组包投稿材料

Это жанровая обёртка, совместимый вход и слой маршрутизации. При срабатывании этого навыка в первую очередь необходимо принудительно загрузить текущий жанровый Skill и `通用-组包投稿材料`; текущий жанровый Skill отвечает за подачу «Городской офисной прозы» в рамках мужской прозы Qidian и ограничения маршрутизации, а `通用-组包投稿材料` — за общий каркас, правила четырёх элементов, запись на диск и квитанции.

## Соответствующий общий Skill

- `通用-组包投稿材料`

## Обязанности слоя

- Сохранять жанровое входное имя «都市职场-组包投稿材料».
- Маршрутизировать общий каркас сборки пакета подачи в `通用-组包投稿材料`.
- Дополнять профессиональный зацеп, аномальные доказательства, процедурное трение, реальную цену и описание долгих закулисных фактов в жанре «Городская офисная проза».
- Усваивать вывод оценки Qidian, чтобы не «втискивать» в пакет внутренней подачи рукопись, не подходящую для Qidian.

## Цепочка взаимодействия по умолчанию

- Если для текущего произведения оценка Qidian ещё не завершена или уже есть оценка, но она не усвоена в пакет, обязательно дополнительно вызвать `都市职场-平台签约评估框架`.
- Если аннотацию нужно переписать в «кликабельную версию Qidian», обязательно дополнительно вызвать `都市职场-撰写内容简介`.
- При сборке пакета нельзя в обход жанрового Skill напрямую «голо» использовать общий слой или старые псевдонимы Prompt.

## Предварительные шаги чтения шаблонов в норме Qidian (обязательно, приоритет над любым действием записи на диск)

При сборке по норме Qidian **перед выполнением любой записи на диск или написания плана** необходимо по порядку выполнить:

1. `read_file` открыть `小说大纲/小说总大纲.md`, найти и прочитать `

## 模板组合声明`, записать название основного шаблона и список вспомогательных шаблонов
2. `read_file` физически открыть файл основного шаблона (`CommonSkills/写作研究/起点模板/总纲模板/<название основного шаблона>.md`), буквально извлечь перечень обязательных полей первого / второго уровня
3. Построить «таблицу покрытия полей шаблона» (три столбца: исходное поле основного шаблона / соответствующее место в плане для внутренней подачи / покрыто ли), и видимо показать эту таблицу в чате
4. Только когда все обязательные поля в таблице покрытия отмечены «да», можно переходить к написанию официальной версии плана для внутренней подачи; если любое поле «нет», сначала обязательно вернуть на доработку

> Раздел плана в `references/起点内投材料落盘模板.md` — динамический заполнитель, фиксированной структуры не даёт; поля основного шаблона — единственный законный источник структуры.

## Требования к исполнению полной сборки (обязательно)

- При выполнении этого Skill обязательно сначала загрузить `通用-组包投稿材料` и по шлюзу качества общего слоя сначала определить: остановить формальную сборку / предварительная версия подаваемого пакета / разрешить формальную сборку пакета.
- Если ещё не достигнута единая линия внутренней подачи Qidian (`30000` знаков непрерывного основного текста + `内投版总大纲〈最低5000字〉` (общий план для внутренней подачи, минимум 5000 знаков) + `内投版第1卷卷纲` (план 1-го тома для внутренней подачи) + `内投版简介` (аннотация для внутренней подачи)), обязательно заметно пометить «предварительная версия с недостающими документами» или «предварительная версия подаваемого пакета»; нельзя выдавать за зрелый пакет внутренней подачи.
- Нельзя собирать материалы «Городской офисной прозы» лишь в облегчённый пакет с примерами глав; их необходимо организовать как «`аннотация для внутренней подачи` + `30000` знаков непрерывного текста + `общий план〈минимум 5000 знаков〉` + `план 1-го тома` + `самопроверка сборки` той же версии» и полностью доказать: профессиональный разрез, аномальные доказательства, процедурное трение, цену для главного героя, швы городской реальности, обещание первого тома, долгие закулисные факты и способности автора к исполнению.
- Если уже есть оценка платформы, выводы рецензий глав / персонажей / сеттинга / тома / общего плана, обязательно перекрёстно усвоить; нельзя смотреть лишь аннотацию и пробные главы и упаковывать рискованную рукопись как формальную версию внутренней подачи.
- При фактической записи на диск в первую очередь применять `references/起点内投材料落盘模板.md`, не складывать абзацы лишь во временном порядке.
- При фактической записи на диск по умолчанию писать в `投稿材料/起点内投/《作品名》/vYYYY-MM-DD-rN/` и синхронно обновлять `当前版本索引.md`; если пользователь явно не просит дополнительно выгрузить сводный файл, нельзя откатываться к основной форме «один файл».
- `组包自检` (самопроверка сборки) может существовать лишь как внутренний файл на стороне автора, не засчитывается во внешние сдаваемые документы и не отправляется вместе с рукописью.
- Во внешних сдаваемых документах запрещены любые авторские самооценки, самовосхваление, `当前最强 / 最弱一环` (самое сильное / самое слабое звено сейчас), комментарии об остаточных рисках, `建议现在内投` (рекомендуется подавать сейчас), `可以直接进入编辑内投` (можно напрямую переходить к внутренней подаче через редактора) и другие слова, подменяющие суждение редактора.

## Требования к усвоению сигналов рецензии (обязательно)

	- `都市职场-平台签约评估框架`
	- `都市职场-审阅章节正文`
	- `都市职场-审阅人物传记`
	- `都市职场-审阅故事设定`
	- `都市职场-审阅分卷大纲`
	- `都市职场-审阅总大纲`
- При наличии любой из следующих проблем в принципе остановить формальную сборку или понизить до предварительной версии подаваемого пакета:
	- Цепочка доказательств нечестна;
	- Процедурные формулировки искажены;
	- Профессиональный зацеп главного героя неустойчив;
	- Высокий концепт / техническая упаковка не приземлены по-настоящему на реальные процессы, доказательства и цену;
	- Обещание первого тома и долгие закулисные факты явно не работают.

## Справочник частых триггерных слов / формулировок пользователя

- Помоги собрать пакет подачи «Городской офисной прозы»
- Приведи к материалам внутренней подачи, которые Qidian сможет прочитать
- Проверь самое слабое звено имеющихся материалов подачи
- Собери 30000 знаков непрерывного основного текста + общий план / план 1-го тома + аннотацию
- Посмотри, можно ли подавать этот комплект материалов

## Обязательные требования

- При срабатывании этого навыка в первую очередь обязательно принудительно загрузить текущий жанровый Skill и `通用-组包投稿材料`.
- Название, аннотация, план и пример главы должны указывать на одно и то же сочетание «профессия + аномалия + цена + долгие закулисные факты».
- Пакет подачи должен прежде всего доказать, что это «Городская офисная проза», пригодная для продолжения чтения в городской мужской прозе, а не медленное эссе в духе социальной школы или чистая атмосферная рукопись.
- Пример текста должен как можно лучше сохранять: цепкость начала главы, награду в середине, объект эстафеты в конце главы и как минимум одно реальное продвижение на уровне доказательств / процедур / отношений.
- При самопроверке обязательно оглянуться на: состоятельны ли классификация за 30 секунд, причина продолжать смотреть через 3 минуты, причина дочитывать на 30 тысячах знаков / в первом томе.

## Формулировки вывода по умолчанию

- По умолчанию поддерживается: четыре внешних документа в наличии / рабочая версия с недостающими документами / рабочая версия на доработку.
- Вывод обязательно должен ясно сказать: какие файлы относятся к внешним сдаваемым документам, какие — лишь к внутренним файлам на стороне автора, а также какие файлы ещё ждут дописывания / доработки.
