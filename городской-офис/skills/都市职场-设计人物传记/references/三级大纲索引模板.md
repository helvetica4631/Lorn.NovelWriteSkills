## 1. Поля дополнения индекса «Городской офисной прозы»

- Метки институциональных сцен: совещание / показатели эффективности / комплаенс / арбитраж / продвижение проекта
- Метки носителей доказательств: номер расписки / номер заявки / поток согласования / версия протокола
- Изменение положения персонажа: вес должности / принятие риска / степень доверия организации

## 2. Дополнительные пункты приёмки индекса

- [ ] Пункт индекса должен как минимум указывать назад на один «носитель, поддающийся аудиту».
- [ ] Одно и то же событие на уровнях общего плана — тома — главы должно последовательно детализироваться, а не пересказываться.
