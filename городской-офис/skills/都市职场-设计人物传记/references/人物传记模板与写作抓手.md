## 1. Поля дополнения «Городской офисной прозы»

- Профессиональная функциональная позиция: позиция власти и ответственности / позиция «крайнего» / позиция контрдействия / позиция доказательств
- Позиция организационного давления: давление вышестоящих, соперничество равных, институциональное трение
- Предпочтения в оставлении следов: заявка / OA / расписка / пропускная система / протокол совещания

## 2. Дополнительные пункты писательских зацепок

- Исполнимая цена контрдействий
