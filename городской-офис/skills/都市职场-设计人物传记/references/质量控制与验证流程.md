# Контроль качества и процесс проверки

## Критерии успеха

- Нулевые противоречия с планом
- Мотивы персонажа ясны и сопровождаются ценой
- Сеть отношений способна порождать события
- Рычаги письма можно прямо прикреплять к основному тексту
- У психологической дуги есть триггерные события и точки возврата
- Индекс может служить входом для перекрёстной проверки

## Процесс проверки

1. Завершить основной корпус биографии.
2. Сверить согласованность с общим планом / планом тома.
3. Сверить отношения с другими биографиями персонажей.
4. Проверить, можно ли напрямую использовать писательские зацепки.
5. Проверить, есть ли хотя бы одна подтверждаемая доказательствами тайна.
6. Проверить, есть ли у психологической дуги откаты, провалы и ошибки суждения.
7. Дополнить индекс, обеспечив возможность обратной проверки.

## Частые причины переделки

- Много меток, мало рычагов письма
- Психологический рост выглядит как резюме, а не как траектория событий
- В сети отношений нет структуры власти
- Не прописаны границы способностей, персонаж выглядит всемогущим инструментом
