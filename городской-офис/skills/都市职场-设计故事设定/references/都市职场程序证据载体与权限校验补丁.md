# Патч: носители процедурных доказательств и проверка полномочий в «Городской офисной прозе»

## 适用方向

- 裁员、PIP、调岗降薪、绩效、背锅、背调、外包、仲裁、舆情等现实组织冲突
- 需要把高概念、技术包装或信息不对称压回程序链、证据链、职业链时

## 默认冲突入口

- 裁员名单被提前泄露或被二次加工
- PIP / 绩效口径前后不一
- 调岗降薪的通知链、回执链、沟通链互相打架
- 背调反馈被人为放大、误传或定向卡住
- 外包切割、项目归责、权限回收、舆情甩锅
- 仲裁 / 投诉 / 举报前后的材料失真与窗口卡点

## Приоритетные носители доказательств «Городской офисной прозы»

- OA / 审批流 / 回执 / 工单 / 绩效表 / 报销与交接单
- 考勤 / 门禁 / VPN / 登录日志 / 版本记录 / 权限变更记录
- 群聊 / 邮件 / 会议纪要 / 录音 / 培训记录 / 录屏
- 合同 / 外包附件 / 背调反馈 / 仲裁材料 / 公告 / 通知口径

## 关键字段默认要答清

- Кто оставил
- 什么时候留的
- Кто может менять
- Кто может удалять
- 谁能导出
- 谁能卡住验证动作
- 外部验证出口在哪里
- Если затрагиваются условия / возврат платежей / арбитраж / исполнение, ещё нужно ответить: кто платит первым, до какого шага платёж считается вступившим в силу, с какого момента начинается нарушение, кто оставляет следы взыскания, откуда брать номер исполнения и обратную связь по контролю

## 默认链路

原始载体 → 时间戳 / 版本 → 权限节点 → 回执 / 导出 → 外部验证 → 现实后果

## Патч цепочки условий / исполнения / возврата платежей

Подходит для: «сначала оплата, потом подписание», платежей в рассрочку, нарушения мирового соглашения, трудного исполнения, пустого контроля, «притворился мёртвым» после первого поступления.

По умолчанию в первую очередь дополнять:

- Номер принятия к исполнению / обратная связь по контролю / заголовок постановления или образец расписки
- Сумма первого платежа / последующие узлы / срабатывание просрочки / последствия нарушения
- Первый платёжный документ / следы взыскания / текстовые формулировки противоположной стороны: «нет денег / подождите ещё / сначала отзовите, потом заплачу»

Цепочка по умолчанию:

Договорились или выиграли дело → номер / обратная связь по контролю прибивают реальность → написать структуру платежей и срабатывание нарушения → оставить первый платёжный документ → следы взыскания при просрочке → эскалация к исполнению / арбитражу / общественному мнению / организационным последствиям

## Напоминания по письму в «Городской офисной прозе»

- Не писать «процесс пройден» как пустое слово; лучше всего спрессовать процесс в: действие → носитель / номер → последствие.
- Не писать только «противник тянет время», а писать, через какие формулировки, какие таблицы, какие согласования, какое молчание это происходит.
- Если настройка говорит, что она очень жёсткая, но нет первого платёжного документа, внешнего выхода проверки или точки срабатывания нарушения, как правило, она всё ещё остаётся на уровне словесной защиты прав.

## 警戒线

- 禁止只写“有证据”，不写证据从哪来、怎么拿、谁能卡。
- 禁止把组织权限写成想开就开、想查就查。
- 禁止把高风险现实细节写成操作教程。
- 禁止只有概念包装，没有现实流程落点。
- Запрещено ошибочно писать «договорились / выиграли дело / подписали» как конечный возврат; самые частые болевые точки «Городской офисной прозы» нередко возникают именно на этапе реализации.
