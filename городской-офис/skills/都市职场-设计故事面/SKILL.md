这是题材包装层与兼容入口。命中本技能时，**必须优先强制加载**当前题材 Skill 与 `通用-设计故事面`；当前题材 Skill 负责题材口径与边界，`通用-设计故事面` 负责共性骨架与通用流程。

## 对应通用 Skill

- `通用-设计故事面`

## 本层职责

- 保留“都市职场-设计故事面”这个题材入口名。
- 把故事面骨架设计任务路由到 `通用-设计故事面`。
- 不再在本文件重复维护已迁移到通用层的故事面共性结构、规则与模板。

## 常见触发词 / 用户说法速查

- Помоги сделать грани истории «Городской офисной прозы»
- 这个 M0 / X 线故事面不够能供血
- 重写这份故事面，让它能撑分卷
- Плотно сцепи общественные темы с институциональными последствиями / последствиями для отношений / последствиями для заработка
- 故事面太概念化，帮我落地

## 何时使用

- 要新建一个 `M0` 或 `X##` 故事面文件时。
- Когда нужно переписать имеющуюся грань истории, чтобы она лучше поддерживала тома, главы и единицы-события.
- 要审计一个故事面是否存在“概念很强、正文很弱”问题时。

## 题材补充边界

- 题材名与入口兼容性保留在本包装层。
- Если в дальнейшем понадобится дополнить специфические для «Городской офисной прозы» примеры граней истории, платформенные предпочтения или конкретные склонности в зацепах, их следует оставлять на жанровой стороне и не заливать обратно в общий слой.
