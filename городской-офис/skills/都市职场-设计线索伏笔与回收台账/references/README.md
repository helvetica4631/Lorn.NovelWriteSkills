# Дополнительные правила реестра улик и зацепок «Городской офисной прозы»

本文件作为题材包装层补充说明，默认与 `通用-设计线索伏笔与回收台账` 配合使用。

## I. Что дополнительно записывать в реестре «Городской офисной прозы»

除通用字段外，关键条目建议额外记录：

- **Городской интерфейс**: контактные поверхности — управляющая компания / больница / школа / платформа / организация / сообщество / СМИ / транспорт и т. п.;
- **留痕类型**：空间留痕 / 行为留痕 / 数字留痕 / 关系留痕；
- **Историческая связь**: новая ли это улика, эхо старого вопроса или мост между ними;
- **Процедурное сопротивление**: кто будет её тормозить, затягивать, давить, прояснять и опровергать.
- **Поле полномочий**: кто может видеть, кто может менять, кто может дописать задним числом, кто может задержать расписку.

## II. Исторические следы и три временные оси

Многие улики в длинной «Городской офисной прозе» складываются не в одной временной точке, а одновременно затрагивают:

- **Ось исторических фактов**: что именно произошло в тот год;
- **Ось текущей обработки**: кто сейчас продолжает скрывать, повторять, использовать или обращать старый вопрос;
- **揭示时间轴**：主角与读者是按什么顺序重新知道这些事。

建台账时，尽量避免把三条时间轴压成一条平线；否则容易出现“作者知道很多，读者只看到一团雾”。

## III. Проверка причинного самодоказательства для городских жанров

### В ключевых записях типа «переворот» дополнять как минимум три пункта

- **首个可见信号**：读者第一次在哪个都市场景里见到它；
- **最终验证动作**：主角靠什么现实动作把它坐实；
- **揭示后余波**：真相出来后，哪层关系或秩序被重新改写。

### 常见失真信号

- 前文没有足够留痕，终局只能靠一段解释硬兜；
- 误导只有遮挡，没有“为什么看起来像正常城市流程”的合理错觉；
- После раскрытия истины читатель, оглядываясь на предыдущий текст, всё ещё не может ухватить точку приземления доказательства, на которую можно сослаться.

## 四、都市题材的回收奖励

一条回收，最好至少打中以下三项中的两项：

- **认知奖励**：读者突然看懂此前某个反常细节；
- **关系奖励**：人物之间的信任、敌意或站队被改写；
- **风险奖励**：问题虽然解释了，但城市系统里的更大裂缝也露出来了。
