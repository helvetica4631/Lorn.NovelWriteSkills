# Таблица заезженных слов городского жанра

> Источник: усвоено из железных языковых правил InkOS `urban.md` и исследования высокочастотных слов «машинного» письма
> Область применения: жанры «Городская офисная проза», городская бытовая проза
> 运用方式：创作时主动避开，审阅时扫描超标项
> 控制标准：每千字不超过 2 次

## 一级疲劳词（高优先级，尽量不用）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 迅速分析 («быстро проанализировал») | Высокочастотное сочетание «машинного» письма, нарушает железное правило городской разговорности | Заменять конкретным действием (перелистнул договор на третью страницу / прошёлся пальцем по цифрам) |
| 信息差 («информационный разрыв») | Сетевой термин, уже чрезмерно использованный | Писать конкретную информационную асимметрию (он не знал, что поставщика уже сменили) |
| 商业帝国 («бизнес-империя») | Универсальное преувеличивающее слово | Писать конкретный масштаб (три филиала / месячный оборот тридцать миллионов) |
| 雷霆手段 («громовые методы») | Пустое описание силы | Писать конкретное действие (прямо снял менеджера с должности / хлопнул бухгалтерской книгой по столу) |
| 人脉资源 («ресурс связей») | Абстрактное понятие | Писать конкретные отношения (господин Чжан должен ему услугу / старый однокашник в управлении по делам промышленности и торговли) |

## 二级疲劳词（中优先级，控制使用频率）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 博弈 («игра / стратегическое противоборство») | Типичное проникновение коммерческого термина в повествование | Писать конкретное поведение (переговоры / обмен / давление) |
| 布局 («расстановка») | Слишком абстрактное описание замысла | Писать конкретные шаги (сначала пустить слух / дождаться хода противника / затем раскрыть козыри) |
| 运筹帷幄 («планировать, не выходя из шатра») | Суждение с позиции бога | Задним числом из результата выглядит так, будто главный герой всё предусмотрел; использовать реже |
| 碾压 («подавить в пыль») | Универсальное слово 爽-романа, снижает ощущение реальности конфликта | Писать конкретный разрыв преимущества |
| 大佬 («большая шишка») | Превращает персонажа в ярлык, ослабляет дифференциацию | Обращаться по конкретной идентичности (господин Фан / начальник Чжан / тот, в золотых часах) |

## 三级疲劳词（辅助级，仅密集出现时处理）

| 疲劳词 | 说明 |
| -------- | ------ |
| 然而/但是 («однако / но») | Подряд идущие делают повествование аналитическим по тону |
| 值得注意的是 («стоит отметить, что») | Шаблонное начало, особенно неуместное в городской прозе |
| 综上所述 («резюмируя вышесказанное») | Интонация коммерческого отчёта, запрещено входить в основной текст |
| 首先/其次/最后 («во-первых / во-вторых / в-последних») | Списочный стиль, основной текст не должен превышать одноуровневой структуры |
| 一定程度上 («в известной степени») | Расплывчатая оговорка, ослабляет ощущение силы суждения |

## 疲劳词处理原则

1. **В первую очередь удалять или заменять слова первого уровня**: слова первого уровня в тексте «Городской офисной прозы» должны быть почти нулевыми.
2. **Контроль плотности слов второго уровня**: не более 1 раза на тысячу знаков.
3. **三级词仅连续密集出现时才处理**。
4. **Не дублировать правоприменение с городскими языковыми железными правилами InkOS**: эта таблица сосредоточена на уровне лексики, а проблемы структуры языка (например, запрет абзацев-анализа с позиции бога) решает `InkOS都市题材规则.md`.
