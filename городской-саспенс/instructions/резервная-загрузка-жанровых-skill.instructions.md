# Механизм резервной загрузки жанровых Skill

В VS Code существует нераскрытый лимит на число регистрируемых skill. После его превышения skill вида `<название жанра>-*` могут выдавать ошибку «не зарегистрирован / не существует». Это системное ограничение, а не проблема самого skill.

## Обязательный порядок резервной загрузки

Если skill не загрузился, действуй в таком порядке:

1. **Повторная загрузка** → ещё раз вызови команду загрузки skill.
2. **Загрузка по пути** → если повтор не помог, загрузи skill напрямую через `skill(".github/题材专用Skills/<название жанра>-{название skill}")` (это надёжнее, чем читать файлы вручную через `read_file`).
3. **Ручной откат** → если загрузка по пути не сработала, прочитай через `read_file` соответствующий `SKILL.md` и все файлы из `references/`.
4. **Загрузка и исполнение** → получив содержимое skill, немедленно действуй по его правилам; откладывать исполнение ни по какой причине нельзя.
