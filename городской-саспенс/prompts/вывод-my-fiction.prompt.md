# Единый промпт вывода «версии для My Fiction» романа жанра «Городской саспенс»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в английскую версию 【Городской саспенс】, лучше подходящую для My Fiction: сохранить ключевую информацию, соблюдать английские шлюзы, выводить в правильный каталог, сохраняя продвижение дела, тягу отношений и мотивацию продолжать читать.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/создание-основного-текста.prompt.md`
- `.github/prompts/шлифовка-основного-текста.prompt.md`
- `.github/prompts/устранение-духа-ии.prompt.md`

### 1.2 Жанровый вход

- `.github/skills/городской-саспенс-вывод-my-fiction/SKILL.md`
- `.github/skills/городской-саспенс-вывод-my-fiction/references/границы-жанра-и-источник.md`
- `.github/skills/городской-саспенс-вывод-my-fiction/references/детали-исполнения-и-жанровый-патч.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `общий-вывод-my-fiction` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку расследования, реальные процедуры и нулевое добавление фактов, затем усилить английское ощущение интерактивного следования за обновлениями и тягу отношений.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов портить «липкость» глав.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `My Fiction/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)
- `Len` основного текста не ниже 6500
- Кроме строки `## 作者有话说`, китайского / CJK быть не должно
- Нельзя писать «Городской саспенс» как английский текст с одним лишь продвижением отношений, без каркаса расследования

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, английские шлюзы, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
