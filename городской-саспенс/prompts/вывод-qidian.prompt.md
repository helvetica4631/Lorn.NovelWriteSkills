# Единый промпт вывода «версии для Qidian» романа жанра «Городской саспенс»

## Статус миграции (жёстко)

Этот Prompt пока прошёл лишь сжатие до тонкого входа и переделку маршрутизации, **его не следует считать завершившим перенос без потерь**. При срабатывании этого входа его можно использовать как жанровый вход и маршрутизатор Skill, но для достижения переноса без потерь по-прежнему нужно дополнительно выполнить отображение по разделам и возврат детальных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【Городской саспенс】, лучше подходящую контексту Qidian: сохранить ключевую информацию, соблюдать платформенные шлюзы, выводить в правильный каталог, сохраняя длинную дистанцию продолжения чтения, награды на уровне главы и сильный драйв в конце главы.

- Объём основного текста: определяется по «диапазону знаков по умолчанию для платформы» из `общий-вывод-*/SKILL.md`- Слово от автора: 200–300 знаков CJK
