# Единый промпт вывода «версии для Sina Weibo» романа жанра «Городской саспенс»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【Городской саспенс】, лучше подходящую контексту Sina Weibo: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя цепочку доказательств, привязку к реальным общественным темам и драйв комментариев.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

- `.github/prompts/шлифовка-основного-текста.prompt.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем в порядке «`题材边界与来源` → `平台研究补充` → `执行细则与题材补丁` → `分节级补救映射与详细规则回填`» прочитать `общий-вывод-weibo` и его references; жанровый Skill дальше направляет в соответствующий общий Skill.
3. Сначала сохранить цепочку дела, цепочку доказательств, привязку к реальным общественным темам, выбор персонажей и нулевое добавление фактов, затем усилить для Weibo отрывистую цепкость, драйв комментариев и точку распространения.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов превращать текст в пост-комментарий, редакционную статью или текст для «горячего поиска».

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `新浪微博/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `общий-вывод-*/SKILL.md`
- Нельзя писать «Городской саспенс» как комментаторскую пустую рукопись с одним лишь тоном распространения, без каркаса дела, давления реальности и цепочки доказательств

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи платформенных исследований, детали исполнения, правила доработки по разделам, детальные правила заголовка и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill + четыре references».

В этом проходе дополнительно усвоены ключевые моменты: ощущение пережитого лично от первого лица, тематический срез, драйв комментариев и привязка к реальным общественным темам.
