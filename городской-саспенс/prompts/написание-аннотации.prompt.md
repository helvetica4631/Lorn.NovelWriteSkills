# Написание содержания аннотации

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-написание-аннотации`.

Если в этом раунде ещё нужно сначала определить жанровое позиционирование, ось грани истории или платформенные различия, можно по необходимости дополнительно вызывать: `общий-проектирование-позиционирования-жанра`, `общий-проектирование-граней-истории`, `общий-адаптация-под-платформы`.

Prompt не имеет права, минуя жанровый Skill, «голо» использовать общие правила аннотаций.

## Обязанности, которые остаются только у этого Prompt

- Единый вход задач содержания аннотаций
- Сохраняет тип задачи, минимальный вход, запись в самостоятельный файл и минимальное пояснение сдачи
- Маршрутизирует основные правила в `общий-написание-аннотации`

## Минимальный вход

- Тип задачи: серия-вся книга / часть или том / глава
- Заголовок
- Ключевые персонажи
- Дифференцирующая торговая точка одной фразой
- Явный конфликт (открытая линия)
- Эмоциональное ядро
- Целевая платформа (необязательно)

## Минимальные ограничения исполнения

- Аннотация должна сначала ответить на вопрос «кого втянули в какую игру и что ему сейчас грозит потерять», а не просто рассказывать про сеттинг
- В каждой версии должен быть 1 основной крючок, нельзя нагромождать продающие точки параллельно
- По умолчанию записывать в самостоятельный файл; общая библиотека / файл-сборник содержит только индекс и пояснения версий
- Если пользователь не уточнил, по умолчанию консервативно дописывать новую версию, не стирая прежний текст сразу
- Только если пользователь явно сказал «только набросать, файлы не трогать», разрешается не записывать на диск

## Выдача по умолчанию

- Не менее 1 основной версии аннотации
- По необходимости дополнить: краткую версию / версию с платформенным акцентом
- В диалоге как минимум пояснить: в какой файл записано, перезапись или дописывание, приложены ли самопроверка / Rubric

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `городской-саспенс-написание-аннотации` и его общее ядро, и больше не ведётся параллельно в этом Prompt:

- Шаблон трёхуровневой структуры «серия / том / глава» и красная линия против смещения уровней
- Кнопки клика платформы, порядок входов и сигналы провала
- Платформенные различия, нижняя граница читаемости, процесс переписывания и канон Rubric
- Правила послойной записи аннотаций в разные файлы, управления версиями и индекса общей библиотеки
- Для жанра «Городской саспенс»: патчи — аномальные доказательства, процедурное трение, реальная цена и долгая загадка

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящие структурные шаблоны, платформенные различия, правила записи на диск и патчи аннотаций жанра «Городской саспенс» нужно читать в соответствующих Skill и исполнять там.
