# Помощник по написанию биографий персонажей «Названия произведения» жанра «Городской саспенс»

## Связанные навыки (специализированные для биографий персонажей)

[`общий-проектирование-биографии-персонажей`｜проектирование биографий персонажей](../skills/общий-проектирование-биографии-персонажей/SKILL.md)

При следующих задачах необходимо в первую очередь загрузить и соблюдать этот skill:

- Создание новой биографии персонажа
- Переписывание старой биографии
- Дополнение крючков для письма о персонаже
- Дополнение психологической дуги и трёхуровневого индекса

## Цель задачи
Написать или изменить подробную биографию персонажа в романе / триллере «Названия произведения» жанра «Городской саспенс», обеспечив насыщенность образа, согласованность событий и высокое соответствие ключевым сюжетным линиям общего плана.

Одновременно обеспечить, чтобы информация биографии была «пригодной для записи в основной текст и для обратной сверки по ссылкам»: ключевые черты и переломы не обобщаются абстрактными ярлыками, а приземляются в цепочку **【поведенческая деталь → носитель информации (реестр / квитанция / переписка / документ / привычный предмет) → проверяемое последствие】**; и чтобы она могла поддерживать продвижение и развязку цепочки напряжения в длинном сериале.

### 🎯 Целевое позиционирование (справочник для автора｜по умолчанию для проекта)
- Вы пишете **«источник арбитража персонажа / руководство по вызову» авторской стороны**, а не абзац основного текста и не читательскую краткую биографию.
- Главная ценность биографии: чтобы её можно было **напрямую вызывать** в последующих главах (речевые привычки, модели реакций, привычные действия, триггеры, нижняя граница / переключатели, предпочтения в оставлении следов), и при перекрёстной сверке плана и реестров она была **воспроизводимой, подотчётной и поддающейся правке**.
- Допускается небольшое количество «эмоционального повествования», но оно должно служить крючкам для письма (конкретным фразам / действиям / выбору, которые можно вписать в основной текст); запрещается заменять информацию и механизмы чисто литературными оценками.

### ⚙️ Жёсткие требования к записи файлов (дополнительные указания ИИ-помощнику)
- Этот Prompt служит для **создания или изменения конкретных файлов биографий персонажей** в рабочей области VS Code, а не для длинных пояснений о персонаже лишь в диалоге.
- Когда пользователь редактирует некий файл биографии персонажа (например: `人物传记/人物名.md`, `人物传记/周奕.md`, `人物传记/林默.md`, `人物传记/秦岚.md` и т. п.) и вызывает этот режим:

  ### Обязанности, сохраняемые этим Prompt

  - Подтвердить файл целевой биографии персонажа и стратегию записи (перезапись / дополнение)
  - Ограничить: «результат обязательно записывается обратно в реальный файл, а не выводится длинным текстом лишь в чате»
  - Ограничить: биография персонажа — источник арбитража авторской стороны, а не читательский текст

  ### Минимальные требования к сдаче при исполнении

  - Структура биографии должна полностью лечь в целевой файл
  - Крючки для письма, психологическая дуга и трёхуровневый индекс должны быть реально записаны, а не показаны лишь в чате
  - При конфликте плана, отношений персонажей, приёмов / процедур / канона доказательств необходимо явно исправить в файле или пометить риск
  - Итоговая биография должна пройти цепочку проверки из `контроль-качества-и-процесс-проверки.md`
