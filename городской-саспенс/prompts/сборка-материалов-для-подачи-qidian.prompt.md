# Упаковка материалов для внутренней подачи на Qidian

## Маршрутизация жанровых навыков (обязательно)

При формальном исполнении этого Prompt необходимо сначала загрузить: `общий-сборка-материалов-для-подачи`.

Если для текущего произведения ещё не проведена оценка применительно к Qidian, следует дополнительно вызвать `общий-оценка-подписания-на-платформе`; если нужно заодно переписать аннотацию — дополнительно вызвать `общий-написание-аннотации`.

Prompt не вправе в обход жанрового Skill напрямую использовать общие правила упаковки.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом «упаковки материалов для внутренней подачи на Qidian» для произведений жанра «Городской саспенс».
- Сохраняет минимальный ввод, цепочку взаимодействия по умолчанию, требования к записи на диск и минимальную квитанцию в чате.
- Направляет основные правила в `общий-сборка-материалов-для-подачи` и соответствующую общую основу.

## Минимальный вход

1. Название произведения / целевое название для публикации.
2. Жанровое позиционирование целевой версии для внутренней подачи на Qidian (одной фразой).
3. Источник целевого основного текста: по умолчанию в первую очередь читается начальный связный материал, из которого можно собрать связный основной текст для подачи не менее чем в `30000` знаков.
4. Общий план / план тома / ритм первых десяти глав — как минимум что-то одно из них.
5. Главный герой, аномальная механика, ключевая продающая точка.
6. Есть ли уже материалы текущей аннотации; если есть, определить — переписывать или очищать.
7. Если есть: последний основной отчёт оценки Qidian / вывод по вероятности / P0-P1 / минимальный замкнутый цикл исправлений.

## Минимальные ограничения исполнения

- Сначала обязательно прочитать и учесть исследовательские материалы по оценке Qidian и существующие выводы оценки Qidian.
- Сначала обязательно прочитать в общем плане `## 模板组合声明` («Декларация сочетания шаблонов») и подтвердить: основной шаблон, вспомогательные шаблоны, вызван ли по умолчанию откат на `九线写作总纲.md`, причину выбора и обязанности каждого шаблона; при отсутствии обязательно перечитать `CommonSkills/写作研究/起点模板/总纲模板/README.md` и по нему вывести основной шаблон.
- До выбора отрывков основного текста и написания `内投版总大纲 / 第1卷卷纲` обязательно сначала дать **вывод о соответствии шаблону**: можно ли сейчас написать два файла плана по структурным полям основного шаблона; если нет, обязательно остановить формальную упаковку или понизить до предварительной версии пакета, годного к подаче.
- `内投版总大纲 / 第1卷卷纲` обязательно писать по пунктам в соответствии со структурными полями и требованиями к формату основного шаблона; нельзя подменять их общей сводной структурой вроде «высокая концепция / продающие точки / потенциал длинной линии».
- Если есть новый основной отчёт оценки Qidian, сначала нужно учесть из него: вывод о классификации дорожки, P0 / P1, минимальный замкнутый цикл исправлений, слабые места названия / аннотации / «входной двери» и вопросы об обещании первого тома — и лишь затем решать, какие отрывки основного текста выбирать и как выражать план.
- Если сейчас нет пригодного вывода оценки Qidian, сначала нужно дополнительно вызвать `общий-оценка-подписания-на-платформе` и провести как минимум один скрининг при нехватке материалов, формальную оценку основного текста или предварительную оценку плана; нельзя выдавать результат за «формальный пакет, годный к подаче», вовсе без проверки на подписание контракта.
- При нехватке материалов сначала нужно перечислить пробелы и заметно пометить «предварительная версия пакета, годного к подаче»; нельзя подделывать основной текст или выдумывать обещания на длинную дистанцию.
- Если пользователь явно не требует «только набросок, без записи в файлы», запись в репозиторий обязательна.
- По умолчанию в первую очередь запись в каталог версии: `投稿材料/起点内投/《作品名》/vYYYY-MM-DD-rN/`, и одновременно обновляется `当前版本索引.md`
- Внешние передаваемые файлы по умолчанию включают как минимум: `01_内投版简介.md`, `02_内投版正文_至少30000字.md`, `03_内投版总大纲_至少5000字.md`, `04_内投版第1卷卷纲.md`
- Если идёт по канону Qidian, вывод о соответствии шаблону и таблица покрытия полей могут оставаться лишь во внутреннем файле авторской стороны, их нельзя включать во внешние передаваемые файлы.
- Если создаётся `05_组包自检.md`, это может быть лишь внутренний файл авторской стороны, он не отправляется вместе с рукописью; его содержимое нельзя писать как анализ сильнейшего / слабейшего звена или рекомендации по подаче для редактора.
- Если уже есть предыдущие версии, по умолчанию создаётся каталог следующей версии, без смешения со старой; перезапись в том же каталоге версии допустима лишь тогда, когда пользователь явно просит продолжить правку текущей версии.
- В ответе нужно как минимум указать: в какой корневой каталог произведения записано, в какой каталог версии, обновлён ли `当前版本索引.md`, какие файлы относятся к внутренним файлам авторской стороны и какие файлы ещё нужно дописать / вернуть на доработку.
- В внешних передаваемых файлах запрещено любое самооценивание, самовосхваление, «сильнейшее / слабейшее звено на данный момент», остаточные комментарии о рисках, `建议现在内投` («рекомендуется подавать сейчас»), `可以直接进入编辑内投` («можно сразу передавать редактору») и прочее содержимое, где вместо редактора выносится суждение.

## Выдача по умолчанию

- Аннотация версии для внутренней подачи
- Основной текст версии для внутренней подачи (связный основной текст не менее `30000` знаков)
- Общий план версии для внутренней подачи (не менее `5000` знаков)
- План `1`-го тома версии для внутренней подачи

Внутренние файлы авторской стороны (если созданы, вместе с рукописью не отправляются):

- Самопроверка упаковки

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `городской-саспенс-сборка-материалов-для-подачи` и `общий-сборка-материалов-для-подачи`, а основной текст в этом Prompt параллельно больше не сопровождается:

- Спецификация трёх / четырёх файлов для внутренней подачи на Qidian, узлы-арбитры, процесс исполнения и критерии завершения
- Запись файлов внутренней подачи на Qidian на диск, стратегия версий и минимальная квитанция в чате
- Классификация жанра «Городской саспенс» в мужском сегменте Qidian, арбитры отбора основного текста и риски ошибочной упаковки
- По умолчанию сначала учесть выводы быстрого аудита из новой версии оценки подписания контракта с платформой, P0-P1 и минимальный замкнутый цикл исправлений, и лишь затем определять способ написания пакета для внутренней подачи
- Правила маршрутизации по умолчанию с `городской-саспенс-оценка-подписания-на-платформе` и `общий-написание-аннотации`
