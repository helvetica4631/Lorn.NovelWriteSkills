# Создание основного текста романа

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-создание-основного-текста`.

Если задача касается преемственности соседних глав, возврата старых вопросов, «температуры» зацепок и тяги к следующей главе, необходимо продолжать комбинированный вызов: `общий-управление-горячими-и-холодными-линиями` + `общий-генерация-контрольной-карточки-главы`.

Prompt не вправе в обход жанрового Skill напрямую использовать общие правила создания основного текста.

## Цепочка комбинирования по умолчанию

- Контроль перед написанием: `общий-управление-горячими-и-холодными-линиями` + `общий-генерация-контрольной-карточки-главы`
- Строительство основного текста: `общий-создание-основного-текста`
- Разбор на сцены: в первую очередь принимает `общий-исполнение-сценической-единицы`; для глав с плотными диалогами дополнительно `общий-исполнение-диалога-конфликта`; для глав «в упор» в микропространстве дополнительно `общий-исполнение-сцены-в-ограниченном-пространстве`
- Локальное усиление: по необходимости вызывать `общий-усиление-начала-главы`, `общий-усиление-хука-конца-главы`
- Очистка чистового текста: по необходимости вызывать `общий-шлифовка-основного-текста`
- При явном шаблонном тоне / «неживом голосе»: дополнительно вызывать `общий-устранение-духа-ии`

Если позже нужно войти в полный замкнутый цикл главы, порядок по умолчанию следует понимать так: основной текст → рецензия основного текста главы → доработка → шлифовка слова от автора → читательские заметки / отзыв на главу; нельзя позволять `作者有话说` («Слово от автора») или удалению ИИ-привкуса опережать структурную доработку и «латать» основной текст.

Когда у главы уже есть чёткий план тома, список глав или задача по единице-делу, контроль перед написанием по умолчанию нельзя опускать; сначала следует сжать вышестоящую задачу в контрольную карту, и лишь затем входить в строительство основного текста.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом создания основного текста главы в жанре «Городской саспенс»
- Сохраняет платформу по умолчанию, каталог основного текста по умолчанию, минимальный ввод, минимальные ограничения записи обратно и минимальную квитанцию в чате
- Направляет основные правила в `общий-создание-основного-текста` и связанные общие Skill

## Использование по умолчанию

- Целевая платформа определяется основной платформой вывода в Agents.md в корне проекта
- Каталог текста по умолчанию: `小说正文/`
- Продукты по умолчанию: эпиграф главы, основной текст, крючок в конце главы, `## 作者有话说` («Слово от автора»), `## 章节后记` («Послесловие к главе»)
- Запись по умолчанию: прямая запись обратно в целевой файл Markdown; если пользователь не уточнил, перезаписывать или дописывать, придерживаться консервативной стратегии

## Минимальный вход

- `OUTLINE_FILE` или чёткие материалы плана главы
- `CHAPTER_FILE` или выводимый путь к целевой главе
- Необходимый связанный контекст: персонажи / сеттинг / зацепки / хронология (если текущая глава явно от них зависит)

## Минимальные ограничения исполнения

- В основном тексте, эпиграфе главы и `## 作者有话说` («Слово от автора») не должно быть управленческих номеров авторской стороны; исключение — реальные номера внутри сюжета.
- В основном тексте и во встроенных в него интерфейсах / журналах / номерах / квитанциях по умолчанию не должно быть конкретных годов.
- В каждой главе должны быть чёткая читательская награда и краткосрочная цель; в середине главы должно быть реализовано одно существенное продвижение; в конце главы персонаж должен быть подтолкнут к худшей ситуации или более опасному вопросу.
- Нельзя писать процедуры, доказательства и институциональные препятствия как учебник; нужно писать их как то, что персонажи переживают.
- Если пользователь явно не требует «только обсудить, не сохранять в файл», обязательно записывать прямо в целевой файл Markdown.

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `городской-саспенс-создание-основного-текста`, `городской-саспенс-управление-горячими-и-холодными-линиями`, `городской-саспенс-генерация-контрольной-карточки-главы` и соответствующую им общую основу, а основной текст в этом Prompt параллельно больше не сопровождается:

- Ритм глав Qidian, критерии успеха и логика преемственности соседних глав
- Что необходимо прочитать перед написанием, список используемых ресурсов и требования к выравниванию с источником арбитража
- Подробные нормы эпиграфа главы, `## 作者有话说` («Слово от автора») и `## 章节后记` («Послесловие к главе»)
- Для жанра «Городской саспенс»: процедурное сопротивление, носители доказательств, границы реальных номеров и приёмы создания городского давления
- Приёмы против ИИ-привкуса, конкретизации эмоций, отчуждения повседневности, цепляющего начала главы и крючка в конце главы
- Мост строительства основного текста: как контрольная карта дальше разбивается на сценические единицы, давление диалогом и кадры микропространства
