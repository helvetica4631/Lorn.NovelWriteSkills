# Анализ конкурентов

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-分析竞对作品`.

Если вход-Prompt противоречит правилам этого Skill, приоритет имеют правила пула образцов, доказательств, записи на диск и отчётов из Skill и его references.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом анализа конкурентов жанра «Городской саспенс»
- Сохраняет минимальный ввод, канон рейтингов по умолчанию, каталог записи по умолчанию и минимальный порядок вывода
- Направляет правила поиска по рейтингам, поштучного углублённого поиска, отчёта по одной книге и сводного горизонтального обзора в `通用-分析竞对作品`

## Минимальный вход

- Проект, который сейчас обслуживается / текущее произведение (если есть)
- Целевая платформа (по умолчанию из `Agents.md` в корне проекта берётся основная платформа вывода)
- Канон жанра: городской саспенс / городской триллер / городские странные истории и т. п. (если не указан — жанровый Skill определяет по рабочей области)
- Значение N для топ-N (если не указано, по умолчанию 10)
- Если есть: общий план, планы томов, основной текст, персонажи, сеттинг, замечания рецензии и прочие материалы текущего проекта
- Если нужен собственный каталог вывода, его тоже нужно указать

## Минимальные ограничения исполнения

- Сначала обязательно прочитать материалы рабочей области, относящиеся к жанру «Городской саспенс», целевой платформе и текущему проекту, и лишь затем определять измерения конкурентного анализа этого прохода.
- Сначала нужно зафиксировать рейтинг и пул образцов, и только потом искать углублённо по каждой книге; нельзя пропускать пул образцов и выбирать книги по впечатлению.
- Если рейтинг не указан, по умолчанию из исследовательского отчёта целевой платформы берётся пул-кандидат топ-10, ближайший к коммерческой конкурентной позиции
- По умолчанию из пула топ-N сначала выбираются `3–5` основных образцов для четырёхслойного разбора; если пользователь явно требует записи на диск всего топ-N по каждой книге, тогда расширяемся на все образцы.
- Для каждого образца нужно записать отдельный подробный отчёт по анализу конкурентов; нельзя сжимать все произведения в одно смешанное впечатление.
- Если пользователь дополнительно просит горизонтальную сводную таблицу, её нужно дополнить сводным отчётом уже после завершения отчётов по каждой книге.
- Отчёт должен опираться на анализ, сравнение и обобщение; нельзя переносить крупные куски основного текста или длинные отзывы.
- По умолчанию отчёты в первую очередь пишутся в `竞对分析/`, и ведётся главный отчёт по одному и тому же произведению, а не создаются снова и снова параллельные почти дублирующие файлы.

## Выдача по умолчанию

- Зафиксированный пул образцов топ-N того же жанра
- Подробный отчёт по анализу конкурентов отдельно по каждому произведению
- Если пользователь просит: дополнительный горизонтальный сводный обзор
- В диалоге как минимум подтвердить: какие ключевые материалы прочитаны в этом проходе, какие образцы зафиксированы, куда записаны отчёты

## Основное содержимое, перенесённое в Skill

Следующее содержимое перенесено в `都市悬疑-分析竞对作品` и его общее ядро, и больше не ведётся параллельно в этом Prompt:

- Правила выделения измерений анализа рабочей области
- Правила поиска по рейтингам и определения пула образцов
- Шаблон отчёта по одной книге, шаблон сводного обзора и правила записи на диск
- Специальные измерения жанра «Городской саспенс», границы отбора образцов и нормы доказательств
- Границы авторского права и цитирования, формулировки слепых зон суждения

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящий процесс анализа конкурентов, правила пула образцов, специальные измерения жанра и шаблоны отчётов нужно читать в соответствующем жанровом Skill и исполнять там.
