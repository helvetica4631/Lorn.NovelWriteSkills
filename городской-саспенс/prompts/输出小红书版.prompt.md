# Единый промпт вывода «версии для Xiaohongshu» романа жанра «Городской саспенс»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【Городской саспенс】, лучше подходящую контексту Xiaohongshu: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя цепочку доказательств, телесную аномалию и эмпатию к простым людям.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

- `.github/prompts/正文润色.prompt.md`
- `.github/prompts/去AI味.prompt.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем в порядке «`题材边界与来源` → `平台研究补充` → `执行细则与题材补丁` → `分节级补救映射与详细规则回填`» прочитать `通用-输出小红书版` и его references; жанровый Skill дальше направляет в соответствующий общий Skill.
3. Сначала сохранить цепочку дела, цепочку доказательств, реальные повседневные сцены, тайны простых людей и нулевое добавление фактов, затем усилить для Xiaohongshu телесную аномалию, «приклеивание» на мобильных и эмпатию к простым людям.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов превращать текст в тон заметок, «впечатления от прочитанного» или «травяной» пост.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `小红书/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Нельзя писать «Городской саспенс» как пустую рукопись в жанре «делюсь опытом» с одними лишь телесными ощущениями и эмоциями, без каркаса дела и цепочки доказательств

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи платформенных исследований, детали исполнения, правила доработки по разделам, детальные правила заголовка и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill + четыре references».

В этом проходе дополнительно усвоены ключевые моменты: сначала телесная аномалия, эмпатия к простым людям / «офисному планктону», короткие фразы для мобильных и запоминающиеся ощущения, которыми хочется делиться.
