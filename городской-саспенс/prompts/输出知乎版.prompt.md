# Единый промпт вывода «версии для Zhihu (Yanxuan / колонки / сериал)» романа жанра «Городской саспенс»

## Статус миграции (жёстко)

Этот Prompt пока прошёл лишь сжатие до тонкого входа и переделку маршрутизации, **его не следует считать завершившим перенос без потерь**. При срабатывании этого входа его можно использовать как жанровый вход и маршрутизатор Skill, но для достижения переноса без потерь по-прежнему нужно дополнительно выполнить отображение по разделам и возврат детальных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【Городской саспенс】, лучше подходящую контексту Zhihu: сохранить ключевую информацию, соблюдать платформенные шлюзы, выводить в правильный каталог, сохраняя высокую концепцию, отображение на реальность, логику расследования и чувство участия читателя.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/创建小说正文.prompt.md`
- `.github/prompts/正文润色.prompt.md`
- `.github/prompts/去AI味.prompt.md`

### 1.2 Жанровый вход

- `.github/skills/都市悬疑-输出知乎版/SKILL.md`
- `.github/skills/都市悬疑-输出知乎版/references/题材边界与来源.md`
- `.github/skills/都市悬疑-输出知乎版/references/执行细则与题材补丁.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出知乎版` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Через жанровый Skill зафиксировать реальные общественные темы, логику дела, цепочку доказательств и жанровые патчи, одновременно унаследовав общие положения платформы Zhihu.
4. Сначала сохранить жанровый каркас и нулевое добавление фактов, затем усилить в духе Zhihu, и лишь в последнюю очередь — снижение схожести.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `知乎/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Заголовок должен соответствовать склонности контекста Zhihu к фразе-правилу / фразе-цене / постановке вопроса
- Нельзя писать «Городской саспенс» как текст-объяснение концепции, рассуждение или текст с одними лишь мнениями без дела

## 4. Пояснение о текущем состоянии

На данный момент выполнено лишь сжатие в виде «тонкий вход + маршрутизация + сводные refs»; это **не равнозначно тому, что исходный длинный Prompt уже разобран и перенесён без потерь**.

Для достижения переноса без потерь по-прежнему нужно как минимум дополнить:

- Журнал отображения исходного Prompt по разделам;
- Поэлементные места принятия подробных жёстких ограничений, исследовательских патчей и деталей исполнения, которые были сжаты;
- Проверяемое соответствие «исходный пункт → новый файл-носитель».
