### 2. Напоминание о сочетании приёмов

Городской саспенс — типичный событие-ориентированный жанр, принципиально отличающийся от женской романтики (ориентированной на отношения):

- **Обязателен слой ключевого конфликта**: основной приём — «разгадка / расследование, сюжетный случай-юнит», способ организации длинной основной линии — «закулисный злодей»
- **Рекомендуется для слоя запуска повествования**: перерождение (восполнение сожаления «знаю убийцу, но нет доказательств»), повседневное / реалистичное начало (сверхъестественные элементы нужно прижать к рамке реальности)
- **Рекомендуется для слоя непрерывного драйва**: двойная линия «единицы-дела + основная линия» (в каждом томе одно замкнутое дело + продвижение скрытой линии долгой загадки)
- **Слой эмоциональной зацепки**: вспомогательная позиция. Контрастная группа / «обратный удар», отношения наставника и ученика встречаются часто, но не определяют движущую силу
- **Антишаблонные новшества**: социальная школа глубоко копает человеческую природу vs «чистая» школа с изящными уловками; либо слияние: «детектив + офис», «детектив + городские способности»

### 3. Элементы, требующие специализации на стадии инициализации

| Элемент | Значение в «Городском саспенсе» | Пункт проверки инициализации |
| --- | --- | --- |
| **Профессиональный разрез** | С какой профессиональной позиции главный герой входит в дело? Судмедэксперт / следователь / журналист / юрист / психолог / обычный человек, втянутый в историю | Обладает ли профессия правдоподобностью «приблизиться к ядру дела»? |
| **Система аномальных доказательств** | В чём «точка аномалии» дела? Научно объяснимое vs сверхъестественное | Совместима ли система доказательств с красными линиями платформы? |
| **Городское давление пространства** | Становится ли городская среда частью повествования? Городская деревня / старый жилой комплекс / офисное здание / подземное пространство | Не абстрагируется ли городское пространство в «используемый ресурс сцен»? |
| **Якорь реальной цены** | Сопровождается ли разгадка / раскрытие дела личной ценой главного героя? Давление системы / телесное и психическое истощение / разрыв отношений | Достаточна ли цена, чтобы поддержать долгое эмоциональное перетягивание? |
| **Режим выпуска информации** | Цикл «сначала задать интригу → постепенно раскрывать → частично закрывать → новая интрига» | Поддерживается ли этот цикл в планировании на уровне тома? |

### 4. Значение эмоциональной оси по умолчанию

Основная эмоциональная ось «Городского саспенса» по умолчанию опирается на главное обещание **саспенса** — основная движущая сила продолжения чтения у читателя — «хочется узнать истину». Дополняется **爽-романом** — выплата в момент раскрытия дела или удара по лицу. Кривая эмоций должна следовать:

```
Напряжение (появление дела) → недоумение (начало расследования) → частичное прояснение (получены улики) → новый вопрос (более глубокая загадка) → этапное раскрытие (конец тома) → большая интрига (продвижение долгой линии)
```

### 5. Дополнения по красным линиям платформ

- Qidian «Городской саспенс»: избегать чрезмерно кровавых / насильственных описаний; затрагивая реальные дела, делать вымышленную обработку
- Qimao / Fanqie: избегать феодально-суеверных сверхъестественных настроек (можно упаковывать как «научно неразгаданную загадку» или «психологическую иллюзию»)
- Все платформы: в реальных уголовно-следственных процедурах не должно быть явных грубых ошибок (можно ориентироваться на реальные процессы судмедэксперта / следователя из исследовательских отчётов)
