# Дополнение к шаблону отчёта оценки вероятности подписания на Qidian («Городской саспенс»)

> Этот файл **не является полным главным шаблоном**. При выполнении обязательно сначала использовать:
>
> - `CommonSkills/общий-оценка-подписания-на-платформе/references/шаблон-отчёта-оценки-подписания-на-платформе.md`

## 1. Способ использования (обязательно)

1. Сначала по общему главному шаблону завершить весь отчёт об оценке.
2. Затем дописать пункты этого файла в соответствующие разделы.
3. Этот файл занимается лишь критериями жанра «Городской саспенс» и не переписывает общий оценочный каркас.

## 2. Специальные поля жанрового дополнения

### 2.1 Классификация трека и вердикт по первому экрану (дополнение)

- Можно ли за 30 секунд прочитать как «длинный роман для продолжения чтения „Городского саспенса“»
- Не прочитывается ли ошибочно как: медленный литературный детектив / атмосферная эссеистика / демонстрация сверхъестественных зрелищ

### 2.2 Улики и цепочка доказательств (дописать)

- Можно ли вернуться к зацепкам, проверить и опровергнуть их
- Обладает ли носитель доказательства «видимостью для читателя + функцией продвижения»
- Реальны ли процедурное трение (возбуждение дела / запрос доказательств / сопротивление учреждений / временные издержки)

### 2.3 Честность дедукции (дописать)

- Есть ли точки нечестности, когда «ключевая информация известна автору, но не дана читателю»
- Можно ли опровергнуть введение в заблуждение (не принудительный разворот)

### 2.4 Запас хода первого тома и риски середины (дополнение)

- Продолжают ли юнит-случаи питать основную линию
- Нет ли в середине риска остывания: «нагромождение загадок без возврата вознаграждения»

## 3. Шаблон жанровых итоговых фраз (можно использовать напрямую)

- Нынешний наибольший блокирующий пункт (норма «Городского саспенса»):
  - Обычно «нестабильное отнесение к жанру, виртуальные доказательства, нечестная дедукция, запоздалые награды»
