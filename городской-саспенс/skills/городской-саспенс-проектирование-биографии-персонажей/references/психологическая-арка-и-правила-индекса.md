# Психологическая дуга и правила индекса

## Психологическая дуга — не список эмоций

Годная психологическая дуга должна удовлетворять:

- У каждого шага есть триггерное событие.
- Каждый шаг можно увидеть в основном тексте.
- Ключевые шаги по возможности можно вернуть к какому-то носителю (квитанции, предмету, показаниям, скриншоту, старой вещи, обращению, месту).
- Продвижение дуги в обратную сторону меняет отношения, выбор и цену.

## Рекомендуемое число шагов

- Ключевой персонаж: 30–40 шагов
- Важный персонаж: 20–30 шагов
- Второстепенный персонаж: 10–20 шагов

## Формулировка четырёх этапов

### 1. Исходное состояние

- Откуда берётся уверенность в идентичности
- На чём построено доверие к правилам
- Каков самый устойчивый якорь отношений

### 2. Потрясение и пробуждение

- Какая аномалия первой пробила его здравый смысл
- Какое расхождение формулировок / улик / отношений впервые заставило его осознать потерю контроля
- Где впервые оформились страх, стыд, гнев

### 3. Глубокое исследование

- Как он перестраивает способ понимания мира
- На какой новый метод действия он начинает полагаться
- Какая старая связь вынужденно перестраивается

### 4. Пробуждение и возрождение

- Что он в итоге осознаёт
- Как цена остаётся на нём
- Какое непрерывное давление он может оставить последующему сюжету

## Правила трёхуровневого индекса

В конце биографии персонажа обязательно сохранять «индекс соответствия сюжета трёхуровневого плана».

Рекомендуемые поля:

- Уровень источника: общий план / часть / том / глава
- Номер: например `T1.1`, `1.1`, `1.1.3`
- Временной узел
- Описание события
- Психологический этап / номер шага
- Последствия этого события для персонажа

## Частые ошибки

### 1. В психологической дуге написаны только прозрения, а не события

Исправление: после каждого поворота добавить «каким событием запущен».

### 2. В индексе только номера, нет роли персонажа

Исправление: добавить «что персонаж сделал, что потерял, что узнал в этом событии».

### 3. Психологический рост слишком чистый

Исправление: добавить повторы, откаты, провалы, ошибки суждения, чтобы дуга больше походила на человека, а не на ответ на отлично.
