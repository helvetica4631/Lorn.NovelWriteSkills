## Обязанности слоя

- Маршрутизировать общий каркас уровня общего плана в `общий-проектирование-общего-плана`.
- Продолжать сохранять жёсткие правила жанра «Городской саспенс» на уровне общего плана: цепочка доказательств, честная дедукция, процедурное трение, система нумерации, связка группы файлов уровня общего плана.

## Дополнения для жанра «Городской саспенс» (сохраняются)

- Общий план по умолчанию понимается как «файловая группа уровня общего плана», а не только правка `小说总大纲.md`.
- Три слоя `M0 / X / C` по-прежнему обязаны опираться на цепочку доказательств, изменения пула подозреваемых, процедурное трение и систему нумерации как на жёсткие зацепки.
- Каждое дело в матрице сюжетных случаев-юнитов должно чётко указывать: какой пазл оно продвигает для основной линии, какой проверяемый носитель оставляет, какую цену для персонажей или изменение границ правил приносит.
- Нельзя писать общий план городского саспенса как пояснительную записку к теме; необходимо постоянно сохранять инженерное выражение «кто что сделал → какие доказательства / номера оставил → какие последствия вызвал».

## Исходное жанровое инженерное определение (сохранено)

- «Общий план», о котором говорит этот Skill, **по умолчанию не означает единственный** `小说大纲/小说总大纲.md`.
- Это взаимосвязанная **файловая группа слоя общего плана**, как минимум включающая:
	- `小说大纲/小说总大纲.md`
	- `小说大纲/故事面/`
	- `小说大纲/伏笔与回收总纲.md`
	- `小说大纲/故事多面体大纲.md`
	- а также другие связанные файлы слоя общего плана, такие как `时间轴_总表.md`, индекс общего плана, матрицы / реестры уровня общей таблицы и т. п.
- Поэтому, когда пользователь говорит «измени общий план», по умолчанию следует сначала определить, это **правка одного файла** или **согласованная правка уровня общего плана**; если пользователь явно не ограничил, нельзя механически править только `小说总大纲.md`.
- Если пользователь устно употребляет формулировки вроде «общий план предзнаменований и перекличек», в текущем репозитории единообразно обрабатывать как `小说大纲/伏笔与回收总纲.md`.

## Когда использовать
- Пользователь хочет создать, переписать или изменить план уровня всей книги.
- Целевой файл относится к файловой группе уровня общего плана, например `小说总大纲`, `故事面/`, `伏笔与回收总纲`, `故事多面体大纲`, индекс общего плана, планирование уровня сводных таблиц.
- Основное внимание задачи — на загадке основной линии `M0`, побочных поверхностях истории `Xxx`, матрице сюжетных случаев-юнитов `Cxx`, межтомовом продвижении и приёмке уровня общего плана.

## Разделение с входным Prompt
- Входной Prompt продолжает отвечать за **общие правила**: позиционирование исполнительной версии для автора, политику записи файлов, исследование и глубокое мышление, жёсткие нормы цепочки доказательств, судейские источники, увязку временной оси с журналами, общий контроль качества.
- Этот Skill отвечает только за **специальные правила уровня общего плана**, чтобы не продолжать нагромождать во входном Prompt шаблон общего плана, приёмку общего плана и специальные ограничения общего плана.

## Порядок выполнения по умолчанию

1. Сначала по входному Prompt обработать общие ограничения и стратегию записи целевого файла.
2. Подтвердить, что текущая задача относится к «уровню общего плана», и не втягивать по ошибке задачи частей / томов.
3. Выполнить [специальные правила проектирования общего плана](references/специальные-правила-проектирования-общего-плана.md).
4. При выводе строго сверяться с [шаблон общего плана и приёмка](references/шаблон-общего-плана-и-приёмка.md).
5. Если пользователь дополнительно просит продолжить разбиение на части / тома, сначала окончательно утвердить общий план, затем вызывать `городской-саспенс-проектирование-плана-тома`.

## Минимальная сдача уровня общего плана

- Чётко указать, какие файлы уровня общего плана затрагивает данное изменение и какие обязательно нужно синхронно согласовать.
- Фраза-«фишка» всей книги и точки дифференциации.
- Загадка основной линии `M0`: условие загадки, истина, цена.
- Важные побочные линии `X01+` и матрица единичных дел `C01+`.
- Траектория межтомного продвижения, стратегия завязок и развязок, чек-лист приёмки уровня общего плана.
- Пометки о конфликтах и предложения по правке в связи с биографиями персонажей, временной осью, реестрами зацепок / пула подозреваемых.

## Запреты

- Подменять краткое содержание истории тематическими концепциями.
- Писать общий план в гранулярности планов томов и глав.
- Выдают лишь «пояснения настроек», не давая «кто что сделал → какие доказательства оставил → какую цену вызвал».
- Прыгать к детальному разбиению на тома без закрытия общего плана.
