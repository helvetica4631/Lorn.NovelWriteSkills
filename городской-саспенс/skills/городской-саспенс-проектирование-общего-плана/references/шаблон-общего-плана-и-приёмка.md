# Дополнение к шаблону общего плана и приёмке (городской саспенс)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/общий-проектирование-общего-плана/references/шаблон-общего-плана-и-приёмка.md`

## 1. Способ использования (обязательно)

1. Сначала по общему главному шаблону завершить структуру общего плана.
2. Затем наложить специальные пункты данного файла для городского саспенса.

## 2. Специальные дополнения для «Городского саспенса»

- В общем плане нужно ясно прописать четырёхзвенную связку «загадка главной линии — единица-дело — цепочка доказательств — цепочка возврата».
- Стратегические грани истории должны удовлетворять честности дедукции: ключевую информацию можно проследить, а ложные ходы — опровергнуть.
- Матрица единиц-дел в первую очередь охватывает: действия расследования, вход доказательств, процедурное трение, узлы награды.
- Межтомный рост должен отражать «расширение пула подозреваемых -> конфликт доказательств -> приближение истины -> реализация цены».

## 3. Дополнительные пункты приёмки для «Городского саспенса»

- [ ] Как минимум 1 главная линия в первых двух томах завершает замкнутый цикл «переворот доказательств + логическая самосогласованность».
- [ ] У ключевых предзнаменований полный путь «закладка — продвижение — раскрытие — отголосок».
- [ ] Инженерия дочитывания глав учла цепкость первого экрана и вознаграждение середины, избегая «нагромождения загадок».
