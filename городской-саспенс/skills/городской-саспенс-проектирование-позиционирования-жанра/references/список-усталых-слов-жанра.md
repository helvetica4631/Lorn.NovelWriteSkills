# Список «усталых слов» жанра саспенса / ужасов

> Источник: усвоено из железных языковых правил InkOS `horror.md` и исследований высокочастотных слов ИИ
> Область применения: городской саспенс, детектив-расследование
> Способ использования: при создании активно избегать, при рецензировании сканировать превышения
> Норма контроля: не более 2 раз на тысячу знаков

## Усталые слова первого уровня (высокий приоритет, по возможности не использовать)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| мрачный (阴森) | Самая высокая частота злоупотребления, уже не создаёт картины | Заменять конкретными деталями среды (запах плесени / путь холодного ветра / форма тени) |
| жуткий (诡异) | Универсальное слово, уже не создаёт ощущения ужаса | Писать конкретную аномалию (вещь не на месте / звук доносится оттуда, откуда не должен) |
| мороз по коже (毛骨悚然) | Прямо объявляет эмоцию, нарушает железное языковое правило ужаса | Заменять телесной реакцией (волоски на затылке встают / онемели кончики пальцев) |
| волна холода (一阵寒意) | Абстрактный эмоциональный ярлык | Писать конкретный перепад температуры или телесное ощущение (по шее пробежал холодок / спина прижалась к холодному стеклу) |
| тревога (不安) | Рассказчик объявляет эмоцию за персонажа | Писать наблюдаемое поведение (часто оглядывается / сжимает кулак и разжимает) |
| удушье (窒息感) | Уже чрезмерно использовано | Писать конкретное затруднение дыхания (дыхание стало поверхностным / на груди будто что-то лежит) |

## Усталые слова второго уровня (средний приоритет, контролировать частоту использования)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| темнота (黑暗) | Слишком абстрактно | Писать конкретную видимость (дверной косяк в трёх шагах расплылся в один тёмный ком) |
| тишина (寂静) | Пустое объявление среды | Писать конкретную пропажу звука (шаги пропали / дыхание стало резким) |
| страх (恐惧) | Прямо называет эмоцию | Показывать поведением (ноги подкашиваются / ногти впились в ладонь) |
| гнетущий (压抑) | Универсальное атмосферное слово | Писать конкретный источник давления (потолок такой низкий, что можно достать рукой / окно заколочено) |
| неладно (不对劲) | Расплывчатое суждение | Писать, что именно не так (окно приоткрыто на три сантиметра / на столе нет той связки ключей) |
| жуткая атмосфера (诡异的气氛) | Двойная избыточность | Прямо писать само аномальное явление |

## Усталые слова третьего уровня (вспомогательный, обрабатывать только при плотном появлении)

| Усталое слово | Пояснение |
| -------- | ------ |
| вдруг (突然) | Подряд создаёт эффект дешёвого испуга, не более 1–2 раз на главу |
| рывком (猛地) | То же |
| инстинктивно (下意识地) | Действия персонажа и так не должны проходить через размышление, отмечать не нужно |
| некий (某种) | Расплывчатый ограничитель, ослабляет картину |
| казалось / будто (似乎/好像) | Появляясь подряд, делают повествование неопределённым и ослабляют напряжение |

## Принципы обработки усталых слов

1. **В первую очередь удалять или заменять слова первого уровня**: в тексте саспенса слова первого уровня должны быть почти нулевыми.
2. **Контроль плотности слов второго уровня**: не более 1 раза на тысячу знаков.
3. **Слова третьего уровня обрабатываются только при непрерывной плотной встречаемости**: единичное появление обработку не запускает.
4. **Не дублировать обработку со списком высокочастотных слов ИИ**: этот список дополняет таблицу высокочастотных слов ИИ из `общий-устранение-духа-ии/references/радар-распознавания-духа-ии.md`, каждый проверяется независимо.
