# Дополнение к шаблону рецензии на персонажей жанра («Городской саспенс»)

Этот файл дополняет лишь **жанровый раздел рецензии на биографии персонажей «Городского саспенса»**; при выполнении обязательно сначала использовать «Каркас отчёта рецензии на биографию персонажа» из `общий-рецензия-биографии-персонажей`, а затем записать содержимое этого файла в соответствующие разделы-заполнители.

## 1. Пояснение о разделении общего / жанрового

- Перенесено в общий слой: основной каркас цепочки чтения, проверка базовой информации, определение персонажа одной фразой, функциональная позиция персонажа, общая рамка играбельности / пишемости, ярлыки и арка роста, библиотека материалов, градация проблем, оценка, рекомендации по правке, идеи для рывка `9.2+` и выдача кадров выхода / повторно используемых реплик.
- Этот файл отвечает лишь за специальные нормы рецензирования, свойственные «Городскому саспенсу»: городская идентичность и трещины институтов, функциональная позиция в деле, секреты, поддающиеся доказательству, стойкость к допросу, пути «выставления подозреваемым» и «оправдания», городские микроаномалии повседневности, жанровая специальная оценка и жанровый вывод.
