# городской-саспенс-сборка-материалов-для-подачи

Это жанровая обёртка, совместимый вход и слой маршрутизации. При срабатывании этого навыка в первую очередь необходимо принудительно загрузить текущий жанровый Skill и `общий-сборка-материалов-для-подачи`; текущий жанровый Skill отвечает за подачу «Городского саспенса» в рамках мужской прозы Qidian и ограничения маршрутизации, а `общий-сборка-материалов-для-подачи` — за общий каркас, правила четырёх элементов, запись на диск и квитанции.

## Соответствующий общий Skill

## Обязанности слоя

- Сохранять жанровое входное имя «городской-саспенс-сборка-материалов-для-подачи».
- Маршрутизировать общий каркас сборки пакета подачи в `общий-сборка-материалов-для-подачи`.
- Дополнять профессиональный зацеп, аномальные доказательства, процедурное трение, реальную цену и описание долгой загадки в жанре «Городской саспенс».
- Усваивать вывод оценки Qidian, чтобы не «втискивать» в пакет внутренней подачи рукопись, не подходящую для Qidian.

## Цепочка взаимодействия по умолчанию

- Если для текущего произведения оценка Qidian ещё не завершена или уже есть оценка, но она не усвоена в пакет, обязательно дополнительно вызвать `городской-саспенс-оценка-подписания-на-платформе`.
- Если аннотацию нужно переписать в «кликабельную версию Qidian», обязательно дополнительно вызвать `городской-саспенс-написание-аннотации`.
- При сборке пакета нельзя в обход жанрового Skill напрямую «голо» использовать общий слой или старые псевдонимы Prompt.

## Требования к исполнению полной сборки (обязательно)

- При выполнении этого Skill обязательно сначала загрузить `общий-сборка-материалов-для-подачи` и по шлюзу качества общего слоя сначала определить: остановить формальную сборку / предварительная версия подаваемого пакета / разрешить формальную сборку пакета.
- Если цель — Qidian (起点中文网), либо платформа не указана и применяется критерий Qidian по умолчанию, обязательно сначала выполнить **предварительную проверку соответствия шаблона общего плана**: сначала прочитать `

## 模板组合声明` (объявление о сочетании шаблонов), подтвердить состояние основного шаблона / вспомогательного шаблона / отката к «девяти линиям», и только затем решать, можно ли в этом раунде переходить к формальной сборке пакета.
- В жанре «Городской саспенс», если основной шаблон — `副本单元剧总纲.md`, внутренний план обязан по полям основного шаблона последовательно прописать дела / единицы-дела; нельзя подменять это обобщённым резюме в духе «высокий концепт + продающая точка + долгий потенциал».
- Если шаблон не соответствует, даже при хороших жанровых точках продажи, пробных главах и выводах оценки можно лишь понизить до «предварительной версии подаваемого пакета / версии на доработку»; **нельзя упаковывать план с нарушением шаблона как формальную версию подачи**.
- Если ещё не достигнута единая линия внутренней подачи Qidian (`30000` знаков непрерывного основного текста + `内投版总大纲〈最低5000字〉` (общий план для внутренней подачи, минимум 5000 знаков) + `内投版第1卷卷纲` (план 1-го тома для внутренней подачи) + `内投版简介` (аннотация для внутренней подачи)), обязательно заметно пометить «предварительная версия с недостающими документами» или «предварительная версия подаваемого пакета»; нельзя выдавать за зрелый пакет внутренней подачи.
- Нельзя собирать материалы «Городского саспенса» лишь в облегчённый пакет с примерами глав; их необходимо организовать как «`аннотация для внутренней подачи` + `30000` знаков непрерывного текста + `общий план〈минимум 5000 знаков〉` + `план 1-го тома` + `самопроверка сборки` той же версии» и полностью доказать: профессиональный разрез, аномальные доказательства, процедурное трение, цену для главного героя, швы городской реальности, обещание первого тома, долгую загадку и способности автора к исполнению.
- Если уже есть оценка платформы, выводы рецензий глав / персонажей / сеттинга / тома / общего плана, обязательно перекрёстно усвоить; нельзя смотреть лишь аннотацию и пробные главы и упаковывать рискованную рукопись как формальную версию внутренней подачи.
- При фактической записи на диск в первую очередь применять `references/шаблон-записи-материалов-внутренней-подачи-qidian.md`, не складывать абзацы лишь во временном порядке.
- При фактической записи на диск по умолчанию писать в `投稿材料/起点内投/《作品名》/vYYYY-MM-DD-rN/` и синхронно обновлять `当前版本索引.md`; если пользователь явно не просит дополнительно выгрузить сводный файл, нельзя откатываться к основной форме «один файл».
- `组包自检` (самопроверка сборки) может существовать лишь как внутренний файл на стороне автора, не засчитывается во внешние сдаваемые документы и не отправляется вместе с рукописью.
- Во внешних сдаваемых документах запрещены любые авторские самооценки, самовосхваление, `当前最强 / 最弱一环` (самое сильное / самое слабое звено сейчас), комментарии об остаточных рисках, `建议现在内投` (рекомендуется подавать сейчас), `可以直接进入编辑内投` (можно напрямую переходить к внутренней подаче через редактора) и другие слова, подменяющие суждение редактора.

- При наличии любой из следующих проблем в принципе остановить формальную сборку или понизить до предварительной версии подаваемого пакета:

	- Процедурные формулировки искажены;

	- Обещание первого тома и долгосрочная загадка явно не работают.

## Справочник частых триггерных слов / формулировок пользователя

- Помоги собрать пакет подачи «Городского саспенса»
- Приведи к материалам внутренней подачи, которые Qidian сможет прочитать
- Проверь самое слабое звено имеющихся материалов подачи
- Собери 30000 знаков непрерывного основного текста + общий план / план 1-го тома + аннотацию
- Посмотри, можно ли подавать этот комплект материалов

## Обязательные требования

- При срабатывании этого навыка в первую очередь обязательно принудительно загрузить текущий жанровый Skill и `общий-сборка-материалов-для-подачи`.
- При использовании критериев Qidian перед выбором фрагментов основного текста и написанием плана сначала обязательно выдать: `主模板 / 辅助模板 / 是否九线回退 / 模板符合性结论` (основной шаблон / вспомогательный шаблон / откат к девяти линиям / вывод о соответствии шаблону).
- Название, аннотация, план, пробные главы обязаны единообразно указывать на одно и то же обещание: профессия + аномалия + цена + долгосрочная загадка.
- Пакет подачи должен прежде всего доказать, что это «Городской саспенс», пригодный для продолжения чтения в городской мужской прозе, а не медленное эссе в духе социальной школы или чистая атмосферная рукопись.
- Пример текста должен как можно лучше сохранять: цепкость начала главы, награду в середине, объект эстафеты в конце главы и как минимум одно реальное продвижение на уровне доказательств / процедур / отношений.
- При самопроверке обязательно оглянуться на: состоятельны ли классификация за 30 секунд, причина продолжать смотреть через 3 минуты, причина дочитывать на 30 тысячах знаков / в первом томе.

## Формулировки вывода по умолчанию

- По умолчанию поддерживается: четыре внешних документа в наличии / рабочая версия с недостающими документами / рабочая версия на доработку.
- Вывод обязательно должен ясно сказать: какие файлы относятся к внешним сдаваемым документам, какие — лишь к внутренним файлам на стороне автора, а также какие файлы ещё ждут дописывания / доработки.
