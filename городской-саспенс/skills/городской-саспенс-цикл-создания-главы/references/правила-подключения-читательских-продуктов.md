# Правила подключения читательских продуктов

## После шага 10 по умолчанию идут две линии

1. Линия читательских заметок: в первую очередь создавать по читательскому формату `городской-саспенс/.github/agents/читатель-романов.agent.md`.
2. Линия рецензий по главам: в первую очередь идти по критериям рецензии по главам из `городской-саспенс-написание-рецензии-на-книгу`.

## Позиционирование продуктов по умолчанию

- Читательские заметки: записывать, почему обычный читатель хочет дочитывать / чем озадачен / где запоздалый страх.
- Рецензия по главам: превратить самые ценные в этой главе аномалию, вознаграждение и хук в одну распространяемую рекомендательную статью.

## Требования замкнутого цикла

- Без `READER_NOTE_FILE` замкнутый цикл читательской стороны не засчитывается.
- Без `BOOK_REVIEW_FILE` замкнутый цикл распространения по главам не засчитывается.
- Оба должны основываться на последнем основном тексте, а не на впечатлении от старого черновика.
