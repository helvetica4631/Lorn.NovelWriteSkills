# 都市悬疑-多平台输出编排

Это жанровая обёртка, совместимый вход и слой маршрутизации.


<!-- ===== Layer 3: кэш сценария ===== -->

## Соответствующий общий Skill

- `通用-多平台输出编排`

## Обязанности слоя

- Сохранять жанровое входное имя «都市悬疑-多平台输出编排».
- Маршрутизировать общую оркестрацию SOP мультиплатформенного вывода в `通用-多平台输出编排`.
- Дополнять фиксацию основы жанра перед рассылкой по платформам: аномальные доказательства, процедурное трение, реальная цена, городское ощущение давления и долгая загадка нельзя вымывать до нейтрального саспенс-черновика.

## Жанровые references для дальнейшего чтения

- `references/题材多平台输出保真规则.md`

## Справочник частых триггерных слов / формулировок пользователя

- Разошли эту главу «Городского саспенса» на несколько платформ
- Запусти SOP многоплатформенного вывода «Городского саспенса»
- Сделай платформенное переписывание и сохранение для этих глав разом
- Массовая раздача с жанровой достоверностью

## Порядок комбинированных вызовов по умолчанию

1. Сначала загрузить и использовать `通用-多平台输出编排`
2. Сначала вызвать `都市悬疑-提纯多平台母稿`
3. Затем вызвать `都市悬疑-多平台小说适配`
4. В конце по платформам вызвать соответствующие `都市悬疑-输出*版`

## Правила наследования исполнения (обязательно)

- При срабатывании этого навыка, помимо патчей жанровой достоверности, обязательно полностью наследовать и исполнять «15-шаговый замкнутый цикл исполнения» `通用-多平台输出编排`, не удаляя, не изменяя, не пропуская шаги и не понижая уровень.
- Если пользователь ставит задачу в виде «какая часть, какой том, какая глава», целевое положение по умолчанию обязательно определять в `小说正文/`, не требуя от пользователя повторно указывать путь.
- Если пользователь не указал платформы, множество платформ по умолчанию обязано динамически определяться по текущим доступным платформам вывода (сейчас 14, новые платформы автоматически включаются).
- Сходство, объём знаков, борьба с «водой» и ворота бессмысленных символов — всё жёсткие ворота; при провале любых обязательно доработка до достижения порога.
- Пока не завершены «запись на диск по всем указанным платформам + достижение порога всех ворот + журнал, допускающий возобновление», нельзя останавливать процесс.
- Необходимо наследовать и выполнять «ворота полноты вызовов» общего слоя: в каждой главе этого жанра обязательно вызывать `都市悬疑-提纯多平台母稿` и `都市悬疑-多平台小说适配`, а для каждой пары «глава × целевая платформа» — соответствующий `都市悬疑-输出*版`; если в журнале вызовов есть пробел, задача не может считаться завершённой.

## Обязательные требования

- При срабатывании этого навыка в первую очередь обязательно принудительно загрузить текущий жанровый Skill и `通用-多平台输出编排`.
- При срабатывании этого навыка в первую очередь обязательно принудительно загрузить текущий жанровый Skill и `通用-多平台输出编排` и строго исполнять по 15-шаговому замкнутому циклу общего слоя.
- Нельзя в обход жанровой цепочки раздавать исходный черновик по платформам.
- Основу жанра нужно сначала зафиксировать, затем делать платформизацию и снижение сходства.
- Ни одна платформенная версия не должна вымывать «Городской саспенс» до чистого уголовного розыска, чистого общественного комментария или нейтрального триллерного черновика.
- Даже если ворота платформы пройдены, если якоря реальности, цепочка аномальных доказательств, процедурное трение, номерной формат, городское ощущение давления или питание долгой загадки основной линии вымыты, обязательно возвращать на доработку.
- Гранулярность продолжения должна доходить до узлов «глава × платформа»; жанровый слой не должен стирать результаты жанровой достоверности, уже прошедшие на других платформах, из-за провала на одной платформе.
