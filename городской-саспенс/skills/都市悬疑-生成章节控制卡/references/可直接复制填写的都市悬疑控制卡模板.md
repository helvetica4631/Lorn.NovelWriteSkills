>
> - `CommonSkills/通用-生成章节控制卡/references/章节控制卡模板.md`

## 1. Способ использования (обязательно)

1. Сначала по общему шаблону контрольной карточки заполнить полную главную карточку.
2. Затем дописать поля этого файла в соответствующие разделы.

## 2. Поля дополнения «Городского саспенса»

- Состояние зацепки: заложена / продвинута / опровергнута / возвращена
- Состояние доказательств: появилось / в конфликте / перевёрнуто / выплачено
- Процедурное трение: полномочия расследования, сложность запроса доказательств, сопротивление учреждений

## 3. Дополнительные пункты приёмки

- [ ] Как минимум один сценический юнит несёт вознаграждение середины.
- [ ] Как минимум в одном узле реализовано «опровержимое введение в заблуждение».
