# Стратегия заголовка, абзацев и слова автора для контрольной карточки

## Стратегия кандидатов в заголовки

- Заголовки в первую очередь брать из: вещей-улик, аномальных действий, трещин в отношениях, институциональных барьеров.
- Реже использовать пустые заголовки вроде «Правда приближается», «Опасность приходит».
- Приоритетнее: заголовки вроде `回执倒签` (квитанция, подписанная задним числом), `灰掉的三分钟` (три серые минуты), `物业说没这回事` (управляющая компания говорит, что такого не было), способные напрямую вызывать образ.

## Стратегия построения абзацев

- При разбиении контрольной карточкой на сцены по умолчанию каждый сценический юнит должен нести чёткую задачу.
- Лучше, чтобы каждый сценический юнит нёс лишь один основной вид давления, не смешивать несколько равноправных давлений.
- Между абзацами сцен должно образоваться нарастание «ответ на один старый вопрос + добавление одного худшего вопроса».

## Стратегия слова автора

- Если контрольная карточка заранее предполагает, что главе понадобится `## 作者有话说` (слово автора), нужно заранее отметить его функцию:
  - Буфер
  - Напоминание о дочитывании
  - Лёгкое эмоциональное завершение
- Не превращать `作者有话说` (слово автора) в мусорный ящик для доделки логики сюжета.
- Если основной текст этой главы уже очень насыщен, слово автора по умолчанию делать лёгким, чтобы не перетягивать на себя.
