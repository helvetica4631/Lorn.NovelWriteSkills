# Пример индекса трёхуровневого плана

## Рекомендуемые поля

- Уровень источника плана
- Номер (например, `T1.1 → 1.1 → 1.1.3`)
- Временной узел
- Описание события
- Функция присутствия персонажа
- Влияние на психологическую дугу

## Скелет примера

```markdown
## Индекс соответствия сюжета трёхуровневого плана

### Траектория развития полной психологической дуги персонажа

#### Первый этап: исходное состояние
- Шаг 1: профессиональная уверенность (соответствует: период будничной стабильности)
- Шаг 2: доверие к правилам (соответствует: вышестоящий порядок по-прежнему по умолчанию считается надёжным)

#### Второй этап: потрясение и пробуждение
- Шаг 6: первое аномальное потрясение (соответствует `T1.1`)
- Шаг 8: ключевая формулировка переписана (соответствует `1.1 / 1.3`)

### Ключевой сюжет первого уровня (общий план)
- `T1.1`: персонаж впервые соприкасается с ключевой аномалией и меняет направление последующих действий.

### Тактический сюжет второго уровня (часть / том)
- `1.1`: персонаж проходит опросы, упирается в стены, восстанавливает цепочку.
- `1.3`: персонаж при сверке в ключевой организации обнаруживает трещину в формулировках.

### Исполнительный сюжет третьего уровня (глава)
- `1.1.1`: запуск аномалии.
- `1.1.3`: опросы, упирание в стены.
- `1.3.2`: сверка в ключевой организации / восстановление цепочки.
```

## Принципы использования

- Индекс — не украшение, он обязан поддерживать обратную проверку.
- По одному и тому же событию по возможности писать «что сделал персонаж», «что потерял», «как его вынудило идти дальше».
