# Дополнение к шаблону части (городской саспенс)

## 1. Дополнительные правила для частей «Городского саспенса»

- В списке принятого частью отдельно указать: пазл загадки главной линии, эволюцию пула подозреваемых, продвижение цепочки доказательств.
- Каждый сюжетный блок должен чётко указывать «точку введения в заблуждение + точку опровержения».

## 2. Дополнительные пункты приёмки

- [ ] При распределении данной части по томам продвижение загадки основной линии не ниже 1 эффективного прогресса на каждый том.
- [ ] Конечная точка части обязана давать двойной вывод: «отвеченные вопросы + новый разрыв-вопрос».
