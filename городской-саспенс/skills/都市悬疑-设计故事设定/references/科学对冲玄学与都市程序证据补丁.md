# Патч «наука хеджирует мистику» и городских процедурных доказательств

## Подходящие направления

- Когда в городской саспенс входят фольклор / сверхъестественное / аномалии типа правил
- Когда нужно «прижать» аномальный сигнал обратно к процедурной цепочке, цепочке доказательств и профессиональной цепочке

## Основные требования

- Ощущение мистики может быть поверхностным переживанием, но в основании оно обязано приземляться на:
  - Фиксируемую аномалию
  - Проверяемую лазейку в процедуре
  - Носитель доказательств, который можно воспроизвести
  - Переносимую цену и границы
- Городской саспенс по умолчанию в первую очередь дополняет: **триггер / первый признак / окно утраты силы / выход первого слоя — запечатывание или экспорт / формулировка ошибочного суждения первого слоя / действие опровержения первого слоя**.

## Приоритетные способы упаковки

- Профессиональными знаниями объяснять границы явления
- Обнажать следы аномалии через процедурное трение
- Использовать инструменты, данные и носители записей как гвоздь доказательств первого слоя
- Сохранять запах фольклора / легенд, но не писать их как инструкцию по применению

## Рекомендации по двухслойной формулировке

- **Поверхностная формулировка**: сначала дать читателю ощущение «как будто призрак / как будто проклятие / как будто совпадение».
- **Нижележащая формулировка**: далее дать автору процедурные выходы — «пропуск кадров камеры / сбой допуска / номер медицинского анализа / временная пломбировочная этикетка / каталог экспорта / сопоставление на одном экране».
- **Переходная формулировка**: пусть персонажи вокруг «просто совпадения / не сообщайте наверх / сначала оформите как обычный случай» сначала один раз совершат ошибочное суждение, и лишь затем переходят к опровержению.

## Приоритетные поля «Городского саспенса»

- Предмет-триггер / место-триггер / время первого появления
- Первые видимые признаки первого уровня (звук, перепад температуры, искажение, разрыв в картинке, остаточные предметы)
- Условия отказа / затухания / загрязнения
- Выход — опечатывание, выгрузка, перепроверка, сопоставление на одном экране
- Кто первым заподозрил, кто первым надавил на формулировки, кто первым понял, что это не совпадение

## Сторожевая линия

- Запрещено продвижение в духе чисто мистических явлений.
- Запрещены странные явления без выхода в доказательную форму.
- Запрещено писать высокорисковые реальные детали как инструкцию.
- Запрещено оставлять аномалию на уровне «атмосфера очень странная»; необходимо дать как минимум один жёсткий гвоздь, способный пришить её к городской процедурной цепочке.
