# Дополнительные правила реестра улик, закладок и возвратов в «Городском саспенсе»

Этот файл служит жанровым дополнением обёртки и по умолчанию используется вместе с `通用-设计线索伏笔与回收台账`.

## 1. Что реестр «Городского саспенса» должен фиксировать дополнительно

Помимо общих полей, для ключевых записей рекомендуется дополнительно фиксировать:

- **Городской интерфейс**: контактные поверхности — управляющая компания / больница / школа / платформа / организация / сообщество / СМИ / транспорт и т. п.;
- **Тип следа**: пространственный след / поведенческий след / цифровой след / след отношений;
- **Связь со старым делом**: новая зацепка, эхо старого дела или мост между ними;
- **Процедурное сопротивление**: кто будет её тормозить, затягивать, давить, «отмывать».

## 2. Эхо старых дел и три временные оси

Многие улики в длинных романах городского саспенса держатся не на одной временной точке, а одновременно затрагивают:

- **Временная ось старого дела**: что на самом деле произошло тогда;
- **Временная ось нынешнего дела**: кто сейчас продолжает скрывать, повторять, использовать или бить отдачей по старому делу;
- **Временная ось раскрытия**: в каком порядке герой и читатель заново узнают об этом.

При составлении реестра по возможности избегать сжатия трёх временных осей в одну плоскую линию; иначе легко получить «автор знает многое, читатель видит лишь туман».

## 3. Проверка честности дедукции для городских жанров

### Записи типа ключевой разгадки — дополнить как минимум три пункта

- **Первый видимый сигнал**: в какой городской сцене читатель впервые это видит;
- **Итоговое действие проверки**: каким реальным действием герой это подтверждает;
- **Отголосок после раскрытия**: какой слой отношений или порядка заново переписан после выхода правды.

### Частые сигналы искажения

- В предыдущем тексте недостаточно следов, финал может держаться только на жёстком пояснительном абзаце;
- У введения в заблуждение есть только экранирование, но нет разумной иллюзии «почему похоже на нормальный городской процесс»;
- После раскрытия истины читатель, оглядываясь на предыдущий текст, всё ещё не может ухватить точку приземления доказательства, на которую можно сослаться.

## 4. Вознаграждение от возврата в городском жанре

Один возврат лучше всего попадает как минимум в два из трёх:

- **Когнитивная награда**: читатель вдруг понимает какую-то прежнюю аномальную деталь;
- **Награда в отношениях**: переписываются доверие, враждебность или выбор сторон между персонажами;
- **Награда риска**: проблема объяснена, но в городской системе обнажилась ещё более крупная трещина.
