# Границы жанра и описание входа (городской саспенс)

> Формат: табу жанра → специальные правила → железные языковые правила → руководство по повествованию → справка по ритму
> Это стандартный пятираздельный шаблон жанровых правил, все описания границ и входа жанров организованы по этой структуре.

## Табу жанра

- Разрыв городской реальности: аномалия витает на фоне и не вступает в реальное трение с жизнью героя
- Остаётся лишь чистый криминалистический процесс: теряется особое качество саспенса — «городская странность» и «правила кусаются в ответ»
- Движение только атмосферой триллера: нет якорей реальности, воспроизводимых доказательств и процедурной цепочки
- Длинная загадка погребена единицами-делами: «одно дело — один финал», нет длинного драйвера, чтобы дочитать том целиком

## Специальные правила

### На что эта жанровая линия по умолчанию должна ответить

- Где вход городской реальности.
- Какой именно знакомый порядок первой разорвала аномалия.
- С помощью какой профессии / идентичности / методологии главный герой входит в игру.
- Как доказательства, номера, процедуры, системные подсказки, общественное мнение или групповые формулировки непрерывно усиливают опасность.
- Почему длинная загадка способна вытянуть длинный роман, а не «одно дело — один финал».

### Условия минимального замыкания

- С первого взгляда видно «опасную аномалию, происходящую в городе», а не повисший в воздухе фон.
- Вход героя в дело — не чистая случайность, а сильная связь с профессией, идентичностью или реальными потерями.
- Опасность должна входить в цепочку улик, процедурную цепочку и цепочку отношений, а не оставаться лишь атмосферой.
- Долгосрочные награды не могут держаться лишь на раскрытии правды, они должны держаться и на эскалации правил, эскалации цены, эскалации трещин в отношениях.

## Железные языковые правила

- **Не заменять картину абстрактными словами страха**: ✗ «атмосфера жуткая» → ✓ «в конце коридора погасла лампа с датчиком звука, а шаги всё ещё приближались»
- **Описание доказательств должно допускать воспроизведение**: каждая ключевая улика должна удовлетворять замкнутому циклу «что увидел персонаж → почему это аномально → кто и когда мог подстроить»
- **Запрещено объявлять «здесь проблема» с позиции бога**: сомнения героя должны проявляться через действия и поведение (трижды перелистал записи / позвонил сверить), а не внутренним монологом, прямо говорящим читателю
- **Процедурные детали определяют правдоподобие**: термины документов, номеров, меток времени, записей передачи в процессе расследования / проверки должны быть точными

## Руководство по повествованию

- Ключевой драйвер городского саспенса — «разгадывание»: ключевая движущая сила продолжения чтения — «хочется узнать истину»
- Опасность должна прорастать из трещин повседневности: в системе допуска лишняя запись о прикладывании карты без регистрации, в уведомлении управляющей компании лишняя строка о несуществующей плате
- Высвобождение информации следует циклу «сначала задать интригу → постепенно раскрывать → частично возвращать → новая интрига»
- В каждом томе одна единица-дело замыкается, а скрытая линия параллельно продвигает длинную загадку (закулисный злодей / нераскрытое дело)
- Безопасные зоны временны — примерно каждые 3 главы нужно нарушать уже установленный безопасный шаблон

## Справка по ритму

- Начало: с первого взгляда дать сигнал «что-то не так», в первых 3 главах — переход повседневность → аномалия
- Ритм единицы-дела: обнаружение аномалии → продвижение расследования → столкновение с сопротивлением → ключевое доказательство / переворот → преследование / противостояние → последствия
- Длинный ритм: после каждых 2–3 единиц-дел длинная загадка один раз всплывает на поверхность
- Плотность высвобождения информации: в каждой главе как минимум одна улика продвинута или одно представление перевёрнуто
