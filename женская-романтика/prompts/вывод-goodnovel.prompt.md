# Вывод версии для GoodNovel

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-вывод-goodnovel`.

Prompt не вправе в обход жанрового Skill напрямую «переделывать» платформенный текст.

## Обязанности, которые остаются только у этого Prompt

- Служит входом платформенного вывода для GoodNovel
- Сохраняет минимальный ввод, каталог вывода и напоминание об английских шлюзах
- Маршрутизирует основные правила в `общий-вывод-goodnovel`

## Минимальные требования к исполнению

- Сначала сохранить линию роста, напряжение отношений, эмоциональные награды и нулевое добавление фактов, затем заняться адаптацией под английскую платформу.
- Корень каталога вывода: `GoodNovel/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)
- Кроме строки `## 作者有话说`, китайского / CJK быть не должно.

## Напоминание одной фразой

Этот Prompt теперь — **слой платформенного входа жанра «женская романтика»**; настоящие платформенные исследования, детали исполнения и жанровые патчи нужно по-прежнему читать в соответствующих Skill `общий-*` и исполнять там.
