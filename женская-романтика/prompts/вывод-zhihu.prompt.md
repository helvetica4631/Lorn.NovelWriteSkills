# Вывод версии для Zhihu

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-вывод-zhihu`.

Prompt не вправе в обход жанрового Skill напрямую «переделывать» платформенный текст.

## Обязанности, которые остаются только у этого Prompt

- Служит входом платформенного вывода для Zhihu
- Сохраняет минимальный ввод, каталог вывода и напоминание о шлюзах основного текста
- Маршрутизирует основные правила в `общий-вывод-zhihu`

## Минимальные требования к исполнению

- Сначала сохранить линию роста, натяжение отношений, отображение на реальность и нулевое добавление фактов, затем усилить для Zhihu высокую концепцию и постановку вопроса.
- Корень каталога вывода: `知乎/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `общий-вывод-*/SKILL.md`.

## Напоминание одной фразой

Этот Prompt теперь — **слой платформенного входа жанра «женская романтика»**; настоящие платформенные исследования, детали исполнения и жанровые патчи нужно по-прежнему читать в соответствующих Skill `общий-*` и исполнять там.
