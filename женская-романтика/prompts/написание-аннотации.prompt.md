# Написание содержания аннотации

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-написание-аннотации`.

Если в этом проходе также нужно сначала откалибровать жанровое позиционирование, главную ось граней истории или платформенные различия, по необходимости можно дополнительно вызвать: `общий-проектирование-позиционирования-жанра`, `общий-проектирование-граней-истории`, `общий-адаптация-под-платформы`.

Prompt не имеет права, минуя жанровый Skill, «голо» использовать общие правила аннотаций.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом задач по аннотациям в жанре «женская романтика»
- Сохраняет тип задачи, минимальный ввод и ограничения записи отдельным файлом на диск
- Маршрутизирует основные правила в `общий-написание-аннотации`

## Минимальный вход

- Тип задачи: серия-вся книга / часть или том / глава
- Заголовок
- Ключевые персонажи
- Дифференцирующая торговая точка одной фразой
- Явный конфликт (открытая линия)
- Эмоциональное ядро
- Целевая платформа (необязательно)

## Минимальные требования к исполнению

- Аннотация должна сначала ответить на вопрос «кого втянули в какую игру и что ему сейчас грозит потерять», а не просто рассказывать про сеттинг.
- Главный крючок должен быть ясным, нельзя нагромождать продающие точки в ряд.
- Обязательно отразить линию роста, напряжение отношений и эмоциональную ценность, но нельзя писать это как «обещания влюблённой головы».
- Не записывать на диск разрешено, лишь когда пользователь явно сказал, что набрасывает только вчерне и файлы не трогать.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящую структуру аннотации, платформенные различия, управление версиями и жанровые патчи нужно по-прежнему читать в соответствующих Skill `общий-*` и исполнять там.
