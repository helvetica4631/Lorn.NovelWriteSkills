# Рецензирование биографий персонажей

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-рецензия-биографии-персонажей`.

Prompt не имеет права, минуя жанровый Skill, «голо» рецензировать.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом рецензирования биографий персонажей жанра «женская романтика»
- Сохраняет целевого персонажа, роль персонажа, читательскую цепочку и ограничения на внесение отчёта в библиотеку
- Направляет основные правила рецензирования в `общий-рецензия-биографии-персонажей`

## Минимальный вход

1. Путь к файлу биографии целевого персонажа
2. Роль персонажа: главный герой / важный персонаж / антагонист / персонаж отношений / функциональный персонаж
3. Том или окно ключевого появления, к которому он относится
4. Стратегия вывода: перезапись / дополнение рецензией этого прохода

## Минимальные требования к исполнению

- Обязательно проверить, состоятельны ли личность, мотивация, цена, настоящие слабости, натяжение в отношениях, психологическая дуга и цепкость первого появления.
- Обязательно судить, способен ли этот персонаж постоянно питать линию роста, линию отношений или эмоциональную линию.
- Обязательно записать результат рецензии как отчёт, пригодный для записи обратно, а не как разрозненные реплики в чате.
- В отчёте нужно дать как минимум патчи на уровне пунктов, предложения по кадрам появления и крючки для реплик, пригодные для прямого повторного использования.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящий каркас рецензии персонажа, измерения оценки и шаблон записи обратно нужно по-прежнему читать в соответствующих Skill `общий-*` и исполнять там.
