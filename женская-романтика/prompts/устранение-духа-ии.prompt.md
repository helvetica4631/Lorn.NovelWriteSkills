# Удаление ИИ-привкуса

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-устранение-духа-ии`.

Prompt не вправе в обход жанрового Skill напрямую вызывать общие правила удаления ИИ-привкуса.

## Обязанности, которые остаются только у этого Prompt

- Распознаёт «удаление ИИ-привкуса» как вход задачи, которую обязательно сначала направить в `общий-устранение-духа-ии`
- Ограничивает: необходимо менять реальный файл основного текста в рабочей области, а не просто показывать пример в чате
- Требовать при неясном объёме сначала одной фразой подтвердить границы
- Требовать, чтобы окно чата по умолчанию возвращало только краткую проверяемую сводку правок, не вставляя всю главу

## Минимальные пункты подтверждения

1. Путь к файлу целевой главы
2. Охват обработки: целая глава / сцена / абзац
3. Акцент этого прохода: шаблонная интонация / объясняющая интонация / равномерные группы предложений / одинаковый голос у персонажей / искажение эмоций
4. Разрешена ли запись обратно в файл напрямую (по умолчанию разрешена)

## Минимальные требования к исполнению

- Сначала обязательно дать диагноз «очага болезни» одной фразой, и лишь затем переходить к формальному переписыванию.
- Нельзя смыть заодно линию роста, линию отношений, награды в середине и крючок в конце главы.
- Текст после удаления привкуса должен больше походить на живого человека на месте событий, который несёт давление, прощупывает, тянет, колеблется и отвечает ударом.
- Если пользователь явно не требует «только обсудить, не сохранять в файл», обязательно записывать прямо в целевой файл Markdown.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящую градацию «очагов болезни», контроль интенсивности, действия по переписыванию и правила повторной проверки нужно по-прежнему читать в соответствующих Skill `общий-*` и исполнять там.
