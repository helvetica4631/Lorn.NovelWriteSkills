# SOP рецензии и оптимизации плана

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-大纲审阅优化闭环`.

Этот вход не имеет права выдавать «однократную рецензию» за «замкнутый цикл рецензии и правки» и не имеет права пропускать жанровые Skill рецензии / проектирования, «голо» рецензируя или правя.

При исполнении происходит разветвление по уровню объекта:

- Слой общего плана: `通用-审阅总大纲` ↔ `通用-设计总大纲`
- Уровень части / тома / единицы-события: `通用-审阅分卷大纲` ↔ `通用-设计分卷大纲`

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом замкнутого цикла рецензирования и оптимизации плана жанра «женская романтика»
- Сохраняет минимальный ввод, якорь порядка исполнения, порог оценки и минимальные ограничения на квитанцию
- Маршрутизирует основную логику цикла в `通用-大纲审阅优化闭环`

## Минимальный вход

- Путь к целевому файлу плана
- Тип объекта: общий план / часть / том / единица-событие

## Минимальные требования к исполнению

- В первом проходе сначала обязательно записать полный отчёт рецензии, и лишь затем переходить к правке с доработкой.
- Пока последний сводный балл `<= 9.2`, обязательно продолжать правку и повторную рецензию.
- Результат каждого прохода обязательно записывается обратно в один и тот же основной отчёт рецензии, нельзя параллельно размножать несколько версий.
- Остановиться разрешено, лишь когда последний сводный балл **строго больше** `9.2`; сам `9.2` проходом не считается.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящие правила замкнутого цикла, отслеживание проходов, разветвление по объектам и детали перезаписи отчёта нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
