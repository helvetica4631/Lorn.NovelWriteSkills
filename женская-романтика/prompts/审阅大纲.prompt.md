# Рецензирование плана

## Маршрутизация жанровых навыков (обязательно)

При исполнении этого Prompt необходимо сначала определить уровень объекта рецензирования, затем вызвать соответствующий жанровый Skill:

- Общий план / общая таблица / грани истории / общий план зацепок / общая хронология → `通用-审阅总大纲`
- Часть / том / список глав / исполняемая версия единицы-события / артефакты ритма и крючков → `通用-审阅分卷大纲`

Prompt не имеет права, минуя жанровый Skill, «голо» рецензировать.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом рецензирования плана в жанре «женская романтика»
- Сохраняет разделение по объектам, общий арбитражный канон рецензирования, читательскую цепочку, минимальный ввод и ограничения на внесение отчёта в библиотеку
- Направляет специфичные для уровня проверки, акцент оценки и стратегию минимальных патчей в соответствующий жанровый Skill

## Минимальные требования к исполнению

- На уровне общего плана обязательно акцентно рецензировать: главную продающую точку, линию роста, линию отношений, обещание начала, питание серий томов и замыкание финала.
- На уровне тома обязательно акцентно рецензировать: цепочку продолжения чтения первых 5 глав, награды внутри главы, крючок в конце тома, продвижение отношений внутри тома и эмоциональное замыкание.
- Отчёт по умолчанию записывается в `审阅意见/`, в чате делается лишь минимальная квитанция.
- Если вышестоящее отсутствует, в отчёте обязательно отметить блокирующую точку, замещающее основание и риск.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика» + слой общего арбитража**; настоящие специфичные для уровней проверки, дополнения отчёта и стратегию записи обратно нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
