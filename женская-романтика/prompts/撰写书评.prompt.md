# Написание рецензии на книгу

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-撰写书评`.

Если в этом проходе также нужно сначала выделить продающие точки, грани истории, цепкие точки сериала или платформенный канон, по необходимости можно дополнительно вызвать: `通用-设计题材定位框架`, `通用-设计故事面`, а при необходимости дополнительно наложить `通用-输出*版` соответствующей платформы.

Prompt не вправе в обход жанрового Skill напрямую использовать общие правила отзывов.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом задач по отзывам в жанре «женская романтика»
- Сохраняет уровень задачи, минимальный вход, цепочку комбинирования по умолчанию и ограничения сдачи по умолчанию
- Маршрутизирует основные правила в `通用-撰写书评`

## Минимальный вход

- Тип рецензии: вся книга / часть / том / глава
- Заголовок соответствующего охвата
- Целевая платформа (необязательно)
- Ракурс письма (необязательно)
- Публичные продающие точки, крючки отношений между персонажами и материалы о читательских ощущениях (необязательно)

## Минимальные требования к исполнению

- Обязательно без спойлеров и без восстановления ключевой причинно-следственной цепочки.
- Обязательно сохранять ракурс обычного читателя, нельзя переключаться на авторский или лекторский ракурс.
- По умолчанию в первую очередь писать о вовлечении, соотношении «сладкого» и «爽», линии роста, натяжении отношений и послевкусии, подталкивающем продолжать читать.
- По умолчанию записывать отдельным файлом на диск; без записи файла можно обойтись, лишь когда пользователь явно пояснил, что набрасывает только в чате.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящие структурные шаблоны отзывов, платформенные различия, правила записи на диск и жанровые патчи нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
