# Написание биографии персонажа

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-设计人物传记`.

Prompt не вправе в обход жанрового Skill напрямую писать общие правила биографий персонажей.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом проектирования биографий персонажей жанра «женская романтика»
- Сохраняет файл целевого персонажа, стратегию записи и границы авторского источника арбитража
- Маршрутизирует основные правила в `通用-设计人物传记`

## Минимальный вход

1. Путь к файлу биографии целевого персонажа или имя персонажа
2. Способ обработки: создать заново / переписать / локально усилить
3. Роль персонажа: главный герой / важный персонаж / антагонист / персонаж отношений / функциональный персонаж
4. Разрешена ли запись обратно в файл напрямую (по умолчанию разрешена)

## Минимальные требования к исполнению

- Биография обязательно должна ложиться в авторский источник арбитража, на который можно прямо ссылаться обратно, а не быть краткой биографией для читателя.
- Обязательно чётко прописать личность, мотивацию, настоящие слабости, сеть отношений, психологическую дугу, крючки для письма и отображение индексов.
- Если затронуты конфликты плана, отношений персонажей или канона сеттинга, обязательно явно исправить в файле или пометить риск.
- Если пользователь явно не требует лишь обсуждения без записи на диск, формальный результат обязательно записывается в целевой Markdown-файл.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящий шаблон биографии персонажа, процесс проверки и жанровые патчи нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
