# SOP написания главы романа

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-章节创作闭环`.

Если у текущей партии глав уже есть чёткий план тома / список глав, по умолчанию `通用-生成章节控制卡` следует считать обязательным вышестоящим слоем перед строительством основного текста.

Этот вход не вправе выдавать «написание одного лишь чернового варианта» за «полный SOP главы» и не вправе в обход жанровой цепочки напрямую вызывать общую основу создания основного текста.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом замкнутого цикла создания главы
- Сохраняет каталог основного текста по умолчанию, обнаруживаемость пакетного режима, минимальное условие завершения и ограничения на итоговую сводку
- Направляет основной ход исполнения в `通用-章节创作闭环`

## Минимальный вход

- `OUTLINE_FILE`
- `CHAPTER_FILE`
- `RELATED_CONTEXT_FILES[]` (необязательно)
- `CHAPTER_FILES[] / OUTLINE_FILES[] / CHAPTER_BATCH[] / BATCH_ID` (необязательно, для пакетного режима)

## Минимальные требования к исполнению

- Основной объект по умолчанию — исходный основной текст главы в `小说正文/`; версии для других платформ передаются последующей мультиплатформенной цепочке.
- Пакетный режим должен замыкаться по главам; нельзя подменять поглавную проверку устным обобщением всей партии.
- Заявлять о завершении можно лишь тогда, когда основной текст, итоговый отчёт рецензии, читательские заметки, отзыв на главу и журнал полностью замкнуты.
- В чате в конце разрешено выводить только сводку о завершении задачи, но не основной текст главы.

## Выдача по умолчанию

- `CHAPTER_FILE`
- `REVIEW_REPORT_FILE`
- `READER_NOTE_FILE`
- `BOOK_REVIEW_FILE`
- В чате в конце возвращается лишь сводка о завершении задачи

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящий SOP создания главы, пакетный режим, механизм журналов и ограждения жанра нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
