# 正文润色

## 题材技能路由（强制）

命中本 Prompt 时，必须先调用：`общий-шлифовка-основного-текста`。

若目标进一步收窄，可按需叠加：`общий-шлифовка-слова-автора`、`общий-усиление-начала-главы`、`общий-усиление-хука-конца-главы`、`общий-очистка-мастер-черновика`、`общий-устранение-духа-ии`。

Prompt 不得绕过题材 Skill 直接裸润。

## 本 Prompt 只保留的职责

- 作为女频爱情正文润色的轻入口
- 约束默认属于正式润色并直接回写文件
- 约束默认维护对象是作者工作文件，而不是聊天里的示范文本

## 开工前最小确认

1. 目标章节文件路径
2. 处理范围：整章 / 某场景 / 某几段
3. 本轮重点：开头抓力 / 中段回报 / 章末钩子 / 对话 / 代入感 / 去 AI 味 / 综合精修
4. 是否允许直接写回文件（默认允许）

## 最低执行要求

- 必须保护人物口径、有限视角、情绪闭环、成长线、关系线与章内回报。
- 必须把正式润色结果落实到目标正文文件，而不是停留在聊天输出。
- 必须在完成后给出简短、可核对的修改摘要。
