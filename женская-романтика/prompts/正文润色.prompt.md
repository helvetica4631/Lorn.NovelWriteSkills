# Шлифовка основного текста

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-正文润色`.

Если цель сужается дальше, по необходимости можно дополнительно наложить: `通用-润色作者有话说`, `通用-强化章节开头`, `通用-强化章末钩子`, `通用-提纯多平台母稿`, `通用-去AI味重写`.

Prompt не вправе в обход жанрового Skill напрямую «шлифовать вслепую».

## Обязанности, которые остаются только у этого Prompt

- Служит лёгким входом шлифовки основного текста жанра «женская романтика»
- Ограничивает: по умолчанию это формальная шлифовка с прямой записью обратно в файл
- Ограничивает: объект сопровождения по умолчанию — рабочий файл автора, а не демонстрационный текст в чате

## Минимальное подтверждение перед началом работы

1. Путь к файлу целевой главы
2. Охват обработки: целая глава / некая сцена / несколько абзацев
3. Акцент этого прохода: цепкость начала / награда в середине / крючок в конце главы / диалоги / вовлечение / удаление ИИ-привкуса / комплексная доводка
4. Разрешена ли запись обратно в файл напрямую (по умолчанию разрешена)

## Минимальные требования к исполнению

- Обязательно защищать речевой канон персонажей, ограниченную точку зрения, эмоциональное замыкание, линию роста, линию отношений и награды внутри главы.
- Обязательно записывать результат формальной шлифовки в целевой файл основного текста, а не оставлять его выводом в чате.
- После завершения обязательно давать краткую, поддающуюся проверке сводку правок.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящий процесс шлифовки, усиливающие приёмы, жанровые патчи и нормы записи обратно нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
