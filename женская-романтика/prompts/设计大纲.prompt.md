# Проектирование плана

## Маршрутизация жанровых навыков (обязательно)

При исполнении этого Prompt необходимо сначала определить уровень задачи, затем вызвать соответствующий жанровый Skill:

- Общий план / общая таблица / грани истории / общий план зацепок / общая хронология → `通用-设计总大纲`
- Часть / том / список глав / таблица запуска тома / сюжетные точки / расстановка точек 爽 / разбор единиц-событий внутри тома → `通用-设计分卷大纲`

Prompt не вправе в обход жанрового Skill напрямую использовать общую основу проектирования плана.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом проектирования плана в жанре «женская романтика»
- Сохраняет разделение по объектам, общий арбитражный канон, минимальный ввод, запись обратно в файл и ограничения на минимальную квитанцию
- Направляет шаблоны, правила, приёмку и артефакты уровня глав, специфичные для уровня, в соответствующий жанровый Skill

## Минимальные требования к исполнению

- План прежде всего служит тому, чтобы «автор мог писать, разбивать на главы, записывать обратно и проверять», а не быть рекламным текстом для прямого чтения читателем.
- Линия роста, линия отношений, главная продающая точка, обещание начала, питание серий томов и замыкание финала обязательно записываются как исполнимая автором цепочка обещаний.
- Ключевые узлы в первую очередь записывать так: кто что сделал → какие проверяемые последствия вызвал → какой новый разрыв оставил.
- Если пользователь явно не требует лишь обсуждения без записи в файл, по умолчанию запись напрямую в файл целевого плана.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика» + слой общего арбитража**; настоящие специфичные для уровней правила, шаблоны, артефакты и критерии приёмки нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
