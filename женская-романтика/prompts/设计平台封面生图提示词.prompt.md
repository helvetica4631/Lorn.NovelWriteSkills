# ИИ-промпт обложки для платформы

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-设计封面生图提示词`.

Если вход-Prompt противоречит правилам жанрового Skill, приоритет имеют визуальная система, платформенные различия, правила «избегания мин» и структура вывода из жанрового Skill и его references.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом задач генерации обложек для жанра «женская романтика»
- Ограничивает минимальный ввод, белый список платформ и границу бесспойлерности
- Направляет суждение о произведении, суждение о платформе, выбор визуальной системы и итоговую выдачу промпта в `通用-设计封面生图提示词`

## Минимальный вход

- Целевая платформа
- Название книги, используемое на этой платформе
- Если есть: аннотация, план, персонажи, сеттинг, фрагменты основного текста, пункты без спойлеров, имя автора

## Минимальные требования к исполнению

- Сначала обязательно прочитать материалы произведения, явно предоставленные пользователем, и лишь затем решать визуальную систему.
- Сначала обязательно судить о платформенных различиях, и лишь затем решать настрой обложки; нельзя угадывать предпочтения платформы по впечатлению.
- Использовать только бесспойлерные ключевые мотивы; нельзя прямо рисовать на обложке итоговую личность, ключевой переворот или ответ о ключевых отношениях.
- Обязательно одновременно выдавать: основной промпт генерации изображения, надёжную версию промпта без текста, Negative Prompt, примечания по вёрстке.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящие платформенные визуальные суждения, выбор системы обложки, жанровые «мины» и шаблоны вывода нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
