# Входной Prompt «проектирование сеттинга истории» жанра «женская романтика»

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-设计故事设定`.

Если в этом проходе данных, поддерживающих сеттинг, недостаточно (нет конкурентов, нет знаний предметной области), по необходимости дополнительно вызвать: `通用-分析竞对作品`, `通用-深度研究`.

Если в этом проходе также затрагиваются питание единиц-событий, цепочки ложных следов и опровержений или план развязки зацепок, по необходимости дополнительно вызвать: `通用-设计事件案件引擎`, `通用-设计线索伏笔与回收台账`.

Prompt не вправе в обход жанрового Skill напрямую писать.

## Обязанности, которые остаются только у этого Prompt

- Стабильно направлять задачу в `通用-设计故事设定`
- Закреплять, что продукт по умолчанию — **справочный документ авторской стороны**, а не научно-популярное пояснение для читателя
- Закреплять, что результат по умолчанию записывается обратно в реальный справочный файл, а не остаётся длинным текстом в чате

## Минимальные пункты подтверждения

1. Путь к целевому справочному файлу или название файла сеттинга, который нужно создать в этом проходе
2. Способ обработки: полная переработка / локальное дополнение / правка с исправлением
3. Нужно ли дополнительно увязывать питание единиц-событий или реестр зацепок и развязок
4. Разрешена ли запись обратно в файл напрямую (по умолчанию разрешена)

## Минимальные требования к исполнению

- В целевом файле как минимум должны появиться: формулировка одной фразой, ключевые пункты правил, границы и цена, путь ложного следа и опровержения, пригодный для написания пакет кадров.
- Если этот сеттинг входит в основную линию длинной формы, нужно также чётко прописать способ развития и развязки.
- При затрагивании высокорискованных деталей реальности необходимо использовать нарративизированное, оставляющее пробелы выражение, избегая формата учебника.
- Если пользователь явно не просит ограничиться обсуждением, формальный результат обязательно записывается в целевой Markdown-файл.

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящий каркас сеттинга, процесс проверки и жанровые патчи нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
