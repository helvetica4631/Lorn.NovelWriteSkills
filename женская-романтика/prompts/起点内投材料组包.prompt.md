# Упаковка материалов для внутренней подачи на Qidian

## Маршрутизация жанровых навыков (обязательно)

При формальном исполнении этого Prompt необходимо сначала загрузить: `通用-组包投稿材料`.

Если для текущего произведения ещё не проведена оценка применительно к Qidian, следует дополнительно вызвать `通用-平台签约评估框架`; если нужно заодно переписать аннотацию — дополнительно вызвать `通用-撰写内容简介`.

Prompt не вправе в обход жанрового Skill напрямую использовать правила упаковки.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом «упаковки материалов для внутренней подачи на Qidian» для произведений жанра «женская романтика»
- Сохраняет минимальный ввод, цепочку взаимодействия по умолчанию, требования к записи на диск и минимальную квитанцию в чате
- Маршрутизирует основные правила в `通用-组包投稿材料`

## Минимальный вход

1. Название произведения / название для целевой подачи
2. Жанровое позиционирование целевой версии для внутренней подачи на Qidian (одной фразой)
3. Источник целевого основного текста: по умолчанию в первую очередь читается начальный связный материал, из которого можно собрать связный основной текст для подачи не менее чем в `30000` знаков
4. Общий план / план тома / ритм первых десяти глав — достаточно хотя бы одного
5. Главный герой, жанровая механика, ключевая продающая точка
6. Есть ли уже текущие материалы аннотации
7. Если есть: последний основной отчёт оценки Qidian / вывод по вероятности / минимальный замкнутый цикл исправлений

## Минимальные требования к исполнению

- Сначала обязательно прочитать и учесть исследовательские материалы по оценке Qidian и существующие выводы оценки Qidian.
- Если сейчас нет пригодного вывода оценки Qidian, сначала обязательно дополнительно вызвать `通用-平台签约评估框架`.
- Если сейчас ещё не достигнута единая линия подачи Qidian (`30000` знаков связного основного текста + `内投版总大纲〈最低5000字〉` + `内投版第1卷卷纲` + `内投版简介`), это нужно заметно пометить как «предварительная версия при нехватке файлов» или «предварительная версия пакета, годного к подаче»; нельзя писать как зрелый пакет для внутренней подачи.
- Если пользователь явно не требует лишь наброска без записи в файлы, запись в репозиторий обязательна.
- По умолчанию следует записывать в: `投稿材料/起点内投/《作品名》/vYYYY-MM-DD-rN/`, и одновременно обновлять `当前版本索引.md`.
- Внешние передаваемые файлы включают только: `内投版简介`, `内投版正文`, `内投版总大纲`, `内投版第 1 卷卷纲`.
- Если создаются внутренние файлы авторской стороны вроде `组包自检`, `版本说明`, `模板字段覆盖表`, их обязательно явно пометить «не отправляются вместе с рукописью».
- В внешних передаваемых файлах запрещено любое самооценивание, самовосхваление, «сильнейшее / слабейшее звено на данный момент», остаточные комментарии о рисках, `建议现在内投` («рекомендуется подавать сейчас»), `可以直接进入编辑内投` («можно сразу передавать редактору») и прочее содержимое, где вместо редактора выносится суждение.

## Выдача по умолчанию

- Аннотация версии для внутренней подачи
- Основной текст версии для внутренней подачи (связный основной текст не менее `30000` знаков)
- Общий план версии для внутренней подачи (не менее `5000` знаков)
- План `1`-го тома версии для внутренней подачи

Внутренние файлы авторской стороны (если созданы, вместе с рукописью не отправляются):

- Самопроверка упаковки

## Напоминание одной фразой

Этот Prompt теперь — **слой входа жанра «женская романтика»**; настоящий каркас упаковки, правила записи на диск и арбитражный канон женского сегмента Qidian нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
