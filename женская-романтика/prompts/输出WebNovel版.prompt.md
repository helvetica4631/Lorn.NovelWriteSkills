# Вывод версии для WebNovel

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-输出WebNovel版`.

Prompt не вправе в обход жанрового Skill напрямую «переделывать» платформенный текст.

## Обязанности, которые остаются только у этого Prompt

- Служит входом платформенного вывода для WebNovel
- Сохраняет минимальный ввод, каталог вывода и напоминание об английских шлюзах
- Маршрутизирует основные правила в `通用-输出WebNovel版`

## Минимальные требования к исполнению

- Сначала сохранить линию роста, напряжение отношений, замыкание причинности и нулевое добавление фактов, затем заняться англизацией и кросс-культурной адаптацией.
- Корень каталога вывода: `WebNovel/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)
- Кроме строки `## 作者有话说`, китайского / CJK быть не должно.

## Напоминание одной фразой

Этот Prompt теперь — **слой платформенного входа жанра «женская романтика»**; настоящие платформенные исследования, детали исполнения и жанровые патчи нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
