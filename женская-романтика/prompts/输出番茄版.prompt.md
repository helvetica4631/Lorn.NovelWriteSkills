# Вывод версии для Fanqie

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `通用-输出番茄版`.

Prompt не вправе в обход жанрового Skill напрямую «переделывать» платформенный текст.

## Обязанности, которые остаются только у этого Prompt

- Служит входом платформенного вывода для Fanqie
- Сохраняет минимальный ввод, каталог вывода и напоминание о шлюзах основного текста
- Маршрутизирует основные правила в `通用-输出番茄版`

## Минимальные требования к исполнению

- Сначала сохранить линию роста, натяжение отношений, эмоциональные награды и нулевое добавление фактов, затем усилить для Fanqie ускорение темпа и жёсткий крючок в конце главы.
- Корень каталога вывода: `番茄小说/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`.

## Напоминание одной фразой

Этот Prompt теперь — **слой платформенного входа жанра «женская романтика»**; настоящие платформенные исследования, детали исполнения и жанровые патчи нужно по-прежнему читать в соответствующих Skill `通用-*` и исполнять там.
