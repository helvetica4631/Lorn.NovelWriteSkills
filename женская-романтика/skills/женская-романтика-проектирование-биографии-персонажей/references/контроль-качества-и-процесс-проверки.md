# Контроль качества и процесс проверки

## Критерии успеха

- Ни одного противоречия с планом
- Мотив персонажа ясен и сопряжён с ценой
- Сеть отношений способна порождать события
- Зацепы письма можно прямо приложить к основному тексту
- У психологической арки есть триггерное событие и точки обратной ссылки
- Индекс может служить входом для перекрёстной проверки

## Процесс проверки

1. Завершить основную часть биографии.
2. Сверить согласованность с общим планом / планом тома.
3. Сверить отношения с биографиями других персонажей.
4. Проверить, можно ли прямо использовать зацепы письма.
5. Проверить, что у секрета есть хотя бы одна форма, поддающаяся доказательству.
6. Проверить, есть ли в психологической арке откаты, неудачи и ошибочные суждения.
7. Дополнить индекс, чтобы можно было возвращаться к источникам.

## Типичные причины доработки

- Много ярлыков, но слишком мало зацепов для основного текста
- Психологический рост похож на резюме, а не на траекторию событий
- В сети отношений нет структуры власти
- Не прописаны границы способностей, персонаж похож на универсальный инструмент
