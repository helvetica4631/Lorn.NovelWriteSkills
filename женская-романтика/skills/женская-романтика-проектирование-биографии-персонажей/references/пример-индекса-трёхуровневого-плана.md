# Пример индекса трёхуровневого плана

## Рекомендуемые поля

- Уровень источника в плане
- Номер (например, `T1.1 → 1.1 → 1.1.3`)
- Временной узел
- Описание события
- Функция присутствия персонажа
- Влияние на психологическую арку

## Образец каркаса

```markdown
## Индекс соответствия сюжета трёхуровневого плана

### Траектория полного развития психологической арки персонажа

#### Первый этап: исходное состояние
- Шаг 1: профессиональная уверенность (соответствует: периоду повседневной стабильности)
- Шаг 2: доверие к правилам (соответствует: вышестоящий порядок по-прежнему считается надёжным)

#### Второй этап: потрясение и пробуждение
- Шаг 6: первое аномальное потрясение (соответствует `T1.1`)
- Шаг 8: ключевая формулировка переписана (соответствует `1.1 / 1.3`)

### Первый уровень (общий план): ключевые сюжетные ходы
- `T1.1`: персонаж впервые соприкасается с ключевой аномалией и меняет направление дальнейших действий.

### Второй уровень (часть / том): тактические сюжетные ходы
- `1.1`: персонаж проходит обход, упирается в стену, достраивает звено цепочки.
- `1.3`: персонаж при сверке в ключевом учреждении обнаруживает трещину в формулировках.

### Третий уровень (глава): исполнительные сюжетные ходы
- `1.1.1`: запуск аномалии.
- `1.1.3`: обход, упирание в стену.
- `1.3.2`: сверка в ключевом учреждении / достройка звена.
```

## Принципы использования

- Индекс — не украшение, он должен допускать обратную проверку.
- Для одного и того же события по возможности ясно писать «что сделал персонаж», «что потерял», «как его вынудили к следующему шагу».
