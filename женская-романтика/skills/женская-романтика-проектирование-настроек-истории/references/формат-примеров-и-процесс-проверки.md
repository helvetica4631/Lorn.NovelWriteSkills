# Формат примеров и процесс проверки

## Образец каркаса

```markdown
# [Название элемента] — документ по приёмам / процедурам / доказательствам / настройкам

## Основные сведения
## Механизм / процедура
## Сценарии применения
## Общественное влияние
## Эволюция и возврат
## Роль в длинном романе
## Проверка достоверности
```

## Процесс проверки

1. Завершить первый черновик настройки.
2. Проверить, можно ли разбить правила на пункты.
3. Проверить, есть ли следы, границы, цена, лазейки, контрмеры.
4. Проверить соответствие ресурсам персонажей, временной линии, городской экосистеме.
5. Проверить, можно ли написать это в виде кадров, а не только в тоне справочника.

## Типичные причины доработки

- Настройка крутая, но в сюжете не нужна
- Есть механизм, нет следов
- Есть следы, нет сложности получения
- Есть правила, нет человеческой и общественной цены
