# Дополнение к жанровому шаблону рецензии персонажей (женская романтика)

Этот файл дописывает лишь **жанровый раздел рецензии биографий персонажей женской романтики**; при выполнении сначала используй «Каркас отчёта о рецензии биографий персонажей» из `общий-рецензия-биографии-персонажей`, затем впиши содержимое этого файла в соответствующие разделы-заполнители.

## 1. Пояснение о разделении общего / жанрового

- Перенесено в общий слой: основной каркас цепочки чтения, проверка базовой информации, определение персонажа одной фразой, функциональная позиция персонажа, общая рамка играбельности / пишемости, ярлыки и арка роста, библиотека материалов, градация проблем, оценка, рекомендации по правке, идеи для рывка `9.2+` и выдача кадров выхода / повторно используемых реплик.
- Этот файл отвечает лишь за специфический для женской романтики критерий рецензии: городская идентичность и институциональные щели, позиция в рабочем конфликте (позиция полномочий / «крайнего»), тайна, поддающаяся фиксации уликами, стойкость к беседе по подотчётности, возможность стать «крайним» и путь оправдания с пересмотром дела, мелкие городские микроаномалии, жанровая оценка по специальным критериям и жанровый вывод.
