# Единый промпт вывода «версии для Bilibili» романа жанра «ИИ-фантастика»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【ИИ-фантастика】, лучше подходящую контексту Bilibili: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя цепочку данных, аудиовизуальную аномалию и ощущение обсуждения.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/создание-основного-текста.prompt.md`
- `.github/prompts/шлифовка-основного-текста.prompt.md`
- `.github/prompts/устранение-духа-ии.prompt.md`

### 1.2 Жанровый вход

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `общий-вывод-bilibili` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку технических событий, цепочку данных, давление реального пространства и нулевое добавление фактов, затем усилить для Bilibili аудиовизуальную аномалию, читаемость для молодых и ощущение обсуждения.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов превращать текст в закадровый комментарий или текст-мем.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `B站/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `общий-вывод-*/SKILL.md`
- Нельзя писать «ИИ-фантастику» как закадровый текст для видео, пост-разбор «вторичного творчества» или пустую рукопись с одними лишь молодёжными оборотами

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».

В этом проходе дополнительно усвоены ключевые моменты: аудиовизуальный вход через аномалию, лёгкая подколка без выпадения из образа, точки для обсуждения, растущие из прорех в уликах и выбора персонажей.
