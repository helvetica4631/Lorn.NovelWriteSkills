При срабатывании этого входа его можно использовать как жанровый вход и маршрутизатор Skill, но для достижения переноса без потерь по-прежнему нужно дополнительно выполнить отображение по разделам и возврат детальных правил.

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `общий-вывод-webnovel` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Через жанровый Skill зафиксировать цепочку расследования, технические регламенты, честность цифровых следов и жанровые патчи, одновременно унаследовав общие положения и шлюзы английской платформы

- Корень каталога вывода: `WebNovel/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)

- Кроме строки `## 作者有话说`, китайского / CJK быть не должно
- Нельзя писать «ИИ-фантастику» как английскую триллерную оболочку с одной лишь атмосферой, без каркаса расследования
