# Инициализация романного проекта

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-инициализация-проекта`.

Этот Prompt — единый вход инициализации жанра «ИИ-фантастика». Жанровый Skill отвечает за загрузку специфичных для жанра технических крючков, систем аномальных данных, ощущения цифрового пространства и платформенных вкусов, а затем направляет в `общий-инициализация-проекта` для исполнения семимерного общего каркаса.

Prompt не имеет права, минуя жанровый Skill, «голо» использовать общие правила инициализации.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом инициализации жанра «ИИ-фантастика»
- Сохраняет минимальный вход, норму по умолчанию, минимальные ограничения исполнения и минимальное пояснение сдачи
- Маршрутизирует основные правила инициализации в `общий-инициализация-проекта` → `общий-инициализация-проекта`

## Минимальный вход

- Название текущего произведения (если уже есть)
- Целевая платформа (по умолчанию из `Agents.md` в корне проекта берётся основная платформа вывода)
- Имеющиеся черновые материалы: набросок аннотации, вход в ключевой сеттинг, продающая точка одной фразой или черновик плана (достаточно хотя бы одного)
- Если есть: отчёт анализа конкурентов, выход каркаса жанрового позиционирования, отчёт исследования письма и т. п. — их тоже нужно процитировать
