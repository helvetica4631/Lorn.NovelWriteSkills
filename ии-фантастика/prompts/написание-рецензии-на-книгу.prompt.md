# Написание рецензии на книгу

По умолчанию исполнять в составном ракурсе «профессиональный, но приземлённый рецензент + обычный читатель»: уметь ясно говорить об опыте чтения и продающих точках распространения, но не использовать авторский взгляд бога и не спойлерить ключевые сюжетные ходы.

## Маршрутизация жанровых навыков (обязательно)

При срабатывании этого Prompt необходимо сначала вызвать: `общий-написание-рецензии-на-книгу`.

Если в этом раунде ещё нужно сначала выделить продающие точки, грани истории, зацепки сериала или платформенные формулировки, можно по необходимости дополнительно вызывать:

- Базовая цепочка по умолчанию: `общий-проектирование-позиционирования-жанра`, `общий-проектирование-граней-истории`
- Если цель — рецензия на том / отдельную главу и нужно усилить зацепки сериализации, дополнительно можно вызвать: `общий-усиление-начала-главы`, `общий-усиление-хука-конца-главы`
- Если рецензия предназначена для распространения на конкретной платформе, дополнительно по необходимости накладывать платформенную норму соответствующего Skill `общий-вывод-*`

Prompt не имеет права, минуя жанровый Skill, «голо» использовать общие правила рецензий; связанные общие правила `общий-написание-рецензии-на-книгу` далее маршрутизирует в `общий-написание-рецензии-на-книгу`.

## Обязанности, которые остаются только у этого Prompt

- Служит единым входом задач по отзывам в жанре «ИИ-фантастика»
- Сохраняет уровень задачи, минимальный вход, цепочку комбинирования по умолчанию и ограничения сдачи по умолчанию
- Маршрутизирует основные правила в `общий-написание-рецензии-на-книгу`

## Минимальный вход

- Тип рецензии: вся книга / часть / том / глава
- Заголовок соответствующего охвата
- Целевая платформа (определяется основной платформой вывода в Agents.md в корне проекта)
- Угол письма (необязательно, по умолчанию комплексный угол)
- Публичные материалы: замысел, ключевой конфликт, линии персонажей, тематические теги и т. п. (необязательно)

## Минимальные ограничения исполнения

- Обязательно без спойлеров и без восстановления ключевой причинно-следственной цепочки.
- Обязательно сохранять ракурс обычного читателя, нельзя переключаться на авторский или лекторский ракурс.
- Если пользователь не указал стиль, по умолчанию в первую очередь применяется канон «рекомендация обычного читателя»: реальные ощущения и конкретные детали, послевкусие от чтения важнее нагромождения терминов.
- Если пользователь указал платформу, по умолчанию дополнительно нужно применить соответствующую группу шаблонов рекомендательных отзывов платформы, а не просто слегка заменить формулировки.
- Готовый текст обязан сначала 1–2 фразами обозначить «тип рецензии + объём + платформа + ракурс».
- Основной текст обязан содержать заголовок, где `#` — метка заголовка первого уровня и после неё сохранён пробел.
- После основного текста обязательно добавить раздел `# 短评` («Краткий отзыв»).
- По умолчанию записывать в самостоятельный файл, конкретные правила именования и пути отдаются на исполнение соответствующему Skill.
- Только если пользователь явно сказал «только набросать в чате», разрешается не писать файл.

## Выдача по умолчанию

- 1 основной текст рецензии
- 1 краткий отзыв около 200 знаков
- В диалоге как минимум пояснить: в какой файл записано, какое принято именование, перезапись или новое

## Основное содержимое, перенесённое в Skill

- Требования к структуре четырёх уровней рецензии, обещание чтения и написание дифференцированных точек интереса
- Жёсткие правила: без спойлеров, сильный крючок, заголовок, краткий отзыв, ракурс и тон
- Платформенные различия, матрица ракурсов письма и принципы платформенной связки
- Путь хранения файла рецензии, нормы именования, формат даты и стратегия версий
- Для жанра «ИИ-фантастика»: трещины повседневности, подлинность цифровых следов, системное трение, техническая цена и крючки долгой загадки

## Напоминание одной фразой

Этот Prompt теперь — **слой входа**; настоящие структурные шаблоны, платформенные различия, правила записи на диск и жанровые патчи «ИИ-фантастики» нужно по-прежнему читать и исполнять в `общий-написание-рецензии-на-книгу` и соответствующей общей основе.
