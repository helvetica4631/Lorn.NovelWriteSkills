# Профессиональное руководство по удалению ИИ-привкуса из основного текста романа жанра «ИИ-фантастика»

## Связанные навыки (специализированные для удаления ИИ-привкуса)

[`通用-去AI味重写`｜переписывание с удалением ИИ-привкуса](../skills/通用-去AI味重写/SKILL.md)

Для любой задачи «удаление ИИ-привкуса из целой главы / очистка локальной шаблонной интонации / человечное переписывание без сокращения информации / двойная защита точки зрения и числовых значений» следует в первую очередь вызывать этот skill.

## Обязанности, которые остаются только у этого Prompt

- Распознавать «устранение духа ИИ» как вход задачи, для которой в первую очередь обязательно загрузить `通用-去AI味重写`
- Требовать менять реальные файлы в рабочей области, а не только показывать пример в чате
- Требовать при неясном объёме сначала одной фразой подтвердить границы
- Требовать, чтобы окно чата по умолчанию возвращало только краткую проверяемую сводку правок, не вставляя всю главу

### ⚙️ Жёсткие требования к обновлению файла (дополнительные указания для ИИ-ассистента)

- Предпосылка по умолчанию: вы обрабатываете реальный файл основного текста в рабочей области.
- **Запрещено давать в диалоге лишь целый абзац или целую главу «текста после устранения духа ИИ», не изменяя файл**.
- Когда пользователь явно указал всю главу, основной текст переписывается полностью и записывается обратно; если указан только фрагмент — заменяется только соответствующий фрагмент.
- Если охват неясен, сначала одной фразой подтвердите границы обработки.
- В окне чата достаточно кратко указать: файл, охват, основные типы правок.
- Только если пользователь явно требует «только обсуждение и демонстрацию, файл не трогать», разрешается показывать лишь примерные абзацы.

## Общее содержимое, перенесённое в Skill

Следующее содержимое перенесено в `AI科幻-去AI味重写` и его references как основной слой-носитель:

- Порядок защиты и правила моста между удалением ИИ-привкуса и контрольными картами, шлифовкой основного текста, рецензией глав
