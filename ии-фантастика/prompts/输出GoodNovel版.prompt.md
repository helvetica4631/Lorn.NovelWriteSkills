# Единый промпт вывода «версии для GoodNovel» романа жанра «ИИ-фантастика»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в английскую версию 【ИИ-фантастика】, лучше подходящую для GoodNovel: сохранить ключевую информацию, соблюдать английские шлюзы, выводить в правильный каталог, сохраняя цепочку расследования, напряжение отношений и тягу к следующим главам.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/创建小说正文.prompt.md`
- `.github/prompts/正文润色.prompt.md`
- `.github/prompts/去AI味.prompt.md`

### 1.2 Жанровый вход

- `.github/skills/AI科幻-输出GoodNovel版/SKILL.md`
- `.github/skills/AI科幻-输出GoodNovel版/references/题材边界与来源.md`
- `.github/skills/AI科幻-输出GoodNovel版/references/执行细则与题材补丁.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出GoodNovel版` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку расследования, давление реальности и нулевое добавление фактов, затем усилить английское эмоциональное напряжение и тягу отношений.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов портить плавность английского и напряжение платформы.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `GoodNovel/`
- Выходной файл может содержать только: английский заголовок, английский основной текст, `## 作者有话说` («Слово от автора»)
- `Len` основного текста не ниже 6500
- Кроме строки `## 作者有话说`, китайского / CJK быть не должно
- Нельзя писать «ИИ-фантастику» как английский текст с одними лишь эмоциями, без каркаса расследования

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, английские шлюзы, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
