# Единый промпт вывода «версии для издательства» романа жанра «ИИ-фантастика»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【ИИ-фантастика】, ближе к вкусу издательской рецензии: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя логическое замыкание, фактуру реального расследования и нагрузку на персонажей.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/创建小说正文.prompt.md`
- `.github/prompts/正文润色.prompt.md`
- `.github/prompts/去AI味.prompt.md`

### 1.2 Жанровый вход

- `.github/skills/AI科幻-输出出版社版/SKILL.md`
- `.github/skills/AI科幻-输出出版社版/references/题材边界与来源.md`
- `.github/skills/AI科幻-输出出版社版/references/执行细则与题材补丁.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出出版社版` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить цепочку технических событий, реальную логику и нулевое добавление фактов, затем усилить сдержанное выражение в издательском духе, жанровость и удобство для рецензента.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов ломать устойчивость структуры.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `出版社/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Нельзя писать «ИИ-фантастику» как пустую рукопись с одной лишь издательской интонацией, без каркаса технических событий

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
