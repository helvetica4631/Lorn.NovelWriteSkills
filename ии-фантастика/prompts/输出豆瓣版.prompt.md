# Единый промпт вывода «версии для Douban» романа жанра «ИИ-фантастика»

## Статус миграции (жёстко)

Этот Prompt уже переделан в тонкий вход. При срабатывании этого входа его следует рассматривать как жанровый вход и напоминание об оркестрации, а не как основной файл-носитель платформенных правил.

## 0. Ваша задача (одной фразой)

Переписать входную главу в версию 【ИИ-фантастика】, лучше подходящую контексту Douban Read: сохранить ключевую информацию, соблюдать шлюзы, выводить в правильный каталог, сохраняя фактуру реальности, атмосферу расследования и послевкусие.

## 1. Файлы, которые необходимо одновременно прочитать и использовать (жёстко)

### 1.1 Базовый Prompt

- `.github/prompts/创建小说正文.prompt.md`
- `.github/prompts/正文润色.prompt.md`
- `.github/prompts/去AI味.prompt.md`

### 1.2 Жанровый вход

- `.github/skills/AI科幻-输出豆瓣版/SKILL.md`
- `.github/skills/AI科幻-输出豆瓣版/references/题材边界与来源.md`
- `.github/skills/AI科幻-输出豆瓣版/references/执行细则与题材补丁.md`

## 2. Порядок исполнения (жёстко)

1. Сначала прочитать базовый Prompt и соблюдать его.
2. Затем прочитать `通用-输出豆瓣版` и его references; этот общий Skill дальше направляет в соответствующий жанровый Skill.
3. Сначала сохранить каркас технических событий, технические опорные точки и нулевое добавление фактов, затем усилить для Douban сдержанное выражение, послевкусие и недосказанность.
4. Только в последнюю очередь заниматься снижением схожести; нельзя ради снижения повторов портить жанровость и настрой платформы.

## 3. Минимальные ограничения совместимости, сохраняемые этим входом

- Корень каталога вывода: `豆瓣/`
- Выходной файл может содержать только: заголовок главы, основной текст, `## 作者有话说` («Слово от автора»)
- Канон объёма основного текста: объём основного текста определяется по «диапазону знаков по умолчанию для платформы» из `通用-输出*版/SKILL.md`
- Нельзя писать «ИИ-фантастику» как текст с одной лишь литературной интонацией, без каркаса технических событий

## 4. Пояснение о переносе

Общие положения платформы, границы жанра, патчи исполнения, детальные правила заголовка, ритм внутри главы и канон слова от автора — всё перенесено в соответствующие Skill / references. При конфликте приоритет у цепочки «базовый Prompt + жанровый Skill».
