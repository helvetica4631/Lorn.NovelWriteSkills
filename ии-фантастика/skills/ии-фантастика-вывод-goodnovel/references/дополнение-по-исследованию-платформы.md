# Дополнение по исследованию платформы

- ИИ-фантастика версии для GoodNovel больше ценит быстрый ритм, сильную визуальность, сильные событийные точки.
- В первую очередь усиливать: наглядный конфликт, сильную эмоциональную обратную связь, видимое изменение в каждой главе.
- Главное избегать: чрезмерных местных пропусков информации, из-за которых повышается порог понимания для читателя.
