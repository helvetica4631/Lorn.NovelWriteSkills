# ии-фантастика-вывод-qidian (Вывод версии для Qidian — ИИ-фантастика)

Это жанровая обёртка ИИ-фантастики для вывода версии Qidian.


<!-- ===== Layer 3: кэш сценария ===== -->

## Позиционирование жанровой обёртки

- Поддерживать специальные правила жанра ИИ-фантастики на платформе Qidian, запретные пункты и жанровые патчи.
- Как вход жанра: при срабатывании этого Skill **в первую очередь обязательно загрузить** `общий-вывод-qidian`.

## Соответствующий общий Skill

- `общий-вывод-qidian` (**обязательно загрузить** — сама часть общих правил платформы)

## Обязательные требования

- Нельзя в обход `общий-вывод-qidian` писать параллельный набор общих правил.
- При ссылке на общие способности ссылаться только по названию, без пути.
## Дополнительные обязанности жанра

- Специальные жанровые ограничения ИИ-фантастики на платформе Qidian (плотность интриги, интервал между разворотами, честность данных, технические якоря)
- Запретные пункты жанра, подобные ИИ-фантастике (запрет сверхъестественных объяснений, разрушающих логику детектива; запрет зацепок без возврата)
- Отношения наложения с общими правилами платформы и корректировка приоритетов

## References для дальнейшего чтения (гейт обязательного чтения)

**Перечисленные ниже файлы references обязательно читать по одному через инструмент `read_file`; нельзя пропускать ни один под предлогом «знания уже есть», «в прошлый раз уже читал» или «этот файл — всего лишь справка».** Каждая запись references выполняется принудительно по указанному для неё уровню обязательности чтения:

- Файлы с пометкой **обязательно читать**: их нужно прочитать, пропуск хотя бы одного считается нарушением процесса, начинать выполнение процесса нельзя.
- Файлы без пометки «обязательно»: их нужно прочитать, но после прочтения можно извлечь только фрагменты, прямо относящиеся к текущей задаче, построчное прочтение не требуется.
- Если файла по указанному пути не существует (например, внешний путь не подготовлен), в журнале обязательно явно записать `reference_missing_{refName}`, молча пропускать нельзя.

## Обязательные требования

- В первую очередь обязательно загрузить `общий-вывод-qidian`
- При конфликте жанрового патча и общих правил платформы: границы жанра, запреты жанра → по этому Skill; общий ритм платформы, информационная структура → по общему Skill
- Нельзя в этом Skill параллельно копировать полные общие правила общего Skill
