# Дополнительный шаблон контрольной карточки (ИИ-фантастика)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/общий-генерация-контрольной-карточки-главы/references/шаблон-контрольной-карточки-главы.md`

## 1. Способ использования (обязательно)

1. Сначала по общему шаблону контрольной карточки заполнить полную главную карточку.
2. Затем дописать поля этого файла в соответствующие разделы.

## 2. Дополнительные поля ИИ-фантастики

- Состояние зацепки: заложена / продвинута / опровергнута / возвращена
- Состояние следов данных: появление / конфликт / разворот / реализация
- Системное трение: права на расследование, сложность запроса доказательств, сопротивление учреждений

## 3. Дополнительные пункты приёмки

- [ ] Как минимум один сценический юнит несёт вознаграждение середины.
- [ ] Как минимум в одном узле реализовано «опровержимое введение в заблуждение».
