## Когда использовать

- После выбора платформы и до проектирования плана — запуск инициализации проекта ИИ-фантастики.
- Уже есть жанровое вдохновение, но нет уверенности, сработает ли сочетание «технический крючок + аномальные данные + платформа» в ИИ-фантастике.
- Общий план уже дописан, но кажется, что специфичное для ИИ-фантастики «ощущение цифрового пространства» или «техническая цена» слабовата и нужно вернуться к решениям инициализации.

## Случаи, когда не применяется

- Чисто любительское, вольное письмо ради удовольствия.
- Создание короткой / средней ИИ-фантастики (при объёме в пределах десяти тысяч знаков такая тяжёлая инициализация не нужна).
- Продолжение отдельного тома уже существующего произведения в жанре ИИ-фантастики (следует использовать `ии-фантастика-проектирование-плана-тома`).

## Дополнения к инициализации ИИ-фантастики

### 1. Дополнения по адаптации под платформы

| Платформа | Ключевые моменты адаптации ИИ-фантастики |
| --- | --- |
| **Qidian (起点中文网)** | Главная площадка ИИ-фантастики. Читатели предпочитают социальный детектив, технический детектив в стиле документальной прозы, логически строгие долгие загадки. Режим «сюжетный случай-юнит + основная линия» — стандарт. Порог подписания высок, нужен дифференцирующий срез. |
| **Qimao (七猫小说)** | Принимает ИИ-фантастику, но требует более быстрого темпа. Предпочитает сильную атмосферу и сильную интригу: «городские страшилки», «страшилки о правилах». В первые 3 главы обязательно должно произойти аномальное событие. |
| **Fanqie (番茄小说)** | Подходит для быстрого смешанного жанра «городские способности + детектив». Хорошо принимает детективы с фантазийным уклоном (например, страшилки о правилах, жуткий поток). |
| **Zhihu Yanxuan (知乎盐选)** | Подходит для социального детектива, женских детективов — коротких / средних и длинных форм. Сильные эмоции, сильное погружение, допустимо первое лицо. |
| **Jinjiang (晋江文学城)** | Женский детектив (героиня, две линии — чувства + детектив). Подходит для «женского детектива», «романтического детектива», «детектива про попаданку в книгу». |

### 2. Напоминание о сочетании приёмов

ИИ-фантастика — типичный событийно-ориентированный жанр, принципиально отличающийся от женской любовной прозы (ориентированной на отношения):

- **Обязателен слой ключевого конфликта**: основной приём — «разгадка / расследование, сюжетный случай-юнит», способ организации длинной основной линии — «закулисный злодей»
- **Рекомендуется слой запуска повествования**: перерождение («восполнение сожаления о том, что знал атакующего, но не имел следов данных»), будничное / реалистичное начало (сверхъестественные элементы нужно вернуть в рамки реальности)
- **Рекомендуется слой устойчивого двигателя**: двухлинейное продвижение «сюжетный случай-юнит + основная линия» (в каждом томе — одно замкнутое техническое событие + продвижение скрытой линии длинной загадки)
- **Слой эмоциональной зацепки**: вспомогательная позиция. Контрастная группа / «обратный удар», отношения наставника и ученика встречаются часто, но не определяют движущую силу
- **Антишаблонные новшества**: социальная школа глубоко копает человеческую природу vs «чистая» школа с изящными уловками; либо слияние: «детектив + офис», «детектив + городские способности»

### 3. Элементы, требующие специализации на стадии инициализации

| Элемент | Смысл в ИИ-фантастике | Пункт проверки при инициализации |
| --- | --- | --- |
| **Технический срез** | С какой технической точки зрения главный герой входит в техническое событие? Судмедэксперт / следователь / журналист / юрист / психолог / обычный человек, оказавшийся втянутым | Достаточно ли правдоподобно, что профессия позволяет «приблизиться к ядру технического события»? |
| **Система аномальных данных** | Что такое «аномальная точка» технического события? Научно объяснимое vs сверхъестественное | Совместима ли система следов данных с красными линиями платформы? |
| **Давление цифрового пространства** | Становится ли городская среда частью повествования? Старые цифровые районы / старые системные районы / этажи технической платформы / подземные пространства | Абстрагировано ли цифровое пространство до «пригодного сценического актива»? |
| **Якорь технической цены** | Сопровождается ли разгадка / технический прорыв личной ценой героя? Давление системы / физическое и душевное истощение / разрыв отношений | Достаточна ли цена, чтобы поддерживать эмоциональное натяжение на длинной дистанции? |
| **Режим выпуска информации** | Цикл «сначала задать интригу → постепенно раскрывать → частично закрывать → новая интрига» | Поддерживается ли этот цикл в планировании на уровне тома? |

### 4. Значение эмоциональной оси по умолчанию

По умолчанию эмоциональная ось ИИ-фантастики главным обещанием берёт **детектив** — ключевой двигатель дочитывания: «хочется узнать правду». Дополняет её **爽-проза** — реализуется в моменты технического прорыва или «обратного удара». Эмоциональная кривая должна следовать схеме:

```
напряжение (появляется техническое событие) → недоумение (начинается расследование) → частичное разрешение недоумения (получена зацепка) → новый вопрос (более глубокая загадка) → поэтапное раскрытие (конец тома) → более крупная интрига (продвижение длинной линии)
```

### 5. Дополнения по красным линиям платформ

- Qidian, ИИ-фантастика: избегать чрезмерно кровавых / жестоких описаний; реальные технические события требуется переносить в вымышленный мир
- Qimao / Fanqie: избегать феодально-суеверных сверхъестественных настроек (можно упаковывать как «научно неразгаданную загадку» или «психологическую иллюзию»)
- Все платформы: в реальных процедурах технического детектива не должно быть явных грубых ошибок (можно ориентироваться на реальные процедуры судмедэкспертов / следователей из исследовательского отчёта)
