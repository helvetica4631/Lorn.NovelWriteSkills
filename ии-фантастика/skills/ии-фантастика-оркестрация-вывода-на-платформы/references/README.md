# Референсы мультиплатформенного вывода ИИ-фантастики

В этом каталоге хранятся патчи жанровой достоверности для мультиплатформенного вывода в жанре ИИ-фантастики; общие правила оркестрации, журналов и итогового контроля сходства по системному контролю доступа — по `общий-оркестрация-вывода-на-платформы`.
