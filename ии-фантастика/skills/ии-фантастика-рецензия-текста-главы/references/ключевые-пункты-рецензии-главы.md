# Ключевые пункты рецензии глав

## Структура внутри главы

- В первых 2–3 абзацах обязательно как минимум два из: аномалия / направление действия / ощущение опасности
- В середине обязательно исполнить одну награду по информации / эмоциям / ресурсам / отношениям
- Хук конца главы обязан быть как минимум одним из: поворот, раскрытие, кризис

## Инженерная проверка

- Функциональные точки тома приземлены в полном объёме
- Все появляющиеся персонажи проверены по биографиям
- Ключевые суждения можно сослаться на следы данных
- Системное трение служит конфликту, а не популяризации
- В основном тексте, эпиграфе главы и `## 作者有话说` (слово автора) не должно быть конкретных годов и авторских управленческих номеров
- Авторские поля на стороне автора в `## 章节后记` (послесловие к главе) / пояснениях к шлифовке по умолчанию не считаются нарушением по этому пункту, если только они не выходят на читательски видимый слой

## Проверка на читательской стороне

- У каждого абзаца ясный фокус
- Диалог несёт функцию
- Как минимум одно эмоциональное исполнение
- Как минимум одна запоминающаяся точка, привязанная к персонажу и эпохе
