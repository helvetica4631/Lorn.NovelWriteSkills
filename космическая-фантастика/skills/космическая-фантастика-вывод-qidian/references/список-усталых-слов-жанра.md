# Список «усталых» слов жанра научной фантастики (космос)

> Источник: усвоено из правил технической согласованности InkOS `sci-fi.md`
> Область применения: космическая фантастика, межзвёздная тематика
> Норма контроля: не более 2 раз на тысячу знаков

## Усталые слова первого уровня

| Усталое слово | Пояснение | Направление замены |
| --- | --- | --- |
| 虫洞跳跃 (прыжок через червоточину) | Универсальное пространственное перемещение, чрезмерно заезженное | Писать конкретное ощущение скачка (корпус вытягивается в нить / звёздный свет за окном растягивается в линии) |
| 星际联邦 (межзвёздная федерация) | Политическое образование-ярлык | Писать конкретную политическую структуру (парламент / колониальная компания / военный союз) |
| 超光速 (сверхсветовая скорость) | Универсальное физическое понятие | Писать конкретное техническое ограничение (радиомолчание в течение xx часов после скачка) |
| 外星文明 (инопланетная цивилизация) | Слишком расплывчато | Писать конкретные культурные черты (они не общаются словами / думают столетиями) |
| 第三类接触 (контакт третьего рода) | Исчерпанный шаблон научной фантастики | Писать конкретные детали первого взаимодействия |

## Усталые слова второго уровня

| Усталое слово | Пояснение | Направление замены |
| --- | --- | --- |
| 殖民船 (колониальный корабль) | Стандартный реквизит межзвёздного сеттинга | Писать конкретную цель и затруднения |
| 冬眠舱 (криокапсула) | То же | Писать конкретные телесные реакции после пробуждения |
| 资源星球 (планета-ресурс) | Фантастическая версия «той же карты в другой обёртке» | Писать конкретную добычу / экологию / конфликты |
| 舰队 (флот) | Групповой ярлык | Писать конкретную организацию и тактику |
| 末日武器 (оружие судного дня) | Универсальный триггер кризиса | Писать конкретный технический принцип и политические последствия |

## Усталые слова третьего уровня

| Усталое слово | Пояснение |
| --- | --- |
| 泰坦/巨构 (титан / мегаструктура) | Чрезмерно заезженный образ научной фантастики |
| 硅基生命 (кремниевая жизнь) | Универсальный шаблон инопланетных существ |
| 次元 (измерение) | Универсальный «объяснитель» межмировых переходов |

## Принцип обработки

Как в правилах InkOS для научной фантастики: слов первого уровня почти нет, слов второго уровня ≤ 1 раза на тысячу знаков, слова третьего уровня обрабатывать только при плотном появлении.
