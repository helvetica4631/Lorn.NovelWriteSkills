# Описание каталога распространения романов

`распространение-романов/` служит для хранения планов и процессных документов по распространению на платформах; его роль — **каталог процессов распространения**, а не жанровый каталог.

## Границы каталога

- Здесь в основном лежат SOP распространения, стратегии записи на диск по платформам, оркестрация исполнения, чек-листы и документы разбора.
- В этом каталоге не требуется обязательно создавать жанровые Skill по схеме «название жанра — название способности».
- Если в этом каталоге добавляется новый Skill, он не обязан находиться во взаимно-однозначном соответствии с жанровыми Skill.

## Точка входа в правила

Правила управления этим каталогом см.:

- `.github/instructions/distribution-directory-boundary.instructions.md`

## Связь с общими способностями

Если в сценариях распространения выкристаллизовались устойчивые способности, которые можно переиспользовать между жанрами, их следует вернуть в `CommonSkills/`;
в `распространение-романов/` остаются лишь дополнительные правила стороны процесса распространения и пояснения по внедрению.
