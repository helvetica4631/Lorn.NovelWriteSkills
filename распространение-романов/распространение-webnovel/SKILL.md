# Загрузка указанных глав в WebNovel с сохранением

Используется, чтобы загрузить указанную вами 1 или несколько глав в соответствующее произведение WebNovel (Inkstone) и сохранить их согласно требованиям кабинета.


<!-- ===== Layer 3: кэш сценария ===== -->

## Правило маршрутизации рабочего каталога (обязательно)

Перед выполнением этого Skill необходимо определить рабочий каталог по следующим правилам:

1. **Прочитать `Agents.md` в корне проекта** и проверить в нём объявление `主输出平台` («основная платформа вывода»)
2. Если текущая платформа (WebNovel) совпадает с `主输出平台` → рабочий каталог — `小说正文/`
3. Если текущая платформа не совпадает с `主输出平台`, либо `Agents.md` не существует / `主输出平台` не объявлена → рабочий каталог — `WebNovel/`

Все последующие пути к файлам глав, README.md и 分发记录.md (журнал распространения) строятся от этого рабочего каталога. **Явно уточняется**:
  - **Когда эта платформа — основная платформа вывода** → файлы глав, `README.md`, `分发记录.md` находятся в `小说正文/`
  - **Когда эта платформа — не основная платформа вывода** → файлы глав, `README.md`, `分发记录.md` находятся в `WebNovel/`

> **О путях**: все пути вида `WebNovel/` в нижеследующих разделах (например, `WebNovel/README.md`, `WebNovel/分发记录.md`) приведены как примеры написания рабочего каталога. Фактический каталог определяется приведённым выше «Правилом маршрутизации рабочего каталога»: если эта платформа — основная платформа вывода, все эти пути соответствуют `小说正文/`; если нет — `WebNovel/`.

## Когда использовать

- Вы уже положили главы для загрузки в каталог `WebNovel/`.
- Вы уже записали в `WebNovel/README.md` аккаунт, пароль, ID книги WebNovel, название книги и названия томов.
- Вы хотите, чтобы по фиксированному процессу автоматически выполнялось: вход в кабинет → подтверждение ручного входа → определение режима создания / изменения → заполнение заголовка главы → вставка основного текста → добавление слова от автора → сохранение → переход к следующей главе.

## Случаи, когда не применяется

- Вы хотите лишь отшлифовать текст и не нуждаетесь в открытии сайта для загрузки.
- Вы не предоставили аккаунт WebNovel или ID книги.
- Цель — не «сохранить главу», а только сверка содержимого.

## Требования ко входным данным (обязательно)

### 1) Каталог файлов глав

- Файлы для загрузки должны лежать в `WebNovel/`.
- Вы явно указываете, какие главы загружать (одну или несколько).
- Заголовок главы **не берётся напрямую из имени файла**: его необходимо извлечь из содержимого файла главы, нормализовать и затем внести в поле заголовка на странице.

### 1.1) Правила извлечения и сборки заголовка главы (обязательно)

- Из файла главы обязательно извлечь: номер главы (арабскими цифрами), заголовок главы, основной текст, «слово от автора».
- Если строка заголовка файла главы — `# 1.1.3 三分钟`, где `1.1.3` означает `номер части.номер тома.номер главы`; при извлечении необходимо взять только последний сегмент `3` как «номер главы», а `三分钟` — как «заголовок главы».
- WebNovel — платформа с делением на тома, при загрузке используется только номер главы внутри тома; нельзя переносить в поле заголовка трёхуровневую нумерацию вроде `1.1.3`, `2.4.17` как есть; итоговая запись допустима только в формате вроде `Chapter 3 三分钟`.
- На странице WebNovel есть только **одно поле заголовка главы**, итоговое вносимое значение — полная строка: `Chapter {章号} {章节标题}`.
- Между `Chapter`, `章号` (номером главы) и `标题` (заголовком) обязательно сохранять **1 пробел**, например: `Chapter 1 天降奇缘`.
- Если строка заголовка файла главы уже имеет полный формат (например, `Chapter 12 Night Visitor`) и номер главы совпадает, её можно использовать напрямую.
- Если извлечённая строка заголовка содержит лишь текст заголовка (например, `夜半来客`), необходимо автоматически собрать `Chapter {章号} 夜半来客`.
- Нельзя переносить в поле заголовка суффикс платформы из имени файла (например, `_WebNovel版`).

### 2) Источник метаданных

- Обязательно прочитать `WebNovel/README.md` и извлечь как минимум следующее:
  - имя пользователя авторского кабинета WebNovel
  - пароль авторского кабинета WebNovel
  - ID книги WebNovel (только цифры, например `11997642`; выбрать значение, соответствующее текущей главе, по «правилу определения ID книги»)
  - название романа (название книги, для текущей цели загрузки)
  - название каждого тома
### 2.1) Проверка платформы (обязательно)

После чтения `WebNovel/README.md` необходимо проверить, равен ли его первый заголовок первого уровня `# WebNovel 分发配置`:
  - **Совпадает** → продолжить последующий процесс
  - **Не совпадает** → немедленно остановить загрузку и сообщить пользователю об ошибке: `README.md 平台标识与当前 Skill 不符：预期"WebNovel 分发配置"，实际读取到"{实际读取到的标题}"。请检查是否将其他平台的 README.md 误放到了当前工作目录。` (Идентификатор платформы в README.md не соответствует текущему Skill: ожидалось «WebNovel 分发配置», фактически прочитано «{фактически прочитанный заголовок}». Проверьте, не положен ли в текущий рабочий каталог README.md другой платформы.)
### 3) Источник журнала распространения (обязательно)

- Обязательно прочитать `WebNovel/分发记录.md`:
  - если файла нет, сначала создать его, затем выполнять распространение.
  - используется для запроса соответствия «уникальный ключ главы -> ID главы» и определения для главы «режима создания» или «режима изменения».

### 4) Правило определения названия книги (обязательно)

- Если у романа нет частей: название книги берётся из «названия романа (названия книги)» в `README.md` каталога этой платформы.
- Если у романа есть части (несколько частей): название книги — название той части, в которой находится глава; нельзя ошибочно использовать общее название.

### 4.1) Правило определения ID книги (обязательно)

- Если у романа нет частей: ID книги берётся из парной записи к «названию романа (названию книги)» в `README.md` каталога этой платформы.
- Если у романа есть части (несколько частей): ID книги берётся из парной записи к названию той части, в которой находится глава.
- Запрещено использовать ID книги общего названия для глав частей или ID книги одной части для глав другой части.

### 5) Шаблон `分发记录.md` (при первом создании использовать напрямую)

Если `WebNovel/分发记录.md` не существует, его необходимо создать по следующему шаблону:

```markdown
# WebNovel 分发记录

> Назначение: фиксирует соответствие «уникальный ключ главы -> ID главы WebNovel», чтобы процесс распространения мог определять «режим создания / режим изменения».

## Описание полей

- `章节唯一键` (уникальный ключ главы): фиксированный формат `WebNovel书籍ID|分部名|卷号|章号|章名` (если частей нет, в поле названия части пишется `NA`)
- `WebNovel书籍ID` (ID книги WebNovel): соответствует ID книги в `WebNovel/README.md`
- `章节Id` (ID главы): ID главы в адресе редактирования главы WebNovel
- `最近操作` (последняя операция): `新建` (создание) или `修改` (изменение)
- `更新时间` (время обновления): `YYYY-MM-DD HH:mm:ss`
- `备注` (примечание): необязательно

## Таблица записей

|章节唯一键|WebNovel书籍ID|章节Id|最近操作|更新时间|备注|
|:--|--:|--:|:--|:--|:--|
```

### 6) Шаблон `README.md` (при первом создании использовать напрямую)

Если `WebNovel/README.md` не существует, его необходимо создать по следующему шаблону:

```markdown
# WebNovel 分发配置

> Назначение: хранит информацию о книгах WebNovel и соответствие названий томов. Процесс распространения требует ручного входа пользователя и пароль не читает.

## Информация о книге

### Роман без частей

| Название романа | ID книги WebNovel |
|:--|--:|
| 作品名 | 11997642 |

### Роман с частями

| Номер части | Название части | ID книги WebNovel | Число томов |
|:--|:--|--:|--:|
| 第1部 | 分部一书名 | 11997642 | 3 |
| 第2部 | 分部二书名 | 11997643 | 2 |

## Соответствие названий томов

### 分部一书名

| Номер тома | Название тома (английское) |
|--:|:--|
| 1 | Volume 1 Title |
| 2 | Volume 2 Title |

## Описание полей

- `小说名称` / `分部名`: должны точно совпадать с «правилом определения названия книги» из SKILL
- `分部号`: необходимо использовать нормативный формат `第N部` (например, `第1部`, `第2部`) и однозначно сопоставлять с `分部名`, без смещений и повторного использования
- `WebNovel 书籍ID`: только цифры, берётся из авторского кабинета WebNovel Inkstone
- `卷名`: английское отображаемое название этого тома на платформе WebNovel

## Способ входа

- **Этот файл не хранит пароль.** Процесс распространения откроет WebNovel Inkstone в браузере, и вам нужно **войти вручную** в браузере.
- Убедитесь, что вошедший аккаунт имеет права редактирования перечисленных книг.

## Примечания

- Процесс распространения проверит состояние входа; если вход не выполнен, нужно вручную завершить вход и только затем продолжать.
- Если появляются дополнительные шаги — проверка безопасности, вторичное подтверждение и т. п., вам нужно выполнить их вручную в браузере.
- Формат заголовка главы: `Chapter {章号} {章节标题}` (на английском).
```

## Процесс выполнения (строго по порядку)

### Шаг 1: чтение локальных входных данных

1. Прочитать и разобрать `WebNovel/README.md`.
2. Убедиться, что получены: аккаунт, пароль, целевой ID книги (выбранный по «правилу определения ID книги»), целевое название романа, целевое название тома.
3. Прочитать `WebNovel/分发记录.md` и построить соответствие «уникальный ключ главы -> ID главы» (рекомендуемый уникальный ключ: `WebNovel书籍ID|分部名|卷号|章号|章名`; если частей нет, название части фиксированно `NA`).
4. Прочитать указанные вами файлы глав и извлечь для каждой главы: номер тома, название тома, номер главы (арабскими цифрами), заголовок главы, основной текст, слово от автора.
5. Для каждой главы сформировать «итоговое значение поля заголовка на странице»: `Chapter {章号} {章节标题}`.

### Шаг 2: вход в авторский кабинет

1. **Обязательно открыть новую вкладку браузера** и в этой новой вкладке перейти по адресу:
   - `https://inkstone.webnovel.com/novels/list`
2. Эта новая вкладка используется только для текущего процесса загрузки в WebNovel; вкладку, в которой вы сейчас решаете другие задачи, повторно не использовать.
3. Если состояние входа недействительно или вход не выполнен:
   - сначала перейти к процессу входа, но **обязательно дождаться, пока пользователь вручную завершит вход**.
   - до тех пор, пока пользователь явно не сообщит вам «登录完成» (вход завершён), запрещено выполнять любые дальнейшие шаги.
   - в это время не пытаться подставлять пароль и не имитировать состояние успешного входа.
4. После завершения входа продолжить последующий процесс редактирования.
5. Если на странице редактирования появляются слой для новичков или подсказки-перекрытия:
   - сначала закрыть, пропустить или свернуть, убедившись, что редактор нормально работает, и только затем продолжать.

### Шаг 3: переход на страницу главы целевой книги (создание / изменение — одно из двух)

1. Перед переходом сначала проверить в `WebNovel/分发记录.md`, есть ли уже у этой главы `章节Id`.
2. Если у этой главы **нет** ID главы (режим создания), перейти по адресу:
   - `https://inkstone.webnovel.com/novels/chapter/create/{小说书籍ID}`
3. Если у этой главы **уже есть** ID главы (режим изменения), перейти по адресу:
   - `https://inkstone.webnovel.com/novels/chapter/edit/{书籍ID}/{章节ID}`
4. `{书籍ID}` обязательно берётся из `README.md` и должен быть строкой, состоящей только из цифр.
5. После входа на страницу редактирования сначала подтвердить информацию о томе:
   - информация о томе обычно находится в левом верхнем углу области редактирования главы, там показаны номер и название тома.

### Шаг 4: проверка информации о текущем произведении

1. Проверить, соответствует ли произведение на текущей странице редактирования целевому названию книги из `README.md`.
2. Если на странице есть информация о томе, информация о разделе тома или метка тома в левом верхнем углу, дополнительно проверить целевое название тома.
3. Если название книги или название тома не совпадает:
   - немедленно остановить загрузку текущей главы.
   - вернуть описание ошибки (название книги / названия тома не совпадают)
   - запрещено продолжать слепую загрузку в неверное произведение.

### Шаг 5: заполнение поля заголовка

1. Найти поле заголовка главы.
2. Установить его содержимое в полную строку: `Chapter {章号} {章节标题}`.
3. Перед вводом сначала выделить всё и очистить старое значение, чтобы не осталось «безымянная глава», «заголовок черновика» или прежние заголовки.
4. Ещё раз сверить:
   - использован арабский номер главы.
   - между `章号` (номером главы) и `标题` (заголовком) только один пробел.
   - не подмешана посторонняя информация — суффикс имени файла, название тома, название платформы и т. п.

### Шаг 6: заполнение основного текста

1. Ввести основной текст главы в область редактирования основного текста.
2. Необходимо гарантировать, что текст взят из указанного вами файла главы, без перепутывания глав.
3. Если редактор — область форматированного или квазиформатированного текста, после ввода необходимо убедиться, что видимый основной текст действительно попал в область редактирования, а не в элемент с неверным фокусом.

### Шаг 7: добавление слова от автора

1. Нажать "ADD AUTHOR'S THOUGHT" под областью редактирования главы.
2. Дождаться появления поля ввода во всплывающем диалоге.
3. В поле ввода диалога **сначала выделить всё и очистить старое содержимое**, затем ввести содержимое «слова от автора» этой главы, чтобы не склеивать его со старым текстом.
4. Если на странице есть подсказка об ограничении числа знаков, сохранить смысл исходного текста в пределах лимита, нельзя насильно превышать.
5. После завершения ввода нажать "SUBMIT".
6. Если страница позволяет свернуть или закрыть диалог, сначала убедиться, что содержимое записано, и только затем сворачивать, чтобы введённое не потерялось.

### Шаг 8: сохранение и получение ID главы

1. Нажать «SAVE».
2. Дождаться сообщения страницы об успешном сохранении или эквивалентного состояния успеха.
3. После успешного сохранения **обязательно сразу подтвердить, что URL текущей страницы главы изменился на**:
   - `https://inkstone.webnovel.com/novels/chapter/edit/{书籍ID}/{章节ID}`
4. Извлечь из URL `{章节ID}` и считать его окончательным `章节Id` этой главы.
5. Если страница не перешла, но сохранение успешно, также нужно продолжить проверку адресной строки и состояния страницы, подтвердив, обновился ли адрес до URL редактирования.
6. Записать «уникальный ключ главы + ID главы + время обновления» обратно в `WebNovel/分发记录.md`:
   - если записи нет: добавить новую.
   - если запись уже есть: обновить `章节Id` (если изменился) и время обновления.
7. `最近操作` записывается как `新建` или `修改` в зависимости от текущего режима.

> Правило формирования уникального ключа главы (обязательно):
> - Порядок полей: `WebNovel书籍ID|分部名|卷号|章号|章名`
> - При этом:
>   - `WebNovel书籍ID` берётся из `WebNovel/README.md`
>   - `分部名` — название книги текущей части; если частей нет — `NA`
>   - `卷号`, `章号` должны быть арабскими цифрами
> - Это правило нужно, чтобы избежать конфликтов одинаковых номеров глав при параллельном распространении многочастных и многотомных романов.

8. Если сохранение успешно, но `章节Id` по-прежнему не получен явно:
   - статус этой главы обязательно пометить как «частичный успех (сохранено, но ID главы не подтверждён)».
   - немедленно явно сообщить пользователю о точке блокировки.
   - запрещено молча засчитывать эту главу как полностью успешную.

### Шаг 9: цикл по нескольким главам

- Для каждой указанной главы строго повторять шаги 3–8, пока не будут завершены все главы.
- Перед началом каждой главы обязательно один раз запрашивать `分发记录.md` для определения режима создания / изменения, нельзя наследовать режим предыдущей главы.

### Опыт пакетной загрузки (подтверждено практикой на 40 главах, 2026-05-24)

> Нижеследующий опыт основан на итогах разовой загрузки в WebNovel глав 1–40 тома 1; все выводы проверены.

#### 1) Обнаружение изменений в редакторе основного текста — самая большая ловушка

Форматированный редактор в iframe на WebNovel **не обнаруживает изменения DOM автоматически**. Если лишь задать через `frame.evaluate()` значение innerHTML основного текста, кнопка SAVE будет кликабельна, но **сохранение не удастся** (URL не переходит на страницу редактирования и остаётся на странице create, без сообщения об ошибке).

**Правильный процесс внесения и запуска обнаружения:**

```javascript
// Внесение основного текста + обнаружение изменений (полный правильный процесс)
const frameEl = await page.locator('iframe').first().elementHandle();
const frame = await frameEl.contentFrame();

// 1. Сфокусировать редактор
const body = frame.locator('body');
await body.click();

// 2. Внести основной текст (разбить по одиночному переводу строки, каждая строка — отдельный абзац)
await frame.evaluate((text) => {
  document.body.innerHTML = '';
  const lines = text.split('\n');
  // Убрать пустые строки в начале и конце
  while (lines.length > 0 && lines[0].trim() === '') lines.shift();
  while (lines.length > 0 && lines[lines.length - 1].trim() === '') lines.pop();
  // Один <p> на строку, пустые строки заполнять &nbsp; для сохранения межстрочного интервала
  for (const line of lines) {
    const trimmed = line.trim();
    const el = document.createElement('p');
    el.textContent = trimmed || '\u00A0';
    document.body.appendChild(el);
  }
}, bodyText);

// 3. Запустить обнаружение изменений в редакторе
await body.press('End');        // подождать 100 мс
await body.press('Space');      // подождать 100 мс
await body.press('Backspace');  // подождать 300 мс
// Нажать SAVE
```

> **⚠️ Железное правило разбиения на абзацы**: основной текст **обязательно разбивать по `\n` (одиночный перевод строки)**, каждая строка — отдельный `<p>`, **запрещено объединять несколько строк в один абзац через `\n\n` (двойной перевод строки)**.
>
> Английские главы WebNovel написаны в стиле «каждое предложение с новой строки + пустая строка между крупными блоками»; одиночный перевод строки `\n` в `<p>.textContent` схлопывается браузером в пробел, из-за чего соседние строки слипаются в нечитаемый блок текста. Логика объединения `split('\n\n')` в этом сценарии — **фатальная ошибка**, она приводит к тому, что уже загруженные главы теряют всё деление на абзацы. #### 5) Сервер содержимого + стратегия предзагрузки малыми партиями (рекомендуется)

Для сценариев пакетной загрузки более 10 глав:

1. **Предобработка**: скриптом извлечь все главы в каталог `.cache/content_parts/no_part/v{номер тома}/` (формат: `{двузначный номер главы}_title.txt`, `{двузначный номер главы}_body.txt`, `{двузначный номер главы}_author.txt`).
2. **Запуск сервера**: `$env:CONTENT_PARTS_PORT='8765'; $env:DISTRIBUTION_PLATFORM_DIR='WebNovel'; node scripts/content_parts_server.mjs`
3. **Предзагрузка в память**: перед началом каждой малой партии сначала выполнить navigate на `http://127.0.0.1:8765/parts/v/1/{章号}`, получить JSON и сохранить в объект в памяти.
4. **Затем начинать цикл загрузки**: брать данные из памяти, не перечитывая файл для каждой главы.
5. **Учитывать CORS**: страница HTTPS не может напрямую делать fetch на HTTP. В коде Playwright сначала нужно получить данные через `page.goto('http://127.0.0.1:8765/...')`, а затем снова navigate на inkstone.

| После внесения основного текста + запуск изменения | 300 мс | Дать редактору переварить событие input |
| После нажатия ADD AUTHOR'S THOUGHT | 1000–1500 мс | Дождаться полной загрузки диалога + слоя |
| После SUBMIT | 500–800 мс | Дождаться закрытия диалога, размещения содержимого |
| После SAVE | 2500–3000 мс | Дождаться сохранения на сервере + перехода по URL |
| После Cancel в окне черновика | 300 мс | Дождаться исчезновения окна |

#### 7) Типичные признаки сбоя

| Симптом | Первопричина | Исправление |
|:---|:---|:---|
| После SAVE URL по-прежнему `/chapter/create/...` | Редактор не обнаружил изменения содержимого | После внесения основного текста добавить End→Space→Backspace |
| **После загрузки в главе нет деления на строки и абзацы, основной текст — единый блок** | **`split('\n\n')` объединил несколько строк в один абзац, `\n` в `textContent` схлопнулся в HTML** | **Перейти на `split('\n')`, каждая строка — отдельный `<p>`** |
| Заголовок не обновился | Прямой `fill()` без предварительной очистки | Сначала `fill('')`, затем `fill(text)` |
| Слово от автора не сохранено | Не нажато SUBMIT или перекрыто слоем | Сначала убрать слой "got it!", затем заполнить textarea + SUBMIT |
| Содержимое главы попало в предыдущую | В окне черновика нажато USE | Нажать Cancel, очистить и заполнить заново |
| `章节Id` отсутствует, но сохранение успешно | URL не перешёл или переход задержался | Подождать дольше (3000 мс+) или проверить через page.url() |

#### 8) Механизм сверки

После завершения каждой малой партии (5–10 глав) обязательно выполнять сверку:

- `плановое число глав = число успешных глав + число сбойных глав`
- У всех успешных глав обязательно должен быть `章节Id` (извлечён из URL)
- Все успешные главы обязательно записаны в `分发记录.md`
- При отсутствии любого пункта → приостановить следующую партию, сначала восполнить пропуски
## Минимальный исполнимый чек-лист (версия на 10 секунд)

> Порядок применения: перед каждым распространением быстро пройтись по пунктам по порядку; если какой-либо пункт не выполнен, сначала исправить, затем загружать.

1. **Полны ли входные данные**
   - Чётко определено, какие именно главы загружаются на этот раз (объём не расширяется).
   - Из `WebNovel/README.md` читаются имя пользователя, пароль, ID книги, название книги, названия томов.

2. **Верна ли цель**
   - Название книги и названия тома на текущей странице редактирования совпадают с `README.md`.
   - Режим главы определён: нет `章节Id` — идти на создание (`/chapter/create/{书籍ID}`), есть `章节Id` — идти на изменение (`/chapter/edit/{书籍ID}/{章节ID}`).

3. **Выполнен ли ключевой ввод**
   - Поле заголовка в полном формате: `Chapter {章号} {章节标题}` (Chapter + арабская цифра + один пробел).
   - Подтверждено, что основной текст записан в видимую область редактора (а не ошибочно внесён в другое место).
   - "作者有话说" («слово от автора») через "ADD AUTHOR'S THOUGHT" открыто в диалоге, заполнено, нажато "SUBMIT".

4. **Замкнуты ли сохранение и запись**
   - Нажато «SAVE» и успех подтверждён.
   - Получен итоговый `章节Id` (URL изменился на `/novels/chapter/edit/{书籍ID}/{章节ID}`).
   - Выполнена запись обратно в `WebNovel/分发记录.md`, причём `|` в `章节唯一键` надлежащим образом обработан по требованиям Markdown.

5. **Явно ли обозначен сбой**
   - Если вход не завершён, сохранение не удалось, `章节Id` не получен, запись не внесена: обязательно пометить как сбой / частичный успех и указать точку блокировки.
