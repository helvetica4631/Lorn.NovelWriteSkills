# 创建小说正文

## 题材技能路由（强制）

命中本 Prompt 时，必须先调用：`общий-создание-основного-текста`。

若任务涉及连续章承接、旧关系回温、旧债回收或下一章牵引，必须继续组合调用：`общий-управление-горячими-и-холодными-линиями` + `общий-генерация-контрольной-карточки-главы`。

Prompt 不得绕过题材 Skill 直接调用通用正文创作规则。

## 默认组合链路

- 写前控制：`общий-управление-горячими-и-холодными-линиями` + `общий-генерация-контрольной-карточки-главы`
- 正文施工：`общий-создание-основного-текста`
- 场景拆落：按需进入 `общий-исполнение-сценической-единицы`、`общий-исполнение-диалога-конфликта`、`общий-исполнение-сцены-в-ограниченном-пространстве`
- 局部增强：按需进入 `общий-усиление-начала-главы`、`общий-усиление-хука-конца-главы`
- 终稿提纯：按需进入 `общий-шлифовка-основного-текста` 与 `общий-устранение-духа-ии`

## 本 Prompt 只保留的职责

- 作为女频爱情章节正文创作的统一入口
- 保留默认正文目录、最小输入、最小写回约束与聊天侧最小回执
- 把主体规则路由到 `общий-создание-основного-текста` 及相关通用 Skill

## 最小输入

- `OUTLINE_FILE` 或明确的章节大纲材料
- `CHAPTER_FILE` 或可推断的目标章节路径
- 必要时补充人物、设定、伏笔、时间线等相关上下文

## 最低执行要求

- 开头尽快交付情绪钩子与身份锚点，不能慢热铺垫。
- 正文必须让成长线先成立，再让关系线跟上发力。
- 中段必须兑现一次情绪、关系、信息、身份或行动层面的实质回报。
- 章末必须留下明确追更驱动，不能平着收尾。
- 除非用户明确要求只讨论不落盘，否则必须直接写回目标 Markdown 文件。
