# Дополнение: шаблон индекса трёхуровневого плана (женская романтика)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон рекомендуется сначала просмотреть:

> - `CommonSkills/общий-проектирование-биографии-персонажей/references/сохранение-файлов-персонажей-и-трёхуровневый-индекс.md`

## 1. Поля дописывания индекса для женской романтики

- Метки смещения отношений: сближение / отдаление / разворот / разрыв / восстановление
- Метки эмоциональной награды: утешение / ответный удар / пробуждение / потеря / самодоказательство
- Метки стадии роста: обновление познания / перестройка границ / исполнение цены

## 2. Дополнительные пункты приёмки индекса

- [ ] Каждое ключевое событие должно возводиться хотя бы к одному из: «изменение отношений + изменение роста».
- [ ] Запрещено записывать лишь «появлялся», обязательно записывать «результат изменения».
