# Дополнение к жанровому шаблону технической рецензии (женская романтика)

Этот файл дописывает лишь **жанровый раздел рецензии настроек истории женской романтики**; при выполнении сначала используй «Шаблон отчёта о рецензии настроек» из `общий-рецензия-настроек-истории`, затем впиши содержимое этого файла в соответствующие разделы-заполнители.

## 1. Пояснение о разделении общего / жанрового

- Перенесено в общий слой: основной каркас цепочки чтения, общая рамка проверки базовой информации, общая структура карточек приземления письма, статьи правил, реальная осуществимость, разумность процедур, долгое нарастание, градация проблем, оценка, конкретные планы правки, идеи `9.2+`.
- Этот файл отвечает лишь за специфический для женской романтики критерий рецензии: швы городской реальности, путь обнаружения аномалии, риск загрязнения улик, институциональное / процедурное сопротивление, давление социальных проблем, жанровая оценка по специальным критериям и жанровый вывод.

### 3. Добавить в общий шаблон в `## 🎣 首次出场与前三章验证（强制）` (проверка первого появления и первых трёх глав, обязательно)

```markdown
- Приходится ли первое видимое отклонение в первой главе на знакомые городские маршруты: коридор / лифт / подземный гараж / дежурка / ресепшен / старый жилой комплекс и т. п.
- Есть ли уже во второй главе человек, которого из-за этого блокирует процесс, который вынужден гонять процедуры, которого неверно оценили или на которого надавили формулировкой
- Исполнена ли уже в третьей главе одна небольшая награда: микроаномалия подтверждена, записи «столкнулись лицом», процесс укусил в ответ, контрудар на дюйм или новое сопротивление нарастает
- Принёс ли дебют уже квитанцию, формулировку или телесный гвоздь, который можно заскринить, а не остановился на уровне объяснения
```

### 4. Добавить в общий шаблон в `## 🎯 人物—情境—观点合拍度` (согласованность «персонаж — ситуация — точка зрения»)

```markdown
- Соответствуют ли реакции героя / противника / наблюдателей вокруг него реальным мыслям, порождённым тревогой перед процессом, обществом знакомых, разницей ресурсов
- Похож ли сеттинг на «то, что действительно может случиться в этом городе», а не на механизм, парящий на абстрактном городском фоне
```

### 5. Добавить в общий шаблон в `## 🧩 写作落地卡片（作者向交付物｜强制｜P0）` (карточки приземления письма, выдача автору, обязательно, P0)

```markdown
- Рекомендуемые сценарии применения: коридор / подземный гараж / дежурка / ресепшен управляющей компании / старый жилой комплекс / больничная кладовая / старый причал / слепая зона лифтового мониторинга
- Рекомендуемые визуальные квитанции: запись об аномалии на проходной / каталог экспорта мониторинга / лист с подписью дежурного / заявка управляющей компании / квитанция о приёме вызова / акт опечатывания / номер медосмотра / скриншот группового объявления
- Примеры привычных формулировок противника:
  1) «Камера как раз сломалась, пока не выноси это наружу».
  2) «Это нужно пускать по процессу, сейчас исходные записи показать нельзя».
  3) «Просто совпадение, не раздувай эмоции жильцов».
- Примеры контрзацепок героя:
  1) Сопоставить записи экспорта с исходными метками времени
  2) Повторная проверка узлов движения заявки и цепочки подписей
  3) Перекрёстное сопоставление многоисточниковых носителей (мониторинг / проходная / управляющая компания / медосмотр / свидетели)
- Примеры отката и цены: права отобраны, слежка, навешен ярлык «сеет панику», разрыв отношений в обществе знакомых
- Примеры кнопок эскалации: удаление архива, смена формулировки, межведомственное перекладывание вины, подавление общественного мнения, упаковка аномалии в обычную аварию
```

### 12. Добавить в общий шаблон в `## ✅ 审阅结论` (вывод рецензии)

Заключительный абзац обязан дополнительно ответить:

- Сильнейшая узнаваемость женской романтики у этой настройки происходит от швов реальности, процедурного трения, пути обнаружения аномалии или давления социальных проблем.
- Самая большая точка кровопотери этого сеттинга — слишком воздушный, слишком учебный, слишком случайный или слишком мало городского жизненного ощущения.
- Если можно подправить только `3` места, какие `3` поправить в первую очередь, чтобы больше всего поднять достоверность, напряжение продолжения чтения и экранизируемость настройки в тексте женской романтики.
- В первых трёх главах в каком знакомом городском месте этот сеттинг лучше всего сначала приземлить, чтобы быстрее всего выдать микроаномалию и процедурную досаду.
