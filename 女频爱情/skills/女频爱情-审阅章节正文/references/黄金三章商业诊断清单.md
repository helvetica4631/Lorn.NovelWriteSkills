# Чек-лист коммерческой диагностики золотых трёх глав

> Источник: перекрёстный консенсус 8 оценок ИИ-начал (2026-06-11)
> Область применения: жанр женской романтики → коммерческие веб-платформы вроде Qimao / Fanqie / Qidian
> Использование: при рецензировании Ch1-3 проходить пункт за пунктом, дефектные пункты сразу вносить в список проблем P1

---

## I. Диагностика характера конфликта (высший приоритет)

Ключ к удержанию читателя веб-романа — не «сколько конфликтов», а «конфликт в настоящем или в прошедшем времени».

| Пункт диагностики | Критерий | Сигнал красного света |
| --- | --- | --- |
| **Настоящее vs прошедшее время** | Конфликт главы — это происходящее внешнее событие или воспоминание / внутреннее переваривание персонажа? | Более 50% конфликтов в Ch1-3 появляются в форме «воспоминаний-флешбэков» |
| **Видеть vs слышать** | Читатель «наблюдает» за происходящим конфликтом или «слушает», как персонаж вспоминает конфликт? | Все узлы причинения вреда исходят из воспоминаний персонажа, а не из текущей сцены |
| **Присутствие противодействующего персонажа** | В каждой главе появляется хотя бы 1 внешний персонаж с позицией, противоположной героине | В Ch1-3 две и более глав подряд только монолог героини / диалоги с союзниками |

**Классический красный свет**: основной вред в Ch1 (холодность в течение трёх лет брака) целиком подан в форме воспоминаний «в тот год у неё была температура… в ту годовщину…» — читатель «слышит», что ей причиняли боль, но не «наблюдает», как её ранят.

**Направление исправления**: сохранить хотя бы один ключевой узел причинения вреда в настоящем времени. Например, в момент подписания в Ch1 Гу Яньшэнь прямо принимает звонок от какой-то женщины и не стесняется присутствия Су Тан — читатель на месте «наблюдает» пренебрежение.

## II. Диагностика плотности противодействующих персонажей

| Пункт диагностики | Ch1 | Ch2 | Ch3 | Сигнал красного света |
| --- | --- | --- | --- | --- |
| Выход враждебных / противостоящих персонажей | | | | До конца Ch3 нет ни одного противодействующего персонажа |
| Действия этого человека | | | | Противодействующий персонаж лишь упоминается в чужих устах, но сам никогда не действует |
| Ответ героини | | | | Героиня на нападки совсем не отвечает — молчание не стратегия, а недостаток проработки |

**Минимальный стандарт**: до конца Ch3 должен появиться хотя бы один внешний персонаж, оказывающий на героиню давление / нападающий / угрожающий. Это может быть мачеха / сводная сестра / секретарша героя / юрист семьи Гу — но не «злодей из воспоминаний».

## III. Диагностика выдвижения точек 爽 вперёд и ожидания

| Пункт диагностики | Критерий | Сигнал красного света |
| --- | --- | --- |
| **Объект мести ясен** | Может ли читатель после Ch3 указать: «я жду, кого она поставит на место» | Объект «пощёчины» размыт — не ясно, пожалеет ли подлец, неясно, кто любовница |
| **Якорь точки 爽 по карьере / способностям** | Знает ли читатель, «за счёт чего» героиня способна победить | Профессиональные навыки героини появляются лишь ярлыком («она консультант по переговорам»), в тексте никогда не показано ощутимое измерение её способностей |
| **Ответ на ожидание продолжения чтения** | Сможет ли читатель к концу Ch3 ответить на три вопроса: ① что смотреть завтра? ② чего ждать? ③ чьего появления ждать? | Минимум на два из трёх вопросов ответ «не знаю» |

**Классический красный свет**: к концу Ch3 дальнейшее ожидание читателя звучит как «ей, одной пробивающейся, будет очень тяжело» — это логика реальной жизни, а не ожидание веб-романа. Вебу нужно: «как она поставит на место», «когда подлец пожалеет», «как вернуть тот актив».

## IV. Диагностика плотности сетки конфликтов персонажей

| Пункт диагностики | Сейчас | Ориентир S1 («Господин Фэн») | Разрыв |
| --- | --- | --- | --- |
| Противостоящие персонажи в Ch1 | | Мачеха / дочь / любовница / муж (4 человека) | |
| Общее число противостоящих персонажей к концу Ch3 | | ≥4 человек | |
| Число раскрываемых побочных линий к концу Ch5 | | Линия раскаяния подлеца / линия обратного удара дочери / линия пощёчины любовнице / линия карьерного взлёта / линия происхождения (5 линий) | |

**Красный свет**: к концу Ch5 раскрываемых побочных линий меньше 3 — значит, сетка конфликтов на уровне настройки слишком разрежена и не выдержит роман в 3 млн знаков.

## V. Быстрая диагностика адаптации к платформе

| Платформа | Ключевые показатели | Текущая степень адаптации с нашей стороны |
| --- | --- | --- |
| Fanqie / Qimao | Удержание в первых 3 главах, плотность эмоций, порог вживания | Самооценка |
| Jinjiang | Идея / образ персонажей / ритм, в первых трёх главах обязательна эскалация конфликта | Самооценка |
| Douban Read | Новизна образов персонажей, качество повествования, способность ломать шаблоны | Самооценка |
| Zhihu Yanxuan | Реалистичность от первого лица, быстрые короткие мощные повороты | Самооценка |

**Красный свет несоответствия**: целевая платформа — Qimao, а манера письма — медленно разгорающийся сдержанный стиль Douban / издательской линии — это «платформенное несоответствие», а не вопрос стиля.
