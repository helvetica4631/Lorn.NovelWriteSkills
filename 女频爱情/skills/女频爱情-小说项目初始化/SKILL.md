## Когда использовать

- После выбора платформы и до проектирования плана запускать инициализацию проекта женской романтики.
- Есть жанровая идея, но не уверены, «сработает ли комбинация шаблонов + CP-ощущение + платформа».
- Общий план уже дописан, но эмоциональное напряжение или CP-ощущение кажутся слабыми, нужно вернуться к решениям инициализации.

## Случаи, когда не применяется

- Чисто любительское, вольное письмо ради удовольствия.
- Короткая / средняя женская проза (при объёме в десяток тысяч знаков не нужна такая тяжёлая инициализация).
- Продолжение одного тома уже существующего женского произведения (следует использовать `女频爱情-设计分卷大纲`).

## Дополнение к инициализации женской романтики

### 1. Дополнения по адаптации под платформы

| Платформа | Ключевые моменты адаптации женской романтики |
| --- | --- |
| **Jinjiang Literature City** | Основной оплот женской романтики. Читатели — преимущественно женщины 18–30 лет, ключевое предпочтение — «эмоциональное напряжение + CP-ощущение». Принимает медленно разгорающуюся линию эмоционального роста, требует тонкой эмоциональной логики. Брак по расчёту с последующей любовью / разбитое зеркало срастается / тайная любовь, ставшая явью — самые любимые классические шаблоны читателей Jinjiang. |
| **Qidian** | Женский канал — преимущественно «сильная героиня» в любовной прозе. Героиня должна обладать самостоятельным характером и карьерной линией, настройка «двое сильных» популярнее. Эмоциональный ритм может быть несколько медленнее, чем на Jinjiang. |
| **Fanqie** | Подходит для быстрых, остро-эмоциональных женских произведений. Классические шаблоны вроде «брака по расчёту с последующей любовью», «погони за женой через крематорий», «малыша-милашки» работают отлично. В начале уже нужен эмоциональный конфликт или эмоциональный крючок. |
| **Qimao** | Высокая приемлемость для традиционного мобильного стиля женской прозы. Классические шаблоны «романа о президенте», «контрактного брака», «побега с беременностью» по-прежнему эффективны. Эмоции подавать прямо, конфликты — плотно. |
| **Zhihu Yanxuan** | Подходит для женского контента вроде «мучительной прозы», «эстетики BE», «эмоционального детектива». Сильные эмоции, сильное вживание, от первого лица работает превосходно. |

### 2. Полная матрица комбинаций шаблонов

Женская романтика — типичный жанр, управляемый отношениями: ключевая движущая сила — «изменение отношений двух людей»:

**Рекомендации для слоя запуска повествования**:
- Перерождение (заново любить с памятью, восполнить сожаления или отомстить с «пощёчиной»)
- Попадание в книгу (оказаться злой второстепенной героиней / пушечным мясом, переписать судьбу вопреки небесам)
- Свидание вслепую / вынужденный брак по расчёту (классическое начало, быстро формируется связка отношений)

**Рекомендации для слоя ключевого конфликта** (выбрать 1 основной шаблон):
| Основной шаблон | Ключевая эмоция | Платформенное предпочтение | Ключевые моменты адаптации |
| --- | --- | --- | --- |
| Брак по расчёту с последующей любовью | Сладкое перетягивание «контракт → внезапно по-настоящему» | Универсально для всех платформ | У причины контракта должна быть достаточная принудительная сила |
| Погоня за женой через крематорий | Эмоциональный разворот «мучения героини → погоня за женой → мучения героя» | Fanqie / Qimao / Zhihu | У мучений героини должна быть разумная мотивация, нельзя мучить ради мучений |
| Разбитое зеркало срастается | «Разлука → рост → встреча» с ощущением «вещи те же, люди иные» | Jinjiang / Qidian | Причина разлуки должна вызывать сочувствие читателя |
| Тайная любовь, ставшая явью | Эмоциональное «брожение» от односторонней к взаимной | Jinjiang | Тайная любовь должна быть подготовлена достаточными деталями |
| Литература о двойнике | Драматический контраст «двойник → обратный удар → правда» | Fanqie / Qimao | Ключевой момент — время раскрытия двойника |
| Двое сильных, подначивающих друг друга | Игра перетягивания между равными соперниками | Qidian / Jinjiang | У обоих должна быть самостоятельная карьерная линия и личное обаяние |

**Рекомендации для слоя устойчивого драйва**:
- Цикл «пощёчин» (второстепенная героиня / злая свекровь / «белая луна» постоянно подставляются под «пощёчины»)
- Развитие бизнеса и рост (двойное продвижение: карьерная линия героини + линия чувств)
- Малыш-милашка помогает (малыш как катализатор отношений)

**Слой эмоциональных зацепок** (обязателен для женского канала, определяет тон CP-ощущения):
- «Сладкий питомец» (раздача сладости), «мучительная любовь» (тип перетягивания), «исцеление» (тип спасения), «счастливые враги» (тип взаимных подколок)

**Антишаблонные новшества**:
- Смена пола в классическом шаблоне (женщина-президент + мужчина-парфюмер)
- Обновление мотивации в шаблоне (погоня за женой через крематорий без мучений героини, спасение без саморазрушения)
- Кросс-жанровое слияние (женская романтика + детектив / работа / сянься)

### 3. Элементы, требующие специализации на стадии инициализации

| Элемент | Значение в женской романтике | Пункт проверки инициализации |
| --- | --- | --- |
| **Модель образов CP** | Сочетание характеров героя и героини (холодный × живая / нежная × упрямая / хитрый × простодушная / двое сильных, подначивающих друг друга) | Достаточно ли у CP пространства для химии? |
| **Механизм связки отношений** | Почему двое «обязаны быть вместе» (контрактный брак / внезапная беременность / рабочая связка / семейный династический брак) | Достаточно ли принудительной силы механизма связки для долгой сюжетной линии? |
| **Кривая эмоционального напряжения** | Ритм от знакомства → сердцебиения → перетягивания → определения отношений | Соответствует ли длительность каждой стадии требованиям платформенного ритма? |
| **Соотношение мучений / сладости** | Сладость с примесью мучений или мучения с примесью сладости | Соответствует ли предпочтениям читателей целевой платформы? |
| **Источник эмоциональных помех** | Кто / что мешает двоим быть вместе (второстепенный герой / героиня / семья / классовая разница / недоразумение) | Достаточно ли у источника помех присутствия и разумности? |

### 4. Значение эмоциональной оси по умолчанию

Эмоциональная главная ось женской романтики имеет основным обещанием **эмоциональное вживание в близкие отношения**:

```
Встреча (формируется первое впечатление) → перетягивание (пробы / отказ / сердцебиение) → противоречие (недоразумение / третий / внешняя сила) → примирение (понимание / рост / сближение) → подтверждение (взаимность / сладость) → новое испытание
```

- Читатели Jinjiang: предпочитают постепенный, настоящий эмоциональный рост, тонкие психологические описания
- Читатели Fanqie / Qimao: предпочитают высокую сладость или сильные мучения с эмоциональным перетягиванием, выражение подавать прямо
- Ключевой принцип: **нельзя без внутреннего надрыва** — читателям нужны идеальные близкие отношения «пусть с неровностями, но в итоге навстречу друг другу»

### 5. Дополнения по красным линиям платформ

- Все платформы: терпимость женского контента к «снижению интеллекта» крайне низкая — героиня не может совершать глупостей, не соответствующих её образу
- Jinjiang: эмоциональная логика должна быть тонкой, нельзя «индустриального сахарина»; всё больше сомнений в разумности «мучений героини» в «погоне за женой через крематорий»
- Qimao / Fanqie: избегать слишком сложных многоугольных любовей, инструментализация второстепенных персонажей допустима, но интеллект главных не должен «отключаться»
- Все платформы: сюжеты с «принудительной любовью», «заточением» и т. п. требуют оправдания и смягчения
