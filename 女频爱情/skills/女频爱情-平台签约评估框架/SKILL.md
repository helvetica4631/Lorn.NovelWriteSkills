## Жанровые дополнительные границы

- По умолчанию приоритетно отвечать: может ли произведение за 30 секунд завершить жанровую классификацию, распознавание эмоциональной зацепки и распознавание ключевого положения героини.

- По умолчанию подчёркивать текущие предпочтения женской романтики: трезвость и независимость, настоящие слабости, дуга роста, мягкое удовлетворение (柔爽) и резонанс с реальностью.

## Усиленные критерии жанра женской романтики (2026)

- По умолчанию проверять по «линия роста > линия любви»: линия отношений должна служить росту, а не заменять его.
- По умолчанию дополнять жёсткой проверкой «золотых трёх глав»: первые `6000-9000` знаков должны образовать ощутимое замыкание, нельзя только нагромождать эмоции без действенной награды.
- Героиня по умолчанию должна обладать: трезвостью и независимостью, настоящими слабостями, видимой ценой, поэтапным ростом; при отсутствии любого пункта снижать потолок подписания.
- Допускается отсутствие CP / двое сильных / карьерная линия вперёд, но обязательно непрерывное обеспечение эмоциональной ценностью, потенциалом отношений между персонажами и драйвом продолжения чтения.
- По умолчанию строго проверять платформенные риски выражения: пошлость на грани, приукрашивание дисбаланса власти, детали романтики с несовершеннолетними, смещение ценностных ориентиров.
