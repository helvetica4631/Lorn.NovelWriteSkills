# Дополнительный шаблон контрольной карточки (женская романтика)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/通用-生成章节控制卡/references/章节控制卡模板.md`

## 1. Способ использования (обязательно)

1. Сначала по общему шаблону контрольной карточки заполнить полную главную карточку.
2. Затем дописать поля эмоций и отношений из этого файла.

## 2. Поля дописывания для женской романтики

- Эмоциональный крючок главы
- Смещение отношений главы (сближение / отдаление / разворот / восстановление)
- Цена роста главы (границы, выбор, последствия)

## 3. Дополнительные пункты приёмки

- [ ] Как минимум одна «эмоциональная награда + новый пробел», сосуществующие вместе.
- [ ] Нельзя лишь изливать лирику, не продвигая события.
