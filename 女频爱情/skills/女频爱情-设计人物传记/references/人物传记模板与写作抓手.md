# Дополнение: шаблон биографии персонажа и зацепки для письма (женская романтика)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/通用-设计人物传记/references/人物传记最小结构模板.md`

## 1. Поля дописывания для женской романтики

- Позиции функции в отношениях: эмоциональная опора, триггер конфликта, зеркало роста, ценностный контраст
- Позиция цены роста: установление границ, стоимость выбора, последствия для отношений
- Эмоциональные триггеры: смена обращения, исполнение обещания / его нарушение, повторное задевание старой раны

## 2. Дополнительные пункты писательских зацепок

- Речевой стиль персонажа должен отражать изменение дистанции отношений (один и тот же персонаж по-разному говорит с разными людьми)
- Контрдействия должны отражать двухслойное изменение «эмоции + действия», а не только психологический монолог
