# Список «усталых» слов женского жанра / любовной прозы

> Источник: заимствовано из языковых правил InkOS `romantasy.md` и исследования высокочастотных ИИ-слов
> Область применения: женская романтика, романтический жанр
> Способ использования: при создании активно избегать, при рецензировании сканировать превышения
> Норма контроля: не более 2 раз на тысячу знаков

## Усталые слова первого уровня (высокий приоритет, по возможности не использовать)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| 嘴角微勾/勾起一抹笑 (уголки губ слегка приподнялись / тень улыбки) | Самое частое ИИ-описание, уже не даёт картинки | Писать конкретное выражение (дрогнул уголок глаза / губы сжались в линию) |
| 眸色一沉/眼底一暗 (взгляд потемнел / в глубине глаз потемнело) | Универсальное описание взгляда, одно лицо на тысячу | Писать конкретную реакцию (отвёл взгляд / смотрел три секунды) |
| 心跳漏了一拍 (сердце пропустило удар) | Романтическая реакция, истёртая бесчисленными авторами | Писать конкретное телесное ощущение (дыхание застряло в горле / онемели кончики пальцев) |
| 一股暖流 (волна тепла) | Абстрактный эмоциональный ярлык | Писать конкретное телесное ощущение (согретая ладонь легла на затылок) |
| 冷冽的气息 (холодное, резкое дыхание) | Обязательный атрибут «президента», эстетическая усталость | Писать конкретный запах (запах лосьона после бритья / табак вперемешку с холодным ветром) |

## Усталые слова второго уровня (средний приоритет, контролировать частоту использования)

| Усталое слово | Пояснение | Направление замены |
| -------- | ------ | --------- |
| 宠溺 (баловать с нежностью) | Истёртый эмоциональный ярлык | Писать конкретное поведение (заменил её кофе на тёплый / встал перед ней) |
| 占有欲 (собственнические чувства) | Прямое объявление мотива | Писать конкретное действие (рука на спинке её стула / взгляд не отрывался) |
| 薄唇 (тонкие губы) | Шаблонное описание лица | Писать состояние или движение губ (сухие, потрескавшиеся / закусил нижнюю губу) |
| 修长的手指 (длинные пальцы) | Шаблонное описание рук | Писать конкретные движения рук (костяшки стучат по столу / медленно закатывает рукав) |
| 深邃的眼眸 (глубокие глаза) | Универсальное слово, уже без визуальной информации | Писать конкретный взгляд (его взгляд долго задержался на какой-то точке) |

## Усталые слова третьего уровня (вспомогательный, обрабатывать только при плотном появлении)

| Усталое слово | Пояснение |
| -------- | ------ |
| 莫名地 (необъяснимо) | Костыль при нечёткой подаче эмоции |
| 不自觉地 (невольно) | То же |
| 竟然 (оказывается / надо же) | Маркер чрезмерного удивления, не больше 2 раз на главу |
| 似乎/仿佛 (словно / будто) | Ослабляют определённость картинки |
| 某种说不清的 (какой-то неописуемый) | Оставить читателю почувствовать сильнее, чем объяснять |

## Формулы замены при показе эмоций

По четырём принципам показа эмоций InkOS:

- **Не объявлять эмоцию** → **вынести действием**
  - ✗ Он очень нервничает → ✓ Он закатал рукава рубашки и опустил
- **Не говорить прямо о сердцебиении** → **телесное выражение**
  - ✗ Сердце забилось чаще → ✓ Дыхание невольно стало тише
- **Не навешивать ярлык** → **проекция среды**
  - ✗ Атмосфера двусмысленная → ✓ Шум дождя за окном словно стал тише

## Принципы обработки усталых слов

1. **Слов первого уровня в основном тексте должно быть близко к нулю**.
2. **Слов второго уровня — не более 1 раза на тысячу знаков**.
3. **Не повторять обработку со списком высокочастотных ИИ-слов**: эта таблица дополняет `通用-去AI味重写/references/去AI味识别雷达.md`.
