# Таблица быстрого подбора типов пространства

| Пространство | Наиболее подходящий тип аномалии | Наиболее подходящие последствия |
| --- | --- | --- |
| Коридор | Звук, свет, смещение положения | Ошибочное суждение при слежке, перекрытие линии взгляда |
| Лифт | Ошибка объявления этажа, временной сдвиг, аномалия отражения | Клаустрофобия, ошибка пути |
| Дежурка | Аномалия записи, слепая зона мониторинга, смещение предметов | Вход улик, искажение записи |
| Подземный гараж | Эхо, управление светом, запах, сжатие дальности видимости | Ошибочное суждение при погоне, потеря направления |
| Съёмная квартира | Положение предметов, бытовые следы, конфликт запахов | Нарушение границ приватности |
| Больничный коридор | Запах дезинфекции, звук тележки, аномалия номеров | Недоверие к институтам, странности медкарты |
