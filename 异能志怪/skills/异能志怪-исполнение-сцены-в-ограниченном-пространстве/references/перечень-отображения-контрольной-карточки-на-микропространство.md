# Перечень соответствия «контрольная карточка → микропространство»

## I. Как вдавливать поля контрольной карточки в сцену микропространства

- **Опорная точка реальности** → бытовая функция пространства и текущее действие персонажа
- **Аномальный сигнал** → первая пропускаемая, но колющая глаз аномалия
- **Носитель улик** → то, что в этой сцене можно потрогать, увидеть, услышать, сверить
- **Награда в середине** → одно подтверждение, чуть-чуть контроля, одно новое открытие или одно исправление ошибочного суждения
- **Повышение цены** → действие не удалось, откат правил, ухудшение отношений, усугубление реальных хлопот
- **Крючок конца главы** → более близкая опасность, более дорогое суждение, более жёсткий новый вопрос

## II. Самые устойчивые пять шагов сцены микропространства

1. Вход через обычное действие
2. Появление микроаномалии
3. Верификация персонажем или ошибочное суждение
4. Продвижение улик / правил
5. Приземление последствий и завершение с крючком

## III. Сигналы негодности

- Есть только атмосфера, нет действий.
- Есть только аномалия, нет реальной функции.
- Есть только пугание, нет улик.
- Есть лишь испуг в конце главы, нет награды в середине.
