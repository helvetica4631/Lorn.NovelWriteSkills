# Чек-лист удаления ИИ-привкуса в городской мистике

- [ ] Информация не потеряна
- [ ] Фактические формулировки, имена, время, номера, поля улик не деформированы
- [ ] Швы реальности на месте и не превращены в пустую атмосферу
- [ ] Профессиональные действия по-прежнему видны, а не остался лишь доклад о результате
- [ ] Границы правил и цена не вымыты
- [ ] Абстрактные эмоции по возможности приземлены на действие / предмет / физиологическую реакцию
- [ ] Голоса персонажей в диалоге лучше различимы, не похожи на одного человека, говорящего под разными именами
- [ ] Награда в середине по-прежнему ясна
- [ ] Крючок конца главы по-прежнему конкретен и действен
- [ ] Двойная числовая дорожка по-прежнему состоятельна
- [ ] Авторские номера со стороны автора полностью удалены
- [ ] Ссылки уровня повествования вида «в предыдущих главах / в следующей главе / в главе X» обнулены
- [ ] Выполнен хотя бы один раунд проверки содержания + один раунд проверки стиля + один раунд проверки деталей
- [ ] Нет побочного эффекта «стало глаже, но стало пустее»
