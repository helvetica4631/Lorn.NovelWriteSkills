# Описание подключения читательских продуктов

## I. Читательские заметки

- В настоящее время по умолчанию по-прежнему создаются на шаге 10 `общий-цикл-создания-главы`.
- Этот жанровый слой не выделяет отдельный «Skill читательских заметок», чтобы не вести параллельную поддержку.

## II. Рецензия на главу

- По умолчанию передаётся `异能志怪-написание-рецензии-на-книгу`.
- Если объект — одна глава / один том, в первую очередь пишите рекомендацию без спойлеров: «зачем после этой главы / этого тома хочется продолжать читать».

## III. Слово автора

- По умолчанию передаётся `异能志怪-шлифовка-слова-автора`.
- Отвечает за послевкусие после главы и лёгкое взаимодействие, но не за объяснение процесса создания.

## IV. Минимальный замкнутый контур читательских продуктов

- После прохождения текстом порога как минимум нужно добавить: читательские заметки + рецензию на главу.
- Если файл главы содержит `## 作者有话说`, это тоже нужно включить в тот же круг цикла, а не откладывать «на потом, когда будет время».
