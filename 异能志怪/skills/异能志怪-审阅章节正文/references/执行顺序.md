
## Порядок выполнения

1. Сначала пройтись по общим красным линиям существующего рецензионного Prompt.
2. Затем повторно проверить по специальным пунктам исполнительного слоя городской магии и сверхспособностей этого Skill.
3. При выводе в первую очередь давать: серьёзные проблемы, обычные проблемы, рекомендации по патчам, пригодные для обратной записи.
4. Если явно не работает любое из: начало главы, середина, награда в середине, крючок — прямо признавать, что нужна переделка.
5. Если нужны более тонкие оценки, градация и действия по переделке, продолжить чтение «шкалы оценки исполнительного слоя», «таблицы градации проблем» и «таблицы типичных производственных травм и действий-патчей».
6. При выводе обязательно мимоходом указать, куда возвращать на доработку: шлифовка / удаление ИИ-привкуса / переписывание основного текста / возврат к контрольной карточке.
7. При записи в базу сначала подтвердить каталог части / тома, затем записывать отчёт о рецензии главы по соответствующему вложенному пути.
