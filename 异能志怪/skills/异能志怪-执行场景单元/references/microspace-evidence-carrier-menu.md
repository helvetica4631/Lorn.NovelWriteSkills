# Меню носителей улик микропространства

## 1. Цель использования

Чтобы сцена микропространства не останавливалась на атмосфере, необходимо оставить носитель, который можно разобрать впоследствии.

Носитель — это не пустая фраза «есть улики», а конкретная вещь, которую читатель может увидеть, персонаж — потрогать, а дальше по тексту — перепроверить.

## II. Приоритетные типы носителей

### 1. Класс системных записей

Подходит: дежурка / лифт / больница / офисное здание / системы сообщества

Типичные носители:

- Записи системы контроля доступа
- Журнал работы лифта
- Метка времени мониторинга
- Журнал регистрации дежурного
- Печатная квитанция
- График смен
- Номер страницы медкарты / запись вызова очереди

Плюсы:

- Легко образует «разницу формулировок»
- Легко двигает последующее расследование
- Несёт ощущение институционального давления

### 2. Класс положения предметов

Подходит: съёмная квартира / зона хлама в коридоре / задняя зона офиса / подземный гараж

Типичные носители:

- Сдвинутые туфли
- Мусорное ведро, смещённое на одну клетку
- Камера мониторинга, повёрнутая под другим углом
- Лишний / недостающий бумажный стаканчик
- Ключ / карточка / шнурок, оставленные не на месте

Плюсы:

- Зрительно прямолинейно
- Очень подходит для первой аномалии
- Легко связывается с действиями персонажа

### 3. Класс запахов / пятен

Подходит: больничный коридор / подземный гараж / дежурка / лифт / съёмная квартира

Типичные носители:

- Сырой рыбный запах в смеси с дезинфекцией
- Липкая влажность на дверной ручке
- Свежий серый след, протёртый на углу стены
- Грязь / пепел бумаги / следы воды, которых там быть не должно

Плюсы:

- Быстро создаёт остранение
- Можно накладывать вместе с осязанием и светом

Внимание:

- Нельзя писать лишь «был запах», он должен соответствовать последующему суждению

### 4. Класс электронных интерфейсов

Подходит: все полузакрытые сцены современных городских пространств

Типичные носители:

- Подсказки групповых сообщений
- Журнал звонков
- Скриншоты
- Всплывающие окна
- Страницы приложений доставки / такси / управляющей компании
- Записи платежей / время счёта

Плюсы:

- Сильное ощущение реальности
- Легко связывается с немедленными действиями персонажа
- Легко образует временной сдвиг

### 5. Класс формулировок свидетелей

Подходит: дежурка / больница / сообщество / будка охраны / задняя зона ресепшена

Типичные носители:

- Слова дежурного
- Формулировка медсестры
- Пересказ соседа
- Повтор охранника

Плюсы:

- Легко создавать ошибочные суждения
- Легко образует конфликт с системными записями

Внимание:

- Сама формулировка — не конечная точка улики, лучше привязать её к другому носителю

## III. Три вещи, которые необходимо прояснить при приземлении

Когда каждый носитель улик входит в сцену, необходимо как минимум прояснить:

1. **Кто первым с ним соприкоснулся**
2. **Каким способом произошло соприкосновение**
3. **Что оно оставило такого, что можно проверить впоследствии**

Пример:

- Запись проходной: первым увидел охранник; соприкосновение через печатную квитанцию; оставила метку времени и номер прохода по карте
- Сдвинутые туфли: первым увидел герой, придя домой; подтвердил, нагнувшись и выровняв; оставила разницу между «привычным прежним положением» и «новым положением»

## IV. Рекомендуемые носители для разных пространств

| Пространство | Носитель первого приоритета | Носитель второго приоритета |
| --- | --- | --- |
| Коридор | Управление светом / проходная | Положение предметов |
| Лифт | Запись объявления этажей / время мониторинга | Отражение / отпечатки / запах |
| Дежурка | Журнал регистрации / запись мониторинга | Бумажный стаканчик / пепел / положение ключей |
| Подземный гараж | Управление светом / состояние парковочного места | Запах / грязь / источник эха |
| Съёмная квартира | Бытовые следы / смещение предметов | Электронные счета / записи чатов |
| Больничный коридор | Медкарта / запись вызова / номер койки | Звук тележки / запах дезинфекции / формулировка медсестры |

## V. Частые эффективные сочетания

### 1. Запись + разница формулировок

Лучше всего подходит для «кто-то лжёт / что-то было изменено».

### 2. Смещение предмета + память персонажа

Лучше всего подходит для «лишь герой осознаёт, что не так».

### 3. Запах / пятно + «система в норме»

Лучше всего подходит для «система говорит, что проблем нет, но на месте что-то не так».

### 4. Электронный интерфейс + неудачное действие на месте

Лучше всего подходит для временного сдвига и эскалации ошибочного суждения.

## 6. Красные линии

- Не писать лишь «оставил зацепку», носитель нужно написать достоверно
- Не допускать, чтобы носитель служил лишь атмосфере на месте, а позже его нельзя было вернуть в сюжет
- Не нагромождать за раз слишком много носителей, в первую очередь 1 основной носитель + 1 вспомогательный
- Не втискивать носитель, оторванный от функции пространства

## VII. Критерий приёмки

Квалифицированный носитель улик микропространства должен:

- Разумно существовать в этом пространстве
- Быть тем, с чем персонаж может естественно соприкоснуться
- Быть запоминаемым читателем
- Позволять впоследствии продолжать суждения, пересмотр дел или эскалацию
