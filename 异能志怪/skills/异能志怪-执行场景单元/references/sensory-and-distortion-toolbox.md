# Инструментарий ощущений и деталей остранения

## I. Пять классов приоритетных триггеров

### 1. Звук

- Сигнал проходной запаздывает на полтакта
- Объявление этажей в лифте не совпадает с реальным этажом
- С конца коридора доносятся повторяющиеся шаги, которых быть не должно

### 2. Свет

- Свет загорелся со смещением по ступеням
- Положение блика неверное
- Локально слишком ярко / слишком темно, а проблемы с источником света не найти

### 3. Запах

- В запахе дезинфекции примешан сырой рыбный запах
- В лифте появился запах уличной грязи
- В дежурке беспричинный запах бумажного пепла

### 4. Осязание

- Дверная ручка аномально холодная / липкая
- Сырость на перилах лестницы неуместна
- На ощупь штукатурка / металлическая поверхность противоречат обстановке на месте

### 5. Смещение положения

- Предмет чуть сдвинут
- Угол камеры мониторинга слегка смещён
- Дверь, которая должна быть заперта, приоткрыта на щель

## II. Принципы использования

- В одной сцене в первую очередь задействовать только 1–2 класса триггеров
- Триггер должен вызывать действие персонажа
- Триггер лучше, чтобы оставлял носитель, пригодный для последующего разбора
