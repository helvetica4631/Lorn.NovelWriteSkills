# Таблица маршрутизации расширенных справочников (совместимая оболочка)

> Общая расширенная маршрутизация из этого файла перенесена в `общий-шлифовка-основного-текста/references/正文润色扩展参考路由.md`.

## Как использовать теперь

- При попадании в общие слабые места — язык / действие / психика / портрет / пейзаж / статика / сцена и т. п. — единообразно сначала прочитать:
  - `通用-正文润色`
  - `通用-正文润色/references/正文润色扩展参考路由.md`
- Затем общий слой по необходимости продолжает чтение соответствующих 7 общих справочников по приёмам.

## Цель сохранения этого файла

- Служит лишь для совместимости с историческими ссылками старого жанрового Skill.
- Больше не является источником независимой маршрутизации жанрового слоя городской магии и сверхспособностей.

## Что жанровый слой по-прежнему обязан делать

- Определять, не задевают ли общие способы исправления швы реальности, профессиональные действия, границы правил и ритм Qidian «Ночных стражей среди людей» (《守夜人间》).
- Если общие приёмы конфликтуют с жанровым суждением, приоритет у жанрового суждения.
