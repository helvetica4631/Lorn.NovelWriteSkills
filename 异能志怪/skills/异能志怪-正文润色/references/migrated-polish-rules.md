# Правила достоверности шлифовки основного текста (совместимая оболочка)

> Общие правила достоверности из этого файла подняты в `общий-шлифовка-основного-текста`.

## Как читать теперь

При попадании в старую цепочку шлифовки основного текста городской магии и сверхспособностей прямо читать следующие общие файлы:

- `通用-正文润色`
- `通用-正文润色/references/正文润色保真迁移规则.md`
- `通用-正文润色/references/正文润色总裁判与默认交付.md`
- `通用-正文润色/references/正文润色数值双轨禁忌与沉浸控制.md`

## Цель сохранения этого файла

- Служит лишь для совместимости со старыми названиями жанровых references.
- Больше не является источником общих правил достоверности, независимо сопровождаемым жанровым слоем.

## Что жанровый слой по-прежнему обязан дополнительно судить

- Не задевают ли общие способы исправления достоверности швы реальности, границы правил и интонацию городских аномальных техник жанра городской магии и сверхспособностей.
- Если исправления общего слоя конфликтуют с жанровым суждением, приоритет у жанрового суждения.
