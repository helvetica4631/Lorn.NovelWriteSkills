# Дополнительный шаблон контрольной карточки (городская магия и сверхспособности)

> Этот файл — жанровый шаблон-дополнение. Главный шаблон находится в:
>
> - `CommonSkills/通用-生成章节控制卡/references/章节控制卡模板.md`

## 1. Способ использования (обязательно)

1. Сначала по общему шаблону контрольной карточки заполнить полную главную карточку.
2. Затем дописать специальные поля городской магии и сверхспособностей из этого файла.

## 2. Поля дописывания для городской магии и сверхспособностей

- Опорная точка реальности (профессия / сцена / институты)
- Аномальный сигнал (триггер правил)
- Носитель улик (поддающийся аудиту)
- Верификация правил / ошибочное суждение

## 3. Дополнительные пункты приёмки

- [ ] Если «границы правил / цена» не удаётся ясно написать, эту главу не допускать к написанию.
- [ ] В середине хотя бы один раз «проявление правил + изменение ситуации».
