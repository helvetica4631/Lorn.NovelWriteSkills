- Общий план должен ясно передавать `异能志怪-设计分卷大纲`: что принимает каждый том, чем каждый том питает, какой новый разрыв оставляет в конце каждого тома.
- Общий план должен резервировать информацию, которую можно спустить в `异能志怪-生成章节控制卡`: якорь реальности, сигнал аномалии, носитель доказательства, цепочку цены, тип награды.
- Если общий план не может ответить на вопрос «как цель уровня тома разбивается на цепочку продолжения чтения из 3–5 глав», значит, он ещё по-настоящему не замкнут.

## Жанровые дополнительные границы

- В жанре «Городская магия и сверхспособности» уровень общего плана помимо каркаса `M0 / X / C` должен продолжать ставить вперёд: обещание читателю, якорь реальности, якорь цены, инновационную комбинацию, главную линию платформы.
- Нельзя писать общий план как простое описание «фольклор / правила / сеттинг»; сверхъестественные механизмы должны вырастать вместе с профессией, городом, трещинами институтов, давлением быта.
- Непрерывное питание середины не может держаться лишь на росте числа аномалий; ему нужны переписывание познания, раскол отношений, проявление правил и эскалация цены.
- Финальное замыкание не просто объясняет механизм, но и объясняет, почему персонажи, институты, старые долги и трещины города могли дойти лишь до этого.

## Определение общего плана (обязательная норма)

Под «общим планом / общей схемой книги / планом стратегического уровня» в этом Skill **по умолчанию понимается не один файл**, а **пакет общего плана**, совместно составленный из нескольких файлов стратегического уровня.

### Минимальный состав (по умолчанию обязательно)

- `小说大纲/小说总大纲.md`: общий вход и стратегическая общая картина всей книги.
- `小说大纲/故事面/`: отдельные файлы с текстом `M0` и каждой грани `X01-XNN`.
- `小说大纲/伏笔与呼应总纲.md`: пульт управления зацепками, перекличками, интригами и возвратами T/P/V/S и т. п.

### Часто связанные файлы (обычно считаются частью уровня общего плана)

- `小说大纲/故事多面体大纲.md`
- `小说大纲/分卷故事面推进表.md`
- `小说大纲/时间轴（总）.md`
- `小说大纲/线索台账.md`
- `小说大纲/嫌疑池台账.md`
- Прочие файлы общего плана, непосредственно служащие стратегическому уровню всей книги, межтомному продвижению, возврату зацепок и координации цепочки доказательств

### Толкование при исполнении

- Когда пользователь говорит «поправь общий план / сделай общий план / перепиши общий план всей книги», **по умолчанию понимается изменение согласованной связи всего этого набора файлов**, а не только одного входного файла `小说总大纲.md`.
- Если пользователь назвал лишь один из этих файлов, всё равно нужно обращаться с ним как с **одним из компонентов пакета общего плана** и проверить его согласованность с `故事面/`, `伏笔与呼应总纲.md` и другими связанными файлами общего плана.
- `小说大纲/小说总大纲.md` — общий вход общего плана, **но не весь общий план**; `故事面/` и `伏笔与呼应总纲.md` тоже входят в определение общего плана.

## Основная задача общего плана

Общий план — не рекламный текст, а исполнительный чертёж автора. Он должен одновременно:

- **Быть исполнимым**: автор может прямо по нему разбить на тома, главы, сцены.
- **Быть проверяемым**: допускает перекрёстную сверку с биографиями персонажей, временной осью, журналом улик, журналом пула подозреваемых.
- **Допускать обратную запись**: после инкрементальных правок в ходе сериализации не выходит из-под контроля.
- **Быть затягивающим**: ясно задаёт длинную цепочку читательских наград «обещание → выплата → новый разрыв / новая цена».

## Специальные требования к сдаваемому для общего плана

## Усиленная исследованиями рамка (новые требования к исполнению на основе `写作研究/`)

Соблюдая файл правил ссылок, при создании общего плана необходимо дополнительно усвоить следующие межплатформенные выводы исследований; эти требования — **новый усиливающий слой**, они не заменяют имеющихся правил общего плана.

### 1. Калибровка стиля общего плана по умолчанию

- По умолчанию основная ориентация — **длинная сериализация Qidian**: подчёркивать долгосрочное обещание, непрерывное повышение, награды уровня тома.
- Одновременно усваивать фактуру реальности **Yanxuan / Douban**: персонажи должны быть как реальные люди, а не чисто функциональные роли.
- Частично заимствовать плотность крючков **Fanqie / подписных аккаунтов**: уровень общего плана тоже должен заранее планировать зацепки раннего читателя, а не просто выставлять стратегическую витрину.

### 2. Четыре читательских вопроса, на которые общий план обязан ответить в первую очередь

Перед выводом любой громоздкой структуры сначала кратким языком ясно сформулируйте:

1. **В чём новизна этой книги с первого взгляда?**
2. **Почему главный герой обязательно должен войти в эту игру?**
3. **Почему основной загадки хватает на долгий роман?**
4. **Если читатель дочитает до середины и конца, какова самая большая непрерывная награда?**

Если на любой из этих четырёх вопросов ответ расплывчат, общий план считается не откалиброванным.

### 3. Новое требование общего плана: «якорь реальности + якорь цены»

- По каждой основной и побочной линии нужно прописать как минимум один **якорь реальности**: любое из — профессиональный процесс, институциональное трение, региональное пространство, экономическое давление, семейные отношения, общественное мнение.
- По каждой основной и побочной линии нужно прописать как минимум один **якорь цены**: явная потеря в телесной, репутационной, отношенческой, профессиональной, юридической или психологической сфере.
- Если у линии есть лишь загадка и нет якоря реальности, она будет казаться парящей; если есть лишь продвижение и нет якоря цены, она будет казаться дешёвой.

### 4. В общий план необходимо добавить два исследовательских артефакта

Помимо прежних сдаваемых элементов, если пользователь явно не отказался, в общий план следует добавить следующие два подраздела:

#### A. Таблица обещаний продолжения чтения

4–8 пунктов-буллетов должны описывать, что эта книга будет непрерывно поставлять; рекомендуется записывать так:

- `содержание обещания → узел первой выплаты → способ повышения / новый разрыв`

Содержание обещаний должно охватывать как минимум:
- Продвижение истины главной линии
- Рост способности / метода главного героя
- Изменение отношений или раскол команды
- Проявление правил мира

#### B. Описание инновационной комбинации

Ясно указать, что эта книга — не «перелицовка такого-то шаблона», а пересечение каких элементов:

- Профессиональный разрез
- Общественная тема
- Фольклорные / региональные символы
- Сверхъестественные правила
- Механизм детектива

Как минимум ясно описать, **как 2–4 из них сцеплены друг с другом**, избегая лишь нагромождения понятий.

### 5. Девять вопросов аудита общего плана (самопроверка перед выводом)

1. Способна ли основная загадка `M0` одной фразой вызвать желание расспрашивать дальше?
2. Являются ли `X01-XNN` не бегущими рядом, а действительно поставляющими разные типы повествовательных наград?
3. Все ли единицы-дела складывают пазл основной линии, а не повторяют фарм подземелья?
4. Сопровождается ли каждое продвижение героя более высокой ценой, а не бесплатным получением ответов?
5. Запланирован ли хотя бы один крупный переворот уровня «переписывания познания» в середине?
6. Приземлены ли темы реальности через положение персонажей и механизмы дел, а не через тематические лозунги?
7. Действительно ли фольклор / правила входят в цепочку доказательств и цепочку конфликтов, а не являются украшением атмосферы?
8. Объясняет ли финальное замыкание не только «что произошло», но и «почему закончиться могло только так»?
9. Если убрать сверхъестественные элементы, сохранит ли эта история напряжение реального саспенса? Если совсем нет, значит, реальный скелет слишком слаб.

### 1. Сначала построить общую картину, потом писать детали

В общем плане должны быть ясно прописаны как минимум следующие 8 пунктов:

1. Продающая точка в одну фразу / точка дифференциации.
2. Основная загадка `M0`: загадка, истина, цена.
3. Важные побочные линии `X01-XNN`: самостоятельная повествовательная ценность каждой линии.
4. Матрица единиц-дел `C01-CNN`: какой кусок пазла основной линии питает каждое дело.
5. Соотношение основной и побочных линий: по умолчанию планировать **7:3**, если пользователь не требует иного.
6. Ритм многотомного продвижения: как минимум пояснить обязанности каждого тома — разгон / развитие / поворот / развязка.
7. Финальное замыкание: замыкание мотивов, замыкание доказательств, замыкание временной линии.
8. Эластичные узлы: места, допускающие расширение, и жёсткие ограничения, которые нельзя поколебать.

### 2. Явно задать четыре уровня грануляции

Общий план должен явно описать четыре уровня грануляции, чтобы последующие части / тома не потеряли фокус:

- **Общий план**: норма информационного резюме на 500–2000 знаков, отвечает за стратегические решения для всей книги.
- **План тома**: цель уровня тома, конфликт уровня тома, способ развязки уровня тома.
- **План главы**: по 200–500 знаков на главу, ясно прописывает сбор доказательств / противостояние / цену / крючок.
- **Детальный план**: сценические узлы внутри главы, спускающиеся до кадров, действий, диалогов и доказательств.

### 3. Структура сверхдлинного романа по умолчанию

Если пользователь не указал иного, по умолчанию использовать трёхактную структуру сверхдлинного романа:

- **Акт первый (около 400 тыс. знаков)**: появление главного героя, первое знакомство с правилами, вход в основную линию.
- **Акт второй (около 1,2 млн знаков)**: единицы-дела непрерывно питают основную линию, многократные перевороты и эскалация цены.
- **Акт третий (около 400 тыс. знаков)**: сосредоточенный возврат улик, финальное сведение счётов, приземление отголосков.

Дополнительно добавить два межмасштабных ритма:

- Примерно каждые **30 тыс. знаков** — один эмоциональный взрыв для читателя.
- Примерно каждые **100 тыс. знаков** — один поворот уровня направления сюжета.

### 4. Пирамида эскалации конфликта

В общем плане должны быть прописаны правила эскалации конфликта:

- В каждой главе как минимум 1 небольшой бытовой конфликт.
- Каждые 3 главы как минимум 1 крупный конфликт уровня главы.
- Каждые 10–15 глав как минимум 1 крупный конфликт уровня тома.

### 5. Трёхуровневая система цепочки интриг

Для каждой ключевой интриги нужно отметить как минимум: **главу постановки / узел усиления / главу возврата / отголосок после возврата**.

По умолчанию планируется в три уровня:

- **Интрига входа в игру**: чтобы читатель сразу продолжил.
- **Интрига продвижения**: поддерживает структуру середины.
- **Интрига мира / старого дела**: переписывает познание читателя.

## Как писать стратегические грани истории (ядро общего плана)

### Определение

«Грань истории» в общем плане — это межтомная стратегическая повествовательная единица, подразделяемая на:

- **Грань загадки основной линии**: `M0` (единственная на всю книгу)
- **Важные грани побочных линий**: `X01`, `X02`……

### Обязательные требования к конкретизации

Каждая грань истории должна быть целостной историей, а не абстрактной темой. Необходимо ясно прописать:

- **Краткое содержание истории**: 500–800 знаков, ясно излагает ключевые события и промежуточные финалы.
- **WHO**: конкретные имена, идентичности, мотивы.
- **WHAT**: цепочка ключевых событий, основные конфликты, влияние результата.
- **WHEN**: время начала, ключевые узлы, длительность.
- **WHERE**: основные сцены, изменение пространства, влияние пространства.
- **WHY**: мотивы персонажей, исторический фон, движимость интересами.
- **HOW**: средства реализации, изменение стратегий, технический или институциональный путь.

### Запрещённая манера письма

Следующее не может считаться гранью истории:

- Только суждение о теме, без цепочки событий.
- Только слова-понятия, без персонажей, места и времени.
- Написаны лишь абстрактные ярлыки вроде «возобновление старого дела / истина всплывает / опасность растёт».

### Рекомендуемая манера письма

Для описания грани истории в первую очередь использовать тройное предложение «действие → носитель доказательства → проверяемое последствие / цена».

## Что общий план обязан дополнительно разъяснить

### 1. Правила разбиения граней истории на части / тома

Общий план обязан сообщить последующим частям / томам, как их принимать:

- На какие этапы будет в будущем разложена каждая стратегическая грань истории.
- На какие группы томов / единицы-дела, как ожидается, ляжет каждый этап.
- Какую информацию можно отложить, какие кусочки пазла необходимо заложить заранее.

### 2. Стратегия питания матрицы единиц-дел

По каждому `Cxx` нужно разъяснить как минимум:

- Какой кусок пазла основной линии вносит это дело.
- Какой тип носителя доказательства оно поставляет.
- Какой пул подозреваемых оно расширяет или сужает.
- Какую эскалацию отношений / цены оно вызывает.

### 3. Контроль гибкости длинного романа

В общем плане обязательно отдельно выделить раздел «Эластичные узлы и нерешённые пункты», включающий:

- Персонажей, чьи сцены можно добавлять и убирать.
- Карты / сцены, куда можно вставить новые единицы-дела.
- Изменяемые повороты сюжета, не меняющие предпосылку финальной истины.
- Явно прописать: основную истину, ключевые цепочки доказательств, поворотные точки основной судьбы нельзя трогать произвольно.

При следующих обстоятельствах общий план по-прежнему не соответствует стандарту:

- Написан как тематическое эссе или справочник по сеттингу.
- Есть лишь сеттинг без цепочки событий.
- Есть лишь список единиц-дел, без логики питания основной линии.
- Есть лишь структура «большая и полная», без явной цены и пути доказательства.
