# Правила жанров «культивация / фэнтези» InkOS (материал для усвоения)

> Источник: [Narcooo/inkos/packages/core/genres/xuanhuan.md](https://github.com/Narcooo/inkos/blob/master/packages/core/genres/xuanhuan.md) + [xianxia.md](https://github.com/Narcooo/inkos/blob/master/packages/core/genres/xianxia.md)
> Встроенные в InkOS файлы правил жанров «фэнтези» и «сянься», применимые к проектированию и созданию в жанрах «Городская магия и сверхспособности», «культивация / фэнтези» и т. п.
>
> Достаточность доказательств: достаточная — правила «фэнтези» / «сянься» InkOS являются кодифицированными правилами, проверенными проектной практикой
> Достоверность: высокая — правила конкретны и исполнимы, прямо соответствуют рамке позиционирования жанра «Городская магия и сверхспособности» этого репозитория
> Принадлежность к платформе: критерии по умолчанию (Qidian / платформа не указана)

## Жанровые табу (общие)

- Главный герой ради продвижения сюжета вдруг становится милосердным, глупым, соблюдает кодекс воинской чести
- Однородные ресурсы засчитываются в полном объёме без затухания
- Пропуск расчёта числовых значений словами «резко вырос», «огромное количество»
- Пробуждение способности без подготовки
- Злодеи, как деревянные колышки, выстраиваются в очередь на смерть
- Без подготовки насильно возвращать ушедшего персонажа
- Без подготовки внезапно вставлять новую систему, новую карту, нового «читера» для решения проблемы
- Писать все главы как главы высокоскоростных боёв
- Подмешивание в стиль городской интонации, научно-фантастической интонации, интонации системных оповещений игры, юмористической интонации лайт-новелл

### Специальные табу «сянься»

- Прорывы в уровне культивации скачками без подготовки
- Магический артефакт появляется из воздуха и решает кризис
- Противоречия в правилах Небесного Дао
- Пропуск конкретного процесса культивации словами «Великое Дао бесформенно», «отклик Небесного Дао»
- Однородные ресурсы засчитываются в полном объёме без затухания

## Числовые правила (специфично для «фэнтези»)

- **Настройки нельзя «съедать»**: числа настроек, установленные ранее, нельзя произвольно менять потом без процесса повышения
- **Четыре измерения ограничений «золотого пальца»**:
  - **Потолок способности**: необходимо задать чёткий потолок способностей, нельзя бесконечно повышать
  - **Сопутствующая цена**: использование сопровождается ценой (продолжительность жизни, силы, побочные эффекты), взвешивание плюсов и минусов усиливает конфликт
  - **Условия запуска**: активация связана с конкретными сценами / событиями, нельзя использовать везде и всегда без условий
  - **Путь роста**: растёт синхронно с опытом главного героя, процесс разблокировки привязан к узлам сюжета
- **При повторном поглощении однородных ресурсов необходимо прописать затухание**, нельзя засчитывать по умолчанию в полном объёме
  - Формула затухания: выгода = базовое значение × max(0,3, 1 − 0,15×(N−1))
- Не пропускать расчёт числовых значений словами «резко вырос», «огромное количество», «трудно оценить»
- Начальное значение брать из бухгалтерской книги (не по памяти), приросты перечислять по одному с указанием источника
- Расходы перечислять по одному с указанием назначения, итог = начало + прирост − расход, пропуск шагов недопустим
- Системные подсказки в тексте (например, [Здоровье +X]) обязаны совпадать с книгой
- Если в тексте написано сравнение вроде «выше, чем у A», его необходимо подтвердить числами, прежде чем оставлять
- Непрерывность чисел должна быть прослеживаемой: приросты образцов того же уровня и типа не должны без пояснения перескакивать порядок величины

## Правила культивации (специфично для «сянься»)

- Прорыв уровня должен иметь процесс накопления: постижение Дао, пилюли, озарение в бою, шанс-судьба
- Повторная переплавка однородных ресурсов обязана прописывать затухание
- Система магических артефактов делится на ранги, использование имеет цену (духовная сила, срок жизни, карма)
- **Четыре измерения ограничений «золотого пальца» / методики**:
  - Потолок способности: есть чёткий потолок уровня / ранга
  - Сопутствующая цена: культивация / использование сопровождается ценой (срок жизни, карма, сердечный демон)
  - Условия запуска: прорыв / пробуждение требует особых условий (постижение Дао, шанс-судьба, небесная кара)
  - Путь роста: методика повышается вместе с уровнем культивации, перескакивать ранги нельзя
- Правила Небесного Дао, раз установленные, нарушать нельзя, если нет явного особого механизма
- Начальный уровень культивации / ресурсы брать из книги, приросты перечислять по одному
- Прорыв через большой уровень требует небесной кары или особых условий

## Железные языковые правила

- **Масштаб системы силы передавать телесными ощущениями, а не абстрактными числами**. ✗ «Его огненных нитей стало 24 вместо 12» → ✓ «Руки стали сильнее прежнего, при сжатии кулака напряглись костяшки»
- **В одном кульминационном эпизоде** (например, поглощение огня / прорыв / пробуждение) отображение одной и той же образной области не более двух раундов, третий раунд обязан вводить новую информацию или новое действие
- **В эпизодах обыска трупов / подсчёта / экипировки запрещены списочные перечисления**, необходимо вносить суждение или выбор персонажа: ✗ «Он достал грубую соль, бурдюк, чёрную лепёшку» → ✓ «Бурдюк ценнее всего, а оставшаяся в нём вода весит не легче жизни»

## Руководство по повествованию

### Нарратив «фэнтези»

- Сюжет движут бои и добыча ресурсов
- Поведение главного героя движимо выгодой, он решителен в убийствах
- У «золотого пальца» / системы способностей обязательны ограничения: частота использования, ограничение дальности или цена использования
- Настройки нельзя «съедать»
- **В течение трёх глав должна быть явная обратная связь**, но обратной связью могут быть удар по лицу, выплата выгоды, информационный переворот, смена статуса — не обязательно убийство
- При поглощении выгода должна одновременно ложиться и в пояснение ресурса, и в конкретный прирост, нельзя писать лишь абстрактное повышение
- **Мелкие конфликты как можно скорее выплачивают обратную связь**; не откладывать точки 爽 бесконечно
- **У ключевого противника должен быть мозг**: пробы, ошибочные суждения, контратаки
- Можно оставить человека в живых, ловить на живца, изображать слабость, убивать чужими руками, но лишь при условии большей выгоды, и никогда из-за мягкосердечия
- Использовать действия, раны, звуки, вес, удар, температуру, чтобы приземлить «силу», меньше использовать пустые суждения
- **В каждой сцене продвигать хотя бы одно**: информацию, статус, ресурсы, потери, ненависть, уровень культивации

### Нарратив «сянься»

- Культивация и постижение Дао — ядро нарратива, но они должны вплетаться в сюжет, а не быть самостоятельной проповедью
- **Сцены постижения Дао писать пятью чувствами, а не вливать абстрактные философские рассуждения**
- Ощущение правил в мире «сянься» должно быть сильным: карма, небесная кара, удача — всё это инструменты нарратива
- Долги по человеческим отношениям и связанность долгом — специфичные для «сянься» движущие силы
- Школьная политика, межсектантская игра — важные средства раскладки
- Бой строится на заклинаниях, магических артефактах, построениях, с вниманием к ощущению пространства и масштаба

### Справочник по ритму

| Жанр | Правила ритма |
| --- | --- |
| Фэнтези | В течение трёх глав обязательна явная обратная связь: удар по лицу, выплата выгоды, информационный переворот, смена статуса |
| Сянься | Культивация / постижение Дао чередуются с боями, каждые 3–5 глав — небольшой прорыв или ключевая добыча |

### Различия между китайским и западным «сяньсяем»

> Эти правила в основном рассчитаны на китайское «фэнтези» / «сянься». Если нужны правила для англоязычного жанра культивации, смотрите `cultivation.md` из InkOS — там используется подключаемая система наименований вроде Copper/Iron/Jade/Gold, а не прямое применение китайских слов для уровней.
