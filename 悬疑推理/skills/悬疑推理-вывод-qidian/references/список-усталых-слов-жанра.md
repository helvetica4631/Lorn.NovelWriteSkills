# Список «усталых» слов жанра детектива-расследования

> Источник: усвоено из «железных правил языка» InkOS `horror.md`
> Область применения: жанр детектива-расследования
> Норма контроля: не более 2 раз на тысячу знаков

## Усталые слова первого уровня

| Усталое слово | Пояснение | Направление замены |
| --- | --- | --- |
| 真相只有一个 (правда только одна) | Окаменевшая формула дедукции, запрещена | Вместо объявления — вывод из улик |
| 密室 (запертая комната) | Чрезмерно заезженный сеттинг детектива | Писать конкретное алиби или физическое противоречие |
| 不在场证明 (алиби) | Стандартный элемент детектива, нужна более конкретная подача | Писать конкретные детали конфликта на временной линии |
| 凶手是 (убийца — это) | Фраза-спойлер детективного романа | Сохранять интригу, двигаться по цепочке улик |
| 破案/结案 (раскрыть дело / закрыть дело) | Ярлык вместо процесса | Писать конкретные звенья (вычислен подозреваемый / найдена ключевая улика) |

## Усталые слова второго уровня

| Усталое слово | Пояснение | Направление замены |
| --- | --- | --- |
| 线索中断了 (нить оборвалась) | Шаблонная фраза детектива | Писать конкретный тупик (камера не засняла / свидетель изменил показания) |
| 直觉告诉我 (интуиция подсказывает мне) | Ленивый приём детектива | Писать конкретное аномальное наблюдение |
| 一定有问题 (тут точно что-то не так) | Расплывчатое суждение | Писать конкретное противоречие (время не сходится / мотив не состоятелен) |
| 杀人动机 (мотив убийства) | Стандарт детектива, нужна конкретизация | Писать конкретные человеческие отношения и конфликт интересов |
| 完美犯罪 (идеальное преступление) | Чрезмерно заезженное | Писать конкретные прорехи и точки прорыва |

## Усталые слова третьего уровня

| Усталое слово | Пояснение |
| --- | --- |
| 反转 (разворот) | Исчерпанный повествовательный ярлык, писать конкретный поворот прямо |
| 细思极恐 («мороз по коже от осмысления») | Интернет-словечко, не подходит для основного текста |
| 真凶 (настоящий убийца) | Выражение в духе закрытия дела, использовать осторожно |

## Принцип обработки

Как в `InkOS悬疑恐怖题材规则.md` (правила InkOS для жанра саспенса и ужаса).
