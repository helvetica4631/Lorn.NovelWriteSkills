# Список «усталых» слов киберпанка и жанра будущего

> Источник: усвоено из принципов описания технологий InkOS
> Область применения: жанр киберпанка
> Норма контроля: не более 2 раз на тысячу знаков

## Усталые слова первого уровня

| Усталое слово | Пояснение | Направление замены |
| --- | --- | --- |
| 霓虹灯 (неоновые огни) | Киберпанк-ярлык номер один, чрезмерно заезженный | Писать конкретные источники света и цвета (голографическая реклама / люминесцентные вывески / синие световые полосы на улице) |
| 义肢/义体 (протез / кибернетическое тело) | Универсальное слово для модификаций | Писать конкретную модель, бренд, износ или ощущение в руке |
| 黑客 (хакер) | Расплывшийся профессиональный ярлык | Писать конкретные технические умения и интерфейс операций |
| 数据/信息 (данные / информация) | Универсальное абстрактное слово | Писать конкретные форматы файлов, элементы интерфейса, способы передачи |
| 芯片植入 (имплантация чипа) | Стандартный сеттинг, нужна конкретизация | Писать опыт операции, реакцию отторжения, каналы чёрного рынка |
