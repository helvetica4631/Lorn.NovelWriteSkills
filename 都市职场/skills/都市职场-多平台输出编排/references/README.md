# References многоплатформенного вывода «Городской офисной прозы»

Этот каталог хранит жанровые патчи сохранности при многоплатформенном выводе в жанре «Городская офисная проза»; общую оркестровку, журнал, ворота и правила финальной проверки сходства определяет `общий-оркестрация-вывода-на-платформы`.
